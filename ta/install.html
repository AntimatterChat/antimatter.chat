தொடங்குங்கள்

உங்கள் சொந்த சர்வரில் Antimatter-ஐ இயக்குங்கள்

ஒரு கோப்பு, மூன்று கட்டளைகள், சுமார் பத்து நிமிடங்கள்: Docker உள்ள எந்த Linux சர்வரிலும், Antimatter அதன் தரவுத்தளம், கோப்புச் சேமிப்பகம், GIF சேவை ஆகியவற்றுடன் இயங்கும்.

பத்து நிமிடங்களில் தயார்

உங்களுக்குத் தேவை: Docker, அதன் Compose பிளக்கின் நிறுவப்பட்ட ஒரு Linux சர்வர், குறைந்தது 2 CPU கோர்கள், 4 GB நினைவகம்.

1. compose கோப்பைப் பதிவிறக்குங்கள்

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. சீரற்ற கடவுச்சொற்களுடன் அதன் அமைப்புகளை உருவாக்குங்கள்

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

பயனர்கள் அணுகப் போகும் முகவரியை SITE_URL-இல் அமையுங்கள்; எடுத்துக்காட்டாக, உள்ளூர் நெட்வொர்க்கில் http://192.168.1.20:8065.

3. இயக்குங்கள்

$ docker compose up -d

முதல் முறை தொடங்கும்போது தரவுத்தளம் உருவாக்கப்படுவதால் ஓரிரு நிமிடங்கள் ஆகும். பிறகு உங்கள் உலாவியில் SITE_URL-ஐத் திறந்து உங்கள் கணக்கை உருவாக்குங்கள்: முதல் கணக்கே அமைப்பு நிர்வாகியாகும்; உங்கள் முதல் சமூகத்தை உருவாக்குவதற்கு அமைவு வழிகாட்டி உங்களை அழைத்துச் செல்லும்.

உங்கள் சொந்த டொமைன் மற்றும் HTTPS உடன்

உங்கள் டொமைனின் DNS பதிவை சர்வரை நோக்கிச் சுட்டுங்கள், 80, 443 போர்ட்களைத் திறங்கள், பிறகு டொமைனை .env-இல் சேருங்கள்:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy, Let's Encrypt-இலிருந்து சான்றிதழைப் பெற்று, அதைத் தானாகவே புதுப்பித்துக்கொள்ளும்.

என்னென்ன இயங்குகின்றன

  • antimatter: சர்வர், அதன் செயலிகளுடன் (குறிப்புகள், வெள்ளைப் பலகைகள், குரல் சேனல்கள், அழைப்புகள், கருத்துக் கணிப்புகள் மற்றும் பிற). இது வட்டில் எதையும் சேமிப்பதில்லை: அதன் அமைப்புகள் தரவுத்தளத்திலும் கோப்புகள் சேமிப்புச் சேவையிலும் உள்ளன; எனவே கண்டெய்னரை எப்போது வேண்டுமானாலும் மாற்றலாம்.
  • postgres: தரவுத்தளம்.
  • files: RustFS, பதிவேற்றப்படும் கோப்புகளுக்கான S3-இணக்கமான சேமிப்பகம்.
  • gifs: Antimatter-இன் GIF மற்றும் ஸ்டிக்கர் சேவை, ஒரு தொடக்க ஸ்டிக்கர் தொகுப்புடன்.
  • https: Caddy, https profile உடன் மட்டும்.

தரவுத்தளம், சேமிப்பகம், GIF சேவை ஆகியவை Antimatter மட்டுமே அணுகக்கூடிய ஒரு தனிப்பட்ட நெட்வொர்க்கில் உள்ளன.

GIF தேர்வி காலியாகவே இருந்தால், அமைப்பு கன்சோல் › பிளக்கின்கள் › GIFs என்பதைத் திறந்து, சேவை URL-ஐ http://gifs:8080/v2 எனவும், API சாவியை உங்கள் .env கோப்பில் உள்ள GIFS_API_KEY மதிப்பாகவும் அமையுங்கள்.

மேம்படுத்தல்களும் காப்புப்பிரதிகளும்

# சமீபத்திய இமேஜ்களுக்கு மேம்படுத்துதல்
$ docker compose pull && docker compose up -d
# தரவுத்தளத்தைக் காப்புப்பிரதி எடுத்தல்
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

files volume-ஐயும் காப்புப்பிரதி எடுங்கள், அல்லது எந்த S3 கருவியைக் கொண்டும் சேமிப்பகத்தை நகலெடுங்கள். nginx, உங்கள் சொந்தச் சான்றிதழ்கள் கொண்ட அமைவுக்கு, antimatter-docker-இல் உள்ள production கோப்புகளைப் பாருங்கள்.

வெளியீட்டுக் காப்பகத்துடன்

  1. ஒரு PostgreSQL தரவுத்தளத்தையும் பயனரையும் அமையுங்கள்.
  2. காப்பகத்தை (antimatter-<os>-<arch>.tar.gz) பிரித்தெடுங்கள், எடுத்துக்காட்டாக /opt/antimatter-க்குள். பிறகு config/config.json-இல் உள்ள SqlSettings.DataSource-ஐ (அல்லது AM_SQLSETTINGS_DATASOURCE சூழல் மாறியை) அந்தத் தரவுத்தளத்தை நோக்கி அமையுங்கள்.
  3. சிறப்புரிமை இல்லாத ஒரு பயனராக bin/antimatter மூலம் சர்வரைத் தொடங்கி, http://localhost:8065-ஐத் திறங்கள். முதலில் உருவாக்கப்படும் கணக்கே அமைப்பு நிர்வாகியாகும்.

bin/amctl இயங்கிக்கொண்டிருக்கும் சர்வரைக் கட்டளை வரியிலிருந்து நிர்வகிக்கிறது (சர்வரிலேயே ServiceSettings.EnableLocalMode இயக்கப்பட்டிருந்தால் bin/amctl --local).

அடுத்த படிகள்

  • அழைப்புகள்: குரலும் வீடியோவும் சர்வரைச் சென்றடைய, அழைப்புகளுக்கான போர்ட்டைத் திறங்கள் (இயல்பாக UDP, TCP 8443).
  • மின்னஞ்சல்: அழைப்பிதழ்களுக்கும் அறிவிப்புகளுக்கும் SMTP-ஐ உள்ளமையுங்கள்.
  • AI: ஏஜென்ட் அமைப்புகளில் ஒரு மாடலைச் சேருங்கள்; நீங்களே இயக்கும் சர்வர் உட்பட OpenAI-இணக்கமான எந்த API-யும் வேலை செய்யும்.
  • பேச்சும் மொழிபெயர்ப்பும்: அழைப்பு எழுத்துப்பதிவு, உரக்கப் படித்தல், தானியங்கி மொழிபெயர்ப்பு ஆகியவற்றை, நீங்களே இயக்கும் பேச்சு-உரை, உரை-பேச்சு, மொழிபெயர்ப்பு மாடல்களுடன் இணையுங்கள்.
