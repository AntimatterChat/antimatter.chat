Bottit ja interaktiiviset viestit

Bottitili on ohjelmaa varten luotu käyttäjä. Sillä on oma nimi, kuva ja tunnukset, ja sen nimen vieressä näkyy BOTTI-merkki. Tässä sivussa käsitellään myös viestien interaktiiviset osat: painikkeet, valikot ja dialogit, joita mikä tahansa integraatio voi käyttää.

Miksi bottitili

  • Sen viestit tulevat selvästä identiteetistä, jossa on BOTTI-merkki, eikä kollegan tililtä.
  • Sen tunnukset toimivat edelleen, vaikka asettaja vaihtaisi roolia tai poistuisi (ellei palvelin poista poistettujen omistajien bottitilejä käytöstä, ks. alla).
  • Bottit eivät voi kirjautua salasanan avulla, eikä ne koskaan näe verkkosovellusta.

Sovellukset luovat omat bottitilinsä, kuten Tehtävälista- ja Ohjekirja-bottit, liitännäis-API:n (EnsureBotUser) kautta.

Ota bottitilit käyttöön

Järjestelmän ylläpitäjä ottaa Ota bottitilien luominen käyttöön -asetuksen käyttöön kohdassa Järjestelmäkonsoli › Integraatiot › Bottitilit (ServiceSettings.EnableBotAccountCreation, AM_SERVICESETTINGS_ENABLEBOTACCOUNTCREATION). Asetus on oletusarvona pois käytöstä. Vain järjestelmän ylläpitäjät voivat luoda bottitilejä, ellei he anna oikeutta muihin rooleihin oikeusasetuksissa.

Samalla sivulla Poista bottitili käytöstä, kun omistaja poistetaan käytöstä (ServiceSettings.DisableBotsWhenOwnerIsDeactivated, oletusarvona käytössä) poistaa bottitilin käytöstä, kun sen omistajan tili poistetaan käytöstä.

Luo bottitili

  1. Avaa profiilikuvake yläreunan oikeassa reunassa, valitse Integraatiot › Bottitilit ja sen jälkeen Lisää bottitili.
  2. Syötä Käyttäjätunnus (piisää kirjaimia, numeroita, pisteitä, väliviivoja ja alaviivoja) sekä valinnaisesti Bottin kuvake, Näyttönimi ja Kuvaus.
  3. Valitse Rooli: Jäsen tai Järjestelmän ylläpitäjä, jos botti hallinnoi palvelinta. Anna bottille vain se, mitä se todella tarvitsee.
  4. Valitse post:channels, jotta botti voi lähettää viestejä kaikkiin julkisiin kanaviin, tai post:all, jotta se voi lähettää viestejä kaikkiin kanaviin, myös yksityisiin kanaviin ja suoriin viesteihin, ilman että se on kanavan jäsen.
  5. Aseta, milloin sen oletustunnus vanhenee, ja valitse Luo bottitili.
  6. Kopioi näytetty pääsytunnus. Sitä ei näytetä uudelleen.

Myöhemmin Luo uusi tunnus bottitilin rivillä lisää uuden tunnuksen, ja jokainen tunnus voidaan poistaa käytöstä tai poistaa. Bottitunnukset toimivat, vaikka henkilökohtaiset pääsytunnukset olisivat poistettu käytöstä käyttäjiä varten.

API:n avulla:

# create the bot (you become its owner)
curl -X POST https://chat.example.com/api/v4/bots \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"username": "deploy-bot", "display_name": "Deploy", "description": "Posts deployments"}'

# give it a token
curl -X POST https://chat.example.com/api/v4/users/$BOT_USER_ID/tokens \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"description": "deploy pipeline"}'

Komentoriviltä, kirjautuneena ylläpitäjänä (ei paikallisessa tilassa): amctl bot create deploy-bot --display-name Deploy --with-token --expires-in 90d. Muut rajapinnat: GET /api/v4/bots, PUT /api/v4/bots/{bot_user_id}, POST /api/v4/bots/{bot_user_id}/disable ja /enable sekä POST /api/v4/bots/{bot_user_id}/assign/{user_id} omistajan vaihtamiseksi.

Lisää botti yhteisöihin ja kanaviin

Uusi botti ei ole missään yhteisössä. Lisää se kuten henkilö, yhteisön jäsenhallinnasta tai API:n kautta:

curl -X POST https://chat.example.com/api/v4/teams/$TEAM_ID/members \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"team_id": "'$TEAM_ID'", "user_id": "'$BOT_USER_ID'"}'

curl -X POST https://chat.example.com/api/v4/channels/$CHANNEL_ID/members \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"user_id": "'$BOT_USER_ID'"}'

Botti, jolla on post:channels- tai post:all-oikeus, voi kirjoittaa ilman jäsenyyttä, mutta se saa WebSocket-tapahtumat vain sille kanaville, joihin se on liitetty.

Kirjoita bottin nimellä

Käytä bottin tokenia minkä tahansa API-kutsun yhteydessä; POST /api/v4/posts on yleisin (katso Pääresurssit). Suoraan jollekulle kirjoittamiseksi avaa ensin suora viestikanava:

# returns the channel; use its "id" as channel_id
curl -X POST https://chat.example.com/api/v4/channels/direct \
  -H "Authorization: Bearer $BOT_TOKEN" -H 'Content-Type: application/json' \
  -d '["'$BOT_USER_ID'", "'$USER_ID'"]'

Reaktioita ihmisten kommentteihin varten seuraa WebSocket-yhteyttä bottin tokenilla ja vastaa posted-tapahtumiin, jotka kiinnostavat. Ohita bottin omat viestit, jotta vältät silmukat.

Viesti, jonka vain yksi henkilö näkee (ephemeral-viesti), lähetetään POST /api/v4/posts/ephemeral-kutsulla ja {"user_id", "post": {"channel_id", "message"}}-kuormalla. Se vaatii create_post_ephemeral-oikeuden, joka on oletuksena vain järjestelmäylläpitäjillä. Integraatiot lähettävät ephemeral-viestit yleensä kauttaviivakomentojen ja painikkeiden vastauksina.

Interaktiiviset viestit: painikkeet ja valikot

Mikään liitteitä sisältävä viesti voi kantaa toimintoja: painikkeita ja valikoita, joista voi valita. Ne toimivat API:n, webhookkien ja kauttaviivakomentojen vastauksien kautta lähetetyissä viesteissä. Kun joku käyttää toimintoa, Antimatter kutsuu integraation URL:ää.

{
  "channel_id": "…",
  "message": "Deploy **api 2.4.0** to production?",
  "props": {
    "attachments": [{
      "actions": [
        {
          "id": "approve",
          "type": "button",
          "name": "Approve",
          "style": "primary",
          "integration": {"url": "https://deploy.example.com/actions", "context": {"release": "2.4.0", "action": "approve"}}
        },
        {
          "id": "env",
          "type": "select",
          "name": "Pick an environment",
          "options": [{"text": "Staging", "value": "staging"}, {"text": "Production", "value": "production"}],
          "integration": {"url": "https://deploy.example.com/actions", "context": {"release": "2.4.0", "action": "env"}}
        }
      ]
    }]
  }
}
  • type: button tai select.
  • id: kirjaimet, numerot, väliviivat ja alaviivat, erilainen jokaiselle viestin toiminnolle. Se generoidaan, jos jätät sen pois.
  • style (painikkeet): default, primary, success, good, warning, danger tai heksadesimaalinen väri.
  • options (valikot) tai data_source: users tai channels henkilön tai kanavan valintaan. default_option esivalitsee arvon.
  • integration.url: kohtaus, johon napsautus lähetetään. Sovellus (liitännäinen) voi käyttää omaa reittiään, kuten /plugins/com.example.deploy/actions. integration.context on sinun käytössäsi: se palautuu napsautuksen mukana, eikä asiakkaat koskaan näe sitä.

Integraation vastaanottama pyyntö

{
  "user_id": "…",
  "user_name": "priya",
  "channel_id": "…",
  "channel_name": "releases",
  "team_id": "…",
  "team_domain": "lumen-labs",
  "post_id": "…",
  "trigger_id": "…",
  "type": "button",
  "context": {"release": "2.4.0", "action": "approve"}
}

Valikon tapauksessa type on select ja context.selected_option sisältää valitun arvon.

Vastauksesi

{
  "update": {"message": "Deploy of **api 2.4.0** approved by @priya", "props": {}},
  "ephemeral_text": "Done. The deploy starts in a minute."
}
  • update: korvaa viestin tekstin ja ominaisuudet, esimerkiksi poistaaksesi painikkeet käytön jälkeen (tyhjä props).
  • ephemeral_text: viesti, jonka näkee vain napsauttanut henkilö.
  • goto_location: avattava URL-osoite.
  • Tyhjä ruumis ei muuta mitään.

Palvelin odottaa niin kauan kuin Integraatiopyyntöjen aikakatkaisu sallii (oletus 30 sekuntia). Integraatioiden URL-osoitteet, jotka osoittavat yksityisen verkon osoitteisiin, on ylläpitäjän hyväksyttävä, kuten webhooken kohdalla.

Dialogit

Dialogi on lomake, joka avautuu chatin päälle. Sen voi avata vain vastauksena siihen, mitä henkilö juuri teki, kuten kauttaviivakomennon tai painikkeen, koska se vaatii kyseisen pyynnön trigger_id:n. trigger_id on voimassa integraatiopyyntöjen aikakatkaisun ajan.

curl -X POST https://chat.example.com/api/v4/actions/dialogs/open \
  -H 'Content-Type: application/json' \
  -d '{
    "trigger_id": "'$TRIGGER_ID'",
    "url": "https://deploy.example.com/dialog",
    "dialog": {
      "callback_id": "new-release",
      "title": "New release",
      "introduction_text": "Fill in the release details.",
      "submit_label": "Create",
      "notify_on_cancel": false,
      "state": "anything you want back",
      "elements": [
        {"display_name": "Version", "name": "version", "type": "text", "placeholder": "2.4.0"},
        {"display_name": "Notes", "name": "notes", "type": "textarea", "optional": true},
        {"display_name": "Environment", "name": "env", "type": "select",
         "options": [{"text": "Staging", "value": "staging"}, {"text": "Production", "value": "production"}]},
        {"display_name": "Owner", "name": "owner", "type": "select", "data_source": "users"},
        {"display_name": "Notify the channel", "name": "notify", "type": "bool", "default": "true"}
      ]
    }
  }'
Alueen tyyppiMikä näytetään
textYksirivinen kenttä. subtype: text, email, number, password, tel tai url. min_length ja max_length rajoittavat sitä.
textareaMonirivinen kenttä.
selectLista: options tai data_source users, channels tai dynamic yhdessä data_source_url:n kanssa. multiselect sallii useamman arvon.
boolValintaruutu.
radioYksi valinta vaihtoehdoista options.
date, datetimePäivämäärä tai päivämäärä ja kellonaika.

Jokainen alue ottaa vastaan display_name, name, help_text, placeholder, default ja optional.

Kun henkilö lähettää, Antimatter POSTtaa dialogin url:iin:

{
  "type": "dialog_submission",
  "callback_id": "new-release",
  "state": "anything you want back",
  "user_id": "…",
  "channel_id": "…",
  "team_id": "…",
  "submission": {"version": "2.4.0", "notes": "", "env": "staging", "owner": "…", "notify": true},
  "cancelled": false
}

Vastaa tyhjällä ruumilla sulkeaksesi dialogin, tai pidä se auki ja näytä, mikä on vialla:

{"errors": {"version": "This version already exists."}}

{"error": "…"} näyttää viestin koko lomakkeelle. notify_on_cancel:n kanssa dialogin sulkeminen lähettää "cancelled": true. Dialogit toimivat samalla tavalla sovelluksissa: liitännäis-API:n OpenInteractiveDialog ottaa saman pyynnön.
