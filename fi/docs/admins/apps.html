Sisällytetyt sovellukset

Antimatterin Docker-kuvat sisältävät joukon sovelluksia (Järjestelmäkonsolin pluginit). Tämä sivu luettaa ne, kertoo mitkä ovat käytössä asennuksen jälkeen ja käsittelee kunkin sovelluksen ylläpitäjän tarvitsemat asetukset.

Sisällytetyt sovellukset

Sovellukset näkyvät Liiteohjelmat-osiossa Järjestelmäkonsolissa. Ne ovat mukana kuvassa (hakemistossa /antimatter/prepackaged_plugins) ja allekirjoitettu Antimatterin sovellusavaimella, joten ne asennetaan ilman Internet-yhteyttä.

Oletuksena käytössä olevat sovellukset asennetaan joka käynnistyksen yhteydessä, jos niitä ei ole vielä asennettu, tai päivitetään, jos kuvassa on uudempi versio. Jos poistat sovelluksen käytöstä, se pysyy poissa käytöstä: oletus koskee vain sovelluksia, joita asetukset eivät vielä mainitse. Sovellukset, jotka säilyttävät Mattermost-id:n (Agentit, Puhelut, Kanban, Ohjekirjat ja integraatiot), ovat Antimatterin omia käännöksiä.

Sovellusten ottaminen käyttöön, poistaminen käytöstä ja konfigurointi

Siirry kohtaan Järjestelmäkonsoli › Liiteohjelmat › Liiteohjelmien hallinta. Asennetut lisäosat-osiossa jokaisella sovelluksella on Ota käyttöön- tai Poista käytöstä-valinta, Asetukset ja Poista, sekä sen tila (Käynnissä, Ei käynnissä, Käynnistys epäonnistui…). Jokaisella sovelluksella, jolla on asetuksia, on oma sivunsa kohtaan Järjestelmäkonsoli › Liiteohjelmat.

Oletusarvoinen poissa olevat mukana toimitetut sovellukset asennetaan kuvan omasta kopiosta: avaa Sovelluskauppa tuotemenusta, etsi sovellus ja napsauta Asenna, ota se sitten käyttöön Liiteohjelmien hallinnassa. Komentoriviltä:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Muut komennot: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Sovellusten ottaminen käyttöön konfiguraation kautta

Mikä sovellukset ovat käytössä, määritellään asetuksella PluginSettings.PluginStates, joka on sovellus-tunnisteiden kartoitus. Voit lisätä kohteita siihen amctl:llä; jos Ota automaattiset valmiit lisäosat käyttöön on päällä (oletusarvo), käytössä oleva mukana toimitettu sovellus asennetaan seuraavalla käynnistyksellä:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Tämä on myös tapa asennella Tehtävälista, jota ei tarjota Marketplaces-sovellusikkunassa. Muuttuja AM_PLUGINSETTINGS_PLUGINSTATES toimii myös, mutta se korvaa koko kartoituksen: luettele kaikki sovellukset, jotka haluat käytössä.

Sovellusasetukset

Sovelluksen asetukset tallennetaan polkua PluginSettings.Plugins.<app id> pitkin, ja avaimet ovat pien kirjaimin. Muuta niitä sovelluksen Järjestelmäkonsoli-sivulla tai komennolla amctl config patch, kuten Asetukset-osiossa näytetään. AM_PLUGINSETTINGS_PLUGINS korvaa kerralla kaikkien sovellusten asetukset ja lukitsee ne, joten vältä sen käyttöä.

GIFit

GIF:t-sovellus lisää GIF- ja tarravälilehden emoji-valitsimeen. Sen taustalla toimii Antimatterin GIF-palvelu (gifs-server), joka käyttää Tenor API:ta. Lisää omia GIF-kuvia massiivisesti tuomalla ne manifesin avulla hakemistosta, joka on liitetty kertakäyttöiseen astiaan:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

Tuo aloitustarrat uudelleen päivityksen jälkeen: docker compose run --rm gifs stickers. Manifestin muoto ja muut komennot ovat gifs-serverin README-tiedostossa.

Sähköposti ja kalenteri

Sähköposti ja kalenteri yhdistävät jokaisen henkilön omaan postilaatikkoonsa (IMAP ja SMTP) ja omaan kalenteriinsa (CalDAV). Henkilöt syöttävät palvelimen ja salasanan sovellukseen; salasanat tallennetaan salattuina. Et määritä heille sähköposti- tai kalenteripalvelimia, mutta päätät, mihin he voivat yhdistyä:

Sähköposti, kalenteriSalli sähköpostipalvelimet yksityisissä verkkoissa, Salli kalenteripalvelimet yksityisissä verkkoissa (AllowPrivateNetworks)Ei käytössäEi käytössä, palvelu hylkää yhteydet loopback-, yksityisiin ja linkkilokaali-osoitteisiin, jotta sovelluksia ei voi käyttää sisäisen verkkoasi tavoittamiseen. Ota käyttöön, jos sähköposti- tai kalenteripalvelimesi on yksityisessä osoitteessa.
Sähköposti, kalenteriSalli salaamattomat yhteydet (AllowInsecureConnections)Ei käytössäEi käytössä, yhteyksien on käytettävä TLS:ää (Sähköposti: TLS tai STARTTLS; Kalenteri: HTTPS).
SähköpostiLukemattomien tarkistusväli (minuutteja) (UnreadCheckMinutes)2 minuuttiaKuinka usein lukemattomien lukumäärä tarkistetaan, kun sähköpostipalvelu ei voi lähettää niitä eteenpäin.
SähköpostiSuurin viestin koko (MB) (MaxMessageSizeMB)25 MBRaja viestien koolla, jotka lähetetään ja luetaan.
KalenteriLähetä muistutukset (EnableReminders)onKalenteribotti lähettää suoran viestin tapahtumien edellä (10 minuuttia ennen, tapahtumille, joilla ei ole omaa hälytystään).

Jotta ihmiset voivat kirjautua Gmail- tai Microsoft 365 -postilaatikoihinsa tilinsä sijaan salasanalla, luo OAuth-asiakas ja täytä Sähköposti-sovelluksen Google- tai Microsoft-kentät:

  • Google: Web OAuth-asiakas Gmail API:lla ja alueella https://mail.google.com/.
  • Microsoft: Entra ID -sovellus delegoiduilla oikeuksilla IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email ja profile. Vajaus on common oletuksena.
  • Molemmissa takaisinkytkennän URI on https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (omasi sivuston URL).

Kanban, muistiinpanot, valkotaulu, kyselyt ja ohjekirjat

  • Kanban (focalboard) sijaitsee osoitteessa /kanban (vanhat /boards-linkit ohjaavat sinne). Sen ainoa asetus, Allow Publicly Shared Boards (EnablePublicSharedBoards, pois käytöstä), mahdollistaa taulun muokkaajille taulun jakamisen kenelle tahansa, jolla on linkki, ilman kirjautumista.
  • Muistiinpanoilla ja Kyselyillä ei ole asetuksia.
  • Valkotaulu: järjestelmän ylläpitäjät voivat ladata koko palvelimelle muotojen kirjastot (Excalidraw-.excalidrawlib-tiedostot, enintään 5 Mt kpl) sen asetus sivulla. Yhteisöjen ylläpitäjät hallinnoivat omien yhteisöjensä kirjastoja.
  • Ohjekirjoilla on muutama asetus, pääosin kokeellisia ominaisuuksia; oletusarvot sopivat suurimmalle osalle palvelimia.
  • Memet: Who can add meme templates (oletuksena kaikki, tai ylläpitäjät).
  • Tehtävälistalla ei ole palvelimen asetuksia.

GitHub, GitLab ja Jira

Nämä sovellukset yhdistävät Antimatterin koodinvärastoon ja vikajäljittelemään. Jokainen vaatii OAuth-sovelluksen toisella puolella ja webhoonin, joka osoittaa takaisin Antimatteriin. Ota sovellus käyttöön ja aja sen asennuskomento missä tahansa kanavassa, joka ohjaa sinut vaihe vaiheelta: /github setup, /gitlab setup tai /jira setup.

SovellusOAuth-ohjaus-URLWebhook-URL
GitHubhttps://chat.example.com/plugins/github/oauth/completehttps://chat.example.com/plugins/github/webhook
GitLabhttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/oauth/completehttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/webhook
Jira/jira instance install server <url> tai /jira instance install cloud-oauth <url>; /jira webhook tulostaa webhook-URLit.
Jätä Use Preregistered OAuth Application pois käytöstä GitHub- ja GitLab-sovelluksissa: se perustuu Mattermost-palveluun, jota Antimatterilla ei ole, ja sovellus kieltäytyy käynnistymästä, jos se on päällä. Rekisteröi oma OAuth-sovelluksesi.

GitHub- ja GitLab-sovellukset generoivat webhook-salasanansa ja salausavaimensa ensimmäisellä tallennuksella. GitHub-sovellus voidaan rajoittaa organisaatioihin (GithubOrg) ja GitLab-sovellus ryhmään (GitlabGroup); GitHub Enterprise -tai itse isännöidyn GitLabin tapauksessa aseta sen perus-URL.

Mittarit

Metrics-sovellus kerää palvelimen suorituskykytilastot pienen aikasarjatietokannan sisään Antimatteriin, jotta voit ladata ne tai sisällyttää ne tukipakettiin ilman Prometheusia. Kun se käynnistyy, se ottaa palvelimen metrikkipäätteen (MetricsSettings.Enable) käyttöön. Katso Operations.

Muiden sovellusten asennus

Antimatter ajaa Mattermost-sovelluksia (liitännäisiä). Kolme tapaa lisätä yksi:

  • Etäkaupasta. Ota etäkauppa käyttöön (PluginSettings.EnableRemoteMarketplace) on oletusarvona poissa, ja Kaupan URL (PluginSettings.MarketplaceURL) on tyhjä: Antimatter ei käytä Mattermostin sovelluskauppaa ja ohittaa sen osoitteen, jos Mattermostin asetuksissa on se vielä. Luetteloidaksesi luotettavan sovelluskauppapalvelimen sovellukset, ota asetus käyttöön ja aseta sen URL. Sen sovelluskaupan Antimatterin mukana toimitetut sovellukset (Calls, Playbooks, Kanban ja muut) ovat piilossa, joten ne eivät voi korvata Antimatterin omia: Salli Markkinapaikan Antimatter-liiteohjelmien rakennelmia (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) on oletusarvona poissa.
  • Lähettämällä paketti (.tar.gz). Lähetys on oletusarvoisesti poistettu käytöstä, eikä sille ole vaihtoehtoa Järjestelmäkonsolissa: aseta AM_PLUGINSETTINGS_ENABLEUPLOADS=true ja käytä sitten Lähetä liiteohjelma -toimintoa Liiteohjelmien hallinnassa tai komentoa amctl --local plugin add app.tar.gz.
  • URL:stä: amctl plugin install-url <url>, myös kun lähetys on käytössä.

Antimatter tarkistaa sovellusten allekirjoitukset luottamustensa avainparien avulla: Antimatterin avain, avain, jolla Mattermost, Inc. allekirjoittaa julkaisemansa sovellukset (joten itse lataamasi Mattermost-sovellus asennetaan) ja kaikki avaimet, jotka lisäät kohtaan PluginSettings.SignaturePublicKeyFiles. Kun Vaadi lisäosan allekirjoitusta (PluginSettings.RequirePluginSignature, oletusarvoisesti poistettu käytöstä) on käytössä, allekirjoittamattomat sovellukset hylätään ja lähetys poistetaan käytöstä.

Sovellus ajetaan palvelimen sisällä ja sillä on täysi pääsy sen tietoihin. Asenna vain sovelluksia, joita luotat.

Jotkut Mattermostin maksullisille versioille tehdyt sovellukset tarkistavat Mattermost-lisenssin itsenäisesti ja kieltäytyvät ajamasta; Antimatter ei väitä omaavansa sellaista niiden puolesta.
