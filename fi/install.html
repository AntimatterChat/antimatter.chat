Antimatter omalle palvelimellesi

Yksi tiedosto, kolme komentoa ja noin kymmenen minuuttia: Antimatter sekä sen tietokanta, tiedostotallennus ja GIF-palvelu millä tahansa Linux-palvelimella, jolla on Docker.

Käynnissä kymmenessä minuutissa

Tarvitset Linux-palvelimen, jossa on Docker ja sen Compose-lisäosa, vähintään 2 suoritinydintä ja 4 Gt muistia.

1. Lataa compose-tiedosto

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Luo asetukset satunnaisine salasanoineen

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Aseta SITE_URL-arvoksi osoite, jota käyttäjät käyttävät, esimerkiksi lähiverkossa http://192.168.1.20:8065.

3. Käynnistä

$ docker compose up -d

Ensimmäinen käynnistys kestää minuutin tai kaksi, kun tietokantaa luodaan. Avaa sitten SITE_URL selaimessa ja luo tilisi: ensimmäisestä tilistä tulee järjestelmän ylläpitäjä, ja käyttöönotto opastaa sinut luomaan ensimmäisen yhteisösi.

Oma verkkotunnus ja HTTPS

Osoita verkkotunnuksesi DNS-tietue palvelimeen, avaa portit 80 ja 443 ja lisää verkkotunnus .env-tiedostoon:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy hakee varmenteen Let's Encryptiltä ja uusii sen itsestään.

Mitä käynnistyy

  • antimatter: palvelin sovelluksineen (muistiinpanot, valkotaulut, äänikanavat, puhelut, kyselyt ja muut). Se ei tallenna mitään levylle: sen asetukset ovat tietokannassa ja tiedostot tallennuspalvelussa, joten kontin voi vaihtaa milloin tahansa.
  • postgres: tietokanta.
  • files: RustFS, S3-yhteensopiva tallennustila ladatuille tiedostoille.
  • gifs: Antimatterin GIF- ja tarrapalvelu sekä aloitustarrapaketti.
  • https: Caddy, vain https-profiilin kanssa.

Tietokanta, tallennustila ja GIF-palvelu ovat yksityisessä verkossa, johon vain Antimatterilla on pääsy.

Jos GIF-valitsin pysyy tyhjänä, avaa Järjestelmäkonsoli › Lisäosat › GIFs ja aseta palvelun URL-osoitteeksi http://gifs:8080/v2 ja API-avaimeksi .env-tiedostosi GIFS_API_KEY.

Päivitykset ja varmuuskopiot

# päivitä uusimpiin levykuviin
$ docker compose pull && docker compose up -d
# varmuuskopioi tietokanta
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Varmuuskopioi myös files-taltio tai replikoi tallennustila millä tahansa S3-työkalulla. Jos haluat käyttää nginxiä ja omia varmenteitasi, katso tuotantoympäristön tiedostot antimatter-docker-varastosta.

Julkaisupaketista

  1. Luo PostgreSQL-tietokanta ja -käyttäjä.
  2. Pura paketti (antimatter-<os>-<arch>.tar.gz) esimerkiksi hakemistoon /opt/antimatter ja osoita tiedoston config/config.json asetus SqlSettings.DataSource (tai ympäristömuuttuja MM_SQLSETTINGS_DATASOURCE) tietokantaan.
  3. Käynnistä palvelin komennolla bin/antimatter tavallisena käyttäjänä ilman pääkäyttäjän oikeuksia ja avaa http://localhost:8065. Ensimmäisestä luodusta tilistä tulee järjestelmän ylläpitäjä.

bin/amctl hallitsee käynnissä olevaa palvelinta komentoriviltä (palvelimella itsellään bin/amctl --local, kun ServiceSettings.EnableLocalMode on käytössä).

Seuraavat vaiheet

  • Puhelut: avaa puheluportti (oletuksena UDP ja TCP 8443), jotta ääni ja video pääsevät palvelimelle.
  • Sähköposti: määritä SMTP kutsuja ja ilmoituksia varten.
  • Tekoäly: lisää malli agenttien asetuksissa; mikä tahansa OpenAI-yhteensopiva API käy, myös itse ylläpitämäsi palvelin.
  • Puhe ja käännökset: ohjaa puheluiden transkriptio, ääneen luku ja automaattinen kääntäminen itse ylläpitämillesi puheentunnistus-, puhesynteesi- ja käännösmalleille.
