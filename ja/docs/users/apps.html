アプリ

Antimatterには、チャットと並行して動作するアプリが用意されています。一緒に編集できるメモとホワイトボード、Kanbanボード、カレンダーとメール、投票、ToDoリストなどです。ここでは、各アプリを開く方法とその用途について説明します。

アプリの検索と開き方

サーバーにどのアプリがあるかは管理者が選択するため、このページに記載されているすべてのアプリが表示されない場合があります。ほとんどのアプリには、ウィンドウの右端にあるあなたのアバターの下に位置するアプリレールにアイコンが表示されます。アイコンにカーソルを合わせるとアプリ名が表示され、クリックすると会話の横のパネルにアプリが開きます。もう一度クリックするとパネルを閉じることができます。パネルの端をドラッグして幅を広げることができます。デフォルトの幅に戻すで元に戻せます。

アプリは他の場所にも表示されます：

  • メッセージボックスの+メニュー（ファイルなどを追加）、例えば投票を作成など。
  • 絵文字ピッカーのタブ：GIFs、ステッカー、ミーム。
  • メッセージのその他のアクションメニュー内のメッセージアクション部分。例えばToDoに追加やプレイブックを実行などです。
  • スラッシュコマンド、例えば/pollや/todo：/を入力するとリストが表示されます。
  • 全ページ表示: KanbanとPlaybooksは、アプリレールの下端にあるAntimatterについてメニュー内のプロダクトにリストされています。パネル内にもページ全体で開くボタンがあります。
  • 一部のアプリの設定は、あなたの設定内のプラグインセクションにあります。

スマートフォンでは、アプリレールは右側のドロワー内にあります。左にスワイプするか、会話ヘッダーのさらに › メンバーとアプリを選択してください。

メモ

Notesは、チャットの横で複数の人が同時に編集できるドキュメントです。他のユーザーが入力している間、そのカーソルと名前が表示され、入力した内容はすべて自動的に保存されます。

メモの作成

  1. アプリレールでNotesをクリックします。
  2. タブを選択します：このチャンネルはチャンネルの全メンバーが読み書きできるメモ、マイはあなただけが閲覧できる個人用メモです。
  3. +（このチャンネルに新しいメモまたは新しい個人用メモ）をクリックします。「Untitled note」が開きます。
  4. タイトルを入力してから本文を書きます。フォーマットバーには、太字、斜体、取り消し線、見出し、リスト、チェックリストがあります。リンク、引用、コードも使用できます。@を入力すると、チャンネルのメンバーをメンションできます（メモ内のメンションは誰にも通知されません）。
  5. すべてのメモをクリックして、リストに戻ります。

チャンネル内のメモにタイトルが付けられると、Antimatter はそのチャンネルに「メモを共有しました」と投稿し、メモを開くボタンを表示します。

メモのその他の機能

メモにスターを付けると、お気に入りタブから検索できます。メモの⋯メニューには、チャンネルに共有（リンク付きカードを投稿します）、~channelに共有（個人メモを恒久的にチャンネルメモにします）、バージョン履歴（表示しこのバージョンを復元する）、Markdownとしてエクスポート、削除があります。チャンネルメモの削除は、メモの作成者とチャンネルの管理者のみ可能です。

ホワイトボード

ホワイトボードは、みんなで一緒に描くキャンバスです。図形、矢印、テキスト、フリーハンド描画が可能で、全員のポインターがリアルタイムで表示されます。

  1. アプリレールのホワイトボードをクリックします。
  2. メモと同様に、このチャンネルまたは自分のものを選択し、+（このチャンネルに新しいボードまたは新しい個人ボード）をクリックします。
  3. ツールで描画します：選択と移動 (V)、移動 (H)、長方形 (R)、楕円 (O)、矢印 (A)、描画 (P)、テキスト (T)、消しゴム (E)。ツールバーで色、線種、フォントを選択し、ライブラリから図形を選択します。元に戻す (Ctrl+Z)で直前の変更を取り消せます。

ボード操作メニューには、全画面表示、ボード全体を表示、.excalidraw、PNG、SVG形式でのダウンロード、バージョン履歴、.excalidrawファイルを読み込む…（全員のボードが置き換えられます）、チャンネルへの共有、削除があります。ホワイトボードはAntimatterサーバー上に保存されます。

Kanban

カンバンボードは、ワークを「ToDo」、「進行中」、「完了」などのカラム内のカードとして整理します。ボードは、テーブル、ギャラリー、カレンダー形式でも表示できます。

チャンネルのボードを開く

アプリレールのカンバンをクリックします。パネルにはチャンネルにリンクされたボードがリスト表示され、クリックすると開きます。まだリンクされていない場合は、…にボードをリンクをクリックし、ボードの横のリンクをクリックするか、ボードを作成します。チャンネルのメンバーは、リンクされたボードのエディターになります。

ボードで作業する

  • すべてのボードを表示するには、Kanbanを全ページ表示として開きます。パネル内のページ全体で開く、またはAntimatterについて › プロダクト › Kanbanを選択してください。
  • ボードを作成するには、+ ボードを追加をクリックし、テンプレート（会議アジェンダ、プロジェクトタスク、ロードマップ、スプリントプランナーなど）から開始するか、空のボードを作成します。
  • カラム内の + 新規 をクリックしてカードを追加します。カードを開くと、プロパティの設定、テキスト・チェックボックス・画像の追加、ファイルの添付、コメントの投稿ができます。カード内で誰かをメンションすると、その人に通知が届きます。
  • カードをカラム間へドラッグします。グループ化、フィルター、ソート、カードを検索を使用して見つけることができ、ビューを追加でテーブル、ギャラリー、カレンダービューを作成できます。
  • ボードの 共有 を使用して、ボードの閲覧または編集を許可するユーザーを選択します。

カレンダー

カレンダーアプリは、チャット横にあなたのカレンダーを表示し、リマインダーを送信し、Antimatter 内でミーティングを行うことを可能にします。Nextcloud、Fastmail、Radicale など、CalDAV を使用するカレンダーサーバーと連携できます。

カレンダーの接続

  1. アプリレールで カレンダー をクリックします。
  2. カレンダーの接続 で、CalDAV サーバー のアドレス（多くの場合、プロバイダーのドメイン名のみで構いません）、ユーザー名、パスワード を入力します。プロバイダーがアプリパスワードを提供している場合は、それを使用してください。
  3. アラームのないイベントのリマインダー のタイミングを選択し、接続 をクリックします。

パスワードは Antimatter サーバー上で暗号化されて保存されます。後でこれらの詳細を変更したり、接続を解除したりするには、パネル内の アカウント設定 を使用します。

使用方法

  • アジェンダ と 週 を切り替え、前へ、今日、次へ で移動し、カレンダーのチップをクリックして表示または非表示に切り替えます。
  • 新しいイベントをクリックし、タイトル、開始、終了を入力し、必要に応じて繰り返し、リマインダー、場所、説明を入力してから保存するをクリックします。イベントをクリックすると、変更または削除できます。
  • Antimatterで会議を行うには、Antimatterで会議をチャンネルまたは音声チャンネル、または通話に設定し、チャンネルを選択します。時間になると、イベントに通話を開始、通話に参加、または参加するが表示されます。
  • リマインダーはカレンダーボットからのダイレクトメッセージとして届き、通話がある場合は通話に参加するためのリンクが付随します。

このアプリはあなた自身のカレンダーのみを表示し、他の人に招待を送信しません。

メール

メールアプリは、チャット横にメールボックスを表示するため、Antimatter を離れずにメールの読み取り、返信、共有を行うことができます。

メールボックスの接続

  1. アプリレールで メール をクリックします。
  2. 管理者が設定している場合、GoogleでサインインまたはMicrosoftでサインインをクリックします。それ以外の場合、または他のプロバイダーを使用する場合、電子メールアドレスとお名前を入力し、受信メール (IMAP)サーバーと送信メール (SMTP)サーバー、それぞれのセキュリティ、ポート、ユーザー名、パスワードを入力します。プロバイダーのヘルプページにこれらの詳細が記載されています。
  3. 接続 をクリックします。

使用方法

  • フォルダーを選択し、このフォルダーを検索で検索し、メッセージをクリックして読みます。インターネットからの画像は、画像を表示をクリックするまで非表示になります。
  • 返信する、全員に返信、または進むで応答するか、新しいメッセージで入力してください。メッセージはプレーンテキストのみで、新しいファイルを添付することはできません。
  • チャンネルに共有をクリックすると、メールの送信者、件名、抜粋をコメント付きでチャンネルに投稿できます。

投票

投票は会話内で質問を行い、全員がワンクリックで投票できます。結果はリアルタイムで更新されます。

  1. メッセージボックスの+をクリックして投票を作成を選択するか、/pollと入力します。
  2. 質問と少なくとも2つの選択肢を入力します。選択肢を追加で最大10個まで追加できます。
  3. 複数選択を許可する場合は複数回答を許可をオンにし、誰が何に投票したかを見せない場合は匿名投票をオンにします。
  4. 期間を1時間から1週間の間で選択するか、終了なしにします。
  5. 投票を公開をクリックします。

投票するには選択肢をクリックし、もう一度クリックすると投票を取り消せます。投票は期間終了時、または作成者またはチャンネル管理者が投票を終了をクリックした時点で終了し、その後最終結果が表示されます。

1行で投票全体を書くこともできます: /poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h。すべてのオプションについては /poll help を入力してください。

ToDo

ToDoはToDoリストを管理します：自分自身のもの、チャンネル用の共有リスト、および他の人に送ったタスクです。

  • アプリレールのToDoをクリックします。このチャンネルタブで、チャンネルの共有リストにタスクを追加し、割り当て…を使用してメンバーに割り当てます。リストにスターを付けてフォローすると、フォロー中のリストはフォロー中タブに集約されます。
  • マイタブには、あなた自身のタスク、チャンネルであなたに割り当てられたタスク、およびあなたに送信されたまたはあなたから送信されたタスクが表示されます。送信先…で相手を選択してタスクを送信できます。相手は承認、拒否、または完了としてマークを選択できます。
  • メッセージをタスクに変換するには、そのメニューからメッセージアクション › ToDoに追加を選択してください。
  • タスクが完了したら完了にするをクリックします。

個人タスクには、/todo add …、/todo list、/todo send @someone …も使用できます。

GIF、ステッカー、ミーム

メッセージボックスの絵文字（スマイリーフェイス）をクリックします。これらのアプリが設定されている場合、ピッカーには絵文字の隣にGIF、ステッカー、ミームタブが表示されます。

  • GIF: 検索するか、お気に入り、最近使用したもの、トレンド、カテゴリを閲覧できます。GIFをクリックするとすぐに送信されます。星マークをクリックするとお気に入りに追加できます。また、/gif と数語を入力することもできます。
  • ステッカー: 検索するかステッカーパックを閲覧し、ステッカーをクリックして送信します。/sticker も使用できます。
  • ミーム: テンプレートを選択し、ミームを作成 でテキストを入力し、プレビューを確認して ミームを投稿 をクリックします。また、/meme を入力するか、/meme help を入力して1行で記述する方法を確認することもできます。

サーバーの設定によっては、検索ボックス横の + を使用して、独自のGIF、ステッカー、ミームテンプレートを追加できる場合があります。

プレイブック

プレイブックは、毎回同じ手順で進める作業用の再利用可能なチェックリストです。インシデント、リリース、新入社員の歓迎などです。使用するたびに 実行 が開始され、独自のタスク、担当者、ステータス更新、そして最後に振り返りが行われます。

  • アプリレールの プレイブック をクリックすると、現在のチャンネルの実行状況を確認し、プレイブックを実行 で開始したり、新しいチェックリスト で素早く作成したりできます。
  • プレイブックの作成または編集には、全画面を開きます：Antimatterについて › プロダクト › プレイブック。プロダクトリリース、インシデント解決、または従業員オンボーディングなどのテンプレートから始めるか、空のプレイブックから始めることもできます。
  • 実行を開始するには、プレイブック上の実行をクリックし、実行に名前と概要を付け、チャンネルを作成するか既存のチャンネルにリンクするかを選択し、実行開始をクリックします。メッセージに対してメッセージアクション › プレイブックを実行を選択することもできます。
  • 実行中は、タスクにチェックを入れ、割り当てたり期限を指定したりし、更新を投稿をクリックして現在の状況を全員に共有します。オーナーは最後に完了をクリックします。

/playbook を入力すると、/playbook run や /playbook update などのコマンドを確認できます。

GitHub、GitLab、Jira

これらのアプリは、Antimatter を開発者が使用するツールに接続します。まず管理者が設定する必要があります。その後:

  1. /github connect、/gitlab connect、または /jira connect を入力してアカウントを接続し、リンクに従ってそのサイトでサインインします。GitLab の場合は、デスクトップアプリではなくWebブラウザでこれを行ってください。
  2. その後、誰かにメンションされたとき、レビューを依頼されたとき、またはタスクが割り当てられたときにダイレクトメッセージが届くようになります。
  3. チャンネルがリポジトリやプロジェクトをフォローするには、/github subscriptions add owner/repo、/gitlab subscriptions add group/project、または /jira subscribe を使用します。
  4. メッセージから問題を作成または添付するには、メッセージのメッセージアクションからGitHub Issueを作成、GitLab Issueを作成、Jira Issueを作成、または該当する…に添付項目を選択してください。

すべてのコマンドについては、/github help、/gitlab help、または /jira help を入力してください。

モバイルアプリでのアプリ

モバイルアプリでは、投票の作成と投票、GIF やステッカーの送信、あなたに送信されたタスクへの回答が可能です。メモとホワイトボードはアプリ内のブラウザウィンドウで開かれます。Kanban、カレンダー、メール、ミームは現時点ではモバイルアプリには対応していません。これらには Web またはデスクトップアプリを使用してください。
