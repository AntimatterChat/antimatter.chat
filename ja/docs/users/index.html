Antimatter の使い方

このガイドは、職場やコミュニティでAntimatterサーバー上でチャットするすべての人向けです。技術的な知識は不要です。ここから始めて、サインインと操作方法を学びましょう。

このガイドの内容

Antimatterは、チームやコミュニティと対話する場所です。チャンネル、プライベートな会話、通話、共有メモやホワイトボードなどのアプリを通じて交流できます。このガイドの各ページでは、各操作の手順をステップバイステップで解説します：

  • メッセージの作成：書式設定、メンション、絵文字、返信とスレッド、編集、下書き、予約投稿など。
  • コミュニティとチャンネル：参加、サイドバーの整理、ダイレクトメッセージとグループメッセージ。
  • 通話と音声チャンネル：会話、画面共有、ライブ字幕。
  • アプリ：メモ、ホワイトボード、Kanbanボード、カレンダー、メール、投票、ToDoリストなど。
  • AIエージェント：サーバーで利用可能な場合の、要約、書き換え、質問応答。
  • 通知とステータス：どのような通知が届き、いつ届くか。
  • プロフィールとプライバシー：プロフィール、メッセージを受け取れる相手、ブロック、アカウントのセキュリティ。
  • 検索と物事の見つけ方：検索、メンション、保存されたメッセージ、未読メッセージ。
  • 設定とショートカット：テーマ、言語、キーボードショートカット。

各Antimatterサーバーは独自の管理者によって運営されており、管理者が有効にする機能やアプリを選択します。このガイドにある内容が表示されない場合は、おそらくあなたのサーバーでは無効化されています。管理者に確認してください。

サインイン

Antimatterには中央のサインインサイトはありません。各組織やコミュニティが独自のサーバーを運営しており、それぞれに独自のアドレス（例：chat.example.com）があります。そのアドレスは、管理者またはあなたを招待した人から受け取ります。

  1. Webブラウザでそのアドレスを開くか、デスクトップアプリまたはモバイルアプリに追加してください（デスクトップアプリとモバイルアプリを参照）。
  2. アカウントにログインする画面で、メールアドレスまたはユーザー名とパスワードを入力し、ログインをクリックします。組織が独自のサインインシステムを使用している場合は、「または以下でログイン」の下にあるそのボタンをクリックしてください。
  3. 多要素認証を有効にしている場合は、認証アプリからコードを入力します。

招待リンクを受け取った場合は、リンクを開いてアカウントを作成します。アカウントを作成するフォームにメールアドレス、ユーザー名、パスワードを入力し、アカウントを作成するをクリックします。パスワードをお忘れの場合は、パスワードをお忘れですか?をクリックしてメールアドレスを入力してください。新しいパスワードを設定するためのリンクが届きます。

一部のコミュニティでは、新参者への歓迎としていくつかの質問が用意されており、その回答によって適切なロールとチャンネルが割り当てられます。回答するか、スキップをクリックしてください。

ウィンドウ

Antimatterのウィンドウは、左から右へ5つのカラムで構成されています。

  1. 画面の左端にあるコミュニティレール：所属する各コミュニティには丸いアイコンが1つずつ表示されます。ドットは未読メッセージがあることを示し、数字はメンションの件数です。アイコンの下にあるチームを追加（+）から、コミュニティへの参加または作成ができます。最下部には、新しいダイレクトメッセージを送ってきた人の写真と、すべてを検索（虫眼鏡アイコン）があります。
  2. サイドバー：現在のコミュニティ名（クリックするとメニューが開きます）と、カテゴリごとにグループ化されたそのチャンネルがリスト表示されます。最下部の開いている会話には最近のダイレクトメッセージがリスト表示され、その横の吹き出しアイコン（すべてのダイレクトメッセージ）からは、すべてのダイレクトメッセージ、メンション、フォロー中のスレッド、保存されたメッセージ、下書き、自分へのメモにアクセスできます。
  3. 会話：開いたチャンネルまたは会話のメッセージと、下部のメッセージボックスが表示されます。ヘッダーには、名前（クリックするとチャンネル情報）、短いヘッダーテキスト、検索ボックス、通話、メンション、保存されたメッセージ、ピン留めされたメッセージ、ファイル、メンバーリスト表示などのボタンがあります。
  4. 右側パネル：チャンネルのメンバー、またはスレッド、検索結果、アプリを開いた場合に表示されます。パネルを閉じるにはEscキーを押します。
  5. アプリレール（右端）：上部には自分の写真があり、クリックするとステータスと設定が開きます。中央にはアプリのアイコン、最下部にはAntimatterについてメニューがあります。

通話中、通話ドックがサイドバーの下部に現れ、ミュート、画面共有、退出のボタンが表示されます。通話ドックを参照してください。

小画面での使用

狭いウィンドウやスマートフォンのブラウザでは、サイドバーがドロワーになります。左上のナビゲーションを開くをタップするか、右にスワイプすると、コミュニティとチャンネルが表示されます。左にスワイプすると、メンバーリストとアプリが表示されます。メッセージを長押しすると、そのメニューが開きます。

はじめの一歩

  1. プロフィールを設定：写真を追加し、名前を確認して、他の人に自分であることを認識してもらいましょう。プロフィールを編集を参照してください。
  2. ブラウザが要求した際に通知を許可してください。そうすることで、誰かがあなたを必要としていることを把握できます。通知を参照してください。
  3. 関心のあるチャンネルに参加：コミュニティメニュー（コミュニティ名をクリック）を開き、チャンネルを閲覧を選択します。チャンネルの検索と参加を参照してください。
  4. 挨拶を送る：チャンネルをクリックし、下部のメッセージボックスにテキストを入力して、Enterキーを押します。
  5. 特定のユーザーに直接メッセージを送る：そのユーザーの名前をクリックし、メッセージを選択します。

どこでもすばやくジャンプするには、Ctrl+K（Macの場合は⌘+K）を押して、チャンネル、ユーザー、またはメッセージのいくつかの文字を入力します。

ヘルプの取得

アプリレールの下部にあるAntimatterロゴをクリックすると、Antimatterについてが開きます。ヘルプの下に：

  • ユーザーガイドは、メッセージング、送信、フォーマット、メンション、ファイル、コマンドに関するAntimatterの組み込みヘルプを開きます。
  • キーボードショートカットは、すべてのショートカットをリスト表示します。
  • 書式ヘルプでは、メッセージの書式設定方法について説明しています。
  • 管理者が設定している場合、問題を報告するから問題を管理者に伝えることができます。

同じメニューには、KanbanやPlaybooksなど、フルページとして開くプロダクトもリストされています。メッセージボックスのフォーマットバーにある?ボタンもヘルプを開きます。アカウントやサーバーに関する事項については、管理者に問い合わせてください。

デスクトップアプリとモバイルアプリ

Antimatterは、最近のWebブラウザであればすべてで使用できます。また、コンピュータ用とスマートフォン用のアプリも用意されています。

デスクトップアプリとモバイルアプリの最初のリリースは準備中です。公開されるまで、スマートフォンを含むWebブラウザでAntimatterを使用してください。

デスクトップアプリ

デスクトップアプリは Windows、macOS、Linux で動作します。ブラウザと同じウィンドウを表示し、さらに以下を追加します: ブラウザへの確認なしで通知を受け取ること、アイコンへの未読バッジ、コミュニティレールの上部にある戻ると進むボタン、通話での独自の画面共有ピッカー、そして1つのアプリで複数のサーバーへの接続。

  1. アプリを起動します。ウェルカム画面の後、開始するをクリックします。
  2. サーバーに接続で、管理者から提供されたサーバーURLを入力し、任意のサーバー表示名を設定してから、接続をクリックします。
  3. ブラウザと同様にサインインします。

別のサーバーを追加するには、ウィンドウ上部のサーバーメニューからサーバーを追加を選択するか、アプリの設定内のサーバーから選択します。アプリの設定ウィンドウ（Windows と Linux では Ctrl+,、Mac では環境設定…）では、ログイン時の自動起動、ファイルのダウンロード先、スペルチェックの言語、通知設定も変更できます。

モバイルアプリ

モバイルアプリは Android 11 以降、iOS 18 以降で動作します。

  1. アプリを開き、ウェルカム画面をタップして進みます。
  2. サーバーに接続で、サーバーURLを入力にサーバーのアドレスを入力し、表示名を選択して、接続をタップします。
  3. メールアドレスまたはユーザー名とパスワード、または組織のサインインシステムでサインインします。

モバイルアプリは独自のデザインを採用しています。下部のタブからホーム、検索、メンション、保存されたメッセージ、アカウント（ステータスの設定やアプリの設定を確認できます）にアクセスできます。メッセージ、スレッド、チャンネル、通話、音声チャンネル、投票、GIF、ステッカーに対応しています。Webアプリのいくつかの機能（通話中のカメラ、メモやホワイトボードの編集、Kanban、Calendar、Mailなど）はまだモバイルアプリには搭載されていません。スマートフォンのプッシュ通知には、管理者がサーバー側で設定を行う必要があります。
