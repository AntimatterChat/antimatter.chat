Kebijakan Privasi

Terakhir diperbarui: 16 Oktober 2026.

Halaman ini membahas dua hal: perangkat lunak Antimatter, yang dijalankan organisasi di server mereka sendiri, dan situs web ini, antimatter.chat.

Perangkat lunak Antimatter

Antimatter bersifat self-hosted. Ketika Anda menggunakan server Antimatter, organisasi yang menjalankannya yang menentukan data apa yang disimpan, berapa lama, dan siapa yang dapat mengaksesnya. Proyek Antimatter tidak memiliki akses ke server, akun, atau pesan Anda. Untuk pertanyaan tentang data Anda di server tertentu, hubungi administratornya; kebijakan privasi mereka sendiri yang berlaku.

Apa yang dilakukan perangkat lunak secara mandiri:

  • Tidak ada telemetri. Server tidak mengirim statistik penggunaan, diagnostik, atau data lainnya ke proyek Antimatter, ke Mattermost, Inc. (perusahaan yang perangkat lunaknya menjadi dasar Antimatter), atau ke pihak ketiga lainnya.
  • Koneksi keluar hanya untuk fitur yang diaktifkan oleh administrator, ke layanan yang mereka konfigurasikan: misalnya layanan notifikasi push, penyedia GIF, server email, penyedia identitas untuk single sign-on, atau model AI, suara, atau penerjemahan.
  • Dua pengecualian, yang aktif secara default, dan dapat dinonaktifkan oleh administrator. Pratinjau tautan: ketika seseorang memposting tautan, server mengambil halaman tersebut untuk menampilkan judul dan gambarnya. Dan panggilan: mereka menggunakan server STUN publik Cloudflare (stun.cloudflare.com) untuk menemukan alamat jaringan publik. Server bertanya ke sana saat aplikasi Calls dimulai, dan perangkat masing-masing orang bertanya ke sana saat mereka bergabung ke panggilan. Cloudflare hanya melihat alamat IP dan port server dan masing-masing orang yang bergabung, bukan panggilannya itu sendiri. Administrator dapat menggunakan server STUN mereka sendiri, atau tidak sama sekali; lihat Panggilan dan suara.
  • Fitur AI menggunakan model yang dipilih oleh administrator. Ketika model dihosting oleh pihak ketiga, apa yang dikirim ke mereka (pesan untuk ditulis ulang, percakapan untuk diringkas, audio dari panggilan yang ditranskripsi) akan pergi ke penyedia tersebut. Administrator dapat menggunakan model self-hosted sehingga tidak ada data yang keluar dari jaringan mereka.

Situs web ini

  • antimatter.chat adalah situs web statis yang dihosting di GitHub Pages.
  • Situs ini tidak menggunakan cookie, dan tidak menggunakan analitik, pelacak, atau iklan. Font dan gambar disajikan langsung dari situs ini, sehingga browser Anda tidak membuat permintaan ke situs web lain saat Anda membacanya.
  • Seperti penyedia web lainnya, GitHub menerima alamat IP Anda dan halaman yang Anda minta untuk menyajikannya. Lihat Pernyataan Privasi GitHub.
  • Jika Anda membuka masalah atau berkontribusi di GitHub, apa yang Anda posting di sana bersifat publik dan ditangani oleh GitHub sesuai dengan syarat dan ketentuan mereka.
