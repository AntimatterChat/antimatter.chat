Jalankan Antimatter di server Anda sendiri

Satu file, tiga perintah, sekitar sepuluh menit: Antimatter beserta basis data, penyimpanan file, dan layanan GIF-nya, di server Linux mana pun yang memiliki Docker.

Siap digunakan dalam sepuluh menit

Anda memerlukan server Linux dengan Docker dan plugin Compose-nya, 2 inti CPU, dan memori 4 GB atau lebih.

1. Unduh file compose

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Buat pengaturannya, dengan kata sandi acak

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Atur SITE_URL ke alamat yang akan digunakan orang-orang, misalnya http://192.168.1.20:8065 di jaringan lokal.

3. Jalankan

$ docker compose up -d

Saat pertama kali dijalankan, prosesnya memakan waktu satu atau dua menit selama basis data dibuat. Setelah itu, buka SITE_URL di browser dan buat akun Anda: akun pertama akan menjadi administrator sistem, dan proses penyiapan akan memandu Anda membuat komunitas pertama.

Dengan domain dan HTTPS Anda sendiri

Arahkan data DNS domain Anda ke server, buka port 80 dan 443, lalu tambahkan domain tersebut ke .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy akan mendapatkan sertifikat dari Let's Encrypt dan memperbaruinya secara otomatis.

Apa saja yang berjalan

  • antimatter: server, beserta aplikasinya (catatan, papan putih, kanal suara, panggilan, jajak pendapat, dan lainnya). Server ini tidak menyimpan apa pun di disk: pengaturannya ada di basis data dan file-filenya ada di layanan penyimpanan, sehingga kontainernya bisa diganti kapan saja.
  • postgres: basis data.
  • files: RustFS, penyimpanan yang kompatibel dengan S3 untuk file yang diunggah.
  • gifs: layanan GIF dan stiker Antimatter, dengan paket stiker awal.
  • https: Caddy, hanya dengan profil https.

Basis data, penyimpanan, dan layanan GIF berada di jaringan privat yang hanya bisa dijangkau oleh Antimatter.

Jika pemilih GIF tetap kosong, buka Konsol Sistem › Plugins › GIFs, lalu atur URL layanan ke http://gifs:8080/v2 dan kunci API ke nilai GIFS_API_KEY di .env Anda.

Pembaruan dan pencadangan

# perbarui ke image terbaru
$ docker compose pull && docker compose up -d
# cadangkan basis data
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Cadangkan juga volume files, atau replikasikan penyimpanannya dengan alat S3 apa pun. Untuk penyiapan dengan nginx dan sertifikat Anda sendiri, lihat file produksi di antimatter-docker.

Dengan arsip rilis

  1. Siapkan basis data dan pengguna PostgreSQL.
  2. Ekstrak arsipnya (antimatter-<os>-<arch>.tar.gz), misalnya ke /opt/antimatter, lalu arahkan SqlSettings.DataSource di config/config.json (atau variabel lingkungan AM_SQLSETTINGS_DATASOURCE) ke basis data tersebut.
  3. Jalankan server dengan bin/antimatter sebagai pengguna tanpa hak istimewa, lalu buka http://localhost:8065. Akun pertama yang dibuat akan menjadi administrator sistem.

bin/amctl mengelola server yang sedang berjalan dari baris perintah (bin/amctl --local di server itu sendiri, dengan ServiceSettings.EnableLocalMode).

Langkah berikutnya

  • Panggilan: buka port panggilan (UDP dan TCP 8443 secara default) agar suara dan video bisa mencapai server.
  • Email: konfigurasikan SMTP untuk undangan dan notifikasi.
  • AI: tambahkan model di pengaturan Agents; API apa pun yang kompatibel dengan OpenAI bisa digunakan, termasuk server yang Anda jalankan sendiri.
  • Ucapan dan terjemahan: arahkan transkripsi panggilan, fitur baca dengan suara, dan terjemahan otomatis ke model ucapan-ke-teks, teks-ke-ucapan, dan terjemahan yang Anda jalankan sendiri.
