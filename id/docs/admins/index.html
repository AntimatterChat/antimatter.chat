Menjalankan server

Panduan ini ditujukan untuk administrator sistem yang menginstal dan menjalankan server Antimatter. Panduan ini mengasumsikan Anda sudah familiar dengan Linux, Docker, dan reverse proxy, tetapi belum familiar dengan Antimatter.

Komponen sebuah deployment

Antimatter adalah obrolan tim self-hosted, sebuah fork dari Mattermost. Deployment lengkap terdiri dari bagian-bagian berikut. Hanya tiga bagian pertama yang wajib.

BagianFungsinyaWajib
Server AntimatterSatu program Go (antimatter) yang menyajikan web app, API, dan websockets pada port 8065, menjalankan aplikasi bawaan (plugin), dan membawa media panggilan pada port 8443. Alat baris perintah amctl mengelolanya.ya
PostgreSQLBasis data: pesan, pengguna, komunitas, dan, dalam konfigurasi yang direkomendasikan, konfigurasi server. Versi 15 atau lebih baru.ya
Penyimpanan fileFile, gambar, dan aplikasi yang diunggah: layanan kompatibel S3 (file compose menjalankan RustFS), atau direktori lokal.ya
Reverse proxyHTTPS di depan server: profil Caddy dari file compose, atau nginx Anda sendiri.untuk produksi
Layanan GIF (gifs-server)GIF dan stiker untuk pemilih GIF, dari katalog Anda sendiri. Layanan ini berbicara API Tenor.tidak
Push proxyMeneruskan notifikasi ke aplikasi seluler melalui Apple dan Google.untuk notifikasi seluler
rtcd, server TURNServer media terpisah untuk banyak panggilan, dan relay untuk orang-orang di balik firewall ketat.tidak
Endpoint AIModel di balik agen AI, transkripsi panggilan, baca-loud, dan terjemahan: penyedia cloud atau server yang Anda jalankan.tidak

Antimatter tidak memiliki lisensi dan tidak ada edisi berbayar: single sign-on, LDAP, ketersediaan tinggi, ekspor kepatuhan, retensi data, dan fitur-fitur lain yang Mattermost simpan untuk paket berbayarnya semuanya disertakan.

Persyaratan

  • Server Linux, amd64 atau arm64, dengan 2 core CPU dan 4 GB memori atau lebih untuk beberapa ratus orang, serta ruang disk untuk file yang diunggah oleh pengguna.
  • Docker Engine dengan plugin Compose (docker compose), untuk instalasi yang direkomendasikan.
  • Untuk produksi: nama domain yang menunjuk ke server, dan port 80 dan 443 terbuka untuk HTTPS.
  • Untuk panggilan: port 8443, UDP dan TCP, dapat dijangkau oleh orang-orang yang melakukan panggilan.
  • Untuk email: server SMTP yang dapat digunakan Antimatter untuk mengirim.

Mulai cepat

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Lalu buka URL situs dan buat akun Anda: akun pertama menjadi administrator sistem. Pemasangan menjelaskan setiap langkah dan cara pemasangan lainnya.

Dalam panduan ini

  • Pemasangan: Docker Compose, image, arsip rilis, administrator pertama.
  • Konfigurasi: pengaturan di database atau file, variabel lingkungan AM_, Konsol Sistem, amctl, log.
  • Domain dan HTTPS: URL situs, Caddy, nginx, alamat klien.
  • Panggilan dan suara: port, NAT, TURN, rtcd, transkripsi dan teks langsung.
  • Email dan push: SMTP, proxy push, dan aplikasi seluler.
  • Aplikasi bawaan: aplikasi yang aktif, pengaturannya, dan pemasangan aplikasi lain.
  • AI: model untuk agen, ucapan, dan terjemahan, serta ke mana data dikirim.
  • Masuk dan akun: pendaftaran, kata sandi, MFA, single sign-on, LDAP, tamu, sesi.
  • Cadangan dan peningkatan: cadangan, pemulihan, peningkatan, migrasi dari Mattermost.
  • Operasi: pemantauan, penskalaan, retensi data, kepatuhan, pemecahan masalah.
  • Keamanan: daftar periksa penguatan dan koneksi keluar.

Mengelola komunitas alih-alih server (kanal, peran, moderasi)? Lihat Mengelola komunitas. Membangun integrasi? Lihat Membangun di Antimatter.

Jam pertama Anda

  1. Pasang, dan buat akun administrator segera.
  2. Letakkan server di belakang HTTPS pada domain sendiri.
  3. Konfigurasikan SMTP dan kirim email uji.
  4. Buka port panggilan, dan matikan mode uji aplikasi Panggilan.
  5. Tentukan siapa yang boleh mendaftar, dan aktifkan MFA.
  6. Tinjau koneksi keluar di Keamanan.
  7. Atur cadangan harian.

Mendapat bantuan

Ajukan pertanyaan di diskusi komunitas, dan laporkan bug di repositori komunitas. Laporkan masalah keamanan secara pribadi, seperti dijelaskan dalam kebijakan keamanan.
