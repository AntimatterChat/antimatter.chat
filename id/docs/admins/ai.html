AI

Fitur AI Antimatter menggunakan model yang Anda pilih: penyedia cloud, atau server di jaringan Anda sendiri. Tidak ada data yang dikirim ke mana pun sampai Anda mengonfigurasi model. Halaman ini membahas setiap fitur, data yang dikirim, dan cara menonaktifkannya.

Fitur-fitur AI

FiturDikonfigurasi diJenis modelAktif secara bawaan
Agen AI: obrolan dengan bot, ringkasan utas dan kanal, bantuan di komposerAplikasi AgenLayanan model bahasa besar (LLM) apa punAplikasinya aktif, tetapi tidak melakukan apa-apa sampai Anda menambahkan layanan
Transkrip panggilan dan teks langsungAplikasi PanggilanTranskripsi suara, kompatibel dengan OpenAItidak
Baca kerasServerTeks ke suara, kompatibel dengan OpenAItidak

"Kompatibel OpenAI" berarti server yang menawarkan API HTTP yang sama dengan OpenAI. Sebagian besar server model yang dapat Anda jalankan sendiri melakukannya (misalnya Ollama, vLLM, server llama.cpp, atau server Whisper dan teks ke suara), begitu pula banyak penyedia cloud. Tidak diperlukan lisensi untuk fitur-fitur ini.

Agen AI

Aplikasi Agen (id mattermost-ai) aktif secara bawaan. Pengaturannya terdiri dari dua langkah: tambahkan layanan (koneksi ke penyedia model), lalu buat agen (bot yang menggunakan layanan tersebut).

1. Tambahkan layanan

Buka Konsol Sistem › Plugin › Agen dan, di bawah Layanan AI, klik Tambahkan Layanan AI. Pilih Jenis Layanan:

  • Kompatibel OpenAI: untuk server model yang Anda jalankan sendiri, atau penyedia apa pun dengan API bergaya OpenAI. Isi URL API (misalnya http://ollama:11434/v1 atau http://vllm.internal:8000/v1), dan Kunci API hanya jika server membutuhkannya. Jika server hanya mendukung API Completions Chat, matikan Gunakan API Respons.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: penyedia yang dihosting. Masing-masing membutuhkan Kunci API (Bedrock: wilayah AWS dan kredensial atau peran IAM; Vertex AI: proyek, wilayah, dan akun layanan; Azure: juga URL API).

Lalu, atur Default model (sebuah daftar jika penyedia dapat melaporkan modelnya, atau ketik nama modelnya), dan, jika penyedia tidak melaporkannya, atur Input token limit dan Output token limit. Fallback Service dapat mengambil alih jika layanan ini gagal. Simpan.

Server membuat permintaan ini sendiri, jadi server harus dapat mengakses API: server model dalam proyek compose yang sama, di jaringan Anda, atau di Internet. Permintaan keluar menghormati variabel HTTP_PROXY dan HTTPS_PROXY.

2. Buat agen

Agen dibuat di halaman Agen aplikasi web: buka dari menu produk, atau dengan Kelola di pemilih agen pada panel Agen. Alamatnya adalah https://chat.example.com/plug/mattermost-ai/agents. Setiap agen memiliki Nama Tampilan, Nama Pengguna Agen (cara orang menyebutnya), Layanan, dan secara opsional model, Instruksi Kustom, serta sakelar untuk Aktifkan Visi (gambar) dan Aktifkan Alat. Tab Akses membatasi kanal mana yang dapat digunakan dan pengguna mana yang dapat menggunakannya. Di bawah Fungsi AI di Konsol Sistem, Bot bawaan memilih agen yang digunakan ketika tidak ada yang dipilih, misalnya untuk ringkasan panggilan.

Secara bawaan, setiap pengguna dapat membuat agen mereka sendiri, dengan layanan yang Anda konfigurasikan. Untuk membatasi ini hanya untuk administrator, hapus izin Kelola Agen AI Sendiri dari peran anggota di Konsol Sistem › Manajemen Pengguna › Izin.

Fitur opsional dari aplikasi Agents

  • Embedding search (eksperimental, nonaktif): pencarian semantik atas pesan. Membutuhkan PostgreSQL dengan ekstensi pgvector dan model embedding (OpenAI atau kompatibel dengan OpenAI). Mengirim setiap pesan ke model embedding, termasuk kanal privat dan pesan langsung.
  • Web search (nonaktif): memungkinkan agen mencari di web melalui Google, Brave, atau server SearXNG yang Anda jalankan.
  • Native tools: dengan penyedia yang menawarkannya, agen dapat menggunakan pencarian web milik penyedia (aktif secara default untuk agen baru, jika didukung), pengambilan web, dan eksekusi kode. Ini berjalan di sisi penyedia. Matikan per agen.
  • Model Context Protocol (MCP): hubungkan agen ke server MCP yang Anda percaya, untuk alat tambahan.
  • Debug: Trace Output (nonaktif, log server atau endpoint OpenTelemetry) dan Enable Token Usage Logging, yang menulis jumlah token ke logs/agents/token_usage.log.

Speech-to-text: transkrip dan teks langsung panggilan

Panggilan dapat ditranskripsi, dengan teks langsung, oleh server speech-to-text yang menyediakan endpoint /v1/audio/transcriptions yang kompatibel dengan OpenAI. Konfigurasinya ada di Panggilan dan suara. Jika Ringkaskan transkripsi diaktifkan, agen default juga akan memposting ringkasan dari setiap transkripsi.

Text-to-speech: bacakan

Dengan teks ke suara aktif, setiap menu pesan memiliki Baca dengan suara: server mengirim teks pesan ke API teks ke suara dan memutar audionya. Pengaturan, di Konsol Sistem › Integrasi › Teks ke Suara:

PengaturanKunci dan variabelIsi apa
Baca pesan dengan lantangTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (nonaktif secara default)
URL dasar APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLURL dasar hingga dan termasuk /v1, misalnya http://tts.internal:8000/v1. Server akan memanggil endpoint /audio/speech miliknya.
ModelTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELModel sesuai nama yang digunakan oleh API, misalnya tts-1. Wajib diisi.
SuaraTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICESalah satu suara dari model tersebut, atau kosong untuk menggunakan default.
Kunci APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYDikirim sebagai bearer token. Kosong jika API tidak membutuhkannya.

Sebelum dikirim, server akan menghapus blok kode, tautan, kode emoji, dan format, serta mempertahankan maksimal 4000 karakter. Server meminta audio MP3 dan menyimpan 64 hasil terakhir di memori, sehingga pesan yang dibacakan dua kali hanya dikirim sekali.

Terjemahan otomatis

Terjemahan otomatis menampilkan pesan dari sebuah kanal dalam bahasa masing-masing pembaca. Konfigurasinya ada di Konsol Sistem › Konfigurasi Situs › Lokalisasi, di bawah Terjemahan otomatis:

PengaturanKunciBawaan
AktifkanAutoTranslationSettings.Enablenonaktif
Penyedia terjemahanAutoTranslationSettings.Providerlibretranslate, openai (ditampilkan sebagai "OpenAI-compatible API") atau agents (layanan dari aplikasi Agents)
Bahasa yang diizinkanAutoTranslationSettings.TargetLanguagesen: bahasa yang dapat menjadi target terjemahan pesan
Batas waktu terjemahan (ms)AutoTranslationSettings.TimeoutMs5000
Batasi terjemahan otomatis pada pesan langsung dan pesan grupAutoTranslationSettings.RestrictDMAndGMnonaktif

Setiap penyedia memiliki field-nya masing-masing:

  • LibreTranslate: Endpoint API LibreTranslate dan API Key LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Server LibreTranslate dapat dijalankan di jaringan Anda sendiri.
  • API kompatibel OpenAI: URL dasar API (hingga dan termasuk /v1; server menggunakan endpoint chat completions-nya), Model dan Kunci API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Model terjemahan kecil yang dijalankan secara lokal bekerja dengan baik.
  • Agen: Layanan AI, salah satu layanan yang dikonfigurasikan di aplikasi Agen.

Setelah diaktifkan, admin kanal mengaktifkan terjemahan untuk sebuah kanal di pengaturannya (Terjemahan Otomatis), dan setiap anggota dapat memilih untuk tidak ikut dari menu kanal (Terjemahkan pesan). Dalam pesan langsung dan grup, anggota mana pun dapat mengaktifkannya; dengan pembatasan aktif, terjemahan tidak tersedia di sana. Pesan yang diterjemahkan menampilkan "Diterjemahkan dari …" dengan tautan ke aslinya.

Kode, tautan, sebutan, dan emoji diganti dengan penanda sementara sebelum teks dikirim, lalu dikembalikan setelahnya.

Untuk menyimpan semuanya di jaringan Anda, arahkan setiap fitur ke server yang Anda jalankan sendiri. Jika menggunakan penyedia cloud, periksa ketentuan retensi datanya, dan informasikan ke pengguna Anda fitur mana yang mengirim pesan mereka keluar.

Mematikan AI

Tidak ada satu saklar tunggal: setiap fitur memiliki saklarnya sendiri.

  • Agen: nonaktifkan aplikasi Agen di Konsol Sistem › Plugin › Manajemen Plugin. Ini juga menghapus ringkasan panggilan dan penyedia terjemahan Agen.
  • Transkripsi dan teks langsung: AM_CALLS_ENABLE_TRANSCRIPTIONS=false dan AM_CALLS_ENABLE_LIVE_CAPTIONS=false (nilai bawaan).
  • Baca dengan suara: Baca pesan dengan lantang nonaktif (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, bawaan).
  • Terjemahan: matikan auto-translation (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, nilai bawaan).

Menonaktifkan aplikasi Agents tidak mematikan tiga fitur lainnya: mereka memanggil API mereka sendiri secara langsung.
