Rularea unui server

Acest ghid este destinat administratorilor de sistem care instalează și rulează un server Antimatter. Se presupune că cunoașteți Linux, Docker și proxii inversi, dar nu și Antimatter.

Din ce este alcătuită o instalare

Antimatter este o aplicație de chat pentru echipe, auto-găzduită, un derivat (fork) al Mattermost. O instalare completă are următoarele componente. Doar primele trei sunt obligatorii.

ComponentăCe faceObligatorie
Serverul AntimatterUn program Go (antimatter) care servește aplicația web, API-ul și websockets-ul pe portul 8065, rulează aplicațiile incluse (pluginurile) și transportă media apelurilor pe portul 8443. Instrumentul de linie de comandă amctl îl gestionează.da
PostgreSQLBaza de date: mesaje, utilizatori, comunități și, în configurația recomandată, configurația serverului. Versiunea 15 sau mai nouă.da
Stocarea fișierelorFișierele, imaginile și aplicațiile instalate încărcate: un serviciu compatibil S3 (fișierul de compozare rulează RustFS) sau un director local.da
Un proxy inversHTTPS în fața serverului: profilul Caddy din fișierul de compozare, sau propriul nginx.pentru producție
Serviciul GIF (gifs-server)GIF-uri și stickere pentru selectorul de GIF-uri, din propriul catalog. Folosește API-ul Tenor.nu
Un proxy de notificări pushTrimite notificările către aplicația mobilă prin Apple și Google.pentru notificări mobile
rtcd, un server TURNUn server de media separat pentru multe apeluri și un retransmițător (relay) pentru persoanele aflate în spatele firewall-urilor stricte.nu
Endpoint-uri AIModelele din spatele agenților AI, transcrierii apelurilor, citirii în voce și traducerii: un furnizor de cloud sau servere pe care le rulați voi.nu

Antimatter nu are licență și nu are o ediție plătită: autentificarea unică (single sign-on), LDAP, disponibilitatea ridicată, exporturile de conformitate, reținerea datelor și celelalte funcții pe care Mattermost le rezervă planurilor plătite sunt toate incluse.

Cerințe

  • Un server Linux, amd64 sau arm64, cu 2 nuclee CPU și 4 GB de memorie sau mai mult pentru câteva sute de persoane, și spațiu pe disc pentru fișierele încărcate de utilizatori.
  • Docker Engine cu plugin-ul Compose (docker compose), pentru instalarea recomandată.
  • Pentru producție: un nume de domeniu care indică către server, și porturile 80 și 443 deschise pentru HTTPS.
  • Pentru apeluri: portul 8443, UDP și TCP, accesibil pentru persoanele care apelează.
  • Pentru e-mail: un server SMTP prin care Antimatter poate trimite.

Început rapid

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Apoi deschide URL-ul site-ului și creează-ți contul: primul cont devine administratorul de sistem. Instalarea explică fiecare pas și celelalte moduri de instalare.

În acest ghid

  • Instalarea: Docker Compose, imaginile, arhiva de lansare, primul administrator.
  • Configurarea: setări în baza de date sau într-un fișier, variabile de mediu AM_, Consola de sistem, amctl, jurnale.
  • Domeniu și HTTPS: URL-ul site-ului, Caddy, nginx, adresele clientului.
  • Apeluri și voce: porturi, NAT, TURN, rtcd, transcriere și subtitrări.
  • E-mail și notificări push: SMTP, proxy-ul push și aplicația mobilă.
  • Aplicații incluse: ce aplicații sunt activate, setările acestora, instalarea altora.
  • Inteligență artificială: modele pentru agenți, vorbire și traducere, și ce date ajung unde.
  • Autentificare și conturi: înregistrare, parole, MFA, single sign-on, LDAP, oaspeți, sesiuni.
  • Copii de rezervă și actualizări: copiere de rezervă, restaurare, actualizare, migrare de la Mattermost.
  • Operațiuni: monitorizare, scalare, retenția datelor, conformitate, depanare.
  • Securitate: listă de verificare pentru întărire și conexiuni externe.

Rulezi o comunitate, nu un server (canale, roluri, moderare)? Vezi Gestionarea unei comunități. Construiești integrări? Vezi Construire pe Antimatter.

Prima ta oră

  1. Instalează și creează imediat contul de administrator.
  2. Pune serverul în spatele HTTPS pe un domeniu propriu.
  3. Configurează SMTP și trimite un e-mail de test.
  4. Deschide portul pentru apeluri și dezactivează modul de test al aplicației de apeluri.
  5. Stabilește cine se poate înregistra și activează MFA.
  6. Revizuieste conexiunile externe în Securitate.
  7. Configurează copiile de rezervă zilnice.
