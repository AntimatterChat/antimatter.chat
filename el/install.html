Εγκαταστήστε το Antimatter στον δικό σας διακομιστή

Ένα αρχείο, τρεις εντολές, περίπου δέκα λεπτά: το Antimatter μαζί με τη βάση δεδομένων του, τον αποθηκευτικό χώρο αρχείων και την υπηρεσία GIF, σε οποιονδήποτε διακομιστή Linux με Docker.

Σε λειτουργία μέσα σε δέκα λεπτά

Χρειάζεστε έναν διακομιστή Linux με Docker και το πρόσθετο Compose, 2 πυρήνες CPU και τουλάχιστον 4 GB μνήμης.

1. Κατεβάστε το αρχείο compose

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Δημιουργήστε τις ρυθμίσεις, με τυχαίους κωδικούς πρόσβασης

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Ορίστε στο SITE_URL τη διεύθυνση που θα χρησιμοποιούν οι χρήστες, για παράδειγμα http://192.168.1.20:8065 σε ένα τοπικό δίκτυο.

3. Ξεκινήστε το

$ docker compose up -d

Η πρώτη εκκίνηση διαρκεί ένα με δύο λεπτά, όσο δημιουργείται η βάση δεδομένων. Στη συνέχεια ανοίξτε το SITE_URL στο πρόγραμμα περιήγησης και δημιουργήστε τον λογαριασμό σας: ο πρώτος λογαριασμός γίνεται διαχειριστής συστήματος και η διαδικασία ρύθμισης σας καθοδηγεί στη δημιουργία της πρώτης σας κοινότητας.

Με δικό σας τομέα και HTTPS

Κατευθύνετε μια εγγραφή DNS του τομέα σας στον διακομιστή, ανοίξτε τις θύρες 80 και 443 και προσθέστε τον τομέα στο .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Το Caddy λαμβάνει πιστοποιητικό από το Let's Encrypt και το ανανεώνει αυτόματα.

Τι εκτελείται

  • antimatter: ο διακομιστής, με τις εφαρμογές του (σημειώσεις, λευκοί πίνακες, φωνητικά κανάλια, κλήσεις, ψηφοφορίες και οι υπόλοιπες). Δεν αποθηκεύει τίποτα στον δίσκο: οι ρυθμίσεις του βρίσκονται στη βάση δεδομένων και τα αρχεία του στην υπηρεσία αποθήκευσης, οπότε το container μπορεί να αντικατασταθεί ανά πάσα στιγμή.
  • postgres: η βάση δεδομένων.
  • files: RustFS, αποθηκευτικός χώρος συμβατός με S3 για τα αρχεία που ανεβαίνουν.
  • gifs: η υπηρεσία GIF και αυτοκόλλητων του Antimatter, με ένα αρχικό πακέτο αυτοκόλλητων.
  • https: Caddy, μόνο με το προφίλ https.

Η βάση δεδομένων, ο αποθηκευτικός χώρος και η υπηρεσία GIF βρίσκονται σε ένα ιδιωτικό δίκτυο στο οποίο έχει πρόσβαση μόνο το Antimatter.

Αν ο επιλογέας GIF μένει άδειος, ανοίξτε Κονσόλα συστήματος › Πρόσθετα › GIFs και ορίστε ως URL της υπηρεσίας το http://gifs:8080/v2 και ως κλειδί API το GIFS_API_KEY του αρχείου .env σας.

Αναβαθμίσεις και αντίγραφα ασφαλείας

# αναβάθμιση στις πιο πρόσφατες εικόνες
$ docker compose pull && docker compose up -d
# αντίγραφο ασφαλείας της βάσης δεδομένων
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Κρατήστε αντίγραφο ασφαλείας και του τόμου files ή αναπαράγετε τον αποθηκευτικό χώρο με οποιοδήποτε εργαλείο S3. Για εγκατάσταση με nginx και δικά σας πιστοποιητικά, δείτε τα αρχεία παραγωγής στο antimatter-docker.

Με αρχείο έκδοσης

  1. Δημιουργήστε μια βάση δεδομένων PostgreSQL και έναν χρήστη.
  2. Αποσυμπιέστε το αρχείο (antimatter-<os>-<arch>.tar.gz), για παράδειγμα στο /opt/antimatter, και ρυθμίστε το SqlSettings.DataSource στο config/config.json (ή τη μεταβλητή περιβάλλοντος AM_SQLSETTINGS_DATASOURCE) ώστε να δείχνει στη βάση δεδομένων.
  3. Ξεκινήστε τον διακομιστή με το bin/antimatter, ως χρήστης χωρίς αυξημένα δικαιώματα, και ανοίξτε το http://localhost:8065. Ο πρώτος λογαριασμός που δημιουργείται γίνεται διαχειριστής συστήματος.

Το bin/amctl διαχειρίζεται έναν διακομιστή σε λειτουργία από τη γραμμή εντολών (bin/amctl --local στον ίδιο τον διακομιστή, με το ServiceSettings.EnableLocalMode).

Επόμενα βήματα

  • Κλήσεις: ανοίξτε τη θύρα κλήσεων (UDP και TCP 8443 από προεπιλογή), ώστε ήχος και βίντεο να φτάνουν στον διακομιστή.
  • Email: ρυθμίστε το SMTP για προσκλήσεις και ειδοποιήσεις.
  • AI: προσθέστε ένα μοντέλο στις ρυθμίσεις Agents· λειτουργεί οποιοδήποτε API συμβατό με το OpenAI, ακόμη και ένας διακομιστής που τρέχετε εσείς.
  • Ομιλία και μετάφραση: συνδέστε τη μεταγραφή κλήσεων, την ανάγνωση φωναχτά και την αυτόματη μετάφραση με μοντέλα μετατροπής ομιλίας σε κείμενο, κειμένου σε ομιλία και μετάφρασης που τρέχετε εσείς.
