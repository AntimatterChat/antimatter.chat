Οι εφαρμογές

Το Antimatter διαθέτει εφαρμογές που λειτουργούν παράλληλα με τη συνομιλία: σημειώσεις και λευκοί πίνακες που επεξεργάζεστε μαζί, πίνακες Kanban, το ημερολόγιο και η αλληλογραφία σας, ψηφοφορίες, λίστες εκκρεμοτήτων και πολλά άλλα. Εδώ θα δείτε πώς να ανοίξετε καθεμία και ποιος είναι ο σκοπός της.

Εύρεση και άνοιγμα των εφαρμογών

Ο διαχειριστής σας επιλέγει ποιες εφαρμογές διαθέτει ο διακομιστής σας, οπότε ενδέχεται να μην βλέπετε όλες αυτές που αναφέρονται σε αυτήν τη σελίδα. Οι περισσότερες εφαρμογές έχουν εικονίδιο στη στήλη εφαρμογών, τη στενή στήλη στη δεξιά άκρη του παραθύρου, κάτω από τη φωτογραφία σας. Κάντε δείκτη πάνω σε ένα εικονίδιο για να δείτε το όνομα της εφαρμογής και κάντε κλικ σε αυτό για να ανοίξετε την εφαρμογή σε ένα πάνελ δίπλα στη συνομιλία. Κάντε κλικ ξανά για να το κλείσετε. Σύρετε την άκρη του πάνελ για να το κάνετε πιο πλατύ· με Επαναφορά προεπιλεγμένου πλάτους επανέρχεται στην αρχική του κατάσταση.

Οι εφαρμογές εμφανίζονται και σε άλλες θέσεις:

  • Το μενού + του πεδίου μηνύματος (Προσθήκη αρχείου και άλλων), για παράδειγμα Δημιουργία ψηφοφορίας.
  • Οι καρτέλες του επιλογέα emoji: GIF, Αυτοκόλλητα και Μίμες.
  • Το τμήμα Ενέργειες μηνύματος του μενού Περισσότερες ενέργειες ενός μηνύματος, για παράδειγμα Προσθήκη σε εκκρεμότητες ή Εκτέλεση playbook.
  • Εντολές καθέτου, όπως /poll ή /todo: πληκτρολογήστε / για να δείτε τη λίστα.
  • Πλήρεις σελίδες: Τα Kanban και Playbooks αναφέρονται κάτω από Προϊόντα στο μενού Σχετικά με το Antimatter, στο κάτω μέρος της ράχης της εφαρμογής. Το πάνελ τους διαθέτει επίσης ένα κουμπί Άνοιγμα σε πλήρη σελίδα.
  • Οι ρυθμίσεις ορισμένων εφαρμογών βρίσκονται κάτω από Προσθήκες στις ρυθμίσεις σας.

Σε ένα τηλέφωνο, η στήλη εφαρμογών βρίσκεται σε ένα συρτάρι στη δεξιά πλευρά: σύρετε προς τα αριστερά ή επιλέξτε Περισσότερα › Μέλη και εφαρμογές στην κεφαλίδα της συνομιλίας.

Σημειώσεις

Οι σημειώσεις είναι έγγραφα που επεξεργάζονται ταυτόχρονα πολλοί χρήστες, δίπλα στη συνομιλία. Βλέπετε τους δείκτες και τα ονόματα των άλλων καθώς πληκτρολογούν, και όλα αποθηκεύονται καθώς προχωράτε.

Γραφή σημείωσης

  1. Κάντε κλικ σε Σημειώσεις στη στήλη εφαρμογών.
  2. Επιλέξτε μια καρτέλα: Αυτό το κανάλι για σημείωση που μπορούν να διαβάσουν και να επεξεργαστούν όλοι οι μέλη του καναλιού, ή Εμείς για προσωπική σημείωση που βλέπετε μόνο εσείς.
  3. Κάντε κλικ σε + (Νέα σημείωση σε αυτό το κανάλι ή Νέα προσωπική σημείωση). Ανοίγει μια «Σημείωση χωρίς τίτλο».
  4. Πληκτρολογήστε τον τίτλο του και γράψτε. Η μπάρα Μορφοποίηση περιλαμβάνει έντονα, πλάγια, διαγραμμένα, κεφαλίδες, λίστες και checklists· λειτουργούν επίσης σύνδεσμοι, παραθέσεις και κώδικας. Πληκτρολογήστε @ για να αναφέρετε ένα μέλος του καναλιού (οι αναφορές σε σημειώσεις δεν ειδοποιούν κανέναν).
  5. Κάντε κλικ στο Όλες οι σημειώσεις για να επιστρέψετε στη λίστα.

Όταν μια σημείωση σε ένα κανάλι λάβει τίτλο, το Antimatter δημοσιεύει «Κοινοποίηση σημείωσης» στο κανάλι, με ένα κουμπί Ανοίξτε σημείωση.

Περισσότερα με μια σημείωση

Βάλτε αστέρι σε μια σημείωση για να τη βρείτε στην καρτέλα ΑΓΑΠΗΜΕΝΑ. Το μενού ⋯ της σημείωσης προσφέρει Κοινή χρήση στο κανάλι (δημοσιεύει μια κάρτα με σύνδεσμο προς αυτή), Κοινή χρήση στο ~κανάλι (μετατρέπει μια προσωπική σημείωση σε σημείωση καναλιού, οριστικά), Ιστορικό εκδόσεων (προβολή και Επαναφορά αυτής της έκδοσης), Εξαγωγή ως Markdown και Διαγραφή. Μόνο ο δημιουργός της σημείωσης και οι διαχειριστές του καναλιού μπορούν να διαγράψουν μια σημείωση καναλιού.

Λευκός πίνακας

Ένας λευκός πίνακας είναι ένα καμβάς στον οποίο σχεδιάζετε μαζί: σχήματα, βέλη, κείμενο και ελεύθερο σχεδιασμό, με τους δείκτες όλων να εμφανίζονται σε πραγματικό χρόνο.

  1. Κάντε κλικ στο Λευκός πίνακας στη ράβα εφαρμογών.
  2. Όπως και με τις σημειώσεις, επιλέξτε Αυτό το κανάλι ή Τα δικά μου, και κάντε κλικ στο + (Νέος πίνακας σε αυτό το κανάλι ή Νέος προσωπικός πίνακας).
  3. Σχεδιάστε με τα εργαλεία: Επιλογή και μετακίνηση (V), Μετακίνηση γύρω (H), Ορθογώνιο (R), Ελλειψή (O), Βέλος (A), Σχεδίαση (P), Κείμενο (T) και Διαγραφέας (E). Επιλέξτε χρώματα, στυλ γραμμών και γραμματοσειρές στη γραμμή εργαλείων, και σχήματα στη Βιβλιοθήκη. Το Αναίρεση (Ctrl+Z) ανακτά την τελευταία σας αλλαγή.

Το μενού Ενέργειες πίνακα περιλαμβάνει Πλήρης οθόνη, Εμφάνιση ολόκληρου του πίνακα, λήψη ως .excalidraw, PNG ή SVG, Ιστορικό εκδόσεων, Εισαγωγή αρχείου .excalidraw… (αντικαθιστά τον πίνακα για όλους), κοινοποίηση στο κανάλι, και Διαγραφή. Οι λευκοί πίνακες παραμένουν στον διακομιστή Antimatter.

Kanban

Οι πίνακες Kanban οργανώνουν την εργασία ως κάρτες σε στήλες, όπως «Εκκρεμότητες», «Σε εξέλιξη» και «Ολοκληρώθηκε». Ένας πίνακας μπορεί επίσης να εμφανιστεί ως πίνακας, γκαλερί ή ημερολόγιο.

Ανοίξτε τους πίνακες ενός καναλιού

Κάντε κλικ στο Kanban στη ράχη της εφαρμογής. Το πάνελ εnumerates τα πίνακες συνδεδεμένους με το κανάλι· κάντε κλικ σε έναν για να τον ανοίξετε. Αν δεν υπάρχει ακόμη κανένας συνδεδεμένος, κάντε κλικ στο Σύνδεση πινάκων με …, στη συνέχεια στο Σύνδεση δίπλα σε έναν πίνακα, ή στο Δημιουργία πίνακα. Τα μέλη του καναλιού γίνονται συντάκτες ενός συνδεδεμένου πίνακα.

Εργασία με έναν πίνακα

  • Για να δείτε όλους τους πίνακες σας, ανοίξτε το Kanban ως πλήρη σελίδα: Άνοιγμα σε πλήρη σελίδα στο πάνελ, ή Σχετικά με το Antimatter › Προϊόντα › Kanban.
  • Για να δημιουργήσετε έναν πίνακα, κάντε κλικ στο + Προσθήκη πίνακα, και στη συνέχεια ξεκινήστε από ένα πρότυπο (ημερήσια διάταξη συνεδρίας, εργασίες έργου, χάρτης οδού, προγραμματιστής sprint και άλλα) ή Δημιουργία κενού πίνακα.
  • Κάντε κλικ στο + Νέο σε μια στήλη για να προσθέσετε μια κάρτα. Ανοίξτε μια κάρτα για να ορίσετε τις ιδιότητές της, να προσθέσετε κείμενο, πλαίσια ελέγχου και εικόνες, να συνηψετε αρχεία και να σχολιάσετε. Η αναφορά κάποιου σε μια κάρτα τον ειδοποιεί.
  • Σύρετε κάρτες μεταξύ στηλών. Χρησιμοποιήστε Ομαδοποίηση κατά, Φίλτρο, Ταξινόμηση και Αναζήτηση καρτών για να βρείτε τον δρόμο σας, και Προσθήκη προβολής για προβολή πίνακα, γκαλερί ή ημερολογίου.
  • Χρησιμοποιήστε το Κοινή χρήση σε έναν πίνακα για να επιλέξετε ποιοι μπορούν να τον δουν ή να τον επεξεργαστούν.

Ημερολόγιο

Η εφαρμογή Ημερολόγιο εμφανίζει το δικό σας ημερολόγιο δίπλα στη συνομιλία, σας στέλνει υπενθυμίσεις και σας επιτρέπει να συναντιέστε στο Antimatter. Λειτουργεί με διακομιστές ημερολογίου που χρησιμοποιούν CalDAV, όπως Nextcloud, Fastmail ή Radicale.

Σύνδεση του ημερολογίου σας

  1. Κάντε κλικ στο Ημερολόγιο στη ράβα εφαρμογών.
  2. Στο Σύνδεση ημερολογίου σας, συμπληρώστε τη διεύθυνση του CalDAV server (συνήθως απλώς το domain του πάροχού σας), το Όνομα χρήστη και τον Κωδικό σας. Αν ο πάροχός σας προσφέρει κωδικούς εφαρμογών, χρησιμοποιήστε έναν.
  3. Επιλέξτε πότε να Με θυμίζει για συμβάντα χωρίς συναγερμούς, και στη συνέχεια κάντε κλικ στο Σύνδεση.

Ο κωδικός πρόσβασης αποθηκεύεται κρυπτογραφημένος στον διακομιστή Antimatter. Για να αλλάξετε αυτές τις λεπτομέρειες αργότερα, ή να αποσυνδεθείτε, χρησιμοποιήστε Ρυθμίσεις λογαριασμού στον πίνακα.

Χρήση

  • Εναλλάσσεστε μεταξύ Ημερήσιας διάταξης και Εβδομάδας, κινείστε με Προηγούμενο, Σήμερα και Επόμενο, και κάντε κλικ στο chip ενός ημερολογίου για να το εμφανίσετε ή να το κρύψετε.
  • Κάντε κλικ στο Νέο συμβάν, συμπληρώστε τον Τίτλο, το Έναρξη και το Τέλος, και προαιρετικά την Επανάληψη, την Υπενθύμιση, τη Τοποθεσία και την Περιγραφή, στη συνέχεια Αποθήκευση. Κάντε κλικ σε ένα συμβάν για να το αλλάξετε ή να το διαγράψετε.
  • Για να συναντηθείτε στο Antimatter, ορίστε το Συνάντηση στο Antimatter σε ένα κανάλι ή φωνητικό κανάλι, ή σε μια κλήση, και επιλέξτε το Κανάλι. Όταν έρθει η ώρα, το συμβάν εμφανίζει Έναρξη κλήσης, Συμμετοχή στην κλήση ή Συμμετοχή.
  • Οι υπενθυμίσεις φτάνουν ως άμεσα μηνύματα από το bot Ημερολογίου, με σύνδεσμο για συμμετοχή στην κλήση όταν υπάρχει.

Η εφαρμογή εμφανίζει τα δικά σας ημερολόγια· δεν στέλνει προσκλήσεις σε άλλους.

Email

Η εφαρμογή Email εμφανίζει το ταχυδρομικό σας κουτί δίπλα στη συνομιλία, ώστε να μπορείτε να διαβάζετε, να απαντάτε και να κοινοποιείτε email χωρίς να αποχωρείτε από το Antimatter.

Σύνδεση του ταχυδρομικού σας κουτιού

  1. Κάντε κλικ στο Email στη ράβα εφαρμογών.
  2. Αν ο διαχειριστής σας το έχει ρυθμίσει, κάντε κλικ στο Σύνδεση με Google ή Σύνδεση με Microsoft. Αλλιώς, ή για έναν άλλο πάροχο, συμπληρώστε τη Διεύθυνση email και το Όνομά σας, στη συνέχεια τους διακομιστές Εισερχόμενης αλληλογραφίας (IMAP) και Εξερχόμενης αλληλογραφίας (SMTP), με την ασφάλεια, την θύρα, το όνομα χρήστη και τον κωδικό τους. Οι σελίδες βοήθειας του πάροχού σας παρέχουν αυτές τις λεπτομέρειες.
  3. Κάντε κλικ στο Σύνδεση.

Χρήση

  • Επιλέξτε έναν Φάκελο, αναζητήστε με Αναζήτηση σε αυτόν τον φάκελο και κάντε κλικ σε ένα μήνυμα για να το διαβάσετε. Οι εικόνες από το διαδίκτυο είναι κρυφές μέχρι να κάνετε κλικ στο Εμφάνιση εικόνων.
  • Απαντήστε με Απάντηση, Απάντηση σε όλους ή Επόμενο, ή γράψτε με Νέο μήνυμα. Τα μηνύματα είναι απλό κείμενο και δεν μπορείτε να συνηψετε νέα αρχεία.
  • Κάντε κλικ στο Κοινοποίηση σε κανάλι για να δημοσιεύσετε τον αποστολέα, το θέμα και ένα απόσπασμα ενός ηλεκτρονικού μηνύματος σε ένα κανάλι, με ένα σχόλιο.

Ψηφοφορίες

Μια ψηφοφορία θέτει μια ερώτηση σε μια συζήτηση και όλοι ψηφίζουν με ένα κλικ. Τα αποτελέσματα ενημερώνονται σε πραγματικό χρόνο.

  1. Κάντε κλικ στο + στο πεδίο μηνύματος και επιλέξτε Δημιουργία ψηφοφορίας, ή πληκτρολογήστε /poll.
  2. Πληκτρολογήστε την Ερώτηση και τουλάχιστον δύο απαντήσεις. Το Προσθήκη απάντησης προσθέτει περισσότερες, έως δέκα.
  3. Ενεργοποιήστε το Επιτρέπει πολλαπλές απαντήσεις αν οι χρήστες μπορούν να επιλέξουν περισσότερες από μία, και το Ανώνυμη ψηφοφορία αν κανείς δεν πρέπει να δει ποιος ψήφισε για τι.
  4. Επιλέξτε μια Διάρκεια, από 1 ώρα έως 1 εβδομάδα, ή Χωρίς τέλος.
  5. Κάντε κλικ στο Δημοσίευση ψηφοφορίας.

Για να ψηφίσετε, κάντε κλικ σε μια απάντηση. Κάντε κλικ ξανά για να ανακαλέσετε την ψήφο σας. Η ψηφοφορία λήγει στο τέλος της διάρκειάς της, ή όταν ο δημιουργός της ή ένας διαχειριστής του καναλιού κάνει κλικ στο Κλείσιμο ψηφοφορίας. Τότε εμφανίζονται τα Τελικά αποτελέσματα.

Μπορείτε επίσης να γράψετε ολόκληρη τη ψήφωση σε μία γραμμή: /poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h. Πληκτρολογήστε /poll help για όλες τις επιλογές.

Εκκρεμότητες

Το Todo διαχειρίζεται λίστες εκκρεμοτήτων: τις δικές σας, κοινές λίστες για ένα κανάλι, και εργασίες που στέλνετε σε άλλους.

  • Κάντε κλικ στο Εκκρεμότητες στη ράβα της εφαρμογής. Στη καρτέλα Αυτό το κανάλι, προσθέστε μια εργασία στη κοινή λίστα του καναλιού και χρησιμοποιήστε Αναзначение σε… για να την αναθέσετε σε ένα μέλος. Βάλτε αστέρι στη λίστα για να την παρακολουθείτε. Οι λίστες που παρακολουθείτε συγκεντρώνονται στην καρτέλα Παρακολουθείτε.
  • Η καρτέλα Δικά μου περιέχει τις δικές σας εργασίες, αυτές που σας έχουν ανατεθεί σε κανάλια και αυτές που σας έχουν στείλει ή που έχετε στείλετε εσείς. Επιλέξτε κάποιον με Αποστολή σε… για να του στείλετε μια εργασία: μπορεί να την Αποδοχή, να την Απόρριψη ή να την Σήμανση ως ολοκληρωμένη.
  • Για να μετατρέψετε ένα μήνυμα σε εργασία, επιλέξτε Ενέργειες μηνύματος › Προσθήκη σε εκκρεμότητες από το μενού του.
  • Κάντε κλικ στο Σήμανση ως ολοκληρωμένη όταν μια εργασία ολοκληρωθεί.

Μπορείτε επίσης να χρησιμοποιήσετε τις εντολές /todo add …, /todo list και /todo send @someone … για τα προσωπικά σας καθήκοντα.

GIF, αυτοκόλλητα και μεμ

Κάντε κλικ στο Emoji (το χαμογελαστό πρόσωπο) στο πεδίο μηνύματος: όταν αυτές οι εφαρμογές είναι ρυθμισμένες, ο επιλογέας διαθέτει καρτέλες GIF, Αυτοκόλλητα και Μεμ δίπλα στην καρτέλα Emoji.

  • GIF: αναζητήστε ή περιηγηθείτε στα ΑΓΑΠΗΜΕΝΑ, Πρόσφατα χρησιμοποιημένα, Τάσεις και στις κατηγορίες. Κάντε κλικ σε ένα GIF για να το στείλετε αμέσως. Κάντε κλικ στο αστέρι του για να το προσθέσετε στα αγαπημένα σας. Μπορείτε επίσης να πληκτρολογήσετε /gif και μερικές λέξεις.
  • Αυτοκόλλητα: αναζητήστε ή περιηγηθείτε στις συλλογές αυτοκόλλητων και κάντε κλικ σε ένα αυτοκόλλητο για να το στείλετε. Λειτουργεί και η εντολή /sticker.
  • Μεμ: επιλέξτε ένα πρότυπο, συμπληρώστε τα κείμενά του στο Δημιουργία μεμ, δείτε την προεπισκόπηση και κάντε κλικ στο Δημοσίευση μεμ. Μπορείτε επίσης να πληκτρολογήσετε /meme ή /meme help για να δείτε πώς να γράψετε ένα σε μία γραμμή.

Ανάλογα με τις ρυθμίσεις του διακομιστή σας, ενδέχεται να μπορείτε να προσθέσετε τα δικά σας GIF, αυτοκόλλητα ή πρότυπα μεμ με το + δίπλα στο πεδίο αναζήτησης.

Playbooks

Ένα playbook είναι μια επαναχρησιμοποιήσιμη λίστα ελέγχου για εργασίες που ακολουθούν τα ίδια βήματα κάθε φορά: ένα περιστατικό, μια κυκλοφορία, η υποδοχή ενός νέου συναδέλφου. Κάθε φορά που το χρησιμοποιείτε, ξεκινάτε μια Εκτέλεση, με τις δικές της εργασίες, υπεύθυνους, ενημερώσεις κατάστασης και, στο τέλος, μια αναδρομή.

  • Κάντε κλικ στο Playbooks στη ράβα εφαρμογών για να δείτε τις εκτελέσεις του τρέχοντος καναλιού, να ξεκινήσετε μία με Εκτέλεση playbook ή να δημιουργήσετε μια γρήγορη Νέα λίστα ελέγχου.
  • Για να δημιουργήσετε ή να επεξεργαστείτε playbooks, ανοίξτε τη πλήρη σελίδα: Σχετικά με το Antimatter › Προϊόντα › Playbooks. Ξεκινήστε από ένα πρότυπο, όπως κυκλοφορία προϊόντος, επίλυση περιστατικού ή ενσωμάτωση νέου υπαλλήλου, ή από ένα κενό playbook.
  • Για να ξεκινήσετε μια εκτέλεση, κάντε κλικ στο Εκτέλεση σε ένα playbook, δώστε ένα όνομα και μια περίληψη στην εκτέλεση, επιλέξτε να δημιουργήσετε ένα κανάλι για αυτήν ή να το συνδέσετε με ένα υπάρχον και κάντε κλικ στο Έναρξη εκτέλεσης. Μπορείτε επίσης να επιλέξετε Ενέργειες μηνύματος › Εκτέλεση playbook σε ένα μήνυμα.
  • Κατά τη διάρκεια μιας εκτέλεσης, σημειώνετε τις ολοκληρωμένες εργασίες, τις αναθέτετε και τους ορίζετε ημερομηνίες λήξης, και κάνετε κλικ στο Δημοσίευση ενημέρωσης για να ενημερώσετε όλους για την κατάσταση των πραγμάτων. Ο υπεύθυνος κάνει κλικ στο Ολοκλήρωση στο τέλος.

Πληκτρολογήστε /playbook για να δείτε τις εντολές, όπως /playbook run ή /playbook update.

GitHub, GitLab και Jira

Αυτές οι εφαρμογές συνδέουν το Antimatter με τα εργαλεία που χρησιμοποιούν οι προγραμματιστές. Ο διαχειριστής σας πρέπει πρώτα να τα ρυθμίσει. Τότε:

  1. Συνδέστε τον λογαριασμό σας πληκτρολογώντας /github connect, /gitlab connect ή /jira connect, και στη συνέχεια ακολουθήστε τον σύνδεσμο και συνδεθείτε στην αντίστοιχη πλατφόρμα. Για το GitLab, εκτελέστε αυτή τη διαδικασία σε περιηγητή και όχι στην εφαρμογή για υπολογιστή.
  2. Έτσι, θα λαμβάνετε άμεσα μηνύματα όταν κάποιος σας αναφέρει, ζητά την αξιολόγησή σας ή σας αναθέτει κάποια εργασία.
  3. Για να κάνει ένα κανάλι παρακολούθηση ενός αποθετηρίου ή ενός έργου, χρησιμοποιήστε /github subscriptions add owner/repo, /gitlab subscriptions add group/project ή /jira subscribe.
  4. Για να δημιουργήσετε ή να συσχετίσετε ένα ζήτημα από ένα μήνυμα, επιλέξτε Δημιουργία ζητήματος GitHub, Δημιουργία ζητήματος GitLab, Δημιουργία ζητήματος Jira ή το αντίστοιχο στοιχείο Συσχέτιση με … στις Ενέργειες μηνύματος.

Πληκτρολογήστε /github help, /gitlab help ή /jira help για να δείτε όλες τις εντολές τους.

Εφαρμογές στην κινητή εφαρμογή

Η κινητή εφαρμογή μπορεί να δημιουργεί και να ψηφίζει σε ψηφοφορίες, να στέλνει GIF και αυτοκόλλητα, και να απαντά σε εργασίες που σας έχουν αποσταλεί. Τα σημειώματα και οι λευκοί πίνακες ανοίγουν σε παράθυρο περιηγητή εντός της εφαρμογής. Οι πίνακες Kanban, το ημερολόγιο, το ηλεκτρονικό ταχυδρομείο και τα memes δεν είναι ακόμη διαθέσιμα στην κινητή εφαρμογή: χρησιμοποιήστε την εφαρμογή για τον υπολογιστή ή τον περιηγητή για αυτά.
