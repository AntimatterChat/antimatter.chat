Λειτουργία διακομιστή

Αυτός ο οδηγός απευθύνεται σε διαχειριστές συστημάτων που εγκαθιστούν και εκτελούν έναν διακομιστή Antimatter. Υποθέτει ότι γνωρίζετε Linux, Docker και reverse proxies, αλλά όχι το Antimatter.

Από τι αποτελείται μια εγκατάσταση

Το Antimatter είναι μια αυτοξεζυγισμένη (self-hosted) εφαρμογή ομαδικής συνομιλίας, ένα fork του Mattermost. Μια πλήρης εγκατάσταση αποτελείται από τα εξής μέρη. Μόνο τα πρώτα τρία είναι υποχρεωτικά.

ΜέροςΛειτουργίαΥποχρεωτικό
Ο διακομιστής AntimatterΈνα πρόγραμμα Go (antimatter) που εξυπηρετεί την web εφαρμογή, το API και τα websockets στην θύρα 8065, εκτελεί τις ενσωματωμένες εφαρμογές (plugins) και μεταφέρει τα μέσα των κλήσεων στην θύρα 8443. Το εργαλείο γραμμής εντολών amctl το διαχειρίζεται.ναι
PostgreSQLΗ βάση δεδομένων: μηνύματα, χρήστες, κοινότητες και, στη συνιστώμενη διαμόρφωση, η ρύθμιση του διακομιστή. Έκδοση 15 ή νεότερη.ναι
Αποθήκευση αρχείωνΑνεβασμένα αρχεία, εικόνες και εγκατεστημένες εφαρμογές: μια S3-συμβατή υπηρεσία (το αρχείο compose εκτελεί RustFS) ή έναν τοπικό κατάλογο.ναι
Ένας reverse proxyHTTPS μπροστά από τον διακομιστή: το προφίλ Caddy του αρχείου compose, ή ο δικός σας nginx.για παραγωγή
Η υπηρεσία GIF (gifs-server)GIFs και αυτοκόλλητα για τον επιλογέα GIF, από τον δικό σας κατάλογο. Ομιλεί την API του Tenor.όχι
Ένας push proxyΜεταβιβάζει ειδοποιήσεις στην κινητή εφαρμογή μέσω Apple και Google.για κινητές ειδοποιήσεις
rtcd, ένας TURN serverΈνας ξεχωριστός διακομιστής μέσων για πολλές κλήσεις, και ένα relay για άτομα πίσω από αυστηρά firewalls.όχι
AI endpointsΤα μοντέλα πίσω από τους AI πράκτορες, τη μεταγραφή κλήσεων, την ανάγνωση σε φωνή και τη μετάφραση: ένας cloud πάροχος ή διακομιστές που εκτελείτε εσείς.όχι

Το Antimatter δεν έχει άδεια χρήσης και δεν έχει πληρωμένη έκδοση: single sign-on, LDAP, υψηλή διαθεσιμότητα, εξαγωγές συμμόρφωσης, διατήρηση δεδομένων και τα άλλα χαρακτηριστικά που το Mattermost κρατάει για τα πληρωμένα του πακέτα, όλα περιλαμβάνονται.

Απαιτήσεις

  • Ένας διακομιστής Linux, amd64 ή arm64, με 2 πυρήνες CPU και 4 GB μνήμης ή περισσότερο για μερικές εκατοντάδες χρήστες, και χώρο δίσκου για τα αρχεία που ανεβάζουν οι χρήστες.
  • Docker Engine με το plugin Compose (docker compose), για τη συνιστώμενη εγκατάσταση.
  • Για παραγωγή: ένα domain name που δείχνει στον διακομιστή, και οι θύρες 80 και 443 ανοιχτές για HTTPS.
  • Για κλήσεις: η θύρα 8443, UDP και TCP, προσβάσιμη από τα άτομα που κάνουν κλήσεις.
  • Για email: ένας SMTP διακομιστής μέσω του οποίου το Antimatter μπορεί να στείλει.

Γρήγορη έναρξη

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Στη συνέχεια, ανοίξτε τη διεύθυνση URL του δικτυακού τόπου και δημιουργήστε τον λογαριασμό σας: ο πρώτος λογαριασμός γίνεται διαχειριστής συστήματος. Το Εγκατάσταση εξηγεί κάθε βήμα και τους άλλους τρόπους εγκατάστασης.

Σε αυτόν τον οδηγό

  • Εγκατάσταση: Docker Compose, εικόνες, αρχείο έκδοσης, ο πρώτος διαχειριστής.
  • Διαμόρφωση: ρυθμίσεις στη βάση δεδομένων ή σε αρχείο, μεταβλητές περιβάλλοντος AM_, Κονσόλα συστήματος, amctl, αρχεία καταγραφής.
  • Δομένιο και HTTPS: διεύθυνση URL του δικτυακού τόπου, Caddy, nginx, διευθύνσεις πελατών.
  • Κλήσεις και φωνή: θύρες, NAT, TURN, rtcd, μεταγραφή και υπότιτλοι.
  • Email και push: SMTP, proxy push και κινητή εφαρμογή.
  • Ενσωματωμένες εφαρμογές: ποιες εφαρμογές είναι ενεργές, οι ρυθμίσεις τους, εγκατάσταση άλλων.
  • Τεχνητή νοημοσύνη: μοντέλα για πράκτορες, ομιλία και μετάφραση, και πού πηγαίνουν τα δεδομένα.
  • Σύνδεση και λογαριασμοί: εγγραφή, κωδικοί πρόσβασης, MFA, μονοσήμαντη σύνδεση, LDAP, επισκέπτες, συνεδρίες.
  • Αντιγραφή και αναβαθμίσεις: αντιγραφή, επαναφορά, αναβάθμιση, μεταφορά από Mattermost.
  • Λειτουργίες: παρακολούθηση, κλιμάκωση, διατήρηση δεδομένων, συμμόρφωση, αντιμετώπιση προβλημάτων.
  • Ασφάλεια: κατάλογος ενίσχυσης και εξωτερικές συνδέσεις.

Διαχειρίζεστε μια κοινότητα αντί για έναν διακομιστή (κανάλια, ρόλοι, διαχείριση); Δείτε Διαχείριση κοινότητας. Δημιουργείτε ολοκληρώματα; Δείτε Δημιουργία σε Antimatter.

Η πρώτη σας ώρα

  1. Εγκαταστήστε και δημιουργήστε αμέσως τον λογαριασμό διαχειριστή.
  2. Τοποθετήστε τον διακομιστή πίσω από HTTPS σε δικό του δομένιο.
  3. Διαμορφώστε SMTP και στείλτε ένα δοκιμαστικό email.
  4. Ανοίξτε τη θύρα κλήσεων και απενεργοποιήστε τη δοκιμαστική λειτουργία της εφαρμογής Κλήσεις.
  5. Αποφασίστε ποιοι μπορούν να εγγραφούν και ενεργοποιήστε MFA.
  6. Εξετάστε τις εξωτερικές συνδέσεις στην ενότητα Ασφάλεια.
  7. Ρυθμίστε ημερήσιες αντιγραφές.

Λήψη βοήθειας

Τα ερωτήματα μπορείτε να τα θέτετε στις συζητήσεις της κοινότητας, ενώ τα σφάλματα αναφέρετε στο αποθετήριο της κοινότητας. Τα θέματα ασφαλείας αναφέρονται ιδιωτικά, όπως εξηγεί η πολιτική ασφαλείας.
