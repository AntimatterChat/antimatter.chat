Τεχνητή νοημοσύνη

Τα χαρακτηριστικά τεχνητής νοημοσύνης του Antimatter χρησιμοποιούν μοντέλα της επιλογής σας: έναν πάροχο στο cloud ή έναν διακομιστή στο δικό σας δίκτυο. Κανένα δεδομένο δεν αποστέλλεται πουθενά μέχρι να ρυθμίσετε ένα μοντέλο. Αυτή η σελίδα καλύπτει κάθε χαρακτηριστικό, τα δεδομένα που αποστέλλει και τον τρόπο απενεργοποίησής του.

Τα χαρακτηριστικά τεχνητής νοημοσύνης

ΧαρακτηριστικόΡυθμίζεται σεΕίδος μοντέλουΕνεργό από προεπιλογή
Πράκτορες ΤΝ: συνομιλία με bot, σύνοψη νημάτων και καναλιών, βοήθεια στη γραφίδαΗ εφαρμογή AgentsΟποιαδήποτε υπηρεσία μεγάλου γλωσσικού μοντέλου (LLM)Η εφαρμογή είναι ενεργή, αλλά δεν κάνει τίποτα μέχρι να προσθέσετε μια υπηρεσία
Μεταγραφές κλήσεων και ζωντανοί υπότιτλοιΗ εφαρμογή CallsΜετατροπή ομιλίας σε κείμενο, συμβατή με OpenAIόχι
Ανάγνωση σε φωνήΟ διακομιστήςΜετατροπή κειμένου σε ομιλία, συμβατή με OpenAIόχι
Αυτόματη μετάφραση καναλιώνΟ διακομιστήςLibreTranslate, LLM συμβατό με OpenAI ή υπηρεσία Agentsόχι

«Συμβατό με OpenAI» σημαίνει διακομιστής που προσφέρει το ίδιο HTTP API με το OpenAI. Οι περισσότεροι διακομιστές μοντέλων που μπορείτε να εκτελέσετε μόνοι σας το κάνουν (για παράδειγμα Ollama, vLLM, ο διακομιστής του llama.cpp, ή διακομιστές Whisper και μετατροπής κειμένου σε ομιλία), όπως και πολλοί πάροχοι στο cloud. Δεν απαιτείται άδεια για κανένα από αυτά τα χαρακτηριστικά.

Πράκτορες ΤΝ

Η εφαρμογή Agents (id mattermost-ai) είναι ενεργή από προεπιλογή. Η ρύθμισή της απαιτεί δύο βήματα: προσθέστε μια υπηρεσία (σύνδεση με πάροχο μοντέλου) και στη συνέχεια δημιουργήστε πράκτορες (bots που χρησιμοποιούν μια υπηρεσία).

1. Προσθήκη υπηρεσίας

Μεταβείτε στο Κονσόλα συστήματος › Προσθήκες › Πράκτορες και, κάτω από Υπηρεσίες Τεχνητής Νοημοσύνης, κάντε κλικ στο Προσθήκη Υπηρεσίας AI. Επιλέξτε τον Τύπο υπηρεσίας:

  • Συμβατό με OpenAI: για διακομιστή μοντέλου που εκτελείτε μόνοι σας ή για οποιονδήποτε πάροχο με API τύπου OpenAI. Συμπληρώστε το URL API (για παράδειγμα http://ollama:11434/v1 ή http://vllm.internal:8000/v1) και το Κλειδί API μόνο αν ο διακομιστής το απαιτεί. Αν ο διακομιστής υποστηρίζει μόνο το Chat Completions API, απενεργοποιήστε το Χρήση Responses API.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: πάροχοι στο cloud. Κάθε ένας απαιτεί το Κλειδί API του (Bedrock: περιοχή AWS και διαπιστευτήρια ή ρόλος IAM; Vertex AI: έργο, περιοχή και λογαριασμός υπηρεσίας; Azure: και το URL API).

Στη συνέχεια, ορίστε το Προεπιλεγμένο μοντέλο (λίστα, αν ο πάροχος αναφέρει τα μοντέλα του, αλλιώς πληκτρολογήστε το όνομα), καθώς και, αν ο πάροχος δεν τα αναφέρει, τα Όρια εισόδου και Όρια εξόδου. Ένα Εναλλακτικό μπορεί να αναλάβει όταν αυτό αποτύχει. Αποθηκεύστε.

Ο διακομιστής εκτελεί αυτά τα αιτήματα μόνος του, οπότε πρέπει να μπορεί να φτάσει το API: σε έναν διακομιστή μοντέλων στο ίδιο compose project, στο δίκτυό σας ή στο Διαδίκτυο. Τα εξερχόμενα αιτήματα σέβονται τις μεταβλητές HTTP_PROXY και HTTPS_PROXY.

2. Δημιουργία πρακτόρων

Οι πράκτορες δημιουργούνται στη σελίδα Πράκτορες της web εφαρμογής: ανοίξτε τη από το μενού προϊόντος ή με Διαχείριση στον επιλογέα πρακτόρων του πάνελ Πράκτορες. Η διεύθυνσή της είναι https://chat.example.com/plug/mattermost-ai/agents. Κάθε πράκτορας έχει Εμφανιζόμενο όνομα, Όνομα χρήστη (πώς αναφέρεται από τους χρήστες), Υπηρεσία και, προαιρετικά, μοντέλο, Προσαρμοσμένες οδηγίες και διακόπτες για Ενεργοποίηση όρασης (εικόνες) και Ενεργοποίηση εργαλείων. Η καρτέλα Πρόσβαση περιορίζει σε ποιες κανάλια μπορεί να χρησιμοποιηθεί και από ποιους χρήστες. Υπό Λειτουργίες AI στο Κονσόλα συστήματος, το Προεπιλεγμένο bot επιλέγει τον πράκτορα που χρησιμοποιείται όταν δεν επιλέγεται άλλος, για παράδειγμα για συνόψεις κλήσεων.

Εξ ορισμού, κάθε χρήστης μπορεί να δημιουργήσει τους δικούς του πράκτορες, χρησιμοποιώντας τις υπηρεσίες που διαμόρφωσατε. Για να το περιορίσετε στους διαχειριστές, αφαιρέστε το δικαίωμα Διαχείριση Δικών σας AI Πρακτόρων από τον ρόλο των μελών στο Κονσόλα συστήματος › Διαχείριση Χρηστών › Δικαιώματα.

Προαιρετικές λειτουργίες της εφαρμογής Πράκτορες

  • Αναζήτηση ενσωματώσεων (πειραματική, απενεργοποιημένη): σημασιολογική αναζήτηση σε μηνύματα. Απαιτεί PostgreSQL με την επέκταση pgvector και ένα μοντέλο ενσωματώσεων (OpenAI ή συμβατό με OpenAI). Στέλνει κάθε μήνυμα στο μοντέλο ενσωματώσεων, συμπεριλαμβανομένων των ιδιωτικών καναλιών και άμεσων μηνυμάτων.
  • Αναζήτηση στο web (απενεργοποιημένη): επιτρέπει στους πράκτορες να αναζητούν στο web μέσω Google, Brave ή ενός server SearXNG που εκτελείτε εσείς.
  • Ενδογενή εργαλεία: με παρόχους που τα προσφέρουν, οι πράκτορες μπορούν να χρησιμοποιήσουν την ίδια αναζήτηση web του παρόχου (ενεργοποιημένη εξ ορισμού για νέους πράκτορες, όπου υποστηρίζεται), λήψη από web και εκτέλεση κώδικα. Εκτελούνται στον πάροχο. Απενεργοποιήστε τα ανά πράκτορα.
  • Πρωτόκολλο Συνόρου Μοντέλου (MCP): συνδέστε πράκτορες σε server MCP που εμπιστεύεστε, για επιπλέον εργαλεία.
  • Αποσφαλμάτωση: Εξόδος ίχνους (απενεργοποιημένη, ημερολόγια διακομιστή ή ένα endpoint OpenTelemetry) και Ενεργοποίηση καταγραφής χρήσης, η οποία γράφει τους αριθμούς στο logs/agents/token_usage.log.

Από ομιλία σε κείμενο: μεταγραφές και υπότιτλοι κλήσεων

Οι κλήσεις μπορούν να μεταγραφούν, με ζωντανούς υπότιτλους, από έναν server μεταγραφής ομιλίας σε κείμενο που προσφέρει ένα endpoint /v1/audio/transcriptions συμβατό με το OpenAI. Η ρύθμιση βρίσκεται στο Κλήσεις και φωνή. Όταν η επιλογή Σύνοψη μεταγραφών είναι ενεργοποιημένη, ο προεπιλεγμένος πράκτορας δημοσιεύει επίσης μια σύνοψη κάθε μεταγραφής.

Μετατροπή κειμένου σε ομιλία: ανάγνωση σε φωνή

Με ενεργοποιημένη τη μετατροπή κειμένου σε ομιλία, το μενού κάθε μηνύματος περιλαμβάνει την επιλογή Μεγαλόφωνη ανάγνωση: ο διακομιστής στέλνει το κείμενο του μηνύματος σε μια API μετατροπής κειμένου σε ομιλία και αναπαράγει την ηχογράφηση. Οι ρυθμίσεις βρίσκονται στο Κονσόλα συστήματος › Ολοκληρώσεις › Μετατροπή κειμένου σε ομιλία:

ΡύθμισηΚλειδί και μεταβλητήΤι να εισάγετε
Ανάγνωση μηνυμάτων σε φωνήTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (απενεργοποιημένη από προεπιλογή)
Βασική διεύθυνση URL APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLΗ βασική διεύθυνση URL έως και συμπεριλαμβανομένου του /v1, για παράδειγμα http://tts.internal:8000/v1. Ο server καλεί το endpoint /audio/speech του.
ΜοντέλοTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELΤο μοντέλο όπως το ονομάζει το API, για παράδειγμα tts-1. Υποχρεωτικό.
ΦωνήTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEΜία από τις φωνές του μοντέλου, ή άδειο για την προεπιλογή του.
Κλειδί APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYΣτέλνεται ως bearer token. Άδειο αν το API δεν απαιτεί κλειδί.

Πριν από την αποστολή, ο server αφαιρεί μπλοκ κώδικα, συνδέσμους, κώδικες emoji και μορφοποίηση, και διατηρεί το πολύ 4000 χαρακτήρες. Ζητά ηχητική εγγραφή σε MP3 και διατηρεί τα τελευταία 64 αποτελέσματα στη μνήμη, οπότε ένα μήνυμα που διαβάζεται δύο φορές στέλνεται μόνο μία φορά.

Αυτόματη μετάφραση

Η αυτόματη μετάφραση εμφανίζει τα μηνύματα ενός καναλιού στη γλώσσα του κάθε αναγνώστη. Διαμορφώστε τη στο Κονσόλα συστήματος › Διαμόρφωση Ιστοτόπου › Τοποθετικοποίηση, κάτω από Αυτόματη μετάφραση:

ΡύθμισηΚλειδίΠροεπιλογή
ΕνεργοποίησηAutoTranslationSettings.Enableαπενεργοποιημένη
Πάροχος μετάφρασηςAutoTranslationSettings.Providerlibretranslate, openai (εμφανίζεται ως «API συμβατό με OpenAI») ή agents (υπηρεσία της εφαρμογής Πράκτορες)
Επιτρεπόμενες γλώσσεςAutoTranslationSettings.TargetLanguagesen: οι γλώσσες στις οποίες μπορούν να μεταφραστούν τα μηνύματα
Χρονικό όριο μετάφρασης (ms)AutoTranslationSettings.TimeoutMs5000
Περιορισμός αυτόματης μετάφρασης σε άμεσα και ομαδικά μηνύματαAutoTranslationSettings.RestrictDMAndGMαπενεργοποιημένη

Κάθε πάροχος έχει τα δικά του πεδία:

  • LibreTranslate: Τελικό σημείο API LibreTranslate και Κλειδί API LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Ένας διακομιστής LibreTranslate μπορεί να εκτελείται στο δικό σας δίκτυο.
  • Συμβατή API με OpenAI: Βασική διεύθυνση URL API (έως και συμπεριλαμβανομένου του /v1; ο διακομιστής χρησιμοποιεί το τελικό σημείο chat completions), Μοντέλο και Κλειδί API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Ένα μικρό μοντέλο μετάφρασης που εκτελείται τοπικά λειτουργεί καλά.
  • Πράκτορες: Υπηρεσία Τεχνητής Νοημοσύνης, μία από τις υπηρεσίες που διαμορφώθηκαν στην εφαρμογή Πράκτορες.

Όταν είναι ενεργοποιημένη, οι διαχειριστές καναλιού ενεργοποιούν τη μετάφραση για ένα κανάλι στις ρυθμίσεις του (Αυτόματη μετάφραση), και κάθε μέλος μπορεί να απενεργοποιήσει τη λειτουργία από το μενού του καναλιού (Μετάφραση μηνυμάτων). Στα άμεσα και ομαδικά μηνύματα, οποιοδήποτε μέλος μπορεί να την ενεργοποιήσει· με την περιοριστική ρύθμιση, η μετάφραση δεν είναι διαθέσιμη εκεί. Τα μεταφρασμένα μηνύματα εμφανίζουν «Μεταφράστηκε από …» με σύνδεσμο προς το αρχικό.

Ο κώδικας, οι σύνδεσμοι, οι αναφορές και τα emoji αντικαθίστανται από προσωρινά σύμβολα πριν το κείμενο σταλεί, και επαναφέρονται στη συνέχεια.

Για να κρατήσετε όλα τα δεδομένα στο δίκτυό σας, κατευθύνετε κάθε λειτουργία σε διακομιστές που εκτελείτε εσείς. Με έναν πάροχο cloud, ελέγξτε τους όρους διατήρησης δεδομένων του, και ενημερώστε τους χρήστες σας ποιες λειτουργίες στέλνουν τα μηνύματά τους εξωτερικά.

Απενεργοποίηση της AI

Δεν υπάρχει ένας ενιαίος διακόπτης: κάθε λειτουργία έχει τον δικό της.

  • Πράκτορες: απενεργοποιήστε την εφαρμογή Πράκτορες στο Κονσόλα συστήματος › Προσθήκες › Διαχείριση Plugins. Αυτό αφαιρεί επίσης τις συνόψεις κλήσεων και τον πάροχο μετάφρασης των Πράκτορων.
  • Μεταγραφή και υπότιτλοι: AM_CALLS_ENABLE_TRANSCRIPTIONS=false και AM_CALLS_ENABLE_LIVE_CAPTIONS=false (τις προεπιλογές).
  • Μεγαλόφωνη ανάγνωση: απενεργοποιήστε την επιλογή Ανάγνωση μηνυμάτων σε φωνή (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, η προεπιλογή).
  • Μετάφραση: απενεργοποιήστε την αυτόματη μετάφραση (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, η προεπιλογή).

Η απενεργοποίηση της εφαρμογής Πράκτορες δεν απενεργοποιεί τις άλλες τρεις: αυτές καλούν τα δικά τους API απευθείας.
