Приложения и интеграции

Какие приложения доступны вашим участникам, что вы можете настроить для своего сообщества самостоятельно, а что требует действий системного администратора.

Приложения, доступные вашим участникам

Antimatter поставляется с набором приложений. Если системный администратор не отключил какие-то из них, все сообщества на сервере имеют к ним доступ:

ПриложениеНазначение
Звонки и голосовые каналыЗвонки в любом канале, а также голосовые каналы: постоянно открытые звонки, в которые участники могут заходить и выходить.
ОпросыОпросы в обсуждении с результатами в реальном времени, анонимным голосованием и временем окончания. Команда /poll создаёт опрос.
Список делОбщий список дел в каждом канале, а также личные списки.
ЗаметкиДокументы, редактируемые совместно в реальном времени, которые можно разделить с каналом или оставить личными.
Доска для рисованияДоски для рисования, которые можно разделить с каналом или оставить личными.
KanbanДоски с карточками в колонках, связанные с каналами.
ПлейбукиЧек-листы для повторяющихся процессов, запускаемых в канале.
GIF и мемыВыбор GIF и наклеек, а также создание мемов по шаблонам — в окне выбора эмодзи.
Календарь и почтаЛичный календарь и почтовый ящик каждого участника, связанные с их собственными аккаунтами.
АгентыИИ-ассистенты, если на сервере настроена модель ИИ.
GitHub, GitLab и JiraУведомления и команды для этих сервисов после их подключения.

Большинство приложений открываются из панели приложений — колонки значков на правом краю окна. Приложения включаются или отключаются для всего сервера в Системная консоль › Плагины: администратор сообщества не может включить или отключить приложение для одного конкретного сообщества. Их параметры также действуют на уровне всего сервера, если на этой странице не указано иное. Чтобы добавить приложение или изменить его параметры, обратитесь к системному администратору.

Внутри сообщества приложения подчиняются правам доступа к каналам: например, участники, которые могут только читать канал, видят его список дел и заметки, но не могут их изменять, а администраторы канала могут удалять его заметки и задачи. Администраторы и участники с правом Управление сообщениями могут закрыть любой опрос в канале.

Пользовательские эмодзи

Пользовательские эмодзи — это изображения, которые участники используют в сообщениях и реакциях, как и любые другие эмодзи, вводя их имя между двоеточиями, например :party_parrot:.

  1. Откройте окно выбора эмодзи (в поле ввода сообщения или через Добавить реакцию к сообщению).
  2. Выберите + (Добавить пользовательский эмодзи) рядом с полем поиска.
  3. На вкладке Добавить выберите изображение: PNG, GIF (в том числе анимированные), JPEG или WebP, размером не более 1 МБ.
  4. Укажите Имя: строчные буквы, цифры, а также -, + или _.
  5. Выберите Добавить эмодзи.

Вкладка Все пользовательские эмодзи содержит список эмодзи, поле поиска и позволяет удалять те, на которые у вас есть права.

  • Пользовательские эмодзи принадлежат всему серверу, а не отдельному сообществу: их могут использовать все участники сервера. Выбирайте имена, которые не будут конфликтовать с эмодзи других сообществ.
  • По умолчанию каждый участник может добавлять пользовательские эмодзи. Пользователи могут удалять только свои эмодзи; удалить чужие могут только системные администраторы, поэтому попросите одного из них удалить ненужный эмодзи. Системный администратор может изменить эти настройки в правах сервера или полностью отключить пользовательские эмодзи с помощью параметра Включить пользовательские смайлы в Системной консоли.

GIF, наклейки и мемы

Если соответствующие приложения включены, в пикере эмодзи появятся вкладки GIF, Наклейки и Мемы.

  • GIF и наклейки поступают от сервиса GIF, выбранного системным администратором, с рейтингом контента, установленным системным администратором. Если системный администратор разрешает, пользователи могут добавлять собственные GIF и наклейки. По умолчанию это могут делать только системные администраторы; они делают это из пикера или через разделы Пользовательские GIF и Пользовательские наклейки на страницах интеграций. Добавленные GIF и наклейки доступны всем на сервере.
  • Мемы: любой пользователь выбирает шаблон на вкладке Мемы, вводит подписи и публикует мем. Также работает команда /meme. По умолчанию любой пользователь может добавить шаблон мема с помощью кнопки + рядом с полем поиска на вкладке Мемы; системный администратор может ограничить эту возможность только для системных администраторов. Шаблоны разделяются всем сервером, и удалять их могут только их создатели и системные администраторы.

В публичном сообществе рассмотрите возможность просьбы к системному администратору ограничить загрузку GIF и шаблонов мемов только для администраторов.

Библиотеки для досок для рисования

Администраторы сообщества могут добавлять библиотеки фигур для всех в сообществе: на доске для рисования откройте меню доски или панель библиотек и выберите Управление библиотеками. Библиотека — это файл .excalidrawlib размером до 5 МБ.

Вебхуки, команды с косой чертой и боты

Интеграции связывают ваше сообщество с другими инструментами: система мониторинга, которая публикует оповещения, форма, которая публикует ответы, команда, которая что-то ищет. Для их настройки нажмите на свой аватар и выберите Интеграции. Вы увидите типы интеграций, которыми вам разрешено управлять:

ИнтеграцияНазначениеКто может создавать по умолчанию
Входящие вебхукиДругой сервис публикует сообщения в канал, вызывая секретный URL.Администраторы сообщества
Исходящие вебхукиСообщения с триггерным словом в канале отправляются в другой сервис, который может ответить.Администраторы сообщества
Команды с косой чертойКоманда, например /weather, вызывает другой сервис, который отвечает в канале.Администраторы сообщества
Аккаунты ботовАккаунты для программ, которые публикуют сообщения от своего имени с меткой БОТ.Системные администраторы
Приложения OAuth 2.0Приложения, которые позволяют пользователям входить в систему с помощью аккаунта Antimatter.Системные администраторы

Пользователи с кастомной ролью Управление интеграциями также могут управлять вебхуками и командами с косой чертой (см. Роли и разрешения). Вебхуки и команды с косой чертой принадлежат команде, в которой они были созданы.

Системный администратор должен включить каждый тип интеграции в Системная консоль › Интеграции › Управление интеграцией. Входящие и исходящие вебхуки, а также команды с косой чертой, включены по умолчанию; создание аккаунтов ботов отключено. Относитесь к URL вебхука и токену команды как к паролям: любой, у кого они есть, может публиковать сообщения в вашей команде.

Чтобы создать интеграцию, бота или приложение, см. Разработка на Antimatter.

Автоссылки

Автоссылки превращают текст, например номера задач, в ссылки во всех сообщениях вашей команды без необходимости устанавливать приложение. Администраторы команды настраивают их в Параметры команды › Автоссылки; см. Автоссылки.

Плейбуки

Плейбук — это чек-лист для повторяющегося процесса: обработка инцидента, адаптация нового коллеги, подготовка релиза. Каждый раз, когда процесс начинается, вы запускаете плейбук: Antimatter создает или использует канал для запуска, где находятся чек-лист, его владелец и обновления статуса.

Откройте Плейбуки из панели приложений. Плейбуки принадлежат команде. По умолчанию любой, кто может создавать каналы, может создавать плейбуки, поэтому на практике это может сделать любой участник. Плейбук может быть публичным для всей команды или доступным только для ее участников.

Некоторые хорошие плейбуки для команды: приветствие нового модератора, обработка жалобы, подготовка события. Для организации: реагирование на инцидент, приход и уход сотрудника.
