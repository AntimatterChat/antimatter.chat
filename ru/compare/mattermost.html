Antimatter или Mattermost

Antimatter — форк Mattermost: в нём сохранены сервер, API и интеграции Mattermost. Отличаются лицензирование, интерфейс и приложения.

Почему команды выбирают Antimatter

  • Все функции — свободное ПО под AGPL: SSO, синхронизация с LDAP, экспорт для комплаенса, хранение данных и всё остальное есть на каждом сервере.
  • Новый интерфейс с голосовыми каналами, ролями и значками, онбордингом и инструментами модерации.
  • Встроенные заметки, доски для рисования, списки дел, календарь и почта, а также ИИ-транскрипция без дополнительных сервисов.
  • API Mattermost сохранены, поэтому интеграции, написанные для Mattermost, продолжают работать.

Когда Mattermost может подойти лучше

  • Вам нужна коммерческая поддержка с SLA от компании-разработчика.
  • Вам нужны сертифицированные сборки, например образы с FIPS 140-3 или усиленные по STIG.
  • Вам нужны функции, которых в Antimatter пока нет, например кластеризация для высокой доступности, проверенная в крупных масштабах, или юридическое удержание данных (legal hold).
