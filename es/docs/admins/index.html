Ejecución de un servidor

Esta guía está dirigida a administradores de sistemas que instalan y ejecutan un servidor de Antimatter. Se asume que conocen Linux, Docker y los proxies inversos, pero no Antimatter.

De qué consta una implementación

Antimatter es un chat de equipo autoalojado, un bifurcación de Mattermost. Una implementación completa tiene estas partes. Solo las tres primeras son obligatorias.

ParteQué haceObligatoria
El servidor de AntimatterUn programa en Go (antimatter) que sirve la aplicación web, la API y los websockets en el puerto 8065, ejecuta las aplicaciones integradas (plugins) y transporta los medios de las llamadas en el puerto 8443. La herramienta de línea de comandos amctl lo administra.sí
PostgreSQLLa base de datos: mensajes, usuarios, comunidades y, en la configuración recomendada, la configuración del servidor. Versión 15 o posterior.sí
Almacenamiento de ArchivosArchivos, imágenes y aplicaciones instaladas: un servicio compatible con S3 (el archivo compose ejecuta RustFS) o un directorio local.sí
Un proxy inversoHTTPS delante del servidor: el perfil de Caddy del archivo compose, o su propio nginx.para producción
El servicio de GIF (gifs-server)GIFs y pegatinas para el selector de GIF, desde su propio catálogo. Habla la API de Tenor.no
Un proxy de notificaciones pushReenvía las notificaciones a la aplicación móvil a través de Apple y Google.para notificaciones móviles
rtcd, un servidor TURNUn servidor de medios independiente para muchas llamadas, y un retransmisor para personas detrás de cortafuegos estrictos.no
Puntos de conexión de IALos modelos detrás de los agentes de IA, la transcripción de llamadas, la lectura en voz alta y la traducción: un proveedor en la nube o servidores que usted ejecute.no

Antimatter no tiene licencia ni edición de pago: el inicio de sesión único, LDAP, la alta disponibilidad, las exportaciones de cumplimiento, la retención de datos y otras funciones que Mattermost reserva para sus planes de pago están todas incluidas.

Requisitos

  • Un servidor Linux, amd64 o arm64, con 2 núcleos de CPU y 4 GB de memoria o más para unas pocas cientos de personas, y espacio en disco para los archivos que la gente sube.
  • Docker Engine con el plugin Compose (docker compose), para la instalación recomendada.
  • Para producción: un nombre de dominio que apunte al servidor, y los puertos 80 y 443 abiertos para HTTPS.
  • Para llamadas: el puerto 8443, UDP y TCP, accesible para las personas que llaman.
  • Para correo electrónico: un servidor SMTP por el que Antimatter pueda enviar.

Inicio rápido

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Luego, abre la URL del sitio y crea tu cuenta: la primera cuenta se convierte en el administrador del sistema. Instalación explica cada paso y las otras formas de instalar.

En esta guía

  • Instalación: Docker Compose, las imágenes, el archivo de la versión y el primer administrador.
  • Configuración: ajustes en la base de datos o en un archivo, variables de entorno AM_, la Consola de sistema, amctl y registros.
  • Dominio y HTTPS: la URL del sitio, Caddy, nginx y las direcciones de los clientes.
  • Llamadas y voz: puertos, NAT, TURN, rtcd, transcripción y subtítulos.
  • Correo y notificaciones push: SMTP, el proxy de notificaciones push y la aplicación móvil.
  • Aplicaciones incluidas: qué aplicaciones están activas, sus ajustes y cómo instalar otras.
  • IA: modelos para agentes, voz y traducción, y qué datos se envían a dónde.
  • Inicio de sesión y cuentas: registro, contraseñas, MFA, inicio de sesión único, LDAP, invitados y sesiones.
  • Copias de seguridad y actualizaciones: copia de seguridad, restauración, actualización y migración desde Mattermost.
  • Operaciones: supervisión, escalado, retención de datos, cumplimiento normativo y solución de problemas.
  • Seguridad: lista de verificación para endurecer la seguridad y conexiones externas.

¿Prefieres gestionar una comunidad en lugar de un servidor (canales, roles, moderación)? Consulta Cómo gestionar una comunidad. ¿Quieres crear integraciones? Consulta Desarrollo en Antimatter.

Tu primera hora

  1. Instala y crea la cuenta de administrador de inmediato.
  2. Coloca el servidor detrás de HTTPS en su propio dominio.
  3. Configura SMTP y envía un correo de prueba.
  4. Abre el puerto de llamadas y desactiva el modo de prueba de la aplicación Llamadas.
  5. Decide quién puede registrarse y activa MFA.
  6. Revisa las conexiones externas en Seguridad.
  7. Configura copias de seguridad diarias.

Obtén ayuda

Haz preguntas en las discusiones de la comunidad y reporta errores en el repositorio de la comunidad. Informa de problemas de seguridad de forma privada, como explica la política de seguridad.
