IA

Las funciones de IA de Antimatter utilizan modelos que tú eliges: un proveedor en la nube o un servidor en tu propia red. No se envía nada a ningún lugar hasta que configuras un modelo. Esta página describe cada función, los datos que envía y cómo desactivarla.

Las funciones de IA

FunciónConfigurada enTipo de modeloActivada por defecto
Agentes de IA: chatear con un bot, resúmenes de hilos y canales, ayuda en el editor de mensajesLa app AgentsCualquier servicio de modelo de lenguaje grande (LLM)La app está activada, pero no hace nada hasta que añades un servicio
Transcripciones de llamadas y subtítulos en vivoLa app CallsTranscripción de voz, compatible con OpenAIno
Lectura en voz altaEl servidorSíntesis de voz, compatible con OpenAIno
Traducción automática de canalesEl servidorLibreTranslate, un LLM compatible con OpenAI o un servicio de Agentsno

«Compatible con OpenAI» significa un servidor que ofrece la misma API HTTP que OpenAI. La mayoría de los servidores de modelos que puedes ejecutar tú mismo lo hacen (por ejemplo, Ollama, vLLM, el servidor de llama.cpp, o servidores de transcripción de voz y síntesis de voz), al igual que muchos proveedores en la nube. No se necesita licencia para ninguna de estas funciones.

Agentes de IA

La app Agents (id mattermost-ai) está activada por defecto. Su configuración requiere dos pasos: añadir un servicio (una conexión a un proveedor de modelos) y luego crear agentes (bots que utilizan un servicio).

1. Añadir un servicio

Vaya a Consola de sistema › Plugins › Agentes y, bajo Servicios de IA, haga clic en Añadir un servicio de IA. Elija el Tipo de servicio:

  • Compatible con OpenAI: para un servidor de modelos que ejecutas tú mismo, o cualquier proveedor con una API estilo OpenAI. Rellena URL de la API (por ejemplo http://ollama:11434/v1 o http://vllm.internal:8000/v1) y Clave de API solo si el servidor la requiere. Si el servidor solo admite la API de Chat Completions, desactiva Usar API de Respuestas.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: proveedores alojados. Cada uno requiere su Clave de API (Bedrock: una región de AWS y credenciales o un rol IAM; Vertex AI: un proyecto, una región y una cuenta de servicio; Azure: también la URL de la API).

A continuación, configura el Modelo predeterminado (una lista si el proveedor puede informar sus modelos, o escribe el nombre) y, si el proveedor no los informa, el Límite de tokens de entrada y el Límite de tokens de salida. Un Servicio de respaldo puede tomar el control si este falla. Guarda.

El servidor realiza estas solicitudes por sí mismo, por lo que debe poder acceder a la API: un servidor de modelos en el mismo proyecto de compose, en tu red o en Internet. Las salientes respetan las variables HTTP_PROXY y HTTPS_PROXY.

2. Crear agentes

Los agentes se crean en la página Agentes de la aplicación web: ábrala desde el menú del producto o con Administrar en el selector de agentes del panel de Agentes. Su dirección es https://chat.example.com/plug/mattermost-ai/agents. Cada agente tiene un Nombre a mostrar, un Nombre de usuario del agente (cómo lo mencionan las personas), un Servicio y, opcionalmente, un modelo, Instrucciones personalizadas y conmutadores para Habilitar visión (imágenes) y Habilitar herramientas. Su pestaña Acceso limita en qué canales puede usarse y qué usuarios pueden usarlo. Bajo Funciones de IA en la Consola de sistema, Bot predeterminado elige el agente que se usa cuando no se selecciona ninguno, por ejemplo para resúmenes de llamadas.

De forma predeterminada, cada usuario puede crear sus propios agentes, con los servicios que configuró. Para restringir esto a los administradores, elimine el permiso Gestionar agentes de IA propios del rol de los miembros en Consola de sistema › Gestión de Usuarios › Permisos.

Funciones opcionales de la aplicación Agentes

  • Búsqueda de incrustaciones (experimental, desactivada): búsqueda semántica sobre mensajes. Requiere PostgreSQL con la extensión pgvector y un modelo de incrustaciones (OpenAI o compatible con OpenAI). Envía cada mensaje al modelo de incrustaciones, incluidos los canales privados y los mensajes directos.
  • Búsqueda web (desactivada): permite a los agentes buscar en la web a través de Google, Brave o un servidor SearXNG que ejecutes.
  • Herramientas nativas: con proveedores que las ofrezcan, los agentes pueden usar la búsqueda web propia del proveedor (activada por defecto para nuevos agentes, donde se admita), la recuperación web y la ejecución de código. Estas se ejecutan en el proveedor. Desactívalas por agente.
  • Protocolo de contexto de modelo (MCP): conecta agentes a servidores MCP en los que confíes, para herramientas adicionales.
  • Depurar: Salida de seguimiento (desactivado, registros del servidor o un punto de conexión de OpenTelemetry) y Habilitar registro de uso de tokens, que escribe los recuentos de tokens en logs/agents/token_usage.log.

Conversión de voz a texto: transcripciones y subtítulos de llamadas

Las llamadas pueden transcribirse, con subtítulos en vivo, mediante un servidor de voz a texto que ofrezca un endpoint /v1/audio/transcriptions compatible con OpenAI. La configuración se encuentra en Llamadas y voz. Con Resumir transcripciones activado, el agente predeterminado también publica un resumen de cada transcripción.

Texto a voz: leer en voz alta

Con el texto a voz activado, el menú de cada mensaje incluye Leer en voz alta: el servidor envía el texto del mensaje a una API de texto a voz y reproduce el audio. La configuración se encuentra en Consola de sistema › Integraciones › Texto a voz:

AjusteClave y variableQué introducir
Leer mensajes en voz altaTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (desactivado por defecto)
URL base de la APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLLa URL base hasta e incluyendo /v1, por ejemplo http://tts.internal:8000/v1. El servidor llama a su endpoint /audio/speech.
ModeloTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELEl modelo tal como lo nombra la API, por ejemplo tts-1. Obligatorio.
VozTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEUna de las voces del modelo, o vacío para usar la predeterminada.
Clave de APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYSe envía como token de portador. Déjalo vacío si la API no lo requiere.

Antes de enviar, el servidor elimina bloques de código, enlaces, códigos de emoji y formato, y conserva como máximo 4000 caracteres. Solicita audio en MP3 y conserva los últimos 64 resultados en memoria, por lo que un mensaje leído dos veces solo se envía una vez.

Traducción automática

La traducción automática muestra los mensajes de un canal en el idioma propio de cada lector. Configúrela en Consola de sistema › Configuración del Sitio › Idiomas, bajo Traducción automática:

AjusteClavePredeterminado
ActivarAutoTranslationSettings.Enabledesactivado
Proveedor de traducciónAutoTranslationSettings.Providerlibretranslate, openai (mostrado como "API compatible con OpenAI") o agents (un servicio de la app Agentes)
Idiomas permitidosAutoTranslationSettings.TargetLanguagesen: los idiomas en los que se pueden traducir los mensajes
Tiempo de espera de la traducción (ms)AutoTranslationSettings.TimeoutMs5000
Restringir la traducción automática en mensajes directos y de grupoAutoTranslationSettings.RestrictDMAndGMdesactivado

Cada proveedor tiene sus propios campos:

  • LibreTranslate: Punto de conexión API de LibreTranslate y Clave API de LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Un servidor de LibreTranslate puede ejecutarse en su propia red.
  • API compatible con OpenAI: URL base de la API (hasta e incluyendo /v1; el servidor usa su endpoint de completado de chat), Modelo y Clave de API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Un pequeño modelo de traducción ejecutado localmente funciona bien.
  • Agentes: Servicio de IA, uno de los servicios configurados en la app Agentes.

Una vez activado, los administradores de canal activan la traducción para un canal en su configuración (Traducción automática), y cada miembro puede desactivarla desde el menú del canal (Traducir mensajes). En los mensajes directos y de grupo, cualquier miembro puede activarla; si la restricción está activada, la traducción no está disponible allí. Los mensajes traducidos muestran «Traducido de …» con un enlace al original.

El código, los enlaces, las menciones y los emojis se reemplazan por marcadores antes de enviar el texto, y se restauran después.

Qué datos van a dónde

FunciónLo que se envíaDestino
AgentesLa solicitud, los mensajes del hilo o canal al que se refiere, las instrucciones del agente, los resultados de las herramientas, las imágenes cuando la visión está activada, y el nombre, el nombre de usuario, el cargo y el idioma del usuario que hace la preguntaLa API del servicio
Búsqueda por incrustacionesCada mensaje (excepto los de bots y mensajes del sistema)La API de incrustaciones
Herramientas nativas y búsqueda webConsultas de búsqueda, páginas a recuperar, códigoEl proveedor, o el motor de búsqueda que hayas elegido
Transcripción de llamadasLa voz de todos los que hablan mientras esté activadaLa API de voz a texto
Lectura en voz altaEl texto del mensaje que se está leyendoLa API de texto a voz
TraducciónEl texto de los mensajes en los canales traducidosLibreTranslate, la API de LLM, o el servicio de Agentes

Para mantener todo en tu red, dirige cada función a servidores que ejecutes tú mismo. Con un proveedor en la nube, revisa sus términos de retención de datos y comunica a tus usuarios qué funciones envían sus mensajes hacia el exterior.

Desactivar la IA

No hay un solo interruptor: cada función tiene el suyo.

  • Agentes: desactive la aplicación Agentes en Consola de sistema › Plugins › Gestión de Plugins. Esto también elimina los resúmenes de llamadas y el proveedor de traducción de Agentes.
  • Transcripción y subtítulos: AM_CALLS_ENABLE_TRANSCRIPTIONS=false y AM_CALLS_ENABLE_LIVE_CAPTIONS=false (los valores predeterminados).
  • Leer en voz alta: desactiva Leer mensajes en voz alta (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, el valor predeterminado).
  • Traducción: desactiva la traducción automática (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, el valor predeterminado).

Desactivar la app Agentes no desactiva las otras tres: estas llaman directamente a sus propias APIs.
