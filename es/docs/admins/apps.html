Aplicaciones incluidas

Las imágenes de Docker de Antimatter incluyen un conjunto de aplicaciones (plugins, en la Consola de sistema). Esta página las enumera, indica cuáles están activas tras la instalación y describe los ajustes que cada una requiere de un administrador.

Las aplicaciones incluidas

Las aplicaciones se listan como Plugins en la Consola de sistema. Están en la imagen (en /antimatter/prepackaged_plugins), firmadas con la clave de firma de aplicaciones de Antimatter, por lo que se instalan sin conexión a Internet.

Las aplicaciones que están activas por defecto se instalan en cada inicio si aún no lo están, o se actualizan si la imagen tiene una versión más reciente. Si desactiva una, permanece desactivada: el valor por defecto solo se aplica a las aplicaciones que la configuración aún no menciona. Las aplicaciones que conservan su id de Mattermost (Agentes, Llamadas, Kanban, Playbooks y las integraciones) son compilaciones propias de Antimatter.

Activar, desactivar y configurar aplicaciones

Vaya a Consola de sistema › Plugins › Gestión de Plugins. Bajo Plugins instalados, cada aplicación tiene Activado o Desactivado, Ajustes y Quitar, y muestra su estado (En ejecución, No en ejecución, Error al iniciar…). Cada aplicación con ajustes también tiene su propia página bajo Consola de sistema › Plugins.

Las aplicaciones incluidas que están desactivadas por defecto se instalan desde la copia propia de la imagen: abra Aplicación Marketplace desde el menú del producto, encuentre la aplicación y haga clic en Instalar, luego actívela en la Gestión de Plugins. Desde la línea de comandos:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Otros comandos: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Activar aplicaciones mediante la configuración

Qué aplicaciones están activas lo define el ajuste PluginSettings.PluginStates, un mapa de ids de aplicaciones. Puede fusionar entradas en él con amctl; con Habilitar plugins pre-empacados automaticamente activado (el valor por defecto), una aplicación incluida habilitada se instala en el siguiente inicio:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Esta es también la forma de instalar Por hacer, que no se ofrece en el diálogo del Marketplace. La variable AM_PLUGINSETTINGS_PLUGINSTATES también funciona, pero reemplaza el mapa completo: liste todas las aplicaciones que desee activar.

Ajustes de las aplicaciones

La configuración de las aplicaciones se guarda en PluginSettings.Plugins.<app id>, con claves en minúsculas. Puedes modificarla en la página de la Consola de sistema de la aplicación o mediante amctl config patch, como se muestra en Configuración. AM_PLUGINSETTINGS_PLUGINS reemplaza la configuración de todas las aplicaciones a la vez y las bloquea, por lo que se recomienda evitarlo.

GIFs

La aplicación GIF añade una pestaña de GIF y pegatinas al selector de emojis, respaldada por el servicio de GIF de Antimatter (gifs-server), que utiliza la API de Tenor. El archivo compose del sitio ejecuta el servicio y configura la aplicación mediante variables. Su configuración, en Consola de sistema › Plugins › GIF:

AjusteVariable (valor predeterminado)PredeterminadoQué hace

Clave de APIAM_GIFS_API_KEYvacíoUna de las AM_GIFS_API_KEYS del servicio.
Clave de subidaAM_GIFS_UPLOAD_KEYvacíoUna de las AM_GIFS_UPLOAD_KEYS del servicio. Permite a las personas añadir GIF y pegatinas. Si está vacío, las subidas se desactivan.
Quién puede añadir GIF y pegatinasadministradoresSolo administradores del sistema, o todos los usuarios.
Habilitar pegatinasactivadoMuestra la pestaña de pegatinas.
Filtro de contenidomedioalto, medio, bajo o desactivado.
Servir los medios a través de AntimatteractivadoLos navegadores cargan los GIF desde Antimatter, que los obtiene del servicio. Mantenlo activado si el servicio solo está en tu red interna.

Para esta aplicación, las variables son solo valores predeterminados: un valor establecido en la Consola de sistema tiene prioridad sobre ellos. Si el selector de GIF permanece vacío, revisa la URL del servicio y la clave de API en esa página.

Mientras la aplicación GIF esté configurada, su pestaña reemplaza al selector de Giphy integrado (Consola de sistema › Integraciones › GIF › Habilitar Selector de GIF, ServiceSettings.EnableGifPicker).

El servicio de GIF

El servicio guarda todo en su directorio de datos (/data, el volumen gifs): un índice de búsqueda y los medios. Sus variables principales:

VariablePredeterminadoQué hace
AM_GIFS_API_KEYSningunaClaves de API separadas por comas. Sin una clave, la API queda abierta a cualquiera que pueda acceder a ella. Varias claves permiten rotarlas.
AM_GIFS_UPLOAD_KEYSningunaClaves autorizadas para subir. Sin una, no se permiten subidas.
AM_GIFS_RATE_LIMIT20Solicitudes por segundo por cliente (clave de API y dirección); 0 lo desactiva. El archivo compose establece 0, porque todas las solicitudes de Antimatter comparten una sola clave y dirección.
AM_GIFS_LISTEN:8080Dirección de escucha.
AM_GIFS_PUBLIC_URLde las solicitudesURL externa, si expones el servicio.
AM_GIFS_TRUST_PROXYfalseConfiar en las cabeceras X-Forwarded-*, solo detrás de un proxy.
AM_GIFS_UPLOAD_MAX_MB16Tamaño máximo de los archivos subidos.

Para añadir tus propios GIF en lotes, impórtalos con un manifiesto, desde un directorio montado en un contenedor de un solo uso:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

Para volver a importar las pegatinas iniciales tras una actualización: docker compose run --rm gifs stickers. El formato del manifiesto y los otros comandos están en el README de gifs-server.

Correo y Calendario

Correo y Calendario conectan a cada persona con su propio buzón (IMAP y SMTP) y su propio calendario (CalDAV). Las personas introducen su servidor y contraseña en la aplicación; las contraseñas se almacenan cifradas. No configuras los servidores de correo o calendario por ellas, pero decides a qué pueden conectarse:

AplicaciónAjustePredeterminadoQué hace
Correo, CalendarioPermitir servidores de correo en redes privadas, Permitir servidores de calendario en redes privadas (AllowPrivateNetworks)desactivadoDesactivado, el servidor se niega a conectarse a direcciones de bucle, privadas y de enlace local, de modo que las aplicaciones no pueden usarse para acceder a tu red interna. Actívalo si tu servidor de correo o calendario está en una dirección privada.
Correo, CalendarioPermitir conexiones sin cifrar (AllowInsecureConnections)desactivadoDesactivado, las conexiones deben usar TLS (Correo: TLS o STARTTLS; Calendario: HTTPS).
CorreoIntervalo de comprobación de mensajes sin leer (minutos) (UnreadCheckMinutes)2 minutosFrecuencia con la que se comprueban los recuentos de mensajes sin leer cuando el servidor de correo no puede enviarlos.
CorreoTamaño máximo de los mensajes (MB) (MaxMessageSizeMB)25 MBLímite de tamaño de los mensajes enviados y leídos.
CalendarioEnviar recordatorios (EnableReminders)activadoEl bot de Calendario envía un mensaje directo antes de los eventos (10 minutos antes, para eventos que no tienen su propia alarma).

Para permitir a las personas iniciar sesión en buzones de Gmail o Microsoft 365 con su cuenta en lugar de una contraseña, crea un cliente OAuth y completa los campos de Google o Microsoft de la aplicación Correo:

  • Google: un cliente OAuth web con la API de Gmail y el ámbito https://mail.google.com/.
  • Microsoft: una aplicación de Entra ID con los permisos delegados IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email y profile. El inquilino es common por defecto.
  • En ambos, la URI de redirección es https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (la URL de tu sitio).

Kanban, Notas, Pizarra, Encuestas y Playbooks

  • Kanban (focalboard) está en /kanban (los enlaces antiguos /boards se redirigen allí). Su única configuración, Enable Publicly-Shared Boards (EnablePublicSharedBoards, desactivada), permite a los editores de tableros compartir un tablero con cualquier persona que tenga el enlace, sin necesidad de iniciar sesión.
  • Notes y Polls no tienen configuraciones.
  • Whiteboard: los administradores del sistema pueden subir bibliotecas de formas (archivos Excalidraw .excalidrawlib, de hasta 5 MB cada uno) para todo el servidor en su página de configuración. Los administradores de la comunidad gestionan las bibliotecas de su propia comunidad.
  • Playbooks tiene algunas configuraciones, en su mayoría funciones experimentales; los valores predeterminados son adecuados para la mayoría de los servidores.
  • Memes: Who can add meme templates (todos por defecto, o solo administradores).
  • Todo no tiene configuraciones de servidor.

GitHub, GitLab y Jira

Estas aplicaciones conectan Antimatter con tu servicio de alojamiento de código y tu gestor de incidencias. Cada una requiere una aplicación OAuth en el otro extremo y un webhook que apunte de vuelta a Antimatter. Habilita la aplicación y luego ejecuta su comando de configuración en cualquier canal, que te guiará paso a paso: /github setup, /gitlab setup o /jira setup.

AplicaciónURL de redirección OAuthURL del webhook
GitHubhttps://chat.example.com/plugins/github/oauth/completehttps://chat.example.com/plugins/github/webhook
GitLabhttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/oauth/completehttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/webhook
Jira/jira instance install server <url> o /jira instance install cloud-oauth <url>; /jira webhook muestra las URLs de los webhooks.
Deja Use Preregistered OAuth Application desactivado en las aplicaciones de GitHub y GitLab: se basa en un servicio de Mattermost que Antimatter no tiene, y la aplicación se niega a iniciarse si está activado. Registra tu propia aplicación OAuth.

Las aplicaciones de GitHub y GitLab generan su secreto de webhook y su clave de cifrado al guardar por primera vez. La aplicación de GitHub puede limitarse a organizaciones (GithubOrg) y la de GitLab a un grupo (GitlabGroup); para GitHub Enterprise o un GitLab autoalojado, configura su URL base.

Métricas

La aplicación Metrics recopila las métricas de rendimiento del servidor en una pequeña base de datos de series temporales dentro de Antimatter, para que puedas descargarlas o incluirlas en un paquete de soporte sin ejecutar Prometheus. Al iniciarse, activa el punto de acceso de métricas del servidor (MetricsSettings.Enable). Consulta Operaciones.

Instalación de otras aplicaciones

Antimatter ejecuta aplicaciones de Mattermost (plugins). Tres formas de añadir una:

  • Desde un marketplace remoto. Habilitar Marketplace Remoto (PluginSettings.EnableRemoteMarketplace) está desactivado por defecto y URL del Marketplace (PluginSettings.MarketplaceURL) está vacío: Antimatter no utiliza el marketplace de Mattermost e ignora su dirección si una configuración de Mattermost aún la contiene. Para listar las aplicaciones de un servidor de marketplace en el que confíes, activa la configuración y establece su URL. Las versiones de las aplicaciones que Antimatter incluye (Llamadas, Playbooks, Kanban y las demás) que ofrece ese marketplace se ocultan, por lo que no pueden reemplazar las de Antimatter: Permitir que el Marketplace ofrezca sus propias versiones de los complementos de Antimatter (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) está desactivado por defecto.
  • Subiendo un paquete (.tar.gz). Las subidas están desactivadas por defecto y no tienen un interruptor en la Consola de sistema: establece AM_PLUGINSETTINGS_ENABLEUPLOADS=true y luego usa Cargar Plugin en la gestión de complementos, o amctl --local plugin add app.tar.gz.
  • Desde una URL: amctl plugin install-url <url>, también con las subidas activadas.

Antimatter verifica las firmas de las aplicaciones contra las claves en las que confía: la clave de Antimatter, la clave con la que Mattermost, Inc. firma sus aplicaciones publicadas (de modo que una aplicación de Mattermost que descargues tú se instale) y cualquier clave que añadas en PluginSettings.SignaturePublicKeyFiles. Con Requerir Firma del Plugin (PluginSettings.RequirePluginSignature, desactivado por defecto) activado, se rechazan las aplicaciones sin firma y se desactivan las subidas.

Una aplicación se ejecuta dentro del servidor con acceso completo a sus datos. Instala solo aplicaciones en las que confíes.

Algunas aplicaciones creadas para las ediciones de pago de Mattermost verifican por sí mismas una licencia de Mattermost y se niegan a ejecutarse; Antimatter no finge tener una para ellas.
