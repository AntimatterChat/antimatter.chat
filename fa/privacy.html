این صفحه دو موضوع را پوشش می‌دهد: نرم‌افزار Antimatter که سازمان‌ها روی سرورهای خود اجرا می‌کنند، و این وب‌سایت، antimatter.chat.

نرم‌افزار Antimatter

Antimatter خودمیزبان (self-hosted) است. هنگام استفاده از یک سرور Antimatter، سازمانی که آن را اجرا می‌کند تصمیم می‌گیرد چه داده‌هایی نگهداری شوند، برای مدت چند و چه کسانی به آن‌ها دسترسی دارند. پروژه Antimatter به سرور، حساب کاربری یا پیام‌های شما دسترسی ندارد. برای سؤالات مربوط به داده‌های شما روی یک سرور خاص، با مدیران آن تماس بگیرید؛ سیاست حفظ حریم خصوصی خودشان اعمال می‌شود.

آنچه نرم‌افزار به‌تنهایی انجام می‌دهد:

  • بدون تله‌متری. سرور آمار استفاده، تشخیص‌ها یا هیچ داده دیگری را به پروژه Antimatter، شرکت Mattermost, Inc. (که نرم‌افزار Antimatter بر پایه نرم‌افزار آن ساخته شده) یا سایر طرف‌های ثالث ارسال نمی‌کند.
  • اتصالات خارجی فقط برای ویژگی‌هایی که یک مدیر فعال می‌کند، به سمت سرویس‌هایی که پیکربندی می‌کنند: برای مثال یک سرویس اعلان push، یک ارائه‌دهنده GIF، یک سرور ایمیل، یک ارائه‌دهنده هویت برای ورود یکپارچه (single sign-on)، یا مدل‌های هوش مصنوعی، گفتار یا ترجمه.
  • دو استثنا که به‌طور پیش‌فرض فعال هستند و مدیران می‌توانند آن‌ها را غیرفعال کنند. پیش‌نمایش پیوندها: وقتی کسی پیوندی را منتشر می‌کند، سرور آن صفحه را دریافت می‌کند تا عنوان و تصویر آن را نمایش دهد. و مکالمه‌ها: از سرور STUN عمومی Cloudflare (stun.cloudflare.com) برای یافتن آدرس‌های شبکه عمومی استفاده می‌کنند. سرور هنگام شروع اپلیکیشن Calls از آن سؤال می‌کند و دستگاه هر فرد هنگام پیوستن به یک مکالمه از آن سؤال می‌کند. Cloudflare فقط آدرس IP و پورت سرور و هر فردی که پیوست می‌کند را می‌بیند، نه خود مکالمه. مدیران می‌توانند به‌جای آن از سرور STUN خودشان یا هیچ‌کدام استفاده کنند؛ به مکالمه و صدا مراجعه کنید.
  • ویژگی‌های هوش مصنوعی از مدل‌هایی استفاده می‌کنند که مدیر انتخاب می‌کند. وقتی این مدل‌ها توسط یک طرف ثالث میزبانی می‌شوند، آنچه به آن‌ها ارسال می‌شود (پیامی برای بازنویسی، مکالمه‌ای برای خلاصه‌سازی، یا صدای یک مکالمه که متن‌نویسی شده) به آن ارائه‌دهنده می‌رود. مدیران می‌توانند از مدل‌های خودمیزبان استفاده کنند تا هیچ داده‌ای شبکه آن‌ها را ترک نکند.

این وب‌سایت

  • antimatter.chat یک وب‌سایت ایستا (static) است که روی GitHub Pages میزبانی می‌شود.
  • این صفحه کوکی‌ای تنظیم نمی‌کند و از هیچ تحلیلگر، ردیاب یا تبلیغاتی استفاده نمی‌کند. فونت‌ها و تصاویر آن از خود سایت ارائه می‌شوند، بنابراین مرورگر شما هنگام مطالعه، درخواستی به وب‌سایت‌های دیگر ارسال نمی‌کند.
  • مانند هر میزبان وب دیگری، GitHub آدرس IP شما و صفحاتی که درخواست می‌کنید را دریافت می‌کند تا آن‌ها را ارائه دهد. برای جزئیات بیشتر، به بیانیه حریم خصوصی GitHub مراجعه کنید.
  • اگر در GitHub مشکلی (issue) باز کنید یا مشارکتی داشته باشید، آنچه در آنجا منتشر می‌کنید عمومی است و توسط GitHub بر اساس شرایط خود آن مدیریت می‌شود.
