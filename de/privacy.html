Datenschutzerklärung

Zuletzt aktualisiert: 11. Oktober 2026. Diese Übersetzung dient nur der Information; maßgeblich ist die englische Fassung.

Diese Seite behandelt zwei Dinge: die Software Antimatter, die Organisationen auf ihren eigenen Servern betreiben, und diese Website, antimatter.chat.

Die Software Antimatter

Antimatter wird selbst gehostet. Wenn du einen Antimatter-Server nutzt, entscheidet die Organisation, die ihn betreibt, welche Daten gespeichert werden, wie lange und wer darauf zugreifen kann. Das Antimatter-Projekt hat keinen Zugriff auf deinen Server, dein Konto oder deine Nachrichten. Bei Fragen zu deinen Daten auf einem bestimmten Server wende dich an dessen Admins; es gilt deren eigene Datenschutzerklärung.

Was die Software von sich aus tut:

  • Keine Telemetrie. Der Server sendet weder Nutzungsstatistiken noch Diagnosedaten oder sonstige Daten an das Antimatter-Projekt oder an Dritte.
  • Verbindungen nach außen nur für Funktionen, die ein Admin aktiviert, und nur zu den Diensten, die er konfiguriert: zum Beispiel ein Push-Benachrichtigungsdienst, Linkvorschauen von Websites, die in Nachrichten gepostet werden, ein GIF-Anbieter, ein E-Mail-Server, ein Identitätsanbieter für Single Sign-on oder Modelle für KI, Spracherkennung oder Übersetzung.
  • KI-Funktionen nutzen die Modelle, die der Admin auswählt. Werden sie von einem Drittanbieter gehostet, geht der an sie gesendete Inhalt (eine Nachricht zum Umschreiben, eine Unterhaltung zum Zusammenfassen, die Audiodaten eines transkribierten Anrufs) an diesen Anbieter. Admins können selbst gehostete Modelle verwenden, damit nichts ihr Netzwerk verlässt.

Diese Website

  • antimatter.chat ist eine statische Website, gehostet auf GitHub Pages.
  • Sie setzt keine Cookies und verwendet keine Analyse-Tools, Tracker oder Werbung. Schriften und Bilder werden von der Website selbst ausgeliefert, sodass dein Browser beim Lesen keine Anfragen an andere Websites stellt.
  • Wie jeder Webhoster erhält GitHub deine IP-Adresse und die Seiten, die du aufrufst, um sie auszuliefern. Siehe das GitHub Privacy Statement.
  • Wenn du auf GitHub ein Issue eröffnest oder etwas beiträgst, ist das, was du dort postest, öffentlich und wird von GitHub nach dessen eigenen Bedingungen verarbeitet.
