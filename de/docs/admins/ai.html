KI

Die KI-Funktionen von Antimatter verwenden Modelle Ihrer Wahl: einen Cloud-Anbieter oder einen Server in Ihrem eigenen Netzwerk. Es wird nichts irgendwohin gesendet, bis Sie ein Modell konfiguriert haben. Diese Seite behandelt jede Funktion, die Daten, die sie sendet, und wie Sie sie deaktivieren.

Die KI-Funktionen

FunktionKonfiguriert inArt des ModellsStandardmäßig aktiviert
KI-Agenten: Chat mit einem Bot, Zusammenfassungen von Threads und Kanälen, Hilfe in der EingabezeileDie Agents-AppJeder große Sprachmodell- (LLM-)DienstDie App ist aktiv, tut aber nichts, bis Sie einen Dienst hinzufügen
Transkriptionen und Live-Untertitel für AnrufeDie Calls-AppSpeech-to-Text, OpenAI-kompatibelnein
VorlesenDer ServerText-to-Speech, OpenAI-kompatibelnein
Automatische Übersetzung von KanälenDer ServerLibreTranslate, ein OpenAI-kompatibles LLM oder ein Agents-Dienstnein

„OpenAI-kompatibel“ bedeutet ein Server, der dieselbe HTTP-API wie OpenAI anbietet. Die meisten Modellserver, die Sie selbst betreiben können, tun dies (z. B. Ollama, vLLM, der Server von llama.cpp oder Whisper- und Text-to-Speech-Server), ebenso wie viele Cloud-Anbieter. Für keine dieser Funktionen ist eine Lizenz erforderlich.

KI-Agenten

Die Agents-App (id mattermost-ai) ist standardmäßig aktiv. Die Einrichtung erfolgt in zwei Schritten: Fügen Sie einen Dienst (eine Verbindung zu einem Modellanbieter) hinzu, erstellen Sie dann Agenten (Bots, die einen Dienst verwenden).

1. Einen Dienst hinzufügen

Gehen Sie zu Systemkonsole › Plugins › Agenten und klicken Sie unter AI Services auf Add an AI Service. Wählen Sie den Service type:

  • OpenAI-kompatibel: für einen Modellserver, den Sie selbst betreiben, oder jeden Anbieter mit einer OpenAI-artigen API. Geben Sie die API-URL ein (z. B. http://ollama:11434/v1 oder http://vllm.internal:8000/v1) und den API-Schlüssel nur, wenn der Server einen benötigt. Wenn der Server nur die Chat-Completions-API unterstützt, deaktivieren Sie Responses-API verwenden.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: gehostete Anbieter. Jeder benötigt seinen API-Schlüssel (Bedrock: eine AWS-Region und Zugangsdaten oder eine IAM-Rolle; Vertex AI: ein Projekt, eine Region und ein Servicekonto; Azure: auch die API-URL).

Setzen Sie dann das Standardmodell (eine Liste, wenn der Anbieter seine Modelle melden kann, andernfalls den Namen eingeben) sowie, falls der Anbieter sie nicht meldet, das Eingabe-Token-Limit und das Ausgabe-Token-Limit. Ein Fallback-Dienst kann übernehmen, wenn dieser Dienst fehlschlägt. Speichern Sie die Änderungen.

Der Server stellt diese Anfragen selbst, daher muss er die API erreichen: ein Modellserver im selben Compose-Projekt, in Ihrem Netzwerk oder im Internet. Ausgehende Anfragen respektieren die Variablen HTTP_PROXY und HTTPS_PROXY.

2. Agenten erstellen

Agenten werden auf der Seite Agenten der Web-App erstellt: Öffnen Sie sie über das Produktmenü oder über Verwalten im Agenten-Auswahlfeld des Agenten-Panel. Die Adresse lautet https://chat.example.com/plug/mattermost-ai/agents. Jeder Agent hat einen Anzeigename, einen Agent Username (wie er von anderen erwähnt wird), einen Service und optional ein Modell, Custom Instructions sowie Schalter für Enable Vision (Bilder) und Enable Tools. Der Reiter Zugang legt fest, in welchen Kanälen der Agent verwendet werden kann und welche Benutzer ihn nutzen dürfen. Unter AI Functions in der Systemkonsole bestimmt Default bot, welcher Agent verwendet wird, wenn keiner ausgewählt ist, beispielsweise für Anrufzusammenfassungen.

Standardmäßig kann jeder Benutzer eigene Agenten mit den von Ihnen konfigurierten Diensten erstellen. Um dies nur für Administratoren zu ermöglichen, entfernen Sie die Berechtigung Eigene KI-Agenten verwalten von der Rolle der Mitglieder unter Systemkonsole › Benutzerverwaltung › Berechtigungen.

Optionale Funktionen der Agenten-App

  • Embedding-Suche (experimentell, deaktiviert): semantische Suche über Nachrichten. Erfordert PostgreSQL mit der pgvector-Erweiterung und ein Embedding-Modell (OpenAI oder OpenAI-kompatibel). Es werden alle Nachrichten an das Embedding-Modell gesendet, einschließlich privater Kanäle und Direktnachrichten.
  • Web-Suche (deaktiviert): ermöglicht es Agenten, das Web über Google, Brave oder einen von Ihnen betriebenen SearXNG-Server zu durchsuchen.
  • Native Werkzeuge: Bei Anbietern, die diese anbieten, können Agenten die eigene Websuche des Anbieters (für neue Agenten standardmäßig aktiviert, wo unterstützt), Web-Fetch und Codeausführung verwenden. Diese werden beim Anbieter ausgeführt. Sie können sie pro Agent deaktivieren.
  • Model Context Protocol (MCP): Verbindet Agenten mit MCP-Servern, denen Sie vertrauen, für zusätzliche Werkzeuge.
  • Debuggen: Trace Output (aus, Server-Logs oder ein OpenTelemetry-Endpunkt) und Enable Token Usage Logging, das Token-Zahlen in logs/agents/token_usage.log schreibt.

Sprach-zu-Text: Anruftranskripte und Untertitel

Anrufe können mit Live-Untertiteln durch einen Speech-to-Text-Server transkribiert werden, der einen OpenAI-kompatiblen /v1/audio/transcriptions-Endpunkt anbietet. Die Einrichtung finden Sie unter Anrufe und Sprache. Wenn Transkriptionen zusammenfassen aktiviert ist, veröffentlicht der Standard-Agent auch eine Zusammenfassung jeder Transkription.

Text-to-Speech: Vorlesen

Wenn Text zu Sprache aktiviert ist, enthält das Menü jeder Nachricht die Option Vorlesen: Der Server sendet den Nachrichtentext an eine Text-zu-Sprache-API und spielt die Audio-Datei ab. Die Einstellungen finden Sie unter Systemkonsole › Integrationen › Text zu Sprache:

EinstellungSchlüssel und VariableWas einzugeben ist
Nachrichten vorlesenTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (standardmäßig deaktiviert)
API-Basis-URLTextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLDie Basis-URL bis einschließlich /v1, beispielsweise http://tts.internal:8000/v1. Der Server ruft dessen /audio/speech-Endpunkt auf.
ModellTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELDas Modell, wie es die API bezeichnet, beispielsweise tts-1. Pflichtfeld.
StimmeTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEEine der Stimmen des Modells oder leer für die Standardstimme.
API-SchlüsselTextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYWird als Bearer-Token gesendet. Leer, wenn die API keines benötigt.

Vor dem Senden entfernt der Server Codeblöcke, Links, Emoji-Codes und Formatierungen und behält höchstens 4000 Zeichen bei. Er fordert MP3-Audio an und speichert die letzten 64 Ergebnisse im Speicher, sodass eine zweimal gelesene Nachricht nur einmal gesendet wird.

Automatische Übersetzung

Automatische Übersetzung zeigt die Nachrichten eines Kanals in der jeweiligen Sprache des Lesers an. Richten Sie sie unter Systemkonsole › Systemkonfiguration › Lokalisierung ein, im Bereich Automatische Übersetzung:

EinstellungSchlüsselStandard
AktivierenAutoTranslationSettings.Enableaus
Anbieter von ÜbersetzungenAutoTranslationSettings.Providerlibretranslate, openai (angezeigt als "OpenAI-compatible API") oder agents (ein Dienst der Agents-App)
Erlaubte SprachenAutoTranslationSettings.TargetLanguagesen: die Sprachen, in die Nachrichten übersetzt werden können
Timeout für die Übersetzung (ms)AutoTranslationSettings.TimeoutMs5000
Automatische Übersetzung für Direktnachrichten und Gruppennachrichten einschränkenAutoTranslationSettings.RestrictDMAndGMaus

Jeder Anbieter hat eigene Felder:

  • LibreTranslate: LibreTranslate API Endpunkt und LibreTranslate API-Schlüssel (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Ein LibreTranslate-Server kann in Ihrem eigenen Netzwerk betrieben werden.
  • OpenAI-kompatible API: API-Basis-URL (bis einschließlich /v1; der Server verwendet dessen Chat-Completions-Endpunkt), Modell und API-Schlüssel (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Ein kleines, lokal laufendes Übersetzungsmodell funktioniert gut.
  • Agenten: KI-Dienst, einer der in der Agenten-App konfigurierten Dienste.

Sobald die Funktion aktiviert ist, können Kanal-Administratoren die Übersetzung für einen Kanal in dessen Einstellungen aktivieren (Automatische Übersetzung), und jedes Mitglied kann sich über das Kanalmenü davon ausschließen (Nachrichten übersetzen). In Direktnachrichten und Gruppennachrichten kann jedes Mitglied die Funktion aktivieren; ist die Einschränkung aktiviert, ist die Übersetzung dort nicht verfügbar. Übersetzte Nachrichten zeigen „Übersetzt aus …“ mit einem Link zum Original an.

Code, Links, Erwähnungen und Emojis werden vor dem Senden des Textes durch Platzhalter ersetzt und anschließend wiederhergestellt.

Welche Daten wohin gesendet werden

FunktionWas gesendet wirdAn
AgentenDie Anfrage, die Nachrichten des Threads oder Kanals, um den es geht, die Anweisungen des Agents, die Ergebnisse der Tools, Bilder (wenn Vision aktiviert ist) sowie Name, Benutzername, Position und Sprache des anfragenden NutzersDie API des Dienstes
Embedding-SucheJede Nachricht (ausgenommen Nachrichten von Bots und Systemnachrichten)Die Embedding-API
Native Tools und WebsucheSuchanfragen, abzurufende Seiten, CodeDer Anbieter oder die von Ihnen gewählte Suchmaschine
Transkription von AnrufenDie Stimme aller, die während der Aktivierung sprechenDie Speech-to-Text-API
VorlesenDer Text der gelesenen NachrichtDie Text-to-Speech-API
ÜbersetzungDer Text der Nachrichten in übersetzten KanälenLibreTranslate, die LLM-API oder der Agents-Dienst

Um alles innerhalb Ihres Netzwerks zu halten, richten Sie jede Funktion auf Server ein, die Sie selbst betreiben. Bei einem Cloud-Anbieter prüfen Sie dessen Bedingungen zur Datenhaltung und informieren Sie Ihre Nutzer, welche Funktionen ihre Nachrichten nach außen senden.

KI-Funktionen deaktivieren

Es gibt keinen einzelnen Schalter: Jede Funktion hat ihren eigenen.

  • Agenten: Deaktivieren Sie die App „Agenten“ in Systemkonsole › Plugins › Plugin-Verwaltung. Dadurch werden auch die Zusammenfassungen von Anrufen und der Übersetzungsanbieter für Agenten entfernt.
  • Transkription und Untertitel: AM_CALLS_ENABLE_TRANSCRIPTIONS=false und AM_CALLS_ENABLE_LIVE_CAPTIONS=false (Standardwerte).
  • Vorlesen: Nachrichten vorlesen deaktivieren (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, Standard).
  • Übersetzung: Auto-Übersetzung deaktivieren (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, Standardwert).

Das Deaktivieren der Agents-App schaltet die anderen drei Funktionen nicht ab: Sie rufen ihre eigenen APIs direkt auf.
