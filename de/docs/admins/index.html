Einen Server betreiben

Diese Anleitung richtet sich an Systemadministratoren, die einen Antimatter-Server installieren und betreiben. Es wird vorausgesetzt, dass Sie mit Linux, Docker und Reverse Proxies vertraut sind, aber nicht mit Antimatter.

Was eine Installation ausmacht

Antimatter ist ein selbst gehosteter Team-Chat, ein Fork von Mattermost. Eine vollständige Installation besteht aus diesen Teilen. Nur die ersten drei sind erforderlich.

KomponenteFunktionErforderlich
Der Antimatter-ServerEin Go-Programm (antimatter), das die Web-App, die API und die Websockets auf Port 8065 bereitstellt, die mitgelieferten Apps (Plugins) ausführt und das Anruf-Medien auf Port 8443 transportiert. Das Kommandozeilen-Tool amctl verwaltet es.ja
PostgreSQLDie Datenbank: Nachrichten, Benutzer, Communities und – in der empfohlenen Konfiguration – die Servereinstellungen. Version 15 oder neuer.ja
DateispeicherHochgeladene Dateien, Bilder und installierte Apps: ein S3-kompatibler Dienst (die Compose-Datei verwendet RustFS) oder ein lokales Verzeichnis.ja
Ein Reverse ProxyHTTPS vor dem Server: das Caddy-Profil der Compose-Datei oder Ihr eigener nginx.für den Produktivbetrieb
Der GIF-Dienst (gifs-server)GIFs und Sticker für den GIF-Auswahlbereich, aus Ihrem eigenen Katalog. Er spricht die Tenor-API.nein
Ein Push-ProxyLeitet Benachrichtigungen über Apple und Google an die mobile App weiter.für mobile Benachrichtigungen
rtcd, ein TURN-ServerEin separater Medien-Server für viele Anrufe und ein Relay für Personen hinter strengen Firewalls.nein
KI-EndpunkteDie Modelle hinter KI-Agenten, Anruf-Transkription, Vorlesen und Übersetzung: ein Cloud-Anbieter oder Server, die Sie selbst betreiben.nein

Antimatter hat keine Lizenz und keine kostenpflichtige Edition: Single Sign-On, LDAP, hohe Verfügbarkeit, Compliance-Exporte, Datenhaltung und die anderen Funktionen, die Mattermost für seine kostenpflichtigen Pläne reserviert, sind alle enthalten.

Voraussetzungen

  • Ein Linux-Server, amd64 oder arm64, mit 2 CPU-Kernen und 4 GB Speicher oder mehr für einige hundert Personen, sowie Festplattenspeicher für die Dateien, die hochgeladen werden.
  • Docker Engine mit dem Compose-Plugin (docker compose), für die empfohlene Installation.
  • Für den Produktivbetrieb: ein Domainname, der auf den Server zeigt, und offene Ports 80 und 443 für HTTPS.
  • Für Anrufe: Port 8443, UDP und TCP, erreichbar für die Personen, die anrufen.
  • Für E-Mails: ein SMTP-Server, über den Antimatter senden kann.

Schnellstart

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Öffnen Sie anschließend die URL der Website und erstellen Sie Ihr Konto: Das erste Konto wird zum Systemadministrator. Installation erklärt jeden Schritt sowie die anderen Installationsmöglichkeiten.

In diesem Leitfaden

  • Installation: Docker Compose, die Images, das Release-Archiv, der erste Administrator.
  • Konfiguration: Einstellungen in der Datenbank oder in einer Datei, AM_-Umgebungsvariablen, die Systemkonsole, amctl, Protokolle.
  • Domain und HTTPS: die URL der Website, Caddy, nginx, Client-Adressen.
  • Anrufe und Sprache: Ports, NAT, TURN, rtcd, Transkription und Untertitel.
  • E-Mail und Push: SMTP, der Push-Proxy und die mobile App.
  • Mitgelieferte Apps: welche Apps aktiviert sind, deren Einstellungen, das Installieren anderer Apps.
  • KI: Modelle für Agenten, Sprache und Übersetzung sowie die Datenflüsse.
  • Anmeldung und Konten: Registrierung, Passwörter, MFA, Single Sign-On, LDAP, Gäste, Sitzungen.
  • Backups und Upgrades: Backup, Wiederherstellung, Upgrade, Migration von Mattermost.
  • Betrieb: Überwachung, Skalierung, Datenhaltung, Compliance, Fehlerbehebung.
  • Sicherheit: Härtungs-Checkliste und ausgehende Verbindungen.

Sie betreiben eine Community statt eines Servers (Kanäle, Rollen, Moderation)? Siehe Community betreiben. Sie entwickeln Integrationen? Siehe Entwicklung auf Antimatter.

Ihre erste Stunde

  1. Installieren Sie die Software und erstellen Sie sofort das Administratorkonto.
  2. Schalten Sie den Server hinter HTTPS auf einer eigenen Domain ein.
  3. Konfigurieren Sie SMTP und senden Sie eine Test-E-Mail.
  4. Öffnen Sie den Port für Anrufe und deaktivieren Sie den Testmodus der Anruf-App.
  5. Legen Sie fest, wer sich registrieren darf, und aktivieren Sie MFA.
  6. Prüfen Sie die ausgehenden Verbindungen in Sicherheit.
  7. Richten Sie tägliche Backups ein.

Hilfe erhalten

Stellen Sie Fragen in den Community-Diskussionen und melden Sie Fehler im Community-Repository. Melden Sie Sicherheitsprobleme vertraulich, wie in der Sicherheitsrichtlinie beschrieben.
