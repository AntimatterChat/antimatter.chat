Εγκατάσταση με Docker Compose

Αυτός είναι ο συνιστώμενος τρόπος. Ένα αρχείο compose εκτελεί το Antimatter, το PostgreSQL, την αποθήκη αρχείων και την υπηρεσία GIF. Χρειάζεστε έναν διακομιστή Linux με Docker Engine και το πρόσθετο Compose (docker compose), 2 πυρήνες CPU και 4 GB μνήμης ή περισσότερα.

1. Λήψη του αρχείου compose

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml

2. Δημιουργία του αρχείου .env

Το αρχείο compose διαβάζει τις ρυθμίσεις του από ένα αρχείο .env στον ίδιο φάκελο. Δημιουργήστε το με τυχαία μυστικά:

cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
chmod 600 .env

Ορίστε το SITE_URL στην διεύθυνση που θα πληκτρολογήσουν οι χρήστες στον περιηγητή τους, για παράδειγμα http://192.168.1.20:8065 σε τοπικό δίκτυο ή https://chat.example.com με τομέα. Κρατήστε το αρχείο .env: η βάση δεδομένων και η αποθήκη χρησιμοποιούν αυτά τα κωδικά από την πρώτη εκτέλεση, και χρειάζεστε το ίδιο αρχείο για την αποκατάσταση ενός αντιγράφου ασφαλείας.

3. Εκτέλεση

docker compose up -d
docker compose ps

Η πρώτη εκτέλεση διαρκεί ένα ή δύο λεπτά: το PostgreSQL δημιουργεί τη βάση δεδομένων, μια μονοεπίπεδη υπηρεσία bucket δημιουργεί το δοχείο αποθήκευσης, μια μονοεπίπεδη υπηρεσία gifs-stickers εισάγει το αρχικό πακέτο αυτοκόλλητων και το Antimatter δημιουργεί τους πίνακες του. Παρακολουθήστε την με docker compose logs -f antimatter.

Για να χρησιμοποιήσετε ένα όνομα τομέα και HTTPS από την αρχή, δείτε Τομέας και HTTPS: με το αρχείο compose είναι δύο επιπλέον γραμμές στο .env και το προφίλ https.

Το PostgreSQL, ο αποθηκευτικός χώρος και η υπηρεσία GIF βρίσκονται σε ένα εσωτερικό δίκτυο (private) χωρίς πρόσβαση στο Internet, στο οποίο συμμετέχει μόνο το Antimatter. Κανένα από αυτά δεν εκθέτει θύρα.

Ο διακομιστής Antimatter δεν αποθηκεύει τίποτα στον δίσκο: οι ρυθμίσεις του βρίσκονται στη βάση δεδομένων (το AM_CONFIG δείχνει σε αυτήν) και τα αρχεία και οι εφαρμογές του βρίσκονται στην υπηρεσία αποθήκευσης. Μπορείτε να αφαιρέσετε και να ξαναδημιουργήσετε τον διακομιστή οποιαδήποτε στιγμή. Ό,τι πρέπει να εφεδρεύεται βρίσκεται στους τόμους postgres, files και gifs, καθώς και στο .env.

Επιλέξτε εικόνα

Δημοσιεύονται δύο εικόνες Antimatter, και οι δύο για linux/amd64 και linux/arm64, και και οι δύο δημιουργούνται από το κλάδο main κάθε αποθετηρίου:

ΕικόναΕνσωματωμένες εφαρμογέςΕτικέτες
ghcr.io/antimatterchat/antimatterΠράκτορες, Κλήσεις, GitHub, GitLab, Jira, Kanban, Metrics και Playbooks.latest, X.Y.Z για εκδόσεις, sha-<commit>
ghcr.io/antimatterchat/antimatter-nextΤα ίδια, συν Φωνητικά κανάλια, Ψηφοφορίες, Mail, Ημερολόγιο, Σημειώσεις, Λευκός πίνακας, GIFs, Εκκρεμότητες και Memes. Αναδημιουργείται κάθε βράδυ.latest, nightly, nightly-<YYYYMMDD>, sha-<commit>

Το αρχείο compose του ιστοτόπου χρησιμοποιεί το antimatter-next, επειδή η υπηρεσία GIF και οι περισσότερες εφαρμογές που περιγράφονται σε αυτόν τον ιστότοπο υπάρχουν μόνο σε αυτήν την εικόνα. Για να αλλάξετε εικόνα, ορίστε ANTIMATTER_IMAGE στο .env και εκτελέστε docker compose up -d.

Το latest αλλάζει από κάτω σας. Σε παραγωγή, καρφιτσωθείτε σε μια ετικέτα όπως nightly-20261015 ή sha-<commit>, και αλλάξτε την με σκόπιμη απόφαση όταν κάνετε αναβάθμιση. Ο διακομιστής αναβαθμίζει τη βάση δεδομένων του κατά την εκκίνηση, οπότε δεν μπορείτε να επιστρέψετε σε παλαιότερη εικόνα, ή από antimatter-next σε antimatter, χωρίς να επαναφέρετε ένα εφεδρικό αρχείο που λήφθηκε πριν. Δείτε Εφεδρικά και αναβαθμίσεις.

Εντός της εικόνας

  • Ο διακομιστής βρίσκεται στο /antimatter, με τα εκτελέσιμα antimatter και amctl στο /antimatter/bin (στο PATH).
  • Εκτελείται ως ο μη προνομιούχος χρήστης antimatter (uid 2000) σε μια ελάχιστη βάση distroless, χωρίς shell.
  • Θύρες: 8065 (web και API), 8067 (metrics), 8074 (cluster), 8443 UDP και TCP (κλήσεις).
  • Η τοπική λειτουργία (ServiceSettings.EnableLocalMode) είναι ενεργοποιημένη, οπότε η εντολή amctl --local λειτουργεί εντός του container. Ο έλεγχος υγείας εκτελεί την εντολή amctl system status --local.
  • Τα ενσωματωμένα apps βρίσκονται στο /antimatter/prepackaged_plugins και είναι υπογεγραμμένα με το κλειδί υπογραφής apps του Antimatter.
  • Περιλαμβάνονται εργαλεία εξαγωγής κειμένου (pdftotext, wvText, unrtf, tidy), ώστε να είναι δυνατή η αναζήτηση στο περιεχόμενο των ανεβασμένων εγγράφων.

Άλλα αρχεία compose

Το αποθετήριο antimatter-docker περιλαμβάνει μια ρύθμιση παραγωγής στο deploy/compose/: nginx με δικές σας πιστοποιητικά ή Let's Encrypt (certbot), PostgreSQL, την προαιρετική υπηρεσία GIF (προφίλ gifs) και ονομασμένα volumes για τη ρύθμιση, τα δεδομένα και τα αρχεία καταγραφής του server, όπως τεκμηριώνεται στο README του. Χρησιμοποιεί από προεπιλογή το σταθερό image και αποθηκεύει τα αρχεία σε τοπικό volume αντί για αποθήκευση S3. Χρησιμοποιήστε το αν προτιμάτε nginx έναντι Caddy ή αν διαθέτετε ήδη πιστοποιητικά.

Δημιουργία του πρώτου διαχειριστή

Ανοίξτε το SITE_URL στον περιηγητή σας και δημιουργήστε έναν λογαριασμό. Ο πρώτος λογαριασμός που δημιουργείται σε έναν καινούργιο server γίνεται διαχειριστής συστήματος, και στη συνέχεια η ρύθμιση σας καθοδηγεί στη δημιουργία της πρώτης κοινότητας (η ονομασία που χρησιμοποιεί το Antimatter για ομάδα ή χώρο εργασίας).

Εκτελέστε το αμέσως μετά την πρώτη εκκίνηση: μέχρι τότε, όποιος φτάσει πρώτος στον server γίνεται ο διαχειριστής του. Για να δημιουργήσετε τον λογαριασμό από τη γραμμή εντολών αντί για τον περιηγητή, πριν ο server γίνει προσβάσιμος από το εξωτερικό:

docker compose exec antimatter amctl --local user create --system-admin --email-verified \
    --email admin@example.com --username admin --password 'a-long-password'
docker compose exec antimatter amctl --local team create --name main --display-name "Main"
docker compose exec antimatter amctl --local team users add main admin

Συνδεθείτε στη συνέχεια στο SITE_URL. Ξεκινήστε την εντολή με ένα κενό για να μην καταγραφεί ο κωδικός πρόσβασης στο ιστορικό του shell (με HISTCONTROL=ignorespace), ή αλλάξτε τον κωδικό μετά τη σύνδεση.

Επόμενα βήματα αφού συνδεθείτε:

  1. Καθορίστε ποιοι μπορούν να δημιουργούν λογαριασμούς: Σύνδεση και λογαριασμοί.
  2. Ρυθμίστε το email, ώστε να λειτουργούν οι προσκλήσεις και οι επαναφορές κωδικού: Email και push ειδοποιήσεις.
  3. Ανοίξτε την θύρα για τις κλήσεις στο firewall σας: Κλήσεις και φωνή.
  4. Ελέγξτε ποια apps είναι ενεργοποιημένα: Ενσωματωμένα apps.

Εγκατάσταση από αρχείο έκδοσης

Χωρίς Docker, ο διακομιστής εκτελείται από ένα αρχείο με το όνομα antimatter-<os>-<arch>.tar.gz (για παράδειγμα antimatter-linux-amd64.tar.gz). Περιέχει έναν μόνο κατάλογο antimatter/ με τα bin/antimatter, bin/amctl, config/config.json, τις εφαρμογές του περιβάλλοντος (client/ και client-fusion/), τις προτύπους των email και τις μεταφράσεις.

1. Προετοιμασία του PostgreSQL

Το Antimatter υποστηρίζει μόνο PostgreSQL, έκδοση 15 ή νεότερη (οι παλαιότερες εκδόσεις εκκινούν, αλλά με σφάλμα στο αρχείο καταγραφής). Δημιουργήστε έναν χρήστη και μια βάση δεδομένων:

sudo -u postgres psql <<'EOF'
CREATE USER antimatter WITH PASSWORD 'a-long-password';
CREATE DATABASE antimatter OWNER antimatter;
EOF

2. Αποσυμπίεση και ρύθμιση

sudo tar -xzf antimatter-linux-amd64.tar.gz -C /opt
sudo useradd --system --user-group antimatter
sudo mkdir -p /opt/antimatter/data
sudo chown -R antimatter:antimatter /opt/antimatter

Δείξτε στον διακομιστή τη βάση δεδομένων, είτε στο /opt/antimatter/config/config.json (SqlSettings.DataSource) είτε μέσω μεταβλητών περιβάλλοντος, και ορίστε τη διεύθυνση URL του χώρου εργασίας:

AM_SQLSETTINGS_DRIVERNAME=postgres
AM_SQLSETTINGS_DATASOURCE=postgres://antimatter:a-long-password@localhost:5432/antimatter?sslmode=disable&connect_timeout=10
AM_SERVICESETTINGS_SITEURL=https://chat.example.com

Το config.json του αρχείου είναι μια πλήρης προεπιλεγμένη ρύθμιση: οι αλλαγές που κάνετε στην Κονσόλα συστήματος αποθηκεύονται ξανά σε αυτό. Αν θέλετε να διατηρήσετε τη ρύθμιση στη βάση δεδομένων, δείτε Ρύθμιση.

3. Εκτέλεση ως υπηρεσία

Μονάδα systemd, στο /etc/systemd/system/antimatter.service:

[Unit]
Description=Antimatter
After=network.target postgresql.service

[Service]
Type=notify
User=antimatter
Group=antimatter
WorkingDirectory=/opt/antimatter
ExecStart=/opt/antimatter/bin/antimatter
EnvironmentFile=-/etc/antimatter.env
TimeoutStartSec=3600
Restart=always
RestartSec=10
LimitNOFILE=49152

[Install]
WantedBy=multi-user.target

Τοποθετήστε τις μεταβλητές AM_ στο /etc/antimatter.env (αναγνώσιμο μόνο από τον root), και στη συνέχεια:

sudo systemctl daemon-reload
sudo systemctl enable --now antimatter
journalctl -u antimatter -f

Ο διακομιστής ακούει στην θύρα 8065. Ανοίξτε http://<server>:8065, ή το domain σας μόλις τεθεί σε λειτουργία ένα reverse proxy (βλ. Domain και HTTPS), και δημιουργήστε τον πρώτο λογαριασμό: αυτός γίνεται ο διαχειριστής συστήματος.

Το bin/amctl διαχειρίζεται τον ενεργό διακομιστή από τη γραμμή εντολών. Στο ίδιο το σύστημα, λειτουργεί χωρίς σύνδεση μέσω τοπικής λειτουργίας: ορίστε AM_SERVICESETTINGS_ENABLELOCALMODE=true, και στη συνέχεια εκτελέστε sudo -u antimatter /opt/antimatter/bin/amctl --local system status.

Άλλες εντολές διακομιστή

Πέρα από την εκτέλεση του διακομιστή (antimatter, ή antimatter server), το binary διαθέτει μερικές εντολές συντήρησης. Διαβάζουν την ίδια ρύθμιση με τον διακομιστή.

antimatter db versionΕμφανίζει την τελευταία μεταφορά (migration) που εφαρμόστηκε στη βάση δεδομένων.
