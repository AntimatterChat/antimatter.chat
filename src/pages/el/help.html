Βοήθεια

Βοήθεια και υποστήριξη

Το Antimatter είναι ένα κοινωτικό έργο. Εδώ θα βρείτε απαντήσεις και θα μας ενημερώσετε για ένα πρόβλημα.

Χρήση του Antimatter

  • Στην εφαρμογή, το μενού βοήθειας (? στη γραμμή εργαλείων) περιλαμβάνει τον οδηγό χρήστη, τις συντομεύσεις πληκτρολογίου και βοήθεια για τη μορφοποίηση μηνυμάτων και τις εντολές καθέτου.
  • Η τεκμηρίωση περιλαμβάνει έναν οδηγό για κάθε τύπο αναγνώστη: άτομα που συνομιλούν, διαχειριστές συστήματος, διαχειριστές κοινότητας και προγραμματιστές.
  • Οι ερωτήσεις είναι καλοδεχούμενες στις κοινωτικές συζητήσεις.
  • Οι διαχειριστές του server σας μπορούν να βοηθήσουν με λογαριασμούς, κοινότητες και ρυθμίσεις.

Αναφορά προβλήματος

Βρήκατε ένα σφάλμα ή κάτι που δεν λειτουργεί όπως θα περιμένατε; Ανοίξτε ένα issue στο ανθεκτικό αποθετήριο της κοινότητας Antimatter, όπου συγκεντρώνεται η ανατροφοδότηση για κάθε μέρος του Antimatter: το server, τις web, desktop και mobile εφαρμογές, τις εφαρμογές όπως σημειώσεις ή κλήσεις, τις μεταφράσεις και αυτόν τον ιστότοπο. Δώστε την έκδοση (που εμφανίζεται στο Σχετικά στην εφαρμογή), τι κάνατε, τι περιμένατε και τι συνέβη αντίθετα.

Παρακαλώ αναζητήστε πρώτα τα υπάρχοντα issues και μην συμπεριλάβετε προσωπικές ή εμπιστευτικές πληροφορίες.

Αναφορά ασφάλειας ευπάθειας

Παρακαλώ μην αναφέρετε ασφάλεια ευπάθειες σε δημόσια issues. Ακολουθήστε την πολιτική ασφαλείας του αποθετηρίου, η οποία εξηγεί πώς να αναφέρετε ένα ιδιωτικά. Θα επιβεβαιώσουμε την αναφορά, θα εργαστούμε σε μια διόρθωση και θα σας αναγνωρίσουμε αν το επιθυμείτε.

Εμπορική υποστήριξη

Το Antimatter δεν έχει χρεωμένες συνδρομές υποστήριξης. Αν η οργάνωσή σας χρειάζεται υποστήριξη με επίπεδα υπηρεσιών, αναζητήστε μια εταιρεία που υποστηρίζει self-hosted chat servers.
