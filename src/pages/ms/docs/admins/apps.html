Aplikasi terpalit

Aplikasi disenaraikan sebagai Palam dalam Konsol Sistem. Ia berada dalam imej (dalam /antimatter/prepackaged_plugins), ditandatangani dengan kunci penandatanganan aplikasi Antimatter, jadi ia dipasang tanpa sambungan Internet.

Aplikasi yang dihidupkan secara lalai dipasang pada setiap permulaan jika ia belum ada, atau dinaik taraf jika imej mempunyai versi yang lebih baharu. Jika anda mematikannya, ia kekal mati: lalai hanya terpakai untuk aplikasi yang belum disebut dalam konfigurasi. Aplikasi yang mengekalkan id Mattermost (Ejen, Panggilan, Kanban, Buku Taktik dan integrasi) adalah binaan sendiri Antimatter.

Hidupkan, matikan dan konfigurasi aplikasi

Pergi ke Konsol Sistem › Plugin › Pengurusan Plagin. Di bawah Plugin Dipasang, setiap aplikasi mempunyai Aktifkan atau Lumpuhkan, Tetapan dan Buang, dan menunjukkan statusnya (Berjalan, Tidak berjalan, Gagal bermula…). Setiap aplikasi dengan tetapan juga mempunyai halaman sendiri di bawah Konsol Sistem › Plugin.

Aplikasi terikat yang dimatikan secara lalai dipasang daripada salinan imej itu sendiri: buka Pasaran Aplikasi daripada menu produk, cari aplikasi tersebut dan klik Pasang, kemudian aktifkannya dalam Pengurusan Plagin. Dari baris arahan:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Arahan lain: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Hidupkan aplikasi melalui konfigurasi

Aplikasi yang dihidupkan ialah tetapan PluginSettings.PluginStates, iaitu peta id aplikasi. Anda boleh menggabungkan entri ke dalamnya menggunakan amctl; dengan Aktifkan Plugin Prepackaged Automatik dihidupkan (lalai), aplikasi terikat yang diaktifkan akan dipasang pada permulaan seterusnya:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Ini juga cara untuk memasang Senarai tugasan, yang tidak ditawarkan dalam dialog Pasar. Pemboleh ubah AM_PLUGINSETTINGS_PLUGINSTATES juga berfungsi, tetapi ia menggantikan keseluruhan peta: senaraikan setiap aplikasi yang anda mahu dihidupkan.

Tetapan aplikasi

Tetapan aplikasi disimpan di bawah PluginSettings.Plugins.<app id>, dengan kunci dalam huruf kecil. Ubahkannya di halaman Konsol Sistem aplikasi, atau dengan amctl config patch seperti yang ditunjukkan dalam Konfigurasi. AM_PLUGINSETTINGS_PLUGINS menggantikan tetapan semua aplikasi sekaligus dan menguncinya, jadi elak menggunakannya.

Untuk menambah GIF anda sendiri secara pukal, importkannya dengan manifest, daripada direktori yang dipasang ke dalam kontena sekali guna:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

Untuk mengimport semula pelekat pemula selepas peningkatan: docker compose run --rm gifs stickers. Format manifest dan arahan lain terdapat dalam README gifs-server.

Mel dan Kalendar

Mel dan Kalendar menghubungkan setiap orang kepada peti mel (IMAP dan SMTP) dan kalendar (CalDAV) mereka sendiri. Orang memasukkan pelayan dan kata laluan mereka dalam aplikasi; kata laluan disimpan dalam bentuk disulitkan. Anda tidak mengkonfigurasi pelayan mel atau kalendar untuk mereka, tetapi anda menentukan apa yang boleh mereka sambungkan:

Untuk membolehkan orang log masuk ke peti mel Gmail atau Microsoft 365 dengan akaun mereka sebagai ganti kata laluan, cipta klien OAuth dan isi medan Google atau Microsoft aplikasi Mel:

  • Google: klien OAuth Web dengan Gmail API dan skop https://mail.google.com/.
  • Microsoft: aplikasi Entra ID dengan kebenaran terwakil IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email dan profile. Penguasa adalah common secara lalai.
  • Dalam kedua-duanya, URI alih arah ialah https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (URL laman web anda).

Kanban, Nota, Papan Putih, Undian dan Buku Taktik

  • Kanban (focalboard) berada di /kanban (pautan lama /boards akan dialihkan ke sana). Tetapan satu-satunya, Enable Publicly-Shared Boards (EnablePublicSharedBoards, dimatikan), membolehkan penyunting papan berkongsi papan dengan sesiapa yang mempunyai pautan, tanpa perlu log masuk.
  • Nota dan Undian tiada tetapan.
  • Papan Putih: pentadbir sistem boleh muat naik perpustakaan bentuk (fail Excalidraw .excalidrawlib, sehingga 5 MB setiap satu) untuk seluruh pelayan di halaman tetapan. Pentadbir komuniti menguruskan perpustakaan komuniti mereka sendiri.
  • Buku Taktik mempunyai beberapa tetapan, kebanyakannya ciri eksperimental; nilai lalai sesuai untuk kebanyakan pelayan.
  • Memes: Who can add meme templates (semua orang secara lalai, atau pentadbir).
  • Senarai tugasan tiada tetapan pelayan.

GitHub, GitLab dan Jira

Aplikasi ini menghubungkan Antimatter dengan pelayan kod dan penjejak isu anda. Setiap satu memerlukan aplikasi OAuth di pihak lawan dan webhook yang menunjuk kembali ke Antimatter. Aktifkan aplikasi, kemudian jalankan arahan penetapannya di mana-mana saluran, yang akan membimbing anda langkah demi langkah: /github setup, /gitlab setup atau /jira setup.

Biarkan Use Preregistered OAuth Application dimatikan dalam aplikasi GitHub dan GitLab: ia bergantung pada perkhidmatan Mattermost yang tiada dalam Antimatter, dan aplikasi akan enggan bermula jika ia dihidupkan. Daftarkan aplikasi OAuth anda sendiri.

Aplikasi GitHub dan GitLab menjana rahsia webhook dan kunci penyahkodannya pada simpanan pertama. Aplikasi GitHub boleh dihadkan kepada organisasi (GithubOrg) dan aplikasi GitLab kepada kumpulan (GitlabGroup); untuk GitHub Enterprise atau GitLab yang dihoskan sendiri, tetapkan URL asasnya.

Metrik

Aplikasi Metrik mengumpul metrik prestasi pelayan ke dalam pangkalan data siri masa kecil di dalam Antimatter, supaya anda boleh memuat turunnya atau menyertainya dalam pakej sokongan tanpa menjalankan Prometheus. Apabila ia bermula, ia akan menghidupkan titik akhir metrik pelayan (MetricsSettings.Enable). Lihat Operasi.

Memasang aplikasi lain

Antimatter menjalankan aplikasi Mattermost (plugin). Tiga cara untuk menambah satu:

  • Dari pasaran jauh. Aktifkan Pasaran Jauh (PluginSettings.EnableRemoteMarketplace) dimatikan secara lalai, dan URL Pasaran (PluginSettings.MarketplaceURL) kosong: Antimatter tidak menggunakan pasaran Mattermost, dan mengabaikan alamatnya jika konfigurasi daripada Mattermost masih memilikinya. Untuk menyenaraikan aplikasi pelayan pasaran yang anda percayai, hidupkan tetapan tersebut dan tetapkan URL-nya. Binaan pasaran untuk aplikasi yang dibekalkan oleh Antimatter (Panggilan, Buku Taktik, Kanban dan yang lain) disembunyikan, jadi ia tidak boleh menggantikan milik Antimatter: Benarkan Binaan Pasaran untuk Plagin Antimatter (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) dimatikan secara lalai.
  • Dengan memuat naik bundel (.tar.gz). Muat naik dimatikan secara lalai dan tiada suis Konsol Sistem: tetapkan AM_PLUGINSETTINGS_ENABLEUPLOADS=true, kemudian gunakan Muat Naik Plagin dalam Pengurusan Plagin, atau amctl --local plugin add app.tar.gz.
  • Dari URL: amctl plugin install-url <url>, juga dengan muat naik dihidupkan.

Antimatter menyemak tandatangan aplikasi terhadap kunci yang dipercayai: kunci Antimatter, kunci yang digunakan oleh Mattermost, Inc. untuk menandatangani aplikasi yang diterbitkan (jadi aplikasi Mattermost yang anda muat turun sendiri boleh dipasang) dan mana-mana kunci yang anda tambah dalam PluginSettings.SignaturePublicKeyFiles. Dengan Wajibkan Tandatangan Plugin (PluginSettings.RequirePluginSignature, dimatikan secara lalai) dihidupkan, aplikasi tanpa tandatangan ditolak dan muat naik dilumpuhkan.

Aplikasi berjalan di dalam pelayan dengan akses penuh ke datanya. Hanya pasang aplikasi yang anda percayai.

Beberapa aplikasi yang dibuat untuk edisi berbayar Mattermost menyemak lesen Mattermost sendiri dan enggan berjalan; Antimatter tidak berpura-pura memilikinya untuk mereka.
