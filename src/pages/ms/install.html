Jalankan Antimatter pada pelayan anda sendiri

Satu fail, tiga arahan, kira-kira sepuluh minit: Antimatter bersama pangkalan data, storan fail dan perkhidmatan GIF-nya, pada mana-mana pelayan Linux yang mempunyai Docker.

Sedia digunakan dalam sepuluh minit

Anda memerlukan pelayan Linux dengan Docker dan plugin Compose-nya, 2 teras CPU dan sekurang-kurangnya 4 GB memori.

1. Muat turun fail compose

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Cipta tetapannya, dengan kata laluan rawak

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Tetapkan SITE_URL kepada alamat yang akan digunakan oleh pengguna, contohnya http://192.168.1.20:8065 pada rangkaian setempat.

3. Mulakannya

$ docker compose up -d

Permulaan pertama mengambil masa satu atau dua minit semasa pangkalan data dicipta. Kemudian buka SITE_URL dalam pelayar anda dan cipta akaun anda: akaun pertama akan menjadi pentadbir sistem, dan proses persediaan akan membimbing anda mencipta komuniti pertama anda.

Dengan domain dan HTTPS anda sendiri

Halakan rekod DNS domain anda ke pelayan, buka port 80 dan 443, dan tambahkan domain itu ke dalam .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy mendapatkan sijil daripada Let's Encrypt dan memperbaharuinya secara automatik.

Apa yang dijalankan

  • antimatter: pelayan, bersama aplikasinya (nota, papan putih, saluran suara, panggilan, undian dan lain-lain). Ia tidak menyimpan apa-apa pada cakera: tetapannya berada dalam pangkalan data dan failnya dalam perkhidmatan storan, jadi kontena boleh diganti pada bila-bila masa.
  • postgres: pangkalan data.
  • files: RustFS, storan serasi S3 untuk fail yang dimuat naik.
  • gifs: perkhidmatan GIF dan pelekat Antimatter, dengan pek pelekat permulaan.
  • https: Caddy, hanya dengan profil https.

Pangkalan data, storan dan perkhidmatan GIF berada dalam rangkaian peribadi yang hanya boleh dicapai oleh Antimatter.

Jika pemilih GIF kekal kosong, buka Konsol Sistem › Plugin › GIFs dan tetapkan URL perkhidmatan kepada http://gifs:8080/v2 dan kunci API kepada GIFS_API_KEY dalam fail .env anda.

Naik taraf dan sandaran

# naik taraf ke imej terkini
$ docker compose pull && docker compose up -d
# sandarkan pangkalan data
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Sandarkan juga volum files, atau replikasikan storan dengan mana-mana alat S3. Untuk persediaan dengan nginx dan sijil anda sendiri, lihat fail produksi dalam antimatter-docker.

Dengan arkib keluaran

  1. Sediakan pangkalan data dan pengguna PostgreSQL.
  2. Nyahpek arkib (antimatter-<os>-<arch>.tar.gz), contohnya ke dalam /opt/antimatter, dan halakan SqlSettings.DataSource dalam config/config.json (atau pemboleh ubah persekitaran MM_SQLSETTINGS_DATASOURCE) ke pangkalan data tersebut.
  3. Mulakan pelayan dengan bin/antimatter, sebagai pengguna tanpa keistimewaan, dan buka http://localhost:8065. Akaun pertama yang dicipta akan menjadi pentadbir sistem.

bin/amctl mengurus pelayan yang sedang berjalan daripada baris arahan (bin/amctl --local pada pelayan itu sendiri, dengan ServiceSettings.EnableLocalMode).

Langkah seterusnya

  • Panggilan: buka port panggilan (UDP dan TCP 8443 secara lalai) supaya suara dan video sampai ke pelayan.
  • E-mel: konfigurasikan SMTP untuk jemputan dan pemberitahuan.
  • AI: tambahkan model dalam tetapan Ejen; mana-mana API yang serasi dengan OpenAI boleh digunakan, termasuk pelayan yang anda jalankan sendiri.
  • Pertuturan dan terjemahan: halakan transkripsi panggilan, bacaan dengan kuat dan terjemahan automatik ke model pertuturan-ke-teks, teks-ke-pertuturan dan terjemahan yang anda jalankan sendiri.
