De quoi est composée une installation

Antimatter est un outil de messagerie d'équipe auto-hébergé, une fourche de Mattermost. Une installation complète comprend les éléments suivants. Seuls les trois premiers sont obligatoires.

ÉlémentFonctionObligatoire
Le serveur AntimatterUn programme Go (antimatter) qui sert l'application web, l'API et les websockets sur le port 8065, exécute les applications intégrées (plugins) et transporte les médias des appels sur le port 8443. L'outil en ligne de commande amctl le gère.oui
PostgreSQLLa base de données : messages, utilisateurs, communautés et, dans la configuration recommandée, la configuration du serveur. Version 15 ou plus récente.oui
Stockage de fichiersFichiers, images et applications installées envoyés : un service compatible S3 (le fichier compose exécute RustFS) ou un répertoire local.oui
Un proxy inverseHTTPS devant le serveur : le profil Caddy du fichier compose, ou votre propre nginx.pour la production
Le service GIF (gifs-server)GIFs et stickers pour le sélecteur de GIF, à partir de votre propre catalogue. Il utilise l'API Tenor.non
Un proxy de notifications pushTransmet les notifications à l'application mobile via Apple et Google.pour les notifications mobiles
rtcd, un serveur TURNUn serveur de médias distinct pour de nombreux appels, et un relais pour les personnes situées derrière des pare-feu stricts.non
Points de terminaison IALes modèles derrière la réécriture, les résumés, la traduction, la lecture à voix haute, les agents IA et la transcription des appels, ajoutés en tant que connexions de modèles : un fournisseur cloud ou des serveurs que vous exploitez.non

Antimatter n'a ni licence ni édition payante : l'authentification unique, LDAP, la haute disponibilité, les exports de conformité, la rétention des données et les autres fonctionnalités que Mattermost réserve à ses plans payants sont toutes incluses.

Prérequis

  • Un serveur Linux, amd64 ou arm64, avec 2 cœurs CPU et 4 Go de mémoire ou plus pour quelques centaines de personnes, ainsi que de l'espace disque pour les fichiers envoyés par les utilisateurs.
  • Docker Engine avec le plugin Compose (docker compose), pour l'installation recommandée. Ou, pour les paquets, un serveur compatible Debian, Ubuntu, Fedora ou RHEL avec systemd.
  • Pour la production : un nom de domaine pointant vers le serveur, et les ports 80 et 443 ouverts pour HTTPS.
  • Pour les appels : le port 8443, UDP et TCP, accessible par les personnes qui appellent.
  • Pour l'e-mail : un serveur SMTP par lequel Antimatter peut envoyer des messages.

Démarrage rapide

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)
EOF
docker compose up -d

Ensuite, ouvrez l'URL du site et créez votre compte : le premier compte devient administrateur système. Installation détaille chaque étape ainsi que les autres méthodes d'installation.

Dans ce guide

  • Installation : Docker Compose, les images, le premier administrateur, les paquets .deb et .rpm, l'archive de la version.
  • Configuration : paramètres dans la base de données ou dans un fichier, variables d'environnement AM_, Console système, amctl, journaux.
  • Domaine et HTTPS : URL du site, Caddy, nginx, adresses des clients.
  • Appels et audio : ports, NAT, TURN, rtcd, transcription et sous-titres.
  • E-mail et notifications push : SMTP, proxy push et application mobile.
  • Applications intégrées : quelles applications sont activées, leurs paramètres, installation d'autres applications.
  • IA : connexions de modèles, les fonctionnalités IA intégrées, les agents, la voix et la traduction, la clé de chiffrement, et les données envoyées où.
  • Connexion et comptes : inscription, mots de passe, MFA, connexion unique, LDAP, invités, sessions.
  • Sauvegardes et mises à niveau : sauvegarde, restauration, mise à niveau, migration depuis Mattermost.
  • Exploitation : supervision, mise à l'échelle, rétention des données, conformité, dépannage.
  • Sécurité : liste de contrôle de durcissement et connexions sortantes.
  • Déploiement de l'application de bureau : le MSI, Group Policy et Intune, les profils macOS et le fichier de politique Linux.

Vous gérez une communauté plutôt qu'un serveur (canaux, rôles, modération) ? Consultez Gérer une communauté. Vous développez des intégrations ? Consultez Développer sur Antimatter.

Votre première heure

  1. Installez le serveur et créez immédiatement le compte administrateur.
  2. Placez le serveur derrière HTTPS sur son propre domaine.
  3. Configurez SMTP et envoyez un e-mail de test.
  4. Ouvrez le port des appels. Pour une entreprise, définissez le type de nouvelles communautés sur Entreprise, afin que les appels soient activés dans les canaux.
  5. Décidez qui peut s'inscrire et activez la MFA.
  6. Vérifiez les connexions sortantes dans Sécurité.
  7. Configurez des sauvegardes quotidiennes. Avant d'ajouter des connexions de modèles IA, définissez la clé de chiffrement IA.
