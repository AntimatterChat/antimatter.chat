À propos des agents

Un agent est un assistant IA qui apparaît dans Antimatter sous la forme d'un bot, avec son propre nom. Votre administrateur connecte les agents à un service IA, qui peut être hébergé sur les serveurs de votre organisation ou par un prestataire externe, et décide qui peut utiliser chaque agent et dans quels canaux. Si votre serveur ne dispose d'aucun agent, ou d'aucun agent que vous êtes autorisé à utiliser, les fonctionnalités liées aux agents sur cette page ne s'affichent pas.

Certaines fonctionnalités n'ont pas besoin d'agent : la réécriture de vos messages et les résumés sont intégrés à Antimatter. Ils fonctionnent dès que votre administrateur a choisi un service IA (une connexion à un modèle) pour chacun d'eux.

Les agents peuvent se tromper. Vérifiez ce qu'ils écrivent avant de vous y fier ou de le partager.

Discuter avec un agent

  1. Cliquez sur Agents (l'icône en forme d'étoile) dans la barre d'application située sur le bord droit de la fenêtre. Le panneau Agents s'ouvre.
  2. Si votre serveur a plusieurs agents, choisissez-en un avec le menu des agents dans l'en-tête du panneau (« Choisir un agent »). Votre choix est conservé et utilisé également par les autres fonctionnalités IA.
  3. Saisissez votre question dans « Ask Agents anything... » puis appuyez sur Enter. Vous pouvez également glisser un fichier sur le panneau pour le transmettre à l'agent.

L'agent répond dans le panneau. Pendant qu'il rédige, vous pouvez cliquer sur Arrêter la génération ; une fois terminé, Régénérer demande une autre réponse. Lorsque l'agent a utilisé des outils ou a effectué une recherche sur le web, sa réponse l'indique, par exemple « 3 outils utilisés » ou « Recherche sur le web pour … ».

Chaque question posée depuis le panneau démarre une conversation ; répondez-y pour continuer. Cliquez sur Nouvelle discussion pour en démarrer une autre, et sur Afficher l'historique des discussions pour retrouver vos conversations précédentes. Un petit anneau indique la part de la mémoire de l'agent (sa fenêtre de contexte) utilisée par la conversation.

Le panneau est un message personnel avec l'agent : vous le trouverez également parmi vos messages personnels, et vous pouvez y écrire à l'agent. Chaque nouveau message démarre une nouvelle conversation, répondue dans un fil de discussion.

Poser des questions sur le canal que vous lisez

Lorsque vous ouvrez le panneau Agents pendant que vous lisez un canal, il propose de discuter « À propos de #canal » : cliquez sur Résumer les non-lus, Résumer les 7 derniers jours ou Résumer les 14 derniers jours, ou saisissez une question dans « Demander à propos de … ».

Invites personnalisées

Si vous posez souvent la même question, enregistrez-la en tant que prompt personnalisé via Gérer les prompts, dans le menu IA de la zone de message. Les prompts épinglés apparaissent sous forme de boutons dans le panneau Agents.

Interroger un agent dans un canal

Pour interroger un agent devant tout le monde, mentionnez-le comme une personne : tapez @ suivi du nom de l'agent, puis votre question. L'agent répond dans un fil sous votre message, que tout le monde dans le canal peut lire. Il lit ce fil, et non l'ensemble du canal.

Pour poursuivre la conversation avec l'agent dans un fil, mentionnez-le à nouveau dans votre réponse. Si vous oubliez, Antimatter vous le rappelle, uniquement à vous, avec un lien pour impliquer l'agent.

Un agent ne répond pas si vous n'avez pas l'autorisation de l'utiliser, ou s'il n'est pas autorisé dans ce canal. Certains canaux ont un agent qui répond automatiquement : leurs administrateurs configurent cela dans les paramètres du canal.

Actions IA sur un message

  1. Placez le curseur sur un message et cliquez sur Actions (⋯).
  2. Placez le curseur sur Plus d'actions.
  3. Sous Actions IA, choisissez l'une des options suivantes :
    • Résumer le fil : un résumé du fil dans lequel se trouve le message.
    • Trouver les tâches à faire : les tâches et qui doit les effectuer.
    • Trouver les questions ouvertes : les questions qui attendent encore une réponse.
    • Réagir pour moi : l'agent choisit un emoji approprié et l'ajoute en tant que votre réaction.

La réponse s'affiche dans le panneau Agents, dans votre conversation privée avec l'agent : personne d'autre ne la voit. Les mêmes actions sont disponibles sous Plus d'actions dans le menu Actions sur le fil du panneau du fil de discussion.

Se mettre à jour sur un canal

Lorsque vous ouvrez un canal avec des messages non lus, la ligne « Non-lu » qui marque leur début a un bouton Demander à l'IA. Cliquez dessus, choisissez l'agent sous « Générer avec : », puis sélectionnez Résumer les nouveaux messages, Trouver les tâches à faire ou Trouver les questions ouvertes. La réponse s'affiche dans le panneau Agents, visible uniquement par vous.

Les résumés de canal couvrent au maximum 14 jours.

Réécrire votre message avant de l'envoyer

La réécriture est disponible dès que votre administrateur a choisi un service IA pour cette fonction. Elle n'utilise pas d'agent, il n'y a donc pas d'agent à sélectionner.

  1. Rédigez votre message.
  2. Cliquez sur Afficher la mise en forme (Aa) si la barre de mise en forme est masquée, puis cliquez sur IA à son extrémité gauche.
  3. Sous Réécrire avec l’IA, choisissez Améliorer la rédaction, Corriger l’orthographe et la grammaire, Raccourcir, Rendre plus formel ou Traduire…. Pour une traduction, saisissez la langue, par exemple « Français », puis appuyez sur Enter.

La zone de message affiche « L'IA est en train de réécrire votre message… », puis remplace votre texte par le nouveau, marqué Réécrit par l’IA. Lisez-le, modifiez-le si vous le souhaitez, puis envoyez-le. Cliquez sur Annuler pour récupérer votre texte d'origine. Pour une réponse dans un fil de discussion, l'IA lit également le début du fil et ses dernières réponses, afin que la réécriture s'adapte à la conversation.

Si votre serveur dispose d'agents, le même menu liste également vos invites personnalisées, sous « GÉNÉRER AVEC : », où vous choisissez l'agent qui les exécute.

Résumés

Un résumé est un condensé de plusieurs canaux, préparé pour vous par l'IA : une seule fois, ou selon un horaire, par exemple chaque matin en semaine. Les résumés sont disponibles lorsque votre administrateur a choisi un service IA pour eux. Vous trouvez alors Résumés dans la liste de vos messages personnels. Si le service est supprimé plus tard, vos résumés restent disponibles pour être lus ou supprimés, mais vous ne pouvez pas en créer ou en régénérer d'autres tant qu'un nouveau service n'est pas choisi.

Créer un résumé

  1. Ouvrez Résumés et cliquez sur Ajouter un résumé.
  2. Donnez un nom à votre résumé.
  3. Choisissez Résumer les canaux sélectionnés ou Résumer tous mes messages non-lus.
  4. Activez Exécuter une fois pour obtenir un résumé immédiatement, sans planning.
  5. Pour les canaux sélectionnés, choisissez les canaux à inclure.
  6. Pour un résumé unique, cochez la liste des canaux et cliquez sur Lancer la récapitulation. Pour un résumé planifié, choisissez les jours et l'heure d'exécution, la Période à couvrir (24 dernières heures, 7 derniers jours ou Depuis la dernière lecture), ajoutez des Instructions supplémentaires pour l'IA si vous le souhaitez, puis cliquez sur Créner l’horaire.

La préparation d’un résumé prend un instant. Il apparaît ensuite sous Non-lu, avec une carte pour chaque canal : ses points forts et ses éléments d’action. Depuis le menu d’un résumé, vous pouvez ouvrir un canal, le marquer comme lu, régénérer le résumé ou le supprimer. Vos résumés planifiés se trouvent sous Planifiés, où vous pouvez les mettre en pause. Votre administrateur limite le nombre de résumés que vous pouvez exécuter chaque jour.

Résumés de réunion

Lorsqu’un appel a été transcrit (voir Transcription et sous-titres en direct), le message de la transcription dans le fil de discussion de l’appel peut proposer Créer un résumé de réunion. L’agent rédige le résumé dans votre conversation privée avec lui, et peut proposer de le publier dans le fil de discussion de l’appel pour tout le monde.

Rechercher avec un agent

Si votre administrateur a activé la recherche IA, la zone de recherche dans l’en-tête de la conversation propose une option Agents dans ses suggestions. Choisissez-la, puis posez une question avec vos propres mots : l’agent cherche la réponse dans les messages des canaux dont vous êtes membre, et répond dans le panneau Agents.

Outils et recherche web

Les agents peuvent utiliser des outils connectés par votre administrateur, par exemple pour rechercher des informations dans un autre système ou sur le web. Le menu Outils du panneau liste les fournisseurs d'outils : vous pouvez les activer ou les désactiver individuellement, et Connecter ceux qui nécessitent une connexion.

Certains outils demandent votre approbation avant de s'exécuter : l'agent affiche une carte indiquant ce qu'il souhaite faire, et vous cliquez sur Accepter ou Refuser. Dans un canal, il y a une deuxième étape après l'exécution de l'outil : choisissez Partager pour permettre à l'agent d'utiliser le résultat dans sa réponse, que tous les membres du canal verront, ou Garder privé.

Les agents exécutent les outils avec vos permissions : ils ne peuvent pas accéder à ce à quoi vous n'avez pas accès.

Ce que les agents voient

  • Un agent ne lit que ce que vous pouvez lire vous-même. Les résumés, les récapitulatifs et les recherches vérifient que vous avez le droit de lire chaque canal, et la recherche IA ne couvre que les canaux dont vous êtes membre.
  • Lorsque vous mentionnez un agent dans un fil de discussion, il lit ce fil. Un résumé lit le fil, ou le canal sur la période que vous avez choisie. Une réécriture lit votre brouillon, et dans un fil de discussion, également le début du fil et ses dernières réponses.
  • Avec chaque demande, l'agent reçoit également un certain contexte : le nom du serveur, la personne qui demande, ainsi que le canal et la communauté.
  • Ce que l'agent lit est envoyé au service IA choisi par votre administrateur, et ce qu'une fonction intégrée lit (votre brouillon pour une réécriture, les canaux d'un récapitulatif) au service choisi pour cette fonction. Ce service peut être situé en dehors de votre organisation : demandez à votre administrateur si vous devez savoir où vos données sont envoyées.
  • Vos conversations avec un agent sont stockées sur votre serveur Antimatter, comme les autres messages.
  • Les réponses aux actions IA, aux résumés de canaux et aux recherches sont publiées dans votre conversation privée avec l'agent : seul vous pouvez les voir. Les réponses aux mentions dans un canal sont visibles par tous les membres de ce canal.

Si vous ne voyez pas les agents

Si le panneau Agents indique « Aucun agent pour le moment », votre administrateur n'a pas configuré d'agent utilisable par vous. Si votre serveur permet aux utilisateurs de créer leurs propres agents, le panneau propose Créer un agent, en utilisant un service IA configuré par votre administrateur. Sans agent utilisable, les Actions IA et Demander à l'IA ne s'affichent pas. Le bouton IA de la zone de message s'affiche lorsque la réécriture est configurée, ou lorsque vous disposez d'agents pour vos invites personnalisées.
