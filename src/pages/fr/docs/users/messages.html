Envoyer un message

La zone de message se trouve en bas de chaque canal et conversation. Elle affiche le nom de l’endroit où vous rédigez, par exemple « Message #general ».

  1. Cliquez sur la zone de message, ou appuyez sur Ctrl+Shift+L (⌘+Shift+L sur Mac) pour y accéder.
  2. Saisissez votre message.
  3. Appuyez sur Enter, ou cliquez sur le bouton Envoyer (l’icône avion en papier).

Pour passer à la ligne sans envoyer, appuyez sur Shift+Enter. Si vous préférez utiliser Enter pour passer à la ligne, activez Envoyer avec Ctrl+Entrée dans Paramètres › Messages : vous envoyez alors avec Ctrl+Enter (⌘+Enter sur Mac).

Pendant la saisie, les participants à la conversation voient « … est en train d’écrire… » sous la zone de message. Vous pouvez désactiver cette notification via Ne pas signaler quand j’écris dans Paramètres › Options avancées.

Un message qui n’a pas pu être envoyé reste dans la conversation, grisé et marqué Non envoyé. Cliquez sur Réessayer pour l’envoyer à nouveau, ou sur Supprimer pour le retirer.

Les messages ont une longueur maximale, définie par votre serveur. Lorsque vous approchez de cette limite, un compteur apparaît dans la zone de message. Si un message est trop long, Antimatter vous indique de combien de caractères il dépasse, et ne l’envoie pas.

Mettre en forme votre texte

Antimatter met en forme les messages avec Markdown : quelques caractères autour ou devant votre texte modifient son apparence. Vous n’avez pas besoin de les apprendre : la barre de mise en forme s’en charge pour vous.

Utiliser la barre de mise en forme

  1. Si la barre de mise en forme sous la zone de message est masquée, cliquez sur Afficher la mise en forme (le bouton Aa dans la zone de message).
  2. Sélectionnez du texte, puis cliquez sur un bouton : Gras, Italique, Barré, Titre, Lien, Code en ligne, Bloc de code, Citation, Liste à puces ou Liste numérotée.
  3. Lorsque la fenêtre est étroite, certains boutons se déplacent dans Plus de mise en forme (le bouton ⋯).

Pour vérifier l’apparence d’un message avant de l’envoyer, cliquez sur Afficher l’aperçu du message dans la barre de mise en forme, ou appuyez sur Ctrl+Alt+P (⌘+⌥+P sur Mac). Le bouton ? ouvre les pages d’aide sur la mise en forme, les mentions, les fichiers et les commandes.

Si vous préférez voir le gras, les listes et les liens tels qu’ils apparaîtront pendant la saisie, activez Éditeur de texte enrichi (bêta) dans Paramètres › Messages, si votre serveur le propose.

Des heures que chacun lit dans son fuseau horaire

Quand un message mentionne une heure, par exemple « 15:30 CET » ou « 15 h demain », Antimatter la met en évidence avec une petite horloge. Pointez dessus pour voir cette heure dans votre propre fuseau horaire. Vous pouvez désactiver cette fonction avec Heures dans votre fuseau horaire dans Paramètres › Messages.

Vous pouvez également écrire un moment précis que chaque lecteur voit dans son propre fuseau horaire et format : tapez <t:1700000000>, où le nombre est un horodatage Unix (le nombre de secondes depuis le 1er janvier 1970, UTC). Ajoutez une lettre après un deux-points pour choisir le style : t heure courte, T heure longue, d date courte, D date longue, f date et heure (par défaut), F date et heure avec le jour de la semaine, R temps relatif, par exemple « dans 3 heures ». Par exemple, <t:1700000000:R>.

Mentionner des personnes et des canaux

Une mention notifie quelqu'un, même s'il ne suit pas de près la conversation.

  • Tapez @ suivi du début d'un nom, puis sélectionnez la personne dans la liste à l'aide des touches fléchées et de Tab ou Enter. Elle reçoit une notification.
  • @channel et @all notifient tout le monde dans le canal ; @here notifie ceux qui sont en ligne. Quand un canal a plus de quelques membres, Antimatter vous demande de confirmer d'abord, et indique combien de personnes et de fuseaux horaires vous êtes sur le point de notifier.
  • Tapez ~ et le début du nom d'un canal pour y créer un lien.
  • Votre communauté peut aussi avoir des groupes que vous pouvez mentionner d'un coup, listés avec les personnes quand vous tapez @.

Les mentions que vous ajoutez quand vous modifiez un message ne notifient personne.

Pour mentionner quelqu'un depuis son profil, cliquez avec le bouton droit sur son nom ou sa photo et choisissez Mention.

Emojis et réactions

Ajouter des emojis à un message

  • Cliquez sur Emoji (la tête de smiley dans la zone de message), ou appuyez sur Ctrl+Alt+E (⌘+⌥+E sur Mac). Recherchez, ou parcourez les catégories, et cliquez sur un emoji. Le sélecteur reste ouvert pour que vous puissiez en ajouter plusieurs.
  • Ou tapez : et le début du nom d'un emoji, par exemple :thumb, et sélectionnez-le dans la liste.
  • Choisissez un ton de peau avec le bouton de ton de peau dans le sélecteur. Votre choix est conservé.
  • Par défaut, les émoticônes telles que :) et <3 sont converties en emojis. Vous pouvez désactiver cette option via Convertir les émoticônes en emojis dans Paramètres › Messages.

Le sélecteur a aussi des onglets pour les GIFs et les stickers quand ces applications sont installées : voir GIFs, stickers et mèmes.

Réagir à un message

  1. Pointez vers le message : une barre d'outils apparaît en haut à droite.
  2. Cliquez sur Ajouter une réaction (la smiley) et choisissez un emoji. Le menu sous Plus d'actions (⋯) propose également six réactions rapides.

Les réactions s'affichent sous le message avec un compteur. Cliquez sur une réaction pour ajouter la vôtre, et cliquez à nouveau pour la retirer. Survolez-la pour voir qui a réagi. Pour réagir au dernier message d'une conversation depuis le clavier, appuyez sur Ctrl+Shift+\ (⌘+Shift+\ sur Mac) dans la zone de message.

Si Réactions en un clic est activé dans Paramètres › Messages, l'emoji utilisé précédemment apparaît dans la barre d'outils du message, permettant de réagir en un seul clic.

Ajouter vos propres emojis

Si votre serveur le permet, cliquez sur Ajouter un emoji personnalisé dans le sélecteur d'emojis. Donnez à l'emoji un Nom (lettres minuscules, chiffres, et -, + ou _), choisissez une Image (PNG, GIF, JPEG ou WebP, 1 Mo maximum ; les GIF animés fonctionnent), puis cliquez sur Ajouter l'emoji. Tout le monde sur le serveur pourra alors l'utiliser sous la forme :name:.

Répondre à un message

Il existe deux façons de répondre à un message : une réponse dans la conversation, qui le cite, ou une réponse dans son fil de discussion.

Répondre dans la conversation

  1. Survolez le message et cliquez sur Répondre (la flèche courbée), ou choisissez Répondre dans son menu Plus d'actions.
  2. La zone de message affiche « Réponse à » suivi du message auquel vous répondez. Par défaut, son auteur est notifié. Cliquez sur @ Activé pour passer à @ Désactivé si vous ne souhaitez pas le notifier ; Antimatter mémorise votre choix pour la prochaine fois.
  3. Rédigez votre réponse et envoyez-la. Elle apparaît dans la conversation avec le message cité au-dessus. Cliquez sur la citation pour accéder au message original.

Pour annuler, cliquez sur Annuler la réponse (le ×) ou appuyez sur Esc. Dans une zone de message vide, Shift+Up cite le dernier message, et appuyer à nouveau remonte plus loin ; Shift+Down avance à nouveau.

Votre administrateur peut désactiver ces réponses. Dans ce cas, seuls les fils de discussion sont proposés.

Répondre dans un fil de discussion

Un fil de discussion regroupe une discussion secondaire, sous le message qui l'a initié, sans encombrer le canal.

  1. Survolez le message et cliquez sur Répondre dans le fil, ou choisissez Répondre dans le fil dans son menu Plus d'actions.
  2. Le fil s'ouvre dans le panneau de droite, avec sa propre zone de message, « Répondre au fil ». Rédigez votre réponse et envoyez-la.

Dans le canal, un message avec des réponses indique qui a répondu, le nombre de réponses et la date de la dernière. Cliquez dessus pour ouvrir le fil. Dans le panneau du fil, vous pouvez cliquer sur Ouvrir dans une nouvelle fenêtre pour le lire dans une fenêtre dédiée, ou sur Agrandir le panneau pour l’élargir. Appuyez sur Esc ou cliquez sur Fermer le fil pour le fermer.

Suivre les fils de discussion

Vous suivez automatiquement un fil lorsque vous le créez, y répondez ou y êtes mentionné. Lorsque vous suivez un fil, les nouvelles réponses le marquent comme non-lu. Pour suivre ou arrêter de suivre un fil, sélectionnez Suivre le fil ou Arrêter de suivre le fil dans le menu Plus d'actions du message, ou dans le menu Actions sur le fil du panneau du fil (⋯). Retrouvez tous les fils que vous suivez sous Fils suivis : voir Mentions, messages marqués et épinglés.

Par défaut, les réponses aux fils restent dans leur fil. Si vous préférez voir les réponses également dans le canal, désactivez Garder les réponses dans les fils de discussion dans Paramètres › Messages, si votre serveur propose cette option.

Nommer un fil

Vous pouvez donner un nom à un fil que vous avez créé, ce qui en fait un sous-chat de son canal : tout le monde qui le suit le voit sous le canal dans sa barre latérale.

  1. Ouvrez le menu Plus d'actions du premier message du fil et choisissez Nommer le fil….
  2. Dans Nommer ce fil, saisissez un nom, par exemple « Release 2.1 », puis cliquez sur Enregistrer.

Pour changer le nom plus tard, sélectionnez Renommer le fil… dans le même menu.

Modifier ou supprimer un message

Modifier

  1. Choisir Modifier dans le menu Plus d'actions du message. Pour modifier votre dernier message, vous pouvez également appuyer sur Up dans une zone de message vide.
  2. Modifier le texte sur place. Appuyer sur Enter ou cliquer sur Enregistrer pour enregistrer, Shift+Enter pour une nouvelle ligne, ou Esc pour annuler.

Un message modifié affiche (modifié). Pointez dessus pour voir quand il a été modifié. Sur vos propres messages, cliquez sur (modifié) pour voir les versions précédentes. Votre administrateur peut limiter la durée pendant laquelle un message peut être modifié après sa publication.

Supprimer

  1. Choisir Supprimer dans le menu Plus d'actions du message.
  2. Confirmer avec Supprimer. Le message est supprimé pour tout le monde, ainsi que ses réponses et fichiers s'il a initié un fil de discussion. Cette action est irréversible.

Partager des fichiers et des images

Pour joindre des fichiers à un message, effectuez l'une de ces actions :

  • Cliquez sur Ajouter un fichier et plus encore (le + dans la zone de message) puis sélectionnez Envoyer un fichier.
  • Glissez les fichiers sur la conversation et déposez-les.
  • Collez une image ou un fichier dans la zone de message.

Chaque fichier s'affiche dans la zone de message avec sa progression de téléversement ; cliquez sur son × pour le retirer ou annuler le téléversement. Ajoutez du texte si vous le souhaitez, puis envoyez. Un message peut contenir plusieurs fichiers, jusqu'à une limite ; votre administrateur définit la taille maximale autorisée.

Dans un message, cliquez sur une image pour l’afficher en plus grand. Vous pouvez alors zoomer avec Zoom avant (+) et Zoom arrière (−), passer à l’Image précédente ou à l’Image suivante, la Télécharger ou Copier le lien. Les autres fichiers s’ouvrent dans une aperçu si Antimatter peut les afficher, comme les fichiers PDF, le code, l’audio et la vidéo. Chaque fichier dispose d’un menu avec Télécharger, Copier le lien, Obtenir le lien public (si votre serveur autorise les liens publics) et Ouvrir dans le canal.

Les images s’affichent en taille réelle par défaut. Pour les afficher repliées jusqu’à ce que vous les ouvriez, désactivez Afficher les images dépliées dans Paramètres › Messages, ou tapez /collapse ; /expand les affiche à nouveau.

Liens et aperçus de liens

Quand un message contient un lien vers un site web, Antimatter peut afficher une carte d’aperçu avec le titre, la description et l’image de la page. Si vous avez rédigé le message, vous pouvez cliquer sur Supprimer l’aperçu du lien sur la carte pour le retirer. Pour ne plus voir d’aperçus, désactivez Aperçus des liens de site web dans Paramètres › Messages.

Pour partager un message, choisissez Copier le lien dans son menu et collez le lien n’importe où dans Antimatter. Le lien s’affiche sous forme d’un petit jeton avec le nom du canal ; cliquez dessus pour accéder au message. Seules les personnes pouvant lire ce canal peuvent voir le message.

Transférer un message

  1. Sélectionnez Suivant dans le menu Plus d'actions du message. La boîte de dialogue Transférer le message s’ouvre.
  2. Sélectionnez le canal ou la personne à qui l’envoyer.
  3. Facultatif, écrivez quelque chose dans Ajouter un commentaire (facultatif).
  4. Cliquez sur Suivant.

Un message provenant d’un canal privé ou d’une conversation privée ne peut être transféré qu’à des personnes pouvant déjà le lire ; la boîte de dialogue vous l’indique lorsque c’est le cas.

Brouillons

Antimatter conserve ce que vous écrivez et n’avez pas encore envoyé, pour chaque canal et fil de discussion : vous pouvez partir et revenir pour le terminer. Tous vos messages non envoyés sont répertoriés sous Brouillons, avec un compteur, dans la liste de vos messages personnels (voir la disposition). Depuis là, vous pouvez envoyer, modifier, planifier ou supprimer chaque brouillon.

Avec Synchroniser les brouillons activé dans Paramètres › Messages, vos brouillons sont conservés sur le serveur, ce qui vous permet de les terminer sur un autre appareil.

Planifier un message

Vous pouvez écrire un message maintenant et laisser Antimatter l’envoyer plus tard.

  1. Écrivez le message.
  2. Cliquez sur Planifier un message (l’icône horloge dans la barre de mise en forme, ou dans le menu +).
  3. Sélectionnez Demain à 9 h, Lundi à 9 h, votre Heure personnalisée récente, ou choisissez une date et une heure sous Heure personnalisée puis cliquez sur Planifier.

Une note au-dessus de la zone de message indique alors quand le message sera envoyé. Cliquez sur Tout afficher pour ouvrir la liste de vos messages planifiés, également accessible sous Planifiés dans votre liste de messages personnels. Vous pouvez y envoyer un message immédiatement, le reprogrammer, le modifier ou le supprimer. Si un message planifié ne peut pas être envoyé, par exemple parce que le canal a été archivé, la liste indique la raison.

Quand vous rédigez un message personnel ou de groupe pour quelqu’un pour qui il fait nuit (entre 22 h et 6 h dans sa fuseau horaire), une note indique « Il est 23 h 10 pour … — il/elle peut dormir. » Cliquez sur Envoyer à 7 h, heure du destinataire pour planifier le message pour son matin, ou sur Ignorer pour masquer la note.

Une note similaire vous informe lorsque les personnes à qui vous écrivez ont activé Ne pas déranger ou sont en congé.

Messages importants et urgents

Si votre serveur le permet, vous pouvez marquer un message comme important ou urgent et demander aux personnes de confirmer l'avoir lu. Cela fonctionne pour les nouveaux messages dans un canal ou une conversation, mais pas pour les réponses dans un fil de discussion.

  1. Cliquez sur Priorité du message (l'icône drapeau dans la barre de mise en forme).
  2. Choisissez Standard, Important ou Urgent.
  3. Activez Demander une accusé de réception si les lecteurs doivent confirmer qu’ils l’ont lu.
  4. Pour un message urgent, vous pouvez également activer Notifications persistantes : les personnes notifiées recevront une nouvelle notification toutes les quelques minutes jusqu'à ce qu'elles confirment la lecture.
  5. Cliquez sur Fait, puis envoyez le message.

Le message affiche une étiquette Important ou Urgent. Lorsqu'une confirmation est demandée, un bouton Accuser réception apparaît en dessous, accompagné des photos de ceux qui l'ont déjà fait. Cliquez dessus pour confirmer ; il affiche alors Réception confirmée.

Avertissements de contenu sensible

Un avertissement de contenu sensible masque le texte et les fichiers d'un message jusqu'à ce que chaque lecteur choisisse de les voir. Les notifications n'affichent pas non plus son texte.

  1. Rédigez votre message, avec des fichiers si vous le souhaitez.
  2. Cliquez sur Envoyer en tant que spoiler (l'œil barré dans la barre de mise en forme). Un badge Spoiler s'affiche dans la zone de message ; cliquez sur son × pour annuler.
  3. Envoyez le message.

Les lecteurs voient une couverture rayée. Cliquez dessus pour afficher le message. Pour le masquer à nouveau, cliquez sur Spoiler : afficher ou masquer dans la barre d'outils du message.

Messages autodestructibles

Lorsque votre administrateur l’autorise, vous pouvez envoyer un message qui est supprimé un certain temps après que chaque personne l’a ouvert.

  1. Écrivez le message.
  2. Cliquez sur Suppression après lecture (la flamme dans la barre de mise en forme), activez l'interrupteur, puis cliquez sur Fait. L'interrupteur indique la durée de vie du message une fois ouvert ; votre administrateur définit cette durée.
  3. Envoyez le message.

Les lecteurs voient « Cliquez pour lire — ce message brûle … après que vous l’avez ouvert ». Une fois ouvert, un chronomètre indique le temps restant. En tant qu’expéditeur, vous voyez combien de personnes l’ont lu et vous pouvez le supprimer pour tout le monde d’un coup. Les messages à lecture brûlée ne peuvent pas être répondus dans un fil de discussion ni être transférés.

Épingler un message ou le mettre en avant

Épingler au canal, dans le menu du message, ajoute le message aux messages épinglés du canal, que tous les membres du canal peuvent lister : voir Mentions, messages marqués et épinglés. Les messages épinglés affichent une étiquette Épinglé.

Mettre en tête va plus loin : le message s'affiche dans une bande au-dessus des messages du canal, pour tout le monde, pendant un certain temps.

  1. Dans le menu du message, pointez sur Mettre en tête.
  2. Choisissez la durée : Pour 1 heure, Pour 4 heures, Pour 1 jour, Pour 1 semaine ou jusqu’à suppression.

Plusieurs messages peuvent être en tête à la fois : utilisez Précédent et Suivant dans la bande pour les parcourir, et Aller à pour voir un message dans la conversation. Pour retirer un message de la tête, cliquez sur le × dans la bande, ou choisissez Retirer de la tête sous En tête · Modifier dans son menu.

Marquer des messages et définir des rappels

Choisissez Enregistrer dans le menu d'un message pour le conserver pour plus tard. Les messages marqués affichent une étiquette Marqué, visible uniquement par vous. Trouvez-les sous Messages marqués.

Choisissez Me rappeler pour être rappelé d'un message plus tard, à l'un des moments proposés ou à une Heure personnalisée… (choisissez une date et une heure, puis cliquez sur Fixer le rappel).

Vos Notes personnelles sont une conversation que seul vous pouvez voir, pour les notes, les rappels et les brouillons. Ouvrez-la depuis la liste de vos messages personnels, ou envoyez-y un message avec Enregistrer dans les notes dans son menu.

Canaux traduits

Lorsque les administrateurs d'un canal activent la traduction et que votre serveur prend en charge votre langue, les messages de ce canal s'affichent traduits dans votre langue et l'en-tête du canal indique Traduit. Sous chaque message traduit, vous pouvez cliquer sur Afficher l’original, puis sur Afficher la traduction pour revenir à la version traduite. Pour voir l'ensemble du canal dans ses langues d'origine, désactivez Traduire les messages dans le menu du canal.
