Amihez szükséged van

  • Mehet, a server/go.mod fájlban megadott verzió (írás idején 1.26.7).
  • Node.js és npm, a .nvmrc és a webapp/package.json fájlokban megadott verziókban (Node 24.11.1, npm 11.6.2). A mise segítségével a repozitórium mise.toml fájlja telepíti a megfelelő Node verziót.
  • Docker Compose-kal: a fejlesztői környezet PostgreSQL-t és néhány más szolgáltatást futtat konténerekben.
  • make, git, valamint Linux vagy macOS gépezet.
  • Memória: a webes felületek fordítása a legköltségesebb rész. 16 GB RAM-mal érdemes számolni; lásd: Fordítás és memória.
git clone https://github.com/AntimatterChat/antimatter.git
cd antimatter

A repozitórium a szervert a server/ mappában, a webes felületeket a webapp/ mappában (a Fusion a webapp/fusion-ban, a klasszikus a webapp/channels-ben, a közös csomagok a webapp/platform-ban), valamint a végpont-teszteket az e2e-tests/ mappában tartalmazza.

Fejlesztői szerver futtatása

cd server
make run

A make run parancs elindítja a fejlesztői konténereket (PostgreSQL, Redis, e-mail fogadó és monitorozási eszközök), behelyezi a webes alkalmazás build-jeit, háttérben elindítja a szervert a go run paranccsal, és elindítja a webes alkalmazás figyelőjét, amely újra fordítja a klasszikus felületet, ahogy szerkeszted. Nyisd meg a http://localhost:8065 címet, és hozz létre egy fiókot: az első fiók rendszergazdává válik.

Az ENABLED_DOCKER_SERVICES változóval választhatod ki, mely konténerek induljanak el, a server/config.override.mk fájlban vagy a környezeti változóiddal (lásd: server/config.mk).

A webes felületek

A webapp/ mappában:

npm install      # also builds the shared packages
npm run build    # the classic interface, then Fusion

A build-ek a webapp/channels/dist (klasszikus) és a webapp/fusion/dist (Fusion) könyvtárakba kerülnek. A server/ könyvtárban futtatott make client parancs ezeket server/client és server/client-fusion néven köti össze, ahonnan a szerver szolgálja ki őket: a klasszikus verziót a /static/ alatt, a Fusiont pedig a /static/fusion/ alatt.

  • A npm run run (vagy a webapp/ könyvtárban a make run) figyel és újraépíti a klasszikus felületet. A Fusion újraépítéséhez adjad hozzá a WATCH_FUSION=true környezeti változót.
  • A npm run dev-server (make dev) a webpack fejlesztői szerverét futtatja: a klasszikus felület a 9005-ös, a Fusion a 9006-os porton érhető el.
  • Ha a böngészőben az egyik vagy a másik felületet szeretnéd látni, add hozzá a ?webui=fusion vagy ?webui=classic paramétert bármelyik oldal címéhez.

Kiadási archívumok

cd webapp && npm run build && cd ..
cd server
make build-linux       # the antimatter and amctl binaries
make package-linux     # dist/antimatter-linux-amd64.tar.gz and -arm64

A make build parancs egyben felépíti a webes felületeket és a Linux binárisokat. Az archívum tartalmazza a bin/antimatter, a bin/amctl fájlokat, az alapértelmezett config/config.json konfigurációt, mindkét webes felületet, a sablonokat, a betűtípusokat és a fordításokat. Egyéb platformok: make package-osx, make package-windows, make package-freebsd. Az archívumok nem tartalmazzák a beépített alkalmazásokat; a Docker-képeket viszont igen.

A Docker-kép

Az antimatter-docker repozitórium építi fel a közzétett képeket, a szerverrel és annak alkalmazásaival, teljesen a Dockeren belül:

git clone https://github.com/AntimatterChat/antimatter-docker.git
cd antimatter-docker
scripts/build-all.sh                     # from the main branches on GitHub
SOURCES=local scripts/build-all.sh       # from your checkouts next to this folder
VARIANT=next scripts/build-all.sh        # the "next" image, with every Antimatter app

Ehhez Docker buildx, Python 3, git és gpg szükséges, valamint kb. 16 GB RAM és 30 GB lemezterület. Az eredményt a ghcr.io/antimatterchat/antimatter:dev néven töltjük be; próbáld ki a ANTIMATTER_IMAGE=ghcr.io/antimatterchat/antimatter:dev docker compose -f compose.local.yml up -d paranccsal. A plugins.json fájl felsorolja az alkalmazásokat és a felépített verziókat, a repozitórium README fájlja pedig a változatokat ismerteti.

A build-all.sh script az Antimatter aláírókulccsal aláírja a csomagolt alkalmazásokat, és a képből építés elutasítja az aláíratlan alkalmazásokat. Ha nincs meg a privát kulcs (amelyhez csak a karbantartók férnek hozzá), futtasd külön-külön az első lépéseket: scripts/fetch-sources.sh, scripts/build-plugins.sh (alkalmazáscsomagok a out/plugins/ könyvtárban) és scripts/build-server.sh (szerverarchívumok a out/server/ könyvtárban).

Buildelés és memória

A webes felületek nagy webpack buildjei, és a memória kimerülése a leggyakoribb buildhiba.

  • Az npm run build parancs a klasszikus felületet és a Fusiót egymás után építi, nem párhuzamosan, hogy a csúcsterhelés alacsonyabb maradjon. Ne futtasd párhuzamosan.
  • A minifier minden processzorra egy munkafolyamatot indít. Sokmagos, de kevés memóriájú gépen korlátozd a build által látható processzorok számát: taskset -c 0-5 npm run build.
  • Ha a Node kimeríti a heapet, emeld meg a limitet: NODE_OPTIONS=--max-old-space-size=6144. A Docker build ezt az értéket használja (BUILD_NODE_OPTIONS a build.env fájlban).
  • Kerüld, hogy kis gépen egyszerre fusson a szerver teljes teszt-suite-ja, egy web build és egy Docker build.

Az alkalmazások

Minden alkalmazásnak (pluginnek) van saját repozitórium- és Makefile-ja; a make dist parancs építi a csomagját. Lásd: Buildelés, telepítés és hibakeresés.

Asztali alkalmazás

Az asztali alkalmazás egy Electron app. Node.js 24 vagy újabb verzióval:

npm install --allow-git=all
npm run build          # development build, into dist/
npm start              # run it
npm run package:linux  # packages into release/ (also package:windows, package:mac)

A build idejű beállítások, például a előre konfigurálandó szerverek, a src/common/config/buildConfig.ts fájlban találhatók.

Mobilalkalmazás

Az mobilalkalmazás egy React Native app; a README fájlja felsorolja a parancsokat (npm run ios, npm run android). Saját példányt építenihez saját aláírókulcsok, Android értesítésekhez Firebase projekt, iOS-höz APNs kulcs, valamint egy push proxy is szükséges, amelyben tárolod ezeket a hitelesítő adatokat.
