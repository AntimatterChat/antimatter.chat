Apper som er på som standard, installeres ved hver oppstart hvis de ikke allerede er installert, eller oppgraderes hvis bildet har en nyere versjon. Hvis du slår av en app, forblir den av: standardinnstillingen gjelder bare for apper som konfigurasjonen ikke nevner ennå. Apper som beholder sin Mattermost-id (Agenter, Samtaler, Kanban, Playbooks og integrasjonene) er Antimatters egne bygg.

Aktiver, deaktiver og konfigurer apper

Gå til Systemkonsoll › Plugins › Pluginhåndtering. Under Installerte tillegg har hver app Aktiver eller Deaktiver, Innstillinger og Fjern, og viser sin status (Kjører, Kjører ikke, Feilet ved oppstart…). Hver app med innstillinger har også sin egen side under Systemkonsoll › Plugins.

De medfølgende appene som er av som standard, installeres fra bildets egen kopi: åpne Appmarkedet fra produktmenyen, finn appen og klikk Installer, deretter aktiver den i Pluginhåndtering. Fra kommandolinjen:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Andre kommandoer: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Aktiver apper gjennom konfigurasjonen

Hvilke apper som er på, er innstillingen PluginSettings.PluginStates, en kart over app-ids. Du kan slå sammen poster i den med amctl; med Aktiver automatisk forinstallerte plugins på (standard), installeres en aktivert medfølgende app ved neste oppstart:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Dette er også måten å installere Gjøremål på, som ikke tilbys i dialogen for Appmarkedet. Variabelen AM_PLUGINSETTINGS_PLUGINSTATES fungerer også, men den erstatter hele kartet: list opp alle apper du ønsker på.

Appinnstillinger

App-innstillingene lagres under PluginSettings.Plugins.<app id>, med nøkler i små bokstaver. Du kan endre dem på appens Systemkonsoll-side, eller ved hjelp av amctl config patch som vist i Konfigurasjon. AM_PLUGINSETTINGS_PLUGINS erstatter innstillingene for alle apper samtidig og låser dem alle, så unngå å bruke den.

Tjenesten lagrer alt i datamappen sin (/data, gifs-volumet): en søkeindeks og mediene. De viktigste variablene:

For å legge til egne GIF-er i stor skala, importer dem med en manifest fra en mappe som er montert i en engangskontainer:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

For å re-importere startstickerne etter en oppgradering: docker compose run --rm gifs stickers. Manifestformatet og de andre kommandoene finnes i gifs-server README.

E-post og kalender

E-post og kalender kobler hver person til sin egen postkasse (IMAP og SMTP) og sin egen kalender (CalDAV). Personene oppgir sin server og passord i appen; passordene lagres kryptert. Du konfigurerer ikke epost- eller kalenderserverne for dem, men du bestemmer hva de kan koble til:

Slå det på hvis epost- eller kalenderserveren din er på en privat adresse.
Epost, kalenderTillat ukrypterte tilkoblinger (AllowInsecureConnections)avAv, tilkoblingene må bruke TLS (Epost: TLS eller STARTTLS; Kalender: HTTPS).

E-postStørste meldingsstørrelse (MB) (MaxMessageSizeMB)25 MBStørrelsesgrense for meldinger som sendes og leses.
KalenderSend påminnelser (EnableReminders)påKalender-boten sender en direktemelding før hendelser (10 minutter før, for hendelser som ikke har sin egen alarm).

For å la personer logge inn på Gmail- eller Microsoft 365-postkasser med sin konto i stedet for et passord, opprett en OAuth-klient og fyll inn feltene for Google eller Microsoft i Epost-appen:

  • Google: en Web OAuth-klient med Gmail API og omfanget https://mail.google.com/.
  • Microsoft: en Entra ID-app med delegerte tillatelser IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email og profile. Leietakeren er common som standard.
  • I begge tilfeller er omdirigerings-URI-en https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (din nettside-URL).

Kanban, notater, tavler, avstemninger og playbooks

  • Kanban (focalboard) ligger på /kanban (gamle /boards-lenker omdirigeres dit). Den eneste innstillingen, Enable Publicly-Shared Boards (EnablePublicSharedBoards, av), lar board-redaktører dele et board med alle som har lenken, uten at de må logge seg inn.
  • Notes og Polls har ingen innstillinger.
  • Whiteboard: systemadministratorer kan laste opp formsamlinger (Excalidraw .excalidrawlib-filer, opptil 5 MB hver) for hele serveren på innstillings siden. Community-administratorer håndterer bibliotekene for sin egen community.
  • Playbooks har noen få innstillinger, hovedsakelig eksperimentelle funksjoner; standardinnstillingene passer de fleste servere.
  • Memes: Who can add meme templates (alle som standard, eller administratorer).
  • Todo har ingen serverinnstillinger.

GitHub, GitLab og Jira

Disse appene kobler Antimatter til din kodehosting og issuesporer. Hver av dem krever en OAuth-applikasjon på den andre siden og en webhook som peker tilbake til Antimatter. Aktiver appen, og kjør deretter oppsett-kommandoen i en hvilken som helst kanal, som veileder deg steg for steg: /github setup, /gitlab setup eller /jira setup.

AppOAuth-omdirigerings-URLWebhook-URL
GitHubhttps://chat.example.com/plugins/github/oauth/completehttps://chat.example.com/plugins/github/webhook
GitLabhttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/oauth/completehttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/webhook
Jira/jira instance install server <url> eller /jira instance install cloud-oauth <url>; /jira webhook skriver ut webhook-URLene.
La Use Preregistered OAuth Application stå av i GitHub- og GitLab-appene: den er avhengig av en Mattermost-tjeneste som Antimatter ikke har, og appen nekter å starte hvis den er på. Registrer din egen OAuth-applikasjon.

GitHub- og GitLab-appene genererer sin webhook-nøkkel og krypteringsnøkkel ved første lagring. GitHub-appen kan begrenses til organisasjoner (GithubOrg) og GitLab-appen til en gruppe (GitlabGroup); for GitHub Enterprise eller en selvhostet GitLab, angi dens basis-URL.

Målepunkter

Metrics-appen samler serverens ytelsesmetrikk i en liten tidsseries database inne i Antimatter, slik at du kan laste dem ned eller inkludere dem i en supportpakke uten å kjøre Prometheus. Når den starter, slår den på serverens metrikk-endepunkt (MetricsSettings.Enable). Se Operations.

Installasjon av andre apper

Antimatter kjører Mattermost-apper (plugins). Tre måter å legge til en:

  • Fra et fjernt marked. Aktiver fjernt marked (PluginSettings.EnableRemoteMarketplace) er deaktivert som standard, og Markeds-URL (PluginSettings.MarketplaceURL) er tom: Antimatter bruker ikke Mattermosts marked, og ignorerer adressen hvis en konfigurasjon fra Mattermost fortsatt inneholder den. For å liste appene fra en markedsserver du stoler på, aktiverer du innstillingen og angir URL-en. Bygget av appene som Antimatter leverer (Calls, Playbooks, Kanban og de andre) fra dette markedet er skjult, slik at de ikke kan erstatte Antimatters: Tillat markedsplassversjoner av Antimatter-plugins (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) er deaktivert som standard.
  • Ved å laste opp en pakke (.tar.gz). Opplasting er deaktivert som standard og har ingen bryter i Systemkonsollen: angi AM_PLUGINSETTINGS_ENABLEUPLOADS=true, og bruk deretter Last opp plugin i Plugin Management, eller amctl --local plugin add app.tar.gz.
  • Fra en URL: amctl plugin install-url <url>, også med opplasting aktivert.

Antimatter sjekker app-signaturer mot nøklene det stoler på: Antimatter-nøkkelen, nøkkelen Mattermost, Inc. signerer sine utgitte apper med (slik at en Mattermost-app du laster ned selv kan installeres) og eventuelle nøkler du legger til i PluginSettings.SignaturePublicKeyFiles. Med Krev pluginsignatur (PluginSettings.RequirePluginSignature, deaktivert som standard) aktivert, avslås apper uten signatur, og opplasting deaktiveres.

En app kjører inne i serveren med full tilgang til dataene. Installer bare apper du stoler på.

Noen apper laget for Mattermosts betalte utgaver sjekker etter en Mattermost-lisens på egen hånd og nekter å kjøre; Antimatter gir ikke ut en slik lisens for dem.
