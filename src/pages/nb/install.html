Kjør Antimatter på din egen server

Én fil, tre kommandoer, omtrent ti minutter: Antimatter med database, fillagring og GIF-tjeneste, på en hvilken som helst Linux-server med Docker.

Oppe og går på ti minutter

Du trenger en Linux-server med Docker og Compose-pluginen, minst 2 CPU-kjerner og 4 GB minne.

1. Last ned compose-filen

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Lag innstillingene, med tilfeldige passord

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Sett SITE_URL til adressen folk skal bruke, for eksempel http://192.168.1.20:8065 på et lokalt nettverk.

3. Start den

$ docker compose up -d

Den første oppstarten tar et minutt eller to mens databasen opprettes. Åpne deretter SITE_URL i nettleseren og opprett kontoen din: Den første kontoen blir systemadministrator, og oppsettet leder deg gjennom opprettelsen av ditt første fellesskap.

Med eget domene og HTTPS

Pek en DNS-post for domenet ditt mot serveren, åpne port 80 og 443, og legg til domenet i .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy henter et sertifikat fra Let's Encrypt og fornyer det automatisk.

Dette kjører

  • antimatter: serveren med appene sine (notater, tavler, talekanaler, samtaler, avstemninger og de andre). Den lagrer ingenting på disk: Innstillingene ligger i databasen og filene i lagringstjenesten, så containeren kan byttes ut når som helst.
  • postgres: databasen.
  • files: RustFS, S3-kompatibel lagring for opplastede filer.
  • gifs: GIF- og klistremerketjenesten til Antimatter, med en startpakke med klistremerker.
  • https: Caddy, bare med profilen https.

Databasen, lagringen og GIF-tjenesten ligger på et privat nettverk som bare Antimatter når.

Hvis GIF-velgeren forblir tom, åpner du Systemkonsoll › Plugins › GIFs og setter tjeneste-URL-en til http://gifs:8080/v2 og API-nøkkelen til verdien av GIFS_API_KEY i .env-filen din.

Oppgraderinger og sikkerhetskopier

# oppgrader til de nyeste avbildningene
$ docker compose pull && docker compose up -d
# ta sikkerhetskopi av databasen
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Ta også sikkerhetskopi av volumet files, eller repliker lagringen med et hvilket som helst S3-verktøy. Vil du ha et oppsett med nginx og egne sertifikater, finner du produksjonsfilene i antimatter-docker.

Med et utgivelsesarkiv

  1. Sett opp en PostgreSQL-database og en databasebruker.
  2. Pakk ut arkivet (antimatter-<os>-<arch>.tar.gz), for eksempel til /opt/antimatter, og pek SqlSettings.DataSource i config/config.json (eller miljøvariabelen AM_SQLSETTINGS_DATASOURCE) mot databasen.
  3. Start serveren med bin/antimatter som en bruker uten administratorrettigheter, og åpne http://localhost:8065. Den første kontoen som opprettes, blir systemadministrator.

bin/amctl styrer en kjørende server fra kommandolinjen (bin/amctl --local på selve serveren, med ServiceSettings.EnableLocalMode).

Neste steg

  • Samtaler: Åpne porten for samtaler (UDP og TCP 8443 som standard) slik at lyd og video når fram til serveren.
  • E-post: Konfigurer SMTP for invitasjoner og varsler.
  • KI: Legg til en modell i Agents-innstillingene; et hvilket som helst OpenAI-kompatibelt API fungerer, også en server du kjører selv.
  • Tale og oversettelse: Pek transkripsjon av samtaler, høytlesing og automatisk oversettelse mot tale-til-tekst-, tekst-til-tale- og oversettelsesmodeller du kjører selv.
