O que compõe uma implantação

O Antimatter é um chat de equipe auto-hospedado, um fork do Mattermost. Uma implantação completa tem as seguintes partes. Apenas as três primeiras são obrigatórias.

ParteO que fazObrigatório
O servidor AntimatterUm programa Go (antimatter) que serve o aplicativo web, a API e os websockets na porta 8065, executa os aplicativos integrados (plugins) e transporta a mídia das chamadas na porta 8443. A ferramenta de linha de comando amctl o gerencia.sim
PostgreSQLO banco de dados: mensagens, usuários, comunidades e, na configuração recomendada, a configuração do servidor. Versão 15 ou mais recente.sim
Armazenamento de arquivosArquivos, imagens e aplicativos instalados enviados: um serviço compatível com S3 (o arquivo compose executa RustFS) ou um diretório local.sim
Um proxy reversoHTTPS na frente do servidor: o perfil Caddy do arquivo compose, ou seu próprio nginx.para produção
O serviço de GIF (gifs-server)GIFs e figurinhas para o seletor de GIFs, a partir do seu próprio catálogo. Ele fala a API do Tenor.não
Um proxy de pushEncaminha notificações para o aplicativo móvel através da Apple e do Google.para notificações móveis
rtcd, um servidor TURNUm servidor de mídia separado para muitas chamadas, e um retransmissor para pessoas atrás de firewalls rigorosos.não
Pontos de extremidade de IAOs modelos por trás dos agentes de IA, transcrição de chamadas, leitura em voz alta e tradução: um provedor de nuvem ou servidores que você executa.não

O Antimatter não tem licença nem edição paga: single sign-on, LDAP, alta disponibilidade, exportações de conformidade, retenção de dados e os outros recursos que o Mattermost reserva para seus planos pagos estão todos incluídos.

Requisitos

  • Um servidor Linux, amd64 ou arm64, com 2 núcleos de CPU e 4 GB de memória ou mais para algumas centenas de pessoas, e espaço em disco para os arquivos que as pessoas enviam.
  • Docker Engine com o plugin Compose (docker compose), para a instalação recomendada.
  • Para produção: um nome de domínio apontando para o servidor, e as portas 80 e 443 abertas para HTTPS.
  • Para chamadas: porta 8443, UDP e TCP, acessível pelas pessoas que fazem as chamadas.
  • Para e-mail: um servidor SMTP pelo qual o Antimatter pode enviar.

Início rápido

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Em seguida, abra a URL do site e crie sua conta: a primeira conta se torna o administrador do sistema. Instalação explica cada etapa e as outras formas de instalar.

Neste guia

  • Instalação: Docker Compose, as imagens, o arquivo de liberação, o primeiro administrador.
  • Configuração: configurações no banco de dados ou em um arquivo, variáveis de ambiente AM_, o Console do Sistema, amctl, logs.
  • Domínio e HTTPS: a URL do site, Caddy, nginx, endereços dos clientes.
  • Chamadas e voz: portas, NAT, TURN, rtcd, transcrição e legendas.
  • E-mail e notificações push: SMTP, o proxy de push e o aplicativo móvel.
  • Aplicativos incluídos: quais aplicativos estão ativos, suas configurações, como instalar outros.
  • IA: modelos para agentes, fala e tradução, e para onde os dados são enviados.
  • Login e contas: registro, senhas, MFA, login único, LDAP, convidados, sessões.
  • Backups e atualizações: backup, restauração, atualização, migração do Mattermost.
  • Operações: monitoramento, escalabilidade, retenção de dados, conformidade, solução de problemas.
  • Segurança: lista de verificação de endurecimento e conexões externas.

Sua primeira hora

  1. Instale e crie a conta de administrador imediatamente.
  2. Coloque o servidor atrás de HTTPS em seu próprio domínio.
  3. Configure o SMTP e envie um e-mail de teste.
  4. Abra a porta de chamadas e desative o modo de teste do aplicativo de Chamadas.
  5. Decida quem pode se registrar e ative o MFA.
  6. Revise as conexões externas em Segurança.
  7. Configure backups diários.
