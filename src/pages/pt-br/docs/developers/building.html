O que você precisa

  • Ir, na versão em server/go.mod (1.26.7 no momento da redação).
  • Node.js e npm, nas versões especificadas em .nvmrc e webapp/package.json (Node 24.11.1 com npm 11.6.2). Com o mise, o arquivo mise.toml do repositório instala a versão correta do Node.
  • Docker com Compose: a configuração de desenvolvimento executa o PostgreSQL e alguns outros serviços em contêineres.
  • make, git e uma máquina com Linux ou macOS.
  • Memória: a compilação das interfaces web é a parte mais pesada. Planeje para 16 GB de RAM; consulte Compilações e memória.
git clone https://github.com/AntimatterChat/antimatter.git
cd antimatter

O repositório contém o servidor em server/, as interfaces web em webapp/ (Fusion em webapp/fusion, clássica em webapp/channels, pacotes compartilhados em webapp/platform) e testes de ponta a ponta em e2e-tests/.

Executar um servidor de desenvolvimento

cd server
make run

make run inicia os contêineres de desenvolvimento (PostgreSQL, Redis, um captor de e-mails e ferramentas de monitoramento), vincula as compilações do aplicativo web no lugar, inicia o servidor em segundo plano com go run e inicia o observador do aplicativo web, que recompila a interface clássica conforme você edita. Abra http://localhost:8065 e crie uma conta: a primeira conta se torna o administrador do sistema.

Comando (em server/)O que faz
make run-server, make run-clientIniciar apenas o servidor ou apenas o observador do aplicativo web.
make restart-serverReiniciar o servidor após alterar o código Go.
make stopParar o servidor, o observador e os contêineres.

O banco de dados de desenvolvimento é postgres://mmuser:mostest_password@localhost/mattermost_test, a fonte de dados padrão do servidor. Escolha quais contêineres serão iniciados com ENABLED_DOCKER_SERVICES, em um arquivo server/config.override.mk ou no seu ambiente (veja server/config.mk).

As interfaces web

Em webapp/:

npm install      # also builds the shared packages
npm run build    # the classic interface, then Fusion

Os builds ficam em webapp/channels/dist (clássico) e webapp/fusion/dist (Fusion). O comando make client em server/ os vincula como server/client e server/client-fusion, onde o servidor os serve: o clássico em /static/ e o Fusion em /static/fusion/.

  • npm run run (ou make run em webapp/) monitora e reconstrói a interface clássica. Adicione WATCH_FUSION=true para reconstruir também o Fusion.
  • npm run dev-server (make dev) executa o servidor de desenvolvimento do webpack: o clássico na porta 9005 e o Fusion na porta 9006.
  • Para ver uma interface ou outra no navegador, adicione ?webui=fusion ou ?webui=classic ao endereço de qualquer página.

Arquivos de liberação

cd webapp && npm run build && cd ..
cd server
make build-linux       # the antimatter and amctl binaries
make package-linux     # dist/antimatter-linux-amd64.tar.gz and -arm64

make build compila as interfaces web e os binários para Linux de uma só vez. O arquivo contém bin/antimatter, bin/amctl, um config/config.json padrão, ambas as interfaces web, os modelos, as fontes e as traduções. Outras plataformas: make package-osx, make package-windows, make package-freebsd. Os arquivos não incluem os aplicativos incorporados; a imagem Docker inclui.

A imagem Docker

O repositório antimatter-docker compila as imagens publicadas, o servidor com seus aplicativos, inteiramente dentro do Docker:

git clone https://github.com/AntimatterChat/antimatter-docker.git
cd antimatter-docker
scripts/build-all.sh                     # from the main branches on GitHub
SOURCES=local scripts/build-all.sh       # from your checkouts next to this folder
VARIANT=next scripts/build-all.sh        # the "next" image, with every Antimatter app

É necessário Docker com buildx, Python 3, git e gpg, cerca de 16 GB de RAM e 30 GB de disco. O resultado é carregado como ghcr.io/antimatterchat/antimatter:dev; teste com ANTIMATTER_IMAGE=ghcr.io/antimatterchat/antimatter:dev docker compose -f compose.local.yml up -d. plugins.json lista os aplicativos e as versões compiladas, e o README do repositório explica as variantes.

O build-all.sh assina os aplicativos incluídos com a chave de assinatura do Antimatter, e a construção da imagem rejeita aplicativos não assinados. Sem essa chave privada, que apenas os mantenedores possuem, execute apenas as primeiras etapas: scripts/fetch-sources.sh, scripts/build-plugins.sh (pacotes de aplicativos em out/plugins/) e scripts/build-server.sh (arquivos do servidor em out/server/).

Construção e memória

As interfaces web são grandes compilações webpack, e a falta de memória é a falha de construção mais comum.

  • O npm run build compila a interface clássica e a Fusion uma após a outra, não simultaneamente, para manter o pico de uso mais baixo. Não as execute em paralelo.
  • O minimizador inicia um worker por processador. Em uma máquina com muitos núcleos e pouca memória, limite os processadores que a construção enxerga: taskset -c 0-5 npm run build.
  • Se o Node ficar sem memória de heap, aumente seu limite: NODE_OPTIONS=--max-old-space-size=6144. A construção do Docker usa esse valor (BUILD_NODE_OPTIONS em build.env).
  • Evite executar a suíte de testes completa do servidor, uma compilação web e uma construção do Docker ao mesmo tempo em uma máquina pequena.

Os aplicativos

Cada aplicativo (plugin) tem seu próprio repositório e Makefile; make dist compila seu pacote. Consulte Construir, instalar e depurar.

Aplicativo para desktop

O aplicativo para desktop é um aplicativo Electron. Com Node.js 24 ou posterior:

npm install --allow-git=all
npm run build          # development build, into dist/
npm start              # run it
npm run package:linux  # packages into release/ (also package:windows, package:mac)

As configurações de tempo de compilação, como servidores para pré-configurar, estão em src/common/config/buildConfig.ts.

Aplicativo para celular

O aplicativo para celular é um aplicativo React Native; seu README lista os comandos (npm run ios, npm run android). Para compilar sua própria cópia, você também precisa de suas próprias chaves de assinatura, um projeto Firebase para notificações no Android, uma chave APNs para iOS e um proxy de push que armazene essas credenciais.
