Política de Privacidade

Última atualização: 16 de outubro de 2026.

Esta página aborda dois pontos: o software Antimatter, que as organizações executam em seus próprios servidores, e este site, antimatter.chat.

O software Antimatter

O Antimatter é auto-hospedado. Ao usar um servidor Antimatter, a organização que o opera decide quais dados são mantidos, por quanto tempo e quem pode acessá-los. O projeto Antimatter não tem acesso ao seu servidor, à sua conta ou às suas mensagens. Para perguntas sobre seus dados em um servidor específico, entre em contato com seus administradores; a própria política de privacidade deles se aplica.

O que o software faz por conta própria:

  • Sem telemetria. O servidor não envia estatísticas de uso, diagnósticos ou qualquer outro dado ao projeto Antimatter, à Mattermost, Inc. (cujo software é a base do Antimatter) ou a outras partes terceiras.
  • Conexões externas apenas para recursos que um administrador ativa, para os serviços que eles configuram: por exemplo, um serviço de notificações push, um provedor de GIF, um servidor de e-mail, um provedor de identidade para login único, ou modelos de IA, voz ou tradução.
  • Duas exceções, ativadas por padrão, que os administradores podem desativar. Pré-visualizações de links: quando alguém publica um link, o servidor busca aquela página para exibir seu título e imagem. E chamadas: elas usam o servidor STUN público da Cloudflare (stun.cloudflare.com) para encontrar endereços de rede pública. O servidor consulta esse servidor quando o aplicativo de Chamadas inicia, e o dispositivo de cada pessoa consulta quando ela entra em uma chamada. A Cloudflare vê apenas o endereço IP e a porta do servidor e de cada pessoa que entra, não a própria chamada. Os administradores podem usar seu próprio servidor STUN, ou nenhum; veja Chamadas e voz.
  • Os recursos de IA usam os modelos escolhidos pelo administrador. Quando hospedados por uma terceira parte, o que é enviado a eles (uma mensagem para reescrever, uma conversa para resumir, o áudio de uma chamada transcrita) vai para esse provedor. Os administradores podem usar modelos auto-hospedados para que nada saia de sua rede.

Este site

  • antimatter.chat é um site estático hospedado no GitHub Pages.
  • Ele não define cookies e não usa análises, rastreadores ou publicidade. As fontes e as imagens são fornecidas pelo próprio site, portanto, seu navegador não faz solicitações a outros sites enquanto você o lê.
  • Como qualquer hospedagem web, o GitHub recebe seu endereço IP e as páginas que você solicita, para fornecê-las. Consulte a Declaração de Privacidade do GitHub.
  • Se você abrir uma issue ou contribuir no GitHub, o que você postar lá será público e tratado pelo GitHub de acordo com seus próprios termos.

Contato
