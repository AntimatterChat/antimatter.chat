Política de privacidade

Última atualização: 11 de outubro de 2026. Esta tradução é oferecida por conveniência; em caso de divergência, prevalece a versão em inglês.

Esta página trata de duas coisas: o software Antimatter, que as organizações rodam nos próprios servidores, e este site, antimatter.chat.

O software Antimatter

O Antimatter é auto-hospedado. Quando você usa um servidor Antimatter, é a organização que o administra que decide quais dados são guardados, por quanto tempo e quem pode acessá-los. O projeto Antimatter não tem acesso ao seu servidor, à sua conta nem às suas mensagens. Para dúvidas sobre os seus dados em um servidor específico, entre em contato com os administradores dele; vale a política de privacidade deles.

O que o software faz por conta própria:

  • Nenhuma telemetria. O servidor não envia estatísticas de uso, diagnósticos nem qualquer outro dado ao projeto Antimatter ou a terceiros.
  • Conexões externas apenas para os recursos que um administrador ativar, com os serviços que ele configurar: por exemplo, um serviço de notificações push, pré-visualizações de links de sites publicados em mensagens, um provedor de GIFs, um servidor de e-mail, um provedor de identidade para login único ou modelos de IA, de voz ou de tradução.
  • Os recursos de IA usam os modelos que o administrador escolher. Quando esses modelos são hospedados por terceiros, o que é enviado a eles (uma mensagem a reescrever, uma conversa a resumir, o áudio de uma chamada transcrita) vai para esse provedor. Os administradores podem usar modelos auto-hospedados para que nada saia da rede deles.

Este site

  • antimatter.chat é um site estático hospedado no GitHub Pages.
  • Ele não define nenhum cookie e não usa nenhuma ferramenta de análise, rastreador ou publicidade. As fontes e imagens são servidas pelo próprio site, então o seu navegador não faz nenhuma requisição a outros sites enquanto você o lê.
  • Como qualquer serviço de hospedagem, o GitHub recebe o seu endereço IP e as páginas que você solicita, para poder servi-las. Consulte a Declaração de Privacidade do GitHub.
  • Se você abrir uma issue ou contribuir no GitHub, o que publicar lá é público e tratado pelo GitHub de acordo com os termos dele.

Contato

Para dúvidas sobre esta política, abra uma issue no repositório do site.
