帮助

帮助与支持

Antimatter 是一个社区项目。您可以在这里找到答案，也可以了解如何向我们反馈问题。

使用 Antimatter

  • 在应用中，帮助菜单（应用栏中的 ?）提供用户指南、键盘快捷键，以及消息格式和斜杠命令的帮助。
  • 在 Antimatter 拥有自己的手册之前，Mattermost 文档涵盖了大多数服务器设置和管理任务。
  • 账号、团队和设置方面的问题，可以向您所在服务器的管理员求助。

报告问题

发现了错误，或者有功能不符合预期？请在 GitHub 上提交 issue，注明版本号（可在应用的关于中查看）、您执行的操作、预期的结果以及实际发生的情况：

  • 服务器和 Web 应用：AntimatterChat/antimatter issues
  • 笔记、白板或通话等应用：github.com/AntimatterChat 上对应仓库的 issues
  • 翻译：在服务器仓库中提交 issue，注明语言和相关字符串

请先搜索现有的 issue，并且不要包含任何个人或机密信息。

报告安全漏洞

请不要在公开 issue 中报告安全漏洞。请按照仓库的安全政策私下报告，政策中说明了具体方式。我们会确认收到报告、着手修复，并可根据您的意愿致谢署名。

商业支持

Antimatter 不提供付费支持计划。如果您的组织需要有服务等级保障的支持，请寻找为自托管聊天服务器提供支持的公司。
