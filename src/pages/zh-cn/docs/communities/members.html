邀请人员

打开社区菜单并选择邀请人员。默认情况下，每位成员都可以邀请人员；没有权限的用户不会看到此选项。

  1. 在邀请为下，选择成员或访客。此选项仅在服务器启用访客功能时才会显示。
  2. 在收件人：中，输入已在服务器上拥有账户的人员姓名，或尚未拥有账户的人员的电子邮件地址。
  3. 在添加到频道下，选择被邀请人员将加入的频道。对于成员，此项为可选；对于访客，此项为必填。
  4. 可选地，选择设置自定义消息，在邀请邮件中添加几句欢迎词。
  5. 选择邀请。摘要将显示已邀请的人员以及无法发送的邀请。

通过电子邮件邀请需要服务器能够发送电子邮件，并且已开启电子邮件邀请功能。如果服务器无法发送电子邮件，您仍然可以添加已拥有账户的人员。如果电子邮件地址被拒绝，请咨询系统管理员。

分享邀请链接

在同一个对话框中，选中成员后，点击复制邀请链接即可复制社区的邀请链接。任何打开该链接的人都可以创建账户（如果服务器允许注册）并加入社区。您可以将其分享在新闻通讯、网站或论坛帖子中。

该链接在您更改之前一直有效。如果它出现在不该出现的地方，请在团队设置 › 访问中使用重新生成创建新链接：旧链接随后将停止工作。一个团队同时只有一个邀请链接。

邀请您已认识的人

要将其他社区的人员引入您的社区，右键点击其姓名并选择邀请加入社区，然后选择目标社区。他们会被立即添加。

开放社区

如果团队是公开的（参见谁可以加入），服务器上任何拥有账户的人都可以通过加入其他团队找到并加入该团队，无需邀请。在允许任何人注册的服务器上，这是运行公开团队的最简单方式。如果团队仅允许某些电子邮件域，则拥有其他地址的人无法加入，即使拥有链接也不行。

访客

访客是来自外部的人员，例如客户、承包商或合作伙伴组织。访客只能看到被添加的频道：他们无法浏览或加入社区的其他频道。访客的名称带有 访客 标签，包含访客的频道头部也会显示此信息。

  • 访客账户默认处于关闭状态。系统管理员可在 系统控制台 › 身份验证 › 访客访问 中开启该功能，并可要求访客必须来自特定的电子邮件域或使用双因素认证。
  • 社区管理员可从 邀请人员 中邀请访客，并选择他们可使用的频道。如需稍后为访客添加其他频道，请从该频道将其添加进去。
  • 当系统管理员允许时，允许受邀访客使用魔法链接登录（无需密码） 可让访客通过电子邮件发送的链接登录。
  • 要将访客提升为正式成员，或将成员降级为访客，请联系系统管理员：此操作在 系统控制台 › 用户管理 › 用户 中完成，使用 提升为成员 或 降级为访客。

访客永远不会被自动添加到频道中，即使社区中的每个人都加入了所有频道。

管理成员

打开社区菜单并选择 管理成员（成员看到的是 查看成员）。列表显示所有人及其角色。在人物角色旁边的菜单中，您可以：

  • 使用设置为团队管理员将其设为团队管理员，或使用设置为团队成员撤销该权限；
  • 使用从团队删除将其从团队中移除。

此对话框来自经典界面，因此仍显示“团队”。您还可以在任何看到某人名称的地方对其执行操作：右键单击该名称，或打开其个人资料卡片。有关管理员视图、禁言和移除，请参阅 内容审核。

团队默认没有成员数量限制。如果您的系统管理员设置了限制（每个社区的最大成员数）且邀请开始失败，请要求他们提高该限制。

入职引导

入职引导会在新用户首次打开您的团队时欢迎他们。它会显示欢迎文本和几个问题。每个答案都可以赋予新用户角色和频道，以便人们从第一分钟起就能找到合适的地方。

编写入职引导

  1. 如果答案应赋予角色，请先创建这些角色并为它们开启任何人均可自行获取（参见任何人均可获取的角色）。入职引导只能赋予对所有人开放的角色。
  2. 打开社区菜单，选择 团队设置，然后选择 入职引导…。这将打开社区设置中的 入职引导 选项卡。
  3. 撰写一段欢迎文本：用几行文字介绍社区的主题和主要规则。
  4. 选择添加问题，例如“是什么促使您加入这里？”。如果允许用户选择多个答案，请保持多个答案处于开启状态。
  5. 为每个答案编写文本，然后点击该答案所赋予的角色和公共频道。选择添加答案以添加下一个答案。
  6. 选择保存。

您可以提供的频道是您所在的公共频道。若要移除入门引导，请删除其问题和欢迎文本，然后保存。

新成员看到的内容

某人首次打开社区时，会显示一个欢迎加入对话框，其中包含您的文本和问题。他们选择自己的答案并点击完成，或者选择跳过。无论哪种方式，他们在该社区中都不会再次看到此对话框。在您编写入门引导之前加入的成员，会在下次打开社区时看到它。

成员之后可以从社区菜单下的您的角色…中更改其公开角色。

对于公共社区，请将入门引导与一个锁定的“信息”分类相结合，该分类包含一个规则频道和一个公告频道，并在规则频道顶部添加一个横幅（参见频道设置）。

成员属性

成员属性是关于您社区成员的信息，显示在他们社区的个人资料卡片上，例如他们的公司、站点、分包商或代词。这些属性属于该社区：服务器上的其他社区无法看到它们。

定义属性

打开社区菜单，选择 团队设置，然后选择 成员属性…：这将打开社区设置中的 成员属性 选项卡。选择 添加属性。对于每个属性，请设置：

  • 名称，例如“公司”。
  • 类型：文本、单选、多选、日期、链接、邮箱、电话号码、人员或人员。对于选项，请列出选项。
  • 设置者：每位成员为自己填写，或仅由管理员填写。
  • 可见范围：所有人、管理员或已隐藏。管理员和成员本人始终可见；已隐藏的属性不会显示在个人资料上。
  • 在成员列表中显示：在成员列表中人员名称下方显示该属性，取代其职位，并允许所有人按此属性筛选列表。只能有一个属性以这种方式显示。

使用上移和下移来设置个人资料卡片的显示顺序。一个社区最多可以拥有 50 个属性。删除某个属性时，所有成员对应的值也会被一并删除。

填写它们

要设置某人的属性，请右键点击其姓名并选择编辑属性…。社区管理员可以设置所有人的所有属性；成员可以设置自己的属性，但管理员设置的属性除外。仅对管理员可见的属性会在个人资料卡片上显示一个锁形图标。

在公司环境中，由管理员设置且仅对管理员可见的属性是存放内部细节（例如合同结束日期）的理想位置，这些信息无需让其他同事看到。

服务器本身也拥有自己的属性，这些属性对所有社区都相同，由系统管理员在系统控制台 › 系统属性 › 属性管理中定义。它们显示在您的社区属性之前，且只有系统管理员可以为他人设置这些属性。部分属性可能来自登录提供商，例如公司目录。

当成员离开或被移除时

  • 成员通过团队菜单中的离开团队离开。
  • 离开或被移除的人员将失去其在社区中的角色和团队。他们的消息仍会保留。
  • 被移出社区的人员可以通过新的邀请重新加入，或者如果社区是公共的，也可以重新加入。若要永久禁止某人进入，系统管理员必须停用其账户（参见禁止某人进入）。
