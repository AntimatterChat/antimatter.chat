什么是社区

社区是 Antimatter 服务器上的一个空间，拥有自己的频道、成员、角色和规则。每个社区在“社区栏”（窗口最左侧的列）中都有一个图标。一个服务器可以包含多个社区，一个人也可以属于多个社区。私信不属于任何社区：它们跟随你在服务器上的任何地方。

在系统控制台和一些旧版对话框中，社区仍被称为“团队”。这两个词意思相同。在 Antimatter 中，“团队”指的是社区内部的一组人，拥有标签和负责人（参见社区内的团队）。

两种类型的社区

Antimatter 有两种截然不同的使用方式。本指南涵盖这两种方式，并说明相关建议的差异。每个团队都有一个类型，即社区或工作场所，由管理员在其设置中选择：该类型决定了例如谁可以归档频道（参见团队类型）。

角色与职责

Antimatter 有几个内置角色，每个社区还可以在此基础上添加自己的角色。

  • 系统管理员：管理整个服务器。系统管理员可以在每个社区中执行所有操作，并且是唯一可以使用系统控制台（服务器管理页面）的人。如果你不是系统管理员，某些任务需要他们协助；本指南会说明何时需要。
  • 团队管理员：管理一个团队。团队管理员可以更改团队设置、将其他人设为团队管理员、创建角色，并对除其他管理员外的任何人进行内容管理。其个人资料卡片上会显示团队管理员徽章。创建团队的人将成为该团队的首位管理员。
  • 成员：团队中的其他所有人。默认情况下，成员可以创建频道、邀请人员，并重命名及管理其所加入频道的成员。在工作场所中，他们还可以归档自己创建的频道。
  • 访客：来自外部的人员，仅限于其被邀请加入的频道。只有当系统管理员启用了访客账户时，访客才存在。
  • 频道管理员：在单个频道中拥有额外权限的成员。其个人资料卡片上会显示频道管理员标签。

系统没有内置“版主”角色。版主是一个自定义角色，由您创建，并精确选择其权限：删除消息、暂时禁言、移除用户、管理频道。社区布局预设会为您创建一个“版主”角色。请参阅角色与权限。

创建社区

  1. 在团队栏中，选择+按钮（添加团队），然后选择创建团队。
  2. 输入名称。您可以稍后更改它。
  3. 检查地址：它会根据名称自动填充，并成为社区链接的一部分。之后无法更改。
  4. 保持开启服务器上的任何人都可以加入以创建开放团队，或将其关闭，以便仅通过邀请加入。
  5. 选择创建团队。

您将进入 General，即该团队的首个频道，并且您是其管理员。随后，Antimatter 会建议通过预设来设置团队；参见团队布局。

如果您看不到创建社区，说明系统管理员未授予您创建社区的权限（系统控制台权限中的创建团队）。

要加入一个已存在的团队，请选择+，然后选择加入其他团队：系统将列出您可以加入的团队。

社区菜单

本指南描述的大部分内容都从社区菜单开始。点击频道列表顶部的社区名称，或在侧栏中右键单击社区图标即可打开它。您看到的内容取决于您的权限：

  • 邀请人员、团队设置和管理成员（成员看到的是查看成员）。
  • 团队设置：角色…、入职引导…、团队布局…、成员属性…和模型连接…。每项都会打开团队设置中对应的选项卡。
  • 用户组…、创建频道和创建分类。
  • 个人选项：标记为已读、静音团队、仅显示未读频道、隐藏已静音频道、通知设置以及离开团队。

新社区创建清单

  1. 添加描述和图标，并决定谁可以加入：社区设置。
  2. 决定是否让所有人加入所有频道，并设置分类和频道：频道。
  3. 创建所需的角色，至少包括版主：角色与权限。
  4. 编写入职指南并邀请成员：成员与入职。
  5. 商定管理方式：内容管理。
  6. 添加自定义表情符号、自动链接和集成：应用与集成。
