查找并打开应用

您的管理员决定您的服务器拥有哪些应用，因此您可能无法看到本页列出的所有应用。大多数应用都有图标，位于应用栏中，即窗口右侧边缘、您的头像下方的窄列。将鼠标悬停在图标上可查看应用名称，点击图标可在对话旁边的面板中打开该应用。再次点击可关闭面板。拖动面板边缘可调整宽度；点击恢复默认宽度可将其还原。

应用还会出现在其他位置：

  • 消息框的+菜单（添加文件等），例如创建投票。
  • 表情选择器的选项卡：GIF 图像、贴纸和表情包。
  • 消息的更多操作菜单中的消息操作部分，例如添加到待办事项或运行操作手册。
  • 斜杠命令，例如 /poll 或 /todo：输入 / 即可查看列表。
  • 完整页面：看板和操作手册列在应用栏底部的关于 Antimatter菜单中的产品下。其面板还有一个作为完整页面打开按钮。
  • 某些应用的设置位于您设置中的插件下。

在手机上，应用栏位于右侧的抽屉中：向左滑动，或在对话标题中选择更多 › 成员和应用。

笔记

笔记是多人可同时编辑的文档，位于聊天旁边。您可以看到其他人输入时的光标和姓名，所有内容都会实时保存。

撰写笔记

  1. 点击应用栏中的笔记。
  2. 选择一个选项卡：本频道用于创建频道内所有成员均可阅读和编辑的笔记，或我的用于创建仅您可见的个人笔记。
  3. 点击+（在本频道新建笔记或新建个人笔记）。将打开一个“未命名笔记”。
  4. 输入标题，然后开始编写。格式栏包含加粗、斜体、删除线、标题、列表和待办事项；链接、引用和代码也可以使用。输入 @ 可提及频道中的成员（笔记中的提及不会通知任何人）。
  5. 点击 所有笔记 返回列表。

当频道中的笔记获得标题时，Antimatter 会在频道中发布“共享了笔记”，并附带一个 打开笔记 按钮。

笔记的更多功能

将笔记设为星标，即可在 收藏 选项卡中找到它。笔记的 ⋯ 菜单提供 在频道中共享（发布一张链接到该笔记的卡片）、在 ~channel 中共享（将个人笔记永久变为频道笔记）、版本历史（查看并 恢复此版本）、导出为 Markdown 和 删除。只有笔记的创建者和频道的管理员可以删除频道笔记。

白板

白板是一个可以共同绘制的画布：支持形状、箭头、文本和自由手绘，并实时显示所有人的指针。

  1. 点击应用栏中的 白板。
  2. 与笔记一样，选择 此频道 或 我的，然后点击 +（在此频道中新建看板 或 新建个人看板）。
  3. 使用工具进行绘制：选择和移动 (V)、平移 (H)、矩形 (R)、椭圆 (O)、箭头 (A)、绘制 (P)、文本 (T) 和 橡皮擦 (E)。在工具栏中选择颜色、线条样式和字体，在 库 中选择形状。撤销 (Ctrl+Z) 可撤销上一步操作。

看板操作 菜单包含 全屏、显示整个看板、下载为 .excalidraw、PNG 或 SVG、版本历史、导入 .excalidraw 文件…（这将替换所有人的看板）、在频道中共享，以及 删除。白板保留在你的 Antimatter 服务器上。

看板

看板将工作组织为列中的卡片，例如“待办事项”、“进行中”和“已完成”。看板也可以以表格、画廊或日历的形式显示。

打开频道的看板

点击应用栏中的看板。面板会列出与该频道关联的看板；点击其中一个即可打开。如果尚未关联任何看板，请点击将看板关联到…，然后在看板旁点击关联，或者点击创建看板。频道的成员将成为关联看板的编辑者。

使用看板

  • 要查看所有看板，请将看板作为完整页面打开：在面板中点击 作为完整页面打开，或者点击 关于 Antimatter › 产品 › 看板。
  • 要创建看板，请单击 + 添加看板，然后从模板（如会议议程、项目任务、路线图、冲刺计划等）开始，或选择 创建空白看板。
  • 在列中单击 + 新建 以添加卡片。打开卡片可设置其属性、添加文本、复选框和图片、上传附件以及发表评论。在卡片中提及某人会向其发送通知。
  • 将卡片在不同列之间拖拽。使用 分组依据、筛选、排序 和 搜索卡片 来查找内容，并使用 添加视图 切换为表格、画廊或日历视图。
  • 使用看板的 共享 功能来选择谁可以查看或编辑它。

日历

日历应用会在聊天旁边显示您自己的日历，发送提醒，并允许您在 Antimatter 中会面。它支持与使用 CalDAV 的日历服务器配合使用，例如 Nextcloud、Fastmail 或 Radicale。

连接您的日历

  1. 单击应用栏中的 日历。
  2. 在 连接您的日历 中，填写 CalDAV 服务器 地址（通常只需提供商的域名）、您的 用户名 和 密码。如果您的提供商提供应用密码，请使用该密码。
  3. 选择何时 提醒我没有闹钟的日程，然后单击 连接。

您的密码会以加密形式存储在 Antimatter 服务器上。如需稍后更改这些详细信息或断开连接，请使用面板中的 账户设置。

使用方法

  • 在议程和周之间切换，使用上一页、今天和知道了进行导航，并点击日历的标签以显示或隐藏它。
  • 单击 新建日程，填写 标题、开始时间 和 结束时间，可选填写 重复、提醒、地点 和 描述，然后 保存。单击日程以修改或删除它。
  • 要在 Antimatter 中会面，请将 在 Antimatter 中会面 设置为频道或语音频道，或设置为通话，并选择 频道。时间到达时，日程将显示 开始通话、加入通话 或 加入。
  • 提醒将以日历机器人发送的私信形式到达，如果存在通话，还会附带加入通话的链接。

该应用显示您自己的日历；它不会向其他人发送邀请。

邮件

邮件应用会在聊天旁边显示您的邮箱，因此您可以在不离开 Antimatter 的情况下阅读、回复和分享电子邮件。

连接您的邮箱

  1. 单击应用栏中的 邮件。
  2. 如果管理员已进行配置，请点击使用 Google 登录或使用 Microsoft 登录。否则，或者对于其他提供商，请填写您的邮箱地址和您的姓名，然后填写接收邮件 (IMAP)和发送邮件 (SMTP)服务器，包括其安全设置、端口、用户名和密码。您的提供商的帮助页面会提供这些详细信息。
  3. 点击连接。

使用方法

  • 选择一个文件夹，使用搜索此文件夹进行搜索，并点击邮件进行阅读。来自互联网的图像在您点击显示图像之前是隐藏的。
  • 使用回复、回复所有人或前进进行答复，或使用新消息撰写新邮件。消息为纯文本，您无法附加新文件。
  • 点击共享到频道，可将邮件的发件人、主题和摘录连同评论一起发布到频道中。

投票

投票用于在对话中提出问题，每个人只需点击一次即可投票。结果实时更新。

  1. 点击消息框中的+并选择创建投票，或输入/poll。
  2. 输入问题和至少两个选项；添加选项可添加更多，最多十个。
  3. 如果允许人们选择多个选项，请开启允许多个答案；如果不应让任何人看到谁投了什么票，请开启匿名投票。
  4. 选择时长，从 1 小时到 1 周，或者选择无结束时间。
  5. 点击发布投票。

要投票，请点击一个选项；再次点击可撤回您的投票。投票在持续时间结束时结束，或者当创建者或频道管理员点击结束投票时结束；随后将显示最终结果。

你也可以在一行中编写整个投票：/poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h。输入 /poll help 以列出所有选项。

待办事项

待办事项用于管理待办列表：您自己的列表、频道的共享列表，以及您发送给其他人的任务。

  • 点击应用栏中的待办事项。在此频道选项卡中，向频道的共享列表添加任务，并使用分配给…将其分配给某位成员。将列表设为星标以关注它；您关注的列表会汇总在关注中选项卡中。
  • 我的选项卡包含您自己的任务、在频道中分配给您的任务，以及发送给您或由您发送的任务。使用发送给…选择某人以向他们发送任务：他们可以接受、拒绝或标记为已完成。
  • 要将消息转换为任务，请在其菜单中选择消息操作 › 添加到待办事项。
  • 当任务完成时，点击标记为已完成。

你也可以使用 /todo add …、/todo list 和 /todo send @someone … 来管理个人待办事项。

GIF、贴纸和表情包

点击消息框中的表情符号（笑脸图标）：当这些应用设置好后，选择器会在表情符号旁边显示GIF 图像、贴纸和表情包选项卡。

  • GIF 图像：搜索，或浏览收藏、最近使用过、热门和分类。点击 GIF 即可立即发送。点击其星标可将其添加到您的收藏中。您也可以输入 /gif 和几个关键词。
  • 贴纸：搜索或浏览贴纸包，点击贴纸即可发送。/sticker 命令同样有效。
  • 表情包：选择一个模板，在 制作表情包 中填入文字，查看预览，然后点击 发布表情包。你也可以输入 /meme，或输入 /meme help 查看如何在一行中编写。

根据服务器的设置，你可能能够使用搜索框旁边的 + 添加自己的 GIF、贴纸或表情包模板。

操作手册

操作手册是一份可重复使用的检查清单，适用于每次遵循相同步骤的工作：例如事故处理、版本发布或欢迎新同事。每次使用时，你都会启动一个 运行，其中包含独立的任务、负责人、状态更新，最后还有一个回顾。

  • 点击应用栏中的 操作手册 可查看当前频道的运行记录，通过 运行操作手册 启动一个新的，或快速创建 新检查清单。
  • 要创建或编辑操作手册，请打开完整页面：关于 Antimatter › 产品 › 操作手册。你可以从模板开始，例如产品发布、事故解决或员工入职，或者从空白操作手册开始。
  • 要启动运行，点击操作手册上的 运行，为运行命名并填写摘要，选择为其创建频道或链接到现有频道，然后点击 开始运行。你也可以在消息上选择 消息操作 › 运行操作手册。
  • 在运行期间，勾选完成的任务，分配负责人并设置截止日期，点击 发布更新 告知所有人当前进展。负责人在最后点击 完成。

输入 /playbook 查看命令，例如 /playbook run 或 /playbook update。

GitHub、GitLab 和 Jira

这些应用将 Antimatter 连接到开发者使用的工具。你的管理员必须首先进行设置。然后：

  1. 输入 /github connect、/gitlab connect 或 /jira connect 来连接您的账户，然后按照链接指引在该网站上登录。对于 GitLab，请在网页浏览器中操作，而不是在桌面应用中。
  2. 当有人提及您、请求您审查或分配任务给您时，您会收到私信。
  3. 要让频道关注某个仓库或项目，请使用 /github subscriptions add owner/repo、/gitlab subscriptions add group/project 或 /jira subscribe。
  4. 要从消息中创建或关联问题，请在消息的消息操作中选择创建 GitHub 问题、创建 GitLab 问题、创建 Jira 问题或相应的关联到……选项。

输入 /github help、/gitlab help 或 /jira help 以查看所有相关命令。

移动应用中的功能

移动应用支持创建和参与投票、发送 GIF 和贴纸，以及处理发送给您待办事项。笔记和白板会在应用内的浏览器窗口中打开。看板、日历、邮件和表情包功能尚未在移动应用中提供：请使用网页版或桌面版应用来使用这些功能。
