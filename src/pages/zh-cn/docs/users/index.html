本指南包含的内容

Antimatter 是与团队或社区交流的场所：可以在频道、私密对话、通话中进行交流，也可以使用共享笔记和白板等应用。本指南的页面将逐步讲解如何执行每项操作：

  • 撰写消息：格式设置、提及、表情符号、回复与话题、编辑、草稿、定时发送等。
  • 社区与频道：加入、整理侧栏、私信与群组消息。
  • 通话与语音频道：语音交流、屏幕共享、实时字幕。
  • 应用：笔记、白板、看板、日历、邮件、投票、待办事项等。
  • AI 智能体：摘要、改写和问答（如果您的服务器已启用）。
  • 通知与状态：哪些通知会送达给您，以及何时送达。
  • 个人资料与隐私：您的个人资料、谁可以向您发送消息、屏蔽功能以及账户安全。
  • 搜索与查找：搜索、提及、保存的消息和未读消息。
  • 设置与快捷键：主题、语言和键盘快捷键。

每个 Antimatter 服务器都由其各自的管理员运营，由管理员决定启用哪些功能和应用程序。如果本指南中的某些内容未显示，可能是您的服务器未启用该功能：请咨询您的管理员。

登录

Antimatter 没有统一的中央登录网站：每个组织或社区都运行自己的服务器，拥有独立的地址，例如 chat.example.com。您的管理员或邀请您的人会提供该地址。

  1. 在 Web 浏览器中打开该地址，或将其添加到桌面或移动应用中（参见 桌面和移动应用）。
  2. 在登录您的账号页面，输入您的电子邮件地址或用户名以及密码，然后单击登录。如果您的组织使用自己的登录系统，请单击“或登录”下方的相应按钮。
  3. 如果您已启用多因素身份验证，请输入身份验证器应用中的验证码。

如果您收到了邀请链接，请打开它以创建您的账号：在创建您的账号中填写电子邮件地址、用户名和密码，然后单击创建账号。如果您忘记了密码，请单击忘记密码？并输入您的电子邮件地址：您将收到一个用于设置新密码的链接。

一些社区会通过几个问题来欢迎新成员，回答这些问题将为您分配相应的角色和频道。您可以回答这些问题，或者单击跳过。

窗口

Antimatter 的窗口从左到右分为五列。

  1. 团队栏位于最左侧：每个您所属的团队都有一个圆形图标。圆点表示有未读消息，数字表示提及次数。在图标下方，添加团队（+）允许您加入或创建一个团队。在底部，所有私信（对话气泡图标）显示您的所有私信，包括提及、关注的话题、保存的消息、草稿和给自己的笔记。当未读会话无法在打开的会话中完全显示时，它们的头像会显示在气泡下方，并附带未读计数。最后是搜索所有内容（放大镜图标）。
  2. 侧栏：显示当前团队的名称，点击可打开其菜单，随后是按分类分组的频道。在底部，打开的会话列出您最近的私信，默认最多显示 10 条。未读会话的头像周围有一个红色圆环，并带有灰色的未读计数。
  3. 对话区：显示您打开的频道或对话的消息，底部为消息输入框。其标题栏显示名称（点击可查看频道信息）、简短的标题文本、搜索框，以及用于发起通话、查看提及、保存和固定的消息和文件、以及显示成员列表的按钮。
  4. 右侧面板：显示频道的成员，或者当您打开时，显示话题、搜索结果或应用。按 Esc 可关闭面板。
  5. 应用栏位于最右侧边缘：顶部是您的头像，点击可打开您的状态和设置；中间是应用的图标；底部是关于 Antimatter菜单。

通话时，侧栏底部会出现通话停靠栏，提供静音、屏幕共享和离开按钮：请参阅通话停靠栏。

在小屏幕上

在窄窗口或手机浏览器中，侧栏会变成抽屉。点击左上角的打开导航或向右滑动，即可查看社区和频道。向左滑动可查看成员列表和应用。长按消息即可打开其菜单。

入门步骤

  1. 设置个人资料：添加头像并核对姓名，以便他人能够认出您。请参阅编辑个人资料。
  2. 当浏览器询问时，允许通知，以便您知道何时有人需要您。请参阅通知。
  3. 加入您关心的频道：打开社区菜单（点击社区名称），然后选择浏览频道。请参阅查找并加入频道。
  4. 打个招呼：点击一个频道，在底部的消息框中输入内容，然后按Enter。
  5. 直接给某人发消息：点击其姓名，然后选择私信。

要快速跳转到任意位置，请按Ctrl+K（Mac 上为⌘+K），然后输入频道、人员或消息的几个字母。

获取帮助

点击应用栏底部的 Antimatter 标志以打开关于 Antimatter。在帮助下：

  • 用户指南打开 Antimatter 内置的帮助，涵盖消息发送、格式设置、提及、文件和命令等内容。
  • 键盘快捷键列出所有快捷键。
  • 格式说明解释了如何格式化消息。
  • 报告问题（如果管理员已设置），用于向管理员反馈问题。

在网页浏览器中，同一菜单还提供下载应用，点击可打开下载您的服务器桌面版和移动应用的页面。如果某个应用有独立页面，菜单会在产品下列出它。消息框格式栏中的?按钮也会打开帮助。关于您的账号或服务器的任何问题，请咨询您的管理员。

桌面版和移动版应用

您可以在任何较新的 Web 浏览器中使用 Antimatter。此外，还有适用于电脑和手机的应用。

应用发布在 GitHub 上：桌面版在其发布页面，移动版在其发布页面。关于 Antimatter菜单中的下载应用会跳转到管理员选择的下载页面，默认为发布页面。

桌面版和移动版应用的首个版本 0.9.0 正在准备中。在它们发布之前，请在网页浏览器中使用 Antimatter，包括在手机上的浏览器。

桌面版应用

桌面应用支持 Windows、macOS 和 Linux。它显示与浏览器相同的窗口，并增加了以下功能：无需通过浏览器即可接收通知、图标上的未读徽章、社区栏顶部的返回和前进按钮、通话中独立的屏幕共享选择器，以及在一个应用中连接多个服务器。

要安装该应用，请从发布页面下载适用于您系统的文件：Windows 用户下载 .exe 安装程序；Mac 用户下载 .dmg 磁盘映像；Linux 用户下载 .deb 或 .rpm 软件包，或 .AppImage。该应用目前尚未签名，因此系统首次使用时会发出警告：

  • 在 Windows 上，SmartScreen 会警告发布者未知：请选择更多信息，然后选择仍要运行。
  • 在 macOS 15 及更高版本上，先尝试打开一次应用，然后前往系统设置 › 隐私与安全性，点击 Antimatter 相关消息旁边的仍要打开。在旧版本中，控制点击应用并选择打开。

然后将其连接到您的服务器：

  1. 启动应用。在欢迎界面之后，点击开始使用。
  2. 在连接到您的服务器中，输入管理员提供的服务器 URL，并选择一个您喜欢的服务器显示名称，然后点击连接。
  3. 像在浏览器中一样登录。

要添加另一个服务器，请在窗口顶部的服务器菜单中选择添加服务器，或在应用的设置中的服务器部分操作。应用的设置窗口（在 Windows 和 Linux 上为 Ctrl+,，在 Mac 上为偏好设置…）还可设置是否在登录时启动、文件下载位置、拼写检查器的语言以及通知。

移动应用

移动应用支持 Android 11 或更高版本以及 iOS 18 或更高版本。在 Android 上，从发布页面下载 .apk 文件并打开；您的手机会首先要求您允许从浏览器安装应用。发布页面上的 iPhone 版本未签名，因此无法直接安装：您的组织必须先对其进行签名。请咨询您的管理员如何获取该应用。

  1. 打开应用并点击通过欢迎界面。
  2. 在连接到您的服务器中，在输入服务器 URL中输入服务器地址，选择一个显示名称，然后点击连接。
  3. 使用您的电子邮件或用户名和密码登录，或使用您组织的登录系统。

移动应用拥有独立的设计：底部标签页可访问主页、搜索、提及、已保存消息以及您的账户，您可以在其中设置状态并找到应用设置。它涵盖消息、话题、频道、通话和语音频道、投票、GIF 和贴纸。Web 应用的一些功能尚未包含在内，其中包括通话中的摄像头、编辑笔记和白板、看板、日历和邮件。手机上的推送通知需要您的管理员在服务器上完成设置。
