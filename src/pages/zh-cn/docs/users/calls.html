开始之前

通话是由管理员安装并启用的应用。如果您在对话头部看不到电话按钮，则说明您的服务器上未启用通话，或该频道不支持通话。

首次加入通话时，您的浏览器或桌面应用会请求使用麦克风。请允许使用，否则其他人将无法听到您的声音。如需选择 Antimatter 使用的麦克风、扬声器和摄像头，请参阅选择麦克风、扬声器和摄像头。

发起通话

在频道或对话中

  1. 打开频道、私信或群组消息。
  2. 点击发起通话（对话右上角的电话图标）。

通话开始，您已进入通话。对话中会出现一张卡片，告知其他人通话已开始，并带有加入按钮。您仍停留在对话的消息中：通话显示在侧栏底部的停靠区（参见通话停靠区）。

与单人通话

点击某人的姓名或头像打开其个人资料卡片，然后点击通话。Antimatter 将打开与对方的私信并在那里发起通话。您也可以右键点击某人并选择通话。

呼叫铃声

当您在私信或群组消息中发起通话时，如果管理员已启用铃声，其他人会听到铃声。无论他们在 Antimatter 的哪个位置，其屏幕右上角都会出现一张卡片，显示“正在呼叫您”或“…正在呼叫该群组”。他们可以点击加入、拒绝，或点击静音铃声以停止声音但保留卡片。如果约 30 秒内无人加入，通话将停止，对话中的卡片会显示无人接听、已拒绝或已取消。

如果您正在另一通通话中、状态为请勿打扰或外出、处于已静音的对话中，或呼叫者是您忽略或屏蔽的人，则不会收到呼叫铃声。

要选择铃声或将其关闭，请前往 设置 › 通知，在 桌面端和浏览器 下：打开或关闭 来电铃声，并在 铃声 中选择一种声音。

加入或离开通话

当某个您未加入的频道或对话中有通话正在进行时，您可以通过以下几种方式加入：

  • 点击会话中该通话卡片上的加入。
  • 点击会话标题下方横幅（“…… 开始了一次通话”）中的加入通话。
  • 点击标题栏中绿色的加入按钮，该按钮会显示当前通话中的人数。

在侧栏中，频道名称后的绿色电话图标，或会话上的通话中徽章，表示该处正在进行通话。进行中的通话会话会在通话期间移至您的私信列表顶部。

您一次只能处于一个通话中：加入另一个通话会离开您当前所在的通话。

要离开通话，请点击离开通话（标题栏中的红色电话）、通话坞或通话控件中的断开连接，或按 Ctrl+Shift+L（Mac 上为 ⌘+Shift+L）。

语音频道

语音频道是一个始终开放的通话房间：无需任何人发起通话。人们可以自由进出，社区中的每个人都能在侧栏的频道下方看到谁在里面。语音频道使用扬声器图标而不是 #。

加入语音频道

  1. 点击侧栏中的语音频道。您会立即连接（“已连接到 …”），并保留在您之前阅读的会话中。
  2. 要查看房间内的人员，请再次点击该语音频道，或点击通话坞中的显示语音频道。

在某些服务器上，点击语音频道只会打开房间而不会加入：请点击加入语音以加入。前往另一个语音频道会将您移动过去。

其文字聊天

每个语音频道也有消息，用于在对话期间分享链接和笔记。点击侧栏中频道旁边的打开文字聊天，或其标题栏中的文字聊天，即可在右侧面板中打开它们。您无需处于通话中即可在那里阅读或撰写。

静音

在语音频道中，静音会停止来自通话的所有声音，并同时将您静音。再次点击它，或取消静音，即可再次听到其他人的声音。

创建语音频道

如果您可以创建频道，请在社区菜单中选择创建频道，选择语音频道类型，为其命名，然后创建。参见创建频道。

通话坞

在通话或语音频道中，侧栏底部会显示一个停靠栏，指示语音已连接或通话已连接，并显示通话所在位置。点击该名称即可跳转到对应的会话。停靠栏包含以下按钮：

  • 静音或取消静音您的麦克风。
  • 静音（在语音频道中）。
  • 摄像头，在允许视频的地方。
  • 共享屏幕，或 停止共享。
  • 显示通话（或显示语音频道），在主区域中打开通话。
  • 断开连接，以离开。

当有人共享屏幕时，停靠栏中会出现一个小预览。点击它以查看通话。

显示通话

通话可以在三个位置显示：

  • 在主区域，取代消息：点击会话标题或停靠栏中的显示通话。点击显示消息可返回会话。在这种方式显示的通话中，通话聊天会在旁边打开该通话的话题。
  • 在一个小的浮动窗口中，您可以拖动它：按Ctrl+Shift+P（在 Mac 上按⌘+Shift+P）。点击返回侧栏以关闭它；您仍留在通话中。
  • 在独立窗口中：点击通话控件中的在新窗口中打开。如果您的浏览器阻止弹出窗口，通话将在浮动窗口中打开。关闭窗口会将通话带回 Antimatter。

每个人都有一个图块。点击图块上的固定到舞台，或双击它，以保持该人员的大图显示；点击取消固定以撤销。在摄像头或共享屏幕上，画中画使其在您的其他窗口之上保持可见（如果您的浏览器支持），而全屏将共享屏幕显示在整个屏幕上。

通话期间

通话下方的控件允许您：

按钮功能说明
静音 / 取消静音关闭或打开您的麦克风。快捷键：Ctrl+Shift+Space（在 Mac 上按⌘+Shift+Space）。
静音停止听到通话，在语音频道中。
摄像头打开或关闭您的摄像头，在允许视频的地方。
共享屏幕 / 停止共享共享屏幕、窗口或浏览器标签页。快捷键：Ctrl+Shift+E。
举手 / 放下手请求发言。快捷键：Ctrl+Shift+Y。
表情回应发送一个快速表情回应，在通话上漂浮几秒钟。
显示实时字幕在通话被转录时，以文本形式显示人们说的话。
通话聊天打开通话的话题，适用于在对话中发起的通话。
在新窗口中打开将通话移至独立窗口。
断开连接离开通话。

在 Mac 上，这些快捷键中的 Ctrl 对应 ⌘。您可以在 设置 › 键盘 中更改它们。

视频

当管理员开启视频功能时，摄像头可在两人之间的私信和语音频道中使用。在其他地方，摄像头 按钮会显示“此通话中摄像头已关闭”。点击 摄像头 按钮上的小箭头（摄像头选项）可开启 模糊我的背景 并选择其 强度：轻度、中度 或 重度。

屏幕共享

  1. 点击 共享屏幕。要选择共享的内容和方式，请先点击其上的小箭头（屏幕共享选项）。
  2. 在 共享您的屏幕 中，选择 整个屏幕、一个窗口 或 浏览器标签页（某些浏览器仅提供 选择屏幕或窗口…）。您还可以选择 分辨率（从 480p 到 来源）以及 帧率（15、30 或 60 fps）。Antimatter 会记住您的选择。
  3. 在随后出现的对话框中选择屏幕或窗口。

同一时间只能有一人共享屏幕。在桌面应用中，Antimatter 会显示其自身的选择器 选择要共享的内容，其中包含您的 屏幕 和 窗口；在 Windows 和 Linux 上，您可以勾选 同时共享电脑声音。在 Mac 上，系统会要求您一次允许该应用进行屏幕录制。

举手

点击 举手 表示您希望发言。您的头像上会出现一只手，并显示您在队列中的位置，例如“已举手，第 1 位”。发言结束后，点击 放下手。

更改某人的音量

右键点击某人的头像，或侧栏中语音频道下方的其姓名，然后移动 音量 滑块。Antimatter 会在此浏览器中记住该人的音量设置。

按住说话

如果您希望保持静音，仅在按住某个键时说话，请前往 设置 › 键盘，点击 通话中按住说话（按住） 旁边的 更改，然后按下您想要的按键。在通话期间，按住该键即可说话。当 Antimatter 窗口位于前台时，此功能有效。

静音及其他主持人操作

发起通话的人，以及频道和社区的管理员，可以管理该通话。在语音频道中，社区的主持人也可以。右键点击某人以打开其菜单；在“在 …”下，主持人可以找到：

  • 静音：静音正在说话的人。他们可以自行取消静音。
  • 请求取消静音：请求已静音的人发言。对方会看到“……请求您取消静音”，并显示取消静音和暂不。
  • 在此通话中静音：即使对方离开后返回，也会保持其静音状态，直到您允许其取消静音。允许取消静音 可解除此限制。
  • 放下手和停止屏幕共享。
  • 移出通话，或 从语音频道移除。

如果管理员为您在本次通话中禁用了麦克风，您的麦克风按钮将显示“管理员已为您静音”，待其允许后您可以取消静音。

每个人还可以在该菜单中找到个人资料、消息、通话、复制用户名和音量。

转录与实时字幕

当管理员配置了转录功能后，发起通话的人可以在控制栏中点击转录通话。随后，所有人都会看到一个正在转录的徽章：所有人的发言都会被转换为文本。当主持人点击停止转录或通话结束时，转录内容将作为文本文件发布在通话的话题中（“这是通话转录”），或在语音频道的频道中发布。

在通话转录期间，如果管理员开启了实时字幕，点击显示实时字幕可在通话底部查看最近说出的语句及说话者姓名。点击隐藏实时字幕可将其隐藏。如果配置了智能体，可以根据转录内容生成会议摘要：参见智能体。

选择您的麦克风、扬声器和摄像头

  1. 打开设置（点击右上角的头像，然后选择个人资料与设置）。
  2. 在插件下，选择通话。
  3. 在音频设备中，点击编辑，选择您的麦克风输入和扬声器输出，然后保存。
  4. 当视频可用时，视频设备允许您选择摄像头输入、镜像视频并设置背景模糊。
  5. 屏幕共享设置用于设置是否包含共享内容的声音（随屏幕共享声音）。

在通话期间，摄像头选项中的摄像头和麦克风设置…会打开相同的页面。如果 Antimatter 无法使用您的麦克风，会显示一条消息，例如“请允许访问您的麦克风以便在通话中说话”：请在浏览器或系统设置中允许访问。

移动应用上的通话

移动应用可以发起和加入通话及语音频道，支持静音、取消音频、举手以及显示实时字幕。它不支持摄像头、按住说话或单独调节音量。请参阅桌面和移动应用。
