发送消息

消息框位于每个频道和对话的底部。它会显示您正在向其发送消息的位置名称，例如“Message #general”。

  1. 点击消息框，或按 Ctrl+Shift+L（Mac 上为 ⌘+Shift+L）以跳转到该位置。
  2. 输入您的消息。
  3. 按 Enter，或点击 发送 按钮（纸飞机图标）。

若要换行而不发送，请按 Shift+Enter。如果您更喜欢使用 Enter 换行，请在 设置 › 消息 中开启 使用 Ctrl+Enter 发送：此时您需按 Ctrl+Enter（Mac 上为 ⌘+Enter）发送消息。

当您输入时，对话中的人会在消息框下方看到“… 正在输入…”。您可以在 设置 › 高级 中通过 不发送正在输入通知 来停止发送此通知。

无法发送的消息会保留在对话中，显示为灰色并标记为发送失败。点击重试重新发送，或点击丢弃将其移除。

消息有最大长度限制，由您的服务器设置。当接近该限制时，消息框中会出现计数器。如果消息过长，Antimatter 会告知您超出多少字符，并且不会发送该消息。

格式化您的文本

Antimatter 使用 Markdown 格式化消息：文本周围或前面的几个字符会改变其外观。您无需学习这些语法：格式栏会为您处理。

使用格式栏

  1. 如果消息框下方的格式栏被隐藏，请点击 显示格式（消息框中的 Aa 按钮）。
  2. 选中部分文本，然后点击按钮：粗体、斜体、删除线、标题、链接、行内代码、代码块、引用、项目符号列表或编号列表。
  3. 当窗口较窄时，部分按钮会移至 更多格式（⋯ 按钮）中。

要在发送前查看消息的效果，请点击格式栏中的查看消息效果，或按 Ctrl+Alt+P（Mac 上为 ⌘+⌥+P）。? 按钮可打开关于格式、提及、文件和命令的帮助页面。

如果你希望在输入时就能看到加粗、列表和链接的最终效果，请在服务器支持的情况下，于 设置 › 消息 中开启 富文本编辑器（测试版）。

要以纯文本形式查看消息（不带任何格式），请在 设置 › 消息 中关闭 消息格式。

按各自时区显示的时间

当消息中提到时间（例如“15:30 CET”或“明天下午 3 点”）时，Antimatter 会将其高亮显示，并附带一个小时钟图标。将鼠标悬停在该时间上，即可查看您所在时区的时间。您可以在设置 › 消息中关闭显示您时区的时间。

你还可以写入一个精确的时间点，每位读者都会看到自己时区和格式下的显示结果：输入 <t:1700000000>，其中的数字是 Unix 时间戳（自 1970 年 1 月 1 日 UTC 起经过的秒数）。在冒号后添加一个字母可选择样式：t 短时间、T 长时间、d 短日期、D 长日期、f 日期和时间（默认）、F 带星期的日期和时间、R 相对时间，例如“3 小时后”。例如，<t:1700000000:R>。

提及人员和频道

提及会通知某人，即使他们并未密切关注该对话。

  • 输入 @ 和名称的开头，然后使用方向键和 Tab 或 Enter 从列表中选择该人员。他们会收到通知。
  • @channel 和 @all 会通知频道中的所有人；@here 会通知其中在线的人。当频道成员较多时，Antimatter 会要求你先进行确认，并告知你即将通知的人数和时区。
  • 输入 # 和频道名称的开头，然后选择该频道，即可创建链接：消息中将 #channel-name 显示为链接。~ 也会打开相同的列表。如果 # 后跟一个空格，则开始一个标题；如果 #word 不对应社区中的任何频道，则保持为标签。
  • 你的社区可能还有可以一次性提及的群组，输入 @ 时它们会与人员一起列出。

编辑消息时添加的提及不会通知任何人。

要从个人资料中提及某人，右键单击其姓名或头像，然后选择提及。

表情符号和表情回应

在消息中添加表情符号

  • 点击表情符号（消息框中的笑脸），或按 Ctrl+Alt+E（Mac 上为 ⌘+⌥+E）。搜索或浏览分类，然后点击表情符号。选择器会保持打开状态，以便你可以添加多个。
  • 或者输入 : 和表情符号名称的开头，例如 :thumb，然后从列表中选择。
  • 使用选择器中的肤色按钮选择肤色。你的选择会被保留。
  • 默认情况下，颜文字（如 :) 和 <3）会转换为表情符号。您可以在设置 › 消息中关闭将颜文字转换为表情符号。

当这些应用已安装时，选择器还有 GIF 和贴纸选项卡：请参阅GIF、贴纸和表情包。

对消息进行表情回应

  1. 将鼠标悬停在消息上：其右上角会出现一个工具栏。
  2. 点击添加表情回应（笑脸图标），然后选择一个表情符号。消息操作（⋯）菜单还提供六个快速表情回应。

表情回应会显示在消息下方，并带有计数。点击表情回应即可添加你的回应，再次点击即可移除。将鼠标悬停在表情回应上，即可查看谁做出了回应。若要使用键盘回应会话中的最后一条消息，请在消息框中按 Ctrl+Shift+\（Mac 上为 ⌘+Shift+\）。

在设置 › 消息中开启一键表情回应后，你上次使用的表情符号会显示在消息工具栏中，方便你一键回应。

添加自定义表情符号

如果服务器允许，表情符号选择器搜索框旁边有两个按钮：添加自定义表情符号（+）和自定义表情符号。它们会在选择器内部打开各自的视图；点击返回或按 Esc 可返回到表情符号列表。

  1. 点击添加自定义表情符号。
  2. 拖放、粘贴或选择一张图片：支持 PNG、GIF（动画，最多 70 帧）、JPEG 或 WebP，大小不超过 512 KB，分辨率不超过 1028 × 1028 像素。选择器会以表情回应、消息和选择器中的尺寸显示该图片。
  3. 输入其名称：仅限小写字母、数字以及 -、+ 或 _，最多 64 个字符。输入时，选择器会提示该名称是否可用。
  4. 点击保存。新的表情符号会首先出现在选择器中，位于刚刚添加下方。

之后，服务器上的所有人都可以使用 :name: 来使用它。自定义表情符号 会列出服务器上的所有自定义表情符号，并显示添加者及添加时间；你可以搜索它们，并删除你有权限删除的表情符号。

回复消息

回复消息有两种方式：在会话中回复（会引用该消息），或在话题中回复。

在会话中回复

  1. 将鼠标悬停在消息上，点击回复（弯曲箭头），或者在其消息操作菜单中选择回复。
  2. 消息框会显示“回复”以及您正在回复的消息。默认情况下，会通知该消息的作者。如果您不想通知对方，请点击@ 已开启切换为@ 已关闭；Antimatter 会记住您下次使用的选择。
  3. 输入你的回复并发送。它会显示在会话中，上方是引用的消息。点击引用内容可跳转到原始消息。

要取消，请单击 取消回复（×）或按 Esc。在空消息框中，按 Shift+Up 可引用上一条消息，再次按可继续向前；按 Shift+Down 可向后移动。

你的管理员可以关闭这些回复功能。届时，系统将只提供话题回复选项。

在话题中回复

话题将侧边讨论集中在发起该讨论的消息下方，避免占用频道空间。

  1. 将鼠标悬停在消息上，点击在话题中回复，或者在其消息操作菜单中选择在话题中回复。
  2. 话题会在右侧面板中打开，拥有独立的消息框，显示“回复话题”。输入你的回复并发送即可。

在频道中，带有回复的消息会显示回复者、回复数量以及最后一条回复的时间。点击该消息即可打开话题。在话题面板中，您可以点击在新窗口中打开，在独立窗口中查看，或点击展开面板以加宽面板。按Esc键或点击关闭话题即可关闭面板。

关注话题

当你创建、回复或被提及某个话题时，会自动关注该话题。关注话题后，新的回复会使该话题显示为未读。要关注或取消关注话题，请在消息的消息操作菜单或话题面板的话题操作菜单（⋯）中选择关注话题或取消关注话题。你可以在关注的话题中找到你关注的所有话题：参见提及、保存和固定的消息。

默认情况下，话题回复保留在话题内。如果您希望也在频道中看到回复，请在设置 › 消息中关闭将回复保留在话题中（如果您的服务器提供此选项）。

将话题设为主题

主题是频道内的命名对话：所有关注它的人都能在侧栏的该频道下看到它。你可以将你创建的话题设为主题。

  1. 打开话题第一条消息的消息操作菜单，选择设为主题…。
  2. 输入名称（例如“Release 2.1”），然后单击保存。

如需稍后更改名称，请在同一菜单中选择重命名话题…。将名称留空即可将其恢复为普通话题。

将话题转换为频道

当话题逐渐发展成为一个独立的主题时，话题面板会在其第一条消息下方显示“值得拥有独立空间吗？”的提示，并提供将其设为话题和将其设为频道选项。这两个选项也位于面板的话题操作菜单（⋯）中。单击忽略（×）可隐藏该提示。

  1. 单击将其设为频道。
  2. 检查频道的名称（该名称继承自话题），如果仅希望其成员可见，请开启私有频道。
  3. 保持开启添加话题中的其他人员，以便将曾在该话题中发言的所有人都设为成员。
  4. 单击创建频道。

如果您有权移动该话题（见下文），其消息将连同作者和时间一起移至新频道，并在原话题位置保留指向新频道的链接。否则，回复将保留在原话题中：新频道将以指向原话题的链接开始，而原话题则会获得指向新频道的链接。您需要拥有创建频道的权限。

移动话题

在消息菜单中选择移动话题…，可将整个话题移至同一社区内的其他频道。您可以将自己发起的话题在公共频道之间移动；如果话题中的所有消息均由您发送，则可以将其移至任何位置。频道管理员、社区管理员和版主可以移动社区内的任何话题。每个频道中都会有一行链接指向另一个位置，例如“一个包含 13 条消息的话题已移至 #ops”。已归档频道中的话题、私信和群组消息中的话题，以及非常长的话题无法移动。

编辑或删除消息

编辑

  1. 在消息的 消息操作 菜单中选择 编辑。若要编辑上一条消息，也可以将光标置于空消息框中并按 Up 键。
  2. 就地修改文本。按Enter键或点击保存以保存，按Shift+Enter键换行，或按Esc键取消。

已编辑的消息会显示（已编辑）。将鼠标悬停在该标记上可查看编辑时间。对于您自己的消息，点击（已编辑）可查看之前的版本。管理员可能会限制消息发布后允许编辑的时间长度。

删除

  1. 在消息的 消息操作 菜单中选择 删除。
  2. 点击删除进行确认。该消息将对所有人移除，如果它开启了话题，其回复和文件也会被一并移除。此操作无法撤销。

共享文件和图片

要将文件附加到消息中，请执行以下操作之一：

  • 点击添加文件等（消息框中的 +），然后选择上传文件。
  • 将文件拖放到对话中并释放。
  • 将图片或文件粘贴到消息框中。

每个文件都会显示在消息框中，并带有上传进度；点击其×可移除文件或取消上传。你可以添加一些文本，然后发送。一条消息可以包含多个文件，但有数量限制；你的管理员会设置允许的最大文件大小。

在消息中，点击图片可放大查看。在那里，你可以使用放大 (+)和缩小 (−)进行缩放，切换到上一张图片或下一张图片，下载图片，或复制链接。其他文件在 Antimatter 能够显示时（例如 PDF 文件、代码、音频和视频）会以预览形式打开。每个文件都有一个菜单，包含下载、复制链接、复制公开链接（如果你的服务器允许公开链接）以及在频道打开。

图片默认以完整形式显示。若要将其折叠，直到你打开时才展开，请在 设置 › 消息 中关闭 展开显示图片，或者输入 /collapse；输入 /expand 可再次展开显示。

链接和链接预览

当消息包含指向网站的链接时，Antimatter 可以显示一张预览卡片，包含页面标题、描述和图片。如果该消息是您发送的，您可以点击卡片上的 移除链接预览 将其移除。若要停止查看预览，请在 设置 › 消息 中关闭 链接预览。

要分享一条消息，请在其菜单中选择 复制链接，然后将链接粘贴到 Antimatter 的任何位置。该链接会显示为一个带有频道名称的小标签；点击它即可跳转到该消息。只有能够读取该频道的人才能看到该消息。

转发消息

  1. 在消息的 消息操作 菜单中选择 转发。将打开 转发消息 对话框。
  2. 选择要发送到的频道或人员。
  3. 可选地，在 添加评论（可选） 中填写一些内容。
  4. 点击转发。

来自私有频道或私有对话的消息只能转发给已经能够读取它的人；当这种情况发生时，对话框会提示你。

草稿

Antimatter 会为您在每个频道和话题中保留已输入但尚未发送的内容：您可以离开，甚至关闭或重新加载页面，之后回来继续完成。在侧栏中，如果有草稿等待，铅笔图标会取代频道的 # 符号，或跟随会话名称显示。您所有未发送的消息都会列出在 草稿 下，并带有数量统计，位于您的私信列表中（参见 布局）。您可以从那里发送、编辑、安排或删除每个草稿。

在 设置 › 高级 中开启 同步草稿（默认开启）后，您的草稿将保存在服务器上，以便您可以在其他设备上完成它们。一旦您发送或安排发送消息，草稿就会从服务器上移除。

安排消息

你可以现在撰写一条消息，并让 Antimatter 稍后发送它。

  1. 撰写消息。
  2. 点击 稍后发送，即 发送 按钮旁边的小箭头。
  3. 选择明天 9:00、周一 9:00、你的最近使用的自定义时间，或在自定义时间下选择日期和时间，然后点击计划。

随后，消息框上方会显示一条说明，告知消息将在何时发送。点击查看全部可打开你的已计划消息列表，该列表也位于你的私信列表中的已计划部分。在那里，你可以立即发送消息、重新安排时间、编辑或删除消息。如果无法发送已计划的消息（例如因为频道已被归档），列表会说明原因。

当您向某人发送私信或群组消息，而对方正处于夜间（其时区 22:00 至 06:00 之间）时，会显示一条提示：“对方现在是 23:10 — 他们可能正在睡觉。” 点击 在对方时间 … 发送 可将消息安排在对方工作日开始时发送，或点击 忽略 隐藏该提示。具体时间取决于对方所在国家：例如中欧和北欧为 08:00，许多其他国家为 09:00，而在 Antimatter 不了解常规工作时间的地区则为 08:30。

类似的提示会告知你，你正在与之通信的人已开启 请勿打扰，或处于外出状态。

重要和紧急消息

如果你的服务器允许，你可以将消息标记为重要或紧急，并要求接收者确认已读。此功能适用于频道或对话中的新消息，不适用于话题中的回复。

  1. 单击 消息优先级（格式栏中的旗帜图标）。
  2. 选择 标准、重要 或 紧急。
  3. 如果希望读者确认已读，请开启 请求确认。
  4. 对于紧急消息，你还可以开启 持续通知：被通知的人每隔几分钟会再次收到通知，直到他们确认已读。
  5. 单击 完成，然后发送消息。

消息会显示 重要 或 紧急 标签。如果请求了确认，下方会出现 确认 按钮，并显示已确认者的头像。单击该按钮进行确认；确认后，按钮文字变为 已确认。

剧透

剧透会在每位读者选择查看之前，隐藏消息的文本和文件。通知中也不会显示其文本。

  1. 编写你的消息，如有需要可添加文件。
  2. 单击 作为剧透发送（格式栏中带有斜线的眼睛图标）。消息框中会出现一个 剧透 标签；单击其 × 可撤销。
  3. 发送消息。

读者会看到带条纹的封面。单击它以显示消息。若要再次隐藏，请单击消息工具栏中的 剧透：显示或隐藏。

阅后即焚消息

当管理员允许时，您可以发送一条消息，该消息会在每个人打开后一段时间自动删除。

  1. 撰写消息。
  2. 点击阅后即焚（格式栏中的火焰图标），打开开关，然后点击完成。开关显示消息被打开后的保留时长，该时长由管理员设置。
  3. 发送消息。

读者会看到“点击阅读——此消息在您打开后……将自动删除”。打开后，会显示一个倒计时，指示剩余时间。作为发送者，您可以查看有多少人已阅读，并可以一次性为所有人删除该消息。阅后即焚消息无法在话题中回复或转发。

固定消息或置顶消息

在消息菜单中选择固定至频道，可将该消息添加到频道的已固定消息中，频道内的所有人都可以查看列表：参见提及、保存和固定的消息。已固定的消息会显示已固定标签。

置顶更进一步：消息会显示在频道消息上方的横条中，供所有人暂时查看。在频道中，只有该频道的管理员、社区的管理员和版主可以置顶或取消置顶消息；在私信和群组消息中，对话中的所有人都可以。

  1. 在消息菜单中，将鼠标悬停在置顶上。
  2. 选择持续时间：1 小时、4 小时、1 天、1 周或直到移除。

可以同时置顶多条消息：使用顶部条带中的上一页和知道了来浏览它们，并使用跳转在对话中查看某条消息。要取消置顶，点击条带中的×，或在其菜单中的置顶 · 更改下选择取消置顶。

保存消息并设置提醒

在消息菜单中选择保存，以便稍后查看。保存的消息会显示已保存标签，仅您自己可见。您可以在保存的消息中找到它们。

选择提醒我，以便稍后在建议的时间或自定义时间…（选择日期和时间，然后点击设置提醒）收到该消息的提醒。

您的给自己的笔记是一个只有您能看到的对话，用于记录笔记、提醒和草稿。您可以从私信列表打开它，或者通过消息菜单中的保存到笔记将消息发送至此。

已翻译的频道

当频道管理员开启翻译功能，且您的服务器支持您的语言时，该频道的消息将以您的语言显示，频道标题栏会显示 已翻译。在每条已翻译的消息下方，您可以点击 显示原文，然后点击 显示译文 来回切换。若要查看整个频道的原始语言内容，请在频道菜单中关闭 翻译消息。

斜杠命令

以 / 开头的消息是命令。输入 / 可查看命令列表，每个命令都附有简短说明；应用也会添加自己的命令。输入命令时，建议会将其及其每个参数显示为块，并为当前正在输入的参数提供帮助。一些你可能会用到的命令：

命令功能说明
/away, /online, /offline, /dnd设置您的状态。
/msg @name message发送私信。
/groupmsg @name1, @name2 message发送群组消息。
/join #channel, /leave加入或离开频道。
/mute静音或取消静音当前频道。
/header text, /purpose text设置频道的标题或用途。
/me text发布一个动作，以斜体显示。
/shrug text在您的消息中添加 ¯\_(ツ)_/¯。
/tableflip text, /unflip text将 (╯°□°)╯︵ ┻━┻ 或 ┬─┬ノ( º _ ºノ) 添加到你的消息中。
/code text将文本作为代码块发布。
/search words搜索消息。
/expand, /collapse展开或折叠显示图片。
/settings, /shortcuts打开设置，或查看键盘快捷键列表。
/logout退出登录。
