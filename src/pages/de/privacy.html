Datenschutzerklärung

Zuletzt aktualisiert: 16. Oktober 2026.

Diese Seite behandelt zwei Aspekte: die Antimatter-Software, die Organisationen auf eigenen Servern betreiben, und diese Website, antimatter.chat.

Die Antimatter-Software

Antimatter wird selbst gehostet. Wenn Sie einen Antimatter-Server verwenden, entscheidet die Organisation, die ihn betreibt, welche Daten gespeichert werden, wie lange und wer darauf Zugriff hat. Das Antimatter-Projekt hat keinen Zugriff auf Ihren Server, Ihr Konto oder Ihre Nachrichten. Für Fragen zu Ihren Daten auf einem bestimmten Server wenden Sie sich an dessen Administratoren; deren eigene Datenschutzerklärung gilt.

Was die Software von sich aus tut:

  • Keine Telemetrie. Der Server sendet keine Nutzungsstatistiken, Diagnosen oder andere Daten an das Antimatter-Projekt, an Mattermost, Inc. (auf dessen Software Antimatter basiert) oder an andere Dritte.
  • Außerverbindungen nur für Funktionen, die ein Administrator aktiviert, zu den Diensten, die sie konfiguriert: zum Beispiel einem Push-Benachrichtigungsdienst, einem GIF-Anbieter, einem E-Mail-Server, einem Identitätsanbieter für Single Sign-On oder KI-, Sprach- oder Übersetzungsmodellen.
  • Zwei Ausnahmen, die standardmäßig aktiviert sind und von Administratoren deaktiviert werden können. Link-Vorschauen: Wenn jemand einen Link postet, ruft der Server diese Seite ab, um deren Titel und Bild anzuzeigen. Und Anrufe: Sie verwenden den öffentlichen STUN-Server von Cloudflare (stun.cloudflare.com), um öffentliche Netzwerkadressen zu ermitteln. Der Server fragt diesen ab, wenn die Anruf-App startet, und das Gerät jeder Person fragt ihn ab, wenn sie einem Anruf beitreitet. Cloudflare sieht nur die IP-Adresse und den Port des Servers und der beitretenden Personen, nicht den Anruf selbst. Administratoren können stattdessen einen eigenen STUN-Server verwenden oder keinen; siehe Anrufe und Sprache.
  • KI-Funktionen verwenden die Modelle, die der Administrator auswählt. Wenn diese von einem Dritten gehostet werden, wird das, was an sie gesendet wird (eine Nachricht zum Umschreiben, ein Gespräch zum Zusammenfassen, die Audioaufnahme eines transkribierten Anrufs), an diesen Anbieter gesendet. Administratoren können selbst gehostete Modelle verwenden, damit nichts das Netzwerk verlässt.

Diese Website

  • antimatter.chat ist eine statische Website, die auf GitHub Pages gehostet wird.
  • Es werden keine Cookies gesetzt und es werden keine Analysen, Tracker oder Werbung verwendet. Die Schriftarten und Bilder werden von der Website selbst bereitgestellt, sodass Ihr Browser beim Lesen keine Anfragen an andere Websites sendet.
  • Wie jeder Webhost empfängt GitHub Ihre IP-Adresse und die von Ihnen angeforderten Seiten, um sie bereitzustellen. Siehe die GitHub-Datenschutzerklärung.
  • Wenn Sie ein Issue auf GitHub eröffnen oder dort mitwirken, ist das, was Sie dort veröffentlichen, öffentlich und wird von GitHub gemäß seinen eigenen Bedingungen verarbeitet.
