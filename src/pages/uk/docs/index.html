Документація Antimatter

Чотири посібники, кожен написаний для тих, хто в них потребує. Оберіть той, що відповідає вашим завданням.

{{icon:chat}}Використання Antimatter

Для всіх, хто спілкується: повідомлення та обговорення, канали та спільноти, дзвінки та голосові канали, додатки, сповіщення та конфіденційність.

{{icon:server}}Адміністрування сервера

Для системних адміністраторів: встановлення Antimatter, налаштування, HTTPS, дзвінки, електронна пошта та push-сповіщення, моделі ШІ, вхід, резервні копії та оновлення.

{{icon:users}}Адміністрування спільноти

Для адміністраторів і модераторів спільноти, на роботі чи в публічному просторі: налаштування, канали, ролі та дозволи, учасники, модерація та додатки.

{{icon:code}}Розробка на базі Antimatter

Для розробників: REST API, вебхуки та команди зі скісною рискою, боти, написання додатків, збирання Antimatter із джерела та внески.

Не можете знайти потрібне? Запитайте в обговореннях спільноти або перегляньте Довідку та підтримку.
