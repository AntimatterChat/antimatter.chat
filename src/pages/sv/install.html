Kom igång

Kör Antimatter på din egen server

En fil, tre kommandon, ungefär tio minuter: Antimatter med databas, fillagring och GIF-tjänst, på valfri Linuxserver med Docker.

Igång på tio minuter

Du behöver en Linuxserver med Docker och dess Compose-plugin, 2 processorkärnor och minst 4 GB minne.

1. Ladda ner compose-filen

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Skapa inställningarna, med slumpmässiga lösenord

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Sätt SITE_URL till den adress som användarna ska nå servern på, till exempel http://192.168.1.20:8065 i ett lokalt nätverk.

3. Starta

$ docker compose up -d

Den första starten tar en minut eller två medan databasen skapas. Öppna sedan SITE_URL i webbläsaren och skapa ditt konto: det första kontot blir systemadministratör, och installationen guidar dig när du skapar din första community.

Med egen domän och HTTPS

Peka en DNS-post för din domän mot servern, öppna portarna 80 och 443 och lägg till domänen i .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy hämtar ett certifikat från Let's Encrypt och förnyar det automatiskt.

Det här körs

  • antimatter: servern med sina appar (anteckningar, whiteboards, röstkanaler, samtal, omröstningar och de övriga). Den sparar ingenting på disk: inställningarna ligger i databasen och filerna i lagringstjänsten, så containern kan bytas ut när som helst.
  • postgres: databasen.
  • files: RustFS, S3-kompatibel lagring för uppladdade filer.
  • gifs: Antimatters tjänst för GIF-bilder och klistermärken, med ett startpaket med klistermärken.
  • https: Caddy, bara med profilen https.

Databasen, lagringen och GIF-tjänsten ligger i ett privat nätverk som bara Antimatter når.

Om GIF-väljaren förblir tom öppnar du Systemkonsol › Plugins › GIFs och sätter tjänstens URL till http://gifs:8080/v2 och API-nyckeln till värdet av GIFS_API_KEY i din .env.

Uppgraderingar och säkerhetskopior

# uppgradera till de senaste avbildningarna
$ docker compose pull && docker compose up -d
# säkerhetskopiera databasen
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Säkerhetskopiera även volymen files, eller replikera lagringen med valfritt S3-verktyg. För en installation med nginx och egna certifikat, se produktionsfilerna i antimatter-docker.

Med ett releasearkiv

  1. Skapa en PostgreSQL-databas och en databasanvändare.
  2. Packa upp arkivet (antimatter-<os>-<arch>.tar.gz), till exempel i /opt/antimatter, och peka SqlSettings.DataSource i config/config.json (eller miljövariabeln AM_SQLSETTINGS_DATASOURCE) mot databasen.
  3. Starta servern med bin/antimatter som en användare utan administratörsrättigheter, och öppna http://localhost:8065. Det första kontot som skapas blir systemadministratör.

bin/amctl hanterar en körande server från kommandoraden (bin/amctl --local på själva servern, med ServiceSettings.EnableLocalMode).

Nästa steg

  • Samtal: öppna samtalsporten (UDP och TCP 8443 som standard) så att ljud och video når servern.
  • E-post: konfigurera SMTP för inbjudningar och aviseringar.
  • AI: lägg till en modell i agentinställningarna; alla OpenAI-kompatibla API:er fungerar, även en server som du kör själv.
  • Tal och översättning: koppla transkribering av samtal, uppläsning och automatisk översättning till tal-till-text-, text-till-tal- och översättningsmodeller som du kör själv.
