Checklista efter installation

  1. Skapa det första administratörskontot innan någon annan kan nå servern (Installation).
  2. Servera Antimatter enbart över HTTPS och ställ in webbplatsens URL till https://-adressen (Domän och HTTPS).
  3. Se till att .env, config.json och TLS-nycklar endast kan läsas av root (eller serverns användare): chmod 600 .env.
  4. Avgör vem som kan skapa konton, håll Aktivera Open Server avstängd om inte communityn är offentlig, och aktivera Kräv e-postverifiering när e-posten fungerar (Inloggning och konton).
  5. Aktivera multifaktorautentisering och gör den obligatorisk åtminstone för administratörskonton, eller använd din identitetsleverantörs.
  6. Granska de externa anslutningarna nedan, särskilt STUN-servern som Samtal använder som standard.
  7. Gör en säkerhetskopia och testar en återställning (Säkerhetskopior och uppgraderingar).
  8. Håll bilderna uppdaterade: säkerhetskorrigeringar kommer med nya bilder.

Bakom en proxy fungerar begränsningar baserade på adress endast om servern känner till varje klients adress (ServiceSettings.TrustedProxyIPHeader och ServiceSettings.TrustedProxyIPs, se Klientadresser bakom en proxy). Annars verkar alla förfrågningar komma från proxyn, och alla delar samma begränsning. Detsamma gäller för IP-filter och för adresserna i revisionsloggarna.

Inloggningsförsök begränsas separat: Maximalt antal inloggningsförsök (10) låser ett konto efter så många felaktiga lösenord.

IP-filter

Systemkonsol › Site-konfiguration › IP-filtrering begränsar åtkomst till servern via IP-adress, med tillåt- och neka-regler (en adress eller ett CIDR-intervall vardera). Med Aktivera IP-filtrering på kan personer vars adress matchar en neka-regel, eller ingen tillåt-regel när det finns tillåt-regler, inte nå servern. Sidan vägrar regler som skulle blockera din egen adress. Bakom en proxy, konfigurera klientadresser först (Klientadresser bakom en proxy): annars verkar varje förfrågan komma från proxyn.

Ignoring, blocking and message requests

Med Aktivera ignorera, blockera och meddelandeförfrågningar på (standardinställningen) kan personer ignorera och blockera varandra, och kan välja att ta emot direktmeddelanden från personer de inte känner som meddelandeförfrågningar, som inte avisera dem förrän de accepteras. Detta passar offentliga communityer. På en arbetsplats där kollegor alltid måste kunna nå varandra, stäng av det (AM_PRIVACYSETTINGS_ENABLEUSERBLOCKING=false): inget av detta är längre tillämpat, men listorna och valen som personer gjorde bevaras, och tillämpas igen om du aktiverar det på nytt.

Sessions and tokens

  • Session lengths and idle timeout: see Sign-in and accounts. Shorter sessions mean a lost laptop or phone stays signed in for less time.
  • Aktivera Personliga Access-tokens (ServiceSettings.EnableUserAccessTokens, av) låter användare skapa API-tokens; Maximal giltighetstid för personliga åtkomsttoken (dagar) sätter en övre gräns för dem. Båda finns i Systemkonsol › Integrationer › Hantera integrationer.
  • För att logga ut alla användare samtidigt, till exempel efter ett misstänkt intrång: Återkalla alla sessioner i Systemkonsol › Hantera användare › Användare.

Connections to outside services

Antimatter contacts no service run by Mattermost, Inc. It sends no telemetry, crash reports or security update checks, and fetches no product notices. A configuration brought over from Mattermost that still names one of Mattermost's services (its push services, its app marketplace, its notices or its STUN server for calls) doesn't make the server contact them: those addresses are ignored.

The server and the apps connect to other outside services only for the features that need them, and to the services you configure:

Som standard vägrar servern att ansluta till privata och loopback-adresser för dessa (förhandsgranskning av länkar, webhooks, appar), så att ett meddelande eller en integration inte kan användas för att nå ditt interna nätverk. Ange de interna värdar den får nå i Tillåt osäkra interna anslutningar till (ServiceSettings.AllowedUntrustedInternalConnections, i Systemkonsol › Miljö › Utvecklare); webbställens compose-fil listar gifs där.

Rapportera en sårbarhet

Rapportera säkerhetsproblem privat, enligt beskrivningen i Antimatters säkerhetspolicy, inte i offentliga ärenden.
