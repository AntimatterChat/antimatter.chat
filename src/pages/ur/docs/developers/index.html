Antimatter کو وسیع کرنے کے طریقے

جو کام کرے اس کے لیے ہلکا پھلکا ترین ٹول منتخب کریں۔ پہلے چار کے لیے سرور تک رسائی کی ضرورت نہیں ہے؛ ایپس اس کے اندر چلتی ہیں۔

ٹولیہ کیا کرتا ہےکس کے لیے موزوں ہے
REST APIایپس جو کچھ بھی کرتی ہیں: پیغامات، چینلز، لوگ، فائلیں، ترتیبات۔ ایک WebSocket واقعات کے ہوتے ہی انہیں بھیجتا ہے۔اسکرپٹس، دوسرے نظاموں کے ساتھ ہم آہنگی، کسٹم کلائنٹس۔
Incoming webhooksایک خفیہ URL جو کسی چینل میں پیغام پوسٹ کرتا ہے جب کوئی اسے JSON بھیجتا ہے۔الارمز، CI نتائج، مانیٹرنگ، دوسرے ٹولز سے اطلاعات۔
Outgoing webhooksجب عوامی چینل میں کوئی پیغام ٹریگر ورڈ سے شروع ہو تو Antimatter آپ کے URL کو کال کرتا ہے اور آپ کا جواب پوسٹ کرتا ہے۔سادہ چیٹ پر مبنی خودکار عملیات۔
Slash commandsلوگ /something ٹائپ کرتے ہیں؛ Antimatter آپ کے URL کو کال کرتا ہے اور آپ کا جواب انہیں یا چینل کو دکھاتا ہے۔تلاشیں، چیٹ سے شروع کیے جانے والے اقدامات۔
Botsپروگرامز کے لیے بنائے گئے اکاؤنٹس، جن کے اپنے ٹوکنز، بوٹ ٹیگ، اور انٹرایکٹو پیغامات اور ڈائیلاگز ہیں۔اسسٹنٹس، نٹیفائرز، یا کوئی بھی چیز جو لوگوں کے ساتھ بات چیت کرتی ہے۔
Apps (plugins)کوڈ جو سرور (Go) اور ویب ایپ (React) کے اندر چلتا ہے: ہر پیغام پر ہکس، نئے مینو، پینلز، پیغامات کی اقسام، صفحات۔خصوصیات: پولز، نوٹس، کیلنڈرز، ایسے انضمام جو صارف انٹرفیس کی ضرورت رکھتے ہیں۔

انٹرفیس میں، لوگ پلگ انز کو "ایپس" کہتے ہیں۔ یہ رہنما جہاں دونوں الفاظ مددگار ہوں وہاں "ایپس (پلگ انز)" لکھتا ہے، کیونکہ کوڈ، API اور کنفیگریشن ابھی بھی "پلگ ان" کہتے ہیں۔

Mattermost کے ساتھ ہم آہنگی

Antimatter، Mattermost کا فورک ہے۔ Mattermost سرور کے ساتھ جو کچھ کام کرتا ہے، وہ Antimatter کے ساتھ بھی کام کرتا ہے۔

کیا ایک جیسا ہے

  • REST API جو /api/v4 کے تحت ہے، اس کی تصدیق، اس کا WebSocket اور اس کی غلطی کی شکل۔ سرور ورژن 12.0.0 رپورٹ کرتا ہے، اس لیے کلائنٹس اور ایپس جو سرور کے ورژن کی جانچ کرتی ہیں، انہیں ایک حالیہ Mattermost نظر آتا ہے۔
  • ویب ہکس اور سلاش کمانڈز، بشمول ان کے Slack-سازگار payloads۔
  • سرور پلگ ان API اور hooks: Antimatter نے ان میں کوئی تبدیلی نہیں کی ہے۔ سرور کوڈ اسی Go module کے خلاف بنایا جاتا ہے، github.com/mattermost/mattermost/server/public۔
  • ویب ایپ پلگ ان رجسٹری: Mattermost کی رجسٹری کے ہر register… طریقہ Antimatter کے دونوں ویب انٹرفیسز میں موجود ہے۔
  • کلائنٹ لائبریریز: Go کلائنٹ model.Client4 اور TypeScript کلائنٹ @mattermost/client (دیکھیں کلائنٹ لائبریریز)۔
  • پلگ ان باندل: ایک .tar.gz جس میں plugin.json manifest شامل ہے۔ Mattermost کے کلید سے دستخط شدہ پلگ انسٹال ہوتے ہیں، اور Antimatter کے کلید سے دستخط شدہ بھی۔

کیا مختلف ہے

  • دو ویب انٹرفیسز۔ نیا انٹرفیس، Fusion، ڈیفالٹ ہے؛ کلاسیکی Mattermost انٹرفیس ابھی بھی دستیاب ہے۔ Fusion زیادہ تر پلگ اجزاء کو رینڈر کرتا ہے، لیکن کچھ کو مختلف جگہ رکھتا ہے اور کچھ کو باہر چھوڑ دیتا ہے۔ ایپ بتا سکتی ہے کہ کون سا انٹرفیس چل رہا ہے۔ دیکھیں Fusion انٹرفیس کی سپورٹ۔
  • اضافی API۔ Antimatter اپنے اپنے فیچرز کے لیے endpoints شامل کرتا ہے: community attributes، timeouts، messages on top، message requests، channel اور category overrides، channel export، اور communities پر نئے fields۔ دیکھیں Antimatter API میں کیا شامل کرتا ہے۔
  • اضافی پیغام فیچرز۔ پیغامات کے attachments pipeline stages اور ایک چھوٹا سا chart دکھا سکتے ہیں؛ posts inline replies یا spoilers ہو سکتے ہیں۔
  • ایپس کے لیے اضافی ویب ایپ hooks: composer "+" menu item، emoji picker tabs، channel view میں ایک panel، sidebar channels کے نیچے ایک footer، اور integrations pages پر ایک entry۔ دیکھیں صرف Antimatter کے پاس موجود hooks۔
  • کوئی لائسنس نہیں۔ ہر فیچر لائسنس کلید کے بغیر دستیاب ہے۔ لائسنس، trial اور enterprise upgrade endpoints غائب ہیں؛ GET /api/v4/license/client ان کلائنٹس کے لیے باقی ہے جو پوچھتے ہیں۔ Mattermost کے ادائیگی والے ایڈیشنز کے لیے بنائے گئے کچھ ایپس خود لائسنس کی جانچ کرتے ہیں اور چلنے سے انکار کر دیتے ہیں۔
  • نام۔ انٹرفیس میں ٹیمز کو communities کہا جاتا ہے، لیکن API اور کوڈ ابھی بھی team کہتے ہیں۔ Environment variables AM_ prefix استعمال کرتے ہیں، command-line tool amctl ہے اور سرور binary antimatter ہے۔

کوڈ کہاں موجود ہے

ہر چیز اوپن سورس ہے، GitHub پر AntimatterChat تنظیم میں۔ ہر ریپوزٹری اپنے main برانچ پر کام کرتی ہے۔

ریپوزٹریاس میں کیا ہے
antimatterسرور (Go، server/ میں)، دونوں ویب انٹرفیس (webapp/fusion اور webapp/channels)، TypeScript کلائنٹ اور amctl۔
antimatter-dockerDocker امیجز، جن میں شامل ایپس اور compose فائلیں ہیں۔
antimatter-plugin-*ہر شامل ایپ کے لیے ایک ریپوزٹری: polls، todo، notes، whiteboard، calendar، mail، gifs، memes، voice-channels، calls، boards (Kanban)، playbooks، agents اور metrics۔
gifs-serverGIFs ایپ کے استعمال ہونے والا خود میزبان GIF اور اسٹیکر سروس۔
desktop-app، mobile-app، push-proxyڈیسک ٹاپ اور موبائل ایپس، اور وہ سروس جو فونز کو پش اطلاعات بھیجتی ہے۔
antimatter.chatیہ ویب سائٹ اور اس کی دستاویزات۔
communityAntimatter کے ہر حصے کے لیے مسائل اور گفتگو۔

شروع کرنے سے پہلے

  • ٹیسٹ سرور حاصل کریں۔ سب سے تیز طریقہ Docker image ہے: Antimatter کی تنصیب دیکھیں۔ Antimatter پر کام کرنے کے لیے، سورس سے بلڈنگ دیکھیں۔
  • چیک کریں کہ سرور کون سی چیزیں اجازت دیتا ہے۔ کئی انٹیگریشن فیچرز پہلے سے بند ہوتے ہیں اور ان کے لیے سسٹم ایڈمن کی ضرورت ہوتی ہے: پراسنل ایکسس ٹوکنز، بوٹ اکاؤنٹس، یوزرنیم اور آئیکن اوور رائڈز، اور ایپس اپ لوڈ کرنا۔ ہر صفحہ بتاتا ہے کہ اس کے لیے کون سی ترتیب ضروری ہے۔
  • اپنے سائٹ کے URL کو جانیں۔ مثالوں میں https://chat.example.com استعمال ہوا ہے۔ اسے اپنے سرور کے پتے سے تبدیل کریں۔

اس گائیڈ میں

  • REST API: تصدیق، بنیادی وسائل، پیجینیشن، غلطیاں، ریٹ لمٹس، WebSocket، کلائنٹ لائبریریز، اور Antimatter کے اضافے۔
  • ویب ہکس: داخلہ اور خارجہ ویب ہکس، پے لوڈز، منسلک فائلیں اور کارڈز۔
  • سلاش کمانڈز: کسٹم کمانڈز، ان کی درخواست اور جواب، اور آٹو کمپلیٹ۔
  • بوٹس اور انٹرایکٹو پیغامات: بوٹ اکاؤنٹس، بٹن، مینوز اور ڈائیلاگز۔
  • ایپس لکھنا: پلگ ان کی ترتیب، سرور ہکس، ویب ایپ رجسٹری، Fusion، ترتیبات، اسٹوریج، تراجم اور پیکنگ۔
  • سورس سے بلڈنگ: سرور، ویب انٹرفیسز، Docker image اور ایپس۔
  • معاشرے میں حصہ لینا: مسائل، پُل ریکسٹس، اسٹائل، تراجم، سیکیورٹی اور لائسنس۔
سوال کمیونٹی ڈسکشنز میں خوش آمدید ہیں۔ باگز کمیونٹی آئیوز میں رپورٹ کریں۔
