Antimatter کو وسیع کرنے کے طریقے

جو ہلکا پھلکا ٹول کام کر سکے اسے چنیں۔ پہلے چار طریقوں کے لیے سرور تک رسائی کی ضرورت نہیں ہے؛ ایپس اس کے اندر چلتی ہیں۔

ٹولیہ کیا کرتا ہےکس کے لیے موزوں ہے
REST APIایپس جو کچھ بھی کرتی ہیں: پیغامات، چینلز، لوگ، فائلیں، ترتیبات۔ ایک WebSocket واقعات کے ہوتے ہی انہیں بھیجتا ہے۔اسکرپٹس، دوسرے نظاموں کے ساتھ ہم آہنگی، کسٹم کلائنٹس۔
Incoming webhooksایک خفیہ URL جو کسی چینل میں پیغام پوسٹ کرتا ہے جب کوئی چیز اسے JSON بھیجتی ہے۔الارمز، CI نتائج، مانیٹرنگ، دوسرے ٹولز سے اطلاعات۔
Outgoing webhooksجب عوامی چینل میں کوئی پیغام ٹریگر ورڈ سے شروع ہو تو Antimatter آپ کے URL کو کال کرتا ہے اور آپ کا جواب پوسٹ کرتا ہے۔سادہ چیٹ پر مبنی آٹومیشنز۔
Slash commandsلوگ /something ٹائپ کرتے ہیں؛ Antimatter آپ کے URL کو کال کرتا ہے اور آپ کا جواب انہیں یا چینل کو دکھاتا ہے۔لاک اپس، چیٹ سے شروع کیے جانے والے اقدامات۔
Botsپروگرامز کے لیے بنائے گئے اکاؤنٹس، جن کے اپنے ٹوکنز، بوٹ ٹیگ، اور انٹرایکٹو پیغامات اور ڈائیلاگز ہیں۔اسسٹنٹس، نٹیفائرز، یا کوئی بھی چیز جو لوگوں کے ساتھ بات چیت کرتی ہے۔
Apps (plugins)کوڈ جو سرور (Go) اور ویب ایپ (React) کے اندر چلتا ہے: ہر پیغام پر ہکس، نئے مینو، پینلز، پیغامات کی اقسام، صفحات۔خصوصیات: پولز، نوٹس، کیلنڈرز، ایسی انٹیگریشنز جو یوزر انٹرفیس کی ضرورت ہوتی ہے۔

انٹرفیس میں لوگ پلگ انز کو "ایپس" کہتے ہیں۔ یہ رہنما جہاں دونوں الفاظ مددگار ہوں وہاں "ایپس (پلگ انز)" لکھتا ہے، کیونکہ کوڈ، API اور کنفیگریشن اب بھی "پلگ ان" کہتے ہیں۔

Mattermost کے ساتھ مطابقت

Antimatter، Mattermost کا فورک ہے۔ جو کچھ Mattermost سرور کے ساتھ کام کرتا ہے، وہ Antimatter کے ساتھ بھی کام کرتا ہے۔

کیا ایک جیسا ہے

  • REST API جو /api/v4 کے تحت ہے، اس کی تصدیق، اس کا WebSocket اور اس کی غلطی کی شکل۔ سرور ورژن 12.0.0 رپورٹ کرتا ہے، لہذا کلائنٹس اور ایپس جو سرور کے ورژن کی جانچ کرتی ہیں، انہیں ایک تازہ Mattermost نظر آتا ہے۔
  • ویب ہکس اور سلاش کمانڈز، بشمول ان کے Slack کے ساتھ مطابقت رکھنے والے payloads۔
  • سرور پلگ ان API اور hooks: Antimatter نے ان میں کوئی تبدیلی نہیں کی ہے۔ سرور کوڈ اسی Go module کے خلاف build ہوتا ہے، github.com/mattermost/mattermost/server/public۔
  • ویب ایپ پلگ ان رجسٹری: Mattermost کی رجسٹری کے ہر register… طریقہ Antimatter کے دونوں ویب انٹرفیسز میں موجود ہے۔
  • کلائنٹ لائبریریز: Go کلائنٹ model.Client4 اور TypeScript کلائنٹ @mattermost/client (دیکھیں کلائنٹ لائبریریز)۔
  • پلگ ان بنڈلز: .tar.gz فائل جس میں plugin.json manifest شامل ہو۔ Mattermost کے key سے sign شدہ پلگ انسٹال ہوتے ہیں، اور Antimatter کے key سے sign شدہ پلگ بھی۔

کیا مختلف ہے

  • دو ویب انٹرفیسز۔ نیا انٹرفیس، Fusion، ڈیفالٹ ہے؛ کلاسیکی Mattermost انٹرفیس ابھی بھی دستیاب ہے۔ Fusion زیادہ تر پلگ ان اجزاء کو render کرتا ہے، لیکن ان میں سے کچھ کو مختلف جگہ رکھتا ہے اور کچھ کو چھوڑ دیتا ہے۔ ایپ بتا سکتی ہے کہ کون سا انٹرفیس چل رہا ہے۔ دیکھیں Fusion انٹرفیس کی سپورٹ۔
  • اضافی API۔ Antimatter اپنے اپنے فیچرز کے لیے endpoints شامل کرتا ہے: community attributes، timeouts، messages on top، message requests، channel اور category overrides، channel export، اور communities پر نئے fields۔ دیکھیں Antimatter API میں کیا شامل کرتا ہے۔
  • اضافی پیغام فیچرز۔ پیغامات کے attachments pipeline stages اور ایک چھوٹا سا chart دکھا سکتے ہیں؛ posts inline replies یا spoilers ہو سکتے ہیں۔
  • ایپس کے لیے اضافی ویب ایپ hooks: composer "+" مینیٹم، emoji picker tabs، channel view میں ایک panel، sidebar channels کے نیچے ایک footer، اور integrations صفحات پر ایک entry۔ دیکھیں صرف Antimatter کے پاس موجود hooks۔
  • کوئی لائسنس نہیں۔ ہر فیچر لائسنس key کے بغیر دستیاب ہے۔ لائسنس، trial اور enterprise upgrade endpoints ختم ہو گئے ہیں؛ GET /api/v4/license/client ان کلائنٹس کے لیے باقی ہے جو اس کی درخواست کرتے ہیں۔ Mattermost کے paid editions کے لیے بنائے گئے کچھ ایپس خود لائسنس کی جانچ کرتے ہیں اور چلنے سے انکار کر دیتے ہیں۔
  • نام۔ انٹرفیس میں Teams کو communities کہا جاتا ہے، لیکن API اور کوڈ ابھی بھی team کہتے ہیں۔ Environment variables AM_ prefix استعمال کرتے ہیں، command-line tool amctl ہے اور سرور binary antimatter ہے۔

کوڈ کہاں موجود ہے

ہر چیز اوپن سورس ہے، GitHub پر AntimatterChat تنظیم کے تحت۔ ہر ریپوزٹری اپنے main برانچ پر کام کرتی ہے۔

ریپوزٹریاس میں کیا ہے
antimatterسرور (Go، server/ میں)، دونوں ویب انٹرفیسز (webapp/fusion اور webapp/channels)، TypeScript کلائنٹ اور amctl۔
antimatter-dockerDocker امیجز، جن میں شامل ایپس اور compose فائلز شامل ہیں۔
antimatter-plugin-*ہر شامل ایپ کے لیے ایک ریپوزٹری: polls، todo، notes، whiteboard، calendar، mail، gifs، memes، voice-channels، calls، boards (Kanban)، playbooks، agents اور metrics۔
gifs-serverGIFs ایپ کے استعمال ہونے والا خود میزبان (self-hosted) GIF اور اسٹیکر سروس۔
desktop-app، mobile-app، push-proxyڈیسک ٹاپ اور موبائل ایپس، اور وہ سروس جو فونز کو پش اطلاعات (push notifications) بھیجتی ہے۔
antimatter.chatیہ ویب سائٹ اور اس کی دستاویزات۔
communityAntimatter کے ہر حصے کے لیے مسائل (issues) اور گفتگو (discussions)۔

شروع کرنے سے پہلے

  • ٹیسٹ سرور حاصل کریں۔ سب سے تیز طریقہ Docker image ہے: Antimatter کی تنصیب دیکھیں۔ Antimatter پر کام کرنے کے لیے، سورس سے بلڈنگ دیکھیں۔
  • چیک کریں کہ سرور کس چیز کی اجازت دیتا ہے۔ کئی انٹیگریشن فیچرز پہلے سے بند ہوتے ہیں اور ان کے لیے سسٹم ایڈمن درکار ہوتا ہے: پرسنل ایکسس ٹوکنز، بوٹ اکاؤنٹس، یوزر نیم اور آئیکن اوور رائڈز، اور ایپس اپ لوڈ کرنا۔ ہر صفحہ بتاتا ہے کہ اس کے لیے کون سی ترتیب درکار ہے۔
  • اپنے سائٹ کے URL کو جانیں۔ مثالوں میں https://chat.example.com استعمال ہوا ہے۔ اسے اپنے سرور کے پتے سے تبدیل کریں۔

اس گائیڈ میں

  • REST API: تصدیق (authentication)، بنیادی وسائل، پیجینیشن، غلطیاں، ریٹ لمٹس، WebSocket، کلائنٹ لائبریریز، اور Antimatter کی اضافی خصوصیات۔
  • ویب ہکس: داخلہ اور نکلنے والے ویب ہکس، پے لوڈز، منسلک فائلیں اور کارڈز۔
  • سلاش کمانڈز: کسٹم کمانڈز، ان کی درخواست اور جواب، اور آٹو کمپلیٹ۔
  • بوٹس اور انٹرایکٹو پیغامات: بوٹ اکاؤنٹس، بٹن، مینو اور ڈائیلاگز۔
  • ایپس لکھنا: پلگ ان کی ترتیب، سرور ہکس، ویب ایپ رجسٹری، Fusion، ترتیبات، اسٹوریج، ترجمے اور پیکنگ۔
  • سورس سے بلڈنگ: سرور، ویب انٹرفیسز، Docker image اور ایپس۔
  • معاہدہ (Contributing): مسائل (issues)، پُل ریکسٹس، اسٹائل، ترجمے، سیکیورٹی اور لائسنس۔
