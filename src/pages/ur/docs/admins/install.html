Docker Compose کے ساتھ انسٹال کریں

یہ سفارش کردہ طریقہ ہے۔ ایک compose فائل Antimatter، PostgreSQL، فائل اسٹوریج اور GIF سروس کو چلاتی ہے۔ آپ کو Docker Engine اور اس کے Compose پلگ ان (docker compose) کے ساتھ ایک لائنکس سرور، 2 CPU کورز اور 4 GB یا اس سے زیادہ میموری درکار ہے۔

1. compose فائل ڈاؤن لوڈ کریں

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml

2. .env فائل بنائیں

compose فائل اپنی ترتیبات اسی ڈائریکٹری میں موجود .env فائل سے پڑھتی ہے۔ اسے رینڈم سیکرٹس کے ساتھ بنائیں:

cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
chmod 600 .env

SITE_URL کو اس ایڈریس پر سیٹ کریں جو لوگ اپنے براؤزر میں ٹائپ کریں گے، مثلاً مقامی نیٹ ورک پر http://192.168.1.20:8065 یا ڈومین کے ساتھ https://chat.example.com۔ .env فائل کو محفوظ رکھیں: ڈیٹا بیس اور اسٹوریج پہلی بار شروع ہونے پر ان پاس ورڈز کا استعمال کرتے ہیں، اور بیک اپ بحال کرنے کے لیے آپ کو وہی فائل درکار ہے۔

3. اسے شروع کریں

docker compose up -d
docker compose ps

پہلی بار شروع ہونے میں ایک یا دو منٹ لگتے ہیں: PostgreSQL ڈیٹا بیس بناتا ہے، ایک one-shot bucket سروس اسٹوریج باکٹ بناتی ہے، ایک one-shot gifs-stickers سروس اسٹارٹر اسٹیکر پیک امپورٹ کرتی ہے، اور Antimatter اپنے ٹیبلز بناتا ہے۔ اسے docker compose logs -f antimatter کے ساتھ دیکھیں۔

اگر آپ شروع سے ڈومین نام اور HTTPS استعمال کرنا چاہتے ہیں، تو ڈومین اور HTTPS دیکھیں: compose فائل کے ساتھ یہ .env میں دو مزید لائنز اور https پروفائل ہیں۔

PostgreSQL، اسٹوریج اور GIF سروس ایک اندرونی نیٹ ورک (private) پر ہیں جس کا انٹرنیٹ تک رسائی نہیں ہے، اور اس میں صرف Antimatter شامل ہوتا ہے۔ ان میں سے کوئی بھی پورٹ پبلش نہیں کرتا۔

Antimatter کنٹینر ڈسک پر کچھ نہیں رکھتا: اس کی ترتیبات ڈیٹا بیس میں ہیں (AM_CONFIG اس کی طرف اشارہ کرتا ہے) اور اس کی فائلیں اور ایپس اسٹوریج سروس میں ہیں۔ آپ کنٹینر کو کسی بھی وقت ہٹا کر دوبارہ بنا سکتے ہیں۔ بیک اپ کے لیے سب کچھ postgres، files اور gifs وولمز میں ہے، ساتھ ہی آپ کا .env بھی۔

ایک امیج منتخب کریں

Antimatter کی دو امیجز پبلش کی گئی ہیں، دونوں linux/amd64 اور linux/arm64 کے لیے، اور دونوں ہر ریپوزٹری کے main برانچ سے بنائی گئی ہیں:

امیجباندل شدہ ایپسٹگز
ghcr.io/antimatterchat/antimatterAgents, Calls, GitHub, GitLab, Jira, Kanban, Metrics اور Playbooks۔latest، ریلیز کے لیے X.Y.Z، اور sha-<commit>
ghcr.io/antimatterchat/antimatter-nextاسی کے علاوہ Voice channels, Polls, Mail, Calendar, Notes, Whiteboard, GIFs, Todo اور Memes۔ ہر رات دوبارہ بنائی جاتی ہے۔latest, nightly, nightly-<YYYYMMDD>, sha-<commit>

سائٹ کا compose فائل antimatter-next استعمال کرتی ہے، کیونکہ GIF سروس اور اس سائٹ پر بیان کردہ زیادہ تر ایپس صرف اس امیج میں موجود ہیں۔ امیج بدلنے کے لیے .env میں ANTIMATTER_IMAGE سیٹ کریں اور docker compose up -d چلائیں۔

latest آپ کے نیچے بدل جاتا ہے۔ پروڈکشن میں، کسی ٹگ کو پن کریں جیسے nightly-20261015 یا sha-<commit>، اور اپ گریڈ کے وقت اسے جان بوجھ کر تبدیل کریں۔ سرور شروع ہونے پر اپنی ڈیٹا بیس کو اپ گریڈ کرتا ہے، اس لیے آپ بیک اپ واپس کرنے کے بغیر پرانی امیج پر واپس نہیں جا سکتے، نہ ہی antimatter-next سے antimatter پر۔ دیکھیں بیک اپس اور اپ گریڈز۔

امیج کے اندر

  • سرور /antimatter میں موجود ہے، جس میں /antimatter/bin میں antimatter اور amctl باینریز ہیں (PATH پر)۔
  • یہ غیر پرائیویلیجڈ یوزر antimatter (uid 2000) کے طور پر ایک منیمل ڈسٹریلس بیس پر چلتا ہے، جس میں کوئی شیل نہیں ہے۔
  • پورٹس: 8065 (ویب اور API)، 8067 (میٹرکس)، 8074 (کلسٹر)، 8443 UDP اور TCP (کالز)۔
  • لوکل موڈ (ServiceSettings.EnableLocalMode) فعال ہے، اس لیے amctl --local کنٹینر کے اندر کام کرتا ہے۔ ہیلتھ چیک amctl system status --local چلاتا ہے۔
  • باندل شدہ ایپس /antimatter/prepackaged_plugins میں موجود ہیں، جو Antimatter ایپ سائننگ کی کے ذریعے سائن شدہ ہیں۔
  • ٹیکسٹ ایکسٹریکشن ٹولز (pdftotext، wvText، unrtf، tidy) شامل ہیں، تاکہ اپ لوڈ شدہ دستاویزات کے مواد کی تلاش کی جا سکے۔

دیگر کمپوز فائلز

antimatter-docker ریپوزٹری میں deploy/compose/ میں پروڈکشن سیٹ اپ موجود ہے: nginx آپ کے اپنے سرٹیفکیٹس یا Let's Encrypt (certbot) کے ساتھ، PostgreSQL، اختیاری GIF سروس (پروفائل gifs) اور سرور کی ترتیبات، ڈیٹا اور لاگز کے لیے نامیاتی وولومز، جو اس کے README میں دستاویز شدہ ہیں۔ یہ ڈیفالٹ طور پر اسٹبل امیج استعمال کرتا ہے اور فائلوں کو S3 اسٹوریج کے بجائے لوکل وولوم پر محفوظ کرتا ہے۔ اگر آپ nginx کو Caddy پر ترجیح دیتے ہیں یا پہلے سے سرٹیفکیٹس رکھتے ہیں، تو اسے استعمال کریں۔

پہلا ایڈمن بنائیں

اپنے براؤزر میں SITE_URL کھولیں اور اکاؤنٹ بنائیں۔ نئے سرور پر بنایا گیا پہلا اکاؤنٹ سسٹم ایڈمن بن جاتا ہے، اور سیٹ اپ پھر آپ کو اپنی پہلی کمیونٹی (Antimatter کی ٹیم یا ورک اسپیس کے لیے اصطلاح) بنانے میں رہنمائی فراہم کرتا ہے۔

پہلی شروع ہونے کے فوراً بعد یہ کریں: اس سے پہلے، جو بھی سرور تک پہلے پہنچتا ہے، وہ اس کا ایڈمن بن جاتا ہے۔ اگر آپ چاہتے ہیں کہ اکاؤنٹ کمانڈ لائن سے بنایا جائے، تو اس سے پہلے کہ سرور باہر سے قابل رسائی ہو:

docker compose exec antimatter amctl --local user create --system-admin --email-verified \
    --email admin@example.com --username admin --password 'a-long-password'
docker compose exec antimatter amctl --local team create --name main --display-name "Main"
docker compose exec antimatter amctl --local team users add main admin

پھر SITE_URL پر سائن ان کریں۔ پاس ورڈ کو اپنے شل ہسٹری سے باہر رکھنے کے لیے کمانڈ کے شروع میں ایک سپیس لگائیں (جیسے HISTCONTROL=ignorespace)، یا سائن ان کرنے کے بعد پاس ورڈ تبدیل کریں۔

اندر آ جانے کے بعد اگلی مراحل:

  1. فیصلہ کریں کہ کون اکاؤنٹس بنا سکتا ہے: سائن ان اور اکاؤنٹس۔
  2. ای میل کی ترتیب کریں، تاکہ مدعوں اور پاس ورڈ ری سیٹ کام کریں: ای میل اور پش اطلاعات۔
  3. اپنے فائر وال میں کالز پورٹ کھولیں: کالز اور وائس۔
  4. چیک کریں کہ کون سی ایپس فعال ہیں: باندل شدہ ایپس۔

ریلیس آرکائیو سے انسٹال کریں

Docker کے بغیر، سرور ایک آرکائیو سے چلتا ہے جس کا نام antimatter-<os>-<arch>.tar.gz ہے (مثلاً antimatter-linux-amd64.tar.gz)۔ اس میں ایک واحد antimatter/ ڈائریکٹری ہوتی ہے جس میں bin/antimatter، bin/amctl، config/config.json، ویب ایپس (client/ اور client-fusion/)، ای میل ٹیمپلیٹس اور تراجم شامل ہیں۔

1. PostgreSQL کی تیاری

Antimatter صرف PostgreSQL کو سپورٹ کرتا ہے، ورژن 15 یا اس سے نیا (پرانی ورژنز لوگ میں ایک ایرر کے ساتھ شروع ہوتی ہیں)۔ ایک یوزر اور ڈیٹابیس بنائیں:

sudo -u postgres psql <<'EOF'
CREATE USER antimatter WITH PASSWORD 'a-long-password';
CREATE DATABASE antimatter OWNER antimatter;
EOF

2. انپیک اور کنفیگریشن

sudo tar -xzf antimatter-linux-amd64.tar.gz -C /opt
sudo useradd --system --user-group antimatter
sudo mkdir -p /opt/antimatter/data
sudo chown -R antimatter:antimatter /opt/antimatter

سرور کو ڈیٹابیس سے جوڑیں، چاہے /opt/antimatter/config/config.json (SqlSettings.DataSource) میں یا ماحولیاتی متغیروں کے ذریعے، اور سائٹ URL سیٹ کریں:

AM_SQLSETTINGS_DRIVERNAME=postgres
AM_SQLSETTINGS_DATASOURCE=postgres://antimatter:a-long-password@localhost:5432/antimatter?sslmode=disable&connect_timeout=10
AM_SERVICESETTINGS_SITEURL=https://chat.example.com

آرکائیو کا config.json ایک مکمل ڈیفالٹ کنفیگریشن ہے: سسٹم کنسول میں تبدیلی کی گئی ترتیبات اس میں واپس محفوظ کی جاتی ہیں۔ اگر آپ ڈیٹابیس میں کنفیگریشن رکھنا چاہتے ہیں، تو کنفیگریشن دیکھیں۔

3. اسے سروس کے طور پر چلائیں

ایک systemd یونٹ، /etc/systemd/system/antimatter.service میں:

[Unit]
Description=Antimatter
After=network.target postgresql.service

[Service]
Type=notify
User=antimatter
Group=antimatter
WorkingDirectory=/opt/antimatter
ExecStart=/opt/antimatter/bin/antimatter
EnvironmentFile=-/etc/antimatter.env
TimeoutStartSec=3600
Restart=always
RestartSec=10
LimitNOFILE=49152

[Install]
WantedBy=multi-user.target

اپنے AM_ متغیروں کو /etc/antimatter.env میں رکھیں (صرف root کے لیے قابلِ مطالعہ)، پھر:

sudo systemctl daemon-reload
sudo systemctl enable --now antimatter
journalctl -u antimatter -f

سرور پورٹ 8065 پر سنتا ہے۔ http://<server>:8065 کھولیں، یا ایک ریورس پراکسی کے بعد اپنا ڈومین (دیکھیں ڈومین اور HTTPS)، اور پہلا اکاؤنٹ بنائیں: یہ سسٹم ایڈمن بن جائے گا۔

bin/amctl کمانڈ لائن سے چل رہے سرور کو منظم کرتا ہے۔ سرور پر خود، یہ لوکل موڈ کے ذریعے سائن ان کے بغیر کام کرتا ہے: AM_SERVICESETTINGS_ENABLELOCALMODE=true سیٹ کریں، پھر sudo -u antimatter /opt/antimatter/bin/amctl --local system status چلائیں۔

دیگر سرور کمانڈز

سرور چلانے کے علاوہ (antimatter، یا antimatter server)، بائنری میں کچھ دیکھ بھال کی کمانڈز ہیں۔ یہ سرور کی اسی کنفیگریشن کو پڑھتی ہیں۔

کمانڈیہ کیا کرتا ہے
antimatter versionورژن، بلڈ نمبر، بلڈ تاریخ اور بلڈ ہیش پرنٹ کرتا ہے۔
antimatter db pingچیک کرتا ہے کہ ڈیٹابیس تک رسائی ممکن ہے۔
antimatter db initڈیٹابیس میں کنفیگریشن بناتا ہے (AM_CONFIG کو postgres:// URL پر سیٹ کر کے)۔
antimatter db migrateسرور شروع کیے بغیر ڈیٹابیس مائیگریشنز لاگو کرتا ہے۔
antimatter db versionڈیٹابیس پر لاگو ہونے والی آخری مائیگریشن پرنٹ کرتا ہے۔
antimatter import bulk, antimatter export bulkبُلک فارمیٹ میں ڈیٹا امپورٹ یا ایکسپورٹ کرتا ہے (دیکھیں بیک اپس اور اپ گریڈز)۔
