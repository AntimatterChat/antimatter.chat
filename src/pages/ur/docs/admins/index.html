ڈیپلائمنٹ میں کیا شامل ہے

Antimatter ایک سیلف-ہوسٹڈ ٹیم چیٹ ہے، جو Mattermost کا فورک ہے۔ ایک مکمل ڈیپلائمنٹ میں یہ اجزاء شامل ہیں۔ صرف پہلے تین اجزاء لازمی ہیں۔

جزویہ کیا کرتا ہےلازمی
Antimatter سرورایک Go پروگرام (antimatter) جو پورٹ 8065 پر ویب ایپ، API اور ویب ساکٹس فراہم کرتا ہے، شامل ایپس (پلگ انز) کو چلاتا ہے، اور پورٹ 8443 پر کال میڈیا منتقل کرتا ہے۔ کمانڈ لائن ٹول amctl اس کا انتظام کرتا ہے۔ہاں
PostgreSQLڈیٹا بیس: پیغامات، صارفین، کمیونٹیز اور، سفارش شدہ سیٹ اپ میں، سرور کی ترتیبات۔ ورژن 15 یا اس سے نیا۔ہاں
فائل اسٹوریجاپ لوڈ شدہ فائلیں، تصاویر اور انسٹال شدہ ایپس: ایک S3-موزوں سروس (compose فائل RustFS چلاتی ہے)، یا ایک مقامی ڈائریکٹری۔ہاں
ایک ریورس پروکسیسرور کے سامنے HTTPS: compose فائل کا Caddy پروفائل، یا آپ کا اپنا nginx۔پروڈکشن کے لیے
GIF سروس (gifs-server)GIF پکر کے لیے GIFs اور اسٹیکرز، آپ کے اپنے کٹالگ سے۔ یہ Tenor API سے بات چیت کرتا ہے۔نہیں
ایک پش پروکسیApple اور Google کے ذریعے موبائل ایپ کو اطلاعات بھیجتا ہے۔موبائل اطلاعات کے لیے
rtcd, ایک TURN سروربہت سی کالز کے لیے ایک الگ میڈیا سرور، اور سخت فائر والز کے پیچھے موجود لوگوں کے لیے ایک ریلی۔نہیں
AI اینڈ پوائنٹسAI ایجنٹس، کال ٹرانسکرپشن، پڑھ کر سنائے جانے اور ترجمے کے پیچھے ماڈلز: ایک کلاؤڈ پرووائیڈر یا آپ کے چلائے جانے والے سرورز۔نہیں

Antimatter میں کوئی لائسنس یا ادائیگی والا ایڈیشن نہیں ہے: سنگل سائن-آن، LDAP، ہائی ایویلیبلٹی، کمپلائنس ایکسپورٹس، ڈیٹا رٹینشن اور دیگر خصوصیات جو Mattermost اپنے ادائیگی والے پلانز کے لیے محفوظ رکھتا ہے، سب شامل ہیں۔

ضروریات

  • ایک Linux سرور، amd64 یا arm64، کچھ سو لوگوں کے لیے 2 CPU کورز اور 4 GB میموری یا اس سے زیادہ، اور لوگوں کے اپ لوڈ کردہ فائلوں کے لیے ڈسک اسپیس۔
  • Docker Engine، Compose پلگ ان (docker compose) کے ساتھ، سفارش شدہ انسٹالیشن کے لیے۔
  • پروڈکشن کے لیے: سرور کی طرف اشارہ کرنے والا ایک ڈومین نام، اور HTTPS کے لیے پورٹ 80 اور 443 کھلے۔
  • کالز کے لیے: پورٹ 8443، UDP اور TCP، کال کرنے والے لوگوں کے لیے رسائی پذیر۔
  • ای میل کے لیے: ایک SMTP سرور جس کے ذریعے Antimatter بھیج سکتا ہے۔

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml

پھر سائٹ کا URL کھولیں اور اپنا اکاؤنٹ بنائیں: پہلا اکاؤنٹ سسٹم ایڈمن بن جاتا ہے۔ انسٹالیشن ہر مرحلے اور انسٹال کرنے کے دوسرے طریقوں کی وضاحت کرتا ہے۔

اس گائیڈ میں

  • انسٹالیشن: Docker Compose، امیجز، ریلیس آرکائیو، پہلا ایڈمن۔
  • ترتیبات: ڈیٹا بیس یا فائل میں ترتیبات، AM_ ماحولیاتی متغیرات، سسٹم کنسول، amctl، لاگز۔
  • ڈومین اور HTTPS: سائٹ کا URL، Caddy، nginx، کلائنٹ کے پتے۔
  • کالز اور آواز: پورٹس، NAT، TURN، rtcd، ٹرانسکرپشن اور کیپشنز۔
  • ای میل اور پش: SMTP، پش پراکسی اور موبائل ایپ۔
  • باندل ایپس: کون سی ایپس فعال ہیں، ان کی ترتیبات، اور دوسری ایپس کی انسٹالیشن۔
  • AI: ایجنٹس، بول چال اور ترجمے کے لیے ماڈلز، اور ڈیٹا کہاں جاتا ہے۔
  • سائن ان اور اکاؤنٹس: سائن اپ، پاسورڈز، MFA، سنگل سائن آن، LDAP، مہمان، سیشنز۔
  • بیک اپس اور اپ گریڈز: بیک اپ، ریستور، اپ گریڈ، اور Mattermost سے منتقلی۔
  • آپریشنز: نگرانی، اسکیلنگ، ڈیٹا رٹینشن، مطابقت، اور ٹربل شوٹنگ۔
  • سیکیورٹی: ہارڈننگ چیک لسٹ اور باہری کنکشنز۔

کیا آپ سرور کے بجائے کمیونٹی چلانا چاہتے ہیں (چینلز، کردار، مڈریشن)؟ کمیونٹی کی انتظامیہ دیکھیں۔ انٹیگریشنز بنانے کے لیے؟ Antimatter پر تعمیر دیکھیں۔

آپ کا پہلا گھنٹہ

  1. انسٹال کریں، اور فوراً ایڈمن اکاؤنٹ بنائیں۔
  2. سرور کو اپنے ڈومین پر HTTPS کے پیچھے رکھیں۔
  3. SMTP ترتیب دیں اور ایک ٹیسٹ ای میل بھیجیں۔
  4. کالز کا پورٹ کھولیں، اور Calls ایپ کے ٹیسٹ موڈ کو بند کریں۔
  5. فیصلہ کریں کہ کون سائن اپ کر سکتا ہے، اور MFA کو فعال کریں۔
  6. سیکیورٹی میں باہری کنکشنز کا جائزہ لیں۔
  7. روزانہ بیک اپس ترتیب دیں۔
