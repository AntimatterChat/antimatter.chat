Встроенные роли

В каждом сообществе есть одинаковые встроенные роли. Их права определяются схемой прав сервера, которую может изменить только системный администратор.

Администратор сообществачип Администратор командыНастройки, роли, онбординг и макет сообщества; модерация и удаление участников; удаление сообщений любого пользователя; преобразование каналов в закрытые; архивирование каналов по умолчанию; вебхуки и команды с косой чертой.

Эти значения по умолчанию подходят для рабочей среды, где участники доверяют друг другу в организации собственных каналов. В публичном сообществе обычно требуется, чтобы участники имели меньше прав: попросите системного администратора настроить разрешения для вашего сообщества в Системная консоль › Управление пользователями › Разрешения, где Схема переопределения команды может применяться только к вашему сообществу.

Назначение администратора сообщества

  1. Откройте меню сообщества и выберите Управление участниками.
  2. Найдите пользователя, откройте меню рядом с его ролью и выберите Сделать администратором команды. (В этом диалоге по-прежнему используется слово «команда» вместо «сообщение».)

Чтобы снять роль, выберите Сделать участником команды. Это могут сделать только администраторы сообщества и системные администраторы: пользовательская роль не может сделать кого-либо администратором сообщества.

Держите не менее двух администраторов сообщества, чтобы сообщество не осталось без управления, если один из них уйдёт.

Пользовательские роли

Пользовательские роли — это роли, которые вы создаёте для своего сообщества, как в Discord: «Модераторы», «Сотрудники», «Бета-тестеры», «Вкладчики». Роль может задавать цвет, отдельную группу в списке участников и права. Каждую роль можно упомянуть, что отправит уведомление всем, у кого она есть.

Чтобы управлять ролями, откройте меню сообщества, выберите Настройка команды, затем Роли…. Этот пункт видят администраторы сообщества и пользователи с разрешением Управление ролями.

Создание роли

  1. В диалоговом окне Роли выберите Создать роль.
  2. Введите Имя.
  3. Выберите Цвет или введите код цвета.
  4. Оставьте включённым Показывать участников отдельно, если участники с этой ролью должны отображаться отдельной группой в списке участников.
  5. Включите Доступна всем, если участники могут присвоить себе эту роль (см. Роли, доступные всем).
  6. Включите Разрешения, которые должна предоставлять роль (см. таблицу ниже).
  7. В разделе Участники добавьте людей с помощью Добавить участников команды….
  8. Выберите Создать роль.

В списке ролей кнопки Переместить вверх и Переместить вниз задают порядок. Порядок важен: самая высокая роль участника определяет цвет его имени и то, кого он может управлять (см. Порядок ролей). Удалить роль немедленно удаляет её без запроса подтверждения.

Разрешения, которые может предоставлять роль

Управление ролямиСоздание и редактирование ролей, стоящих ниже собственной, и назначение их участникам. Также создание и редактирование команд.

Управление интеграциямиВебхуки и команды с косой чертой, собственные и других участников.
  • Администратор не включает Управление ролями и Удаление участников. Для человека, который должен управлять сообществом вместе с вами, включите все три разрешения или сделайте его администратором сообщества.
  • Роль может только добавлять разрешения. Пригласить людей и два переключателя Создать по умолчанию уже выданы каждому участнику, поэтому они имеют значение только в том случае, если системный администратор отобрал их у участников.
  • Участник, не являющийся администратором сообщества, может назначить роли только те разрешения, которыми обладает сам.

Роль модератора

Для публичного сообщества типичная роль «Модераторы» включает Управление сообщениями, Удаление участников и Управление каналами и отображается отдельно со своим цветом. Роль «Модераторы», создаваемая пресетами макета, не содержит Удаление участников: добавьте её, если ваши модераторы должны блокировать или удалять участников.

Порядок ролей

Роли ранжируются по их позиции в списке, начиная с высшего ранга, как в Discord:

  • Участники с Управление ролями могут редактировать, перемещать и назначать только те роли, которые находятся ниже их высшего ранга, а также создавать новые роли ниже этого уровня.
  • Участники с Удаление участников могут блокировать только тех, чей высший ранг ниже их собственного.
  • Роли, которые может принять любой участник, не учитываются при определении ранга.
  • Администраторы сообщества находятся выше всех ролей. Их нельзя заблокировать.
При удалении участника из сообщества ранг не проверяется: любой участник с Удаление участников может удалить любого, включая тех, кто выше по рангу. Назначайте Удаление участников только тем, кому вы доверяете.

Назначение роли

Существует три способа:

  • В Роли… отредактируйте роль и добавьте участника в разделе Участники.
  • В режиме модератора участника, в разделе Роли, используйте Добавить роль или нажмите × на роли, чтобы удалить её (см. Режим модератора).
  • Через процесс онбординга для ролей, которые может принять любой участник (см. Онбординг).

Роли сообщества могут иметь только его участники. Тот, кто покидает сообщество, теряет его роли и не получает их обратно при возвращении.

Роли, доступные всем

Роль с флагом Доступна всем открыта для всех: участники могут назначить её себе или снять через меню сообщества в разделе Ваши роли…. Этот пункт появляется только если в сообществе есть такие роли. Используйте их для интересов или групп уведомлений, например «Анонсы», «Пользователи Linux» или «Встречи в Париже», на которые можно ссылаться упоминаниями.

Роль, доступная всем, всё равно предоставляет свои разрешения тому, кто её принял. Не включайте разрешения в такой роли, если не хотите, чтобы все участники их имели.

Цвета, группы и значки

Вверху диалога Роли администраторы сообщества имеют два переключателя для всего сообщества:

  • Цвета ролей: имена участников окрашиваются в цвет их высшего ранга. Включено по умолчанию.
  • У всех отображается значок команды: у тех, кто не выбрал значок, отображается тег их первой команды в этом сообществе. По умолчанию выключено; полезно в компании, где значок указывает, в каком отделе работает человек.

В списке участников каждая роль, отображаемая отдельно, получает собственную группу онлайн-участников, начиная с высшей роли. Если ни одна роль не отображается отдельно, список группирует администраторов и модераторов под Администратор и Модераторы. Участники могут переключать список между Роли и Команды. Системный администратор может отключить группировку по ролям на всем сервере с помощью Группировка участников по ролям в Системной консоли.

Команды внутри сообщества

В Antimatter команда — это группа людей внутри сообщества, например отдел, проект или рабочая группа. У команды есть имя, которое можно упомянуть, короткий тег (до 8 символов, например «DET»), лидер, описание и канал команды. Участники могут отображать тег одной из своих команд рядом со своим именем.

Создание команды

  1. Откройте меню сообщества и выберите Группы пользователей…. Открывающийся диалог по-прежнему называется «Группы пользователей».
  2. Выберите Создать группу, введите имя команды и имя для упоминания, добавьте участников и создайте её.
  3. Чтобы установить тег, руководителя и канал, щелкните тег команды рядом с именем одного из её участников, чтобы открыть её карточку, затем выберите Изменить команду. Заполните Тег, Руководитель, Канал команды и Чем занимается команда, и сохраните.

Администраторы сообщества и пользователи с правом Управление ролями создают и редактируют команды. Лидер не имеет дополнительных прав: это название носит информационный характер. Каждый участник сам выбирает, какой значок команды отображать, в своих настройках в разделе Мой аккаунт, Значок команды.

Список участников может группировать людей по командам: выберите Команды в поле Группировать участников по вверху списка.

Права в одном канале

Роли действуют во всех каналах сообщества. Чтобы дать роли больше или меньше прав в одном канале или одной категории, используйте права канала: см. Права канала. Закрытый канал также может быть доступен только определённым ролям: в этом случае его участники автоматически получают соответствующие роли.
