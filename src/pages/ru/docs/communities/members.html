Приглашение людей

Откройте меню сообщества и выберите Пригласить людей. По умолчанию каждый участник может приглашать людей; у тех, кому это запрещено, пункт отсутствует.

  1. В поле Пригласить как выберите Участник или Гость. Этот пункт отображается только в том случае, если на сервере разрешены гости.
  2. В поле Кому: введите имена людей, у которых уже есть аккаунт на сервере, или адреса электронной почты тех, у кого его нет.
  3. В поле Добавить на каналы выберите каналы, к которым будут присоединены приглашённые. Для участников это необязательно, а для гостей — обязательно.
  4. При желании выберите Установить собственное сообщение, чтобы добавить несколько слов в письмо-приглашение.
  5. Выберите Пригласить. Появится сводка: кто был приглашён и какие приглашения не удалось отправить.

Для приглашения по электронной почте сервер должен уметь отправлять письма, а отправка приглашений по электронной почте должна быть включена. Если сервер не отправляет письма, вы всё равно можете добавить людей, у которых уже есть аккаунт. Если адреса электронной почты отклоняются, обратитесь к системному администратору.

Поделиться ссылкой-приглашением

В том же диалоговом окне, когда выбрано Участник, пункт Скопировать ссылку-приглашение копирует ссылку-приглашение сообщества. Любой, кто откроет её, сможет создать аккаунт (если сервер разрешает регистрацию) и присоединиться к сообществу. Поделитесь ссылкой в рассылке, на сайте или в записи на форуме.

Ссылка остаётся действительной, пока вы её не измените. Если она оказалась там, где не должна, создайте новую с помощью Пересоздать в разделе Параметры команды › Доступ: старая ссылка перестанет работать. У сообщества может быть только одна ссылка-приглашение за раз.

Пригласить знакомого

Чтобы переманить кого-то из другого сообщества в ваше, щёлкните правой кнопкой мыши по имени и выберите Пригласить в сообщество, затем нужное сообщество. Человек будет добавлен сразу.

Открытые сообщества

Если сообщество публичное (см. Кто может присоединиться), любой пользователь с аккаунтом на сервере может найти его через Присоединиться к другой команде и присоединиться без приглашения. На сервере, где может зарегистрироваться кто угодно, это самый простой способ вести публичное сообщество. Если сообщество принимает только определённые домены электронной почты, люди с другими адресами не смогут присоединиться, даже по ссылке.

Гости

Гости — это люди извне, например клиенты, подрядчики или партнёры. Гость видит только те каналы, к которым его добавили: он не может просматривать или присоединяться к другим каналам сообщества. Рядом с именем гостя отображается метка Гость, а в заголовке канала с гостями это также указано.

  • Гостевые аккаунты отключены по умолчанию. Системный администратор включает их в Системная консоль › Аутентификация › Гостевой доступ и может потребовать, чтобы гости использовали определённые домены электронной почты или двухфакторную аутентификацию.
  • Администраторы сообщества приглашают гостей через Пригласить людей, выбирая каналы, к которым у них будет доступ. Чтобы позже дать гостю доступ к другому каналу, добавьте его в этот канал.
  • Если системный администратор разрешит это, опция Allow invited guests to log in with a magic link (without password) позволит гостям входить в систему по ссылке, отправленной на электронную почту.
  • Чтобы сделать из гостя полноправного участника, а из участника — гостя, обратитесь к системному администратору. Это делается в Системная консоль › Управление пользователями › Пользователи с помощью Повысить до участника или Понизить до гостя.

Гости никогда не добавляются в каналы автоматически, даже если все участники сообщества состоят во всех каналах.

Управление участниками

Откройте меню сообщества и выберите Управление участниками (участники видят Просмотр участников). В списке отображаются все участники с указанием их ролей. В меню рядом с ролью пользователя можно:

  • сделать его администратором сообщества с помощью Сделать администратором команды или отменить это с помощью Сделать участником команды;
  • удалить его из сообщества с помощью Удалить из команды.

Это диалоговое окно из классического интерфейса, поэтому в нём всё ещё используется слово «команда». Вы также можете выполнить действия с пользователем в любом месте, где видите его имя: щёлкните по нему правой кнопкой мыши или откройте его карточку профиля. См. Модерация для режима модератора, таймаутов и удаления.

По умолчанию в сообществе нет ограничения на количество участников. Если ваш системный администратор установил такое ограничение (Макс. количество участников в сообществе) и приглашения начинают не срабатывать, попросите его увеличить лимит.

Введение в курс

Введение в курс приветствует новичков при первом открытии вашего сообщества. Оно отображает приветственный текст и несколько вопросов. Каждый ответ может назначить новичку роли и каналы, чтобы люди сразу находили нужные места.

Создание введения в курс

  1. Если ответы должны назначать роли, сначала создайте эти роли и включите для них Доступна всем (см. Роли, доступные всем). Введение в курс может назначать только те роли, которые открыты для всех.
  2. Откройте меню сообщества, выберите Настройка команды, затем Онбординг….
  3. Напишите текст Добро пожаловать: о чём сообщество и каковы его основные правила, в нескольких строках.
  4. Выберите Добавить вопрос, например «Что привело вас сюда?». Оставьте Несколько ответов включённым, если участники могут выбрать более одного ответа.
  5. Для каждого ответа напишите его текст, затем щёлкните по ролям и публичным каналам, которые он предоставляет. Выберите Добавить ответ для следующего.
  6. Выберите Сохранить.

Каналы, которые вы можете предложить, — это публичные каналы, участником которых вы являетесь. Чтобы удалить онбординг, удалите его вопросы и текст приветствия, затем сохраните изменения.

Что видят новички

В первый раз, когда кто-то открывает сообщество, появляется диалог Добро пожаловать в с вашим текстом и вопросами. Они выбирают свои ответы и нажимают Готово или Пропустить. В любом случае они больше не увидят его в этом сообществе. Те, кто присоединился до того, как вы создали онбординг, увидят его в следующий раз, когда откроют сообщество.

Участники могут позже изменить свои открытые роли из меню сообщества, в разделе Ваши роли….

Для публичного сообщества сочетайте онбординг с заблокированной категорией «Информация», содержащей канал правил и канал объявлений, а также баннером вверху канала правил (см. Параметры канала).

Атрибуты участников

Атрибуты участников — это сведения о ваших участниках, отображаемые на их карточке профиля в вашем сообществе, такие как компания, сайт, субподрядчик или местоимения. Они принадлежат сообществу: другие сообщества на сервере их не видят.

Определение атрибутов

Откройте меню сообщества, выберите Настройка команды, затем Атрибуты участников… и выберите Добавить атрибут. Для каждого атрибута установите:

  • Имя, например «Компания».
  • Тип: Текст, Вариант, Несколько вариантов, Дата, Ссылка, Электронная почта, Номер телефона, Человек или людей. Для вариантов перечислите Варианты.
  • Кто устанавливает: Каждый участник заполняет его самостоятельно, или это делают только Администраторы.
  • Кто видит: Все, Администраторы или Скрытые. Администраторы и сам участник всегда видят его; скрытые атрибуты не отображаются на профилях.
  • Показывать в списке участников: отображает атрибут под именами людей в списке участников, вместо их должности, и позволяет всем фильтровать список по нему. Таким образом может быть показан только один атрибут.

Используйте Переместить вверх и Переместить вниз, чтобы настроить порядок на карточках профилей. В команде может быть не более 50 атрибутов. При удалении атрибута удаляются значения всех участников.

Заполните их

Чтобы установить атрибуты для участника, щёлкните правой кнопкой мыши по его имени и выберите Редактировать атрибуты…. Администраторы команды могут устанавливать любые атрибуты для всех участников; участники могут устанавливать только свои собственные, за исключением тех, которые установлены администраторами. Атрибуты, видимые только Администраторам, отображаются на карточке профиля с замком.

В компании атрибут, установленный администраторами и видимый только им, — удобное место для внутренних сведений, таких как дата окончания контракта, которые коллегам не нужно видеть.

У сервера также есть собственные атрибуты, одинаковые для всех команд, которые системный администратор определяет в Системная консоль › Системные атрибуты › Управление атрибутами. Они отображаются на карточках профилей перед атрибутами вашей команды, и только системные администраторы могут устанавливать их для других. Некоторые из них могут поступать от провайдера входа, например, из корпоративного каталога.

Когда участники покидают команду или исключаются из неё

  • Участники покидают команду с помощью пункта Покинуть команду в меню команды.
  • Участники, покинувшие команду или исключённые из неё, теряют свои роли и команды в этой команде. Их сообщения сохраняются.
  • Участник, исключённый из команды, может вернуться по новому приглашению или присоединиться снова, если команда публичная. Чтобы навсегда исключить участника, системный администратор должен деактивировать его аккаунт (см. Как не допустить участника обратно).
