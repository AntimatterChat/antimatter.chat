Приглашение людей

Откройте меню сообщества и выберите Пригласить людей. По умолчанию каждый участник может приглашать людей; у тех, кому это запрещено, этого пункта нет.

  1. В поле Пригласить как выберите Участник или Гость. Этот вариант появляется только если на сервере разрешены гости.
  2. В поле Кому: введите имена людей, у которых уже есть аккаунт на сервере, или адреса электронной почты тех, у кого его нет.
  3. В поле Добавить на каналы выберите каналы, к которым присоединятся приглашённые. Для участников это необязательно, для гостей — обязательно.
  4. При желании выберите Установить собственное сообщение, чтобы добавить несколько слов в письмо-приглашение.
  5. Выберите Пригласить. Появится сводка: кого пригласили и какие приглашения не удалось отправить.

Для приглашения по электронной почте сервер должен отправлять письма, а отправка приглашений по электронной почте должна быть включена. Если сервер не отправляет письма, вы всё равно можете добавить людей, у которых уже есть аккаунт. Если адреса электронной почты отклоняются, обратитесь к системному администратору.

Поделиться ссылкой-приглашением

В том же диалоговом окне, когда выбран вариант Участник, кнопка Скопировать ссылку-приглашение копирует ссылку-приглашение сообщества. Любой, кто откроет её, сможет создать аккаунт (если сервер разрешает регистрацию) и присоединиться к сообществу. Поделитесь ею в рассылке, на сайте или в форуме.

Ссылка остаётся действительной, пока вы её не измените. Если она оказалась там, где не должна, создайте новую с помощью кнопки Пересоздать в разделе Параметры команды › Доступ: старая ссылка перестанет работать. У сообщества может быть только одна ссылка-приглашение за раз.

Пригласить знакомого

Чтобы переместить кого-то из другого сообщества в ваше, щёлкните правой кнопкой мыши по имени и выберите Пригласить в сообщество, затем нужное сообщество. Человек будет добавлен сразу.

Открытые сообщества

Если сообщество публичное (см. Кто может присоединиться), любой пользователь с аккаунтом на сервере может найти его через Присоединиться к другой команде и присоединиться без приглашения. На сервере, где может зарегистрироваться кто угодно, это самый простой способ вести публичное сообщество. Если сообщество допускает только определённые домены электронной почты, люди с другими адресами не смогут присоединиться, даже по ссылке.

Гости

Гости — это люди извне, например клиенты, подрядчики или партнёрские организации. Гость видит только те каналы, к которым его добавили: он не может просматривать или присоединяться к другим каналам сообщества. Рядом с именем гостя отображается метка Гость, а в шапке канала с гостями это также указано.

  • Аккаунты гостей по умолчанию отключены. Системный администратор включает их в Системная консоль › Аутентификация › Гостевой доступ и может потребовать, чтобы гости использовали определённые домены электронной почты или двухфакторную аутентификацию.
  • Администраторы сообщества приглашают гостей через Пригласить людей, выбирая каналы, доступ к которым они получат. Чтобы позже предоставить гостю доступ к другому каналу, добавьте его в этот канал.
  • Если системный администратор разрешает это, опция Allow invited guests to log in with a magic link (without password) позволяет гостям входить в систему по ссылке, отправленной на электронную почту.
  • Чтобы сделать из гостя полноправного участника или из участника гостя, обратитесь к системному администратору: это делается в Системная консоль › Управление пользователями › Пользователи с помощью Повысить до участника или Понизить до гостя.

Гостей никогда не добавляют в каналы автоматически, даже если все участники сообщества состоят во всех каналах.

Управление участниками

Откройте меню сообщества и выберите Управление участниками (участники видят Просмотр участников). В списке отображаются все участники с указанием их роли. В меню рядом с ролью пользователя вы можете:

  • сделать его администратором сообщества с помощью Сделать администратором команды или отменить это с помощью Сделать участником команды;
  • удалить его из сообщества с помощью Удалить из команды.

Это диалоговое окно происходит из классического интерфейса и по-прежнему использует слово «команда». Вы также можете выполнить действия с пользователем в любом месте, где видите его имя: щёлкните по нему правой кнопкой мыши или откройте его карточку профиля. См. Модерация для режима модератора, временных блокировок и удаления.

По умолчанию в сообществе нет ограничения на количество участников. Если ваш системный администратор установил такое ограничение (Макс. количество участников в сообществе) и приглашения начинают завершаться ошибкой, попросите его увеличить его.

Введение в курс дела

Введение в курс дела приветствует новичков в первый раз, когда они открывают ваше сообщество, как в Discord. Оно отображает приветственный текст и несколько вопросов. Каждый ответ может назначить новичку роли и каналы, чтобы люди с первой минуты находили нужные места.

Создание введения в курс дела

  1. Если ответы должны назначать роли, сначала создайте эти роли и включите для них Доступна всем (см. Роли, доступные всем). Введение в курс дела может назначать только те роли, которые открыты для всех.
  2. Откройте меню сообщества, выберите Настройка команды, затем Онбординг….
  3. Напишите текст Добро пожаловать: о чём сообщество и каковы его основные правила, в нескольких строках.
  4. Выберите Добавить вопрос, например «Что привело вас сюда?». Оставьте включённым Несколько ответов, если участники могут выбрать более одного ответа.
  5. Для каждого ответа напишите его текст, затем щёлкните по ролям и публичным каналам, которые он выдаёт. Выберите Добавить ответ для следующего.
  6. Выберите Сохранить.

Каналы, которые вы можете предложить, — это публичные каналы, участником которых вы являетесь. Чтобы удалить онбординг, удалите его вопросы и текст приветствия, затем сохраните.

Что видят новички

В первый раз, когда кто-то открывает сообщество, появляется диалог Добро пожаловать в с вашим текстом и вопросами. Участники выбирают свои ответы и нажимают Готово или Пропустить. В любом случае они больше не увидят его в этом сообществе. Те, кто присоединился до того, как вы создали онбординг, увидят его в следующий раз, когда откроют сообщество.

Участники могут позже изменить свои открытые роли из меню сообщества, в разделе Ваши роли….

Для публичного сообщества сочетайте онбординг с заблокированной категорией «Информация», содержащей канал правил и канал объявлений, а также баннером вверху канала правил (см. Параметры канала).

Атрибуты участников

Атрибуты участников — это сведения о ваших участниках, которые отображаются на их карточке профиля в вашем сообществе, например компания, сайт, субподрядчик или местоимения. Они принадлежат сообществу: другие сообщества на сервере их не видят.

Определение атрибутов

Откройте меню сообщества, выберите Настройка команды, затем Атрибуты участников… и выберите Добавить атрибут. Для каждого атрибута установите:

  • Имя, например «Компания».
  • Тип: Текст, Вариант, Несколько вариантов, Дата, Ссылка, Электронная почта, Номер телефона, Человек или людей. Для вариантов перечислите Варианты.
  • Кто устанавливает: Каждый участник заполняет его сам, или это делают только Администраторы.
  • Кто видит: Все, Администраторы или Скрытые. Администраторы и сам участник всегда видят его; скрытые атрибуты не отображаются на профилях.
  • Показывать в списке участников: отображает атрибут под именами людей в списке участников, вместо их должности, и позволяет всем фильтровать список по нему. Так может быть показан только один атрибут.

Используйте Переместить вверх и Переместить вниз, чтобы настроить порядок на карточках профилей. В команде может быть не более 50 атрибутов. При удалении атрибута удаляются значения всех участников.

Заполните их

Чтобы установить атрибуты для кого-либо, щёлкните правой кнопкой мыши по имени и выберите Редактировать атрибуты…. Администраторы команды могут устанавливать любые атрибуты для всех участников; участники могут устанавливать только свои, за исключением тех, которые установлены администраторами. Атрибуты, видимые только Администраторам, отображаются на карточке профиля с замком.

В компании атрибут, установленный администраторами и видимый только им, — удобное место для внутренних сведений, например даты окончания контракта, которые коллегам не нужно видеть.

У сервера также есть собственные атрибуты, одинаковые для всех команд, которые системный администратор определяет в Системная консоль › Системные атрибуты › Управление атрибутами. Они отображаются на карточках профилей перед атрибутами вашей команды, и только системные администраторы могут устанавливать их для других. Некоторые из них могут поступать от провайдера входа, например из корпоративного каталога.

Когда участники покидают команду или исключаются из неё

  • Участники покидают команду с помощью Покинуть команду в меню команды.
  • Участники, покинувшие команду или исключённые из неё, теряют свои роли и команды в этом рабочем пространстве. Их сообщения сохраняются.
  • Участник, исключённый из команды, может вернуться по новому приглашению или присоединиться снова, если команда публична. Чтобы навсегда исключить кого-либо, системный администратор должен деактивировать его аккаунт (см. Как не допустить повторного входа).
