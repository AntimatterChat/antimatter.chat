Файл compose сайта также запускает каждый контейнер с no-new-privileges, запускает Antimatter от непривилегированного пользователя на образе distroless, а GIF-сервис — с файловой системой только для чтения. База данных, хранилище и GIF-сервис находятся в сети без доступа в Интернет.

Чек-лист после установки

  1. Создайте первую учетную запись администратора до того, как кто-либо сможет получить доступ к серверу (Установка).
  2. Предоставляйте Antimatter только по HTTPS и установите URL сайта на адрес https:// (Домен и HTTPS).
  3. Обеспечьте, чтобы файлы .env, config.json и TLS-ключи были доступны только для чтения root (или пользователем сервера): chmod 600 .env.
  4. Определите, кто может создавать аккаунты. Оставьте Открытый сервер выключенным, если сообщество не является публичным, и включите Требовать подтверждение адреса электронной почты, когда почта заработает (Вход и аккаунты).
  5. Включите многофакторную аутентификацию и, как минимум, принудительно применяйте ее для учетных записей администраторов, либо используйте ее в вашем поставщике идентификации.
  6. Проверьте внешние соединения ниже, в частности STUN-сервер, который по умолчанию используется для звонков.
  7. Сделайте резервную копию и протестируйте восстановление (Резервные копии и обновления).
  8. Держите образы актуальными: исправления безопасности приходят с новыми образами.

Ограничение частоты запросов

Сервер может ограничивать количество запросов к API, которые делает каждый клиент. По умолчанию эта функция выключена. В Системная консоль › Окружение › Ограничение скорости:

ПараметрКлючЗначение по умолчанию
Включить ограничение скоростиRateLimitSettings.Enableвыключено
Максимальное количество запросов в секундуRateLimitSettings.PerSec10
Максимальное превышение размера пакетаRateLimitSettings.MaxBurst100
Размер хранилища памятиRateLimitSettings.MemoryStoreSize10000 отслеживаемых клиентов
Изменять ограничение скорости по удаленному адресуRateLimitSettings.VaryByRemoteAddrвкл
Изменение ограничения скорости пользователяRateLimitSettings.VaryByUserвыключено
Изменять ограничение скорости по HTTP заголовкуRateLimitSettings.VaryByHeaderпусто

За прокси-сервером ограничения по адресу работают только в том случае, если сервер знает адрес каждого клиента (ServiceSettings.TrustedProxyIPHeader и ServiceSettings.TrustedProxyIPs, см. Адреса клиентов за прокси). Иначе все запросы выглядят как исходящие от прокси, и все пользователи делят один лимит. То же самое касается фильтрации по IP и адресов в журналах аудита.

Попытки входа ограничиваются отдельно: Максимальное количество попыток входа (10) блокирует аккаунт после такого количества неудачных попыток ввода пароля.

Фильтрация по IP

Системная консоль › Настройки сайта › IP-фильтрация ограничивает доступ к серверу по IP-адресу с помощью правил разрешения и запрета (адрес или диапазон CIDR). Если Включить фильтрацию IP-адресов включено, пользователи, чей адрес соответствует правилу запрета, или которым не соответствует ни одно правило разрешения (если такие правила есть), не могут получить доступ к серверу. Страница отклоняет правила, которые блокируют ваш собственный адрес. Если вы используете прокси, сначала настройте адреса клиентов (Адреса клиентов за прокси), иначе все запросы будут казаться исходящими от прокси.

Игнорирование, блокировка и запросы на сообщения

Если Включить игнорирование, блокировку и запросы сообщений включено (по умолчанию), пользователи могут игнорировать и блокировать друг друга, а также могут настроить получение личных сообщений от незнакомых людей в виде запросов, которые не отправляют уведомлений до их принятия. Это подходит для публичных сообществ. На рабочем месте, где коллеги должны всегда иметь возможность связаться друг с другом, отключите эту функцию (AM_PRIVACYSETTINGS_ENABLEUSERBLOCKING=false): ни одно из этих правил больше не будет применяться, но списки и сделанные пользователем выбор сохранятся и снова вступят в силу, если вы включите функцию обратно.

Сессии и токены

  • Длительность сессий и тайм-аут бездействия: см. Вход и учетные записи. Более короткие сессии означают, что украденный ноутбук или телефон останется в состоянии входа меньшее время.
  • Включить Персональные токены доступа (ServiceSettings.EnableUserAccessTokens, выключено) позволяет пользователям создавать токены API; Максимальный срок действия персонального токена доступа (дней) ограничивает их срок действия. Обе настройки находятся в Системная консоль › Интеграции › Управление интеграцией.
  • Чтобы разом завершить все сеансы, например после предполагаемого нарушения безопасности: Сбросить все сеансы в Системная консоль › Управление пользователями › Пользователи.

Соединения с внешними службами

Antimatter не связывается ни с одной службой, управляемой Mattermost, Inc. Он не отправляет телеметрию, отчеты об ошибках или запросы проверки обновлений безопасности, а также не получает уведомления о продукте. Конфигурация, перенесенная из Mattermost, которая все еще содержит ссылки на службы Mattermost (службы push-уведомлений, маркетплейс приложений, уведомления или STUN-сервер для звонков), не приводит к тому, что сервер будет с ними связываться: эти адреса игнорируются.

Сервер и приложения связываются с другими внешними службами только для тех функций, которые этого требуют, а также с теми службами, которые вы настроили:

ФункцияСвязиПо умолчанию
Звонки: поиск публичных адресов с помощью STUN. Сервер и каждый участник звонка отправляют запрос, который показывает STUN-серверу их IP-адрес и порт.Публичный STUN-сервер Cloudflare, stun.cloudflare.comвключён, если приложение «Звонки» активно. Чтобы изменить это, см. Звонки.
Предпросмотр ссылок: сервер запрашивает страницы, на которые ссылаются сообщения (Включить предпросмотр веб-ссылок, ServiceSettings.EnableLinkPreviews)веб-сайты, на которые ссылаются пользователивключён. Отключите с помощью AM_SERVICESETTINGS_ENABLELINKPREVIEWS=false.
Push-уведомления в мобильное приложениеваш собственный push-прокси (Push-уведомления)выключен, пока вы не укажете его адрес
Удалённый маркетплейс приложений (PluginSettings.EnableRemoteMarketplace)указанный вами URL магазина плагиноввыключен, адрес не задан
Электронная почтаваш SMTP-серверпо умолчанию используется сервер localhost
Единый вход, модели ИИ, распознавание речи и перевод, исходящие вебхуки, а также приложения, такие как Почта, Календарь, GitHub, GitLab или Jiraуслуги, которые вы настроитевыключены, пока вы их не настроите

По умолчанию сервер отказывается устанавливать соединения с внутренними и локальными адресами для этих целей (предпросмотр ссылок, вебхуки, приложения), чтобы сообщения или интеграции не могли быть использованы для доступа к вашей внутренней сети. Перечислите внутренние хосты, к которым разрешено подключение, в Разрешить недоверенные внутренние соединения для (ServiceSettings.AllowedUntrustedInternalConnections, в Системная консоль › Окружение › Разработчик); в compose-файле сайта там указан gifs.
