Политика конфиденциальности

Последнее обновление: 16 октября 2026 г.

Эта страница описывает два аспекта: программное обеспечение Antimatter, которое организации размещают на собственных серверах, и этот веб-сайт, antimatter.chat.

Программное обеспечение Antimatter

Antimatter размещается на собственных серверах. При использовании сервера Antimatter организация, которая им управляет, решает, какие данные хранятся, как долго и кто имеет к ним доступ. Проект Antimatter не имеет доступа к вашему серверу, вашему аккаунту или вашим сообщениям. По вопросам, касающимся ваших данных на конкретном сервере, обращайтесь к его администраторам; к ним применяется их собственная политика конфиденциальности.

Что делает ПО самостоятельно:

  • Нет телеметрии. Сервер не отправляет статистику использования, диагностические данные или какую-либо другую информацию в проект Antimatter, в Mattermost, Inc. (на ПО которого основан Antimatter) или другим третьим лицам.
  • Соединения с внешними сервисами — только для функций, которые администратор включает вручную, а именно для тех сервисов, которые он настраивает: например, для сервиса push-уведомлений, провайдера GIF, почтового сервера, провайдера идентификации для единого входа или моделей ИИ, распознавания речи или перевода.
  • Два исключения, включенные по умолчанию, которые администраторы могут отключить. Предпросмотр ссылок: когда кто-то публикует ссылку, сервер запрашивает эту страницу, чтобы отобразить её заголовок и изображение. И звонки: они используют публичный STUN-сервер Cloudflare (stun.cloudflare.com) для определения публичных сетевых адресов. Сервер обращается к нему при запуске приложения «Звонки», а устройство каждого участника — при присоединении к звонку. Cloudflare видит только IP-адрес и порт сервера и каждого присоединяющегося участника, но не сам звонок. Администраторы могут использовать собственный STUN-сервер или вообще не использовать его; см. Звонки и голосовые каналы.
  • Функции ИИ используют модели, выбранные администратором. Если они размещаются третьей стороной, то то, что отправляется им (сообщение для переписывания, разговор для суммирования, аудиозапись транскрибированного звонка), уходит этому провайдеру. Администраторы могут использовать собственные модели, чтобы никакие данные не покидали их сеть.

Этот веб-сайт

  • antimatter.chat — это статический сайт, размещенный на GitHub Pages.
  • Сайт не устанавливает файлы cookie и не использует аналитику, трекеры или рекламу. Шрифты и изображения загружаются с самого сайта, поэтому во время чтения браузер не обращается к другим веб-сайтам.
  • Как и любой веб-хостинг, GitHub получает ваш IP-адрес и запрашиваемые вами страницы, чтобы предоставить их. См. Политику конфиденциальности GitHub.
  • Если вы создадите проблему (issue) или внесёте вклад на GitHub, всё, что вы там публикуете, является публичным и обрабатывается GitHub в соответствии с его условиями.

Контакты

По вопросам, касающимся этой политики, создайте проблему (issue) в репозитории сообщества Antimatter.

Мы можем обновить эту политику; дата вверху страницы указывает, когда она была изменена в последний раз.
