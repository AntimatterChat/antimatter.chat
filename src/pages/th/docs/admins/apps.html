แอปท่ีเปิิดใช้งานโดยพื้้นฐานจะถูกรบัรองท่ีแต้่ละคร้ังท่ีเปิิดใช้งานถ้้ายังไม่ไดร้บัรอง, หรืออัปเกรดถ้้า image มีเวอร์ชั่ันท่ีใหม่กว่่า. ถ้้าคุณปิิดใช้งานแอปใด, ท่ีจะคงปิิดอย่ี: พื้้นฐานน้ีประยกตต์ิ์ใชก้บัแอปท่ีการตั้่งค่ายังไม่ไดร้บัรอง. แอปท่ีคง id ของ Mattermost (เอเจนต์, การโทร, Kanban, Playbooks และระบบเชื่่อมต่อ) เป็นเวอร์ชั่ันท่ี Antimatter สร้างเอง

เปิิด, ปิิด และตั้่งค่าแอป

ไปท่ี คอนโซลระบบ › ปลั๊กอิน › การจัดการปลั๊กอิน. ใต้ ปลั๊กอินท่ีตดิตั้่ง, แอปแต้่ละแอปมมีี เปิิดใช้งาน หรือ ปิิดใช้งาน, การตั้่งค่า และ นำออก, และแสดงสถานะ (กำลงั รัน, ไม่กำลงั รัน, ล้มเหลอ้ในการเปิิดใช้งาน…). แอปแต้่ละแอปท่ีมกีีารตั้่งค่ามมีีหน้้าของท่ีอย่ีใต้ คอนโซลระบบ › ปลั๊กอิน

แอปท่ีรวมมาให้ท่ีปิิดใช้งานโดยพื้้นฐานจะถูกรบัรองจากสำเนาของ image เอง: เปิิด App Marketplace จากเมนูของผลติภัณ, ค้้นหาแอปและคลิก ตดิตั้่ง, แล้้วเปิิดใช้งานในการจัดการปลั๊กอิน. จากบรรดาสั่่ง:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

คำสั่่งอ่น: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

เปิิดใช้งานแอปผ่่านการตั้่งค่า

แอปท่ีใดเปิิดใช้งานคือการตั้่งค่า PluginSettings.PluginStates, map ของ app ids. คุณสามารถรวมรายการเข้่าในน้ีด้วย amctl; ด้วย เปิิดใช้งานปลั๊กอินท่ีแพ็คมาให้อัตโนมัติ เปิิด (พื้้นฐาน), แอปท่ีรวมมาให้ท่ีเปิิดใช้งานจะถูกรบัรองท่ีคร้ังท่ีเปิิดใช้งานท่ีตอ่ไป:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

น้ีเป็นวิธีท่ีจะตดิตั้่ง Todo, ท่ีไม่ไดร้บัรองในหน้้าของ Marketplace. ตัวแปร AM_PLUGINSETTINGS_PLUGINSTATES ก้ทัง้ใชไ้ด้, แต่มันจะแทนท่ี map ท้ังหมด: รบัรองแอปท้ังหมดท่ีคุณต้อ้งการเปิิดใช้งาน

การตั้่งค่าของแอป

การตั้งค่าแอปถูกเก็บไว้ภายใต้ PluginSettings.Plugins.<app id> โดยใช้คีย์ตัวพิมพ์เล็ก คุณสามารถเปลี่ยนค่าเหล่านี้ในหน้า System Console ของแอป หรือใช้ amctl config patch ตามที่แสดงใน การตั้งค่า AM_PLUGINSETTINGS_PLUGINS จะแทนที่การตั้งค่าของทุกแอปพร้อมกันและล็อกค่าทั้งหมดไว้ ดังนั้นควรหลีกเลี่ยงการใช้อย่าใช้

GIF

แอป GIFs เพิ่มแท็บ GIF และสติกเกอร์ลงในตัวเลือกอิโมจิ โดยทำงานร่วมกับบริการ GIF ของ Antimatter (gifs-server) ซึ่งใช้ Tenor API ไฟล์ compose ของไซต์จะรันบริการและตั้งค่าแอปผ่านตัวแปร การตั้งค่าของแอปใน คอนโซลระบบ › ปลั๊กอิน › GIF:

การตั้งค่าตัวแปร (ค่าเริ่มต้น)ค่าเริ่มต้นสิ่งที่ทำ
URL ของบริการ GIFAM_GIFS_SERVICE_URLว่างAPI base ของบริการ ตัวอย่างเช่น http://gifs:8080/v2 การเลือก GIF จะถูกปิดใช้งานหากฟิลด์นี้ว่างเปล่า
API keyAM_GIFS_API_KEYว่างหนึ่งใน AM_GIFS_API_KEYS ของบริการ
คีย์สำหรับอัปโหลดAM_GIFS_UPLOAD_KEYว่างหนึ่งใน AM_GIFS_UPLOAD_KEYS ของบริการ อนุญาตให้ผู้ใช้เพิ่ม GIF และสติกเกอร์ หากว่างเปล่า การอัปโหลดจะถูกปิด
ใครสามารถเพิ่ม GIF และสติกเกอร์ได้ผู้ดูแลระบบเฉพาะผู้ดูแลระบบ หรือทุกคน
เปิดใช้งานสติกเกอร์เปิดแสดงแท็บสติกเกอร์
ตัวกรองเนื้อหาปานกลางสูง, ปานกลาง, ต่ำ หรือปิด
ให้บริการสื่อผ่าน Antimatterเปิดเบราว์เซอร์จะโหลด GIF จาก Antimatter ซึ่งจะไปดึงข้อมูลจากบริการ 应保持เปิดใช้งานเมื่อบริการอยู่เฉพาะบนเครือข่ายภายใน
URL ของสื่อ/media/ ของบริการตำแหน่งของสื่อ เมื่อให้บริการโดยตรง
ขนาดแคช (MB)64 MBแคชหน่วยความจำของแอป

สำหรับแอปนี้ ตัวแปรเป็นเพียงค่าเริ่มต้น: ค่าที่ตั้งไว้ในคอนโซลระบบจะมีผลเหนือกว่าตัวแปรเหล่านั้น หากตัวเลือกรูป GIF ว่างเปล่า ให้ตรวจสอบ URL ของบริการและ API key ในหน้านั้น

เมื่อตั้งค่าแอป GIFs แล้ว แท็บของมันจะแทนที่ตัวเลือกรูป Giphy ในตัว (คอนโซลระบบ › อินทิเกรชัน › GIF › เปิดใช้งานตัวเลือก GIF, ServiceSettings.EnableGifPicker)

บริการ GIF

บริการจะเก็บทุกอย่างไว้ในไดเรกทอรีข้อมูล (/data, โวลุ่ม gifs): ดัชนีการค้นหาและสื่อ ตัวแปรหลักของมัน:

ตัวแปรค่าเริ่มต้นสิ่งที่ทำ
AM_GIFS_API_KEYSไม่มีคีย์ API ที่คั่นด้วยเครื่องหมายจุลภาค หากไม่มีคีย์ API จะเปิดกว้างสำหรับทุกคนที่เข้าถึงได้ การใช้คีย์หลายตัวช่วยให้คุณสามารถหมุนเวียนคีย์ได้
AM_GIFS_UPLOAD_KEYSไม่มีคีย์ที่อนุญาตให้อัปโหลด ไม่สามารถอัปโหลดได้หากไม่มีคีย์
AM_GIFS_RATE_LIMIT20จำนวนคำขอต่อวินาทีต่อไคลเอนต์ (API key และที่อยู่); 0 ปิดใช้งาน ไฟล์ compose ตั้งค่าเป็น 0 เนื่องจากคำขอทั้งหมดของ Antimatter ใช้คีย์และที่อยู่เดียวกัน
AM_GIFS_LISTEN:8080ที่อยู่สำหรับรับฟัง
AM_GIFS_PUBLIC_URLจากคำขอURL ภายนอก หากคุณเปิดให้บริการ
AM_GIFS_TRUST_PROXYfalseเชื่อถือเฮดเดอร์ X-Forwarded-* เฉพาะเมื่ออยู่เบื้องหลังพร็อกซีเท่านั้น
AM_GIFS_UPLOAD_MAX_MB16ขนาดไฟล์ที่อัปโหลดได้สูงสุด

เพื่อเพิ่ม GIF ของคุณเองเป็นจำนวนมาก ให้นำเข้าโดยใช้ manifest จากไดเรกทอรีที่ mount เข้าไปในคอนเทนเนอร์แบบใช้ครั้งเดียว:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

เพื่อทำการนำเข้าสติ๊กเกอร์เริ่มต้นอีกครั้งหลังการอัปเกรด: docker compose run --rm gifs stickers รูปแบบของ manifest และคำสั่งอื่น ๆ อยู่ใน README ของ gifs-server

อีเมลและปฏิทิน

อีเมลและปฏิทินจะเชื่อมต่อแต่ละบุคคลเข้ากับกล่องจดหมาย (IMAP และ SMTP) และปฏิทิน (CalDAV) ของพวกเขาเอง ผู้ใช้จะกรอกรหัสผ่านและเซิร์ฟเวอร์ในแอป; รหัสผ่านจะถูกเก็บไว้แบบเข้ารหัส คุณไม่ต้องตั้งค่าเซิร์ฟเวอร์อีเมลหรือปฏิทินให้พวกเขา แต่คุณเป็นผู้กำหนดว่าพวกเขาสามารถเชื่อมต่อได้กับอะไรบ้าง:

แอปการตั้งค่าค่าเริ่มต้นสิ่งที่ทำ
อีเมล, ปฏิทินอนุญาตเซิร์ฟเวอร์อีเมลบนเครือข่ายส่วนตัว, อนุญาตเซิร์ฟเวอร์ปฏิทินบนเครือข่ายส่วนตัว (AllowPrivateNetworks)ปิดเมื่อปิดอยู่ เซิร์ฟเวอร์จะปฏิเสธการเชื่อมต่อไปยังที่อยู่ loopback, ส่วนตัว และ link-local เพื่อป้องกันไม่ให้แอปถูกใช้เพื่อเข้าถึงเครือข่ายภายในของคุณ เปิดใช้งานนี้หากเซิร์ฟเวอร์อีเมลหรือปฏิทินของคุณอยู่ที่ที่อยู่ส่วนตัว
อีเมล, ปฏิทินอนุญาตการเชื่อมต่อที่ไม่มีการเข้ารหัส (AllowInsecureConnections)ปิดเมื่อปิดอยู่ การเชื่อมต่อต้องใช้ TLS (อีเมล: TLS หรือ STARTTLS; ปฏิทิน: HTTPS)
อีเมลช่วงเวลาตรวจสอบข้อความที่ยังไม่ได้อ่าน (นาที) (UnreadCheckMinutes)2 นาทีความถี่ในการตรวจสอบจำนวนข้อความที่ยังไม่ได้อ่าน เมื่อเซิร์ฟเวอร์อีเมลไม่สามารถส่งการแจ้งเตือนแบบ push ได้
อีเมลขนาดข้อความสูงสุด (MB) (MaxMessageSizeMB)25 MBขีดจำกัดขนาดของข้อความที่ส่งและอ่าน
ปฏิทินส่งการแจ้งเตือน (EnableReminders)เปิดบอทปฏิทินจะส่งข้อความส่วนตัวก่อนกิจกรรม (10 นาทีก่อน สำหรับกิจกรรมที่ไม่มีเสียงเตือนเป็นของตัวเอง)

เพื่อให้ผู้ใช้สามารถเข้าสู่ระบบกล่องจดหมาย Gmail หรือ Microsoft 365 ด้วยบัญชีของพวกเขาแทนรหัสผ่าน ให้สร้าง OAuth client และกรอกช่อง Google หรือ Microsoft ในแอปอีเมล:

  • Google: Web OAuth client ที่ใช้ Gmail API และ scope https://mail.google.com/
  • Microsoft: แอป Entra ID ที่มีสิทธิ์แบบ delegated IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email และ profile โดยค่าเริ่มต้น tenant คือ common
  • ในทั้งสองกรณี redirect URI คือ https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (URL ของเว็บไซต์คุณ)

Kanban, โน้ต, ไวท์บอรด์, โพล และเพลย์บุ๊ก

  • Kanban (focalboard) อยู่ที่ /kanban (ลิงก์เก่า /boards จะถูกเปลี่ยนเส้นทางไปที่นั่น) การตั้งค่าเพียงอย่างเดียวคือ เปิดใช้งานบอรด์ที่แชร์สาธารณะ (EnablePublicSharedBoards, ปิดอยู่) ซึ่งอนุญาตให้ผู้แก้ไขบอรด์สามารถแชร์บอรด์กับทุกคนที่มีลิงก์ โดยไม่ต้องลงชื่อเข้าใช้
  • โน้ต และ โพล ไม่มีข้อการตั้้งค่า
  • ไวท์บอรด์: ผู้ดู้แลระบบสามารถอัปโหลดไลบรารีรูปร่าง (ไฟล์ Excalidraw .excalidrawlib, ไม่เกิน 5 MB ต่อไฟล์) สำหรับเซิร์ฟเวอร์ทั้่งหมดในหน้้าการตั้้งค่า ผู้ดู้แลชุมชนสามารถจัดการไลบรารีของชุมชนตนเองได้
  • เพลย์บุ๊ก มีข้อการตั้้งค่าอยู่บ้าง ส่วนใหญ่เป็นคุณลักษณะทดลองใช้; ค่าเริ่มต้นเหมาะสำหรับเซิร์ฟเวอร์ส่วนใหญ่
  • Memes: ใครสามารถเพิ่มเทมเพลตมีมได้ (ทุกคนโดยค่าเริ่มต้น หรือเฉพาะผู้ดู้แลระบบ)
  • สืน่่งท่ีต้อ้งทำ ไม่มีข้อการตั้้งค่าของเซิร์ฟเวอร์

ปิด ใช้แอปพลิเคชัน OAuth ท่ีจดทะเบียนไว้แล้้ว ในแอป GitHub และ GitLab: มันพึ่งพาสารวั่่งของ Mattermost ท่ี Antimatter ไม่มี และแอปจะปฏิเสธการเริ่มทำงานหากเปิดอยู่ จดทะเบียนแอปพลิเคชัน OAuth ของคุณเอง

แอป GitHub และ GitLab จะสร้างคีย์ลับเว็บฮุคและคีย์เข้ารหัสเมื่อบันทึกครั้่งแรก แอป GitHub สามารถจำกัดให้อยู่ในองค์กร (GithubOrg) และแอป GitLab สามารถจำกัดให้อยู่ในกลุ่่ม (GitlabGroup); สำหรับ GitHub Enterprise หรือ GitLab ท่ีโฮสต์เอง ให้ตั้้งค่า URL ฐานของมัน

ตัวชี้วัด

แอป Metrics รวบรวมเมตริกสมรรถนะของเซิร์ฟเวอร์เข้าสู่อฐานข้อมูลอนุกรมเวลาขนาดเล็กภายใน Antimatter เพื่อให้คุณสามารถดาวน์โหลดหรือรวมไว้ในแพ็กเก็ตสนับสนุนได้โดยไม่ต้องรัน Prometheus เมื่อมันเริ่มทำงาน มันจะเปิดใช้งานจุดปลายเมตริกของเซิร์ฟเวอร์ (MetricsSettings.Enable) ดู การปฏิบัติการ

การติดตั้งแอปอื่น

Antimatter รันแอปของ Mattermost (ปลั๊กอิน) มีสามวิธีในการเพิ่มแอปหนึ่่ง:

  • จาก Remote Marketplace เปิดใช้งาน Remote Marketplace (PluginSettings.EnableRemoteMarketplace) จะปิดอยู่โดยปริยาย และ URL ของ Marketplace (PluginSettings.MarketplaceURL) จะว่างเปล่า: Antimatter ไม่ใช้ Marketplace ของ Mattermost และจะเพิกเฉยต่อที่อยู่ของมันหากการตั้งค่าจาก Mattermost ยังมีอยู่ เพื่อแสดงรายการแอปของเซิร์ฟเวอร์ Marketplace ที่คุณเชื่อถือ ให้เปิดการตั้งค่านี้และกำหนด URL ของมัน การสร้าง (builds) ของแอปที่ Antimatter จัดส่ง (Calls, Playbooks, Kanban และแอปอื่นๆ) จาก Marketplace นั้นจะถูกซ่อนไว้ จึงไม่สามารถแทนที่ของ Antimatter ได้: อนุญาตให้ Marketplace สร้างปลั๊กอินของ Antimatter (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) จะปิดอยู่โดยปริยาย
  • โดยอปัปลอดไฟล์รวม (bundle) (.tar.gz) การอปัปลอดจะปิดอยู่โดยปริยายและไม่มีสวิตช์ในคอนโซลระบบ: ให้ตั้งค่า AM_PLUGINSETTINGS_ENABLEUPLOADS=true จากนั้นใช้ อปัปลอดปลั๊กอิน ในส่วนจัดการปลั๊กอิน หรือใช้คำสั่ง amctl --local plugin add app.tar.gz
  • จาก URL: amctl plugin install-url <url> ซึ่งต้องเปิดการอปัปลอดไว้ด้วย

Antimatter จะตรวจสอบลายเซ็นของแอปเทียบกับคีย์ที่เชื่อถือได้: คีย์ของ Antimatter, คีย์ที่ Mattermost, Inc. ใช้ลงลายเซ็นแอปที่เผยแพร่ (ดังนั้นแอป Mattermost ที่คุณดาวน์โหลดเองจะติดตั้งได้) และคีย์ใดๆ ที่คุณเพิ่มใน PluginSettings.SignaturePublicKeyFiles เมื่อเปิด กำหนดให้ปลั๊กอินต้องมีลายเซ็น (PluginSettings.RequirePluginSignature, ปิดอยู่โดยปริยาย) แอปที่ไม่มีลายเซ็นจะถูกปฏิเสธและการอปัปลอดจะถูกปิด

แอปจะทำงานภายในเซิร์ฟเวอร์โดยมีสิทธิ์เข้าถึงข้อมูลทั้งหมด ติดตั้งเฉพาะแอปที่คุณเชื่อถือเท่านั้น

แอปบางตัวที่สร้างสำหรับเวอร์ชันเสียเงินของ Mattermost จะตรวจสอบใบอนุญาต (licence) ของ Mattermost ด้วยตนเองและปฏิเสธการทำงาน; Antimatter จะไม่แสร้งว่ามีใบอนุญาตสำหรับแอปเหล่านั้น
