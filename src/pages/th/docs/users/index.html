สิ่งที่อยู่ในคู่มือนี้

Antimatter เป็นพื้นที่สำหรับพูดคุยกับทีมหรือชุมชนของคุณ: ในช่อง, ในบทสนทนาส่วนตัว, ในการโทร, และด้วยแอปเช่นโน้ตและไวท์บอร์ดที่แชร์ร่วมกัน หน้าต่างของคู่มือนี้อธิบายวิธีการทำแต่ละอย่างทีละขั้นตอน:

  • การเขียนข้อความ: การจัดรูปแบบ, เมนชัน, อีโมจิ, การตอบกลับและเธรด, การแก้ไข, ฉบับร่าง, การกำหนดเวลา และอื่น ๆ
  • ชุมชนและช่อง: การเข้าร่วม, การจัดระเบียบแถบด้านข้าง, ข้อความส่วนตัวและข้อความกลุ่ม
  • การโทรและช่องเสียง: การพูด, การแชร์หน้าจอ, คำบรรยาย
  • แอป: โน้ต, ไวท์บอร์ด, บอร์ด Kanban, ปฏิทิน, อีเมล, โพล, รายการสิ่งที่ต้องทำ และอื่น ๆ
  • เอเจนต์ AI: สรุป, การเขียนใหม่ และการถามคำถาม เมื่อเซิร์ฟเวอร์ของคุณมี
  • การแจ้งเตือนและสถานะ: สิ่งที่คุณจะได้รับ และเมื่อไหร่
  • โปรไฟล์และความเป็นส่วนตัว: โปรไฟล์ของคุณ, ใครสามารถส่งข้อความให้คุณได้, การบล็อก, และความมั่นคงปลอดภัยของบัญชีของคุณ
  • การค้นหาและการค้นหาสิ่งต่าง ๆ: การค้นหา, เมนชัน, ข้อความที่บันทึกไว้ และข้อความที่ยังไม่ได้เปิดอ่าน
  • การตั้งค่าและทางลัด: ธีม, ภาษา และทางลัดคีย์บอร์ด

เซิร์ฟเวอร์ Antimatter แต่ละเซิร์ฟเวอร์ดำเนินการโดยผู้ดูแลระบบของตนเอง ซึ่งเลือกเปิดใช้งานฟีเจอร์และแอปใดบ้าง หากสิ่งใดในคู่มือนี้อาจไม่ปรากฏให้คุณเห็น นั่นอาจเป็นเพราะไม่ได้เปิดใช้งานในเซิร์ฟเวอร์ของคุณ: ถามผู้ดูแลระบบของคุณ

เข้าสู่ระบบ

Antimatter ไม่มีเว็บไซต์กลางสำหรับเข้าสู่ระบบ: องค์กรหรือชุมชนแต่ละแห่งดำเนินการเซิร์ฟเวอร์ของตนเอง โดยมีที่อยู่ของตนเอง เช่น chat.example.com ผู้ดูแลระบบของคุณ หรือผู้ที่เชิญคุณ จะให้ที่อยู่ดังกล่าวแก่คุณ

  1. เปิดที่อยู่ดังกล่าวในเว็บเบราว์เซอร์ของคุณ หรือเพิ่มลงในแอปเดสก์ท็อปหรือมือถือ (ดู แอปเดสก์ท็อปและมือถือ)
  2. ในหน้าเข้าสู่ระบบบัญชีของคุณ ให้กรอกอีเมลหรือชื่อผู้ใช้งานและรหัสผ่าน จากนั้นคลิกเข้าสู่ระบบ หากองค์กรของคุณใช้ระบบเข้าสู่ระบบของตัวเอง ให้คลิกปุ่มของระบบนั้นแทน ซึ่งอยู่ใต้ข้อความ "or log in with"
  3. หากคุณเปิดใช้งานการยืนยันตัวตนหลายปัจจัย (multi-factor authentication) ให้กรอกรหัสจากแอปยืนยันตัวตนของคุณ

หากคุณได้รับลิงก์เชิญ ให้เปิดลิงก์นั้นเพื่อสร้างบัญชีของคุณ โดยกรอกอีเมล ชื่อผู้ใช้งาน และรหัสผ่าน จากนั้นคลิกสร้างบัญชี หากคุณลืมรหัสผ่าน? ให้คลิกที่ข้อความดังกล่าวและกรอกอีเมลของคุณ: คุณจะได้รับลิงก์สำหรับตั้งรหัสผ่านใหม่

ชุมชนบางแห่งมีคำถามต้อนรับสมาชิกใหม่ ซึ่งคำตอบจะกำหนดบทบาทและช่องที่คุณมีสิทธิ์เข้าถึง คุณสามารถตอบคำถามเหล่านั้นหรือคลิกข้าม

หน้าต่าง

หน้าต่างของ Antimatter มีห้าคอลัมน์ จากซ้ายไปขวา

  1. แถบชุมชน (community rail) ด้านซ้ายสุด: ไอคอนวงกลมหนึ่งตัวสำหรับแต่ละชุมชนที่คุณเป็นสมาชิก จุดหมายถึงข้อความที่ยังไม่ได้ อ่าน ตัวเลขแสดงจำนวนการเมนชันของคุณ ใต้ไอคอน เพิ่มทีม (+) ช่วยให้คุณเข้าร่วมหรือสร้างชุมชนใหม่ ด้านล่างสุดคือรูปภาพของคนที่ส่งข้อความส่วนตัวใหม่ให้คุณ และ ค้นหาทุกอย่าง (ไอคอนแว่นขยาย)
  2. แถบด้านข้าง (sidebar): ชื่อชุมชนปัจจุบัน ซึ่งเมื่อคลิกจะเปิดเมนูของชุมชนนั้น จากนั้นคือช่องต่างๆ ที่จัดกลุ่มตามหมวดหมู่ ด้านล่าง การสนทนาที่เปิดอยู่ แสดงข้อความส่วนตัวล่าสุดของคุณ; ไอคอนฟองคำพูดข้างๆ (ข้อความส่วนตัวทั้้่งหมด) แสดงข้อความส่วนตัวทั้งหมด รวมถึงการเมนชัน เธรดที่คุณติดตาม ข้อความที่บันทึกไว้ ฉบับร่าง และโน้ตสำหรับตัวเอง
  3. การสนทนา: ข้อความของช่องหรือการสนทนาที่คุณเปิด พร้อมกล่องข้อความด้านล่าง ส่วนหัวจะแสดงชื่อ (คลิกเพื่อดูข้อมูลของช่อง) ข้อความหัวเรื่องสั้นๆ กล่องค้นหา และปุ่มสำหรับการโทร การดูการเมนชัน ข้อความที่บันทึกและปักหมุด ไฟล์ และปุ่มแสดงรายชื่อสมาชิก
  4. แผงด้านขวา: สมาชิกของช่อง หรือเมื่อคุณเปิด เธรด ผลการค้นหา หรือแอป กด Esc เพื่อปิดแผง
  5. แถบแอป (app rail) ขอบด้านขวา: รูปภาพของคุณด้านบน ซึ่งเมื่อคลิกจะเปิดสถานะและการตั้่งค่าของคุณ; ไอคอนของแอปต่างๆ; และด้านล่างสุดคือเมนู เกี่่ยวกับ Antimatter

เมื่อคุณอยู่ในสายการโทร แผงควบคุมการโทร จะปรากฏที่ด้านล่างของแถบด้านข้าง พร้อมปุ่มสำหรับปิดเสียง แชรหน้าจอ หรือออกจากการโทร: ดู แผงควบคุมการโทร

บนหน้าจอขนาดเล็ก

ในหน้าต่างที่แคบหรือบนเบราว์เซอร์ของโทรศัพท์ แถบด้านข้างจะกลายเป็นลิ้นชัก แตะ เปิดการนำทาง ที่มุมบนซ้าย หรือปัดไปทางขวา เพื่อดูชุมชนและช่อง ปัดไปทางซ้ายเพื่อดูรายชื่อสมาชิกและแอป กดค้างบนข้อความเพื่อเปิดเมนูของมัน

ขั้นตอนแรก

  1. ตั้งค่าโปรไฟล์ของคุณ: เพิ่มรูปภาพและตรวจสอบชื่อของคุณ เพื่อให้ผู้คนจดจำคุณได้ ดู แก้ไขโปรไฟล์ของคุณ
  2. อนุญาตการแจ้งเตือน เมื่อเบราว์เซอร์ของคุณถาม เพื่อให้คุณรู้ว่าเมื่อใดที่ใครบางคนต้องการคุณ ดู การแจ้งเตือน
  3. เข้าร่วมช่อง ที่คุณสนใจ: เปิดเมนูชุมชน (คลิกชื่อชุมชน) และเลือก เรียดดูช่อง ดู ค้นหาและเข้าร่วมช่อง
  4. ทักทาย: คลิกที่ช่อง พิมพ์ในกล่องข้อความด้านล่าง และกด Enter
  5. ส่งข้อความถึงใครบางคนโดยตรง: คลิกชื่อของพวกเขา จากนั้นเลือก ข้อความ

เพื่อไปที่ใดก็ได้อย่างรวดเร็ว กด Ctrl+K (⌘+K บน Mac) และพิมพ์ตัวอักษรบางส่วนจากชื่อช่อง ชื่อคน หรือข้อความ

การขอความช่วยเหลือ

คลิกโลโก้ Antimatter ที่ด้านล่างของแถบแอปเพื่อเปิด เกี่ยวกับ Antimatter ภายใต้ ความช่่วยเหลื่อ:

  • คู่มือผู้ใช้ เปิดความช่วยเหลือในตัวเกี่ยวกับข้อความ การส่ง การจัดรูปแบบ เมนชัน ไฟล์ และคำสั่ง
  • คีย์ลัด แสดงรายการคีย์ลัดทั้งหมด
  • คู่มือการจัดรูปแบบ อธิบายวิธีการจัดรูปแบบข้อความ
  • รายงานปัญหา เมื่อผู้ดูแลระบบของคุณตั้งค่าไว้ จะแจ้งปัญหาให้พวกเขาทราบ

เมนูเดียวกันยังแสดง ผลิตภัณฑ์ ที่เปิดเป็นหน้าเต็ม เช่น Kanban และ Playbooks ปุ่ม ? ในแถบจัดรูปแบบของกล่องข้อความยังเปิดความช่วยเหลือได้เช่นกัน สำหรับสิ่งใดก็ตามเกี่ยวกับบัญชีของคุณหรือเซิร์ฟเวอร์ของคุณ ให้ถามผู้ดูแลระบบของคุณ

แอปเดสก์ท็อปและมือถือ

คุณสามารถใช้ Antimatter ในเบราว์เซอร์เว็บรุ่นล่าสุดใดก็ได้ นอกจากนี้ยังมีแอปสำหรับคอมพิวเตอร์และโทรศัพท์ของคุณ

การเปิดตัวครั้งแรกของแอปเดสก์ท็อปและมือถือกำลังอยู่ในระหว่างเตรียมการ จนกว่าจะเผยแพร่ ให้ใช้ Antimatter ในเบราว์เซอร์เว็บของคุณ รวมถึงบนโทรศัพท์ของคุณ

แอปเดสก์ท็อป

แอปเดสก์ท็อปทำงานบน Windows, macOS และ Linux แสดงหน้าต่างเดียวกับเบราว์เซอร์ และเพิ่มฟีเจอร์บางอย่าง: การแจ้งเตือนโดยไม่ต้องถามเบราว์เซอร์, ป้ายจำนวนข้อความที่ยังไม่ได้อ่านบนไอคอน, ปุ่ม กลับ และ ไปข้างหน้า ที่ด้านบนของแถบชุมชน, ตัวเลือกการแชร์หน้าจอสำหรับแอปเองในการโทร และหลายเซิร์ฟเวอร์ในแอปเดียว

  1. เปิดแอป หลังจากหน้าต้อนรับ ให้คลิก เริ่มต้นใช้งาน
  2. ใน เชื่อมต่อเซิร์ฟเวอร์ของคุณ พิมพ์ URL เซิร์ฟเวอร์ ที่ผู้ดูแลระบบให้มา และ ชื่อเซิร์ฟเวอร์ที่แสดง ตามที่คุณต้องการ จากนั้นคลิก เชื่อมต่อ
  3. เข้าสู่ระบบเหมือนในเบราว์เซอร์

เพื่อเพิ่มเซิร์ฟเวอร์อีกตัว เลือก เพิ่มเซิร์ฟเวอร์ ในเมนูเซิร์ฟเวอร์ที่ด้านบนของหน้าต่าง หรือใน การตั้งค่า ของแอป ภายใต้ เซิร์ฟเวอร์ หน้าต่าง การตั้งค่า ของแอป (Ctrl+, บน Windows และ Linux, Preferences… บน Mac) ยังตั้งค่าได้ว่าแอปจะเปิดเมื่อคุณเข้าสู่ระบบหรือไม่ ไฟล์ดาวน์โหลดไปที่ไหน ภาษาของตัวตรวจสอบการสะกด และการแจ้งเตือน

แอปมือถือ

แอปมือถือทำงานบน Android 11 ขึ้นไป และ iOS 18 ขึ้นไป

  1. เปิดแอป และแตะผ่านหน้าต้อนรับ
  2. ใน เชื่อมต่อเซิร์ฟเวอร์ของคุณ ใส่ที่อยู่ของเซิร์ฟเวอร์ใน กรอก URL เซิร์ฟเวอร์ เลือก ชื่อที่แสดง และแตะ เชื่อมต่อ
  3. เข้าสู่ระบบด้วยอีเมลหรือชื่อผู้ใช้และรหัสผ่าน หรือระบบเข้าสู่ระบบขององค์กรคุณ

แอปมือถือมีดีไซน์ของตัวเอง: แท็บที่ด้านล่างนำไปสู่ หน้าหลัก, ค้นหา, เมนชัน, ข้อความที่ บันทึกแล้ว และ บัญชี ของคุณ ซึ่งคุณตั้งค่าสถานะและค้นหาการตั้งค่าของแอปได้ ครอบคลุมข้อความ เธรด ช่อง การโทรและช่องเสียง โพล GIF และสติกเกอร์ ฟีเจอร์บางตัวของแอปเว็บยังไม่มีในแอปมือถือ เช่น กล้องในการโทร การแก้ไขโน้ตและไวท์บอร์ด Kanban ปฏิทิน และอีเมล การแจ้งเตือนแบบ push บนโทรศัพท์ของคุณต้องให้ผู้ดูแลระบบตั้งค่าไว้บนเซิร์ฟเวอร์
