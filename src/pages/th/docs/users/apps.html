ค้นหาและเปิดแอป

ผู้ดูแลระบบเป็นผู้เลือกแอปที่มีอยู่บนเซิร์ฟเวอร์ของคุณ ดังนั้นคุณอาจไม่เห็นแอปทั้งหมดบนหน้านี้ แอปส่วนใหญ่จะมีไอคอนใน แถบแอป ซึ่งเป็นคอลัมน์แคบๆ ที่ขอบขวาของหน้าต่าง ใต้รูปของคุณ ชี้ไปที่ไอคอนเพื่อดูชื่อแอป และคลิกเพื่อเปิดแอปในแผงข้างบทสนทนา คลิกอีกครั้งเพื่อปิดแผง ลากขอบของแผงเพื่อทำให้กว้างขึ้น คืนค่าความกว้างเริ่มต้น จะนำความกว้างกลับสู่ค่าเริ่มต้น เปิดในหน้าต่างใหม่ ในส่วนหัวของแผง จะเปิดแอปในหน้าต่างแยกต่างหาก ที่โน้ต บอร์ด หรือรายการที่คุณเปิดอยู่

แอปยังปรากฏในท่ีอื่่นๆ ด้วย:

  • เมนู + ของกล่องข้อความ (เพิ่มไฟล์และอื่นๆ) เช่น สร้างโพล
  • แท็บของตัวเลือกอิโมจิ: GIF, สติกเกอร์ และ มีม
  • เมนูของข้อความ (การดำเนินการข้อความ, ⋯) ภายใต้ การดำเนินการเพิ่มเติม เช่น เพิ่มเข้าสิ่งที่ต้องทำ หรือ รันเพลย์บุ๊ก แต่ละการดำเนินการจะแสดงไอคอนของแอปนั้น
  • คำสั่งสแลช, เชน /poll หรือ /todo: พิมพ์ / เพื่อดูรายชื่่อ
  • การตั้งค่าของแอปบางตัวอยู่ภายใต้ ปลั๊กอิน ในการตั้งค่าของคุณ

บนโทรศัพท์ แถบแอปจะอยู่ในลิ้นชักด้านขวา: ปัดไปทางซ้าย หรือเลือก เพิ่มเติม › สมาชิกและแอป ในส่วนหัวของบทสนทนา

โน้ต

โน้ตคือเอกสารที้คนหลายคนแก้ไขพร้อมกนั ข้างข้อความ คุณเห็นเคอร์เซอร์และชื่่อของคนอื่่นขณะพิมพ์, และทุกสิ่่งถูกบันทึกตามที้คุณทำ

เขียนโน้ต

  1. คลิก Notes ในแถบแอป
  2. เลือกแท็บ: This channel สำหรับโน้ตที้สมาชิกทุกคนในช่องอ่านและแก้ไขได้, หรือ Mine สำหรับโน้ตส่วนตัวที้เพียะคุณเท่านั้้นเห็น
  3. คลิก + (โน้ตใหม่ในช่องนี้ หรือ โน้ตส่วนตัวใหม่) ในส่วนหัวของแผง จะเปิด "โน้ตไม่มีชื่อ" ขึ้น
  4. พิมพ์ชื่อเรื่องในส่วนหัว จากนั้นจึงเขียน ข้อความ การจัดรูปแบบ ใต้ส่วนหัว ซึ่งแสดงสำหรับผู้ที่สามารถแก้ไขโน้ตได้ มีตัวหนา ตัวเอียง ขีดฆ่า หัวข้อ รายการ และรายการตรวจสอบ; ลิงก์ คำ引用 และโค้ดก็ใช้ได้เช่นกัน ข้างๆ นั้น จุดจะแสดงว่ามีใครกำลังแก้ไขอยู่ และว่ามีการเปลี่ยนแปลงของคุณถูกบันทึกไว้หรือไม่ พิมพ์ @ เพื่อเมนชันสมาชิกของช่อง (การเมนชันในโน้ตจะไม่แจ้งเตือนใคร)
  5. คลิก โน้ตทั้งหมด (ลูกศรทางซ้ายของส่วนหัว) เพื่อกลับไปที่รายการ

เมื่อโน้ตในช่องมีชื่อเรื่องแล้ว Antimatter จะโพสต์ "แชร์โน้ต" ในช่อง พร้อมปุ่มเปิดโน้ต

เพิ่มเติมเกี่ยวกับโน้ต

ให้ดาวกับโน้ตเพื่อค้นหาในแท็บ รายการโปรด เมนู การดำเนินการโน้ต ของโน้ต (⋯) มี แชร์ในช่อง (โพสต์การ์ดที่ลิงก์ไปยังโน้ต), แชร์ใน ~channel (เปลี่ยนโน้ตส่วนตัวให้เป็นโน้ตของช่องอย่างถาวร), ประวัติเวอร์ชัน (ดูและ ฟื้นฟุ่เวอร์ชันนี้), ส่งออกเป็น Markdown และ ลบ เฉพาะผู้สร้างโน้ตและผู้ดูแลระบบของช่องเท่านั้นที่สามารถลบโน้ตของช่องได้

ไวท์บอรด์

ไวท์บอรด์คือผืนผ้าใบที่คุณวาดร่วมกัน: รูปทรง ลูกศร ข้อความ และการวาดอิสระ พร้อมแสดงพอยเตอร์ของทุกคนแบบเรียลไทม์

  1. คลิกไวท์บอรด์ในแถบแอป
  2. เช่นเดียวกับโน้ต เลือกช่องนี้หรือของฉัน แล้วคลิก+ (บอรด์ใหม่ในช่องนี้หรือบอรด์ส่วนตัวใหม่)
  3. วาดด้วยเครื่องมือ: เลือกและย้าย (V), เลื่อนดู (H), สี่เหลี่ยม (R), วงรี (O), ลูกศร (A), วาด (P), ข้อความ (T) และยางลบ (E) เลือกสี สไตล์เส้น และฟอนต์ในแถบเครื่องมือ และรูปทรงในไลบรารี เลิกทำ (Ctrl+Z)เพื่อยกเลิกการเปลี่ยนแปลงล่าสุดของคุณ

เมนู การดำเนินการบอร์ด มี เต็มหน้าจอ, แสดงบอร์ดทั้งหมด, ดาวน์โหลดเป็น .excalidraw, PNG หรือ SVG, ประวัติเวอร์ชัน, นำเข้าไฟล์ .excalidraw… (จะแทนที่บอร์ดสำหรับทุกคน), การแชร์ในช่อง และ ลบ ไวท์บอร์ดจะเก็บอยู่บนเซิร์ฟเวอร์ Antimatter ของคุณ

Kanban

บอรด์ Kanban จัดระเบียบงานเป็นการ์ดในคอลัมน์ เช่น "สิ่งท่ีต้องทำ", "กำลังทำ" และ "เสร็จแล้ว" บอรด์ยังสามารถแสดงเป็นตาราง แกลเลอรี หรือปฏิทินได้

เปิดบอรด์ของช่อง

คลิก Kanban ในแถบแอป Kanban จะเปิดในแผงข้างบทสนทนา และแสดงรายการบอรด์ท่ีเช่ียวกับช่องน้ี; คลิกท่ีบอรด์ใดบอรด์หน่ึงเพ่ือเปิด หากยงัไม่ม้ีบอรด์ใดเช่ียวกัน ให้คลิก Link boards to … แลว้ คลิกลิงก์ Link ข้างบอรด์ หรือ Create a board สมาชิกของช่องจะกลายเป็็นผ้ทู่ีแกไ้ขบอรด์ท่ีเช่ียวกัน บอรด์จะขยายแผงขณะแสดง; ลูกศรกลบัท่ีบนแผงจะกลบัไปท่ีมุมมองก่อนหน้่า

ทำงานกับบอรด์

  • เพ่ือดูบอรด์ทัง้หมดของชุมชน แยกตามหมวดหมู่ ให้คลิก All boards ในแผง ท่ีน้ีคุณสามารถพบบอรด์ สร้างบอรด์หรือหมวดหมู่ และเคล่ือน เลียนแบบ ส่งออก ซ่อน หรือลบบอรด์จากเมนูของบอรด์
  • เพ่ือสร้างบอรด์ ให้คลิก New board ในแผง แลว้ เริ่มจากเทมเพลต (วาระประชุม งานโครงการ แผนงาน ผู้วางแผน Sprint และอื่่นๆ) หรือ Create an empty board
  • คลิก + New ในคอลัมน์เพ่ือเพิ่่มการด์ การด์จะเปิดทับแผง: ตั้่งค่าของ การด์เพิ่่มข้อความ ไม้้กา้ และภาพ แนบไฟล์ และคอมเม้นต์ เมนชัน่ผ้ทู่ีใดใน การด์จะแจ้้งเตือนผู้น้ัน
  • ลากการ์ดข้ามคอลัมน์ ใช้ จัดกลุ่มตาม, ตัวกรอง, เรียงลำดับ และ ค้นหาการ์ด เพื่อค้นหาสิ่งที่คุณต้องการ และใช้ เพิ่มมุมมอง สำหรับมุมมองตาราง แกลเลอรี หรือปฏิทิน
  • ใช้ แชร์ บนบอรด์เพื่อเลือกว่าใครสามารถดูหรือแก้ไขได้

ปฏิทิน

แอปปฏิทินแสดงปฏิทินของคุณข้างแชท ส่งการแจ้งเตือน และให้คุณประชุมใน Antimatter ได้ ทำงานกับเซิร์ฟเวอร์ปฏิทินที่ใช้ CalDAV เช่น Nextcloud, Fastmail หรือ Radicale

เชื่อมต่อปฏิทินของคุณ

  1. คลิก ปฏิทิน ในแถบแอป
  2. ใน Connect your calendar ให้อา้ดรส CalDAV server (มักเป็นเพีียงโดเมนของผ้ทู่ีใหบ้รริการ) ชื่่อผ้ใู้ช้ และ พาสวรด์ ของคุณ หากผ้ทู่ีใหบ้รริการใหพ้าสวรด์สำหรับแอป ให้ใชพ้าสวรด์น้ัน
  3. เลือกเวลาที่จะ แจ้งเตือนฉันเกี่ยวกับกิจกรรมที่ไม่มีตัวเตือน จากนั้นคลิก เชื่อมต่อ

รหัสผ่านของคุณจะถูกเก็บอย่างเข้ารหัสบนเซิร์ฟเวอร์ Antimatter หากต้องการเปลี่ยนรายละเอียดเหล่านี้ในภายหลัง หรือยกเลิกการเชื่อมต่อ ให้ใช้ การตั้งค่าบัญชี ในแผง

การใช้งาน

  • สลับระหว่าง Agenda และ Week เคล่ือนไปดวย ย่อนกลบั, วนัน้ี และ ถดัไป และคลิกชิปของปฏิทินเพ่ือแสดงหรือซ่อน
  • คลิก กิจกรรมใหม่ กรอก ชื่อ, เริ่ม และ สิ้นสุด และโดยไม่บังคับ ทำซ้ำ, การแจ้งเตือน, สถานที่ และ คำอธิบาย จากนั้น บันทึก คลิกที่กิจกรรมเพื่อแก้ไขหรือลบ
  • เพ่ือประชุมใน Antimatter ใหต้ั้่ง Meet in Antimatter เป็็นช่องหรือช่องเสียง หรือเป็็นการโทร และเลืก ช่อง เมื่่อถงึเวลา กจิกรรมจะแสดง เร่ิมโทร, เข้้าร่ว่มการโทร หรือ เข้้าร่ว่ม
  • การแจ้งเตือนจะมาถึงในรูปของข้อความส่วนตัวจากบอทปฏิทิน พร้อมลิงก์สำหรับเข้าร่วมการโทรเมื่อมี

แอปแสดงปฏิทินของคุณเท่านั้น ไม่ส่งคำเชิญไปยังผู้อื่น

อีเมล

แอปอีเมลแสดงกล่องจดหมายของคุณข้างแชท เพื่อให้คุณอ่าน ตอบ และแชร์อีเมลได้โดยไม่ต้องออกจาก Antimatter

เชื่อมต่อกล่องจดหมายของคุณ

  1. คลิก อีเมล ในแถบแอป
  2. หากผู้ดูแลระบบของคุณตั้งค่าไว้ ให้คลิก เข้าสู่ระบบด้วย Google หรือ เข้าสู่ระบบด้วย Microsoft หากไม่เช่นนั้น หรือหากต้องการใช้ผู้ให้บริการรายอื่น ให้กรอก ที่อยู่อีเมล และ ชื่อของคุณ จากนั้นระบุเซิร์ฟเวอร์ อีเมลขาเข้า (IMAP) และ อีเมลขาออก (SMTP) พร้อมข้อมูลความปลอดภัย พอร์ต ชื่อผู้ใช้ และรหัสผ่าน หน้าช่วยเหลือของผู้ให้บริการของคุณจะระบุรายละเอียดเหล่านี้ไว้
  3. คลิก เชื่อมต่อ

การใช้งาน

  • เลือก โฟลเดอร์ ค้นหาด้วย ค้นหาในโฟลเดอร์นี้ และคลิกที่ข้อความเพื่ออ่าน รูปภาพจากอินเทอร์เน็ตจะถูกซ่อนไว้จนกว่าคุณจะคลิก แสดงรูปภาพ
  • ตอบดวย ตอบกลบั, ตอบทัง้หมด หรือ ไปข้างหน้่า หรือเขยีดดวย ข้้อความใหม้ ข้้อความเป็็นข้้อความธรรมดา และคุณไม่อาจแนบไฟล์ใหม้
  • คลิก แชร์ไปยังช่อง เพื่อโพสต์ผู้ส่ง หัวข้อ และส่วนหนึ่งของอีเมลไปยังช่อง พร้อมความคิดเห็น

โพล

โพล (Poll) เป็นการตั้งคำถามในบทสนทนา และทุกคนสามารถโหวตได้ด้วยคลิกเดียว ผลลัพธ์จะอัปเดตแบบเรียลไทม์

  1. คลิก + ในกล่องข้อความแล้วเลือก สร้างโพล หรือพิมพ์ /poll
  2. พิมพ์ คำถาม และคำตอบอย่างน้อยสองข้อ เพิ่มคำตอบ จะเพิ่มคำตอบได้มากขึ้น สูงสุด 10 ข้อ
  3. เปิด อนุญาตให้ตอบหลายข้อ หากผู้คนสามารถเลือกได้หลายข้อ และ โหวตแบบไม่เปิดเผยตัวตน หากไม่มีใครควรเห็นว่ามีใครโหวตให้ใคร
  4. เลือก ระยะเวลา ตั้งแต่ 1 ชั่วโมง ถึง 1 สัปดาห์ หรือ ไม่มีวันสิ้นสุด
  5. คลิก โพสต์โพล

เพื่อโหวต ให้คลิกที่คำตอบ; คลิกอีกครั้งเพื่อยกเลิกการโหวต โพลจะสิ้นสุดเมื่อหมดระยะเวลา หรือเมื่อผู้สร้างหรือผู้ดูแลช่องคลิก ปิดโพล; จากนั้นจะแสดง ผลลัพธ์สุดท้าย

คุณยังสามารถเขียนโพลทั้งฉบับในบรรทัดเดียวได้: /poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h พิมพ์ /poll help เพื่อดูตัวเลือกทั้งหมด

ส่ิงท่ีต้องทำ

Todo ใหม้รายการส่ิงท่ีตองทำ: รายการท่ีเชยี่วในช่องหรือบทสนทนา รายการของคุณเอง และส่ิงท่ีตองทำท่ีคุณส่งไปหาผ้ทู่ีอื่่น คลิก Todo ในแถบแอป ดวยกันดวย Notes แผงม้ีสามแท็บ:

  • ช่องน้ี (หรือ บทสนทนาน้ี): รายการท่ีเชยี่วกับทัง้หมดในน้ัน คลิก + ในหัวของแผง (รายการใหม้ในช่องน้ี) เพ่ือสร้าง
  • รายการโปรด: รายการท่ีคุณดาวไว้ ท่ีใดก้ได
  • ของฉัน: รายการส่วนตวัของคุณ ท่ีเพีียงคุณเท่าน้ันเห็น (ส่ิงท่ีตองทำของฉัน ม้ีอย่ทู่ีน้ีเสมอ; + สร้างอื่่น) แลว้ มอบหมายให้คุณในช่อง, ส่งให้คุณ และ ส่งโดยคุณ

เปิดรายการเพิ่่มสิ่่งท่ีต้อ่งทำ โดยเพิ่่มรายละเอีียดและวันท่ีหมดเขตตามท่ีต้อ่งการ และทำเครื่อกำกับเมื่่อเสร็จแล้้วดวยทำเครื่อกำกับว่าเสร็จแล้้ว ในรายการของช่อง มอบหมายให้... จะมอบสิ่่งท่ีต้อ่งทำให้สมาชิก; ในรายการส่ว่นตัว ส่งให้... จะส่งให้ผู้ใดผุ้หนึ่่ง ท่ีสามารถยอมรบั, ปฏิเสธ หรือทำเครื่อกำกับว่าเสร็จแล้้วได้ เมนูการดำเนิินการของรายการของรายการจะเปลี่่ยนชื่่อ เปลี่่ยนไอคอน เก็บถาวร (รายการจะกลายเป็็นเพิ่่งอ่านเท่านั้่น ใต้เก็บถาวรแล้้ว) หรือลบบท. ทกุ ท่ีท่ีสามารถโพสต์ในช่องสามารถเปลี่่ยนรายการของช่องได้; ผุ้สร้่างรายการและผู้ดูละบบของช่องสามารถลบได้

เพื่่อเปลี่่ยนข้้อความให้เป็็นสิ่่งท่ีต้อ่งทำ เลือกการดำเนิินการเพิ่่มเติิม › เพิ่่มเข้าสิ่่งท่ีต้อ่งทำในเมนู และเลือกรายการ บอทสิ่่งท่ีต้อ่งทำจะแจ้่งเตืือนเมื่่อผุ้ใดผุ้หนึ่่งมอบหมายหรือส่งสิ่่งท่ีต้อ่งทำให้คุณ และจะทักท้วงเรื่่องสิ่่งท่ีต้อ่งทำของคุณวันละครั้่ง

คำสั่่งก็ทำงานได้: /todo lists, /todo new name (เพิ่่ม--personalสำหรับรายการส่ว่นตัว), /todo add list: textเพื่่อเพิ่่มเข้ารายการตามชื่่อ, /todo add textเพื่่อเพิ่่มเข้าสิ่่งท่ีต้อ่งทำส่ว่นตัว, และ/todo send @someone text.

GIF, สติกเกอร์ และมีม

คลิก อิโมจิ (หน้ายิ้ม) ในกล่องข้อความ: เมื่อแอปเหล่านี้ถูกตั้งค่าแล้ว ตัวเลือกจะมีแท็บ GIF, สติกเกอร์ และ มีม อยู่ข้างๆ อิโมจิ

  • GIF: ค้้นหา หรือดูรายการโปรด, ใช้เมื่่อไม่ก่า, เทรนด์และหมวดหมู่ คลิก GIF เพื่่อส่งทันที คลิกดาวเพื่่อเพิ่่มเข้ารายการโปรด คุณยังสามารถพิมพ์/gifและคำบางคำได้
  • สติกเกอร์: ค้นหาหรือเรียกดูแพ็กเกจสติกเกอร์ แล้วคลิกสติกเกอร์เพื่อส่ง /sticker ก็ใช้ได้
  • มีม: เลือกเทมเพลต กรอกข้อความใน สร้างมีม ดูตัวอย่าง แล้วคลิก โพสต์มีม คุณสามารถพิมพ์ /meme หรือ /meme help เพื่อดูวิธีเขียนในบรรทัดเดียวได้

ขึ้่นอยูกกบการตั้่งค่าของเซิร์ฟเวอร์ของคุณ คุณอาจสามารถเพิ่่ม GIF, สติกเกอร์ หรือเทมเพลตมีมของคุณเองดวย+ข้้างกล่องค้้นหา มันจะเปิิดฟอร์มในตั้่งค่า: เลือกรายการ, วางหรือวางไฟล์, ตรวจดูพรีวิิว, ให้ชื่่อ (ชื่่อสำหรับเทมเพลตมีม) และตามท่ีต้อ่งการ แท็กหรือคำหลัก แล้้วคลิกเพิ่่ม (บันทึกเทมเพลตสำหรับเทมเพลตมีม) ส่ิงท่ีคุณเพิ่่มจะปรากฏขึ้่นในตั้่งค่า และทกุ ท่ีในเซิร์ฟเวอร์สามารถค้้นหาได้ ปุ่่มข้้าง+ (จัดการ GIF, จัดการสติกเกอร์ หรือเทมเพลตมีมส่ว่นตัว) จะแสดงรายการส่ิงท่ีผุ้ใดผุ้หนึ่่งเพิ่่ม พร้อมผุ้ท่ีเพิ่่มและเมื่่อใด และอนุญาตให้คุณลบส่ิงท่ีคุณมีอํานาจท่ีจะลบได้ แขกไม่สามารถเพิ่่มหรือลบได้

เพลยบุ๊ก

เพลย์บุ๊กคือรายการตรวจสอบที่นำกลับมาใช้ใหม่ได้สำหรับงานที่ต้องทำตามขั้นตอนเดิมทุกครั้ง: เหตุการณ์, การเปิดตัวผลิตภัณฑ์, การต้อนรับเพื่อนร่วมงานใหม่ ทุกครั้งที่คุณใช้ คุณจะเริ่มต้น รัน ซึ่งจะมีงาน, ผู้รับผิดชอบ, การอัปเดตสถานะ และท้ายที่สุดคือการทบทวน

  • คลิกเพลย์บุ๊กในแถบแอปเพื่่อดูรันของช่องปัจจุบัน, เริ่มดวยรันเพลย์บุ๊ก, หรือสร้่างเช็คลิสต์ใหม่อย่างรวดเร็ว ทกุ ส่ิงในเพลย์บุ๊กจะเปิิดในแผงนี้ พร้อมลูกศรกลับไปท่ีมุมมองก่อนหน้่า
  • เพื่่อค้้นหาส่ิงอื่่นทกุ ส่ิง คลิกดูรัน, เพลย์บุ๊ก และงานที่ด้าบนของแผง: รันทกุ รายการ, เพลย์บุ๊กทกุ รายการ, งานของคุณ, และรายการโปรดและรันท่ีกำลังดำเนิินการของคุณ
  • เพื่อสร้างเพลย์บุ๊ก ให้คลิก สร้างเพลย์บุ๊ก หรือ นำเข้า ในมุมมองนั้น และเพื่อแก้ไข ให้เปิดจาก เพลย์บุ๊กทั้งหมด คุณสามารถเริ่มจากเทมเพลต เช่น การเปิดตัวผลิตภัณฑ์ การจัดการเหตุการณ์ หรือการต้อนรับพนักงานใหม่ หรือเริ่มจากเพลย์บุ๊กเปล่า ตัวแก้ไขเพลย์บุ๊กจะขยายแผงให้กว้างขึ้นเมื่อแสดงอยู่
  • เพื่อเริ่มรัน ให้คลิก รัน บนเพลย์บุ๊ก ตั้งชื่อและสรุปสำหรับรันนั้น เลือกที่จะสร้างช่องสำหรับรันหรือลิงก์กับช่องที่มีอยู่แล้ว แล้วคลิก เริ่มรัน นอกจากนี้ คุณสามารถเลือก การดำเนินการเพิ่มเติม › รันเพลย์บุ๊ก ในเมนูของข้อความได้
  • ระหว่างรัน ให้ทำเครื่องหมายงานที่เสร็จ, มอบหมายและกำหนดวันครบกำหนด แล้วคลิก โพสต์อัปเดต เพื่อแจ้งให้ทุกคนทราบถึงสถานะปัจจุบัน เจ้าของคลิก เสร็จสิ้น เมื่อจบ

GitHub, GitLab และ Jira

แอปเหล่านี้เชื่อมต่อ Antimatter กับเครื่องมือที่นักพัฒนาใช้ ผู้ดูแลระบบของคุณต้องตั้งค่าก่อน จากนั้น:

  1. เชื่อมต่อบัญชีของคุณโดยพิมพ์ /github connect, /gitlab connect หรือ /jira connect จากนั้นคลิกลิงก์และเข้าสู่ระบบบนเว็บไซต์นั้น สำหรับ GitLab ให้ทำในเว็บเบราว์เซอร์ ไม่ใช่ในแอปเดสก์ท็อป
  2. หลังจากนั้นคุณจะได้รับข้อความส่วนตัวเมื่อมีคนเมนชันคุณ ร้องขอให้คุณรีวิว หรือมอบหมายงานให้คุณ
  3. หากต้องการให้ช่องติดตามรีพอสิทอรีหรือโปรเจกต์ ให้ใช้ /github subscriptions add owner/repo, /gitlab subscriptions add group/project หรือ /jira subscribe
  4. เพื่อสร้างหรือแนบปัญหา (issue) จากข้อความ ให้เลือก สร้าง GitHub Issue, สร้าง GitLab Issue, สร้าง Jira Issue หรือรายการ แนบกับ … ที่สอดคล้องกัน ภายใต้ การดำเนินการเพิ่มเติม ในเมนูของข้อความ

พิมพ์ /github help, /gitlab help หรือ /jira help เพื่อดูคำสั่งสแลชทั้งหมด
