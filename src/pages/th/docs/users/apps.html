ค้นหาและเปิดแอป

ผู้ดูแลระบบเป็นผู้เลือกแอปที่มีอยู่บนเซิร์ฟเวอร์ของคุณ ดังนั้นคุณอาจไม่พบแอปทั้งหมดบนหน้านี้ แอปส่วนใหญ่มีไอคอนใน แถบแอป ซึ่งเป็นคอลัมน์แคบๆ ที่ขอบขวาของหน้าต่าง ใต้รูปของคุณ ชี้ไปที่ไอคอนเพื่อดูชื่อแอป และคลิกเพื่อเปิดแอปในแผงข้างบทสนทนา คลิกอีกครั้งเพื่อปิดแผง ลากขอบของแผงเพื่อขยายให้กว้างขึ้น; คืนค่าความกว้างเริ่มต้น จะปรับกลับให้เหมือนเดิม เปิดในหน้าต่างใหม่ ในส่วนหัวของแผง จะเปิดแอปในหน้าต่างแยกต่างหาก ที่โน้ต บอร์ด หรือรายการที่คุณกำลังเปิดอยู่

แอปยังปรากฏในท่ีอื่่นๆ ด้วย:

  • เมนู + ของกล่องข้อความ (เพิ่มไฟล์และอื่นๆ) เช่น สร้างโพล
  • แท็บของตัวเลือกอิโมจิ: GIF, สติกเกอร์ และ มีม
  • เมนูของข้อความ (การดำเนินการข้อความ, ⋯) ภายใต้ การดำเนินการเพิ่มเติม เช่น เพิ่มเข้าสิ่งที่ต้องทำ หรือ รันเพลย์บุ๊ก แต่ละการดำเนินการจะแสดงไอคอนของแอปนั้น
  • คำสั่งสแลช, เชน /poll หรือ /todo: พิมพ์ / เพื่อดูรายชื่่อ
  • การตั้งค่าของแอปบางตัวอยู่ใน ปลั๊กอิน ในหน้าการตั้งค่าของคุณ

บนโทรศัพท์ แถบแอปจะอยู่ในลิ้นชักด้านขวา: เลื่อนซ้าย หรือเลือก เพิ่มเติม › สมาชิกและแอป ในส่วนหัวของบทสนทนา

โน้ต

โน้ตคือเอกสารที้คนหลายคนแก้ไขพร้อมกนั ข้างข้อความ คุณเห็นเคอร์เซอร์และชื่่อของคนอื่่นขณะพิมพ์, และทุกสิ่่งถูกบันทึกตามที้คุณทำ

เขียนโน้ต

  1. คลิก Notes ในแถบแอป
  2. เลือกแท็บ: This channel สำหรับโน้ตที้สมาชิกทุกคนในช่องอ่านและแก้ไขได้, หรือ Mine สำหรับโน้ตส่วนตัวที้เพียะคุณเท่านั้้นเห็น
  3. คลิก + (โน้ตใหม่ในช่องนี้ หรือ โน้ตส่วนตัวใหม่) ในส่วนหัวของแผง จะเปิด "โน้ตไม่มีชื่อ" ขึ้น
  4. พิมพ์ชื่อเรื่องในส่วนหัว จากนั้นเริ่มเขียน แถบ การจัดรูปแบบ ใต้ส่วนหัว ซึ่งแสดงสำหรับผู้ที่มีสิทธิ์แก้ไขโน้ต มีตัวหนา ตัวเอียง ขีดฆ่า หัวข้อ รายการ และรายการตรวจสอบ; ลิงก์ คำอ้าง และโค้ดก็ใช้ได้เช่นกัน ข้างๆ นั้น จุดจะแสดงว่ามีใครกำลังแก้ไขอยู่ และว่ามีการบันทึกการเปลี่ยนแปลงของคุณแล้วหรือยัง พิมพ์ @ เพื่อเมนชันสมาชิกรายหนึ่งของช่อง (การเมนชันในโน้ตจะไม่แจ้งเตือนใคร)
  5. คลิก โน้ตทั้งหมด (ลูกศรทางซ้ายของส่วนหัว) เพื่อกลับไปที่รายการ

เมื่อโน้ตในช่องมีชื่อเรื่องแล้ว Antimatter จะโพสต์ "แชร์โน้ต" ในช่อง พร้อมปุ่มเปิดโน้ต

เพิ่มเติมเกี่ยวกับโน้ต

ใส่ดาวให้โน้ตเพื่อค้นหาได้ในแท็บ รายการโปรด เมนู การดำเนินการโน้ต ของโน้ต (⋯) มี แชร์ในช่อง (โพสต์การ์ดที่ลิงก์ไปยังโน้ต), แชร์ใน ~channel (เปลี่ยนโน้ตส่วนตัวให้เป็นโน้ตของช่องอย่างถาวร), ประวัติเวอร์ชัน (ดูและ ฟื้นฟุ่เวอร์ชันนี้), ส่งออกเป็น Markdown และ ลบ เฉพาะผู้สร้างโน้ตและผู้ดูแลระบบของช่องเท่านั้นที่สามารถลบโน้ตของช่องได้

ไวท์บอรด์

ไวท์บอรด์คือผืนผ้าใบที่คุณวาดร่วมกัน: รูปทรง ลูกศร ข้อความ และการวาดอิสระ พร้อมแสดงพอยเตอร์ของทุกคนแบบเรียลไทม์

  1. คลิกไวท์บอรด์ในแถบแอป
  2. เช่นเดียวกับโน้ต เลือกช่องนี้หรือของฉัน แล้วคลิก+ (บอรด์ใหม่ในช่องนี้หรือบอรด์ส่วนตัวใหม่)
  3. วาดด้วยเครื่องมือ: เลือกและย้าย (V), เลื่อนดู (H), สี่เหลี่ยม (R), วงรี (O), ลูกศร (A), วาด (P), ข้อความ (T) และยางลบ (E) เลือกสี สไตล์เส้น และฟอนต์ในแถบเครื่องมือ และรูปทรงในไลบรารี เลิกทำ (Ctrl+Z)เพื่อยกเลิกการเปลี่ยนแปลงล่าสุดของคุณ

เมนู การดำเนินการบอร์ด มี เต็มหน้าจอ, แสดงบอร์ดทั้งหมด, ดาวน์โหลดเป็น .excalidraw, PNG หรือ SVG, ประวัติเวอร์ชัน, นำเข้าไฟล์ .excalidraw… (จะแทนที่บอร์ดสำหรับทุกคน), แชร์ในช่อง และ ลบ ไวท์บอร์ดจะเก็บอยู่บนเซิร์ฟเวอร์ Antimatter ของคุณ

Kanban

บอรด์ Kanban จัดระเบียบงานเป็นการ์ดในคอลัมน์ เช่น "สิ่งท่ีต้องทำ", "กำลังทำ" และ "เสร็จแล้ว" บอรด์ยังสามารถแสดงเป็นตาราง แกลเลอรี หรือปฏิทินได้

เปิดบอรด์ของช่อง

คลิก Kanban ในแถบแอป บอรด์ Kanban จะเปิดในแผงด้านข้างบทสนทนา และจะแสดงรายการบอรด์ท่ีเช่ียวกับช่องน้ี; คลิกที่บอรด์ใดบอรด์หน่ึงเพ่ือเปิด หากยงัไม่มมีีบอรด์เช่ียวกัน ให้คลิก Link boards to … แลว้ คลิกลิงก์ Link ข้างบอรด์ท่ีตองการ หรือ Create a board สมาชิกของช่องจะกลายเปน็ผ้ทู่ีมีอานาจแก้ไขบอรด์ท่ีเช่ียวกัน บอรด์จะขยายแผงขณะแสดงอยู่; ลูกศรกลับที่บนแผงจะกลบัไปท่ีมุมมองก่อนหน้่า

ทำงานกับบอรด์

  • เพ่ือดูบอรด์ทัง้หมดของชุมชน แยกตามหมวดหมู่ ให้คลิก All boards ในแผง ท่ีน้ีคุณสามารถพบบอรด์ สร้างบอรด์หรือหมวดหมู่ใหม่ และเคลอ่ืน สําเนา ส่งออก ซ่อน หรือลบบอรด์จากเมนูของบอรด์น้ัน
  • เพ่ือสร้างบอรด์ ให้คลิก New board ในแผง แลว้ เลือกท่ีจะเร่ิมจากเทมเพลต (วาระประชุม งานโปรเจกต์ roadmap, sprint planner และอ่นื ๆ) หรือ Create an empty board
  • คลิก + New ในคอลัมน์เพ่ือเพิ่่มการด์ การด์จะเปิดทับแผง: ตั้่งค่านามธรรมของการ์ด เติมข้อความ, ช่องกา้ และภาพ แนบไฟล์ และคอมเม้นต์ การเมนชันใครในการ์ดจะแจ้้งเตือนคนน้ัน
  • ลากการ์ดข้ามคอลัมน์ ใช้ จัดกลุ่มตาม, ตัวกรอง, เรียงลำดับ และ ค้นหาการ์ด เพื่อค้นหาสิ่งที่คุณต้องการ และใช้ เพิ่มมุมมอง สำหรับมุมมองตาราง แกลเลอรี หรือปฏิทิน
  • ใช้ แชร์ บนบอรด์เพื่อเลือกว่าใครสามารถดูหรือแก้ไขได้

ปฏิทิน

แอปปฏิทินแสดงปฏิทินของคุณข้างแชท ส่งการแจ้งเตือน และให้คุณประชุมใน Antimatter ได้ ทำงานกับเซิร์ฟเวอร์ปฏิทินที่ใช้ CalDAV เช่น Nextcloud, Fastmail หรือ Radicale

เชื่อมต่อปฏิทินของคุณ

  1. คลิก ปฏิทิน ในแถบแอป
  2. ใน Connect your calendar, กรอกท่ีท่ีของ CalDAV server (มักจะเป็นโดเมนของผ้เูสนอการบรการ), Username และ Password ของคุณ หากผ้เูสนอการบรการของคุณเสนอพาสวรด์แอป ให้ใชพ้าสวรด์น้ัน
  3. เลือกเวลาที่จะ แจ้งเตือนฉันเกี่ยวกับกิจกรรมที่ไม่มีตัวเตือน จากนั้นคลิก เชื่อมต่อ

รหัสผ่านของคุณจะถูกเก็บอย่างเข้ารหัสบนเซิร์ฟเวอร์ Antimatter หากต้องการเปลี่ยนรายละเอียดเหล่านี้ในภายหลัง หรือยกเลิกการเชื่อมต่อ ให้ใช้ การตั้งค่าบัญชี ในแผง

การใช้งาน

  • สลับระหว่าง Agenda และ Week, เคลอ่ืนด้วย Previous, Today และ Next, และคลิกชิปของปฏิทินเพ่ือแสดงหรือซ่อน
  • คลิก กิจกรรมใหม่ กรอก ชื่อ, เริ่ม และ สิ้นสุด และโดยไม่บังคับ ทำซ้ำ, การแจ้งเตือน, สถานที่ และ คำอธิบาย จากนั้น บันทึก คลิกที่กิจกรรมเพื่อแก้ไขหรือลบ
  • เพ่ือประชุมใน Antimatter, ตั้่ง Meet in Antimatter ให้เปน็ช่องหรือช่องเสยีง หรือการโทร และเลอืก Channel เมื่ถถงึเวลา กจิกรรมจะแสดง Start call, Join call หรือ Join
  • การแจ้งเตือนจะมาถึงในรูปของข้อความส่วนตัวจากบอทปฏิทิน พร้อมลิงก์สำหรับเข้าร่วมการโทรเมื่อมี

แอปแสดงปฏิทินของคุณเท่านั้น ไม่ส่งคำเชิญไปยังผู้อื่น

อีเมล

แอปอีเมลแสดงกล่องจดหมายของคุณข้างแชท เพื่อให้คุณอ่าน ตอบ และแชร์อีเมลได้โดยไม่ต้องออกจาก Antimatter

เชื่อมต่อกล่องจดหมายของคุณ

  1. คลิก อีเมล ในแถบแอป
  2. หากผู้ดูแลระบบของคุณตั้งค่าไว้ ให้คลิก เข้าสู่ระบบด้วย Google หรือ เข้าสู่ระบบด้วย Microsoft หากไม่เช่นนั้น หรือหากต้องการใช้ผู้ให้บริการรายอื่น ให้กรอก ที่อยู่อีเมล และ ชื่อของคุณ จากนั้นระบุเซิร์ฟเวอร์ อีเมลขาเข้า (IMAP) และ อีเมลขาออก (SMTP) พร้อมข้อมูลความปลอดภัย พอร์ต ชื่อผู้ใช้ และรหัสผ่าน หน้าช่วยเหลือของผู้ให้บริการของคุณจะระบุรายละเอียดเหล่านี้ไว้
  3. คลิก เชื่อมต่อ

การใช้งาน

  • เลือก โฟลเดอร์ ค้นหาด้วย ค้นหาในโฟลเดอร์นี้ และคลิกที่ข้อความเพื่ออ่าน รูปภาพจากอินเทอร์เน็ตจะถูกซ่อนไว้จนกว่าคุณจะคลิก แสดงรูปภาพ
  • ตอบด้วย Reply, Reply all หรือ Forward, หรือเขยีดด้วย New message ข้อความเปน็ข้อความธรรมดา และคุณไม่สามารถแนบไฟล์ใหม่ได้
  • คลิก แชร์ไปยังช่อง เพื่อโพสต์ผู้ส่ง หัวข้อ และส่วนหนึ่งของอีเมลไปยังช่อง พร้อมความคิดเห็น

โพล

โพล (Poll) เป็นการตั้งคำถามในบทสนทนา และทุกคนสามารถโหวตได้ด้วยคลิกเดียว ผลลัพธ์จะอัปเดตแบบเรียลไทม์

  1. คลิก + ในกล่องข้อความแล้วเลือก สร้างโพล หรือพิมพ์ /poll
  2. พิมพ์ คำถาม และคำตอบอย่างน้อยสองข้อ เพิ่มคำตอบ จะเพิ่มคำตอบได้มากขึ้น สูงสุด 10 ข้อ
  3. เปิด อนุญาตให้ตอบหลายข้อ หากผู้คนสามารถเลือกได้หลายข้อ และ โหวตแบบไม่เปิดเผยตัวตน หากไม่มีใครควรเห็นว่ามีใครโหวตให้ใคร
  4. เลือก ระยะเวลา ตั้งแต่ 1 ชั่วโมง ถึง 1 สัปดาห์ หรือ ไม่มีวันสิ้นสุด
  5. คลิก โพสต์โพล

เพื่อโหวต ให้คลิกที่คำตอบ; คลิกอีกครั้งเพื่อยกเลิกการโหวต โพลจะสิ้นสุดเมื่อหมดระยะเวลา หรือเมื่อผู้สร้างหรือผู้ดูแลช่องคลิก ปิดโพล; จากนั้นจะแสดง ผลลัพธ์สุดท้าย

คุณยังสามารถเขียนโพลทั้งฉบับในบรรทัดเดียวได้: /poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h พิมพ์ /poll help เพื่อดูตัวเลือกทั้งหมด

ส่ิงท่ีต้องทำ

Todo รกั ษารายการส่ิงท่ีตองทำ: รายการท่ีเช่ียวในช่องหรือบทสนทนา, รายการของคุณเอง, และส่ิงท่ีตองทำท่ีคุณส่งไปหาคนอ่นื ๆ คลิก Todo ในแถบแอป เชน่ใน Notes, แผงมมีีสามแท็บ:

  • This channel (หรือ This conversation): รายการท่ีเช่ียวกับทัง้หมดในน้ัน คลิก + ในหัวของแผง (New list in this channel) เพ่ือสร้าง
  • Favourites: รายการท่ีคุณดาวไว้ ท่ีใดกต็าม
  • Mine: รายการส่วนตวัของคุณ ท่ีเพยีงคุณเท่าน้ันท่ีจะเห็น (My todos จะอย่ทู่ีน้ีเสมอ; + สร้างอ่นื), แลว้ Assigned to you in channels, Sent to you และ Sent by you

เปิดรายการเพื่อเพิ่มสิ่งที่ต้องทำ พร้อมรายละเอียดและวันครบกำหนด (ถ้าต้องการ) และทำเครื่องหมายว่าเสร็จแล้วด้วยทำเครื่องหมายว่าเสร็จแล้ว ในรายการของช่อง มอบหมายให้… จะมอบหมายสิ่งที่ต้องทำให้กับสมาชิก; ในรายการส่วนตัว ส่งให้… จะส่งให้ผู้อื่น ซึ่งผู้รับสามารถยอมรับ, ปฏิเสธ หรือทำเครื่องหมายว่าเสร็จแล้ว ได้ เมนูการดำเนินการของรายการ ของรายการนั้นใช้สำหรับเปลี่ยนชื่อ, เปลี่ยนไอคอน, เก็บถาวร (รายการจะกลายเป็นแบบอ่านอย่างเดียว และย้ายไปอยู่ภายใต้เก็บถาวรแล้ว) หรือลบรายการ ผู้ทุกคนที่สามารถโพสต์ในช่องสามารถแก้ไขรายการของช่องนั้นได้; ผู้สร้างรายการและผู้ดูแลระบบของช่องสามารถลบรายการได้

เพื่อเปลี่ยนข้อความให้เป็นสิ่งที่ต้องทำ เลือกการดำเนินการเพิ่มเติม › เพิ่มเข้าสิ่งที่ต้องทำ ในเมนูของข้อความนั้น แล้วเลือกรายการ บอท Todo จะแจ้งให้คุณทราบเมื่อมีใครมอบหมายหรือส่งสิ่งที่ต้องทำให้คุณ และจะเตือนเกี่ยวกับสิ่งที่ต้องทำของคุณทุกวัน

คำสั่งก็ใช้ได้เช่นกัน: /todo lists, /todo new name (เพิ่ม --personal สำหรับรายการของคุณเอง), /todo add list: text เพื่อเพิ่มเข้ารายการตามชื่อ, /todo add text เพื่อเพิ่มเข้าสิ่งที่ต้องทำของคุณเอง และ /todo send @someone text.

GIF, สติกเกอร์ และมีม

คลิก อิโมจิ (หน้ายิ้ม) ในกล่องข้อความ: เมื่อแอปเหล่านี้ถูกตั้งค่าแล้ว ตัวเลือกจะมีแท็บ GIF, สติกเกอร์ และ มีม อยู่ข้างๆ อิโมจิ

  • GIF: ค้นหา หรือเรียกดูรายการโปรด, ใช้เมื่อไม่นาน, เทรนด์ และหมวดหมู่ คลิก GIF เพื่อส่งทันที คลิกดาวเพื่อเพิ่มเข้ารายการโปรดของคุณ คุณยังสามารถพิมพ์ /gif ตามด้วยคำบางคำได้
  • สติกเกอร์: ค้นหาหรือเรียกดูแพ็กเกจสติกเกอร์ แล้วคลิกสติกเกอร์เพื่อส่ง /sticker ก็ใช้ได้
  • มีม: เลือกเทมเพลต กรอกข้อความใน สร้างมีม ดูตัวอย่าง แล้วคลิก โพสต์มีม คุณสามารถพิมพ์ /meme หรือ /meme help เพื่อดูวิธีเขียนในบรรทัดเดียวได้

ขึ้นอยู่กับค่าการตั้งค่าของเซิร์ฟเวอร์ของคุณ คุณอาจสามารถเพิ่ม GIF, สติกเกอร์ หรือเทมเพลตมีมของคุณเองได้ด้วย+ ที่อยู่ถัดจากช่องค้นหา มันจะเปิดฟอร์มภายในตัวเลือก: เลือก, ลากวาง หรือวางไฟล์, ตรวจสอบตัวอย่าง, ตั้งชื่อ (ชื่อสำหรับเทมเพลตมีม) และถ้าต้องการ แท็กหรือคำหลัก จากนั้นคลิกเพิ่ม (บันทึกเทมเพลต สำหรับเทมเพลตมีม) สิ่งที่คุณเพิ่มจะแสดงเป็นอันดับแรกในตัวเลือก และทุกคนในเซิร์ฟเวอร์สามารถค้นหาได้ ปุ่มถัดจาก+ (จัดการ GIF, จัดการสติกเกอร์ หรือเทมเพลตมีมแบบกำหนดเอง) จะแสดงรายการสิ่งที่ผู้คนเพิ่ม พร้อมชื่อผู้เพิ่มและเวลา และให้คุณลบสิ่งที่คุณมีสิทธิ์ลบได้ แขกไม่สามารถเพิ่มหรือลบสิ่งใดได้

เพลยบุ๊ก

เพลย์บุ๊กคือรายการตรวจสอบที่นำกลับมาใช้ใหม่ได้สำหรับงานที่ต้องทำตามขั้นตอนเดิมทุกครั้ง: เหตุการณ์, การเปิดตัวผลิตภัณฑ์, การต้อนรับเพื่อนร่วมงานใหม่ ทุกครั้งที่คุณใช้ คุณจะเริ่มต้น รัน ซึ่งจะมีงาน, ผู้รับผิดชอบ, การอัปเดตสถานะ และท้ายที่สุดคือการทบทวน

  • คลิกเพลย์บุ๊ก ในแถบแอปเพื่อแสดงรันของช่องปัจจุบัน, เริ่มต้นรันด้วยรันเพลย์บุ๊ก, หรือสร้างรายการตรวจสอบใหม่อย่างรวดเร็ว ทุกอย่างในเพลย์บุ๊กจะเปิดในแผงนี้ พร้อมลูกศรย้อนกลับไปยังมุมมองก่อนหน้า
  • เพื่อค้นหาสิ่งอื่นทั้งหมด คลิกเรียกดูรัน, เพลย์บุ๊ก และงาน ที่ด้านบนของแผง: รันทั้งหมด, เพลย์บุ๊กทั้งหมด, งานของคุณ, และรายการโปรดและรันที่กำลังดำเนินการของคุณ
  • เพื่อสร้างเพลย์บุ๊ก ให้คลิก สร้างเพลย์บุ๊ก หรือ นำเข้า ในมุมมองนั้น; เพื่อแก้ไข ให้เปิดจาก เพลย์บุ๊กทั้งหมด เริ่มจากเทมเพลต เช่น การเปิดตัวผลิตภัณฑ์ การจัดการเหตุการณ์ หรือการต้อนรับพนักงานใหม่ หรือเริ่มจากเพลย์บุ๊กเปล่า ตัวแก้ไขเพลย์บุ๊กจะขยายแผงให้กว้างขึ้นขณะแสดง
  • เพื่อเริ่มรัน ให้คลิก รัน บนเพลย์บุ๊ก ตั้งชื่อและสรุปสำหรับรันนั้น เลือกที่จะสร้างช่องสำหรับมันหรือลิงก์กับช่องที่มีอยู่แล้ว แล้วคลิก เริ่มรัน คุณยังสามารถเลือก การดำเนินการเพิ่มเติม › รันเพลย์บุ๊ก ในเมนูของข้อความได้
  • ระหว่างรัน ให้ทำเครื่องหมายงานที่เสร็จ, มอบหมายและกำหนดวันครบกำหนด แล้วคลิก โพสต์อัปเดต เพื่อแจ้งให้ทุกคนทราบถึงสถานะปัจจุบัน เจ้าของคลิก เสร็จสิ้น เมื่อจบ

GitHub, GitLab และ Jira

แอปเหล่านี้เชื่อมต่อ Antimatter กับเครื่องมือที่นักพัฒนาใช้ ผู้ดูแลระบบของคุณต้องตั้งค่าก่อน จากนั้น:

  1. เชื่อมต่อบัญชีของคุณโดยพิมพ์ /github connect, /gitlab connect หรือ /jira connect จากนั้นคลิกลิงก์และเข้าสู่ระบบบนเว็บไซต์นั้น สำหรับ GitLab ให้ทำในเว็บเบราว์เซอร์ ไม่ใช่ในแอปเดสก์ท็อป
  2. หลังจากนั้นคุณจะได้รับข้อความส่วนตัวเมื่อมีคนเมนชันคุณ ร้องขอให้คุณรีวิว หรือมอบหมายงานให้คุณ
  3. หากต้องการให้ช่องติดตามรีพอสิทอรีหรือโปรเจกต์ ให้ใช้ /github subscriptions add owner/repo, /gitlab subscriptions add group/project หรือ /jira subscribe
  4. เพื่อสร้างหรือแนบปัญหาจากข้อความ ให้เลือก สร้าง GitHub Issue, สร้าง GitLab Issue, สร้าง Jira Issue หรือรายการ แนบกับ … ที่ตรงกันภายใต้ การดำเนินการเพิ่มเติม ในเมนูของข้อความ

พิมพ์ /github help, /gitlab help หรือ /jira help เพื่อดูคำสั่งสแลชทั้งหมด

แอปมือถือสามารถสร้างและโหวตโพล ส่ง GIF และสติกเกอร์ และตอบงานที่ส่งมาให้คุณ โน้ตและไวท์บอร์ดจะเปิดในหน้างายเว็บบราวเซอร์ภายในแอป ส่วน Kanban, Calendar, Mail และมีมยังไม่มีในแอปมือถือ: ใช้แอปเว็บบราวเซอร์หรือแอปเดสก์ท็อปสำหร้บสิ่่งเหล่านี
