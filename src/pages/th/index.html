แชต การโทร และแอปของทีมคุณ บนเซิร์ฟเวอร์ของคุณเอง

Antimatter รวมช่อง เธรด ห้องเสียง แอปสำหรับทำงานร่วมกัน และ AI ไว้ในที่เดียวที่คุณดูแลเอง โดยไม่มีฟีเจอร์ไหนถูกล็อกไว้หลังการจ่ายเงิน

ทำไมต้อง Antimatter

บทสนทนาของคุณ ยังคงเป็นของคุณ

เซิร์ฟเวอร์แชตเก็บทั้งการตัดสินใจ ไฟล์ และประวัติการทำงานของทีม Antimatter เก็บข้อมูลเหล่านี้ไว้บนโครงสร้างพื้นฐานที่คุณควบคุมเอง และไม่มีผู้ให้บริการรายใดมากำหนดว่าคุณใช้ฟีเจอร์ไหนได้บ้าง

{{icon:lock:spark}}

ฟีเจอร์ระดับองค์กร ไม่ต้องซื้อไลเซนส์

ไม่เก็บเงินเพิ่มสำหรับ SSO: การลงชื่อเข้าใช้ครั้งเดียวด้วย SAML และ OpenID Connect, การซิงก์ LDAP, การเก็บรักษาข้อมูล, การส่งออกข้อมูลเพื่อการปฏิบัติตามข้อกำหนด และอื่นๆ มาพร้อมกับทุกเซิร์ฟเวอร์ สำหรับทุกทีม

{{icon:code}}

โอเพนซอร์ส

เซิร์ฟเวอร์ทั้งหมดเป็นซอฟต์แวร์เสรีภายใต้ AGPL v3.0 คุณอ่าน ตรวจสอบ แก้ไข และนำไปให้คนใช้กี่คนก็ได้ตามต้องการ

ความปลอดภัยและความเสถียร

สร้างบนเซิร์ฟเวอร์ที่รองรับงานสำคัญมาร่วมสิบปี

Antimatter ทำงานบนเซิร์ฟเวอร์โอเพนซอร์สที่เติบโตเต็มที่แล้ว และได้รับความไว้วางใจในงานที่ความปลอดภัยสำคัญ ทั้งการส่งข้อความที่เชื่อถือได้ โมเดลข้อมูลที่เสถียร และ API ที่มีเอกสารครบ ระบบที่คุณติดตั้งและการเชื่อมต่อต่างๆ จึงทำงานต่อได้ทุกครั้งที่อัปเดตเวอร์ชัน

  • ผู้ให้บริการยืนยันตัวตนของคุณ: SAML, OpenID Connect, Google, Microsoft Entra, การซิงก์ LDAP และ Active Directory รวมถึงการยืนยันตัวตนแบบหลายปัจจัย
  • การควบคุมสิทธิ์อย่างละเอียด: บทบาท แผนสิทธิ์ การควบคุมการเข้าถึงตามแอตทริบิวต์ บัญชีแขก และการกรอง IP
  • การปฏิบัติตามข้อกำหนด: นโยบายการเก็บรักษาข้อมูล การส่งออกข้อมูลเพื่อการปฏิบัติตามข้อกำหนด บันทึกการตรวจสอบ แบนเนอร์ระดับชั้นความลับ และข้อความที่ลบตัวเองเมื่ออ่านแล้ว
  • ไม่มีการเก็บข้อมูลการใช้งาน: เซิร์ฟเวอร์ไม่ส่งข้อมูลใดๆ กลับไปยังผู้พัฒนา และจะเชื่อมต่อออกไปภายนอกก็ต่อเมื่อคุณเปิดใช้ฟีเจอร์ที่ต้องใช้เท่านั้น
แอปและ ChatOps

ทำงานร่วมกันได้โดยไม่ต้องออกจากบทสนทนา

แอปของ Antimatter เปิดอยู่ข้างแชต แชร์ให้ช่องได้ในคลิกเดียว และอัปเดตแบบเรียลไทม์ให้ทุกคนเห็นพร้อมกัน

  • โน้ต: เอกสารที่แก้ไขร่วมกันได้แบบเรียลไทม์
  • ไวท์บอร์ด: วาดภาพ ร่างไดอะแกรม และระดมความคิดบนพื้นที่วาดร่วมกัน
  • บอร์ดและเพลย์บุ๊ก: คัมบังบอร์ดสำหรับโปรเจกต์ และเช็กลิสต์สำหรับรับมือเหตุการณ์และกระบวนการที่ทำซ้ำ
  • รายการสิ่งที่ต้องทำ โพล ปฏิทิน และอีเมล: งาน การตัดสินใจแบบเร็วๆ กิจกรรมของคุณ และกล่องจดหมาย อยู่ใกล้ๆ ทีมของคุณ
AI ตามเงื่อนไขของคุณ

ผู้ช่วยที่ทำงานกับโมเดลที่คุณเลือก

AI อยู่ในมุมของมัน: ปุ่มหนึ่งปุ่มในช่องพิมพ์ข้อความ แผงที่คุณเปิดเอง หรือสรุปเมื่อคุณขอ มีให้ใช้เมื่อต้องการความช่วยเหลือ และไม่เข้ามากวนในเวลาที่เหลือ เชื่อมต่อโมเดลใดก็ได้ที่เข้ากันได้กับ OpenAI รวมถึงโมเดลที่รันบน GPU ของคุณเอง ข้อมูลของคุณจะไม่ถูกส่งไปที่ไหนที่คุณไม่ได้เลือกเอง

  • เรียบเรียงใหม่และแก้ไขข้อความก่อนส่ง: ให้ชัดขึ้น สั้นลง เป็นมิตรขึ้น หรือแค่ให้ถูกต้อง
  • ข้อความถอดเสียงและสรุปการโทร: คำบรรยายสดระหว่างการโทร จากนั้นจึงได้ข้อความถอดเสียงและสรุปในเธรดของการโทร
  • แผงเอเจนต์: ถามคำถามเกี่ยวกับช่อง เธรด หรืองานของคุณ ภายใต้สิทธิ์ของคุณ
  • สรุปช่องและสรุปย้อนหลัง: ตามทันสิ่งที่พลาดไปได้ในไม่กี่บรรทัด
  • แปลภาษาอัตโนมัติในช่อง และอ่านออกเสียงข้อความใดก็ได้เมื่อต้องการ
การโทรและห้องเสียง

พูดคุยได้ง่ายเหมือนพิมพ์

เริ่มการโทรจากบทสนทนาไหนก็ได้ หรือแวะเข้าช่องเสียงที่เปิดไว้ตลอด เหมือนทีมเดินเข้าห้องประชุม

  • ช่องเสียงในแถบด้านข้าง เห็นว่าใครอยู่ในช่องและใครกำลังพูด
  • วิดีโอและการแชร์หน้าจอ พร้อมค่าคุณภาพสำเร็จรูป การเบลอพื้นหลัง และภาพซ้อนภาพ
  • การยกมือ รีแอคชัน และการปรับเสียงรายบุคคล การกดเพื่อพูด และการควบคุมโดยผู้จัด
  • คำบรรยายสดและข้อความถอดเสียง ด้วยโมเดลแปลงเสียงพูดเป็นข้อความของคุณเอง
การเชื่อมต่อ

เชื่อมกับเครื่องมือที่คุณใช้อยู่แล้ว

REST API ที่ครบถ้วน เว็บฮุค บอท และปลั๊กอิน นำเครื่องมืออื่นๆ ของคุณเข้ามาในบทสนทนา และการเชื่อมต่อที่เขียนไว้สำหรับ Mattermost ก็ใช้ได้เช่นกัน

  • GitHub, GitLab และ Jira: การแจ้งเตือน ตัวอย่างเนื้อหา และการดำเนินการต่างๆ ในช่องของคุณ
  • เว็บฮุค คำสั่งสแลช และบอท สำหรับเชื่อมต่อทุกอย่าง ตั้งแต่ไปป์ไลน์ CI ไปจนถึงระบบมอนิเตอร์
  • ข้อความและกล่องโต้ตอบแบบอินเทอร์แอคทีฟ สำหรับการอนุมัติและแบบฟอร์มในแชตได้ทันที
  • ปลั๊กอิน ที่เพิ่มแอป ประเภทข้อความ คำสั่ง และแผงต่างๆ

พร้อมใช้งานในไม่กี่นาที

ไฟล์ compose ไฟล์เดียวก็เปิดใช้ Antimatter พร้อมฐานข้อมูล ที่เก็บไฟล์ และบริการ GIF ได้ครบ บัญชีแรกที่คุณสร้างจะเป็นผู้ดูแลระบบ

$ curl -fsSLO https://antimatter.chat/compose.yaml
$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
$ docker compose up -d
