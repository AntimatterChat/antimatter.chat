ฟีเจอร์

ทุกสิ่งที่ทีมของคุณต้องการ ในที่เดียวที่คุณเป็นเจ้าของ

พาชม Antimatter พร้อมภาพหน้าจอจากเซิร์ฟเวอร์สาธิต ทุกฟีเจอร์ในหน้านี้รวมอยู่ในซอฟต์แวร์เสรี โดยไม่มีอะไรถูกเก็บไว้ให้เฉพาะรุ่นที่ต้องจ่ายเงิน

การส่งข้อความ

บทสนทนาที่เป็นระเบียบอยู่เสมอ

ช่องที่จัดกลุ่มตามหมวดหมู่ ข้อความส่วนตัวและข้อความกลุ่ม รวมถึงเธรด ในอินเทอร์เฟซที่ออกแบบมาสำหรับวันทำงานที่ยาวนาน

  • ช่องและหมวดหมู่: ช่องสาธารณะและช่องส่วนตัว หมวดหมู่ที่ผู้ดูแลตั้งไว้ให้ทุกคน รายการโปรด และการติดตาม
  • เธรดและแชตย่อยที่ตั้งชื่อได้: ตอบกลับในเธรด ตั้งชื่อเธรดเพื่อให้แสดงอยู่ใต้ช่องของมัน และติดตามเธรดที่คุณสนใจ
  • ข้อความที่จัดรูปแบบได้หลากหลาย: Markdown โค้ดพร้อมไฮไลต์ไวยากรณ์ ตาราง LaTeX ตัวอย่างลิงก์ และไฟล์พร้อมตัวอย่าง
  • ระดับความสำคัญของข้อความ: ข้อความด่วนและข้อความสำคัญ การแจ้งเตือนถาวร และการรับทราบ
  • ข้อความตั้งเวลาส่งและฉบับร่าง การเตือนความจำ การส่งต่อ การแก้ไขพร้อมประวัติ และข้อความที่บันทึกไว้
  • ค้นหาข้อความและไฟล์ พร้อมตัวกรอง วลีที่ตรงทุกคำ และวันที่
คอมมูนิตี้

คอมมูนิตี้ที่มีบทบาท ป้าย และกฎของตัวเอง

จะดูแลบริษัทหรือคอมมูนิตี้ Antimatter ก็มีเครื่องมือสำหรับต้อนรับผู้คนและรักษาบรรยากาศที่ดี

  • บทบาทที่แสดงผลและป้ายทีม: บทบาทที่มีสี บทบาทที่สมาชิกเลือกเองได้ และป้ายข้างชื่อ
  • การต้อนรับสมาชิกใหม่: หน้าต้อนรับและคำถามที่มอบบทบาทและช่องที่เหมาะสมให้ผู้มาใหม่
  • การกำหนดสิทธิ์ทับรายหมวดหมู่และรายช่อง เพิ่มเติมจากแผนสิทธิ์ของเซิร์ฟเวอร์
  • การดูแลความเรียบร้อย: การพักการใช้งานชั่วคราว มุมมองสำหรับผู้ดูแล การรายงานข้อความ และการกักข้อความ
แอป

แอปสำหรับทำงานร่วมกัน ติดตั้งมาในตัว

แอปจะเปิดข้างแชต ในแผงหรือในหน้าต่างของตัวเอง และทุกอย่างที่คุณแชร์ให้ช่องจะอัปเดตแบบเรียลไทม์ให้ทุกคนในช่องเห็น

โน้ต

เอกสารที่แก้ไขร่วมกันได้แบบเรียลไทม์ พร้อมหัวข้อ รายการ เช็กลิสต์ และโค้ด เก็บไว้ใช้เองหรือแชร์ให้ช่องก็ได้

ไวท์บอร์ด

พื้นที่วาดร่วมกันพร้อมรูปทรง ลูกศร ข้อความ คลังรูปทรงที่ผู้ดูแลของคุณเพิ่มเข้ามา และเคอร์เซอร์ของทุกคน โดยไม่ติดต่อบริการภายนอกใด ๆ เลย

คัมบัง

บอร์ด ตาราง และปฏิทินสำหรับโปรเจกต์ พร้อมการ์ด คุณสมบัติ และมุมมองต่างๆ ลิงก์กับช่องที่ทำงานในโปรเจกต์นั้น

เพลย์บุ๊ก

เช็กลิสต์สำหรับรับมือเหตุการณ์ การออกรีลีส และการรับพนักงานใหม่ พร้อมผู้รับผิดชอบ การอัปเดตสถานะ และการทบทวนหลังเหตุการณ์

{{icon:mail:spark}}

โพล

เลือกได้คำตอบเดียวหรือหลายคำตอบ พร้อมเวลาปิดโหวตและผลแบบเรียลไทม์

AI

AI ที่ทำงานในที่ที่คุณกำหนด

ช่วยเมื่อคุณขอ และเงียบในเวลาที่เหลือ เอเจนต์ของ Antimatter ทำงานร่วมกับ OpenAI, Anthropic, Azure, Mistral, Gemini, Bedrock หรือเซิร์ฟเวอร์ใดก็ได้ที่เข้ากันได้กับ OpenAI ซึ่งคุณรันเอง เช่น vLLM, llama.cpp หรือ Ollama

เรียบเรียง แก้ไข และแปลขณะพิมพ์

ให้ช่องพิมพ์ข้อความช่วยแก้การสะกดและไวยากรณ์ ย่อให้สั้นลง ทำให้ชัดเจนขึ้น เปลี่ยนน้ำเสียงของข้อความ หรือแปลก่อนส่ง

แผงเอเจนต์

คุยกับเอเจนต์ของคุณข้างช่องใดก็ได้: สรุปช่อง หาข้อสรุปที่เคยตัดสินกันไว้ ร่างคำตอบ หรือใช้เครื่องมือผ่านเซิร์ฟเวอร์ MCP

ข้อความถอดเสียงและสรุปการโทร

การโทรจะถูกถอดเสียงด้วยโมเดลแปลงเสียงพูดเป็นข้อความของคุณ แสดงเป็นคำบรรยายสด แล้วโพสต์เป็นข้อความถอดเสียงพร้อมสรุปจาก AI ในเธรดของการโทร

สรุปย้อนหลังและสรุปช่อง

กลับจากวันหยุดแล้วตามงานทันได้ด้วยสรุปย้อนหลังของช่องที่คุณเลือก และสรุปเธรดยาวๆ

{{icon:bell}}

ตอบกลับอัจฉริยะ

เอเจนต์ตอบในช่องที่คุณเลือกได้ ภายใต้สิทธิ์ของทีมคุณ

การโทรและช่องเสียง

ห้องเสียงที่เปิดอยู่ตลอดเวลา

ช่องเสียงอยู่ในแถบด้านข้างเหมือนช่องอื่นๆ คลิกเพื่อเข้าร่วม ดูว่าใครอยู่บ้าง แล้วเริ่มคุยได้เลย และยังเริ่มการโทรจากบทสนทนาใดก็ได้ด้วย

  • วิดีโอ การแชร์หน้าจอ และการเบลอพื้นหลัง พร้อมค่าคุณภาพสำเร็จรูปสำหรับแชร์โค้ดหรือสไลด์
  • การยกมือพร้อมคิว รีแอคชัน และการปรับเสียงรายบุคคล
  • กดเพื่อพูด การควบคุมโดยผู้จัด และหน้าต่างการโทรแยกต่างหาก
  • คำบรรยายสดและข้อความถอดเสียงจากเซิร์ฟเวอร์แปลงเสียงพูดเป็นข้อความของคุณเอง โดยไม่ต้องมีโครงสร้างพื้นฐานเพิ่ม
การเชื่อมต่อและ ChatOps

เครื่องมือของคุณ ส่งข่าวสารในช่องของคุณ

REST API และระบบปลั๊กอินที่ครบถ้วน พร้อมการเชื่อมต่อของตัวเอง

  • GitHub, GitLab และ Jira: การติดตามอัปเดต ตัวอย่างเนื้อหา และคำสั่งสแลช
  • เว็บฮุคขาเข้าและขาออก คำสั่งสแลช บอท และแอป OAuth
  • ข้อความและกล่องโต้ตอบแบบอินเทอร์แอคทีฟ: ปุ่ม เมนู และแบบฟอร์มที่ส่งข้อมูลกลับไปยังบริการของคุณ
  • ปลั๊กอิน ที่เพิ่มแอป แผง คำสั่ง และประเภทข้อความลงในอินเทอร์เฟซของ Antimatter
การดูแลระบบและความปลอดภัย

ครบทุกอย่างที่ผู้ดูแลระบบคาดหวัง

คอนโซลระบบที่ครบถ้วน และใช้การตั้งค่าได้ทุกอย่างในทุกเซิร์ฟเวอร์

  • การยืนยันตัวตน: SAML 2.0, OpenID Connect, Google, Microsoft Entra, LDAP/Active Directory, MFA
  • การควบคุมการเข้าถึง: แผนสิทธิ์ การเข้าถึงตามแอตทริบิวต์ บัญชีแขก การกรอง IP
  • การปฏิบัติตามข้อกำหนด: การเก็บรักษาข้อมูล การส่งออกข้อมูลเพื่อการปฏิบัติตามข้อกำหนดและการส่งออกข้อความ บันทึกการตรวจสอบ
  • การดำเนินงานระบบ: การค้นหาด้วย Elasticsearch หรือ OpenSearch เมตริก Prometheus ที่เก็บไฟล์ที่เข้ากันได้กับ S3
  • แบรนด์: ชื่อไซต์ โลโก้ และข้อความหน้าลงชื่อเข้าใช้ของคุณ อิโมจิที่กำหนดเอง และธีม

การรับทราบ
