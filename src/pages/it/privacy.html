Informativa sulla privacy

Ultimo aggiornamento: 16 ottobre 2026.

Questa pagina copre due aspetti: il software Antimatter, che le organizzazioni eseguono sui propri server, e questo sito web, antimatter.chat.

Il software Antimatter

Antimatter è self-hosted. Quando si utilizza un server Antimatter, l'organizzazione che lo gestisce decide quali dati vengono conservati, per quanto tempo e chi può accedervi. Il progetto Antimatter non ha accesso al tuo server, al tuo account o ai tuoi messaggi. Per domande relative ai tuoi dati su un server specifico, contatta i suoi amministratori; si applica la loro politica sulla privacy.

Cosa fa il software in autonomia:

  • Nessuna telemetria. Il server non invia statistiche di utilizzo, diagnostiche o altri dati al progetto Antimatter, a Mattermost, Inc. (il software su cui si basa Antimatter) o ad altri terzi.
  • Connessioni esterne solo per le funzioni attivate da un amministratore, verso i servizi da questi configurati: ad esempio un servizio di notifica push, un provider di GIF, un server di posta, un provider di identità per il single sign-on, o modelli di AI, voce o traduzione.
  • Due eccezioni, attive di default, che gli amministratori possono disattivare. Anteprime dei collegamenti: quando qualcuno pubblica un link, il server recupera la pagina per mostrarne titolo e immagine. E chiamate: utilizzano il server STUN pubblico di Cloudflare (stun.cloudflare.com) per individuare gli indirizzi di rete pubblici. Il server lo interroga all'avvio dell'app Chiamate, e il dispositivo di ogni partecipante lo interroga quando si unisce a una chiamata. Cloudflare vede solo l'indirizzo IP e la porta del server e di ciascun partecipante, non la chiamata in sé. Gli amministratori possono utilizzare un proprio server STUN, oppure nessuno; consulta Chiamate e voce.
  • Le funzioni di AI utilizzano i modelli scelti dall'amministratore. Quando sono ospitati da un terzo, ciò che viene inviato loro (un messaggio da riscrivere, una conversazione da riassumere, l'audio di una chiamata trascritta) va a quel provider. Gli amministratori possono utilizzare modelli self-hosted in modo che nulla lasci la loro rete.

Questo sito web

  • antimatter.chat è un sito web statico ospitato su GitHub Pages.
  • Non imposta cookie e non utilizza strumenti di analisi, tracciamento o pubblicità. I font e le immagini vengono forniti direttamente dal sito, quindi il tuo browser non effettua richieste ad altri siti web durante la lettura.
  • Come qualsiasi host web, GitHub riceve il tuo indirizzo IP e le pagine che richiedi, per servirti il contenuto. Consulta la dichiarazione sulla privacy di GitHub.
  • Se apri un problema o contribuisci su GitHub, ciò che pubblichi lì è pubblico e gestito da GitHub secondo i propri termini.

Contatti
