Di cosa è composta una distribuzione

Antimatter è una chat di lavoro self-hosted, un fork di Mattermost. Una distribuzione completa è composta dalle seguenti parti. Solo le prime tre sono obbligatorie.

ComponenteFunzioneObbligatoria
Il server AntimatterUn programma Go (antimatter) che fornisce l'app web, l'API e i websockets sulla porta 8065, esegue le app integrate (plugin) e gestisce i media delle chiamate sulla porta 8443. Lo strumento da riga di comando amctl ne gestisce l'amministrazione.sì
PostgreSQLIl database: messaggi, utenti, community e, nella configurazione consigliata, la configurazione del server. Versione 15 o successiva.sì
Archiviazione fileFile caricati, immagini e app installate: un servizio compatibile con S3 (il file compose esegue RustFS) o una directory locale.sì
Un proxy inversoHTTPS davanti al server: il profilo Caddy del file compose, oppure il proprio nginx.per la produzione
Il servizio GIF (gifs-server)GIF e sticker per il selettore di GIF, dal proprio catalogo. Comunica tramite l'API di Tenor.no
Un proxy pushInoltra le notifiche all'app mobile tramite Apple e Google.per le notifiche mobili
rtcd, un server TURNUn server media separato per molte chiamate, e un relay per le persone dietro firewall restrittivi.no
Punti di accesso AII modelli alla base della riscrittura, dei riepiloghi, della traduzione, della lettura ad alta voce, degli agenti AI e della trascrizione delle chiamate, aggiunti come connessioni ai modelli: un provider cloud o server gestiti da voi.no

Antimatter non ha licenze a pagamento né edizioni a pagamento: il single sign-on, LDAP, l'alta disponibilità, le esportazioni per la conformità, la conservazione dei dati e le altre funzionalità che Mattermost riserva ai suoi piani a pagamento sono tutte incluse.

Requisiti

  • Un server Linux, amd64 o arm64, con 2 core CPU e 4 GB di memoria o più per alcune centinaia di persone, e spazio su disco per i file caricati dagli utenti.
  • Docker Engine con il plugin Compose (docker compose), per l'installazione consigliata. Oppure, per i pacchetti, un server compatibile con Debian, Ubuntu, Fedora o RHEL con systemd.
  • Per la produzione: un nome di dominio che punti al server, e le porte 80 e 443 aperte per HTTPS.
  • Per le chiamate: la porta 8443, UDP e TCP, raggiungibile dalle persone che effettuano le chiamate.
  • Per la posta elettronica: un server SMTP attraverso cui Antimatter può inviare.

Avvio rapido

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)
EOF
docker compose up -d

Quindi apri l'URL del sito e crea il tuo account: il primo account diventa l'amministratore di sistema. Installazione spiega ogni passaggio e gli altri metodi di installazione.

In questa guida

  • Installazione: Docker Compose, le immagini, il primo amministratore, i pacchetti .deb e .rpm, l'archivio di rilascio.
  • Configurazione: impostazioni nel database o in un file, variabili d'ambiente AM_, la Console di Sistema, amctl, log.
  • Dominio e HTTPS: l'URL del sito, Caddy, nginx, indirizzi dei client.
  • Chiamate e voce: porte, NAT, TURN, rtcd, trascrizione e sottotitoli.
  • Email e notifiche push: SMTP, il proxy push e l'app mobile.
  • App integrate: quali app sono attive, le loro impostazioni, l'installazione di altre app.
  • AI: connessioni ai modelli, le funzionalità AI integrate, agenti, voce e traduzione, la chiave di crittografia e dove vanno i dati.
  • Accesso e account: registrazione, password, MFA, single sign-on, LDAP, ospiti, sessioni.
  • Backup e aggiornamenti: backup, ripristino, aggiornamento, migrazione da Mattermost.
  • Operatività: monitoraggio, scalabilità, conservazione dei dati, conformità, risoluzione dei problemi.
  • Sicurezza: checklista di hardening e connessioni esterne.
  • Distribuzione dell'app desktop: MSI, Group Policy e Intune, profili macOS e file di policy Linux.

Gestisci una community anziché un server (canali, ruoli, moderazione)? Consulta Gestione di una community. Stai creando integrazioni? Consulta Sviluppo su Antimatter.

La tua prima ora

  1. Installa e crea subito l'account amministratore.
  2. Metti il server dietro HTTPS su un dominio dedicato.
  3. Configura SMTP e invia un'email di prova.
  4. Apri la porta delle chiamate. Per un'azienda, imposta il tipo di nuove community su Ambiente di lavoro, in modo che le chiamate siano attive nei canali.
  5. Decidi chi può registrarsi e attiva MFA.
  6. Rivedi le connessioni esterne in Sicurezza.
  7. Configura i backup giornalieri. Prima di aggiungere le connessioni ai modelli AI, imposta la chiave di crittografia AI.
