"Compatibile con OpenAI" significa un server che offre la stessa API HTTP di OpenAI. La maggior parte dei server di modelli che puoi eseguire tu stesso lo fa (ad esempio Ollama, vLLM, il server di llama.cpp, o i server per la conversione da voce a testo e da testo a voce), così come molti provider cloud. Non è necessaria alcuna licenza per nessuna di queste funzionalità.

Agenti IA

L'app Agents (id mattermost-ai) è attiva di default. La sua configurazione richiede due passaggi: aggiungere un servizio (una connessione a un provider di modelli) e quindi creare agenti (bot che utilizzano un servizio).

1. Aggiungi un servizio

Vai a Console di Sistema › Plugins › Agenti e, sotto Servizi AI, fai clic su Aggiungi un servizio AI. Scegli il Tipo di servizio:

  • OpenAI Compatible: per un server di modelli che gestisci tu stesso, o per qualsiasi provider con un'API in stile OpenAI. Compila API URL (ad esempio http://ollama:11434/v1 o http://vllm.internal:8000/v1) e Chiave API solo se il server ne richiede una. Se il server supporta solo l'API Chat Completions, disattiva Use Responses API.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: provider ospitati. Ognuno richiede la propria Chiave API (Bedrock: una regione AWS e le credenziali o un ruolo IAM; Vertex AI: un progetto, una regione e un account di servizio; Azure: anche l'API URL).

Poi imposta il Modello predefinito (una lista se il provider può riportare i suoi modelli, altrimenti digita il nome) e, se il provider non li riporta, il Limite di token in input e il Limite di token in output. Un Servizio di backup può subentrare in caso di errore. Salva.

Il server effettua queste richieste in autonomia, quindi deve poter raggiungere l'API: un server di modelli nello stesso progetto compose, sulla tua rete o su Internet. Le richieste in uscita rispettano le variabili HTTP_PROXY e HTTPS_PROXY.

2. Crea agenti

Gli agenti vengono creati nella pagina Agenti dell'app web: aprila dal menu del prodotto, oppure con Gestisci nel selettore degli agenti del pannello Agenti. Il suo indirizzo è https://chat.example.com/plug/mattermost-ai/agents. Ogni agente ha un Nome visibile, un Nome utente agente (come viene menzionato dalle persone), un Servizio e, facoltativamente, un modello, Istruzioni personalizzate e interruttori per Enable Vision (immagini) e Enable Tools. La sua scheda Accesso limita in quali canali può essere utilizzato e quali utenti possono usarlo. Sotto Funzioni AI nella Console di Sistema, Bot predefinito seleziona l'agente utilizzato quando nessuno è scelto, ad esempio per i riepiloghi delle chiamate.

Per impostazione predefinita, ogni utente può creare i propri agenti, utilizzando i servizi configurati. Per riservare questa funzione agli amministratori, rimuovi il permesso Agenti AI personali dal ruolo dei membri in Console di Sistema › Gestione utenti › Permessi.

Funzionalità facoltative dell'app Agenti

  • Ricerca con embedding (sperimentale, disattivata): ricerca semantica sui messaggi. Richiede PostgreSQL con l'estensione pgvector e un modello di embedding (OpenAI o compatibile con OpenAI). Invia ogni messaggio al modello di embedding, inclusi i canali privati e i messaggi diretti.
  • Ricerca web (disattivata): consente agli agenti di cercare sul web tramite Google, Brave o un server SearXNG gestito da te.
  • Strumenti nativi: con i provider che li offrono, gli agenti possono utilizzare la ricerca web del provider stesso (abilitata di default per i nuovi agenti, dove supportato), il recupero da web e l'esecuzione del codice. Questi vengono eseguiti presso il provider. Disattivali per ogni agente.
  • Model Context Protocol (MCP): collega gli agenti a server MCP di cui ti fidi, per strumenti aggiuntivi.
  • Debug: Output di tracciamento (disattivato, log del server o endpoint OpenTelemetry) e Abilita registrazione utilizzo token, che scrive i conteggi dei token in logs/agents/token_usage.log.

Conversione da voce a testo: trascrizioni e sottotitoli delle chiamate

Le chiamate possono essere trascritte, con sottotitoli in tempo reale, da un server speech-to-text che offre un endpoint /v1/audio/transcriptions compatibile con OpenAI. La configurazione è in Chiamate e voce. Con Riepiloga trascrizioni attivo, l'agente predefinito pubblica anche un riepilogo di ogni trascrizione.

Conversione da testo a voce: lettura ad alta voce

Con la conversione da testo a voce attiva, il menu di ogni messaggio include Leggi ad alta voce: il server invia il testo del messaggio a un'API di conversione da testo a voce e riproduce l'audio. Le impostazioni si trovano in Console di Sistema › Integrazioni › Conversione da testo a voce:

ImpostazioneChiave e variabileCosa inserire
Leggi i messaggi ad alta voceTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (disattivato di default)
URL di base APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLL'URL base fino a e incluso /v1, ad esempio http://tts.internal:8000/v1. Il server chiama il suo endpoint /audio/speech.
ModelloTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELIl modello come denominato dall'API, ad esempio tts-1. Obbligatorio.
VoceTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEUna delle voci del modello, oppure vuoto per usare quella predefinita.
Chiave APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYInviato come token bearer. Lasciare vuoto se l'API non ne richiede uno.

Prima dell'invio, il server rimuove i blocchi di codice, i collegamenti, i codici emoji e la formattazione, mantenendo al massimo 4000 caratteri. Richiede audio in formato MP3 e conserva gli ultimi 64 risultati in memoria, in modo che un messaggio letto due volte venga inviato solo una volta.

Traduzione automatica

La traduzione automatica mostra i messaggi di un canale nella lingua di ciascun lettore. Configurala in Console di Sistema › Configurazione sito › Localizzazione, sotto Traduzione automatica:

ImpostazioneChiavePredefinito
AbilitaAutoTranslationSettings.Enabledisattivato
Provider di traduzioneAutoTranslationSettings.Providerlibretranslate, openai (visualizzato come "API compatibile con OpenAI") o agents (un servizio dell'app Agenti)
Lingue consentiteAutoTranslationSettings.TargetLanguagesen: le lingue in cui i messaggi possono essere tradotti
Timeout di traduzione (ms)AutoTranslationSettings.TimeoutMs5000
Limita la traduzione automatica per i messaggi diretti e i messaggi di gruppoAutoTranslationSettings.RestrictDMAndGMdisattivato

Ogni provider ha i propri campi:

  • LibreTranslate: Endpoint API di LibreTranslate e Chiave API di LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Un server LibreTranslate può essere eseguito sulla tua rete.
  • API compatibile con OpenAI: URL di base API (fino a e incluso /v1; il server utilizza il suo endpoint chat completions), Modello e Chiave API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Un piccolo modello di traduzione eseguito localmente funziona bene.
  • Agenti: Servizio AI, uno dei servizi configurati nell'app Agenti.

Una volta attivato, gli amministratori dei canali attivano la traduzione per un canale nelle sue impostazioni (Traduzione automatica), e ogni membro può disattivarla dal menu del canale (Traduci messaggi). Nei messaggi diretti e di gruppo, qualsiasi membro può attivarla; con la restrizione attiva, la traduzione non è disponibile lì. I messaggi tradotti mostrano "Tradotto da …" con un link all'originale.

Il codice, i collegamenti, le menzioni e le emoji vengono sostituiti da segnaposto prima dell’invio del testo, per poi essere ripristinati successivamente.

Per mantenere tutto all’interno della tua rete, indirizza ogni funzionalità verso server che gestisci tu stesso. Se utilizzi un provider cloud, verifica i termini di conservazione dei dati e informa gli utenti su quali funzionalità inviano i loro messaggi all’esterno.

Disattivare l’IA

Non esiste un unico interruttore: ogni funzionalità ha il proprio.

  • Agenti: disabilita l'app Agenti in Console di Sistema › Plugins › Gestione plugin. Questo rimuove anche i riepiloghi delle chiamate e il provider di traduzione degli Agenti.
  • Trascrizione e sottotitoli: AM_CALLS_ENABLE_TRANSCRIPTIONS=false e AM_CALLS_ENABLE_LIVE_CAPTIONS=false (valori predefiniti).
  • Leggi ad alta voce: disattiva Leggi i messaggi ad alta voce (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, il valore predefinito).
  • Traduzione: disattiva la traduzione automatica (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, valore predefinito).

Disabilitare l’app Agenti non disattiva le altre tre funzionalità: queste chiamano direttamente le proprie API.
