Zásady ochrany osobních údajů

Poslední aktualizace: 11. října 2026. Tento překlad slouží pouze pro informaci; v případě rozporu má přednost anglická verze.

Tato stránka se týká dvou věcí: softwaru Antimatter, který organizace provozují na vlastních serverech, a tohoto webu, antimatter.chat.

Software Antimatter

Antimatter je software, který si každý provozuje sám. Když používáte server Antimatter, o tom, jaká data se uchovávají, jak dlouho a kdo k nim má přístup, rozhoduje organizace, která server provozuje. Projekt Antimatter nemá přístup k vašemu serveru, vašemu účtu ani vašim zprávám. S dotazy ohledně vašich dat na konkrétním serveru se obracejte na jeho administrátory; platí jejich vlastní zásady ochrany osobních údajů.

Co software dělá sám od sebe:

  • Žádná telemetrie. Server neodesílá statistiky používání, diagnostické údaje ani žádná jiná data projektu Antimatter ani třetím stranám.
  • Spojení ven jen kvůli funkcím, které zapne administrátor, a jen ke službám, které sám nastaví: například ke službě push oznámení, k webům, na které vedou odkazy ve zprávách (kvůli náhledům odkazů), k poskytovateli GIFů, k e-mailovému serveru, k poskytovateli identity pro jednotné přihlašování nebo k modelům AI, řeči či překladu.
  • Funkce AI používají modely, které zvolí administrátor. Pokud tyto modely hostuje třetí strana, to, co se jim posílá (zpráva k přepsání, konverzace ke shrnutí, zvuk přepisovaného hovoru), putuje k tomuto poskytovateli. Administrátoři mohou používat modely provozované na vlastní infrastruktuře, aby nic neopustilo jejich síť.

Tento web

  • antimatter.chat je statický web hostovaný na GitHub Pages.
  • Nenastavuje žádné cookies a nepoužívá žádnou analytiku, sledovací nástroje ani reklamu. Písma a obrázky se načítají přímo z tohoto webu, takže váš prohlížeč při čtení neposílá žádné požadavky na jiné weby.
  • Jako každý poskytovatel hostingu dostává GitHub vaši IP adresu a informace o tom, které stránky si vyžádáte, aby vám je mohl doručit. Viz GitHub Privacy Statement.
  • Pokud na GitHubu založíte issue nebo jinak přispějete, vše, co tam zveřejníte, je veřejné a GitHub s tím nakládá podle svých vlastních podmínek.
