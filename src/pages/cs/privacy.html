Zásady ochrany osobních údajů

Naposledy aktualizováno: 16. října 2026.

Tato stránka se zabývá dvěma věcmi: softwarem Antimatter, který organizace provozují na svých vlastních serverech, a tímto webem, antimatter.chat.

Software Antimatter

Antimatter je self-hosted. Když používáte server Antimatter, organizace, která ho provozuje, rozhoduje, jaká data se uchovávají, jak dlouho a kdo má k nim přístup. Projekt Antimatter nemá přístup k vašemu serveru, vašemu účtu ani vašim zprávám. S dotazy na vaše data na konkrétním serveru se obraťte na jeho administrátory; platí jejich vlastní zásady ochrany osobních údajů.

Co software dělá sám o sobě:

  • Žádná telemetrie. Server neodesílá statistiky použití, diagnostiku ani žádná jiná data projektu Antimatter, společnosti Mattermost, Inc. (na jejímž software je Antimatter založen) ani jiným třetím stranám.
  • Připojení k vnějším službám pouze pro funkce, které zapne administrátor, ke službám, které nastaví: například službu pro push notifikace, poskytovatele GIF, e-mailový server, poskytovatele identit pro jednotné přihlašování (single sign-on) nebo modely pro AI, rozpoznávání řeči nebo překlad.
  • Dvě výjimky, které jsou zapnuté ve výchozím nastavení, ale administrátory je lze vypnout. Náhledy odkazů: když někdo pošle odkaz, server načte danou stránku, aby zobrazil její název a obrázek. A hovory: používají veřejný STUN server Cloudflare (stun.cloudflare.com) k nalezení veřejných síťových adres. Server se ho zeptá, když se spustí aplikace Hovory, a zařízení každého účastníka se ho zeptá, když se připojí k hovoru. Cloudflare vidí pouze IP adresu a port serveru a každého připojujícího se účastníka, ne samotný hovor. Administrátoři mohou místo toho použít vlastní STUN server, nebo žádný; viz Hovory a hlas.
  • Funkce AI používají modely, které zvolí administrátor. Pokud jsou hostovány třetí stranou, to, co se k nim odešle (zpráva k přepsání, konverzace k shrnutí, audio z přepsaného hovoru), putuje k tomuto poskytovateli. Administrátoři mohou použít self-hosted modely, aby nic neopustilo jejich síť.

Tento web

  • antimatter.chat je statický web hostovaný na GitHub Pages.
  • Nepoužívá žádné soubory cookie ani žádnou analýzu, sledování nebo reklamu. Písma a obrázky se načítají přímo z tohoto webu, takže váš prohlížeč při čtení neprovádí žádné požadavky na jiné weby.
  • Jako každý webový hostitel přijímá GitHub vaši IP adresu a požadované stránky, aby je mohl poskytnout. Viz GitHub Privacy Statement.
  • Pokud na GitHubu založíte issue nebo přispějete, vše, co tam zveřejníte, je veřejné a GitHub s ním nakládá podle svých podmínek.
