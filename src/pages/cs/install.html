Spusťte Antimatter na vlastním serveru

Jeden soubor, tři příkazy, zhruba deset minut: Antimatter s databází, úložištěm souborů a službou pro GIFy na jakémkoli linuxovém serveru s Dockerem.

Zprovozněno za deset minut

Potřebujete linuxový server s Dockerem a jeho pluginem Compose, alespoň 2 jádry CPU a 4 GB paměti.

1. Stáhněte compose soubor

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Vytvořte nastavení s náhodnými hesly

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Do SITE_URL zadejte adresu, kterou budou lidé používat, například http://192.168.1.20:8065 v místní síti.

3. Spusťte ho

$ docker compose up -d

První spuštění trvá minutu nebo dvě, než se vytvoří databáze. Potom v prohlížeči otevřete SITE_URL a vytvořte si účet: první účet se stane systémovým administrátorem a průvodce nastavením vás provede vytvořením první komunity.

S vlastní doménou a HTTPS

Nasměrujte DNS záznam své domény na server, otevřete porty 80 a 443 a přidejte doménu do .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy získá certifikát od Let's Encrypt a sám ho obnovuje.

Co poběží

  • antimatter: server s aplikacemi (poznámky, tabule, hlasové kanály, hovory, hlasování a další). Na disku nic neukládá: nastavení má v databázi a soubory v úložné službě, takže kontejner můžete kdykoli nahradit.
  • postgres: databáze.
  • files: RustFS, úložiště kompatibilní s S3 pro nahrané soubory.
  • gifs: služba Antimatteru pro GIFy a nálepky, se základní sadou nálepek.
  • https: Caddy, jen s profilem https.

Databáze, úložiště a služba pro GIFy běží v privátní síti, do které má přístup jen Antimatter.

Pokud výběr GIFů zůstává prázdný, otevřete Systémová konzole › Zásuvné moduly › GIFs, jako adresu URL služby nastavte http://gifs:8080/v2 a jako klíč API hodnotu GIFS_API_KEY ze svého souboru .env.

Aktualizace a zálohy

# aktualizace na nejnovější obrazy
$ docker compose pull && docker compose up -d
# záloha databáze
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Zálohujte také svazek files, nebo úložiště replikujte libovolným nástrojem pro S3. Nastavení s nginx a vlastními certifikáty najdete v produkčních souborech v repozitáři antimatter-docker.

Z archivu vydání

  1. Připravte databázi PostgreSQL a uživatele.
  2. Rozbalte archiv (antimatter-<os>-<arch>.tar.gz), například do /opt/antimatter, a v config/config.json nasměrujte SqlSettings.DataSource (nebo proměnnou prostředí MM_SQLSETTINGS_DATASOURCE) na databázi.
  3. Spusťte server příkazem bin/antimatter pod neprivilegovaným uživatelem a otevřete http://localhost:8065. První vytvořený účet se stane systémovým administrátorem.

bin/amctl spravuje běžící server z příkazové řádky (přímo na serveru jako bin/amctl --local, se zapnutým ServiceSettings.EnableLocalMode).

Další kroky

  • Hovory: otevřete port pro hovory (ve výchozím nastavení UDP a TCP 8443), aby se hlas a video dostaly k serveru.
  • E-mail: nastavte SMTP pro pozvánky a oznámení.
  • AI: přidejte model v nastavení agentů; funguje jakékoli API kompatibilní s OpenAI, včetně serveru, který provozujete sami.
  • Řeč a překlad: nasměrujte přepis hovorů, předčítání a automatický překlad na modely pro převod řeči na text, textu na řeč a pro překlad, které provozujete sami.
