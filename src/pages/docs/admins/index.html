What makes up a deployment

Antimatter is a self-hosted team chat, a fork of Mattermost. A complete deployment has these parts. Only the first three are required.

PartWhat it doesRequired
The Antimatter serverOne Go program (antimatter) that serves the web app, the API and the websockets on port 8065, runs the bundled apps (plugins), and carries call media on port 8443. The command-line tool amctl manages it.yes
PostgreSQLThe database: messages, users, communities and, in the recommended setup, the server's configuration. Version 15 or newer.yes
File storageUploaded files, images and installed apps: an S3-compatible service (the compose file runs RustFS), or a local directory.yes
A reverse proxyHTTPS in front of the server: the compose file's Caddy profile, or your own nginx.for production
The GIF service (gifs-server)GIFs and stickers for the GIF picker, from your own catalogue. It speaks the Tenor API.no
A push proxyForwards notifications to the mobile app through Apple and Google.for mobile notifications
rtcd, a TURN serverA separate media server for many calls, and a relay for people behind strict firewalls.no
AI endpointsThe models behind the composer's rewrite, recaps, translation, read-aloud, AI agents and call transcription, added as model connections: a cloud provider or servers you run.no

Antimatter has no licence and no paid edition: single sign-on, LDAP, high availability, compliance exports, data retention and the other features Mattermost reserves for its paid plans are all included.

Requirements

  • A Linux server, amd64 or arm64, with 2 CPU cores and 4 GB of memory or more for a few hundred people, and disk space for the files people upload.
  • Docker Engine with the Compose plugin (docker compose), for the recommended installation. Or, for the packages, a Debian, Ubuntu, Fedora or RHEL-compatible server with systemd.
  • For production: a domain name pointing at the server, and ports 80 and 443 open for HTTPS.
  • For calls: port 8443, UDP and TCP, reachable by the people who call.
  • For email: an SMTP server Antimatter can send through.

Quick start

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Then open the site URL and create your account: the first account becomes the system administrator. Installing explains each step and the other ways to install.

Your first hour

  1. Install, and create the administrator account right away.
  2. Put the server behind HTTPS on its own domain.
  3. Configure SMTP and send a test email.
  4. Open the calls port. For a company, set the kind of new communities to Workplace, so that calls are on in channels.
  5. Decide who can sign up, and turn on MFA.
  6. Review the outside connections in Security.
  7. Set up daily backups. Before adding AI model connections, set the AI encryption key.
