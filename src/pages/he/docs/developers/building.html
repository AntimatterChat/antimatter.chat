מה צריך

  • Go, בגרסה המצוינת ב-server/go.mod (1.26.7 נכון למועד כתיבה).
  • Node.js ו-npm, בגרסאות המצוינות ב-.nvmrc וב-webapp/package.json (Node 24.11.1 עם npm 11.6.2). באמצעות mise, קובץ mise.toml במאגר מתקין את גרסת Node הנכונה.
  • Docker עם Compose: סביבת הפיתוח מריצה את PostgreSQL ואת כמה שירותים נוספים בתוך קונטיינרים.
  • make, git, ומחשב עם מערכת הפעלה Linux או macOS.
  • זיכרון: בניית ממשקי האתר היא החלק הכבד. מומלץ לתכנן 16 GB של RAM; ראו בנייה וזיכרון.
git clone https://github.com/AntimatterChat/antimatter.git
cd antimatter

המאגר מכיל את השרת ב-server/, את ממשקי האתר ב-webapp/ (Fusion ב-webapp/fusion, הקלאסי ב-webapp/channels, חבילות משותפות ב-webapp/platform), ובדיקות end-to-end ב-e2e-tests/.

הרצת שרת פיתוח

cd server
make run

make run מריץ את קונטיינרי הפיתוח (PostgreSQL, Redis, כלי לכידת דוא"ל וכלי ניטור), מקשר את בניית אפליקציית האתר למקומה, מריץ את השרת ברקע באמצעות go run, ומריץ את מנהל השינויים (watcher) של אפליקציית האתר, שבונה מחדש את הממשק הקלאסי בעת עריכה. פתחו את http://localhost:8065 וצרו חשבון: החשבון הראשון יהפוך למנהל המערכת.

פקודה (ב-server/)מה היא עושה
make run-server, make run-clientהרצת השרת בלבד, או מנהל השינויים של אפליקציית האתר בלבד.
make restart-serverהפעלה מחדש של השרת לאחר שינוי קוד Go.
make stopעצירת השרת, מנהל השינויים והקונטיינרים.
make debug-serverהרצת השרת תחת מחליף Delve.
make run-cli ARGS="-version"הרצת פקודת שרת.
make config-resetאיפוס config/config.json לערכי ברירת המחדל.
make clean, make nukeמחיקת קבצי בנייה; nuke מחקה גם את נתוני הפיתוח.

מסד הנתונים לפיתוח הוא postgres://mmuser:mostest_password@localhost/mattermost_test, מקור הנתונים ברירת המחדל של השרת. יש לבחור אילו קונטיינרים יופעלו באמצעות ENABLED_DOCKER_SERVICES, בקובץ server/config.override.mk או בסביבת ההרצה (ראו server/config.mk).

ממשקי האתר

ב-webapp/:

npm install      # also builds the shared packages
npm run build    # the classic interface, then Fusion

הבנייה נשמרת ב־webapp/channels/dist (קלאסי) וב־webapp/fusion/dist (Fusion). הפקודה make client ב־server/ מקשרת אותם כ־server/client ו־server/client-fusion, ומשמש אותם השרת: הקלאסי תחת /static/, ו־Fusion תחת /static/fusion/.

  • npm run run (או make run ב־webapp/) עוקב ומבצע בנייה מחדש של הממשק הקלאסי. הוספת WATCH_FUSION=true תבצע גם בנייה מחדש של Fusion.
  • npm run dev-server (make dev) מפעיל במקום זאת את שרת ההתפתחות של webpack: קלאסי על פורט 9005, ו־Fusion על פורט 9006.
  • כדי לצפות בממשק אחד או בשני בדפדפן, הוסיפו ?webui=fusion או ?webui=classic לכתובת של כל עמוד.

בדיקות ובדיקות תקינות

פקודהמיקוםמה היא עושה
make test-serverserver/סט הבדיקות של השרת, מול מכלי ההתפתחות. זה לוקח זמן רב.
make test-server-quickserver/רק הבדיקות הקצרות.
go test ./channels/app/... -run TestNameserver/חבילה אחת או בדיקה אחת, עם המכלים רצים (make start-docker).
make check-styleserver/go vet, golangci-lint ו־Go checks אחרים.
make testwebapp/בדיקות יחידה של אפליקציית ה־web (Jest), בכל חבילה.
npm run test -- <pattern>webapp/fusionחלק מבדיקות Fusion.
make check-style, make check-typeswebapp/ESLint ו־TypeScript.
make i18n-extractserver/ ו־webapp/מעדכן את קבצי המחרוזות באנגלית לאחר הוספה או שינוי מחרוזות (ראו תרגומים).

הריצו make modules-tidy במקום go mod tidy ב־server/.

ארכיוני שחרור

cd webapp && npm run build && cd ..
cd server
make build-linux       # the antimatter and amctl binaries
make package-linux     # dist/antimatter-linux-amd64.tar.gz and -arm64

make build בונה את ממשקי ה־web ואת הקבצים הליניוקסיים בבת אחת. הארכיון מכיל את bin/antimatter, bin/amctl, config/config.json ברירת מחדל, שני ממשקי ה־web, התבניות, הגופנים והתרגומים. פלטפורמות אחרות: make package-osx, make package-windows, make package-freebsd. הארכיונים אינם כוללים את האפליקציות המצורפות; תמונת ה־Docker כן.

תמונת ה־Docker

מאגר ה־antimatter-docker בונה את התמונות המפורסמות, השרת עם האפליקציות שלו, לחלוטין בתוך Docker:

git clone https://github.com/AntimatterChat/antimatter-docker.git
cd antimatter-docker
scripts/build-all.sh                     # from the main branches on GitHub
SOURCES=local scripts/build-all.sh       # from your checkouts next to this folder
VARIANT=next scripts/build-all.sh        # the "next" image, with every Antimatter app

נדרש Docker עם buildx, Python 3, git ו־gpg, כ־16 GB זיכרון RAM ו־30 GB דיסק. התוצאה נטענת כ־ghcr.io/antimatterchat/antimatter:dev; נסו זאת עם ANTIMATTER_IMAGE=ghcr.io/antimatterchat/antimatter:dev docker compose -f compose.local.yml up -d. plugins.json מפרט את האפליקציות והגרסאות שנבנו, ו־README של המאגר מסביר את הווריאנטים.

build-all.sh חותם את האפליקציות המצורפות עם מפתח החתימה של Antimatter, ובניית התמונה דוחה אפליקציות ללא חתימה. ללא המפתח הפרטי, שיש רק למחזיקים, הרצו את השלבים הראשונים בלבד: scripts/fetch-sources.sh, scripts/build-plugins.sh (חבילות האפליקציות ב-out/plugins/) ו-scripts/build-server.sh (ארכיוני השרת ב-out/server/).

בנייה וזיכרון

ממשקי הווב הם בניית webpack גדולה, וחוסר בזיכרון הוא כשל הבנייה הנפוץ ביותר.

  • npm run build בונה את הממשק הקלאסי ואז את Fusion, לא יחד, כדי להפחית את השיא. אל תריצו אותם במקביל בעצמכם.
  • הממעיך (minifier) מריץ עובד אחד לכל מעבד. במכונה עם הרבה ליבות וזיכרון מוגבל, הגבילו את המעבדים שרואה הבנייה: taskset -c 0-5 npm run build.
  • אם Node מתעורר בזיכרון (heap), העלו את הגבול: NODE_OPTIONS=--max-old-space-size=6144. בניית Docker משתמשת בערך זה (BUILD_NODE_OPTIONS ב-build.env).
  • הימנעו מריצת סוּיט הבדיקות המלא של השרת, בניית ווב ובניית Docker בו-זמנית במכונה קטנה.

האפליקציות

לכל אפליקציה (פלאגין) יש מאגר ו-Makefile משלה; make dist בונה את החבילה שלה. ראו בנייה, התקנה וניפוי תקלות.

אפליקציית שולחן עבודה

האפליקציית שולחן העבודה היא אפליקציית Electron. עם Node.js 24 או גבוה יותר:

npm install --allow-git=all
npm run build          # development build, into dist/
npm start              # run it
npm run package:linux  # packages into release/ (also package:windows, package:mac)

הגדרות בזמן הבנייה, כגון שרתים להגדרה מראש, נמצאות ב-src/common/config/buildConfig.ts.

אפליקציית מובייל

האפליקציית המובייל היא אפליקציית React Native; קובץ ה-README שלה מפרט את הפקודות (npm run ios, npm run android). כדי לבנות עותק משלכם, תצטרכו גם מפתחות חתימה משלכם, פרויקט Firebase להתראות באנדרואיד, מפתח APNs ל-iOS, ו-push proxy שמחזיק את האישורים האלה.
