"תואם OpenAI" פירושו שרת שמציע את אותו ממשק HTTP כמו OpenAI. רוב שרתי המודלים שניתן להפעיל בעצמכם עושים זאת (למשל Ollama, vLLM, שרת של llama.cpp, או שרתי Whisper ותמלול קול), וכך גם ספקי ענן רבים. לא נדרשת רישיון לשום אחת מתכונות אלו.

סוכני AI

אפליקציית הסוכנים (מזהה mattermost-ai) פעילה כברירת מחדל. הגדרתה כוללת שני שלבים: הוספת שירות (חיבור לספק מודלים), ואז יצירת סוכנים (בוטים שמשתמשים בשירות).

1. הוספת שירות

עברו לקונסולת מערכת › תוספים › סוכנים ובחלק שירותי AI, לחצו על הוספת שירות AI. בחרו את סוג השירות:

  • תואם OpenAI: עבור שרת מודלים שאתם מפעילים בעצמכם, או כל ספק עם ממשק בסגנון OpenAI. מלאו את כתובת API (למשל http://ollama:11434/v1 או http://vllm.internal:8000/v1), ואת מפתח API רק אם השרת דורש זאת. אם השרת תומך רק בממשק Chat Completions, כבו את שימוש בממשק Responses.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: ספקים מנוהלים. כל אחד דורש את מפתח API שלו (Bedrock: אזור AWS ואימות זהות או תפקיד IAM; Vertex AI: פרויקט, אזור וחשבון שירות; Azure: גם כתובת API).

לאחר מכן, הגדירו את המודל ברירת המחדל (רשימה אם הספק יכול לדווח על המודלים שלו, אחרת הקלידו את השם), וכן, אם הספק אינו מדווח עליהם, את גבול טוקנים לכניסה ואת גבול טוקנים ליציאה. שירות גיבוי יכול לקחת את העבודה על עצמו אם השירות הנוכחי נכשל. שמרו.

השרת מבצע את הבקשות הללו בעצמו, ולכן הוא חייב להגיע ל-API: שרת מודלים באותו פרויקט compose, ברשת שלכם, או באינטרנט. בקשות יוצאות מכבדות את המשתנים HTTP_PROXY ו-HTTPS_PROXY.

2. יצירת סוכנים

סוכנים נוצרים בדף סוכנים של אפליקציית ה-Web: פתחו אותו מתפריט המוצר, או באמצעות ניהול בבחירת הסוכנים של פאנל הסוכנים. כתובתו היא https://chat.example.com/plug/mattermost-ai/agents. לכל סוכן יש שם תצוגה, שם משתמש לסוכן (כיצד אנשים מזכירים אותו), שירות ובאופן אופציונלי מודל, הוראות מותאמות אישית, ומתגים להפעלת ראייה (תמונות) ולהפעלת כלים. לשונית גישה שלו מגבילה באילו ערוצים ניתן להשתמש בו ומי יכול להשתמש בו. תחת פונקציות AI בקונסולת המערכת, בוט ברירת המחדל בוחר את הסוכן שיושמש כאשר לא נבחר סוכן, למשל עבור סיכומי שיחות.

ברירת המחדל, כל משתמש יכול ליצור סוכנים משלו, עם השירותים שגדרתם. כדי להשאיר זאת למנהלים בלבד, הסירו את ההרשאה ניהול סוכני AI אישיים מתפקיד החברים בקונסולת מערכת › ניהול משתמשים › הרשאות.

תכונות אופציונליות של אפליקציית הסוכנים

  • חיפוש הטמעה (ניסיוני, כבוי): חיפוש סמנטי על פני הודעות. נדרש PostgreSQL עם הרחבת pgvector ומודל הטמעה (OpenAI או תואם OpenAI). הוא שולח כל הודעה למודל ההטמעה, כולל ערוצים פרטיים והודעות ישירות.
  • חיפוש באינטרנט (כבוי): מאפשר לסוכנים לחפש באינטרנט דרך Google, Brave או שרת SearXNG שאתם מפעילים.
  • כלים נייטיביים: עם ספקים שמציעים אותם, סוכנים יכולים להשתמש בחיפוש האינטרנט של הספק עצמו (באופן מובנה עבור סוכנים חדשים, שם נתמך), בשיתוף מסך ובביצוע קוד. אלה רצים אצל הספק. כבו אותם לכל סוכן בנפרד.
  • Model Context Protocol (MCP): חברו סוכנים לשרתי MCP שאתם סומכים עליהם, לכלים נוספים.
  • ניפוי: Trace Output (כבוי, יומני שרת או נקודת OpenTelemetry) והפעלת רישום שימוש בטוקנים, שכותב ספירות טוקנים לlogs/agents/token_usage.log.

המרת דיבור לטקסט: תמלולי שיחות וכתוביות

ניתן לתמלל שיחות, עם כתוביות חיות, באמצעות שרת טקסט-לקול שמציע נקודת קצה /v1/audio/transcriptions תואמת OpenAI. ההגדרה נמצאת בשיחות וקול. כאשר Summarize transcriptions פעיל, הסוכן המוגדר כברירת מחדל מפרסם גם סיכום של כל תמלול.

טקסט לקול: קריאה בקול

כאשר טקסט לקול פעיל, בתפריט של כל הודעה מופיעה האפשרות קריאה בקול: השרת שולח את טקסט ההודעה ל־API של טקסט לקול ומנגן את הקול. ההגדרות נמצאות בקונסולת מערכת › אינטגרציות › טקסט לקול:

הגדרהמפתח ומשתנהמה להזין
קריאת הודעות בקולTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (כבוי כברירת מחדל)
כתובת ה־URL הבסיסית של ה־APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLכתובת ה־URL הבסיסית עד כולל /v1, לדוגמה http://tts.internal:8000/v1. השרת פונה לנקודת הקצה /audio/speech שלו.
מודלTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELהמודל כפי שהוא נקרא ב־API, לדוגמה tts-1. שדה חובה.
קולTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEאחד מקולות המודל, או ריק כדי להשתמש בקול המוגדר כברירת מחדל.
מפתח APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYנשלח כbearer token. ריק אם ה־API אינו דורש מפתח.

לפני השליחה, השרת מסיר חטיבות קוד, קישורים, קודי אמוג'י ופורמט, ומשאיר לכל היותר 4000 תווים. הוא מבקש קול בפורמט MP3 ושומר בזיכרון את 64 התוצאות האחרונות, כך שהודעה שנקראת פעמיים נשלחת פעם אחת בלבד.

תרגום אוטומטי

תרגום אוטומטי מציג את ההודעות בערוץ בשפה של כל קורא. ההגדרה נעשית בקונסולת מערכת › הגדרות האתר › לוקליזציה, תחת תרגום אוטומטי:

הגדרהמפתחברירת מחדל
הפעלהAutoTranslationSettings.Enableכבוי
ספק תרגוםAutoTranslationSettings.Providerlibretranslate, openai (מוצג כ"OpenAI-compatible API") או agents (שירות של אפליקציית הסוכנים)
שפות מורשותAutoTranslationSettings.TargetLanguagesen: השפות אליהן ניתן לתרגם את ההודעות
זמן תגובה לתרגום (ms)AutoTranslationSettings.TimeoutMs5000
הגבלת תרגום אוטומטי בהודעות ישירות ובמסרים לקבוצותAutoTranslationSettings.RestrictDMAndGMכבוי

לכל ספק יש שדות משלו:

  • LibreTranslate: נקודת קצה API של LibreTranslate ומפתח API של LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). ניתן להריץ שרת LibreTranslate על הרשת הפרטית שלכם.
  • OpenAI-compatible API: כתובת ה־URL הבסיסית של ה־API (עד כולל /v1; השרת משתמש בנקודת הקצה chat completions שלו), מודל ומפתח API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). מודל תרגום קטן שמופעל מקומית עובד היטב.
  • סוכנים: שירות AI, אחד השירותים המוגדרים באפליקציית הסוכנים.

כשהתכונה מופעלת, מנהלי הערוץ יכולים להפעיל תרגום עבור ערוץ בהגדרות שלו (תרגום אוטומטי), וכל חבר יכול לבטל את ההשתתפות בתרגום מתפריט הערוץ (תרגום הודעות). בהודעות ישירות ובקבוצות כל חבר יכול להפעיל את התרגום; כאשר ההגבלה פעילה, התרגום אינו זמין שם. הודעות מתורגמות מציגות את הכיתוב "מתורגם מ־…" עם קישור להודעה המקורית.

קוד, קישורים, הזכרות ואמוג'י מוחלפים במקומות לפני שליחת הטקסט, ומחוזרים במקומם לאחר מכן.

כיבוי בינה מלאכותית

אין מתג יחיד: לכל תכונה יש מתג משלה.

  • סוכנים: בטלו את אפליקציית הסוכנים ב־קונסולת מערכת › תוספים › ניהול פלאגינים. פעולה זו מסירה גם את סיכומי השיחות ואת ספק התרגום של הסוכנים.
  • תמלול וכתוביות: AM_CALLS_ENABLE_TRANSCRIPTIONS=false ו־AM_CALLS_ENABLE_LIVE_CAPTIONS=false (הברירת המחדל).
  • קריאה בקול: כיבוי קריאת הודעות בקול (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, הברירת המחדל).
  • תרגום: כיבוי תרגום אוטומטי (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, הברירת המחדל).

כיבוי אפליקציית הסוכנים אינו מכבה את שלוש התכונות האחרות: הן פונות ישירות לממשקי ה־API שלהן.
