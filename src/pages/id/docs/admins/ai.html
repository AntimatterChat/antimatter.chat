"Kompatibel OpenAI" berarti server yang menawarkan API HTTP yang sama seperti OpenAI. Sebagian besar server model yang dapat Anda jalankan sendiri melakukannya (misalnya Ollama, vLLM, server llama.cpp, atau server Whisper dan teks-ke-suara), begitu juga banyak penyedia cloud dan gerbang seperti LiteLLM atau OpenRouter. Tidak diperlukan lisensi untuk fitur-fitur ini.

Fitur bawaan (tulis ulang, ringkasan, terjemahan, dan baca keras) tidak memerlukan aplikasi Agen: mereka menggunakan koneksi model yang Anda tambahkan di Konsol Sistem.

Koneksi model

Koneksi model adalah penyedia AI yang dapat dipanggil oleh Antimatter: alamatnya, kuncinya, dan model-modelnya. Anda menambahnya sekali, lalu memilihnya untuk setiap fitur yang harus menggunakannya. Ada dua jenis:

  • Koneksi server-wide, dikelola oleh administrator sistem di Konsol Sistem › AI › Koneksi model. Hanya mereka yang dapat menyediakan fitur bawaan. Aplikasi juga dapat menggunakannya, untuk orang-orang yang diizinkan.
  • Koneksi komunitas, yang ditambahkan oleh administrator komunitas untuk komunitas mereka sendiri di pengaturan komunitas (lihat di bawah). Aplikasi menggunakannya untuk orang-orang di komunitas tersebut. Mereka tidak pernah menyediakan fitur bawaan.

Bagian AI di Konsol Sistem ditampilkan kepada orang-orang yang dapat mengelola koneksi server-wide: administrator sistem, secara default. Halaman Koneksi model di sana mencantumkan koneksi server-wide dan koneksi dari setiap komunitas.

Uji Koneksi memeriksa alamat dan kunci: server meminta model dari endpoint, atau mengirim obrolan satu token. Alamat yang diubah diuji dengan kunci yang disimpan hanya setelah Anda menyimpan, atau jika Anda mengetik kunci lagi. Klik Tambah koneksi untuk menyimpan.

Server membuat permintaan itu sendiri, jadi server harus dapat mengakses API: server model dalam proyek compose yang sama, di jaringan Anda, atau di Internet. Permintaan keluar menghormati variabel HTTP_PROXY dan HTTPS_PROXY.

Menghapus koneksi akan melupakan kuncinya. Fitur yang menggunakannya akan berhenti menggunakan AI sampai Anda memilih koneksi lain.

Batas dan anggaran

Setiap koneksi memiliki empat batas. Kosong atau 0 berarti tanpa batas.

  • Permintaan per menit dan Per orang, permintaan per menit. Mereka dihitung oleh setiap server secara terpisah: klaster tiga server akan membiarkan hingga tiga kali lipat laju tersebut.
  • Token per bulan dan Per orang, token per bulan: anggaran token, per bulan kalender (UTC), dihitung di database untuk seluruh klaster. Beberapa permintaan yang berjalan pada saat yang sama dapat sedikit melewati anggaran.

Batas per orang juga berlaku untuk penulisan ulang dan ringkasan: mereka dihitung terhadap orang yang menulis ulang, atau yang memiliki ringkasan.

Pemakaian

Daftar ini menunjukkan penggunaan setiap koneksi bulan ini. Pemakaian membuka detail: token masuk dan keluar, permintaan, anggaran bulanan, penggunaan per hari (UTC) dan per penggunaan (Tulis Ulang, Ringkasan, Terjemahan Otomatis, Teks ke Suara, Orang, melalui aplikasi, atau aplikasi).

Setiap panggilan yang dibuat oleh orang atau aplikasi melalui koneksi juga menulis catatan audit: siapa, koneksi, penggunaan, model, jumlah token, dan apakah berhasil, tidak pernah apa yang dikatakan. Fitur bawaan hanya dihitung dalam penggunaan: terjemahan saja membuat satu panggilan per pesan dan bahasa.

Koneksi komunitas

Admin komunitas menambahkan koneksi komunitas mereka sendiri di pengaturan komunitas, di tab Koneksi model. Formulirnya sama, tanpa Komunitas: koneksi komunitas hanya berfungsi di kanal miliknya sendiri, untuk anggotanya sendiri, dan audiensnya hanya dapat menyebut tim miliknya sendiri. Peran dengan izin Kelola koneksi model juga dapat mengelolanya. Secara default, admin komunitas memilikinya.

Koneksi komunitas tidak dapat mencapai alamat privat atau loopback (misalnya server Ollama di jaringan Anda), kecuali Konsol Sistem › Lingkungan › Pengembang › Izinkan koneksi internal yang tidak tepercaya ke (ServiceSettings.AllowedUntrustedInternalConnections) mencantumkannya. Koneksi server-wide dapat.

Lihat Pengaturan komunitas untuk sisi admin komunitas.

Kunci enkripsi

Kunci dan header tambahan untuk koneksi model dienkripsi di database (AES-256-GCM) dengan satu kunci enkripsi. Cadangan database saja tidak akan membocorkannya. Server mencari kunci dengan urutan berikut:

  1. Variabel AM_AI_ENCRYPTION_KEY: 32 byte acak, dalam format base64. Buat satu dengan openssl rand -base64 32.
  2. Jika tidak, file ai-encryption.key di akar direktori data server (FileSettings.Directory, ./data/ secara bawaan). Server membuatnya, hanya dapat dibaca oleh dirinya sendiri, saat pertama kali koneksi membutuhkannya. Aplikasi, ekspor, dan arsip file tidak dapat membacanya.
Tanpa kunci, kunci API yang tersimpan tidak dapat dibaca, dan setiap koneksi harus diberikan kuncinya lagi. Cadangkan kunci ini bersama database (lihat Cadangan dan peningkatan), dan simpan terpisah dari cadangan database.

Kapan mengatur variabel:

  • Dengan file compose situs. compose.yaml meneruskan AM_AI_ENCRYPTION_KEY dari .env, dan menyimpan file kunci di volume data jika variabel kosong. Mengatur variabel lebih baik: cadangan .env kemudian menyimpan kunci, terpisah dari database. Tambahkan ke .env dan jalankan docker compose up -d: 
    echo "AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)" >> .env
    Jika server sudah membuat file kuncinya, masukkan kunci yang dipegangnya ke .env sebagai gantinya, agar kunci yang tersimpan tetap dapat dibaca: docker compose exec antimatter cat /antimatter/data/ai-encryption.key akan menampilkannya.
  • Kluster yang file-filenya ada di S3. Server-servernya tidak berbagi direktori, jadi server tidak membuat file: atur variabel yang sama di setiap server. Sampai diatur, koneksi tidak dapat menyimpan kunci.
  • Dengan arsip rilis atau paket, file ada di data/ (/var/lib/antimatter/data untuk paket). Anda dapat menyimpannya di sana, atau mengatur variabel di file lingkungan Anda.

Untuk mengubah kunci, atur yang baru di AM_AI_ENCRYPTION_KEY dan yang lama di AM_AI_ENCRYPTION_PREVIOUS_KEYS (beberapa kunci dipisahkan oleh koma): kunci yang disimpan dengan yang lama masih dapat dibaca. Kunci koneksi dienkripsi dengan kunci baru saat Anda mengetikkannya lagi. Simpan kunci lama dalam daftar sampai kunci setiap koneksi telah diketik ulang.

Fitur bawaan

Di Konsol Sistem › AI › Fitur bawaan, pilih koneksi dan modelnya untuk setiap fitur di seluruh server, atau Nonaktif. Fitur tanpa koneksi tidak menggunakan AI. Model yang dimuat menampilkan semua model dari koneksi tersebut; secara default, setiap fitur menggunakan model percakapan dari koneksi itu.

Fitur bawaan menggunakan batas dari koneksi, tetapi tidak audiensnya: semua orang yang dapat menggunakan fitur tersebut dapat menggunakan koneksinya. Koneksi yang memerlukan perhatian atau yang dihapus akan menyebabkan fitur gagal sampai Anda memilih koneksi lain: halaman tersebut akan menyatakannya.

Agen AI

Aplikasi Agen (id mattermost-ai) aktif secara bawaan. Pengaturannya terdiri dari dua langkah: tambahkan layanan (koneksi ke penyedia model), lalu buat agen (bot yang menggunakan layanan tersebut).

Agen dari aplikasi Agen masih menggunakan Layanan AI milik aplikasi itu sendiri, bukan koneksi model. Fitur bawaan tidak lagi melewati aplikasi tersebut. Pada server yang diperbarui ke 0.9.0, layanan aplikasi juga disalin sekali ke koneksi model di seluruh server (lihat Pembaruan ke 0.9.0).

1. Tambahkan layanan

Buka Konsol Sistem › Plugin › Agen dan, di bawah Layanan AI, klik Tambahkan Layanan AI. Pilih Jenis Layanan:

  • Kompatibel OpenAI: untuk server model yang Anda jalankan sendiri, atau penyedia apa pun dengan API bergaya OpenAI. Isi URL API (misalnya http://ollama:11434/v1 atau http://vllm.internal:8000/v1), dan Kunci API hanya jika server membutuhkannya. Jika server hanya mendukung API Completions Chat, matikan Gunakan API Respons.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: penyedia yang dihosting. Masing-masing membutuhkan Kunci API (Bedrock: wilayah AWS dan kredensial atau peran IAM; Vertex AI: proyek, wilayah, dan akun layanan; Azure: juga URL API).

Lalu, atur Default model (sebuah daftar jika penyedia dapat melaporkan modelnya, atau ketik nama modelnya), dan, jika penyedia tidak melaporkannya, atur Input token limit dan Output token limit. Fallback Service dapat mengambil alih jika layanan ini gagal. Simpan.

Server membuat permintaan ini sendiri, jadi server harus dapat mengakses API: server model dalam proyek compose yang sama, di jaringan Anda, atau di Internet. Permintaan keluar menghormati variabel HTTP_PROXY dan HTTPS_PROXY.

2. Buat agen

Agen dibuat di halaman Agen aplikasi web: buka halaman tersebut dengan Kelola di pemilih agen pada panel Agen (di antarmuka klasik, juga dari menu produk). Alamatnya adalah https://chat.example.com/plug/mattermost-ai/agents. Setiap agen memiliki Nama Tampilan, Nama Pengguna Agen (cara orang menyebutnya), Layanan, dan secara opsional sebuah model, Instruksi Kustom, serta sakelar untuk Aktifkan Visi (gambar) dan Aktifkan Alat. Tab Akses membatasi kanal mana yang dapat digunakan dan pengguna mana yang dapat menggunakannya. Di bawah Fungsi AI di Konsol Sistem, Bot bawaan memilih agen yang digunakan ketika tidak ada yang dipilih, misalnya untuk ringkasan panggilan.

Secara default, setiap pengguna dapat membuat agen mereka sendiri, dengan layanan yang Anda konfigurasikan. Untuk membatasi ini hanya untuk administrator, hapus izin Kelola Agen AI Sendiri dari peran anggota di Konsol Sistem › Manajemen Pengguna › Izin.

Fitur opsional dari aplikasi Agents

  • Embedding search (eksperimental, nonaktif): pencarian semantik atas pesan. Membutuhkan PostgreSQL dengan ekstensi pgvector dan model embedding (OpenAI atau kompatibel dengan OpenAI). Mengirim setiap pesan ke model embedding, termasuk kanal privat dan pesan langsung.
  • Web search (nonaktif): memungkinkan agen mencari di web melalui Google, Brave, atau server SearXNG yang Anda jalankan.
  • Native tools: dengan penyedia yang menawarkannya, agen dapat menggunakan pencarian web milik penyedia (aktif secara default untuk agen baru, jika didukung), pengambilan web, dan eksekusi kode. Ini berjalan di sisi penyedia. Matikan per agen.
  • Model Context Protocol (MCP): hubungkan agen ke server MCP yang Anda percaya, untuk alat tambahan.
  • Debug: Trace Output (nonaktif, log server atau endpoint OpenTelemetry) dan Enable Token Usage Logging, yang menulis jumlah token ke logs/agents/token_usage.log.

Speech-to-text: transkrip dan teks langsung panggilan

Panggilan dapat ditranskripsi, dengan teks langsung, oleh server speech-to-text yang menyediakan endpoint /v1/audio/transcriptions yang kompatibel dengan OpenAI. Konfigurasinya ada di Panggilan dan suara. Jika Ringkaskan transkripsi diaktifkan, agen default juga akan memposting ringkasan dari setiap transkripsi.

Text-to-speech: bacakan

Dengan teks-ke-suara aktif, setiap menu pesan memiliki Baca dengan suara: server mengirim teks pesan ke API teks-ke-suara dan memutar audionya. Pengaturan, di Konsol Sistem › Integrasi › Teks ke Suara:

Untuk menggunakan koneksi model alih-alih alamat dan kunci di atas, pilih untuk Teks ke Suara di AI › Fitur bawaan. Halaman tersebut kemudian menyatakan bahwa pesan dibaca dengan lantang menggunakan koneksi tersebut: URL dasar API dan Kunci API tidak digunakan, Suara tetap digunakan, dan juga Model ketika koneksi tidak menyebutkan model. Baca pesan dengan lantang harus tetap aktif.

Sebelum dikirim, server akan menghapus blok kode, tautan, kode emoji, dan format, serta mempertahankan maksimal 4000 karakter. Server meminta audio MP3 dan menyimpan 64 hasil terakhir di memori, sehingga pesan yang dibacakan dua kali hanya dikirim sekali.

Terjemahan otomatis

Terjemahan otomatis menampilkan pesan dari sebuah kanal dalam bahasa masing-masing pembaca. Konfigurasinya ada di Konsol Sistem › Konfigurasi Situs › Lokalisasi, di bawah Terjemahan otomatis:

Setiap penyedia memiliki field-nya masing-masing:

  • Koneksi model: koneksi server-wide dan modelnya, pengaturan yang sama dengan Terjemahan Otomatis di AI › Fitur bawaan (AISettings.AutoTranslation). Model terjemahan khusus cepat dan akurat; LLM umum juga berfungsi.
  • LibreTranslate: Endpoint API LibreTranslate dan API Key LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Server LibreTranslate dapat dijalankan di jaringan Anda sendiri.
  • API kompatibel OpenAI: URL dasar API (hingga dan termasuk /v1; server menggunakan endpoint chat completions-nya), Model dan Kunci API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Model terjemahan kecil yang dijalankan secara lokal bekerja dengan baik.
  • Layanan aplikasi obrolan AI (lama): penyedia server yang diatur sebelum 0.9.0, yang menggunakan layanan dari aplikasi Agen. Tidak lagi membutuhkan aplikasi: menerjemahkan dengan koneksi yang dipilih untuk terjemahan otomatis di AI › Fitur bawaan, atau dengan koneksi yang disalin dari layanan aplikasi saat peningkatan. Beralih ke Koneksi Model memindahkan pengaturan ke penyedia yang disarankan.

Setelah diaktifkan, admin kanal mengaktifkan terjemahan untuk sebuah kanal di pengaturannya (Terjemahan Otomatis), dan setiap anggota dapat memilih untuk tidak ikut dari menu kanal (Terjemahkan pesan). Dalam pesan langsung dan grup, anggota mana pun dapat mengaktifkannya; dengan pembatasan aktif, terjemahan tidak tersedia di sana. Pesan yang diterjemahkan menampilkan "Diterjemahkan dari …" dengan tautan ke aslinya.

Kode, tautan, sebutan, dan emoji diganti dengan penanda sementara sebelum teks dikirim, lalu dikembalikan setelahnya.

Mematikan AI

Tidak ada satu saklar tunggal: setiap fitur memiliki saklarnya sendiri.

  • Tulisan ulang dan ringkasan: atur ke Nonaktif di Konsol Sistem › AI › Fitur bawaan. Orang-orang tetap membaca ringkasan yang sudah mereka miliki.
  • Koneksi model: hapus koneksi untuk menghentikan semua penggunaannya. Tanpa koneksi, baik fitur bawaan maupun aplikasi tidak dapat menggunakan AI melalui server.
  • Agen: nonaktifkan aplikasi Agen di Konsol Sistem › Plugin › Manajemen Plugin. Ini juga menghapus ringkasan panggilan.
  • Transkripsi dan teks langsung: AM_CALLS_ENABLE_TRANSCRIPTIONS=false dan AM_CALLS_ENABLE_LIVE_CAPTIONS=false (nilai bawaan).
  • Baca dengan suara: matikan Baca pesan dengan lantang (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, nilai bawaan), terlepas dari apakah fitur ini menggunakan koneksi atau tidak.
  • Terjemahan: matikan auto-translation (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, nilai bawaan).

Menonaktifkan aplikasi Agen tidak mematikan fitur lainnya: fitur tersebut menggunakan koneksi model atau API mereka sendiri.
