Instal dengan Docker Compose

Ini adalah cara yang direkomendasikan. Satu file compose menjalankan Antimatter, PostgreSQL, penyimpanan file, dan layanan GIF. Anda membutuhkan server Linux dengan Docker Engine dan plugin Compose-nya (docker compose), 2 inti CPU, dan 4 GB memori atau lebih.

1. Unduh file compose

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml

2. Buat file .env

File compose membaca pengaturannya dari file .env di direktori yang sama. Buat file tersebut dengan rahasia acak:

cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
chmod 600 .env

Atur SITE_URL ke alamat yang akan diketik orang di browser, misalnya http://192.168.1.20:8065 di jaringan lokal atau https://chat.example.com dengan domain. Simpan file .env: database dan penyimpanan menggunakan kata sandi ini sejak awal, dan Anda membutuhkan file yang sama untuk memulihkan cadangan.

3. Jalankan

docker compose up -d
docker compose ps

Peluncuran pertama memakan waktu satu atau dua menit: PostgreSQL membuat database, layanan sekali jalan bucket membuat bucket penyimpanan, layanan sekali jalan gifs-stickers mengimpor paket stiker awal, dan Antimatter membuat tabelnya. Pantau dengan docker compose logs -f antimatter.

Untuk menggunakan nama domain dan HTTPS sejak awal, lihat Domain dan HTTPS: dengan file compose, ini hanya dua baris lagi di .env dan profil https.

PostgreSQL, penyimpanan, dan layanan GIF berada di jaringan internal (private) tanpa akses Internet, yang hanya diikuti oleh Antimatter. Tidak ada satu pun yang menerbitkan port.

Kontainer Antimatter tidak menyimpan apa pun di disk: pengaturannya ada di database (AM_CONFIG menunjuk ke sana) dan file serta aplikasinya ada di layanan penyimpanan. Anda dapat menghapus dan membuat ulang kontainer kapan saja. Semua yang perlu dicadangkan ada di volume postgres, files, dan gifs, serta .env Anda.

Pilih gambar

Dua gambar Antimatter dipublikasikan, keduanya untuk linux/amd64 dan linux/arm64, dan keduanya dibangun dari cabang main setiap repositori:

GambarAplikasi bawaanTag
ghcr.io/antimatterchat/antimatterAgen, Panggilan, GitHub, GitLab, Jira, Kanban, Metrik, dan Buku Taktik.latest, X.Y.Z untuk rilis, sha-<commit>
ghcr.io/antimatterchat/antimatter-nextSama seperti di atas, ditambah Kanal Suara, Jajak Pendapat, Email, Kalender, Catatan, Papan Putih, GIF, To-do, dan Meme. Dibangun ulang setiap malam.latest, nightly, nightly-<YYYYMMDD>, sha-<commit>

File compose situs menggunakan antimatter-next, karena layanan GIF dan sebagian besar aplikasi yang dijelaskan di situs ini hanya ada di gambar tersebut. Untuk mengubah gambar, atur ANTIMATTER_IMAGE di .env dan jalankan docker compose up -d.

latest berubah di bawah Anda. Di produksi, kunci tag seperti nightly-20261015 atau sha-<commit>, dan ubah dengan sengaja saat Anda melakukan peningkatan. Server meningkatkan database-nya saat dimulai, sehingga Anda tidak bisa kembali ke gambar yang lebih lama, atau dari antimatter-next ke antimatter, tanpa memulihkan cadangan yang diambil sebelumnya. Lihat Cadangan dan peningkatan.

Di dalam gambar

  • Server berada di /antimatter, dengan biner antimatter dan amctl di /antimatter/bin (di PATH).
  • Berjalan sebagai pengguna non-privileg antimatter (uid 2000) di atas basis distroless minimal, tanpa shell.
  • Port: 8065 (web dan API), 8067 (metrik), 8074 (klaster), 8443 UDP dan TCP (panggilan).
  • Mode lokal (ServiceSettings.EnableLocalMode) aktif, sehingga amctl --local dapat digunakan di dalam kontainer. Pemeriksaan kesehatan menjalankan amctl system status --local.
  • Aplikasi bawaan berada di /antimatter/prepackaged_plugins, ditandatangani dengan kunci penandatanganan aplikasi Antimatter.
  • Alat ekstraksi teks (pdftotext, wvText, unrtf, tidy) disertakan, sehingga konten dokumen yang diunggah dapat dicari.

Berkas compose lainnya

Repositori antimatter-docker memiliki konfigurasi produksi di deploy/compose/: nginx dengan sertifikat Anda sendiri atau Let's Encrypt (certbot), PostgreSQL, layanan GIF opsional (profil gifs), dan volume bernama untuk konfigurasi, data, dan log server, yang didokumentasikan dalam README-nya. Secara default menggunakan image stabil dan menyimpan file di volume lokal alih-alih penyimpanan S3. Gunakan ini jika Anda lebih memilih nginx daripada Caddy, atau jika Anda sudah memiliki sertifikat.

Buat administrator pertama

Buka SITE_URL di browser Anda dan buat akun. Akun pertama yang dibuat di server baru akan menjadi administrator sistem, dan proses pengaturan kemudian akan memandu Anda untuk membuat komunitas pertama (istilah Antimatter untuk tim atau ruang kerja).

Lakukan ini segera setelah server pertama kali dijalankan: sampai saat itu, siapa pun yang mengakses server terlebih dahulu akan menjadi administratornya. Untuk membuat akun dari baris perintah alih-alih melalui antarmuka web, lakukan ini sebelum server dapat diakses dari luar:

docker compose exec antimatter amctl --local user create --system-admin --email-verified \
    --email admin@example.com --username admin --password 'a-long-password'
docker compose exec antimatter amctl --local team create --name main --display-name "Main"
docker compose exec antimatter amctl --local team users add main admin

Lalu masuk di SITE_URL. Mulai perintah dengan spasi agar kata sandi tidak tersimpan di riwayat shell Anda (dengan HISTCONTROL=ignorespace), atau ubah kata sandi setelah berhasil masuk.

Langkah selanjutnya setelah Anda masuk:

  1. Tentukan siapa yang dapat membuat akun: Masuk dan akun.
  2. Konfigurasikan email agar undangan dan pengatur ulang kata sandi berfungsi: Email dan notifikasi push.
  3. Buka port panggilan di firewall Anda: Panggilan dan suara.
  4. Periksa aplikasi mana yang aktif: Aplikasi bawaan.

Instal dari arsip rilis

Tanpa Docker, server dijalankan dari arsip bernama antimatter-<os>-<arch>.tar.gz (misalnya antimatter-linux-amd64.tar.gz). Arsip ini berisi satu direktori antimatter/ yang memuat bin/antimatter, bin/amctl, config/config.json, aplikasi web (client/ dan client-fusion/), templat email, dan terjemahan.

1. Siapkan PostgreSQL

Antimatter hanya mendukung PostgreSQL versi 15 atau lebih baru (versi yang lebih lama akan gagal dimulai dan menampilkan error di log). Buat pengguna dan basis data:

sudo -u postgres psql <<'EOF'
CREATE USER antimatter WITH PASSWORD 'a-long-password';
CREATE DATABASE antimatter OWNER antimatter;
EOF

2. Ekstrak dan konfigurasi

sudo tar -xzf antimatter-linux-amd64.tar.gz -C /opt
sudo useradd --system --user-group antimatter
sudo mkdir -p /opt/antimatter/data
sudo chown -R antimatter:antimatter /opt/antimatter

Arahkan server ke basis data, baik melalui /opt/antimatter/config/config.json (SqlSettings.DataSource) maupun dengan variabel lingkungan, lalu atur URL situs:

AM_SQLSETTINGS_DRIVERNAME=postgres
AM_SQLSETTINGS_DATASOURCE=postgres://antimatter:a-long-password@localhost:5432/antimatter?sslmode=disable&connect_timeout=10
AM_SERVICESETTINGS_SITEURL=https://chat.example.com

Berkas config.json dalam arsip adalah konfigurasi bawaan yang lengkap: pengaturan yang Anda ubah di Konsol Sistem akan disimpan kembali ke berkas tersebut. Untuk menyimpan konfigurasi di basis data, lihat Konfigurasi.

3. Jalankan sebagai layanan

Unit systemd, di /etc/systemd/system/antimatter.service:

[Unit]
Description=Antimatter
After=network.target postgresql.service

[Service]
Type=notify
User=antimatter
Group=antimatter
WorkingDirectory=/opt/antimatter
ExecStart=/opt/antimatter/bin/antimatter
EnvironmentFile=-/etc/antimatter.env
TimeoutStartSec=3600
Restart=always
RestartSec=10
LimitNOFILE=49152

[Install]
WantedBy=multi-user.target

Letakkan variabel AM_ Anda di /etc/antimatter.env (hanya dapat dibaca oleh root), lalu:

sudo systemctl daemon-reload
sudo systemctl enable --now antimatter
journalctl -u antimatter -f

Server mendengarkan pada port 8065. Buka http://<server>:8065, atau domain Anda setelah reverse proxy dipasang (lihat Domain dan HTTPS), lalu buat akun pertama: akun ini akan menjadi administrator sistem.

bin/amctl mengelola server yang sedang berjalan dari baris perintah. Di server itu sendiri, alat ini berfungsi tanpa masuk melalui mode lokal: atur AM_SERVICESETTINGS_ENABLELOCALMODE=true, lalu jalankan sudo -u antimatter /opt/antimatter/bin/amctl --local system status.
