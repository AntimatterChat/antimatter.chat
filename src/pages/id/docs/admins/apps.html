Aplikasi bawaan

Aplikasi dicantumkan sebagai Plugins di Konsol Sistem. Aplikasi ini ada di dalam gambar (di /antimatter/prepackaged_plugins), ditandatangani dengan kunci penandatanganan aplikasi Antimatter, sehingga dapat diinstal tanpa koneksi Internet.

Aplikasi yang aktif secara bawaan akan diinstal setiap kali dimulai jika belum ada, atau diperbarui jika gambar memiliki versi yang lebih baru. Jika Anda menonaktifkan salah satu, ia akan tetap nonaktif: pengaturan bawaan hanya berlaku untuk aplikasi yang belum disebutkan dalam konfigurasi. Aplikasi yang mempertahankan ID Mattermost-nya (Agen, Panggilan, Kanban, Buku Taktik, dan integrasi) adalah versi build milik Antimatter sendiri.

Aktifkan, nonaktifkan, dan atur aplikasi

Buka Konsol Sistem › Plugin › Manajemen Plugin. Di bawah Plugin Terpasang, setiap aplikasi memiliki Aktifkan atau Nonaktifkan, Pengaturan, dan Keluarkan, serta menampilkan statusnya (Berjalan, Tidak berjalan, Gagal dimulai…). Setiap aplikasi yang memiliki pengaturan juga memiliki halaman tersendiri di bawah Konsol Sistem › Plugin.

Aplikasi bawaan yang nonaktif secara default diinstal dari salinan gambar itu sendiri: buka Pasar Aplikasi dari menu produk, cari aplikasinya, klik Instal, lalu aktifkan di Manajemen Plugin. Dari baris perintah:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Perintah lain: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Aktifkan aplikasi melalui konfigurasi

Aplikasi yang aktif diatur oleh PluginSettings.PluginStates, yaitu peta ID aplikasi. Anda dapat menggabungkan entri ke dalamnya menggunakan amctl; dengan Aktifkan Plugin Prepackaged Otomatis (default) diaktifkan, aplikasi bawaan yang diaktifkan akan diinstal saat startup berikutnya:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Ini juga cara untuk menginstal To-do, yang tidak ditawarkan di dialog Marketplace. Variabel AM_PLUGINSETTINGS_PLUGINSTATES juga berfungsi, tetapi ia mengganti seluruh peta: cantumkan setiap aplikasi yang ingin Anda aktifkan.

Pengaturan aplikasi

Pengaturan aplikasi disimpan di bawah PluginSettings.Plugins.<app id>, dengan kunci dalam huruf kecil. Ubah di halaman Konsol Sistem aplikasi, atau dengan amctl config patch seperti yang ditunjukkan di Konfigurasi. AM_PLUGINSETTINGS_PLUGINS mengganti pengaturan semua aplikasi sekaligus dan menguncinya, jadi hindari penggunaannya.

Untuk menambahkan GIF Anda sendiri secara massal, impor menggunakan manifest dari direktori yang dimuat ke dalam kontainer sekali pakai:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

Untuk mengimpor ulang stiker awal setelah peningkatan: docker compose run --rm gifs stickers. Format manifest dan perintah lainnya ada di README gifs-server.

Surel dan Kalender

Surel dan Kalender menghubungkan setiap orang ke kotak masuk (IMAP dan SMTP) dan kalender (CalDAV) mereka sendiri. Orang-orang memasukkan server dan kata sandi mereka di aplikasi; kata sandi disimpan secara terenkripsi. Anda tidak mengonfigurasi server surel atau kalender untuk mereka, tetapi Anda menentukan apa yang boleh mereka hubungkan:

Untuk memungkinkan orang masuk ke kotak masuk Gmail atau Microsoft 365 dengan akun mereka alih-alih kata sandi, buat klien OAuth dan isi bidang Google atau Microsoft di aplikasi Surel:

  • Google: klien OAuth Web dengan Gmail API dan cakupan https://mail.google.com/.
  • Microsoft: aplikasi Entra ID dengan izin delegasi IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email dan profile. Tenant default adalah common.
  • Di keduanya, URI pengalihan adalah https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (URL situs Anda).

Kanban, Catatan, Papan Putih, Jajak Pendapat, dan Buku Taktik

  • Kanban (focalboard) berada di /kanban (tautan lama /boards dialihkan ke sana). Satu-satunya pengaturannya, Enable Publicly-Shared Boards (EnablePublicSharedBoards, nonaktif), memungkinkan editor papan untuk membagikan papan kepada siapa pun yang memiliki tautan, tanpa perlu masuk.
  • Catatan dan Jajak Pendapat tidak memiliki pengaturan.
  • Papan Putih: administrator sistem dapat mengunggah pustaka bentuk (berkas Excalidraw .excalidrawlib, maksimal 5 MB per berkas) untuk seluruh server di halaman pengaturannya. Administrator komunitas mengelola pustaka komunitas mereka sendiri.
  • Buku Taktik memiliki beberapa pengaturan, sebagian besar fitur eksperimental; nilai default cocok untuk sebagian besar server.
  • Memes: Who can add meme templates (semua orang secara default, atau admin).
  • To-do tidak memiliki pengaturan server.

GitHub, GitLab dan Jira

Aplikasi ini menghubungkan Antimatter ke platform hosting kode dan pelacak masalah Anda. Masing-masing memerlukan aplikasi OAuth di sisi lain dan webhook yang menunjuk kembali ke Antimatter. Aktifkan aplikasinya, lalu jalankan perintah pengaturannya di kanal mana pun, yang akan memandu Anda langkah demi langkah: /github setup, /gitlab setup atau /jira setup.

Biarkan Use Preregistered OAuth Application nonaktif di aplikasi GitHub dan GitLab: fitur ini bergantung pada layanan Mattermost yang tidak dimiliki Antimatter, dan aplikasi akan menolak untuk dimulai jika fitur ini diaktifkan. Daftarkan aplikasi OAuth Anda sendiri.

Aplikasi GitHub dan GitLab menghasilkan rahasia webhook dan kunci enkripsi mereka saat disimpan pertama kali. Aplikasi GitHub dapat dibatasi untuk organisasi (GithubOrg) dan aplikasi GitLab untuk grup (GitlabGroup); untuk GitHub Enterprise atau GitLab self-hosted, atur URL dasarnya.

Metrik

Aplikasi Metrik mengumpulkan metrik kinerja server ke dalam basis data deret waktu kecil di dalam Antimatter, sehingga Anda dapat mengunduhnya atau menyertakannya dalam paket dukungan tanpa menjalankan Prometheus. Saat dimulai, aplikasi ini mengaktifkan endpoint metrik server (MetricsSettings.Enable). Lihat Operasi.

Menginstal aplikasi lain

Antimatter menjalankan aplikasi Mattermost (plugin). Tiga cara untuk menambahkan satu:

  • Dari marketplace jarak jauh. Aktifkan Marketplace Jarak Jauh (PluginSettings.EnableRemoteMarketplace) nonaktif secara bawaan, dan URL Marketplace (PluginSettings.MarketplaceURL) kosong: Antimatter tidak menggunakan marketplace Mattermost, dan mengabaikan alamatnya jika konfigurasi dari Mattermost masih memuatnya. Untuk menampilkan aplikasi dari server marketplace yang Anda percaya, aktifkan pengaturan tersebut dan atur URL-nya. Build marketplace untuk aplikasi yang dibundel Antimatter (Calls, Playbooks, Kanban, dan lainnya) disembunyikan, sehingga tidak dapat menggantikan milik Antimatter: Izinkan Build Marketplace untuk Plugin Antimatter (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) nonaktif secara bawaan.
  • Dengan mengunggah bundle (.tar.gz). Unggahan nonaktif secara default dan tidak memiliki saklar di Konsol Sistem: setel AM_PLUGINSETTINGS_ENABLEUPLOADS=true, lalu gunakan Unggah Plugin di Manajemen Plugin, atau amctl --local plugin add app.tar.gz.
  • Dari URL: amctl plugin install-url <url>, juga dengan unggahan aktif.

Antimatter memeriksa tanda tangan aplikasi terhadap kunci yang dipercayai: kunci Antimatter, kunci yang digunakan Mattermost, Inc. untuk menandatangani aplikasi publikasinya (sehingga aplikasi Mattermost yang Anda unduh sendiri dapat diinstal), dan kunci apa pun yang Anda tambahkan di PluginSettings.SignaturePublicKeyFiles. Dengan Wajibkan Tanda Tangan Plugin (PluginSettings.RequirePluginSignature, nonaktif secara default) diaktifkan, aplikasi tanpa tanda tangan akan ditolak dan unggahan dinonaktifkan.

Aplikasi berjalan di dalam server dengan akses penuh ke datanya. Hanya instal aplikasi yang Anda percaya.

Beberapa aplikasi yang dibuat untuk edisi berbayar Mattermost memeriksa lisensi Mattermost mereka sendiri dan menolak untuk berjalan; Antimatter tidak berpura-pura memilikinya untuk mereka.
