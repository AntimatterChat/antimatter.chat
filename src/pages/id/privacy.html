Kebijakan privasi

Terakhir diperbarui: 11 Oktober 2026. Terjemahan ini disediakan semata-mata untuk kemudahan Anda; jika terdapat perbedaan, versi bahasa Inggris yang berlaku.

Halaman ini mencakup dua hal: perangkat lunak Antimatter, yang dijalankan organisasi di server mereka sendiri, dan situs web ini, antimatter.chat.

Perangkat lunak Antimatter

Antimatter di-hosting sendiri. Saat Anda menggunakan server Antimatter, organisasi yang menjalankannya menentukan data apa yang disimpan, berapa lama, dan siapa yang dapat mengaksesnya. Proyek Antimatter tidak memiliki akses ke server, akun, maupun pesan Anda. Untuk pertanyaan tentang data Anda di server tertentu, hubungi administrator server tersebut; kebijakan privasi mereka sendirilah yang berlaku.

Yang dilakukan perangkat lunak ini dengan sendirinya:

  • Tanpa telemetri. Server tidak mengirim statistik penggunaan, data diagnostik, atau data lain apa pun ke proyek Antimatter maupun ke pihak ketiga.
  • Koneksi keluar hanya untuk fitur yang diaktifkan administrator, ke layanan yang mereka konfigurasikan: misalnya layanan notifikasi push, pratinjau tautan situs web yang dibagikan dalam pesan, penyedia GIF, server email, penyedia identitas untuk single sign-on, atau model AI, ucapan, maupun terjemahan.
  • Fitur AI menggunakan model yang dipilih administrator. Jika model tersebut di-hosting oleh pihak ketiga, apa yang dikirim ke sana (pesan yang akan ditulis ulang, percakapan yang akan diringkas, audio panggilan yang ditranskripsikan) akan diterima oleh penyedia tersebut. Administrator dapat menggunakan model yang di-hosting sendiri sehingga tidak ada data yang keluar dari jaringan mereka.

Situs web ini

  • antimatter.chat adalah situs web statis yang di-hosting di GitHub Pages.
  • Situs ini tidak menyetel cookie, dan tidak menggunakan analitik, pelacak, maupun iklan. Font dan gambarnya disajikan dari situs ini sendiri, sehingga browser Anda tidak mengirim permintaan ke situs web lain selama Anda membacanya.
  • Seperti layanan hosting web lainnya, GitHub menerima alamat IP Anda dan halaman yang Anda minta, untuk dapat menyajikannya. Lihat Pernyataan Privasi GitHub.
  • Jika Anda membuka issue atau berkontribusi di GitHub, apa yang Anda posting di sana bersifat publik dan ditangani oleh GitHub sesuai dengan ketentuannya sendiri.

Kontak
