Какво ви трябва

  • Отиди, в версията в server/go.mod (1.26.7 към момента на писане).
  • Node.js и npm, в версиите, посочени в .nvmrc и webapp/package.json (Node 24.11.1 с npm 11.6.2). С mise файлът mise.toml в репозиторията инсталира правилната версия на Node.
  • Docker с Compose: конфигурацията за разработка стартира PostgreSQL и няколко други услуги в контейнери.
  • make, git и машина с Linux или macOS.
  • Памет: създаването на уеб интерфейсите е най-тежката част. Предвидете 16 GB RAM; вижте Създаване и памет.
git clone https://github.com/AntimatterChat/antimatter.git
cd antimatter

Репозиторията съдържа сървъра в server/, уеб интерфейсите в webapp/ (Fusion в webapp/fusion, класическият в webapp/channels, споделени пакети в webapp/platform), а тестове край до край в e2e-tests/.

Стартиране на сървър за разработка

cd server
make run

make run стартира контейнерите за разработка (PostgreSQL, Redis, уловача за имейли и инструменти за мониторинг), поставя построяванията на уеб приложенията на мястото им, стартира сървъра в фонов режим с go run и стартира наблюдателя на уеб приложенията, който построява класическия интерфейс отново, докато го редактирате. Отворете http://localhost:8065 и създайте акаунт: първият става системен администратор.

Команда (в server/)Какво прави
make run-server, make run-clientСтартирайте само сървъра или само наблюдателя на уеб приложенията.
make restart-serverРестартирайте сървъра след промяна на Go кода.
make stopСпирайте сървъра, наблюдателя и контейнерите.
make debug-serverСтартирайте сървъра под дебъгъра Delve.
make run-cli ARGS="-version"Изпълнете команда на сървъра.
make config-resetВъзстановява config/config.json до стойностите по подразбиране.

Базата данни за разработка е postgres://mmuser:mostest_password@localhost/mattermost_test, източникът на данни по подразбиране на сървъра. Изберете кои контейнери да се стартират с ENABLED_DOCKER_SERVICES, във файл server/config.override.mk или в вашата среда (вижте server/config.mk).

Уеб интерфейсите

В webapp/:

npm install      # also builds the shared packages
npm run build    # the classic interface, then Fusion

Съборите се записват в webapp/channels/dist (класически) и webapp/fusion/dist (Fusion). make client в server/ ги свързва като server/client и server/client-fusion, откъдето сървърът ги предоставя: класическият интерфейс под /static/, а Fusion под /static/fusion/.

  • npm run run (или make run в webapp/) следи и преизгражда класическия интерфейс. Добавете WATCH_FUSION=true, за да се преизгражда и Fusion.
  • npm run dev-server (make dev) стартира разработъческия сървър на webpack: класическият интерфейс на порт 9005, а Fusion на порт 9006.
  • За да видите единия или другия интерфейс в браузъра, добавете ?webui=fusion или ?webui=classic към адреса на страницата.

Архиви за издаване

cd webapp && npm run build && cd ..
cd server
make build-linux       # the antimatter and amctl binaries
make package-linux     # dist/antimatter-linux-amd64.tar.gz and -arm64

make build изгражда уеб интерфейсите и Linux бинарните файлове едновременно. Архивът съдържа bin/antimatter, bin/amctl, стандартен config/config.json, и двата уеб интерфейса, шаблоните, шрифтовете и преводите. За други платформи: make package-osx, make package-windows, make package-freebsd. Архивите не включват вградените приложения; Docker образът ги включва.

Docker образът

Репозиторията antimatter-docker изгражда публикуваните образи, сървъра с неговите приложения, изцяло в Docker:

git clone https://github.com/AntimatterChat/antimatter-docker.git
cd antimatter-docker
scripts/build-all.sh                     # from the main branches on GitHub
SOURCES=local scripts/build-all.sh       # from your checkouts next to this folder
VARIANT=next scripts/build-all.sh        # the "next" image, with every Antimatter app

Необходими са Docker с buildx, Python 3, git и gpg, около 16 GB RAM и 30 GB дисково пространство. Резултатът се зарежда като ghcr.io/antimatterchat/antimatter:dev; опитайте го с ANTIMATTER_IMAGE=ghcr.io/antimatterchat/antimatter:dev docker compose -f compose.local.yml up -d. plugins.json изброява приложенията и изградените версии, а README на репозиторията обяснява вариантите.

build-all.sh подписва включените приложения с ключа за подписване на Antimatter, а изграждането на образа отхвърля неподписани приложения. Без този частен ключ, който имат само поддръжниците, изпълнете първите стъпки отделно: scripts/fetch-sources.sh, scripts/build-plugins.sh (пакети на приложенията в out/plugins/) и scripts/build-server.sh (архиви на сървъра в out/server/).

Изграждане и памет

Уеб интерфейсите са големи webpack изграждания, а изчерпването на паметта е най-честата причина за неуспешно изграждане.

  • npm run build изгражда класическия интерфейс и Fusion последователно, а не едновременно, за да намали пиковото натоварване. Не ги изпълнявайте паралелно сами.
  • Минификаторът стартира по един работен процес на процесор. На машина с много ядра и малко памет ограничете процесорите, които изграждането вижда: taskset -c 0-5 npm run build.
  • Ако Node изчерпа паметта си, увеличете лимита: NODE_OPTIONS=--max-old-space-size=6144. Docker изграждането използва тази стойност (BUILD_NODE_OPTIONS в build.env).
  • Избягвайте да изпълнявате пълния тестов набор на сървъра, уеб изграждане и Docker изграждане едновременно на малка машина.

Приложенията

Всяко приложение (плъгин) има собствен репозиторий и Makefile; make dist изгражда неговия пакет. Вижте Изграждане, инсталиране и дебъг.

Десктоп приложение

Десктоп приложението е Electron приложение. С Node.js 24 или по-нова версия:

npm install --allow-git=all
npm run build          # development build, into dist/
npm start              # run it
npm run package:linux  # packages into release/ (also package:windows, package:mac)

Настройките при изграждане, като сървъри за предварителна конфигурация, са в src/common/config/buildConfig.ts.

Мобилно приложение

Мобилното приложение е React Native приложение; неговият README изброява командите (npm run ios, npm run android). За да изградите собствен копие, също ви трябват ваши собствени ключове за подписване, Firebase проект за Android известия, APNs ключ за iOS и push прокси, който съхранява тези данни.
