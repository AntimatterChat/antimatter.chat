AI फीचर्स

फीचरकहाँ कॉन्फ़िगर किया जाता हैमॉडल का प्रकारडिफ़ॉल्ट रूप से चालू
AI एजेंट्स: एक बॉट से चैट करें, थ्रेड और चैनल के सारांश, कॉम्पोज़र में सहायताAgents ऐपकिसी भी लार्ज लैंग्वेज मॉडल (LLM) सेवाऐप चालू है, लेकिन जब तक आप एक सेवा नहीं जोड़ते, तब तक कुछ नहीं करता
कॉल ट्रान्सक्रिप्ट और लिवे कैप्शनCalls ऐपस्पीच-टू-टेक्स्ट, OpenAI-संगतनहीं
रीड अलाउडसर्वरटेक्स्ट-टू-स्पीच, OpenAI-संगतनहीं
चैनल का स्वतः अनुवादसर्वरLibreTranslate, एक OpenAI-संगत LLM, या एक Agents सेवानहीं

"OpenAI-संगत" का अर्थ है एक सर्वर जो OpenAI के समान HTTP API प्रदान करता है। अधिकांश मॉडल सर्वर जिन्हें आप स्वयं चला सकते हैं, ऐसा करते हैं (उदाहरण के लिए Ollama, vLLM, llama.cpp का सर्वर, या Whisper और टेक्स्ट-टू-स्पीच सर्वर), और कई क्लाउड प्रोवाइडर भी। इनमें से किसी भी फीचर के लिए कोई लाइसेंस आवश्यक नहीं है।

AI एजेंट

Agents ऐप (id mattermost-ai) डिफ़ॉल्ट रूप से चालू है। इसे सेटअप करने के लिए दो चरण हैं: एक सेवा जोड़ें (मॉडल प्रोवाइडर से कनेक्शन), फिर एजेंट्स बनाएं (बॉट्स जो एक सेवा का उपयोग करते हैं)।

1. एक सेवा जोड़ें

सिस्टम कंसोल › प्लगइन्स › एजेंट पर जाएं और AI Services के नीचे Add an AI Service पर क्लिक करें। Service type चुनें:

  • OpenAI Compatible: आपके द्वारा स्वयं चलाए गए मॉडल सर्वर के लिए, या किसी भी प्रोवाइडर के लिए जिसमें OpenAI-शैली API हो। API URL भरें (उदाहरण के लिए http://ollama:11434/v1 या http://vllm.internal:8000/v1), और API कुंजी केवल तभी भरें जब सर्वर को इसकी आवश्यकता हो। यदि सर्वर केवल Chat Completions API का समर्थन करता है, तो Use Responses API बंद कर दें।
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: होस्टेड प्रोवाइडर। प्रत्येक के लिए API कुंजी आवश्यक है (Bedrock के लिए: AWS क्षेत्र और क्रेडेंशियल या IAM रोल; Vertex AI के लिए: प्रोजेक्ट, क्षेत्र और सर्विस अकाउंट; Azure के लिए: API URL भी)।

फिर Default model (यदि प्रोवाइडर अपने मॉडल की सूची रिपोर्ट कर सके तो सूची, अन्यथा नाम टाइप करें) सेट करें, और यदि प्रोवाइडर उन्हें रिपोर्ट नहीं करता है, तो Input token limit और Output token limit सेट करें। यदि यह सेवा विफल होती है, तो Fallback Service उसकी जगह ले सकती है। सेव करें।

सर्वर ये अनुरोध स्वयं करता है, इसलिए उसे API तक पहुंचना होगा: एक मॉडल सर्वर जो उसी compose project में हो, आपके नेटवर्क पर हो, या इंटरनेट पर हो। आउटगोइंग अनुरोध HTTP_PROXY और HTTPS_PROXY वेरिएबल्स का पालन करते हैं।

2. एजेंट्स बनाएं

एजेंट वेब ऐप के एजेंट पेज पर बनाए जाते हैं: इसे प्रोडक्ट मेनू से खोलें, या एजेंट पैनल के एजेंट सिलेक्टर में प्रबंधित करें का उपयोग करें। इसका पता https://chat.example.com/plug/mattermost-ai/agents है। प्रत्येक एजेंट में प्रदरशित नाम, Agent Username (जिससे लोग इसे उल्लेख करते हैं), Service और वैकल्पिक रूप से मॉडल, Custom Instructions, और Enable Vision (इमेज) और Enable Tools के लिए स्विच होते हैं। इसका पहुंच टैब यह निर्धारित करता है कि यह कौन से चैनल में उपयोग किया जा सकता है और कौन से उपयोगकर्ता इसे उपयोग कर सकते हैं। सिस्टम कंसोल में AI Functions के अंतर्गत, Default bot वह एजेंट चुनता है जो तब उपयोग किया जाता है जब कोई एजेंट चुना नहीं गया हो, उदाहरण के लिए कॉल सारांश के लिए।

डिफ़ॉल्ट रूप से, प्रत्येक उपयोगकर्ता आपके द्वारा कॉन्फ़िगर किए गए सर्विस के साथ अपने स्वयं के एजेंट बना सकता है। यदि आप इसे केवल एडमिन के लिए रखना चाहते हैं, तो सिस्टम कंसोल › यूज़र प्रबंधन › अनुमतियां में सदस्यों की भूमिका से अपनੇ AI एजेंट्स प्रबंधित करें अनुमति हटा दें।

Agents ऐप के वैकल्पिक फीचर्स

  • Embedding search (प्रयोगात्मक, बंद): संदेशों पर सेमैंटिक खोज। इसके लिए pgvector एक्सटेंशन के साथ PostgreSQL और एक embedding मॉडल (OpenAI या OpenAI-compatible) की आवश्यकता होती है। यह हर संदेश को embedding मॉडल को भेजता है, निजी चैनल और डायरेक्ट मैसेज समेत।
  • Web search (बंद): एजेंट्स को Google, Brave या आपके द्वारा चलाए गए SearXNG सर्वर के माध्यम से वेब खोजने की अनुमति देता है।
  • Native tools: उन प्रोवाइडर्स के साथ जो उन्हें प्रदान करते हैं, एजेंट्स प्रोवाइडर की अपनी वेब खोज (नए एजेंट्स के लिए डिफ़ॉल्ट रूप से चालू, जहां समर्थित हो), वेब फेच और कोड निष्पादन का उपयोग कर सकते हैं। ये प्रोवाइडर पर चलते हैं। इन्हें एजेंट के अनुसार बंद करें।
  • Model Context Protocol (MCP): एजेंट्स को आपकी विश्वसनीय MCP सर्वर्स से जोड़ें, अतिरिक्त टूल्स के लिए।
  • डीबग: Trace Output (बंद, सर्वर लॉग या OpenTelemetry एंडपॉइंट) और Enable Token Usage Logging, जो टोकन की गिनती logs/agents/token_usage.log में लिखता है।

Speech-to-text: कॉल ट्रान्सक्रिप्ट और कैप्टन

कॉल की ट्रान्सक्रिप्ट, लाइव कैप्टन के साथ, एक स्पीच-टू-टेक्स्ट सर्वर द्वारा की जा सकती है जो OpenAI-संगत /v1/audio/transcriptions एंडपॉइंट प्रदान करता है। सेटअप कॉल और वॉइस में है। Summarize transcriptions चालू होने पर, डिफ़ॉल्ट एजेंट प्रत्येक ट्रान्सक्रिप्ट का सारांश भी पोस्ट करता है।

टेक्स्ट-टू-स्पीच: पढ़ें

टेक्स्ट-टू-स्पीच चालू होने पर, प्रत्येक संदेश के मेनू में बोलकर पढ़ें होता है: सर्वर संदेश के टेक्स्ट को टेक्स्ट-टू-स्पीच API को भेजता है और ऑडियो चलाता है। सेटिंग्स, सिस्टम कंसोल › इंटीग्रेशन › टेक्स्ट-टू-स्पीच में:

सेटिंगकी और वेरिएबलक्या डालें
संदेशों को वाचन करेंTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (डिफ़ॉल्ट रूप से बंद)
API बेस URLTextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URL/v1 तक और समेत आधार URL, उदाहरण के लिए http://tts.internal:8000/v1। सर्वर इसका /audio/speech एंडपॉइंट कॉल करता है।
मॉडलTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELAPI द्वारा नामित मॉडल, उदाहरण के लिए tts-1। आवश्यक है।
आवाज़TextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEमॉडल की आवाज़ों में से एक, या डिफ़ॉल्ट के लिए खाली।
API कुंजीTextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYबेयरर टोकन के रूप में भेजा जाता है। यदि API को कोई टोकन नहीं चाहिए, तो खाली रखें।

भेजने से पहले, सर्वर कोड ब्लॉक, लिंक, इमोजी कोड और फॉर्मेटिंग हटा देता है, और अधिकतम 4000 अक्षरों को रखता है। यह MP3 ऑडियो के लिए अनुरोध करता है और मेमोरी में अंतिम 64 परिणामों को रखता है, इसलिए दो बार पढ़ा गया संदेश केवल एक बार भेजा जाता है।

स्वतः अनुवाद

स्वतः अनुवाद चैनल के संदेशों को प्रत्येक पाठक की अपनी भाषा में दिखाता है। इसे सिस्टम कंसोल › साइट कॉन्फ़िगरेशन › लोकलाइज़ेशन में, स्वतः अनुवाद के अंतर्गत कॉन्फ़िगर करें:

सेटिंगकुंजीडिफ़ॉल्ट
सक्षम करेंAutoTranslationSettings.Enableबंद
अनुवाद प्रोवाइडरAutoTranslationSettings.Providerlibretranslate, openai ("OpenAI-compatible API" के रूप में दिखाया जाता है) या agents (Agents ऐप की एक सेवा)
अनुमत भाषाएंAutoTranslationSettings.TargetLanguagesen: वे भाषाएँ जिनमें संदेश अनुवादित किए जा सकते हैं
अनुवाद टाइमआउट (ms)AutoTranslationSettings.TimeoutMs5000
Restrict auto-translation on direct messages and group messagesAutoTranslationSettings.RestrictDMAndGMबंद

प्रत्येक प्रोवाइडर के अपने फ़ील्ड हैं:

  • LibreTranslate: LibreTranslate API Endpoint और LibreTranslate API Key (AutoTranslationSettings.LibreTranslate.URL, .APIKey)। LibreTranslate सर्वर आपके अपने नेटवर्क पर चलाया जा सकता है।
  • OpenAI-समान API: API बेस URL (/v1 तक, समेत; सर्वर इसका चैट कंप्लीशन एंडपॉइंट इस्तेमाल करता है), मॉडल और API कुंजी (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey)। स्थानीय रूप से चलने वाला एक छोटा अनुवाद मॉडल अच्छा काम करता है।
  • एजेंट: AI सेवा, एजेंट ऐप में कॉन्फ़िगर की गई सेवाओं में से एक।

एक बार यह चालू हो जाने पर, चैनल एडमिन उसकी सेटिंग्स में चैनल के लिए अनुवाद चालू करते हैं (स्वतः अनुवाद), और हर सदस्य चैनल मेनू से इससे बाहर निकल सकता है (संदेशों का अनुवाद करें)। डायरेक्ट और समूह संदेशों में कोई भी सदस्य इसे चालू कर सकता है; प्रतिबंध के साथ, वहाँ अनुवाद उपलब्ध नहीं होता है। अनुवादित संदेशों पर "अनुवादित … से" लिखा होता है, मूल संदेश के लिए एक लिंक के साथ।

टेक्स्ट भेजे जाने से पहले कोड, लिंक, उल्लेख और इमोजी को प्लेसहोल्डर से बदल दिया जाता है, और बाद में उन्हें वापस रखा जाता है।

इस सबको अपने नेटवर्क पर रखने के लिए, हर फीचर को उन सर्वरों की ओर इंगित करें जो आप स्वयं चलाते हैं। यदि आप क्लाउड प्रोवाइडर का उपयोग कर रहे हैं, तो उसके डेटा रिटेंशन नियमों की जांच करें, और अपने यूज़रों को बताएं कि कौन से फीचर उनके सन्देशों को बाहर भेजते हैं।

AI बंद करना

कोई एकल स्विच नहीं है: हर फीचर का अपना अलग स्विच है।

  • एजेंट: सिस्टम कंसोल › प्लगइन्स › प्लगइन प्रबंधन में एजेंट ऐप को अक्षम करें। इससे कॉल सारांश और एजेंट अनुवाद प्रोवाइडर भी हट जाते हैं।
  • ट्रान्सक्रिप्शन और कैप्शन: AM_CALLS_ENABLE_TRANSCRIPTIONS=false और AM_CALLS_ENABLE_LIVE_CAPTIONS=false (डिफ़ॉल्ट)।
  • बोलकर पढ़ें: संदेशों को वाचन करें बंद करें (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, डिफ़ॉल्ट)।
  • अनुवाद: ऑटो-अनुवाद बंद करें (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, डिफ़ॉल्ट)।

Agents ऐप को अक्षम करने से अन्य तीन फीचर बंद नहीं होते: वे सीधे अपने API को कॉल करते हैं।
