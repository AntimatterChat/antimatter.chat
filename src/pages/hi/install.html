शुरू करें

Antimatter को अपने सर्वर पर चलाएं

एक फ़ाइल, तीन कमांड, लगभग दस मिनट: Antimatter अपने डेटाबेस, फ़ाइल स्टोरेज और GIF सर्विस के साथ, Docker वाले किसी भी Linux सर्वर पर।

दस मिनट में तैयार

आपको Docker और उसके Compose प्लगइन वाला एक Linux सर्वर चाहिए, जिसमें कम से कम 2 CPU कोर और 4 GB मेमोरी हो।

1. कंपोज़ फ़ाइल डाउनलोड करें

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. रैंडम पासवर्ड के साथ इसकी सेटिंग्स बनाएं

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

SITE_URL में वह पता डालें जिससे लोग इसे खोलेंगे, जैसे लोकल नेटवर्क पर http://192.168.1.20:8065।

3. इसे शुरू करें

$ docker compose up -d

पहली बार शुरू होने में एक-दो मिनट लगते हैं, क्योंकि तब डेटाबेस बनता है। इसके बाद अपने ब्राउज़र में SITE_URL खोलें और अपना अकाउंट बनाएं: पहला अकाउंट सिस्टम एडमिनिस्ट्रेटर बनता है, और सेटअप आपको अपनी पहली टीम बनाने में कदम-दर-कदम मदद करता है।

अपने डोमेन और HTTPS के साथ

अपने डोमेन का एक DNS रिकॉर्ड सर्वर की ओर पॉइंट करें, पोर्ट 80 और 443 खोलें, और डोमेन को .env में जोड़ें:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy, Let's Encrypt से सर्टिफ़िकेट लेता है और उसे अपने-आप रिन्यू करता रहता है।

क्या-क्या चलता है

  • antimatter: सर्वर, अपने ऐप्स के साथ (नोट्स, व्हाइटबोर्ड, वॉइस चैनल, कॉल, पोल और बाकी)। यह डिस्क पर कुछ भी नहीं रखता: इसकी सेटिंग्स डेटाबेस में और फ़ाइलें स्टोरेज सर्विस में रहती हैं, इसलिए कंटेनर को कभी भी बदला जा सकता है।
  • postgres: डेटाबेस।
  • files: RustFS, अपलोड की गई फ़ाइलों के लिए S3-संगत स्टोरेज।
  • gifs: Antimatter की GIF और स्टिकर सर्विस, एक शुरुआती स्टिकर पैक के साथ।
  • https: Caddy, सिर्फ़ https प्रोफ़ाइल के साथ।

डेटाबेस, स्टोरेज और GIF सर्विस एक प्राइवेट नेटवर्क पर रहते हैं, जहां तक सिर्फ़ Antimatter पहुंच सकता है।

अगर GIF पिकर खाली रहे, तो सिस्टम कंसोल › प्लगइन › GIFs खोलें, फिर सर्विस URL में http://gifs:8080/v2 और API कुंजी में अपनी .env का GIFS_API_KEY डालें।

अपग्रेड और बैकअप

# सबसे नई इमेज पर अपग्रेड करें
$ docker compose pull && docker compose up -d
# डेटाबेस का बैकअप लें
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

files वॉल्यूम का भी बैकअप लें, या किसी भी S3 टूल से स्टोरेज को रेप्लिकेट करें। nginx और अपने सर्टिफ़िकेट वाले सेटअप के लिए, antimatter-docker में प्रोडक्शन फ़ाइलें देखें।

रिलीज़ आर्काइव के साथ

  1. एक PostgreSQL डेटाबेस और यूज़र सेट अप करें।
  2. आर्काइव (antimatter-<os>-<arch>.tar.gz) को अनपैक करें, उदाहरण के लिए /opt/antimatter में, और config/config.json में SqlSettings.DataSource (या MM_SQLSETTINGS_DATASOURCE एनवायरनमेंट वेरिएबल) को डेटाबेस की ओर पॉइंट करें।
  3. सर्वर को bin/antimatter से, बिना विशेषाधिकार वाले यूज़र के रूप में शुरू करें, और http://localhost:8065 खोलें। बनाया गया पहला अकाउंट सिस्टम एडमिनिस्ट्रेटर बनता है।

bin/amctl कमांड लाइन से चल रहे सर्वर को मैनेज करता है (सर्वर पर ही bin/amctl --local, ServiceSettings.EnableLocalMode के साथ)।

आगे क्या करें

  • कॉल: कॉल पोर्ट (डिफ़ॉल्ट रूप से UDP और TCP 8443) खोलें, ताकि वॉइस और वीडियो सर्वर तक पहुंच सकें।
  • ईमेल: आमंत्रण और सूचनाओं के लिए SMTP कॉन्फ़िगर करें।
  • AI: एजेंट सेटिंग्स में एक मॉडल जोड़ें; कोई भी OpenAI-संगत API काम करता है, आपका अपना चलाया हुआ सर्वर भी।
  • स्पीच और अनुवाद: कॉल ट्रांसक्रिप्शन, बोलकर पढ़ने और ऑटोमैटिक अनुवाद को अपने चलाए स्पीच-टू-टेक्स्ट, टेक्स्ट-टू-स्पीच और अनुवाद मॉडल की ओर पॉइंट करें।
