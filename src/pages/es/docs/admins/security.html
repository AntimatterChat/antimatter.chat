Lista de verificación después de la instalación

  1. Crea la primera cuenta de administrador antes de que nadie más pueda acceder al servidor (Instalación).
  2. Sirve Antimatter solo a través de HTTPS y establece la URL del sitio con la dirección https:// (Dominio y HTTPS).
  3. Mantén .env, config.json y las claves TLS legibles solo por root (o el usuario del servidor): chmod 600 .env.
  4. Decide quién puede crear cuentas, mantén Habilitar Servidor Abierto desactivado a menos que la comunidad sea pública, y activa Require verificación de correo electrónico una vez que el correo funcione (Inicio de sesión y cuentas).
  5. Activa la autenticación multifactor y, al menos, exígela para las cuentas de administradores, o utiliza la de tu proveedor de identidad.
  6. Revisa las conexiones externas a continuación, en particular el servidor STUN que las Llamadas usan de forma predeterminada.
  7. Realiza copias de seguridad y prueba una restauración (Copias de seguridad y actualizaciones).
  8. Mantén las imágenes actualizadas: las correcciones de seguridad llegan con las nuevas imágenes.

Limitación de tasa

El servidor puede limitar la cantidad de solicitudes de API que realiza cada cliente. Está desactivado de forma predeterminada. En Consola de sistema › Entorno › Límite de Velocidad:

Máximo de consultas por segundoRateLimitSettings.PerSec10
Máximo Tamaño de la RáfagaRateLimitSettings.MaxBurst100
Tamaño de memoria de almacenamientoRateLimitSettings.MemoryStoreSize10000 clientes rastreados
Variar el límite de velocidad por dirección remotaRateLimitSettings.VaryByRemoteAddractivado
Variar límite de velocidad por usuarioRateLimitSettings.VaryByUserdesactivado
Variar el límite de velocidad según el encabezado HTTPRateLimitSettings.VaryByHeadervacío

Detrás de un proxy, las limitaciones por dirección solo funcionan si el servidor conoce la dirección de cada cliente (ServiceSettings.TrustedProxyIPHeader y ServiceSettings.TrustedProxyIPs, ver Direcciones de clientes detrás de un proxy). De lo contrario, todas las solicitudes parecen provenir del proxy y todos comparten un único límite. Lo mismo aplica al filtrado por IP y a las direcciones en los registros de auditoría.

Los intentos de inicio de sesión se limitan por separado: Máximo de intentos de conexión (10) bloquea una cuenta después de ese número de contraseñas incorrectas.

Filtrado por IP

Consola de sistema › Configuración del Sitio › Filtrado de IP limita el acceso al servidor por dirección IP, con reglas de permitir y denegar (una dirección o un rango CIDR cada una). Con Activar filtrado de IP activado, las personas cuya dirección coincida con una regla de denegar, o que no coincida con ninguna regla de permitir cuando existen reglas de permitir, no pueden acceder al servidor. La página rechaza las reglas que bloquearían tu propia dirección. Detrás de un proxy, configura primero las direcciones de los clientes (Direcciones de clientes detrás de un proxy): de lo contrario, todas las solicitudes parecen provenir del proxy.

Ignorar, bloquear y solicitudes de mensaje

Con Activar ignorar, bloquear y solicitudes de mensaje activado (valor predeterminado), las personas pueden ignorarse y bloquearse entre sí, y pueden elegir recibir mensajes directos de personas desconocidas como solicitudes de mensaje, que no las notificarán hasta que se acepten. Esto es adecuado para comunidades públicas. En un entorno laboral donde los colegas deben poder contactarse siempre, desactívalo (AM_PRIVACYSETTINGS_ENABLEUSERBLOCKING=false): ninguna de estas funciones se aplicará, pero se conservarán las listas y las elecciones realizadas, y volverán a aplicarse si lo activas de nuevo.

Sesiones y tokens

  • Duración de las sesiones y tiempo de espera por inactividad: véase Inicio de sesión y cuentas. Sesiones más cortas significan que un portátil o teléfono perdido permanecerá conectado durante menos tiempo.
  • Habilitar Tokens de Acceso Personales (ServiceSettings.EnableUserAccessTokens, desactivado) permite a las personas crear tokens de API; Vida útil máxima de token de acceso personal (días) los limita. Ambos se encuentran en Consola de sistema › Integraciones › Gestión de Integraciones.
  • Para cerrar la sesión de todos a la vez, por ejemplo tras una presunta violación de seguridad: Revocar todas las sesiones en Consola de sistema › Gestión de usuarios › Usuarios.

Conexiones con servicios externos

Antimatter no contacta ningún servicio operado por Mattermost, Inc. No envía telemetría, informes de errores ni comprobaciones de actualizaciones de seguridad, y no recupera avisos de producto. Una configuración importada de Mattermost que aún nombre uno de los servicios de Mattermost (sus servicios de notificaciones push, su mercado de aplicaciones, sus avisos o su servidor STUN para llamadas) no hace que el servidor los contacte: esas direcciones se ignoran.

De forma predeterminada, el servidor se niega a conectarse a direcciones privadas y de bucle inverso para estos (previsualizaciones de enlaces, webhooks, aplicaciones), de modo que un mensaje o una integración no pueda usarse para acceder a la red interna. Enumera los hosts internos a los que puede conectarse en Permitir conexiones internas no son de confianza (ServiceSettings.AllowedUntrustedInternalConnections, en Consola de sistema › Entorno › Desarrollo); el archivo de composición del sitio lista gifs allí.
