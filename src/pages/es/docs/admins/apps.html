Las aplicaciones incluidas

Las aplicaciones se listan como Plugins en la Consola de sistema. Están en la imagen (en /antimatter/prepackaged_plugins), firmadas con la clave de firma de aplicaciones de Antimatter, por lo que se instalan sin conexión a Internet.

El archivo de la versión y los paquetes .deb y .rpm incluyen menos aplicaciones: consulte Aplicaciones en los paquetes y el archivo.

Las aplicaciones activas de forma predeterminada se instalan en cada inicio si aún no lo están, o se actualizan si la imagen tiene una versión más reciente. Si desactivas una, permanece desactivada: el valor predeterminado solo se aplica a las aplicaciones que la configuración aún no menciona. Las aplicaciones que conservan su ID de Mattermost (Chat de IA, Llamadas y las integraciones) son compilaciones propias de Antimatter.

Kanban (focalboard) y Playbooks (playbooks) ya no se incluyen con el servidor ni con ninguna de las imágenes: instala la que desees desde su propia versión de GitHub (consulta Aplicaciones en los paquetes y el archivo), igual que cualquier otra aplicación que no esté incluida de forma predeterminada. Un servidor que ya tenga una instalada la conserva tras una actualización. Ambas siguen siendo compilaciones propias de Antimatter: las versiones estándar del Marketplace nunca reemplazan a las de Antimatter.

Activar, desactivar y configurar aplicaciones

Vaya a Consola de sistema › Plugins › Gestión de Plugins. En Plugins instalados, cada aplicación tiene Activado o Desactivado, Configuración y Quitar, y muestra su estado (En ejecución, No en ejecución, Error al iniciar…). Cada aplicación con ajustes también tiene su propia página en Consola de sistema › Plugins.

Las aplicaciones incluidas que están desactivadas por defecto se instalan desde la copia propia de la imagen: haga clic en su foto en la parte superior de la barra lateral y elija Aplicación Marketplace (en la interfaz clásica, está en el menú del producto), busque la aplicación y haga clic en Instalar, luego actívela en Gestión de Plugins. Desde la línea de comandos:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Otros comandos: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Activar aplicaciones mediante la configuración

Qué aplicaciones están activas se define en la configuración PluginSettings.PluginStates, un mapa de ids de aplicaciones. Puede fusionar entradas en él con amctl; con Habilitar plugins pre-empacados automaticamente activado (el valor por defecto), una aplicación incluida habilitada se instala en el siguiente inicio:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Esta es también la forma de instalar Todo, que no se ofrece en el diálogo de Marketplace. La variable AM_PLUGINSETTINGS_PLUGINSTATES también funciona, pero reemplaza todo el mapa: enumera todas las aplicaciones que deseas activar.

Configuración de la aplicación

La configuración de las aplicaciones se almacena en PluginSettings.Plugins.<app id>, con claves en minúsculas. Cámbiala en la página de la Consola de sistema de la aplicación, o con amctl config patch como se muestra en Configuración. AM_PLUGINSETTINGS_PLUGINS reemplaza la configuración de todas las aplicaciones a la vez y las bloquea, así que evítalo.

La aplicación GIF añade una pestaña de GIF y pegatinas al selector de emoji, respaldada por el servicio de GIF de Antimatter (gifs-server), que utiliza la API de Tenor. Mientras la aplicación GIF está configurada, su pestaña reemplaza el selector de Giphy integrado (Consola de sistema › Integraciones › GIF › Habilitar Selector de GIF, ServiceSettings.EnableGifPicker).

El servicio de GIF

El servicio mantiene todo en su directorio de datos (/data, el volumen gifs): un índice de búsqueda y los medios. Sus variables principales:

VariablePredeterminadoQué hace
AM_GIFS_API_KEYSningunaClaves de API separadas por comas. Si no se configura ninguna clave, la API queda abierta a cualquiera que acceda a ella. Varias claves permiten rotarlas.
AM_GIFS_UPLOAD_KEYSningunaClaves autorizadas para subir y para eliminar lo que se haya subido. Sin una clave, no se permiten subidas.
AM_GIFS_RATE_LIMIT20Peticiones por segundo por cliente (clave de API y dirección); 0 lo desactiva. El archivo de composición establece 0, porque todas las peticiones de Antimatter comparten una misma clave y dirección.
AM_GIFS_LISTEN:8080Dirección de escucha.
AM_GIFS_PUBLIC_URLde las peticionesURL externa, si se expone el servicio.
AM_GIFS_TRUST_PROXYfalseConfiar en las cabeceras X-Forwarded-*, solo detrás de un proxy.
AM_GIFS_UPLOAD_MAX_MB16Tamaño máximo del archivo subido.

Para añadir tus propios GIF en lotes, impórtalos con un manifiesto, desde un directorio montado en un contenedor de un solo uso:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

Para volver a importar los stickers iniciales después de una actualización: docker compose run --rm gifs stickers. El formato del manifiesto y los demás comandos están en el README de gifs-server.

Correo y Calendario

Correo y Calendario conectan a cada persona con su propio buzón (IMAP y SMTP) y su propio calendario (CalDAV). Las personas introducen su servidor y contraseña en la aplicación; las contraseñas se almacenan cifradas. No configuras los servidores de correo o calendario por ellas, pero decides a qué pueden conectarse:

AplicaciónAjustePredeterminadoQué hace
Correo, CalendarioPermitir servidores de correo en redes privadas, Permitir servidores de calendario en redes privadas (AllowPrivateNetworks)desactivadoSi está desactivado, el servidor se niega a conectarse a direcciones de bucle, privadas y de enlace local, de modo que las aplicaciones no puedan usarse para acceder a tu red interna. Actívalo si tu servidor de correo o calendario está en una dirección privada.
Correo, CalendarioPermitir conexiones sin cifrar (AllowInsecureConnections)desactivadoSi está desactivado, las conexiones deben usar TLS (Correo: TLS o STARTTLS; Calendario: HTTPS).
CorreoIntervalo de comprobación de no leídos (minutos) (UnreadCheckMinutes)2 minutosCon qué frecuencia se comprueban los recuentos de mensajes sin leer cuando el servidor de correo no puede notificarlos.
CorreoTamaño máximo de mensaje (MB) (MaxMessageSizeMB)25 MBLímite de tamaño de los mensajes enviados y leídos.
CalendarioEnviar recordatorios (EnableReminders)activadoEl bot de Calendario envía un mensaje directo antes de los eventos (10 minutos antes, para eventos que no tienen su propia alarma).

Para permitir que las personas inicien sesión en buzones de Gmail o Microsoft 365 con su cuenta en lugar de una contraseña, crea un cliente OAuth y completa los campos de Google o Microsoft de la aplicación de Correo:

  • Google: un cliente OAuth Web con la API de Gmail y el ámbito https://mail.google.com/.
  • Microsoft: una aplicación de Entra ID con los permisos delegados IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email y profile. El inquilino predeterminado es common.
  • En ambos, la URI de redirección es https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (la URL de tu sitio).

Kanban, Notas, Pizarra, Encuestas y Playbooks

  • Kanban (focalboard) se abre en su panel lateral junto a la conversación, al igual que Playbooks. Los enlaces antiguos a las páginas /kanban/… y /boards/… abren el mismo tablero o tarjeta en una comunidad. Su única configuración, Habilitar tableros compartidos públicamente (EnablePublicSharedBoards, desactivado), permite a los editores del tablero compartirlo con cualquier persona que tenga el enlace, sin necesidad de iniciar sesión.
  • Notas y Encuestas no tienen configuraciones.
  • Pizarra: los administradores del sistema pueden subir bibliotecas de formas (archivos Excalidraw .excalidrawlib, de hasta 5 MB cada uno) para todo el servidor en su página de configuración. Los administradores de la comunidad gestionan las bibliotecas de su propia comunidad.
  • Playbooks se abre en su panel lateral. Los enlaces antiguos a las páginas /playbooks/… abren la misma ejecución o playbook en una comunidad. Tiene algunas configuraciones, en su mayoría funciones experimentales; los valores predeterminados son adecuados para la mayoría de los servidores.
  • Memes: Quién puede añadir plantillas de memes: Todos (predeterminado), Administradores del sistema o Nadie (plantillas personalizadas desactivadas), lo que impide añadir nuevas plantillas, aunque las ya añadidas sigan siendo utilizables. Los invitados nunca añaden plantillas. La persona que añadió una plantilla y los administradores del sistema pueden eliminarla.
  • Por hacer no tiene configuraciones de servidor.

GitHub, GitLab y Jira

Estas aplicaciones conectan Antimatter con tu servicio de alojamiento de código y tu gestor de incidencias. Cada una requiere una aplicación OAuth en el otro extremo y un webhook que apunte de vuelta a Antimatter. Habilita la aplicación y luego ejecuta su comando de configuración en cualquier canal, que te guiará paso a paso: /github setup, /gitlab setup o /jira setup.

Deja Usar aplicación OAuth preregistrada desactivado en las aplicaciones de GitHub y GitLab: se basa en un servicio de Mattermost que Antimatter no tiene, y la aplicación se niega a iniciarse si está activado. Registra tu propia aplicación OAuth.

Las aplicaciones de GitHub y GitLab generan su secreto de webhook y su clave de cifrado al guardarlas por primera vez. La aplicación de GitHub se puede limitar a organizaciones (GithubOrg) y la de GitLab a un grupo (GitlabGroup); para GitHub Enterprise o un GitLab autoalojado, configura su URL base.

Métricas

La aplicación de Métricas recopila las métricas de rendimiento del servidor en una pequeña base de datos de series temporales dentro de Antimatter, de modo que puedes descargarlas o incluirlas en un paquete de soporte sin tener que ejecutar Prometheus. Al iniciarse, activa el punto de acceso de métricas del servidor (MetricsSettings.Enable). Consulta Operaciones.

Instalación de otras aplicaciones

Antimatter ejecuta aplicaciones de Mattermost (complementos). Hay tres formas de añadir una:

  • Desde un Marketplace remoto. Habilitar Marketplace Remoto (PluginSettings.EnableRemoteMarketplace) está desactivado por defecto y URL del Marketplace (PluginSettings.MarketplaceURL) está vacío: Antimatter no utiliza el Marketplace de Mattermost e ignora su dirección si una configuración de Mattermost la incluye. Para listar las aplicaciones de un servidor de Marketplace en el que confíes, activa la configuración y establece su URL. Las versiones de las aplicaciones que Antimatter incluye (Llamadas, Playbooks, Kanban y otras) que ofrezca ese Marketplace se ocultan, por lo que no pueden reemplazar a las de Antimatter: Permitir que el Marketplace ofrezca sus propias versiones de los complementos de Antimatter (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) está desactivado por defecto.
  • Subiendo un paquete (.tar.gz). Las subidas están desactivadas por defecto y no tienen un interruptor en la Consola de sistema: establece AM_PLUGINSETTINGS_ENABLEUPLOADS=true y luego usa Cargar Plugin en la gestión de complementos, o amctl --local plugin add app.tar.gz.
  • Desde una URL: amctl plugin install-url <url>, también con las subidas activadas.

Antimatter verifica las firmas de las aplicaciones contra las claves en las que confía: la clave de Antimatter, la clave con la que Mattermost, Inc. firma sus aplicaciones publicadas (de modo que una aplicación de Mattermost que descargues tú misma se instale) y cualquier clave que añadas en PluginSettings.SignaturePublicKeyFiles. Con Requerir Firma del Plugin (PluginSettings.RequirePluginSignature, desactivado por defecto) activado, se rechazan las aplicaciones sin firma y se desactivan las subidas.

Una aplicación se ejecuta dentro del servidor con acceso completo a sus datos. Instala solo aplicaciones en las que confíes.

Algunas aplicaciones creadas para las ediciones de pago de Mattermost comprueban por sí mismas si existe una licencia de Mattermost y se niegan a ejecutarse; Antimatter no finge tener una para ellas.
