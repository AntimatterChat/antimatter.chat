Política de privacidad

Última actualización: 11 de octubre de 2026. Esta traducción se ofrece solo por comodidad; en caso de discrepancia, prevalece la versión en inglés.

Esta página trata dos cosas: el software Antimatter, que las organizaciones ejecutan en sus propios servidores, y este sitio web, antimatter.chat.

El software Antimatter

Antimatter es autoalojado. Cuando usas un servidor de Antimatter, la organización que lo gestiona decide qué datos se conservan, durante cuánto tiempo y quién puede acceder a ellos. El proyecto Antimatter no tiene acceso a tu servidor, a tu cuenta ni a tus mensajes. Si tienes preguntas sobre tus datos en un servidor concreto, ponte en contacto con sus administradores; se aplica su propia política de privacidad.

Lo que hace el software por sí mismo:

  • No hay telemetría. El servidor no envía estadísticas de uso, diagnósticos ni ningún otro dato al proyecto Antimatter ni a terceros.
  • Solo se conecta al exterior para las funciones que activa un administrador, y únicamente a los servicios que este configura: por ejemplo, un servicio de notificaciones push, las vistas previas de los sitios web enlazados en los mensajes, un proveedor de GIFs, un servidor de correo electrónico, un proveedor de identidad para el inicio de sesión único, o modelos de IA, de voz o de traducción.
  • Las funciones de IA usan los modelos que elige el administrador. Cuando un tercero los aloja, lo que se les envía (un mensaje que reescribir, una conversación que resumir, el audio de una llamada que transcribir) llega a ese proveedor. Los administradores pueden usar modelos autoalojados para que nada salga de su red.

Este sitio web

  • antimatter.chat es un sitio web estático alojado en GitHub Pages.
  • No instala ninguna cookie y no usa analíticas, rastreadores ni publicidad. Sus fuentes e imágenes se sirven desde el propio sitio, así que tu navegador no hace ninguna solicitud a otros sitios web mientras lo lees.
  • Como cualquier servicio de alojamiento web, GitHub recibe tu dirección IP y las páginas que solicitas, para poder servirlas. Consulta la Declaración de privacidad de GitHub.
  • Si abres una incidencia o contribuyes en GitHub, lo que publicas allí es público y GitHub lo trata conforme a sus propias condiciones.

Contacto

Si tienes preguntas sobre esta política, abre una incidencia en el repositorio del sitio web.
