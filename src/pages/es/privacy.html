Política de privacidad

Última actualización: 16 de octubre de 2026.

Esta página cubre dos aspectos: el software Antimatter, que las organizaciones ejecutan en sus propios servidores, y este sitio web, antimatter.chat.

El software Antimatter

Antimatter es autoalojado. Cuando usas un servidor de Antimatter, la organización que lo administra decide qué datos se conservan, durante cuánto tiempo y quién puede acceder a ellos. El proyecto Antimatter no tiene acceso a tu servidor, tu cuenta ni tus mensajes. Para preguntas sobre tus datos en un servidor en particular, contacta a sus administradores; se aplica su propia política de privacidad.

Lo que el software hace por sí mismo:

  • Sin telemetría. El servidor no envía estadísticas de uso, diagnósticos ni ningún otro dato al proyecto Antimatter, a Mattermost, Inc. (cuyo software es la base de Antimatter) ni a otros terceros.
  • Conexiones externas solo para funciones que un administrador activa, hacia los servicios que configuran: por ejemplo, un servicio de notificaciones push, un proveedor de GIF, un servidor de correo, un proveedor de identidad para inicio de sesión único, o modelos de IA, voz o traducción.
  • Dos excepciones, activadas por defecto, que los administradores pueden desactivar. Vista previa de enlaces: cuando alguien publica un enlace, el servidor obtiene esa página para mostrar su título y su imagen. Y las llamadas: utilizan el servidor STUN público de Cloudflare (stun.cloudflare.com) para encontrar direcciones de red pública. El servidor lo consulta cuando se inicia la app de Llamadas, y el dispositivo de cada persona lo consulta cuando se une a una llamada. Cloudflare solo ve la dirección IP y el puerto del servidor y de cada persona que se une, no la propia llamada. Los administradores pueden usar su propio servidor STUN en su lugar, o ninguno; consulta Llamadas y voz.
  • Las funciones de IA utilizan los modelos que el administrador elige. Cuando están alojados por un tercero, lo que se les envía (un mensaje para reescribir, una conversación para resumir, el audio de una llamada transcrita) va a ese proveedor. Los administradores pueden usar modelos autoalojados para que nada salga de su red.

Este sitio web

  • antimatter.chat es un sitio web estático alojado en GitHub Pages.
  • No establece cookies y no utiliza analítica, rastreadores ni publicidad. Sus fuentes e imágenes se sirven desde el propio sitio, por lo que tu navegador no realiza solicitudes a otros sitios web mientras lo lees.
  • Como cualquier host web, GitHub recibe tu dirección IP y las páginas que solicitas para servirlas. Consulta la Declaración de privacidad de GitHub.
  • Si abres un problema o contribuyes en GitHub, lo que publiques allí es público y lo gestiona GitHub según sus propios términos.

Contacto

Para preguntas sobre esta política, abre un problema en el repositorio de la comunidad de Antimatter.
