프로필 편집

  1. 창의 오른쪽 상단에 있는 프로필 사진을 클릭한 다음 내 계정을 선택합니다. 설정이 내 계정 탭에서 열립니다.
  2. 프로필 사진 변경을 클릭하여 JPEG, PNG 또는 BMP 이미지를 업로드하거나, 제거를 클릭하여 이니셜로 되돌립니다.
  3. 이름, 성, 사용자 이름, 별명, 직책(예: 직위)을 입력하거나 변경합니다.
  4. 저장을 클릭합니다.

사용자 이름은 소문자, 숫자, 마침표, 대시, 밑줄을 사용할 수 있으며, 문자로 시작해야 합니다. 일부 필드는 잠겨 있을 수 있습니다. 조직의 로그인 시스템이 제공하는 경우 "로그인 제공자에서 설정됨" 또는 "시스템 관리자에 의해 관리됨"으로 표시됩니다.

이메일 주소를 변경하려면 이메일 변경…을 클릭하고 새로운 전자우편과 현재 비밀번호를 입력한 다음 이메일 변경을 클릭합니다. 새 주소로 확인을 위한 메시지가 전송될 수 있습니다.

조직에서 설정한 프로필 정보

관리자는 부서, 사이트, 전화번호와 같은 필드를 프로필에 추가할 수 있습니다. 이러한 필드는 내 계정의 프로필 정보 아래에 표시되며, 변경이 허용된 필드를 입력할 수 있습니다. 커뮤니티에는 자체 멤버 속성이 있을 수도 있습니다. 일부 속성을 설정할 수 있는 경우, 자신의 이름을 오른쪽 클릭하여 속성 편집…을 선택합니다.

팀 배지

현재 커뮤니티에 팀이 있는 경우, 내 계정의 팀 배지에서 이름 옆에 표시할 팀 태그를 선택하거나 없음을 선택합니다. 각 커뮤니티는 자체 선택을 유지합니다.

내 역할

일부 커뮤니티에는 누구나 선택할 수 있는 역할이 있으며, 이는 이름의 색상을 변경하고 더 많은 작업을 수행할 수 있게 할 수 있습니다. 커뮤니티 메뉴에서 내 역할…을 선택하여 역할을 선택하거나 해제합니다.

다른 사람이 자신을 보는 방법

다른 사람이 이름이나 사진을 클릭하면 프로필 카드를 볼 수 있습니다: 이름, 사용자 이름, 직책, 사용자 지정 상태, 현지 시간, 역할, 그리고 조직이 표시하는 프로필 정보. 자신의 이름을 클릭하여 확인하십시오. 프로필 수정 및 상태 설정 버튼이 있습니다.

기본적으로, 다른 사람은 자신이 자리를 비우거나 오프라인 상태일 때 "마지막 접속 …"을 볼 수 있습니다. 이를 숨추려면 설정 › 모양에서 마지막 접속 시간 공유를 끕니다.

사용자 지정 상태 설정

사용자 지정 상태는 이름 옆에 표시되는 이모지가 포함된 짧은 텍스트로, "회의 중"이나 "휴가 중"과 같은 내용을 사용할 수 있습니다.

  1. 창의 오른쪽 상단에 있는 프로필 사진을 클릭합니다.
  2. 사용자 지정 상태 설정에 내용을 입력하고 이모지 버튼(이모지 선택)을 클릭하여 이모지를 선택합니다. 또는 제안 또는 최근 상태 중 하나를 선택할 수도 있습니다.
  3. 이후 지우기를 사용하여 상태가 사라지는 시점을 선택합니다: 30 분, 1 시간, 4 시간, 오늘, 이번주, 지우지 마세요, 또는 날짜와 시간 선택….

상태를 지우려면 사용자 지정 상태 지우기(×)를 클릭합니다. 가용 상태(온라인, 자리 비움, 방해 금지)에 대해서는 상태를 참고하세요.

다른 사람의 프로필

사용자의 이름이나 사진을 클릭하면 해당 사용자의 프로필 카드가 표시됩니다. 여기에는 사용자의 현지 시간과 내 시간과의 시차가 표시됩니다. 여기서 사용자에게 메시지를 보내거나 통화를 걸 수 있습니다. 이름이나 사진을 우클릭하면 더 많은 옵션이 표시됩니다: 프로필, 메시지, 채널에 추가, 커뮤니티에 초대, 멘션, 사용자 이름 복사, 무시 및 차단….

프로필 카드에는 메모 필드도 있습니다. 클릭하여 해당 사람에 대한 메모를 작성할 수 있습니다. 이 메모는 나만 볼 수 있습니다.

누가 나에게 메시지를 보낼 수 있는지

관리자가 허용하는 경우, 설정 › 개인정보 및 안전에서 아직 대화하지 않은 사람으로부터 다이렉트 메시지를 받는 방식을 결정합니다. 선택한 내용은 다른 사람에게 알려지지 않습니다.

  • 다이렉트 메시지의 아직 대화하지 않은 사람에서 모두 허용 또는 먼저 확인을 선택하세요. 선택 후 해당 사용자의 메시지는 승인할 때까지 알림 없이 메시지 요청 목록에 대기합니다. 봇과 시스템 관리자의 메시지는 항상 전달됩니다.
  • 각 커뮤니티별 항목에서 참여 중인 각 커뮤니티별로 다른 선택을 할 수 있습니다. 공유하는 커뮤니티 중 하나에서 해당 사용자가 허용되면 메시지가 전달됩니다.

메시지 요청

대기 중인 다이렉트 메시지는 다이렉트 메시지 상단의 메시지 요청에 나열됩니다. 요청을 열어서 내용을 읽을 수 있습니다. 메시지 입력 상자 대신 "…(사용자 이름)의 메시지 요청"이라는 표시가 있으며, 세 가지 선택지가 제공됩니다:

  • 수락: 대화가 일반 대화로 전환되고, 해당 사용자의 메시지에 대해 알림을 받습니다.
  • 무시: 해당 사용자가 다시 메시지를 보내기까지 요청이 숨겨집니다.
  • 차단: 아래를 참고하세요.

보낸 사람은 요청이 읽혔는지, 무시되었는지, 차단되었는지 알 수 없습니다. 특정 사용자의 요청을 계속 무시하면 Antimatter가 해당 사용자를 차단할 것을 제안합니다. 이때 나중에 또는 이 사용자에게 다시 묻지 않기로 답할 수 있습니다.

사용자 무시 또는 차단

사용자의 이름이나 프로필 사진을 오른쪽 클릭하거나, 프로필 카드의 ⋯를 열어서:

  • 무시: 해당 사용자가 작성한 메시지로 알림을 받지 않으며, 다이렉트 메시지는 메시지 요청 목록에 대기하고, 채널 내 메시지는 "무시한 사용자의 메시지"라는 한 줄로 접힙니다. 보기를 클릭하여 한 건을 읽을 수 있습니다.
  • 차단…: 해당 사용자가 더 이상 다이렉트 메시지를 보내거나 그룹 메시지를 시작할 수 없으며, 작성한 내용으로 알림을 받지 않고, 공유 채널의 메시지는 접힙니다. 차단으로 확인합니다. 해당 사용자와의 다이렉트 메시지에는 "차단한 사용자"라고 표시되며, 차단을 해제할 때까지 양쪽 모두 해당 대화에 글을 쓸 수 없습니다.

해당 사용자에게는 알려지지 않습니다. 되돌리려면 같은 메뉴에서 무시 해제 또는 차단 해제를 선택하거나, 설정 › 개인정보 및 보안에서 차단됨 및 무시한 사용자 목록에서 처리할 수 있습니다.

차단은 사용자를 채널에서 제거하지 않으며, 신고를 하지 않습니다. 괴롭힘을 당하는 경우 커뮤니티 관리자에게도 알리세요. 커뮤니티에서 제공하는 경우 메시지 메뉴의 메시지 신고를 사용할 수 있습니다.

비밀번호 및 멀티팩터 인증

설정 › 보안으로 이동합니다.

비밀번호 변경

  1. 패스워드 옆의 변경…를 클릭합니다.
  2. 현재 비밀번호, 새 패스워드, 새 비밀번호 확인을 입력합니다.
  3. 비밀번호 변경을 클릭합니다.

조직의 인증 시스템(예: SAML, AD/LDAP 또는 GitLab)을 통해 로그인하는 경우, 페이지에 해당 사항이 표시되며 비밀번호는 해당 시스템에서 관리됩니다. 접속 방식에서 비밀번호와 해당 시스템 간 전환이 가능합니다.

비밀번호를 잊어버린 경우, 로그인 페이지의 비밀번호를 잊어버리셨나요?를 클릭하고 이메일 주소를 입력하여 링크를 받으세요.

멀티팩터 인증 켜기

멀티팩터 인증은 로그인할 때마다 휴대폰 앱에서 코드를 요구하여, 비밀번호만으로는 로그인할 수 없도록 합니다.

  1. Aegis, Google Authenticator 또는 1Password와 같은 인증기 앱을 휴대폰에 설치합니다.
  2. 멀티팩터 인증 옆의 설정…을 클릭합니다.
  3. 앱으로 QR 코드를 스캔하거나, 아래에 표시된 키를 입력합니다.
  4. 앱에 표시된 코드를 입력하고 켜기를 클릭합니다.

다른 휴대폰을 사용하려면 다시 설정…을 클릭합니다. 끄려면 다중 인증 제거 옆의 제거를 클릭합니다. 서버에서 요구하는 경우를 제외하고는 가능합니다.

로그인된 위치

설정 › 보안의 로그인한 기기 섹션에는 계정에 로그인된 각 브라우저, 데스크톱 앱 및 휴대폰과 마지막 활동 시점이 표시됩니다. 알 수 없거나 더 이상 사용하지 않는 기기가 있으면 해당 기기의 로그아웃을 클릭하고, 누군가가 계정을 사용했을 가능성이 있다면 비밀번호를 변경하세요.

접근 기록(보기 클릭)에는 계정에서 최근 발생한 로그인 및 변경 사항과 해당 발생 위치가 나열됩니다.

현재 사용 중인 기기에서 로그아웃하려면 오른쪽 상단의 프로필 사진을 클릭한 뒤 로그아웃을 선택하세요.

토큰 및 승인된 앱

서버가 허용하는 경우, 설정 › 보안에는 개인 액세스 토큰도 있습니다. 이를 통해 스크립트가 사용자를 대신하여 Antimatter를 사용할 수 있습니다. 토큰 생성하기를 통해 하나를 생성하고 즉시 복사하세요. 토큰은 다시 표시되지 않습니다. 더 이상 필요하지 않은 토큰은 취소하고, 토큰을 절대 공유하지 마세요. 승인한 앱 목록에는 계정을 사용할 수 있도록 허용한 외부 애플리케이션이 나열됩니다. 접근 권한 제거를 클릭하여 권한을 회수할 수 있습니다.

계정 비활성화

서버가 허용하는 경우, 설정 › 보안 하단의 계정 비활성화를 통해 서버를 나갈 수 있습니다. 비활성화…를 클릭한 뒤 비활성화를 선택하세요. 로그아웃이 수행되며 다시 로그인할 수 없으나, 작성한 메시지는 유지됩니다. 관리자가 계정을 다시 활성화할 수 있습니다.
