이 가이드의 내용

Antimatter는 팀이나 커뮤니티와 대화하는 곳입니다: 채널, 개인 대화, 통화, 그리고 공유 메모와 화이트보드와 같은 앱. 이 가이드의 각 페이지는 각 작업을 단계별로 설명합니다:

  • 메시지 작성: 서식, 멘션, 이모지, 답글과 글타래, 편집, 임시 저장, 예약 등.
  • 커뮤니티와 채널: 참여, 사이드바 정리, 다이렉트 메시지와 그룹 메시지.
  • 통화와 음성 채널: 대화, 화면 공유, 실시간 자막.
  • 앱: 메모, 화이트보드, 칸반 보드, 캘린더, 메일, 투표, 할 일 목록 등.
  • AI 에이전트: 서버에 해당 기능이 있는 경우, 요약, 재작성 및 질문.
  • 알림과 상태: 어떤 알림이 언제 도달하는지.
  • 프로필과 개인정보: 프로필, 메시징 허용 대상, 차단, 그리고 계정 보안.
  • 검색과 찾기: 검색, 멘션, 저장된 메시지와 읽지 않은 메시지.
  • 설정과 단축키: 테마, 언어 및 키보드 단축키.

각 Antimatter 서버는 자체 관리자에 의해 운영되며, 활성화할 기능과 앱을 선택합니다. 이 가이드에 있는 것이 보이지 않는다면, 아마도 서버에서 비활성화된 것입니다: 관리자에게 문의하세요.

로그인

Antimatter에는 중앙 웹사이트가 없습니다: 각 조직이나 커뮤니티는 chat.example.com과 같은 고유한 주소를 가진 자체 서버를 운영합니다. 관리자나 초대해 준 사람이 그 주소를 알려줍니다.

  1. 웹 브라우저에서 주소를 열거나, 데스크톱 또는 모바일 앱에 추가하세요(참고: 데스크톱 및 모바일 앱).
  2. 계정에 로그인에서 이메일 주소 또는 사용자 이름과 비밀번호를 입력한 후 이 곳을 클릭해서 로그인하세요.를 클릭합니다. 조직이 자체 로그인 시스템을 사용하는 경우, "또는 다음으로 로그인" 아래에 있는 해당 버튼을 대신 클릭합니다.
  3. 다중 인증을 활성화한 경우, 인증 앱에서 제공된 코드를 입력합니다.

초대 링크를 받은 경우, 링크를 열어 계정을 만듭니다: 계정 만들기에 이메일 주소, 사용자 이름, 비밀번호를 입력한 후 계정 만들기를 클릭합니다. 비밀번호를 잊어버린 경우 비밀번호를 잊어버리셨나요?를 클릭하고 이메일 주소를 입력하면 새 비밀번호를 설정할 수 있는 링크가 전송됩니다.

일부 커뮤니티는 새로운 멤버를 몇 가지 질문으로 맞이하며, 이 질문에 대한 답변을 통해 적절한 역할과 채널에 접근할 수 있는 권한이 부여됩니다. 질문에 답하거나 건너뛰기를 클릭할 수 있습니다.

창

Antimatter 창은 왼쪽에서 오른쪽으로 5개의 열로 구성되어 있습니다.

  1. 가장 왼쪽의 커뮤니티 레일: 소속된 각 커뮤니티마다 하나의 원형 아이콘이 표시됩니다. 점은 읽지 않은 메시지를, 숫자는 멘션 수를 나타냅니다. 아이콘 아래에 있는 팀 추가(+)를 통해 커뮤니티에 참여하거나 새로 만들 수 있습니다. 하단에는 모든 다이렉트 메시지(채팅 버블)가 있으며, 여기에 멘션, 팔로우 중인 글타래, 저장된 메시지, 임시 저장 글, 나 자신에게 보낸 메모가 표시됩니다. 읽지 않은 대화가 열린 대화에 모두 표시되지 않으면, 해당 대화의 프로필 사진과 읽지 않은 수가 버블 아래에 대기합니다. 마지막으로 전체 검색(확대경)가 있습니다.
  2. 사이드바: 현재 커뮤니티 이름(클릭 시 메뉴가 열림)과 카테고리별로 그룹화된 채널이 표시됩니다. 하단에는 열린 대화에 최근 다이렉트 메시지가 목록으로 표시되며, 기본적으로 최대 10개까지 표시됩니다. 읽지 않은 대화는 프로필 사진 주위에 빨간색 링이 표시되고, 작은 회색 숫자로 읽지 않은 수가 표시됩니다.
  3. 대화: 열려 있는 채널 또는 대화의 메시지와 하단 메시지 입력 상자가 표시됩니다. 헤더에는 이름(클릭 시 채널 정보 열기), 짧은 헤더 텍스트, 검색 상자, 통화, 멘션, 저장된 메시지, 고정된 메시지, 파일 보기, 멤버 목록 보기 버튼이 있습니다.
  4. 오른쪽 패널: 채널 멤버, 또는 열렸을 때 글타래, 검색 결과, 앱이 표시됩니다. Esc 키를 눌러 패널을 닫을 수 있습니다.
  5. 가장 오른쪽 끝의 앱 레일: 상단에 있는 프로필 사진(클릭 시 상태 및 설정 열기), 앱 아이콘, 하단에 있는 Antimatter 정보 메뉴가 있습니다.

통화 중에는 사이드바 하단에 통화 도크가 표시되며, 음소거, 화면 공유, 나가기 버튼이 있습니다. 통화 도크를 참고하세요.

작은 화면에서

좁은 창이나 휴대폰 브라우저에서는 사이드바가 드로어로 표시됩니다. 왼쪽 상단의 내비게이션 열기를 탭하거나 오른쪽으로 스와이프하면 커뮤니티와 채널을 볼 수 있습니다. 왼쪽으로 스와이프하면 멤버 목록과 앱을 볼 수 있습니다. 메시지를 길게 누르면 해당 메시지의 메뉴가 열립니다.

시작하기

  1. 프로필 설정: 사진을 추가하고 이름을 확인하여 사람들이 자신을 알아볼 수 있도록 하세요. 프로필 편집을 참고하세요.
  2. 브라우저가 요청할 때 알림 허용을 설정하여 누군가 자신을 필요로 할 때 알 수 있도록 하세요. 알림을 참고하세요.
  3. 관심 있는 채널에 참여하세요: 커뮤니티 메뉴(커뮤니티 이름을 클릭)를 열고 채널 탐색을 선택합니다. 채널 찾기 및 참여를 참고하세요.
  4. 인사하기: 채널을 클릭하고 하단 메시지 입력란에 내용을 입력한 뒤 Enter 키를 누릅니다.
  5. 특정 사람에게 직접 메시지 보내기: 해당 사용자의 이름을 클릭한 뒤 메시지를 선택합니다.

어디든 빠르게 이동하려면 Ctrl+K(Mac의 경우 ⌘+K)를 누르고 채널, 사람 또는 메시지의 일부 문자를 입력하세요.

도움 요청

앱 레일 하단의 Antimatter 로고를 클릭하면 Antimatter 정보가 열립니다. 도움말 아래에:

  • 사용자 가이드는 메시징, 전송, 서식, 멘션, 파일 및 명령에 대한 Antimatter의 내장 도움말을 엽니다.
  • 키보드 단축키는 모든 단축키를 나열합니다.
  • 서식 도움말은 메시지 서식 설정 방법을 설명합니다.
  • 관리자가 설정한 경우, 문제 보고하기를 통해 문제를 알려줍니다.

웹 브라우저에서는 동일한 메뉴에서 앱 다운로드도 사용할 수 있으며, 서버의 데스크톱 및 모바일 앱을 다운로드할 수 있는 페이지가 열립니다. 앱에 전용 페이지가 있는 경우, 메뉴의 제품 아래에 나열됩니다. 메시지 입력란의 서식 막대にある ? 버튼도 도움말을 엽니다. 계정 또는 서버에 관한 사항은 관리자에게 문의하세요.

데스크톱 및 모바일 앱

Antimatter는 최신 웹 브라우저에서 사용할 수 있습니다. 컴퓨터와 휴대폰용 앱도 있습니다.

앱은 GitHub에 게시되어 있습니다: 데스크톱 앱은 릴리스 페이지에, 모바일 앱은 릴리스 페이지에 있습니다. 앱 다운로드는 Antimatter 정보 메뉴에서 관리자님이 선택한 다운로드 페이지로 이동하며, 기본적으로는 릴리스 페이지입니다.

데스크톱 앱과 모바일 앱의 첫 릴리스인 버전 0.9.0이 준비 중입니다. 게시될 때까지는 웹 브라우저, 특히 스마트폰에서도 Antimatter를 사용하세요.

데스크톱 앱

데스크톱 앱은 Windows, macOS, Linux에서 실행됩니다. 브라우저와 동일한 창을 표시하며, 몇 가지 기능을 추가합니다: 브라우저에 요청하지 않고도 받을 수 있는 알림, 아이콘에 표시되는 읽지 않은 배지, 커뮤니티 레일 상단의 돌아가기 및 전달하기 버튼, 통화 시 자체 화면 공유 선택기, 그리고 하나의 앱에서 여러 서버를 사용할 수 있는 기능입니다.

설치하려면 릴리스 페이지에서 시스템에 맞는 파일을 다운로드하세요: Windows에서는 .exe 설치 파일, Mac에서는 .dmg 디스크 이미지, Linux에서는 .deb 또는 .rpm 패키지, 또는 .AppImage입니다. 앱이 아직 서명되지 않아 시스템이 처음 실행할 때 경고합니다:

  • Windows에서는 SmartScreen이 알려지지 않은 게시자에 대해 경고합니다: 자세한 정보를 선택한 후 그대로 실행을 선택하세요.
  • macOS 15 이상에서는 앱을 한 번 열려고 한 후 시스템 설정 › 개인정보 보호 및 보안으로 이동하여 Antimatter 관련 메시지 옆의 그대로 열기를 클릭하세요. 이전 버전에서는 앱을 Control-클릭하여 열기를 선택하세요.

이제 서버에 연결하세요:

  1. 앱을 시작합니다. 환영 화면이 지나면 시작하기를 클릭하세요.
  2. 서버에 연결에서 관리자님이 제공한 서버 URL을 입력하고, 원하는 서버 표시 이름을 입력한 후 연결을 클릭하세요.
  3. 브라우저에서와 마찬가지로 로그인하세요.

다른 서버를 추가하려면 창 상단의 서버 메뉴에서 서버 추가를 선택하거나, 앱의 설정에서 서버 섹션에서 선택하세요. 앱의 설정 창(Windows와 Linux에서는 Ctrl+,, Mac에서는 환경설정…)에서는 로그인 시 자동 시작 여부, 파일 다운로드 위치, 철자 검사기 언어, 알림 설정도 할 수 있습니다.

모바일 앱

모바일 앱은 Android 11 이상, iOS 18 이상에서 실행됩니다. Android에서는 릴리스 페이지에서 .apk 파일을 다운로드하여 열면, 처음에 브라우저에서 앱 설치를 허용하라는 메시지가 표시됩니다. 릴리스 페이지의 iPhone 빌드는 서명이 되지 않아 그대로 설치할 수 없습니다. 조직에서 먼저 서명해야 합니다. 앱 설치 방법을 관리자에게 문의하세요.

  1. 앱을 열고 환영 화면을 차례대로 탭하세요.
  2. 서버 연결에서 서버 URL 입력에 서버 주소를 입력하고, 표시명을 선택한 뒤 연결을 탭하세요.
  3. 이메일 또는 사용자 이름과 비밀번호, 또는 조직의 로그인 시스템으로 로그인하세요.

모바일 앱은 자체적인 디자인을 갖추고 있습니다. 하단 탭을 통해 홈, 검색, 멘션, 저장됨 메시지와 계정으로 이동할 수 있으며, 계정에서 상태를 설정하고 앱 설정을 찾을 수 있습니다. 메시지, 글타래, 채널, 통화 및 음성 채널, 투표, GIF와 스티커를 지원합니다. 웹 앱의 일부 기능은 아직 포함되지 않았는데, 여기에는 통화 중 카메라, 메모와 화이트보드 편집, Kanban, Calendar, Mail이 있습니다. 휴대폰의 푸시 알림은 관리자가 서버에서 설정해 두어야 합니다.
