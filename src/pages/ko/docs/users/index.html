이 가이드의 내용

Antimatter는 팀이나 커뮤니티와 대화하는 공간입니다: 채널, 개인 대화, 통화, 그리고 공유 메모와 화이트보드 같은 앱. 이 가이드의 각 페이지는 단계별로 각 작업을 수행하는 방법을 설명합니다:

  • 메시지 작성: 서식, 멘션, 이모지, 답글과 글타래, 편집, 임시 저장, 예약 등.
  • 커뮤니티와 채널: 참여, 사이드바 정리, 다이렉트 메시지와 그룹 메시지.
  • 통화와 음성 채널: 대화, 화면 공유, 실시간 자막.
  • 앱: 메모, 화이트보드, 칸반 보드, 캘린더, 메일, 투표, 할 일 목록 등.
  • AI 에이전트: 서버에 해당 기능이 활성화된 경우, 요약, 재작성 및 질문.
  • 알림과 상태: 어떤 알림이 언제 전달되는지.
  • 프로필과 개인정보: 프로필, 누구에게 메시지를 받을 수 있는지, 차단, 그리고 계정 보안.
  • 검색과 찾기: 검색, 멘션, 저장된 메시지와 읽지 않은 메시지.
  • 설정과 단축키: 테마, 언어 및 키보드 단축키.

각 Antimatter 서버는 자체 관리자가 운영하며, 활성화할 기능과 앱을 선택합니다. 이 가이드에 있는 기능이 표시되지 않는 경우, 아마도 해당 서버에서 활성화되지 않은 것입니다: 관리자에게 문의하세요.

로그인

Antimatter에는 중앙 웹사이트가 없습니다: 각 조직이나 커뮤니티는 chat.example.com과 같은 고유 주소를 가진 자체 서버를 운영합니다. 관리자나 초대해 준 사람이 그 주소를 알려줍니다.

  1. 웹 브라우저에서 주소를 열거나, 데스크톱 또는 모바일 앱에 추가하세요 (데스크톱 및 모바일 앱 참고).
  2. 계정에 로그인 화면에서 이메일 주소 또는 사용자 이름과 비밀번호를 입력한 후 이 곳을 클릭해서 로그인하세요.를 클릭합니다. 조직이 자체 로그인 시스템을 사용하는 경우, "또는 다음으로 로그인" 아래에 있는 해당 버튼을 클릭합니다.
  3. 다중 인증을 활성화한 경우, 인증 앱에서 제공된 코드를 입력합니다.

초대 링크를 받은 경우, 링크를 열어 계정을 만듭니다: 계정 만들기에 이메일 주소, 사용자 이름, 비밀번호를 입력한 후 계정 만들기를 클릭합니다. 비밀번호를 잊어버린 경우, 비밀번호를 잊어버리셨나요?를 클릭하고 이메일 주소를 입력하면 새 비밀번호를 설정할 수 있는 링크를 받게 됩니다.

일부 커뮤니티는 신규 참여자를 위해 몇 가지 질문을 준비해 두며, 이 질문에 답하면 적절한 역할과 채널에 접근할 수 있습니다. 질문에 답하거나 건너뛰기를 클릭할 수 있습니다.

창

Antimatter 창은 왼쪽에서 오른쪽으로 다섯 개의 열로 구성되어 있습니다.

  1. 가장 왼쪽에 있는 커뮤니티 레일: 소속된 각 커뮤니티마다 하나의 원형 아이콘이 표시됩니다. 점은 읽지 않은 메시지를, 숫자는 멘션 수를 나타냅니다. 아이콘 아래에 있는 팀 추가(+)를 통해 커뮤니티에 참여하거나 새로 만들 수 있습니다. 하단에는 새 다이렉트 메시지를 보낸 사람의 사진과 전체 검색(돋보기)가 있습니다.
  2. 사이드바: 현재 커뮤니티 이름(클릭하면 메뉴가 열림)과 카테고리별로 그룹화된 채널이 표시됩니다. 하단에는 열린 대화에 최근 다이렉트 메시지가 나열되며, 그 옆의 말풍선(모든 다이렉트 메시지)을 클릭하면 멘션, 팔로우 중인 글타래, 저장된 메시지, 임시 저장 글, 나 자신에게 보낸 메모를 모두 볼 수 있습니다.
  3. 대화: 열은 채널 또는 대화의 메시지와 하단 메시지 입력 상자가 표시됩니다. 헤더에는 이름(클릭하면 채널 정보 열림), 짧은 헤더 텍스트, 검색 상자와 통화, 멘션, 저장 및 고정된 메시지, 파일, 멤버 목록 보기 버튼이 있습니다.
  4. 오른쪽 패널: 채널의 멤버, 또는 열면 글타래, 검색 결과, 앱이 표시됩니다. Esc를 눌러 패널을 닫을 수 있습니다.
  5. 가장 오른쪽에 있는 앱 레일: 상단에 있는 내 프로필 사진(클릭하면 상태 및 설정 열림), 앱 아이콘, 하단에 있는 Antimatter 정보 메뉴가 있습니다.

통화 중에는 사이드바 하단에 통화 도크가 표시되며, 음소거, 화면 공유, 나가기 버튼이 있습니다. 통화 도크를 참고하세요.

작은 화면에서

좁은 창이나 휴대폰 브라우저에서는 사이드바가 드로어로 표시됩니다. 왼쪽 상단의 내비게이션 열기를 탭하거나 오른쪽으로 스와이프하면 커뮤니티와 채널을 볼 수 있습니다. 왼쪽으로 스와이프하면 멤버 목록과 앱이 표시됩니다. 메시지를 길게 누르면 해당 메뉴가 열립니다.

시작하기

  1. 프로필 설정: 사진을 추가하고 이름을 확인하여 사람들이 자신을 알아볼 수 있도록 하세요. 프로필 편집을 참고하세요.
  2. 브라우저가 요청할 때 알림 허용을 설정하여 누군가 자신을 필요로 할 때 알 수 있도록 하세요. 알림을 참고하세요.
  3. 관심 있는 채널에 참여하세요: 커뮤니티 메뉴(커뮤니티 이름을 클릭)를 열고 채널 탐색을 선택합니다. 채널 찾기 및 참여를 참고하세요.
  4. 인사하기: 채널을 클릭하고 하단 메시지 입력란에 내용을 입력한 후 Enter를 누릅니다.
  5. 특정인에게 직접 메시지 보내기: 해당 사용자의 이름을 클릭한 후 메시지를 선택합니다.

어디로든 빠르게 이동하려면 Ctrl+K(Mac의 경우 ⌘+K)를 누르고 채널, 사용자 또는 메시지의 일부 문자를 입력하세요.

도움 요청

앱 레일 하단의 Antimatter 로고를 클릭하여 Antimatter 정보를 엽니다. 도움말 아래에:

  • 사용자 가이드는 메시징, 전송, 서식, 멘션, 파일 및 명령에 대한 Antimatter의 내장 도움말을 엽니다.
  • 키보드 단축키는 모든 단축키를 나열합니다.
  • 서식 도움말은 메시지 서식 설정 방법을 설명합니다.
  • 관리자가 설정한 경우, 문제 보고하기를 통해 문제를 관리자에게 알릴 수 있습니다.

동일한 메뉴에는 Kanban, Playbooks와 같이 전체 페이지로 열리는 제품이 나열됩니다. 메시지 입력란의 서식 막대にある ? 버튼도 도움말을 엽니다. 계정 또는 서버와 관련된 사항은 관리자에게 문의하세요.

데스크톱 및 모바일 앱

Antimatter는 최신 웹 브라우저에서 사용할 수 있습니다. 컴퓨터와 휴대폰용 앱도 있습니다.

데스크톱 및 모바일 앱의 초기 버전이 준비 중입니다. 공개될 때까지는 휴대폰을 포함한 웹 브라우저에서 Antimatter를 사용하세요.

데스크톱 앱

데스크톱 앱은 Windows, macOS, Linux에서 실행됩니다. 브라우저와 동일한 창을 표시하며, 브라우저에 요청하지 않고 알림을 보내고, 아이콘에 읽지 않은 배지를 표시하며, 커뮤니티 레일 상단에 돌아가기와 전달하기 버튼을 추가하고, 통화에서 자체 화면 공유 선택기를 제공하며, 하나의 앱에서 여러 서버를 사용할 수 있습니다.

  1. 앱을 시작합니다. 환영 화면이 지나면 시작하기를 클릭합니다.
  2. 서버 연결에서 관리자가 제공한 서버 URL을 입력하고, 원하는 서버 표시명을 지정한 후 연결을 클릭합니다.
  3. 브라우저에서와 동일하게 로그인합니다.

다른 서버를 추가하려면, 창 상단의 서버 메뉴에서 서버 추가를 선택하거나, 앱의 설정에서 서버 섹션을 사용합니다. 앱의 설정 창(Windows와 Linux에서는 Ctrl+,, Mac에서는 환경설정…)에서는 로그인 시 시작 여부, 파일 다운로드 위치, 철자 검사 언어, 알림 설정을 할 수 있습니다.

모바일 앱

모바일 앱은 Android 11 이상, iOS 18 이상에서 실행됩니다.

  1. 앱을 열고 환영 화면을 탭하여 진행합니다.
  2. 서버 연결에서 서버 URL 입력에 서버 주소를 입력하고, 표시명을 선택한 후 연결을 탭합니다.
  3. 이메일 또는 사용자 이름과 비밀번호, 또는 조직의 로그인 시스템으로 로그인합니다.

모바일 앱은 자체 디자인을 갖추고 있습니다. 하단 탭을 통해 홈, 검색, 멘션, 저장됨 메시지와 계정으로 이동할 수 있으며, 계정에서 상태를 설정하고 앱 설정을 찾을 수 있습니다. 메시지, 글타래, 채널, 통화, 음성 채널, 투표, GIF, 스티커를 지원합니다. 웹 앱의 일부 기능은 아직 포함되지 않았으며, 여기에는 통화 카메라, 메모와 화이트보드 편집, Kanban, 캘린더, 메일이 포함됩니다. 휴대폰의 푸시 알림은 관리자가 서버에서 설정해 두어야 합니다.
