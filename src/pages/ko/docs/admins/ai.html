"OpenAI 호환"이란 OpenAI와 동일한 HTTP API를 제공하는 서버를 의미합니다. 직접 실행할 수 있는 대부분의 모델 서버가 이를 지원합니다(예: Ollama, vLLM, llama.cpp 서버, 또는 Whisper 및 텍스트 음성 변환 서버). 많은 클라우드 제공업체도 이를 지원합니다. 이 기능들을 사용하려면 라이선스가 필요 없습니다.

AI 에이전트

Agents 앱(id mattermost-ai)은 기본적으로 켜져 있습니다. 설정은 두 단계로 이루어집니다: 서비스(모델 제공업체에 대한 연결)를 추가한 후, 에이전트(서비스를 사용하는 봇)를 생성합니다.

1. 서비스 추가

시스템 콘솔 › 플러그인 › 에이전트로 이동하여 AI 서비스 아래에서 AI 서비스 추가를 클릭합니다. 서비스 유형을 선택합니다:

  • OpenAI Compatible: 직접 실행하는 모델 서버 또는 OpenAI 스타일 API를 지원하는 모든 제공자. API URL(예: http://ollama:11434/v1 또는 http://vllm.internal:8000/v1)을 입력하고, 서버가 필요로 하는 경우에만 API 키를 입력합니다. 서버가 Chat Completions API만 지원하는 경우 Responses API 사용을 끕니다.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: 호스팅 제공자. 각각 API 키가 필요합니다(Bedrock: AWS 리전 및 자격 증명 또는 IAM 역할; Vertex AI: 프로젝트, 리전 및 서비스 계정; Azure: API URL도 필요).

이후 기본 모델(제공자가 모델을 보고할 수 있는 경우 목록, 그렇지 않은 경우 이름을 입력)을 설정하고, 제공자가 보고하지 않는 경우 입력 토큰 제한과 출력 토큰 제한을 설정합니다. 이 제공자가 실패할 때 대체 서비스가 대신 작동할 수 있습니다. 저장합니다.

서버가 이 요청을 직접 보내므로 API에 도달할 수 있어야 합니다: 같은 compose 프로젝트 내의 모델 서버, 네트워크 내의 서버, 또는 인터넷 내의 서버. 발신 요청은 HTTP_PROXY 및 HTTPS_PROXY 변수를 준수합니다.

2. 에이전트 생성

에이전트는 웹 앱의 에이전트 페이지에서 생성됩니다: 제품 메뉴에서 열거나, 에이전트 패널의 에이전트 선택기에서 관리를 통해 열 수 있습니다. 주소는 https://chat.example.com/plug/mattermost-ai/agents입니다. 각 에이전트에는 표시명, 에이전트 사용자 이름(사람들이 멘션하는 방식), 서비스가 있으며, 선택적으로 모델, 사용자 지정 지침, 비전 사용(이미지) 및 도구 사용 전환 스위치가 있습니다. 접근 탭에서는 사용할 수 있는 채널과 사용할 수 있는 사용자를 제한합니다. 시스템 콘솔의 AI 함수에서 기본 봇은 선택된 에이전트가 없을 때, 예를 들어 통화 요약에 사용할 에이전트를 선택합니다.

기본적으로 모든 사용자는 구성된 서비스로 자신의 에이전트를 생성할 수 있습니다. 이를 관리자로만 제한하려면 시스템 콘솔 › 사용자 관리 › 권한에서 멤버 역할에서 본인 AI 에이전트 관리 권한을 제거합니다.

에이전트 앱의 선택 기능

  • 임베딩 검색(실험적, 비활성): 메시지에 대한 의미론적 검색. pgvector 확장 기능이 있는 PostgreSQL과 임베딩 모델(OpenAI 또는 OpenAI 호환)이 필요합니다. 모든 메시지를, 비공개 채널과 다이렉트 메시지를 포함하여 임베딩 모델에 전송합니다.
  • 웹 검색(비활성): 에이전트가 Google, Brave 또는 사용자가 실행하는 SearXNG 서버를 통해 웹을 검색할 수 있게 합니다.
  • 네이티브 도구: 이를 제공하는 제공자의 경우, 에이전트는 제공자 자체의 웹 검색(지원되는 경우 새 에이전트에 대해 기본적으로 활성화), 웹 가져오기 및 코드 실행을 사용할 수 있습니다. 이들은 제공자에서 실행됩니다. 에이전트별로 비활성화할 수 있습니다.
  • Model Context Protocol (MCP): 신뢰하는 MCP 서버에 에이전트를 연결하여 추가 도구를 제공합니다.
  • Debug: Trace Output(끄기, 서버 로그 또는 OpenTelemetry 엔드포인트) 및 Enable Token Usage Logging(토큰 수를 logs/agents/token_usage.log에 기록).

음성 인식: 통화 녹취록 및 자막

OpenAI 호환 /v1/audio/transcriptions 엔드포인트를 제공하는 음성 인식 서버를 사용하여 통화를 녹취하고 실시간 자막을 사용할 수 있습니다. 설정 방법은 통화와 음성 문서에서 확인할 수 있습니다. 녹취록 요약이 켜져 있으면 기본 에이전트가 각 녹취록의 요약을 게시합니다.

텍스트 음성 변환: 소리 내어 읽기

텍스트 음성 변환이 켜져 있으면 모든 메시지의 메뉴에 소리 내어 읽기가 있습니다: 서버는 메시지의 텍스트를 텍스트 음성 변환 API로 보내 오디오를 재생합니다. 설정은 시스템 콘솔 › 통합 › 텍스트 음성 변환에 있습니다:

설정키 및 변수입력 내용
메시지 읽어 주기TextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (기본값: 꺼짐)
API 기본 URLTextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URL/v1까지 포함하는 기본 URL, 예: http://tts.internal:8000/v1. 서버는 해당 /audio/speech 엔드포인트를 호출합니다.
모델TextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELAPI가 지정한 모델 이름, 예: tts-1. 필수 항목입니다.
음성TextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICE모델의 목소리 중 하나를 선택하거나, 기본값을 사용하려면 비워 둡니다.
API 키TextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYBearer 토큰으로 전송됩니다. API가 키를 요구하지 않으면 비워 둡니다.

전송 전 서버는 코드 블록, 링크, 이모지 코드 및 서식을 제거하고 최대 4000자만 유지합니다. MP3 오디오를 요청하며 마지막 64개의 결과를 메모리에 보관하므로, 두 번 읽은 메시지는 한 번만 전송됩니다.

자동 번역

자동 번역은 채널의 메시지를 각 독자의 언어로 표시합니다. 시스템 콘솔 › 사이트 구성 › 지역화의 자동 번역 아래에서 구성합니다:

설정키기본값
활성화AutoTranslationSettings.Enable꺼짐
번역 제공자AutoTranslationSettings.Providerlibretranslate, openai ("OpenAI 호환 API"로 표시) 또는 agents (에이전트 앱의 서비스)
허용된 언어AutoTranslationSettings.TargetLanguagesen: 메시지가 번역될 수 있는 언어
번역 시간 초과(ms)AutoTranslationSettings.TimeoutMs5000
다이렉트 메시지와 그룹 메시지의 자동 번역 제한AutoTranslationSettings.RestrictDMAndGM꺼짐

각 제공자는 고유한 필드를 가집니다:

  • LibreTranslate: LibreTranslate API 엔드포인트 및 LibreTranslate API 키 (AutoTranslationSettings.LibreTranslate.URL, .APIKey). LibreTranslate 서버는 자체 네트워크에서 실행할 수 있습니다.
  • OpenAI 호환 API: API 기본 URL (/v1까지 포함; 서버는 채팅 완성 엔드포인트를 사용), 모델 및 API 키 (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). 로컬에서 실행되는 소형 번역 모델이 잘 작동합니다.
  • 에이전트: 에이전트 앱에서 설정된 서비스 중 하나인 AI 서비스.

이 기능이 켜지면, 채널 관리자는 채널 설정(자동 번역)에서 해당 채널의 번역을 활성화할 수 있으며, 각 멤버는 채널 메뉴(메시지 번역)에서 번역을 비활성화할 수 있습니다. 다이렉트 메시지와 그룹 메시지에서는 모든 멤버가 번역을 켤 수 있지만, 해당 제한이 적용된 경우 번역을 사용할 수 없습니다. 번역된 메시지는 원본으로 연결되는 링크와 함께 "…(어)에서 번역됨"이라는 표시가 나타납니다.

텍스트가 전송되기 전에 코드, 링크, 멘션, 이모지는 플레이스홀더로 대체되고, 전송 후 원래대로 복원됩니다.

기능전송되는 내용대상

모든 데이터를 네트워크 내에 유지하려면, 각 기능을 자체 서버를 가리키도록 설정하세요. 클라우드 제공자를 사용하는 경우, 데이터 보관 정책을 확인하고 어떤 기능이 사용자의 메시지를 외부로 전송하는지 사용자에게 알려야 합니다.

AI 기능 비활성화

단일 스위치는 없습니다. 각 기능마다 개별 설정이 있습니다.

  • 에이전트: 관리자 도구 › 플러그인 › 플러그인 관리에서 에이전트 앱을 비활성화합니다. 통화 요약과 에이전트 번역 제공자도 함께 제거됩니다.
  • 녹취 및 실시간 자막: AM_CALLS_ENABLE_TRANSCRIPTIONS=false 및 AM_CALLS_ENABLE_LIVE_CAPTIONS=false(기본값).
  • 소리 내어 읽기: 메시지 읽어 주기를 끕니다(AM_TEXTTOSPEECHSETTINGS_ENABLE=false, 기본값).
  • 번역: 자동 번역 끄기(AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, 기본값).

에이전트 앱을 비활성화한다고 해서 나머지 세 기능이 꺼지지는 않습니다. 이 기능들은 각각 자체 API를 직접 호출합니다.
