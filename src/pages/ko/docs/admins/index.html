배포 구성 요소

Antimatter는 Mattermost의 포크인 셀프호스팅 팀 채팅 서비스입니다. 완전한 배포는 다음 부분으로 구성됩니다. 첫 세 가지만 필수입니다.

구성 요소기능필수 여부
Antimatter 서버웹 앱, API 및 웹소켓을 포트 8065에서 제공하고, 번들 앱(플러그인)을 실행하며, 포트 8443에서 통화 미디어를 처리하는 단일 Go 프로그램(antimatter)입니다. 명령줄 도구 amctl로 관리됩니다.예
PostgreSQL데이터베이스: 메시지, 사용자, 커뮤니티 및 권장 설정에서 서버 구성을 저장합니다. 버전 15 이상을 사용해야 합니다.예
파일 저장소업로드된 파일, 이미지 및 설치된 앱: S3 호환 서비스(compose 파일은 RustFS를 실행) 또는 로컬 디렉터리입니다.예
리버스 프록시서버 앞의 HTTPS: compose 파일의 Caddy 프로필 또는 자체 nginx를 사용할 수 있습니다.프로덕션 환경용
GIF 서비스 (gifs-server)GIF 선택기에서 사용할 GIF와 스티커를 자체 카탈로그에서 제공합니다. Tenor API를 사용합니다.아니요
푸시 프록시Apple과 Google을 통해 모바일 앱으로 알림을 전달합니다.모바일 알림용
rtcd, TURN 서버많은 통화를 위한 독립 미디어 서버 및 엄격한 방화벽 뒤에 있는 사용자를 위한 릴레이입니다.아니요
AI 엔드포인트AI 에이전트, 통화 녹취록, 낭독 및 번역의 기반이 되는 모델: 클라우드 프로바이더 또는 자체 운영 서버입니다.아니요

Antimatter에는 라이선스나 유료 에디션이 없습니다: 단일 로그인, LDAP, 고가용성, 컴플라이언스 내보내기, 데이터 보존 및 Mattermost의 유료 플랜에 포함된 기타 모든 기능이 포함됩니다.

요구 사항

  • 수백 명의 사용자를 위해 CPU 코어 2개와 4GB 이상의 메모리가 있는 Linux 서버(amd64 또는 arm64) 및 사용자가 업로드하는 파일용 디스크 공간이 필요합니다.
  • 권장 설치를 위해 Compose 플러그인(docker compose)이 포함된 Docker Engine이 필요합니다.
  • 프로덕션 환경용: 서버를 가리키는 도메인 이름과 HTTPS를 위한 80 및 443 포트가 열려 있어야 합니다.
  • 통화용: 통화하는 사용자가 접근할 수 있는 8443 포트(UDP 및 TCP)가 열려 있어야 합니다.
  • 이메일용: Antimatter가 통해 보낼 수 있는 SMTP 서버가 필요합니다.

빠른 시작

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

이제 사이트 URL을 열고 계정을 생성하세요. 첫 번째 계정은 시스템 관리자가 됩니다. 설치에서는 각 단계와 다른 설치 방법을 설명합니다.

이 가이드에서

  • 설치: Docker Compose, 이미지, 릴리스 아카이브, 첫 번째 관리자.
  • 설정: 데이터베이스 또는 파일 설정, AM_ 환경 변수, 시스템 콘솔, amctl, 로그.
  • 도메인과 HTTPS: 사이트 URL, Caddy, nginx, 클라이언트 주소.
  • 통화와 음성: 포트, NAT, TURN, rtcd, 녹취록 및 실시간 자막.
  • 이메일 및 푸시: SMTP, 푸시 프록시 및 모바일 앱.
  • 기본 제공 앱: 활성화된 앱, 앱 설정, 다른 앱 설치.
  • AI: 에이전트, 음성 및 번역용 모델, 데이터 저장 위치.
  • 로그인 및 계정: 가입, 비밀번호, MFA, 단일 로그인, LDAP, 게스트, 세션.
  • 백업 및 업그레이드: 백업, 복원, 업그레이드, Mattermost에서 마이그레이션.
  • 운영: 모니터링, 확장, 데이터 보존, 규정 준수, 문제 해결.
  • 보안: 보안 강화 체크리스트 및 외부 연결.

서버가 아닌 커뮤니티를 운영하시나요(채널, 역할, 관리)? 커뮤니티 운영을 참고하세요. 통합 기능을 구축하시나요? Antimatter 기반 구축을 참고하세요.

첫 1시간

  1. 설치하고 즉시 관리자 계정을 생성하세요.
  2. 서버를 자체 도메인으로 HTTPS 뒤에 배치하세요.
  3. SMTP를 설정하고 테스트 이메일을 보내세요.
  4. 통화 포트를 열고 통화 앱의 테스트 모드를 끄세요.
  5. 누가 가입할 수 있는지 결정하고 MFA를 활성화하세요.
  6. 보안에서 외부 연결을 검토하세요.
  7. 일일 백업을 설정하세요.

도움 요청

커뮤니티 토론에서 질문을 하고, 커뮤니티 저장소에서 버그를 보고하세요. 보안 문제는 보안 정책에 설명된 대로 비공개로 보고해 주세요.
