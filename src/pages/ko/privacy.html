개인정보 처리방침

최종 업데이트: 2026년 10월 11일. 이 번역은 편의를 위해 제공되며, 영어 원문과 내용이 다를 경우 영어 원문이 우선합니다.

이 페이지는 두 가지를 다룹니다. 조직이 자체 서버에서 운영하는 Antimatter 소프트웨어와 이 웹사이트 antimatter.chat입니다.

Antimatter 소프트웨어

Antimatter는 자체 호스팅 소프트웨어입니다. Antimatter 서버를 사용할 때 어떤 데이터를 얼마 동안 보관하고 누가 접근할 수 있는지는 그 서버를 운영하는 조직이 결정합니다. Antimatter 프로젝트는 여러분의 서버, 계정, 메시지에 접근할 수 없습니다. 특정 서버에 있는 내 데이터에 관한 문의는 해당 서버의 관리자에게 하시기 바라며, 그 조직의 개인정보 처리방침이 적용됩니다.

소프트웨어가 스스로 하는 일은 다음과 같습니다.

  • 원격 측정 없음. 서버는 사용 통계, 진단 정보를 비롯한 어떤 데이터도 Antimatter 프로젝트나 제3자에게 보내지 않습니다.
  • 외부 연결은 관리자가 켠 기능에 한해, 관리자가 구성한 서비스로만 이루어집니다. 예를 들어 푸시 알림 서비스, 메시지에 올라온 웹사이트의 링크 미리보기, GIF 제공업체, 이메일 서버, 싱글 사인온용 ID 공급자, AI·음성·번역 모델 등이 있습니다.
  • AI 기능은 관리자가 선택한 모델을 사용합니다. 해당 모델을 제3자가 호스팅하는 경우, 모델에 보내는 데이터(다시 쓸 메시지, 요약할 대화, 녹취할 통화의 음성)는 그 제공업체로 전송됩니다. 관리자는 자체 호스팅 모델을 사용해 어떤 데이터도 네트워크 밖으로 나가지 않게 할 수 있습니다.

이 웹사이트

  • antimatter.chat은 GitHub Pages에서 호스팅하는 정적 웹사이트입니다.
  • 쿠키를 설정하지 않으며, 분석 도구, 추적 도구, 광고를 사용하지 않습니다. 글꼴과 이미지도 이 사이트에서 직접 제공하므로, 사이트를 보는 동안 브라우저가 다른 웹사이트에 요청을 보내지 않습니다.
  • 다른 웹 호스팅 업체와 마찬가지로 GitHub는 페이지를 제공하기 위해 여러분의 IP 주소와 요청한 페이지 정보를 받습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.
  • GitHub에서 이슈를 열거나 기여하면, 그곳에 올린 내용은 공개되며 GitHub의 자체 약관에 따라 처리됩니다.
