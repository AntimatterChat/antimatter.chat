마지막 업데이트: 2026년 10월 16일.

이 페이지는 두 가지를 다룹니다. 조직이 자체 서버에서 실행하는 Antimatter 소프트웨어와, 이 웹사이트인 antimatter.chat입니다.

Antimatter 소프트웨어

Antimatter는 셀프호스팅됩니다. Antimatter 서버를 사용할 때, 해당 서버를 운영하는 조직이 어떤 데이터를 얼마나 오래 보관할지, 그리고 누가 접근할 수 있는지 결정합니다. Antimatter 프로젝트는 사용자의 서버, 계정 또는 메시지에 접근할 수 없습니다. 특정 서버의 데이터에 대한 문의는 해당 서버의 관리자에게 하시기 바랍니다. 그 경우 해당 관리자의 개인정보 처리방침이 적용됩니다.

소프트웨어가 자체적으로 수행하는 작업:

  • 텔레메트리 없음. 서버는 Antimatter 프로젝트, Antimatter의 기반이 되는 소프트웨어를 만든 Mattermost, Inc. 또는 기타 제3자에게 사용 통계, 진단 정보 또는 기타 데이터를 전송하지 않습니다.
  • 관리자가 활성화한 기능에 한해 외부 연결이 설정된 서비스로만 이루어집니다. 예를 들어 푸시 알림 서비스, GIF 제공자, 이메일 서버, 단일 로그인용 ID 제공자, 또는 AI, 음성 또는 번역 모델 등이 있습니다.
  • 기본적으로 켜져 있으며 관리자가 끌 수 있는 두 가지 예외. 링크 미리보기: 누군가 링크를 게시하면 서버가 해당 페이지를 가져와 제목과 이미지를 표시합니다. 그리고 통화: 통화는 Cloudflare의 공개 STUN 서버(stun.cloudflare.com)를 사용하여 공용 네트워크 주소를 찾습니다. 서버는 Calls 앱이 시작될 때 이를 조회하며, 각 사용자의 기기는 통화에 참여할 때 이를 조회합니다. Cloudflare는 통화 자체를 볼 수 없으며, 서버와 각 참여자의 IP 주소와 포트만 확인합니다. 관리자는 대신 자체 STUN 서버를 사용하거나 아예 사용하지 않을 수 있습니다. 통화와 음성을 참고하세요.
  • AI 기능은 관리자가 선택한 모델을 사용합니다. 제3자가 호스팅하는 경우, 해당 제공자에게 전송되는 데이터(재작성할 메시지, 요약할 대화, 녹취된 통화의 오디오)는 해당 제공자에게 전송됩니다. 관리자는 네트워크 외부로 데이터가 나가지 않도록 셀프호스팅 모델을 사용할 수 있습니다.

이 웹사이트

  • antimatter.chat은 GitHub Pages에 호스팅되는 정적 웹사이트입니다.
  • 쿠키를 설정하지 않으며, 분석, 트래커 또는 광고를 사용하지 않습니다. 글꼴과 이미지는 사이트 자체에서 제공되므로, 읽는 동안 브라우저가 다른 웹사이트로 요청을 보내지 않습니다.
  • 기타 웹 호스트와 마찬가지로, GitHub는 페이지를 제공하기 위해 IP 주소와 요청한 페이지를 수신합니다. GitHub 개인정보 처리방침을 참고하세요.
  • GitHub에서 이슈를 열거나 기여하는 경우, 게시한 내용은 공개되며 GitHub의 자체 약관에 따라 처리됩니다.
