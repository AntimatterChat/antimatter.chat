نرم‌افزار Antimatter

Antimatter خودمیزبان است. وقتی از یک سرور Antimatter استفاده می‌کنید، سازمانی که آن را اجرا می‌کند تصمیم می‌گیرد چه داده‌هایی، تا چه مدت نگه داشته شوند و چه کسانی به آن‌ها دسترسی داشته باشند. پروژهٔ Antimatter هیچ دسترسی‌ای به سرور، حساب یا پیام‌های شما ندارد. برای پرسش دربارهٔ داده‌هایتان روی یک سرور مشخص، با مدیران آن تماس بگیرید؛ سیاست حریم خصوصی خود آن‌ها حاکم است.

آنچه نرم‌افزار به‌خودی‌خود انجام می‌دهد:

  • بدون تله‌متری. سرور هیچ آمار استفاده، داده‌های عیب‌یابی یا دادهٔ دیگری برای پروژهٔ Antimatter یا اشخاص ثالث نمی‌فرستد.
  • اتصال به بیرون فقط برای قابلیت‌هایی که مدیر فعال می‌کند، آن هم به سرویس‌هایی که خودش پیکربندی کرده است: برای نمونه یک سرویس اعلان push، پیش‌نمایش پیوند وب‌سایت‌هایی که در پیام‌ها ارسال می‌شوند، یک ارائه‌دهندهٔ گیف، یک سرور ایمیل، یک ارائه‌دهندهٔ هویت برای ورود یکپارچه، یا مدل‌های هوش مصنوعی، گفتار یا ترجمه.
  • قابلیت‌های هوش مصنوعی از مدل‌هایی استفاده می‌کنند که مدیر انتخاب می‌کند. وقتی این مدل‌ها را شخص ثالثی میزبانی می‌کند، آنچه برایشان فرستاده می‌شود (پیامی برای بازنویسی، گفتگویی برای خلاصه‌سازی، صدای تماسی برای متن‌نویسی) به همان ارائه‌دهنده می‌رسد. مدیران می‌توانند از مدل‌های خودمیزبان استفاده کنند تا هیچ‌چیز از شبکه‌شان خارج نشود.

این وب‌سایت

  • antimatter.chat یک وب‌سایت ایستا است که روی GitHub Pages میزبانی می‌شود.
  • هیچ کوکی‌ای تنظیم نمی‌کند و از هیچ ابزار تحلیل، ردیاب یا تبلیغاتی استفاده نمی‌کند. فونت‌ها و تصاویرش از خود سایت ارائه می‌شوند، بنابراین مرورگر شما هنگام خواندن آن هیچ درخواستی به وب‌سایت‌های دیگر نمی‌فرستد.
  • مانند هر میزبان وب دیگری، GitHub نشانی IP شما و صفحه‌هایی را که درخواست می‌کنید دریافت می‌کند تا آن‌ها را ارائه دهد. بیانیهٔ حریم خصوصی GitHub را ببینید.
  • اگر در GitHub یک issue باز کنید یا مشارکت کنید، آنچه آنجا منتشر می‌کنید عمومی است و GitHub طبق شرایط خودش با آن رفتار می‌کند.
