راه‌های گسترش Antimatter

سبک‌ترین ابزاری را انتخاب کنید که کار را انجام می‌دهد. چهار مورد اول به دسترسی به خود سرور نیاز ندارند؛ اپلیکیشن‌ها درون آن اجرا می‌شوند.

ابزارعملکردمناسب برای
REST APIهمه چیزهایی که اپلیکیشن‌ها انجام می‌دهند: پیام‌ها، کانال‌ها، افراد، فایل‌ها، تنظیمات. یک WebSocket رویدادها را به‌محض وقوع ارسال می‌کند.اسکریپت‌ها، همگام‌سازی با سیستم‌های دیگر، کلاینت‌های سفارشی.
Incoming webhooksیک URL مخفی که هنگام ارسال JSON از سمت یک منبع، پیامی را در یک کانال منتشر می‌کند.هشدارها، نتایج CI، پایش، اعلان‌ها از ابزارهای دیگر.
Outgoing webhooksAntimatter هنگامی که یک پیام در یک کانال عمومی با یک کلمه محرک شروع شود، URL شما را فراخوانی می‌کند و پاسخ شما را منتشر می‌کند.اتوماسیون‌های ساده مبتنی بر چت.
Slash commandsافراد /something را تایپ می‌کنند؛ Antimatter URL شما را فراخوانی می‌کند و پاسخ شما را برای آن‌ها یا برای کانال نمایش می‌دهد.جستجوهای سریع، اقداماتی که از چت آغاز می‌شوند.
Botsحساب‌هایی که برای برنامه‌ها ساخته می‌شوند و دارای توکن‌های مستقل، برچسب بات و پیام‌ها و دیالوگ‌های تعاملی هستند.دستیارها، اعلان‌دهنده‌ها، هر چیزی که با افراد گفتگو می‌کند.
Apps (plugins)کدی که درون سرور (Go) و در اپلیکیشن وب (React) اجرا می‌شود: هوک‌ها روی هر پیام، منوهای جدید، پنل‌ها، انواع پیام، صفحات.قابلیت‌ها: نظرسنجی‌ها، یادداشت‌ها، تقویم‌ها، یکپارچه‌سازی‌هایی که به رابط کاربری نیاز دارند.

در رابط کاربری، افراد افزونه‌ها را «اپلیکیشن» می‌نامند. این راهنما در جاهایی که هر دو کلمه مفید هستند، «اپلیکیشن‌ها (افزونه‌ها)» می‌گوید، زیرا کد، API و پیکربندی هنوز «افزونه» می‌گویند.

سازگاری با Mattermost

Antimatter یک فورک از Mattermost است. بیشتر چیزهایی که با سرور Mattermost کار می‌کنند، با Antimatter نیز کار می‌کنند.

چه چیزهایی یکسان است

  • REST API زیر /api/v4، احراز هویت، WebSocket و فرمت خطای آن. سرور نسخه 12.0.0 را گزارش می‌دهد، بنابراین کلاینت‌ها و اپلیکیشن‌هایی که نسخه سرور را بررسی می‌کنند، یک Mattermost جدید را می‌بینند.
  • وب‌هوک‌ها و دستورات اسلش، شامل داده‌های سازگار با اسلک.
  • API و هوک‌های پلاگین سرور: Antimatter آن‌ها را تغییر نداده است. کد سرور در مقابل همان ماژول Go، github.com/mattermost/mattermost/server/public، ساخته می‌شود.
  • رجیستری پلاگین وب‌اپ: هر روش register… از رجیستری Mattermost در هر دو رابط کاربری وب Antimatter وجود دارد.
  • کتابخانه‌های کلاینت: کلاینت Go با نام model.Client4 و کلاینت TypeScript با نام @mattermost/client (به کتابخانه‌های کلاینت مراجعه کنید).
  • باندل‌های پلاگین: یک فایل .tar.gz با مانیفست plugin.json. پلاگین‌هایی که با کلید Mattermost امضا شده‌اند نصب می‌شوند، همان‌طور که پلاگین‌های امضاشده با کلید Antimatter نیز نصب می‌شوند.

چه چیزهایی متفاوت است

  • دو رابط کاربری وب. رابط کاربری جدید، Fusion، پیش‌فرض است؛ رابط کاربری کلاسیک Mattermost همچنان در دسترس است. Fusion اکثر اجزای پلاگین‌ها را رندر می‌کند، اما برخی از آن‌ها را در جای دیگری قرار می‌دهد و چند مورد را حذف می‌کند. یک اپلیکیشن می‌تواند تشخیص دهد کدام رابط کاربری در حال اجراست. به پشتیبانی از رابط کاربری Fusion مراجعه کنید.
  • API اضافی. Antimatter نقاط پایانی (endpoints) برای ویژگی‌های خود را اضافه کرده است: ویژگی‌های جامعه، مهلت‌های زمانی، پیام‌های در بالا، درخواست‌های پیام، بازنویسی کانال و دسته، خروجی کانال، و فیلدهای جدید روی جوامع. به آنچه Antimatter به API اضافه می‌کند مراجعه کنید.
  • ویژگی‌های پیام اضافی. پیوست‌های پیام می‌توانند مراحل خط لوله (pipeline) و یک نمودار کوچک را نمایش دهند؛ پست‌ها می‌توانند پاسخ‌های درون‌خطی یا اسپویلر باشند.
  • هوک‌های وب‌اپ اضافی برای اپلیکیشن‌ها: یک آیتم در منو «+» کامپوزر، تب‌های انتخاب‌گر ایموجی، یک پنل در نمای کانال، یک فوتر زیر کانال‌های نوار کناری، و یک ورودی در صفحات یکپارچه‌سازی. به هوک‌هایی که فقط Antimatter دارد مراجعه کنید.
  • بدون لایسنس. هر ویژگی بدون کلید لایسنس در دسترس است. نقاط پایانی لایسنس، آزمایشی و ارتقای سازمانی حذف شده‌اند؛ GET /api/v4/license/client برای کلاینت‌هایی که درخواست می‌کنند باقی مانده است. برخی اپلیکیشن‌های ساخته‌شده برای نسخه‌های پولی Mattermost خودشان به دنبال لایسنس می‌گردند و از اجرا خودداری می‌کنند.
  • نام‌ها. تیم‌ها در رابط کاربری «جوامع» نامیده می‌شوند، اما API و کد همچنان از team استفاده می‌کنند. متغیرهای محیطی از پیشوند AM_ استفاده می‌کنند، ابزار خط فرمان amctl است و باینری سرور antimatter نام دارد.

کد کجا قرار دارد

همه‌چیز متن‌باز است و در سازمان AntimatterChat در GitHub قرار دارد. هر مخزن روی شاخه‌ی main خود کار می‌کند.

مخزنمحتوا
antimatterسرور (به زبان Go، در server/)، هر دو رابط کاربری وب (webapp/fusion و webapp/channels)، کلاینت TypeScript و amctl.
antimatter-dockerتصویرهای Docker همراه با برنامه‌های همراه و فایل‌های compose.
antimatter-plugin-*یک مخزن برای هر برنامه‌ی همراه: polls، todo، notes، whiteboard، calendar، mail، gifs، memes، voice-channels، calls، boards (Kanban)، playbooks، agents و metrics.
gifs-serverسرویس خودمیزبان GIF و استیکر که توسط برنامه‌ی GIFs استفاده می‌شود.
desktop-app، mobile-app، push-proxyبرنامه‌های دسکتاپ و موبایل، و سرویسی که اعلان‌های push را به تلفن‌ها منتقل می‌کند.
antimatter.chatاین وب‌سایت و مستندات آن.
communityمشکلات و بحث‌ها برای هر بخش از Antimatter.

قبل از شروع

  • یک سرور آزمایشی تهیه کنید. سریع‌ترین راه استفاده از تصویر Docker است؛ برای جزئیات به نصب Antimatter مراجعه کنید. اگر قصد کار روی خود Antimatter را دارید، به ساخت از سورس مراجعه کنید.
  • بررسی کنید که سرور چه چیزهایی را مجاز می‌شمارد. چندین قابلیت یکپارچه‌سازی به‌طور پیش‌فرض غیرفعال است و به یک مدیر سیستم نیاز دارد: توکن‌های دسترسی شخصی، حساب‌های ربات، تغییر نام کاربری و آیکون، و بارگذاری اپلیکیشن‌ها. در هر صفحه ذکر شده است که کدام تنظیمات لازم است.
  • آدرس سایت خود را بدانید. در مثال‌ها از https://chat.example.com استفاده شده است. آن را با آدرس سرور خود جایگزین کنید.

در این راهنما

  • API REST: احراز هویت، منابع اصلی، صفحه‌بندی، خطاها، محدودیت نرخ، WebSocket، کتابخانه‌های کلاینت و افزودنی‌های Antimatter.
  • وب‌هوک‌ها: وب‌هوک‌های ورودی و خروجی، داده‌های ارسال‌شده، پیوست‌ها و کارت‌ها.
  • دستورهای اسلش: دستورات سفارشی، درخواست و پاسخ آن‌ها، و تکمیل خودکار.
  • ربات‌ها و پیام‌های تعاملی: حساب‌های ربات، دکمه‌ها، منوها و دیالوگ‌ها.
  • نوشتن اپلیکیشن‌ها: ساختار افزونه، هوک‌های سرور، ثبت اپلیکیشن وب، Fusion، تنظیمات، ذخیره‌سازی، ترجمه‌ها و بسته‌بندی.
  • ساخت از سورس: سرور، رابط‌های کاربری وب، تصویر Docker و اپلیکیشن‌ها.
  • مشارکت: مشکلات (issues)، درخواست‌های کشش (pull requests)، سبک کدنویسی، ترجمه‌ها، امنیت و مجوزها.
پرسش‌ها در مباحثات جامعه خوش‌آمد هستند. برای گزارش باگ‌ها به مشکلات جامعه مراجعه کنید.
