Antimatter-ஐ விரிவுபடுத்தும் வழிகள்

வேலையைச் செய்யும் மிகக் குறைந்த கருவியைத் தேர்ந்தெடுக்கவும். முதல் நான்கு கருவிகளுக்கான சர்வரின் நேரடி அணுகல் தேவையில்லை; ஆப்ஸ் அதன் உள்ளே இயங்குகின்றன.

கருவிஇது என்ன செய்கிறதுஎதற்கு ஏற்றது
REST APIஆப்ஸ் செய்யும் எல்லாவற்றையும்: செய்திகள், சேனல்கள், மக்கள், கோப்புகள், அமைப்புகள். நிகழ்வுகள் நிகழும்போது அவற்றை அனுப்ப ஒரு WebSocket உள்ளது.ஸ்கிரிப்ட்கள், மற்ற அமைப்புகளுடன் ஒத்திசைவு, தனிப்பயன் கிளையண்டுகள்.
Incoming webhooksஏதாவது JSON அனுப்பும்போது ஒரு சேனலுக்கு செய்தியை அனுப்பும் ரகசிய URL.எச்சரிக்கைகள், CI முடிவுகள், கண்காணிப்பு, மற்ற கருவிகளிலிருந்து அறிவிப்புகள்.
Outgoing webhooksபொது சேனலில் ஒரு செய்தி உங்கள் டிரிகர் வார்த்தையுடன் தொடங்கும்போது, அல்லது யாராவது ஒரு செய்தியின் மெனுவில் உங்கள் செயலைத் தேர்ந்தெடுக்கும்போது, Antimatter உங்கள் URL-ஐ அழைத்து, உங்கள் பதிலைப் பதிவு செய்கிறது.செய்தி-அடிப்படையிலான எளிய தானியங்கி செயல்முறைகள், மற்றொரு கருவியுடன் செய்தியை அனுப்புவது.
Slash commandsமக்கள் /something எனப் பட்டை அழுத்தும்போது, Antimatter உங்கள் URL-ஐ அழைத்து, உங்கள் பதிலை அவர்களிடம் அல்லது சேனலில் காட்டுகிறது.தேடல்கள், சாட்டிலிருந்து தொடங்கும் செயல்கள்.
Botsபிரோகிராம்களுக்காக உருவாக்கப்படும் கணக்குகள்தான், அவுங்களுக்கு தனி டோக்கன்களும், பாட் டேகும், இன்டராக்டிவ் மெசேஜ்களும் டயலாக்களும் உண்டு.உதவியாளர்கள், அறிவிப்பாளர்கள், மக்களுடன் பேசும் எதையும்.
Apps (plugins)சர்வரில் (Go) மற்றும் வெப் ஆப்பில் (React) இயங்கும் குறியீடு: ஒவ்வொரு செய்திக்கும் ஹூக்ஸ், புதிய மென்கள், பேனல்கள், செய்தி வகைகள், பக்கங்கள்.சேவைகள்: கருத்துக் கணிப்புகள், குறிப்புகள், நாட்காட்டிகள், பயனர் இடைமுகத்தைத் தேவைப்படுத்தும் இணைப்புகள்.

இடைமுகத்தில், மக்கள் பிளக்-இன்களை "ஆப்ஸ்" என்று அழைக்கிறார்கள். குறியீடு, API மற்றும் அமைப்பு இன்னும் "பிளக்-இன்" என்று சொல்வதால், இரண்டு வார்த்தைகளும் உதவும் இடங்களில் இந்த வழிகாட்டி "ஆப்ஸ் (பிளக்-இன்கள்)" என்று சொல்கிறது.

Mattermost உடன் இணைவு

Antimatter என்பது Mattermost-இன் ஒரு ஃபோர்க். Mattermost சர்வருடன் வேலை செய்யும் பெரும்பாலானவை Antimatter-உடனும் வேலை செய்யும்.

எது ஒரே மாதிரியானது

  • REST API /api/v4 கீழே, அதன் அங்கீகாரம், அதன் WebSocket மற்றும் அதன் பிழை வடிவம். சர்வர் பதிப்பு 12.0.0 என்று அறிவிக்கிறது, எனவே சர்வர் பதிப்பைச் சரிபார்க்கும் கிளையண்டுகள் மற்றும் ஆப்ஸ் சமீபத்திய Mattermost-ஐக் காண்கின்றன.
  • வெப்க்குக்களும் ஸ்லாஷ் கட்டள்களும், அவற்றின் Slack-உடன் இணைப்படும் payloads உட்பட.
  • சர்வர் பிளக்-இன் API மற்றும் ஹூக்ஸ்: Antimatter அவற்றை அப்படியே வைத்திருக்கிறது. சர்வர் குறியீடு அதே Go மோடியுலுக்கு, github.com/mattermost/mattermost/server/public, எழுதப்படுகிறது. Antimatter அதன் AI சேவைக்காக (பார்க்க AI சேவை) மட்டும் முறைகளைச் சேர்க்கிறது.
  • வெப் அப் பிளகின்க் registry: Mattermost-ன் registry-ன் ஒவ்வொரு register… முறையும் Antimatter-ன் இரண்டு வெப் இடைமுகங்களிலும் உண்டு.
  • கிளையண்ட் நூலகங்கள்: Go கிளையண்ட் model.Client4 மற்றும் TypeScript கிளையண்ட் @mattermost/client (பார் கிளையண்ட் நூலகங்கள்).
  • பிளகின்க் பண்டல்கள்: plugin.json manifest உடனான .tar.gz. Mattermost-ன் key-உடன் கையொப்பம் சேர்க்கப்படும் பிளகின்களும், Antimatter-ன் key-உடன் கையொப்பம் சேர்க்கப்படும் பிளகின்களும் நிறுவப்படும்.

என்ன வித்தியாசம்

  • இரண்டு வெப் இடைமுகங்கள். புதிய இடைமுகம், Fusion, இயல்பாக உள்ளது; பழைய Mattermost இடைமுகம் இன்னும் கிடைக்கிறது. Fusion பெரும்பாலான பிளகின்க் கூறுகளை காட்டுகிறது, ஆனால் சிலவற்றை வேறு இடங்களில் வைக்கிறது, சிலவற்றை விட்டுவிடுகிறது. ஒரு அப் எந்த இடைமுகம் இயங்குகிறது என்பதை அறிய முடியும். பார் Fusion இடைமுகத்தை ஆதரிக்கல்.
  • கூடுதல் API. Antimatter அதன் சொந்த அம்சங்களுக்கான முனைகளைச் சேர்க்கிறது: சமூக பண்புகள், நேரம் முடிவு, மேல் செய்திகள், செய்தி கோரிக்கைகள், சேனல் மற்றும் வகை மாற்றங்கள், சேனல் ஏற்றுமதி, த்ரெட்களை நகர்த்துதல், மாதிரி இணைப்புகள், செய்தி செயல்கள், மற்றும் சமூகங்களில் புதிய புலங்கள். Antimatter API-க்கு சேர்க்கும் விஷயங்கள் பார்க்கவும்.
  • கூடுதல் செய்தி அம்சங்கள். செய்தி attachments pipeline stages-களை ஒரு சிறிய chart-உடன் காட்ட முடியும்; posts inline replies அல்லது spoilers ஆக இருக்க முடியும்.
  • பிரிவுகளுக்கு கூடுதல் வெப் ஆப் ஹூக்ஸ்: ஒரு கம்போசர் "+" மெனு உருப்படிகள், எமோஜி தேர்வி மடக்குகள், சேனல் காட்சியில் ஒரு பலகை, பகக்கவாட்ட்டுப் பட்டை சேனல்களின் கீழ் ஒரு காலடி, இணைப்புகள் பக்கங்களில் ஒரு உருப்படிகள், எமோஜி தேர்வியின் சேர் மற்றும் நிர்வகி காட்சிகள், மற்றும் புதிய ஜன்னலில் அதன் இடத்தில் மீண்டும் திறக்கும் பக்க பலகை. Antimatter மட்டும் கொண்ட ஹூக்ஸ் பார்க்கவும்.
  • உரிமங்கள் இல்லை. உரிம key-இன்றே ஒவ்வொரு அம்சமும் கிடைக்கிறது. உரிமம், trial மற்றும் enterprise upgrade endpoints அகற்றப்படும்; கேட்கும் கிளையண்டுகளுக்காக GET /api/v4/license/client மட்டும் உள்ளது. Mattermost-ன் பணம் செலுத்தும் பதிப்புகளுக்காக உருவாக்கப்படும் சில அப்-கள் உரிமத்தை தங்களுக்குத்தங்களுக்கு சரிபார்த்து இயங்க மறுக்கின்றன.
  • பெயர்கள். இடைமுகத்தில் Teams என்பது communities என்று அழைக்கப்படும், ஆனால் API மற்றும் கோட் இன்னும் team என்று சொல்கிறது. Environment variables AM_ prefix-ஐ பயன்படுத்துகின்றன, command-line tool amctl ஆகவும், server binary antimatter ஆகவும் உள்ளன.

கோட் எங்கே உள்ளது

எல்லாம் திறந்த மூலம், GitHub-ல் AntimatterChat நிறுவனத்தில் உள்ளது. ஒவ்வொரு சேமிப்பகமும் அதன் main கிளை-யில் இயங்குகிறது.

desktop-app, mobile-app, push-proxyடெஸ்க்டாப் மற்றும் மொபைல் செயல்கள், மற்றும் தொலைபேசிகளுக்கு தள்ளு அறிவிப்புகளை அனுப்பும் சேவை.

தொடங்கும் முன்

  • ஒரு சோதனை சர்வரை பெறுங்கள். மிக வேகமான வழி Docker இமேஜ்: Antimatter நிறுவல் பார். Antimatter-ஐ நேரடியாக வேலை செய்ய, மூலத்திலிருந்து உருவாக்கல் பார்.
  • சர்வரை என்ன அனுமதிக்கிறது என்பதை சரிபார்க்கவும். பல ஒருங்கிணைப்பு அம்சங்கள் இயல்பாக அணைக்கப்பட்டுள்ளன மற்றும் சிஸ்டம் நிர்வாகியைத் தேவைப்படுகின்றன: தனிப்பட்ட அணுகல் டோக்கன்கள், பாட் கணக்குகள், பயனர் பெயர் மற்றும் ஐகான் மாற்றங்கள், மற்றும் ஆப் பதிவேற்றம். ஒவ்வொரு பக்கமும் எந்த அமைப்பு தேவை என்பதைக் குறிப்பிடுகிறது.
  • உங்கள் தள URL-ஐ அறிந்து கொள்ளுங்கள். எடுத்துக்காட்டுகள் https://chat.example.com ஐப் பயன்படுத்துகின்றன. அதை உங்கள் சர்வரின் முகவரியுடன் மாற்றவும்.

  • REST API: அங்கீகாரம், முக்கிய மூலங்கள், பக்கப்படுத்தல், பிழைகள், விகித வரம்புகள், WebSocket, கிளையண்ட் நூலகங்கள், மற்றும் Antimatter-இன் சேர்க்கைகள்.
  • Webhooks: வரும் மற்றும் செல்லும் webhooks, payloads, இணைப்புகள் மற்றும் அட்டைகள்.
  • Slash commands: தனிப்பயன் கட்டளைகள், அவற்றின் கோரிக்கை மற்றும் பதில், தானியங்கி நிரப்புதல்.
  • Bots and interactive messages: பாட் கணக்குகள், பொத்தான்கள், மென்கள் மற்றும் டயலாக்கள்.
  • Writing apps: பிளக்-இன் அமைப்பு, சர்வர் ஹூக்க்கள், வெப் ஆப் பதிவேற்றப் பட்டியல், Fusion, அமைப்புகள், சேமிப்பு, மொழிபெயர்ப்புகள் மற்றும் பேக்கேஜிங்.
  • Building from source: சர்வர், வெப் இடைமுகங்கள், Docker இமேஜ் மற்றும் ஆப்ஸ்.
  • Contributing: பிரச்சனைகள், pull requests, பாணி, மொழிபெயர்ப்புகள், பாதுகாப்பு மற்றும் உரிமங்கள்.
கேள்விகள் சமூக விவாதங்களில் வரவேற்கப்படுகின்றன. பிழைகளை சமூக பிரச்சனைகளில் அறிவிக்கவும்.
