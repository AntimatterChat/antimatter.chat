உள்ளடக்கப்பட்ட செயலிகள்

செயலிகள் அமைப்பு கன்சோலில் பிளக்-இன்கள் எனப் பட்டியலிடப்படுகின்றன. அவை படத்தில் (/antimatter/prepackaged_plugins இல்) உள்ளன, Antimatter செயலி கையொப்ப விசையால் கையொப்பம் செய்யப்பட்டுள்ளன, எனவே இணைப்பில் இல்லாமலும் நிறுவ முடிகிறது.

வெளியீட்டு காப்பகமும் .deb மற்றும் .rpm தொகுப்புகளும் குறைவான ஆப்களை உள்ளடக்கியுள்ளன: தொகுப்புகளிலும் காப்பகத்திலும் உள்ள ஆப்கள் எனும் பகுதியைப் பார்க்கவும்.

இயல்பாக இயங்கும் செயலிகள், இன்னும் நிறுவப்படவில்லை என்றால் ஒவ்வொரு தொடக்கத்திலும் நிறுவப்படும், அல்லது படத்தில் புதிய பதிப்பு இருந்தால் புதுப்பிக்கப்படும். நீங்கள் ஒன்றை நிறுத்தினால், அது நிறுத்தப்பட்ட நிலையிலேயே இருக்கும்: இயல்பு நிலை, அமைப்பு இன்னும் குறிப்பிடாத செயலிகளுக்கு மட்டுமே பொருந்தும். Mattermost id ஐ வைத்திருக்கும் செயலிகள் (ஏஜெண்டுகள், அழைப்புகள், Kanban, பிளேபுக்குகள் மற்றும் ஒருங்கிணைப்புகள்) Antimatter இன் சொந்த உருவாக்கங்கள் ஆகும்.

செயலிகளை இயக்கு, நிறுத்து மற்றும் அமை

அமைப்பு கன்சோல் › பிளக்-இன்கள் › பிளகின் மேலாண்மை செல்லு. பதிவான பாட்கள் கீழ், ஒவ்வொரு ஆப்பும் இயக்கு அல்லது முடக்கு, அமைப்புகள் மற்றும் அகற்று ஆகியவற்றைக் கொண்டுள்ளது, மேலும் அதன் நிலையை (Running, Not running, Failed to start...) காட்டுகிறது. அமைப்புகளைக் கொண்ட ஒவ்வொரு ஆப்பும் அமைப்பு கன்சோல் › பிளக்-இன்கள் கீழ் தனியான பக்கத்தைக் கொண்டுள்ளது.

இயல்பாக அணைக்கப்பட்டிருக்கும் (off) இணைக்கப்பட்ட ஆப்கள், ஐமேஜின் சொந்த நகலிலிருந்து நிறுவப்படுகின்றன: ஆப் ரெயிலின் மேல்முனை உங்கள் படத்தைக் கிளிக் செய்து ஆப் மார்க்கெட்பிளேஸ் (கிளாசிக் இடைமுகத்தில், இது பொருள் மெனுவில் உள்ளது) எனத் தேர்ந்தெடுக்கவும், ஆப்பைக் கண்டறிந்து நிறுவ எனக் கிளிக் செய்து, பின்னர் பிளகின் மேனேஜ்மெண்டில் (Plugin Management) இதை இயக்கவும். கமாண்ட் லைனிலிருந்து:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

மற்ற கட்டளைகள்: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

அமைப்புகள் மூலம் செயலிகளை இயக்கு

எந்த ஆப்கள் இயங்குகின்றன என்பது PluginSettings.PluginStates என்ற அமைப்பு, இது ஆப் ஐடிக்களின் ஒரு வரைபடம். amctl மூலம் அதில் நுழைவுகளை இணைக்கலாம்; தானாக முன்-பாக்கேஜ் பண்ணபட்ட பாட்கள்களை இயக்கு இயக்கப்பட்டிருந்தால் (இது இயல்பானது), இயக்கப்பட்ட மூலம் சேர்க்கப்பட்ட ஆப் அடுத்த முறை இயக்கப்படும்போது நிறுவப்படும்:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

சந்தை உரையில் வழங்கப்படாத Todo ஐ நிறுவவும் இதுவே வழி. AM_PLUGINSETTINGS_PLUGINSTATES மாறிவும் வேலை செய்கிறது, ஆனால் அது முழு வரைபடத்தையும் மாற்றுகிறது: நீங்கள் இயக்க விரும்பும் ஒவ்வொரு செயலியையும் பட்டியலிடவும்.

செயலி அமைப்புகள்

பாட்களின் அமைப்புகள் PluginSettings.Plugins.<app id> கீழ் சேமிக்கப்படுகின்றன, விசைகள் சிறிய எழுத்துக்களில் இருக்கும். அவற்றைப் பாட்களின் System Console பக்கத்தில், அல்லது Configuration பகுதியில் காட்டப்பட்டுள்ளபடி amctl config patch மூலம் மாற்றலாம். AM_PLUGINSETTINGS_PLUGINS அனைத்துப் பாட்களின் அமைப்புகளையும் ஒரே நேரத்தில் மாற்றி அவற்றை அனைத்தையும் பூட்டிவிடும், எனவே அதைப் பயன்படுத்த வேண்டாம்.

GIFs

GIFகள் ஆப், எமோஜி தேர்ந்தெடுப்பிக்கு GIF மற்றும் ஸ்டிக்கர் தாவல்களைச் சேர்க்கிறது; இது Antimatter-இன் GIF சேவை (gifs-server) மூலம் ஆதரிக்கப்படுகிறது, இது Tenor API-யுடன் தொடர்பு கொள்கிறது. தளத்தின் compose file சேவையை இயக்கி, மாறிகளின் மூலம் ஆப்பை அமைக்கிறது. அமைப்பு கன்சோல் › பிளக்-இன்கள் › GIFகள் இல் உள்ள அதன் அமைப்புகள்:

அமைப்புமாறி (பிரிவாழ்வு)இயல்புஇது என்ன செய்கிறது
GIF சேவை URLAM_GIFS_SERVICE_URLவெற்றுசேவையின் API அடிப்படை, எடுத்துக்காட்டாக http://gifs:8080/v2. இது வெற்று இருக்கும்போது GIFs அணுகல் இல்லை.
API விசைAM_GIFS_API_KEYவெற்றுசேவையின் AM_GIFS_API_KEYS ஆகியவற்றில் ஒன்று.
பதிவேற்ற விசைAM_GIFS_UPLOAD_KEYவெற்றுசேவையின் AM_GIFS_UPLOAD_KEYS ஆகியவற்றில் ஒன்று. இது மக்கள் பிக்ஸரிலிருந்து GIF-களை மற்றும் ஸ்டிக்கர்களைச் சேர்த்து, இந்த முறையில் சேர்க்கப்பட்டவற்றை நீக்க அனுமதிக்கிறது. காலியாக இருந்தால் பதிவேற்றங்கள் (uploads) அணைக்கப்படும்.
GIFs மற்றும் ஸ்டிக்கர்களை யார் சேர்க்க முடியும்அமைப்பு நிர்வாகிகள்அமைப்பு நிர்வாகிகள் அல்லது அனைவரும். கஸ்டம் எமோஜியைப் போலவே, விருந்தினர்கள் (Guests) இதைச் செய்ய முடியாது. மக்கள் சேர்க்கும்வை அனைவருக்கும் கிடைக்கும்; சேர்த்தவர் மற்றும் அமைப்பு நிர்வாகிகள் இதை நீக்க முடியும்.
ஸ்டிக்கர்களை இயக்குஇயக்கப்பட்டதுஸ்டிக்கர் தாவலைக் காட்டுகிறது.
உள்ளடக்க வடிகட்டிநடுத்தரம்உயர்ந்தது, நடுத்தரம், குறைந்தது அல்லது முடக்கப்பட்டது.
Antimatter மூலம் ஊடகங்களை வழங்குஇயக்கப்பட்டதுபிரவுசர்கள் Antimatter-இலிருந்து GIFs லோடுகின்றன, Antimatter சேவையிலிருந்து அவற்றைப் பெறுகிறது. சேவை உங்கள் உள் நெட்வொர்க்கில் மட்டுமே இருந்தால் இதை இயக்கியிருக்கவும்.
ஊடக URLசேவையின் /media/நேரடியாக வழங்கப்படும்போது ஊடகங்கள் எங்கே உள்ளன.
கேஷ் அளவு (MB)64 MBபாட்களின் நினைவகக் கேஷ்.

இந்தப் பாட்களுக்கு, மாறிகள் பிரிவாழ்வு மதிப்புகள் மட்டுமே: System Console-இல் அமைக்கப்பட்ட மதிப்பு அவற்றை விட முன்னுரிமை பெறும். GIF தேர்ந்தெடுப்பி காலியாக இருந்தால், அந்தப் பக்கத்தில் சேவை URL மற்றும் API விசையைச் சரிபார்க்கவும்.

GIFகள் ஆப் அமைக்கப்பட்டிருக்கும்போது, அதன் தாவல் உள்வாங்கப்பட்ட Giphy தேர்ந்தெடுப்பை (அமைப்பு கன்சோல் › இணைப்புகள் › GIF › GIF தேர்வியை இயக்கு, ServiceSettings.EnableGifPicker) மாற்றுகிறது.

GIF சேவை

சேவை எல்லாவற்றையும் அதன் தரவு அடைவு (/data, gifs தொகுப்பு) இல் வைத்திருக்கிறது: தேடல் அட்டவணை மற்றும் ஊடகங்கள். அதன் முக்கிய மாறிகள்:

மாறிஇயல்புஇது என்ன செய்கிறது
AM_GIFS_API_KEYSஇல்லைகாமா-வெளியிடப்பட்ட API விசைகள். விசை இல்லாமல், அதை அடையும் எவருக்கும் API திறந்திருக்கும். பல விசைகள் அவற்றை மாற்றிப் பயன்படுத்த அனுமதிக்கின்றன.
AM_GIFS_UPLOAD_KEYSஇல்லைபதிவேற்றவும், பதிவேற்றப்பட்டவற்றை நீக்கவும் அனுமதிக்கப்பட்ட கீஸ்கள். ஒன்று இல்லாமல் பதிவேற்றங்கள் இல்லை.

மின்னஞ்சல் மற்றும் நாள்காட்டி

மின்னஞ்சல் மற்றும் நாள்காட்டி ஒவ்வொரு நபரையும் அவர்களின் சொந்த மின்னஞ்சல் பெட்டியுடன் (IMAP மற்றும் SMTP) மற்றும் சொந்த நாள்காட்டியுடன் (CalDAV) இணைக்கின்றன. பயனர்கள் செயலியில் தங்கள் சர்வர் மற்றும் கடவுச்சொல்லை உள்ளிட வேண்டும்; கடவுச்சொற்கள் குறியாக்கத்துடன் சேமிக்கப்படுகின்றன. நீங்கள் அவர்களுக்காக மின்னஞ்சல் அல்லது நாள்காட்டி சர்வர்களை அமைக்க வேண்டியதில்லை, ஆனால் அவர்கள் எதுவுடன் இணைக்க அனுமதிப்பீர்கள் என்பதை நீங்கள் முடிவு செய்கிறீர்கள்:

செயலிஅமைப்புஇயல்புஇது என்ன செய்கிறது
மின்னஞ்சல், நாள்காட்டிதனியார் நெட்வொர்க்களில் மின்னஞ்சல் சர்வர்களை அனுமதி, தனியார் நெட்வொர்க்களில் நாள்காட்டி சர்வர்களை அனுமதி (AllowPrivateNetworks)அணைஅணை, சர்வர் லூப்பேக், தனியார் மற்றும் லிங்க்-லோகல் முகவரிகளுடன் இணைவதை நிராகரிக்கிறது, எனவே செயலிகள் உங்கள் உள்நெட்வொர்க்கை அடைய பயன்படுத்த முடியாது. உங்கள் மின்னஞ்சல் அல்லது நாள்காட்டி சர்வர் தனியார் முகவரியில் இருந்தால் இதை இயக்கு.
மின்னஞ்சல், நாள்காட்டிகுறியாக்கம் இல்லாத இணைப்புகளை அனுமதி (AllowInsecureConnections)அணைஅணை, இணைப்புகள் TLS-ஐப் பயன்படுத்த வேண்டும் (மின்னஞ்சல்: TLS அல்லது STARTTLS; நாள்காட்டி: HTTPS).
மின்னஞ்சல்படிக்காத சோதனை இடைவெளி (நிமிடங்கள்) (UnreadCheckMinutes)2 நிமிடங்கள்மின்னஞ்சல் சர்வர் அவற்றை தள்ள முடியாதபோது, படிக்காத எண்ணிக்கைகள் எவ்வளவு அடிக்கடி சோதிக்கப்படுகின்றன.
மின்னஞ்சல்பெரிய செய்தி அளவு (MB) (MaxMessageSizeMB)25 MBஅனுப்பப்படும் மற்றும் படிக்கப்படும் செய்திகளின் அளவு வரம்பு.
நாட்காட்டிநினைவூட்டல்களை அனுப்பு (EnableReminders)இயக்கப்பட்டதுநாள்காட்டி பாட் நிகழ்வுகளுக்கு முன் நேரடி செய்தியை அனுப்புகிறது (10 நிமிடங்களுக்கு முன், தங்கள் சொந்த அலாரம் இல்லாத நிகழ்வுகளுக்கு).

பயனர்கள் கடவுச்சொல்லைப் பதிலாக தங்கள் கணக்கு மூலம் Gmail அல்லது Microsoft 365 மின்னஞ்சல் பெட்டிகளுக்கு உள்நுழைய அனுமதிக்க, OAuth கிளையண்டை உருவாக்கி மின்னஞ்சல் செயலியின் Google அல்லது Microsoft புலங்களை நிரப்பவும்:

  • Google: Gmail API மற்றும் https://mail.google.com/ ஸ்கோப்புடன் கூடிய Web OAuth கிளையண்ட்.
  • Microsoft: IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email மற்றும் profile டெலிகேட்டட் அனுமதிகளுடன் கூடிய Entra ID செயல்பாடு. டெனண்ட் இயல்பாக common ஆகும்.
  • இருவற்றிலும், ரீடிரெக்ட் URI https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (உங்கள் தள URL).

கான்பான், குறிப்புகள், வெள்ளை பலகை, கருத்துக் கணிப்புகள் மற்றும் பிளேபுக்குகள்

  • கனபான் (focalboard) பேச்சுவார்த்தையின் அருகில், பிளேபுக்ஸ்கள் போல அதன் பக்கப் பலகையில் (side panel) திறக்கிறது. /kanban/… மற்றும் /boards/… பக்கங்களுக்குப் பழைய இணைப்புகள், ஒரு சமூகத்தில் (community) அதே பலகையையோ அல்லது அட்டையையோ திறக்கும். இதன் ஒரே அமைப்பு, பொதுவாகப் பகிரப்பட்ட பலகைகளை இயக்கு (EnablePublicSharedBoards, அணைக்கப்பட்டது), இது பலகை எடிட்டர்கள் (editors) இணைப்பைக் கொண்டிருக்கும் யாருடனும், உள்நுழையாமல் (signing in) பலகையைப் பகிர அனுமதிக்கிறது.
  • Notes மற்றும் Polls அமைப்புகளில் இல்லை.
  • Whiteboard: அமைப்பு நிர்வாகிகள் அமைப்பு அமைப்பு பக்கத்தில், முழு சர்வருக்கும் வடிவ அரங்குகளை (Excalidraw .excalidrawlib கோப்புகள், ஒவ்வொருதும் 5 MB வரை) பதிவேற்றலாம். சமூக நிர்வாகிகள் தங்கள் சமூகத்தின் அரங்குகளை நிர்வகிக்கலாம்.
  • பிளேபுக்ஸ்கள் அதன் பக்கப் பலகையில் திறக்கிறது. /playbooks/… பக்கங்களுக்குப் பழைய இணைப்புகள், ஒரு சமூகத்தில் (community) அதே ரன் (run) அல்லது பிளேபுக்கைத் திறக்கும். இதில் சில அமைப்புகள் உள்ளன, பெரும்பாலும் சோதனை அம்சங்கள்; இயல்புநிலைகள் (defaults) பெரும்பாலான சர்வர்களுக்கு ஏற்றவை.
  • மீம்கள்: மீம் டெம்பிளேட்டுகளை (meme templates) யார் சேர்த்துக்கலாம்: அனைவரும் (இயல்புநிலை), அமைப்பு நிர்வாகிகள், அல்லது யாரும் இல்லை (கஸ்டம் டெம்பிளேட்டுகள் அணைக்கப்பட்டவை), இது புதிய டெம்பிளேட்டுகளை நிறுத்தும், ஏற்கனவே சேர்க்கப்பட்டவை பயன்பாட்டில் இருக்கும். விருந்தினர்கள் (Guests) டெம்பிளேட்டுகளைச் சேர்க்க மாட்டார்கள். டெம்பிளேட்டைச் சேர்த்தவர் மற்றும் அமைப்பு நிர்வாகிகள் இதை நீக்க முடியும்.
  • Todo இல் சர்வர் அமைப்புகள் இல்லை.

GitHub, GitLab மற்றும் Jira

இந்த செயலிகள் Antimatter-ஐ உங்கள் குறியீடு ஹோஸ்டிங் மற்றும் பிரச்சனை டிராக்கருடன் இணைக்கின்றன. ஒவ்வொன்றும் மறுபுறம் ஒரு OAuth செயலியையும், Antimatter-க்கு திரும்பிச் செல்லும் ஒரு webhook-உம் தேவைப்படுகிறது. செயலியை இயக்கவும், பின்னர் எந்த சேனலிலும் அதன் அமைப்பு கட்டளையை இயக்கவும், அது படிப்படியாக வழிகாட்டுகிறது: /github setup, /gitlab setup அல்லது /jira setup.

GitHub மற்றும் GitLab செயலிகள் முதல் சேமிப்பில் webhook secret மற்றும் encryption key ஐ உருவாக்குகின்றன. GitHub செயலி நிறுவனங்களுக்கு (GithubOrg) மற்றும் GitLab செயலி குழுவுக்கு (GitlabGroup) மட்டுப்படுத்தப்படலாம்; GitHub Enterprise அல்லது self-hosted GitLab-க்கு, அதன் base URL ஐ அமைக்கவும்.

அளவீடுகள்

Metrics செயலி சர்வரின் செயல்திறன் அளவீடுகளை Antimatter-இன் உள்ளே ஒரு சிறிய time-series database-இல் சேகரிக்கிறது, இதனால் Prometheus ஐ இயக்காமல் அவற்றை பதிவிறக்கவோ அல்லது ஆதரவு பட்டியலில் சேர்க்கவோ முடியும். அது இயங்கும்போது, சர்வரின் metrics endpoint ஐ (MetricsSettings.Enable) இயக்குகிறது. Operations ஐ பார்க்கவும்.

மற்ற செயலிகளை நிறுவுதல்

Antimatter Mattermost செயலிகளை (plugins) இயக்குகிறது. ஒன்றை சேர்க்கும் மூன்று வழிகள்:

  • தூர மார்க்கெட்பிளேஸிலிருந்து. தூர மார்க்கெட்பிளேஸை இயக்கு (PluginSettings.EnableRemoteMarketplace) இயல்பாக முடக்கப்பட்டிருக்கிறது, மேலும் மார்க்கெட்பிளேஸ் URL (PluginSettings.MarketplaceURL) காலியாக உள்ளது: Antimatter Mattermost-இன் மார்க்கெட்பிளேஸைப் பயன்படுத்தாது, Mattermost-இலிருந்து உள்ளமைவு இன்னும் அதைக் கொண்டிருந்தால் அதன் முகவரியை புறக்கணிக்கிறது. நீங்கள் நம்பும் ஒரு மார்க்கெட்பிளேஸ் சர்வரின் ஆப்களைப் பட்டியலிட, அமைப்பை இயக்கி அதன் URL-ஐ அமைக்கவும். Antimatter வழங்கும் ஆப்களின் (Calls, Playbooks, Kanban மற்றும் மற்றவை) அந்த மார்க்கெட்பிளேஸின் கட்டமைப்புகள் மறைக்கப்படுகின்றன, எனவே அவை Antimatter-இன் ஆப்களை மாற்ற முடியாது: Antimatter பிளகின்களின் மார்க்கெட்பிளேஸ் கட்டமைப்புகளை அனுமதி (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) இயல்பாக முடக்கப்பட்டிருக்கிறது.
  • ஒரு பட்டையை பதிவேற்றமூலம் (.tar.gz). பதிவேற்றம்கள் இயல்பாக முடக்கப்பட்டிருக்கின்றன, மேலும் அவைக்கு அமைப்பு கன்சோலில் எந்த விளக்குமில்லை: AM_PLUGINSETTINGS_ENABLEUPLOADS=true ஐ அமைத்து, பின்னர் பிளகின் மேலாண்மையில் பிளகினை பதிவேற்று ஐப் பயன்படுத்தவும், அல்லது amctl --local plugin add app.tar.gz ஐப் பயன்படுத்தவும்.
  • ஒரு URL-இலிருந்து: amctl plugin install-url <url>, பதிவேற்றங்கள் இயக்கப்பட்ட நிலையில்.

Antimatter, அப்களின் சைக்னேச்சுகளை அது நம்பும் கீகளாடா ஒப்பிடுகிறது: Antimatter கீ, Mattermost, Inc. தனது வெளியிடும் அப்களை சைக்னேசு செய்யும் கீ (எனவே நீங்கள் தானாக பதிவிறக்கிய Mattermost அப்கள் நிறுவப்படும்), மற்றும் PluginSettings.SignaturePublicKeyFiles-ல் நீங்கள் சேர்த்துள்ள எந்த கீ. பிளகின்களுக்கு சைக்னேச்சு தேவை (PluginSettings.RequirePluginSignature, இயல்பாக அணை) இயக்கப்பட்டால், சைக்னேசு இல்லாத அப்கள் நிராகரிக்கப்பட்டு பதிவேற்றங்கள் முடக்கப்படும்.

ஒரு பயன்பாடு சேவையகத்திற்குள் அதன் தரவுக்கு முழு அணுகலுடன் இயங்குகிறது. நம்பகமான பயன்பாடுகளை மட்டுமே நிறுவவும்.

Mattermost-இன் கட்டண பதிப்புகளுக்காக உருவாக்கப்பட்ட சில பயன்பாடுகள் Mattermost உரிமத்தைத் தானாகச் சரிபார்த்து இயங்க மறுக்கின்றன; Antimatter அவற்றுக்காக உரிமம் உள்ளது என்று நடிக்காது.
