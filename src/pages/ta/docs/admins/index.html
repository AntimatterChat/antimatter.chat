ஒரு நிறுவலில் என்னென்ன உள்ளன

Antimatter என்பது தானியங்கு-நிறுவல் (self-hosted) குழு உரையாடல், Mattermost-இன் ஒரு fork. ஒரு முழுமையான நிறுவல் இவற்றால் ஆனது. முதல் மூன்றே அவசியமானவை.

பகுதிஇது என்ன செய்கிறதுஅவசியம்
Antimatter சர்வரர்8065 போர்ட்டில் web app, API மற்றும் websockets-ஐ வழங்கும், சேர்க்கப்பட்ட பயன்பாடுகளை (plugins) இயக்கும், 8443 போர்ட்டில் அழைப்பு ஊடகங்களை (call media) கடத்தும் ஒரு Go நிரல் (antimatter). amctl என்ற கட்டளை-வரி கருவி (command-line tool) இதை நிர்வகிக்கிறது.ஆம்
PostgreSQLதரவுத்தளம்: செய்திகள், பயனர்கள், சமூகங்கள் மற்றும் பரிந்துரைக்கப்பட்ட அமைப்பில் சர்வரின் அமைப்புகள். பதிப்பு 15 அல்லது அதற்குப் புதியது.ஆம்
கோப்பு சேமிப்புபதிவேற்றப்பட்ட கோப்புகள், படங்கள் மற்றும் நிறுவப்பட்ட பயன்பாடுகள்: S3-உடன் இணைக்கக்கூடிய சேவை (compose file RustFS-ஐ இயக்குகிறது) அல்லது உள்ளூர் வடிவமைப்பு (local directory).ஆம்
ஒரு reverse proxyசர்வரின் முன்னால் HTTPS: compose file-இன் Caddy profile அல்லது உங்கள் சொந்த nginx.உற்பத்திக்கு (production)
GIF சேவை (gifs-server)GIF தேர்விக்கான (GIF picker) GIFs மற்றும் stickers, உங்கள் சொந்த வர்த்தகப்பட்டியலிலிருந்து. இது Tenor API-உடன் தொடர்பு கொள்கிறது.இல்லை
ஒரு push proxyApple மற்றும் Google வழியாக அறிவிப்புகளை (notifications) மொபைல் பயன்பாட்டிற்கு முன்னேற்றுகிறது.மொபைல் அறிவிப்புகளுக்கு
rtcd, ஒரு TURN சர்வரர்பல அழைப்புகளுக்கு தனி ஊடக சர்வரர், கடுமையான firewalls-க்கு பின்னால் உள்ளவர்களுக்கு relay.இல்லை
AI முனைகள் (endpoints)AI agents, அழைப்பு எழுத்துப்படுத்தல் (transcription), படித்துக் கேட்பு (read-aloud) மற்றும் மொழிபெயர்ப்பின் பின்னே உள்ள மாதிரிகள்: ஒரு மின்னூட்ட சேவை (cloud provider) அல்லது நீங்கள் இயக்கும் சர்வர்கள்.இல்லை

Antimatter-இல் உரிமம் (licence) இல்லை, கட்டண பதிப்பு இல்லை: single sign-on, LDAP, high availability, compliance exports, data retention மற்றும் Mattermost-இன் கட்டண திட்டங்களுக்காக ஒதுக்கப்பட்ட மற்ற அம்சங்கள் அனைத்தும் இதில் சேர்க்கப்பட்டுள்ளன.

தேவைகள்

  • ஒரு Linux சர்வரர், amd64 அல்லது arm64, சில நூறு மக்களுக்காக 2 CPU cores மற்றும் 4 GB memory அல்லது அதற்கு மேல், மக்கள் பதிவேற்றும் கோப்புகளுக்கான டிஸ்க் இடம்.
  • பரிந்துரைக்கப்பட்ட நிறுவலுக்காக Compose plugin-உடன் கூடிய Docker Engine (docker compose).
  • உற்பத்திக்கு (production): சர்வரை சுட்டிக்காட்டும் ஒரு domain name, HTTPS-க்காக 80 மற்றும் 443 போர்ட்கள் திறந்திருக்க வேண்டும்.
  • அழைப்புகளுக்கு (calls): 8443 போர்ட், UDP மற்றும் TCP, அழைப்பவர்களால் அணுகக்கூடியதாக இருக்க வேண்டும்.
  • மின்னஞ்சலுக்காக (email): Antimatter வழியாக அனுப்பக்கூடிய ஒரு SMTP சர்வரர்.

விரைவு தொடக்கம் (Quick start)

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

பின்னர் தளத்தின் URL-ஐ திறந்து உங்கள் கணக்கை உருவாக்குங்கள்: முதல் கணக்கு அமைப்பு நிர்வாகியாக (system administrator) மாறும். நிறுவல் ஒவ்வொரு படியையும் மற்றும் நிறுவும் மற்ற வழிகளையும் விளக்குகிறது.

இந்த வழிகாட்டியில்

  • நிறுவல்: Docker Compose, ஊடகங்கள் (images), வெளியீட்டு ஆர்கைவ் (release archive), முதல் நிர்வாகி.
  • அமைப்பு: தரவுத்தளத்தில் அல்லது கோப்பில் உள்ள அமைப்புகள், AM_ சூழல் மாறிகள் (environment variables), அமைப்பு கன்சோல் (System Console), amctl, பதிவுகள் (logs).
  • டொமைன் மற்றும் HTTPS: தளத்தின் URL, Caddy, nginx, கிளையன்ட் முகவரிகள்.
  • அழைப்புகள் மற்றும் குரல்: போர்ட்கள், NAT, TURN, rtcd, எழுத்துப்பதிவு (transcription) மற்றும் வசனங்கள் (captions).
  • மின்னஞ்சல் மற்றும் டிவ்: SMTP, டிவ் புராக்சி (push proxy) மற்றும் மொபைல் செயலி.
  • இணைக்கப்பட்ட செயலிகள்: எந்த செயலிகள் இயக்கப்பட்டுள்ளன, அவற்றின் அமைப்புகள், மற்றவற்றை நிறுவுதல்.
  • AI: ஏஜெண்டுகள், குரல் மற்றும் மொழிபெயர்ப்புக்கான மாதிரிகள், மற்றும் எந்த தரவு எங்கு செல்கிறது என்பது.
  • உள்நுழைவு மற்றும் கணக்குகள்: பதிவு (sign-up), கடவுச்சொற்கள், MFA, ஒற்றை உள்நுழைவு (single sign-on), LDAP, விருந்தினர்கள், அமர்வுகள் (sessions).
  • பின்புல நகல்கள் மற்றும் மேம்பாடுகள்: பின்புல நகல் (backup), மீட்பு (restore), மேம்பாடு (upgrade), Mattermost-இலிருந்து நகர்த்தல்.
  • செயல்பாடுகள்: கண்காணிப்பு, விரிவாக்கம் (scaling), தரவு வைப்பு (data retention), சட்டப்படி இயக்கம் (compliance), பிரச்சினை தீர்ப்பு.
  • பாதுகாப்பு: பாதுகாப்பு சரிபார்ப்புப் பட்டியல் (hardening checklist) மற்றும் வெளி இணைப்புகள்.

சர்வர்களுக்குப் பதிலாக ஒரு சமூகத்தை இயக்குவது (சேனல்கள், பங்குகள், நிர்வாகம்)? சமூகத்தை இயக்குதல் காண்க. ஒருங்கிணைப்புகளை உருவாக்குவது? Antimatter-இல் உருவாக்குதல் காண்க.

உங்கள் முதல் மணி நேரம்

  1. நிறுவவும், உடனடியாக நிர்வாகி கணக்கை உருவாக்கவும்.
  2. சர்வரை அதன் சொந்த டொமைனில் HTTPS-இன் பின்னால் வைக்கவும்.
  3. SMTP-ஐ அமைத்து ஒரு சோதனை மின்னஞ்சலை அனுப்பவும்.
  4. அழைப்புகள் போர்டை திறந்து, அழைப்புகள் செயலியின் சோதனை முறையை (test mode) அணைக்கவும்.
  5. யார் பதிவு செய்யலாம் என்பதை முடிவு செய்து, MFA-ஐ இயக்கவும்.
  6. பாதுகாப்பு பகுதியில் உள்ள வெளி இணைப்புகளை சரிபார்க்கவும்.
  7. தினசரி பின்புல நகல்களை அமைக்கவும்.

உதவி பெறுதல்

சமூக விவாதங்களில் கேள்விகளைக் கேளுங்கள், மற்றும் சமூக சேமிப்பகத்தில் பிழைகளை அறிவிக்கவும். பாதுகாப்புக் கொள்கை விளக்குவது போல, பாதுகாப்புப் பிரச்சனைகளை தனியாக அறிவிக்கவும்.
