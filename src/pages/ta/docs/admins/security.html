8067/tcpஅளவீடுகள்செயல்படுத்தப்பட்டால், தனியார் நெட்வொர்க்கு மட்டுமே. உள்நுழைவு இல்லை.

நிறுவல் பின் சோதனைப் பட்டியல்

  1. மற்றவர்கள் சர்வரை அணுகும் முன் முதல் நிர்வாகி கணக்கை உருவாக்கவும் (நிறுவல்).
  2. Antimatter-ஐ HTTPS மூலம் மட்டுமே வழங்கவும், மற்றும் தள URL-ஐ https:// முகவரியாக அமைக்கவும் (டொமைன் மற்றும் HTTPS).
  3. .env, config.json மற்றும் TLS விசைகளை root (அல்லது சர்வரின் பயனர்) மட்டுமே படிக்க முடியும் என்பதை உறுதி செய்யவும்: chmod 600 .env.
  4. எந்தவொருவரும் கணக்குகளை உருவாக்க முடியும் என்பதைத் தீர்மானிக்கவும், சமூகம் பொதுவாக இல்லையெனில் திறந்த சரவரை இயக்கு விதை அணைத்திருக்கவும், மின்னஞ்சல் வேலை செய்யத் தொடங்கிய பிறகு மின்னஞ்சல் சரிபார்ப்பைக் கோரு விதை இயக்கவும் (உள்நுழைவு மற்றும் கணக்குகள்).
  5. பல்தர அங்கீகாரத்தை (multi-factor authentication) இயக்கவும், குறைந்தது நிர்வாகிகளின் கணக்குகளுக்கு இதை கட்டாயமாக்கவும், அல்லது உங்கள் அங்கீகார வழங்குநரின்தைப் பயன்படுத்தவும்.
  6. கீழே உள்ள வெளி இணைப்புகளை சரிபார்க்கவும், குறிப்பாக அழைப்புகள் (Calls) இயல்பாகப் பயன்படுத்தும் STUN சர்வரை.
  7. மாதிரி இணைப்புகளைச் சேர்க்கும் முன், AI மறைவு விசையை (AM_AI_ENCRYPTION_KEY) அமைத்து, தரவுத்தளப் பிடிப்பு நகல்களிலிருந்து தனித்து அதன் நகலை வைத்திருங்கள் (AI).
  8. பின்புலச் சேமிப்பை (backup) எடுக்கவும், மற்றும் மீட்பை (restore) சோதிக்கவும் (பின்புலச் சேமிப்புகள் மற்றும் மேம்பாடுகள்).
  9. படங்களை அல்லது தொகுப்புகளைப் புதுப்பித்திருங்கள்: பாதுகாப்பு சரிசெய்தல்கள் புதிய பதிப்புகளுடன் வருகின்றன.

விகிதக் கட்டுப்பாடு

ஒவ்வொரு கிளையண்டும் எத்தனை API கோரிக்கைகளைச் செய்யலாம் என்பதை சரவர் வரம்பிட முடியும். இது இயல்பாக அணைத்திருக்கும். அமைப்பு கன்சோல் › சூழல் › விகித வரம்பு இல்:

அமைப்புவிசைஇயல்பு
விகித வரம்பை இயக்குRateLimitSettings.Enableஅணை
வினாடிக்கு அதிகபட்ச வினவல்கள்RateLimitSettings.PerSec10
அதிகபட்ச வெடிப்பு அளவுRateLimitSettings.MaxBurst100
நினைவக சேமிப்பு அளவுRateLimitSettings.MemoryStoreSize10000 கிளையன்கள் கண்காணிக்கப்படுகின்றன
தொலைவில் உள்ள முகவரியால் விகித வரம்பை மாற்றுRateLimitSettings.VaryByRemoteAddrஇயக்கப்பட்டது
பயனரால் விகித வரம்பை மாற்றுRateLimitSettings.VaryByUserஅணை
HTTP தலைப்பால் விகித வரம்பை மாற்றுRateLimitSettings.VaryByHeaderவெற்று

ஒரு proxy ஐப் பின்னால், முகவரி அடிப்படையிலான கட்டுப்பாடுகள் சேவையகம் ஒவ்வொரு கிளையனின் முகவரியையும் அறிந்தால் மட்டுமே வேலை செய்யும் (ServiceSettings.TrustedProxyIPHeader மற்றும் ServiceSettings.TrustedProxyIPs, proxy ஐப் பின்னால் உள்ள கிளையன் முகவரிகள் காண்க). இல்லையெனில், அனைத்து கோரிக்கைகளும் proxy ஐ இருந்து வந்ததாகத் தோன்றும், அனைவரும் ஒரே ஒரு கட்டுப்பாட்டைப் பகிர்ந்து கொள்வார்கள். IP வடிகட்டல் மற்றும் audit logs இல் உள்ள முகவரிகளுக்கும் இதே விதி பொருந்தும்.

உள்நுழைவு முயற்சிகள் தனித்தனியாகக் கட்டுப்படுத்தப்படுகின்றன: அதிகபட்ச உள்நுழைவு முயற்சிகள் (10) – அந்த எண்ணிக்கையிலான தோல்வியடைந்த கடவுச்சொற்களுக்குப் பிறகு கணக்கு பூட்டப்படும்.

IP வடிகட்டல்

அமைப்பு கன்சோல் › தள அமைப்பு › IP வடிகட்டல் என்பது IP முகவரி அடிப்படையில் சரவரின் அணுகலை வரம்பிடுகிறது; அனுமதி மற்றும் தடை விதிகள் (ஒவ்வொன்றும் ஒரு முகவரி அல்லது CIDR வரம்பு) மூலம். IP வடிகட்டலை இயக்கு விதை இயக்கப்பட்டால், தடை விதியுடன் பொருந்தும் அல்லது அனுமதி விதிகள் இருந்தால் அவற்றுடன் பொருந்தாத மக்கள் சரவரை அடைய முடியாது. உங்கள் சொந்த முகவரியை தடுக்கும் விதிகளைப் பக்கம் நிராகரிக்கும். புரொக்ஸிக்குப் பின்னால், முதலில் கிளையன்ட் முகவரிகளை அமைக்கவும் (புரொக்ஸிக்குப் பின்னான கிளையன்ட் முகவரிகள்): இல்லையெனில் ஒவ்வொரு கோரிக்கையும் புரொக்ஸியிலிருந்து வந்தது போல் தோன்றும்.

பதிவேற்றங்கள் மற்றும் கோப்புப் பகிர்வு

அமைப்புஇடம்இயல்பு
அதிகபட்ச கோப்பு அளவு (FileSettings.MaxFileSize)Environment › File Storage100 MB. proxy ஐயின் கோரிக்கை அளவுக் கட்டுப்பாட்டை இதற்குச் சமமாக அல்லது அதிகமாக வைத்திருங்கள்.
அதிகபட்ச Payload அளவு (பைட்டுகள்) (ServiceSettings.MaximumPayloadSizeBytes)Environment › Web Server300000: கோப்புப் பதிவேற்றங்களுக்குப் பிறகு மிகப்பெரிய API கோரிக்கை
கோப்பு பகிர்தலை அனுமதி (FileSettings.EnableFileAttachments)Site Configuration › File Sharing and Downloadsஇயக்கப்பட்டது
மொபைலில் கோப்பு பதிவேற்றங்களை அனுமதி, மொபைலில் கோப்பு பதிவிறக்கத்தை அனுமதிSite Configuration › File Sharing and Downloadsஇயக்கப்பட்டது
பொது கோப்பு இணைப்புகளை இயக்கு (FileSettings.EnablePublicLink)Site Configuration › Public Linksஅணைக்கப்பட்டது: இயக்கப்பட்டால், உள்நுழைவது இல்லாமல் ஒரு கோப்பை இணைப்பு மூலம் பகிர முடியும்
SVG-களை இயக்கு (ServiceSettings.EnableSVGs)Site Configuration › Postsபுதிய சேவையகத்தில் அணைக்கப்பட்டது: இயக்கப்பட்டால், SVG படங்கள் நேரடியாகக் காட்டப்படும்

Antimatter பதிவேற்றங்களை மால்வேர் சோதனைக்கு உட்படுத்தாது.

தனியுரிமை அமைப்புகள்

அமைப்பு கன்சோல் › தள அமைப்புகள் › பயனர்கள் மற்றும் குழுக்கள் இல்:

அமைப்புவிசைஇயல்புஇது என்ன செய்கிறது
மின்னஞ்சல் முகவரியை காட்டுPrivacySettings.ShowEmailAddressஇயக்கப்பட்டதுஅணைக்கப்பட்டால், உறுப்பினர்களின் மின்னஞ்சல் முகவரிகள் நிர்வாகிகளுக்கு மட்டுமே தெரியும். பொது சேவையாளிகளில் இதை அணைக்கவும்.
முழு பெயரை காட்டுPrivacySettings.ShowFullNameஇயக்கப்பட்டதுஅணைக்கப்பட்டால், முழு பெயர்கள் மறைக்கப்பட்டு, அதற்குப் பதிலாக பயனர் பெயர்கள் காட்டப்படும்.
புறக்கணிப்பு, தடை மற்றும் செய்தி கோரிக்கைகளை இயக்குPrivacySettings.EnableUserBlockingஇயக்கப்பட்டதுகீழே பார்க்கவும்.
பயனர்கள் நேரடி செய்தி சேனல்களைத் திறக்க அனுமதிக்கTeamSettings.RestrictDirectMessageAntimatter சேவையாளியில் உள்ள எந்தவொரு பயனரையும்அல்லது குழுவின் எந்தவொரு உறுப்பினரும்: ஒரு சமூகத்தைப் பகிர்ந்து கொள்ளும் மக்கள் மட்டுமே.

புறக்கணிப்பு, தடை மற்றும் செய்தி கோரிக்கைகள்

புறக்கணிப்பு, தடை மற்றும் செய்தி கோரிக்கைகளை இயக்கு இயக்கப்பட்டிருந்தால் (இயல்புநிலை), நபர்கள் ஒன்றையொன்று புறக்கணித்து, தடைசெய்யலாம். அறிந்திருக்காத நபர்களிடமிருந்து நேரடி செய்திகளை, ஏற்றுக்கொள்ளப்படும் வரை அறிவிப்பு இல்லாமல், செய்தி கோரிக்கைகளாகப் பெற தேர்ந்தெடுக்கலாம். இது பொது சமூகங்களுக்கு பொருத்தமானது. பணியிடங்களில், சகப்பணியாளர்கள் எப்போதும் ஒன்றையொன்று அடைய வேண்டும் என்றால், இதை அணைக்கவும் (AM_PRIVACYSETTINGS_ENABLEUSERBLOCKING=false): இது எதுவும் இனி நடைமுறைப்படுத்தப்படாது, ஆனால் நபர்கள் செய்த பட்டியல்கள் மற்றும் தேர்வுகள் வைத்திருக்கப்படுகின்றன, மீண்டும் இயக்கினால் அவை மீண்டும் பொருந்தும்.

அமர்வுகள் மற்றும் டோக்கன்கள்

  • அமர்வு நீளங்கள் மற்றும் ஐடிள் டைமவுட்: உள்நுழைவு மற்றும் கணக்குகள் ஐப் பார்க்கவும். குறுகிய அமர்வுகள், இழக்கப்பட்ட லேப்டாப் அல்லது தொலைபேசி குறைந்த நேரம் உள்நுழைந்த நிலையில் இருக்கும் என்பதைக் குறிக்கிறது.
  • தனிப்பட்ட அணுகல் டோகன்களை இயக்கு (ServiceSettings.EnableUserAccessTokens, அணைத்தது) மக்கள் API டோகன்களை உருவாக்க அனுமதிக்கிறது; அதிகபட்ச தனிப்பட்ட அணுகல் டோகன் ஆயுள் (நாட்கள்) அவற்றை வரம்பிடுகிறது. இரண்டும் அமைப்பு கன்சோல் › இணைப்புகள் › இணைப்பு மேலாண்மை இல் உள்ளன.
  • உதாரணமாக, சந்தேகிக்கப்படும் துப்புரவுக்குப் பிறகு அனைவரையும் ஒருசேர உள்நுழைவிலிருந்து வெளியேற்ற: அமைப்பு கன்சோல் › பயனர் மேலாண்மை › பயனர்கள் இல் அனைத்து அமர்வுகளையும் ரத்து செய்.

வெளி சேவைகளுடன் இணைப்புகள்

Antimatter, Mattermost, Inc. இயக்கும் எந்த சேவையையும் தொடர்பு கொள்ளாது. இது டெலிமெட்ரி, கிராஷ் அறிக்கைகள் அல்லது பாதுகாப்பு புதுப்பிப்பு சோதனைகளை அனுப்பாது, மற்றும் தயாரிப்பு அறிவிப்புகளைப் பெறாது.
