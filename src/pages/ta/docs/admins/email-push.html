வெளியேறும் மின்னஞ்சல் (SMTP)

Antimatter உங்கள் வழங்கும் SMTP சேவையகம் மூலம் மின்னஞ்சல் அனுப்புகிறது: உங்கள் நிறுவனத்தின் மின்னஞ்சல் சேவையகம் அல்லது ஒரு பரிவர்த்தனை மின்னஞ்சல் சேவை. இது இல்லாமல், மறந்த கடவுச்சொல்லை மீட்டமைக்க முடியாது, மின்னஞ்சல் அழைப்புகள் மற்றும் சரிபார்ப்புகள் வராது, மேலும் தவறிய செய்திகளின் மின்னஞ்சல் அறிவிப்புகள் யாருக்கும் செல்லாது.

இதை அமைப்பு கன்சோல் › சூழல் › SMTP இல் அமைக்கவும், அல்லது மாறிகளால்:

அமைப்புKey மற்றும் variableஇயல்பு
SMTP சேவையகம்EmailSettings.SMTPServer, AM_EMAILSETTINGS_SMTPSERVERlocalhost
SMTP சேவையக துறைமுகம்EmailSettings.SMTPPort, AM_EMAILSETTINGS_SMTPPORT10025
SMTP அங்கீகாரத்தை இயக்குEmailSettings.EnableSMTPAuth, AM_EMAILSETTINGS_ENABLESMTPAUTHஇணைப்பு பாதுகாப்பு இல்லாமல் அணை; இருந்தால் இயக்கு
SMTP சேவையக பயனர் பெயர்EmailSettings.SMTPUsername, AM_EMAILSETTINGS_SMTPUSERNAMEவெற்று
SMTP சர்வர் கடவுச்சொல்EmailSettings.SMTPPassword, AM_EMAILSETTINGS_SMTPPASSWORDவெற்று
இணைப்பு பாதுகாப்புEmailSettings.ConnectionSecurity, AM_EMAILSETTINGS_CONNECTIONSECURITYஏதும் இல்லை (வெற்று); அல்லது TLS அல்லது STARTTLS
சர்வர் சான்றிதழ் சரிபார்ப்பை தவிர்க்கEmailSettings.SkipServerCertificateVerificationஅணை. உற்பத்தியில் (production) இதை அணைத்திருக்கவும்.

உங்கள் வழங்குநர் கூறுவது போல, துறைமுகம் 587 இல் STARTTLS அல்லது துறைமுகம் 465 இல் TLS பயன்படுத்தவும். பின்னர் அதே பக்கத்தில் இணைப்பை சோதி என்ற பொத்தானை அழுத்தவும்: Antimatter உங்கள் சொந்த முகவரிக்கு ஒரு சோதனை மின்னஞ்சலை அனுப்பும்.

Docker Compose உடன் ஒரு வழக்கமான அமைப்பு, compose.yaml ஐ அடுத்து compose.override.yaml இல்:

services:
  antimatter:
    environment:
      AM_EMAILSETTINGS_SMTPSERVER: smtp.example.com
      AM_EMAILSETTINGS_SMTPPORT: "587"
      AM_EMAILSETTINGS_CONNECTIONSECURITY: STARTTLS
      AM_EMAILSETTINGS_ENABLESMTPAUTH: "true"
      AM_EMAILSETTINGS_SMTPUSERNAME: chat@example.com
      AM_EMAILSETTINGS_SMTPPASSWORD: ${SMTP_PASSWORD}
      AM_EMAILSETTINGS_FEEDBACKNAME: Antimatter
      AM_EMAILSETTINGS_FEEDBACKEMAIL: chat@example.com
      AM_EMAILSETTINGS_REPLYTOADDRESS: chat@example.com

SMTP_PASSWORD ஐ .env இல் வைக்கவும். தளத்தின் compose கோப்பு சேவையகத்தை இயல்புநிலை வலையமைப்பில் வைக்கிறது, அதற்கு இணைய அணுகல் உள்ளது, எனவே வெளிப்புற SMTP சேவையகத்தை அது அடைய முடியும்.

அனுப்பியவர் மற்றும் அறிவிப்பு மின்னஞ்சல் அமைப்புகள்

அமைப்பு கன்சோல் › தள அமைப்பு › அறிவிப்புகள் இல்:

அமைப்புவிசைஇயல்பு
மின்னஞ்சல் அறிவிப்புகளை இயக்குEmailSettings.SendEmailNotificationsஇயக்கப்பட்டது
அறிவிப்பு காட்சி பெயர்EmailSettings.FeedbackNameவெற்று
அறிவிப்பு அனுப்பியவர் முகவரிEmailSettings.FeedbackEmailtest@example.com: இதை மாற்று
அறிவிப்பு பதில்-க்கு முகவரிEmailSettings.ReplyToAddresstest@example.com: இதை மாற்று
மறுபயன்பாட்டு மின்னஞ்சல் முகவரிSupportSettings.SupportEmailவெற்று
அறிவிப்பு கீழ்க்கண்ணுள்ள அஞ்சல் முகவரிEmailSettings.FeedbackOrganizationவெற்று
மின்னஞ்சல் அறிவிப்பு உள்ளடக்கம்EmailSettings.EmailNotificationContentsTypeமுழு செய்தி உள்ளடக்கத்தை (full) அனுப்பவும், அல்லது அனுப்பியவரின் பெயர் மட்டுமே உள்ள பொதுவான விளக்கத்தை (generic) அனுப்பவும்
மின்னஞ்சல் தொகுப்பை இயக்குEmailSettings.EnableEmailBatchingஅணை. இயக்கினால், ஒவ்வொரு 15 நிமிடங்களுக்கு அல்லது ஒவ்வொரு மணிக்கும் தவறிய செய்திகளை ஒரு மின்னஞ்சலில் தொகுத்து பெற பயனர்கள் தேர்ந்தெடுக்க முடியும், ஒவ்வொரு செய்திக்கும் தனி மின்னஞ்சல் அனுப்பப்படாமல்.
மின்னஞ்சல் அறிவிப்புகளில் சேனல் பெயரை பயன்படுத்துEmailSettings.UseChannelInEmailNotificationsஅணை
முன்னோட்ட முறை பட்டையை இயக்குEmailSettings.EnablePreviewModeBannerஇயக்கு: மின்னஞ்சல் அறிவிப்புகள் அணைக்கப்பட்டிருக்கும்போது, மின்னஞ்சல் அமைக்கப்படவில்லை என்று நிர்வாகிகளுக்கு ஒரு பட்டை (banner) தெரிவிக்கும்

From முகவரி உங்கள் SMTP சேவையகம் அனுப்ப அனுமதிக்கப்பட்ட ஒரு முகவரியாக இருக்க வேண்டும்; அதன் டொமைனுக்காக SPF மற்றும் DKIM அமைக்க வேண்டும், இல்லையெனில் மின்னஞ்சல்கள் ஸ்பாம் கோப்புறைகளில் சேர்ந்துவிடலாம்.

மின்னஞ்சல் தொடர்பான உள்நுழைவு அமைப்புகள் (புதிய கணக்குகள் தங்கள் முகவரியை உறுதிப்படுத்த வேண்டுமா, மின்னஞ்சல் மூலம் அழைப்புகளை அனுப்ப முடியுமா) உள்நுழைவு மற்றும் கணக்குகள் பக்கத்தில் உள்ளன.

Push notifications to the mobile app

புஷ் எவ்வாறு செயல்படுகிறது

Antimatter நேரடியாக Apple அல்லது Google உடன் தொடர்பு கொள்ளாது. ஒவ்வொரு அறிவிப்பிற்கும், அது ஒரு புஷ் ப்ராக்ஸி ஐ அழைக்கிறது. இந்த புஷ் ப்ராக்ஸி மொபைல் செயலியின் அங்கீகார விவரங்களை வைத்திருக்கிறது, மேலும் iPhone களுக்கு Apple (APNs) மூலம், Android தொலைபேசிகளுக்கு Google (Firebase Cloud Messaging) மூலம் அறிவிப்பை முன்னேற்றுகிறது. Apple மற்றும் Google, செயலியின் அங்கீகார விவரங்களுடன் அனுப்பப்பட்டால் மட்டுமே அறிவிப்பை வழங்கும். எனவே, ஒரு புஷ் ப்ராக்ஸி மொபைல் செயலியின் ஒரு கட்டமைப்பின் (build) மூலம் செயல்படுகிறது: அதன் அங்கீகார விவரங்களை வைத்திருக்கும் கட்டமைப்பு.

  • Antimatter ஒரு பொதுவான புஷ் ப்ராக்ஸியை இயக்காது. உங்கள் பயனர்கள் நிறுவும் மொபைல் செயலியின் கட்டமைப்பின் அங்கீகார விவரங்களுடன், Antimatter புஷ் ப்ராக்ஸியை நீங்களே இயக்க வேண்டும்.
  • Antimatter Mattermost இன் புஷ் சேவைகளுக்கு (பரிசோதனை அல்லது ஹோஸ்டெட்) அறிவிப்புகளை அனுப்பாது: அவை Mattermost இன் சொந்த மொபைல் செயலிகளுக்கு மட்டுமே வழங்குகின்றன. சேவையகம் அவற்றின் முகவரிகளில் ஒன்றில் அமைக்கப்பட்டால் (எ.கா., https://push-test.mattermost.com, பழைய Mattermost அமைப்புகள் பயன்படுத்தும்), அது எதுவும் அனுப்பாது, தொடக்கத்தில் எச்சரிக்கையை பதிவு செய்யும்.

புதிய சேவையகத்தில் புஷ் அறிவிப்பு சேவையகம் இல்லை, எனவே உங்கள் புஷ் ப்ராக்ஸியின் முகவரியை அமைக்கும் வரை அது புஷ் அறிவிப்புகளை அனுப்பாது. அந்த வரை, மொபைல் செயலி செயல்படும், ஆனால் அறிவிப்புகளைப் பெறாது.

புஷ் ப்ராக்ஸியை இயக்கு

புஷ் ப்ராக்ஸி push-proxy சேமிப்பகத்தில் உள்ளது. உங்கள் மொபைல் செயலியின் கட்டமைப்பை வெளியிடும் கணக்குகளில் இருந்து பெறப்படும் இரண்டு அங்கீகார விவரங்களை எவ்வாறு பெற வேண்டும் என்பதை அதன் README விளக்குகிறது:

  • அண்ட்ராய்டு: உங்கள் Android கட்டமைப்பு பயன்படுத்தும் Firebase திட்டத்தின் சேவை கணக்கு கோப்பு.
  • iOS: உங்கள் iOS கட்டமைப்பை வெளியிடும் Apple டெவலப்பர் கணக்கின் APNs அங்கீகார விசை (AuthKey_<KEY ID>.p8), அதன் விசை ID மற்றும் குழு ID உடன்.

அவற்றை புஷ் ப்ராக்ஸியின் அமைப்பு கோப்பு உடன் compose.yaml ஐ அருகில் வைக்கவும்:

push-proxy/
  config/antimatter-push-proxy.json
  certs/AuthKey_ABCDE12345.p8
  certs/firebase-service-account.json

push-proxy/config/antimatter-push-proxy.json, உங்கள் பண்டிள் அடையாளம் (bundle identifier), விசை ID மற்றும் குழு ID உடன்:

{
    "ListenAddress": ":8066",
    "ThrottlePerSec": 300,
    "ThrottleMemoryStoreSize": 50000,
    "ThrottleVaryByHeader": "X-Forwarded-For",
    "EnableMetrics": false,
    "SendTimeoutSec": 30,
    "RetryTimeoutSec": 8,
    "ApplePushSettings": [
        {
            "Type": "apple_rn",
            "ApplePushUseDevelopment": false,
            "ApplePushTopic": "chat.antimatter.app",
            "AppleAuthKeyFile": "./certs/AuthKey_ABCDE12345.p8",
            "AppleAuthKeyID": "ABCDE12345",
            "AppleTeamID": "FGHIJ67890"
        }
    ],
    "AndroidPushSettings": [
        {
            "Type": "android_rn",
            "ServiceFileLocation": "./certs/firebase-service-account.json"
        }
    ],
    "EnableConsoleLog": true,
    "EnableFileLog": false,
    "LogFormat": "plain",
    "LogLevel": "info"
}

ApplePushTopic உங்கள் கட்டமைப்பின் iOS பண்டிள் அடையாளம். ApplePushUseDevelopment Xcode மூலம் நிறுவப்பட்ட கட்டமைப்புகளுக்கு மட்டுமே true ஆக இருக்கும். அழைப்புகள் (calls) iPhones மூலம் VoIP புஷ்கள் மூலம் ஒலிக்கின்றன, அவை அதே விசையைப் பயன்படுத்துகின்றன, இங்கே மேலும் எதுவும் தேவையில்லை.

இதழில் compose கோப்பைக்கான ஒரு தயார் செய்யப்பட்ட சேர்க்கை உள்ளது: compose.push.example.yaml. இது வெளியிடப்பட்ட இமேஜை இயக்குகிறது: ghcr.io/antimatterchat/push-proxy:latest.

curl -fsSLO https://antimatter.chat/compose.push.example.yaml
docker compose -f compose.yaml -f compose.push.example.yaml --profile push up -d
docker compose -f compose.yaml -f compose.push.example.yaml logs push-proxy

தொடக்கத்தில், proxy-ன் log-ல் அது அமைத்த ஒவ்வொரு push target-ையும் பெயரிடும்; அதன் credentials-ஐ படிக்க முடியாதவற்றிற்கு error-ஐ log செய்யும். proxy எந்த port-ையும் வெளியிடாது; compose network மூலம் Antimatter மட்டுமே அதை அடைய முடியும்.

Docker இல்லாமல், push proxy-ன் .deb அல்லது .rpm package-ஐ நிறுவவும்: GIF சேவை மற்றும் push proxy packages பார்.

push proxy யார் அதை அழைக்கிறார்கள் என்பதை சரிபார்க்காது. அதை இணையத்தில் வெளியிட வேண்டாம். வேறு host-ல் இயங்கினால், அதை HTTPS-ன் பின்னால் வைத்து, யார் அதை அடைய முடியும் என்பதை கட்டுப்படுத்தவும்: notifications-ல் message உள்களம் இருக்கலாம்.

Antimatter-ஐ proxy-க்கு இணைக்க

அமைப்பு கன்சோல் › சூழல் › புஷ் அறிவிப்பு சேவையகம் இல், புஷ் அறிவிப்புகளை இயக்கு ஐ உங்கள் சொந்த push proxy மூலம் push அறிவிப்புகளை அனுப்பு என அமைத்து, புஷ் அறிவிப்பு சேவையகம் ஐ http://push-proxy:8066 (அல்லது வேறு இடத்தில் இயங்கினால் proxy-ன் HTTPS முகவரி) என அமைக்கவும். இந்த விருப்பம் மற்றும் முகவரி இல்லாமல் பக்கத்தை சேமிக்க முடியாது. புஷ் அறிவிப்புகளை அனுப்புவதை நிறுத்த, புஷ் அறிவிப்புகளை அனுப்ப வேண்டாம் ஐ தேர்ந்தெடுக்கவும். அல்லது antimatter சேவையில் variables மூலம்:

AM_EMAILSETTINGS_SENDPUSHNOTIFICATIONS: "true"
AM_EMAILSETTINGS_PUSHNOTIFICATIONSERVER: http://push-proxy:8066

சரிபார்க்க: மொபைல் ஆப் மூலம் உள்நுழைந்து, அதை பின்னணியில் வைத்து, மற்றொரு கணக்கு உங்களை குறிப்பிடட்டும். எதுவும் வரவில்லை என்றால், Antimatter-ன் log-ல் மற்றும் proxy-ன் log-ல் push ஐ தேடுங்கள்: device type தெரியாததா, key நிராகரிக்கப்பட்டதா, அல்லது device வேறு app build-க்கு சேர்ந்ததா என்பதை அவை சொல்லும்.

அறிவிப்புகளில் உள்ளவை

அமைப்பு கன்சோல் › தள அமைப்பு › அறிவிப்புகள் › புஷ் அறிவிப்பு உள்களம் (EmailSettings.PushNotificationContents):

விருப்பம்மதிப்பு
அனுப்பியவர் பெயர் மட்டுமുള്ള பொதுவான விளக்கம்generic_no_channel
அனுப்பியவர் மற்றும் சேனல் பெயர்கள் உள்ள பொதுவான விளக்கம்generic
அறிவிப்பு payload-ல் அனுப்பப்படும் முழு message உள்களம் (இயல்பு)full
பெறும்போது சேவையகத்திலிருந்து பெறப்படும் முழு message உள்களம்id_loaded

id_loaded உடன், proxy மூலம் செல்லும் அறிவிப்பில் Apple மற்றும் Google-ல் id மட்டுமே இருக்கும், app உங்கள் சேவையகத்திலிருந்து message-ஐ பெறும்: message உள்களம் அவற்றின் சேவைகள் வழியாக செல்லாது. messages தனியுரிமை கொண்டிருக்கும்போது இது சிறந்த தேர்வு.

பெரிய சேனல் அறிவிப்பு எல்லை, Push Notification Server பக்கத்தில், (TeamSettings.MaxNotificationsPerChannel, மூலபடி 1000) என்பது @here, @all மற்றும் @channel வேலை செய்ய ஒரு சேனலில் இருக்கக்கூடிய அதிகபட்ச உறுப்பினர் எண்ணிக்கை. பெரிய சேனல்களில், அந்த குறிப்புகளும் தட்டச்சு குறியீடுகளும் முடக்கப்படுகின்றன.
