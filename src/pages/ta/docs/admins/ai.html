AI அம்சங்கள்

அம்சம்அமைக்கப்பட்டதுமாதிரியின் வகைஇயல்பாக இயங்குமா
AI ஏஜென்கள்: ஒரு பாட்களுடன் உரையாடல், த்ரெட்கள் மற்றும் சேனல்களின் சுருக்கங்கள், உருவாக்குநரில் உதவிAgents செயலிஎந்தவொரு பெரிய மொழி மாதிரி (LLM) சேவைசெயலி இயங்குகிறது, ஆனால் நீங்கள் ஒரு சேவையைச் சேர்க்கும் வரை எதுவும் செய்யாது
அழைப்பு பதிவுகள் மற்றும் நேரடி வசனங்கள்Calls செயலிகுரல்-இருந்து-எழுத்து, OpenAI-உடன் இணைக்கக்கூடியதுஇல்லை
படித்துக் கேட்கசர்வர்எழுத்து-இருந்து-குரல், OpenAI-உடன் இணைக்கக்கூடியதுஇல்லை
சேனல்களின் தானியங்கி மொழிபெயர்ப்புசர்வர்LibreTranslate, OpenAI-உடன் இணைக்கக்கூடிய LLM, அல்லது Agents சேவைஇல்லை

"OpenAI-உடன் இணைக்கக்கூடியது" என்பது OpenAI-இன் அதே HTTP API-யை வழங்கும் சர்வரைக் குறிக்கிறது. நீங்களே இயக்கக்கூடிய பெரும்பாலான மாதிரி சர்வர்கள் இதைச் செய்கின்றன (உதாரணமாக Ollama, vLLM, llama.cpp-இன் சர்வர், அல்லது Whisper மற்றும் எழுத்து-இருந்து-குரல் சர்வர்கள்), மேலும் பல மேக வழங்குநர்களும் இதைச் செய்கின்றனர். இந்த அம்சங்களில் எதுவுக்கும் உரிமம் தேவையில்லை.

AI ஏஜென்கள்

Agents செயலி (id mattermost-ai) இயல்பாக இயங்குகிறது. அதை அமைப்பது இரண்டு படிகளைக் கொண்டுள்ளது: ஒரு சேவை (மாதிரி வழங்குநருடன் இணைப்பு) சேர்க்கவும், பின்னர் ஏஜென்கள் (ஒரு சேவையைப் பயன்படுத்தும் பாட்கள்) உருவாக்கவும்.

1. ஒரு சேவையைச் சேர்க்க

System Console › Plugins › Agents சென்று, AI Services கீழே, Add an AI Service ஐக் கிளிக் செய்யவும். Service type ஐத் தேர்ந்தெடுக்கவும்:

  • OpenAI Compatible: நீங்களே இயக்கும் மாதிரி சர்வருக்காக, அல்லது OpenAI-வகை API-யுள்ள எந்தவொரு வழங்குநருக்காக. API URL ஐ நிரப்பவும் (உதாரணமாக http://ollama:11434/v1 அல்லது http://vllm.internal:8000/v1), சர்வருக்கு தேவைப்பட்டால் மட்டுமே API Key ஐ நிரப்பவும். சர்வர் Chat Completions API-யை மட்டுமே ஆதரித்தால், Use Responses API ஐ அணைக்கவும்.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: ஹோஸ்ட்டு செய்யப்பட்ட வழங்குநர்கள். ஒவ்வொன்றும் அதன் API Key ஐத் தேவைப்படுகிறது (Bedrock: ஒரு AWS பகுதி மற்றும் அடையாளப்படுத்தல்கள் அல்லது IAM பங்கு; Vertex AI: ஒரு திட்டம், பகுதி மற்றும் சேவை கணக்கு; Azure: API URL-யும்).

பின்னர் இயல்பு நிலை மாதிரி (பிரவையர் அதன் மாதிரிகளை அறிவிக்க முடிந்தால் பட்டியல், இல்லையெனில் பெயரை உள்ளிடவும்) மற்றும், பிரவையர் அவற்றை அறிவிக்காதபோது உள்வரும் டோக்கன் எல்லை மற்றும் வெளியேறும் டோக்கன் எல்லை ஆகியவற்றை அமைக்கவும். இந்த சேவை தோல்வியடைந்தால் பிரிவு சேவை (Fallback Service) பொறுப்பேற்கும். சேமிக்கவும்.

சர்வர் இந்த கோரிக்கைகளை தானாகவே செய்கிறது, எனவே அது API-யை அடைய வேண்டும்: அதே compose திட்டத்தில் உள்ள மாதிரி சர்வர், உங்கள் நெட்வொர்க்கில் உள்ள சர்வர், அல்லது இணையத்தில் உள்ள சர்வர். வெளியேறும் கோரிக்கைகள் HTTP_PROXY மற்றும் HTTPS_PROXY மாறிகளை மதிப்பிடுகின்றன.

2. ஏஜென்களை உருவாக்குதல்

இணைய செயலியின் ஏஜென்கள் பக்கத்தில் ஏஜென்கள் உருவாக்கப்படுகின்றன: அதை பொருள் மெனுவிலிருந்து திறக்கவும், அல்லது ஏஜென்கள் பலகையின் ஏஜென் தேர்ந்தெடுப்பில் நிரவகி மூலம் திறக்கவும். அதன் முகவரி https://chat.example.com/plug/mattermost-ai/agents. ஒவ்வொரு ஏஜென்க்கும் காட்சிப் பெயர், ஏஜென் பயனர் பெயர் (மக்கள் அதை குறிப்பிடும் முறை), சேவை மற்றும் விருப்பத்திற்குரிய மாதிரி, தனிப்பயன் உத்திகள், மற்றும் விஷன் இயக்கு (படங்கள்) மற்றும் கருவிகள் இயக்கு ஆகியவற்றுக்கான சுவிட்ச்கள் உள்ளன. அதன் அணுகல் தாவலில், அதை எந்த சேனல்களில் பயன்படுத்தலாம் மற்றும் எந்த பயனர்கள் அதை பயன்படுத்தலாம் என்பதை வரையறுக்கலாம். அமைப்பு கன்சோலில் AI செயல்கள் கீழ், இயல்பு நிலை பாட் என்பது எதுவும் தேர்ந்தெடுக்கப்படாதபோது (உதாரணமாக அழைப்பு சுருக்கங்களுக்கு) பயன்படுத்தப்படும் ஏஜென்னை தேர்ந்தெடுக்கிறது.

இயல்பாக, ஒவ்வொரு பயனரும் நீங்கள் அமைத்த சேவைகளுடன் தங்கள் சொந்த ஏஜென்களை உருவாக்க முடியும். அதை நிர்வாகிகளுக்காக மட்டுமே வைத்திருக்க, அமைப்பு கன்சோல் › பயனர் மேலாண்மை › அனுமதிகள் இல் உறுப்பினர்களின் பங்கிலிருந்து சொந்த AI ஏஜென்களை நிரவகி அனுமதியை அகற்றவும்.

ஏஜென்கள் செயலியின் விருப்பத்திற்குரிய சிறப்பம்சங்கள்

  • உள்ளடக்க தேடல் (சோதனை, அணைக்கப்பட்டது): செய்திகளின் மீது உருவக தேடல். இதற்கு pgvector நீட்டிப்புடன் கூடிய PostgreSQL மற்றும் ஒரு உள்ளடக்க மாதிரி (OpenAI அல்லது OpenAI-உடன் இணைக்கக்கூடியது) தேவை. இது ஒவ்வொரு செய்தியையும் உள்ளடக்க மாதிரிக்கு அனுப்புகிறது, தனிப்பட்ட சேனல்கள் மற்றும் நேரடி செய்திகள் உட்பட.
  • இணைய தேடல் (அணைக்கப்பட்டது): ஏஜென்கள் Google, Brave அல்லது நீங்கள் இயக்கும் SearXNG சர்வரின் மூலம் இணையத்தை தேட அனுமதிக்கிறது.
  • தனித்துவமான கருவிகள்: அவற்றை வழங்கும் பிரவையர்களுடன், ஏஜென்கள் பிரவையரின் சொந்த இணைய தேடலை (புதிய ஏஜென்களுக்கு இயல்பாக இயக்கப்பட்டது, ஆதரவு இருந்தால்), இணையம் பெறுதல் மற்றும் குறியீட்டு இயக்கத்தைப் பயன்படுத்தலாம். இவை பிரவையரில் இயங்குகின்றன. ஏஜென் அடிப்படையில் அவற்றை அணைக்கவும்.
  • மாதிரி பின்னணி நெறிமுறை (MCP): கூடுதல் கருவிகளுக்காக, நீங்கள் நம்பும் MCP சர்வர்களுடன் ஏஜென்களை இணைக்கவும்.
  • பிழைச்சரி: மூலம் வெளியீடு (அணைக்கப்பட்டது, சர்வர் பதிவுகள் அல்லது OpenTelemetry முடிவுப்புள்ளி) மற்றும் டோக்கன் பயன்பாட்டு பதிவு இயக்கு, இது டோக்கன் எண்ணிக்கைகளை logs/agents/token_usage.log இல் எழுதுகிறது.

குரல்-இருந்து-எழுத்து: அழைப்பு பதிவுகள் மற்றும் வசனங்கள்

ஒலி-எழுத்து மாற்று சேவையாளர் OpenAI-உடன் இணைப்புள்ள /v1/audio/transcriptions முனைப்பு வழங்குபவராக இருப்படில், அழைப்புகளின் எழுத்துப்பதிவு நேரடி வசனங்களுடன் சாத்தியமாயிற்று. அமைப்பு அழைப்புகளும் குரலும் பகுதியில் உள்ளது. எழுத்துப்பதிவுகளை சுருக்கம் செய்க இயக்கப்படில், மூல ஏஜென்ட் ஒவ்வொரு எழுத்துப்பதிவின் சுருக்கத்தையும் பதிவு செய்கிறது.

எழுத்து-குரல் மாற்று: பேசிக் காட்டு

எழுத்து-குரல் மாற்று இயக்கப்படில், ஒவ்வொரு செய்தியின் மெனுவிலும் பேசிக் காட்டு உள்ளது: சேவையாளர் செய்தியின் எழுத்தை எழுத்து-குரல் மாற்று API-க்கு அனுப்பி, ஒலியை இயக்குகிறது. அமைப்புகள், அமைப்பு கன்சோல் › இணைப்புகள் › எழுத்து-குரல் மாற்று:

அமைப்புKey மற்றும் variableஎன்ன வைக்க வேண்டும்
செய்திகளை பேசிக் காட்டுTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (இயல்பாக இயக்கப்படவில்லை)
API அடிப்படை URLTextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URL/v1 வரை உள்ளடக்கிய அடிப்படை URL, எடுத்துக்காட்டாக http://tts.internal:8000/v1. சேவையாளர் அதன் /audio/speech முனையை அழைக்கிறது.
மாதிரிTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELAPI அதை அழைக்கும் மாதிரி, எடுத்துக்காட்டாக tts-1. தேவை.
குரல்TextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEமாதிரியின் குரல்களில் ஒன்று, அல்லது இயல்புக்கு காலியாக.
API விசைTextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYபெரர் டோக்கனாக அனுப்பப்படுகிறது. API-க்கு தேவையில்லை என்றால் காலியாக.

அனுப்புவதற்கு முன், சேவையாளர் குறியீட்டு தொகுதிகள், இணைப்புகள், எமோஜி குறியீடுகள் மற்றும் வடிவமைப்புகளை அகற்றி, அதிகபட்சம் 4000 எழுத்துக்களை வைத்திருக்கிறது. இது MP3 ஒலியை கோரி, நினைவகத்தில் கடைசி 64 முடிவுகளை வைத்திருக்கிறது, எனவே இரண்டு முறை படிக்கப்பட்ட செய்தி ஒரு முறை மட்டுமே அனுப்பப்படுகிறது.

தானியங்கு மொழிபெயர்ப்பு

தானியங்கு மொழிபெயர்ப்பு ஒரு சேனலின் செய்திகளை ஒவ்வொரு வாசகரின் சொந்த மொழியில் காட்டுகிறது. இதை அமைப்பு கன்சோல் › தள அமைப்பு › உள்கூறு மயமாக்கல் கீழ், தானியங்கு மொழிபெயர்ப்பு பகுதியில் அமைக்கவும்:

அமைப்புவிசைஇயல்பு
இயக்குAutoTranslationSettings.Enableஅணை
மொழிபெயர்ப்பு வழங்குநர்AutoTranslationSettings.Providerlibretranslate, openai ("OpenAI-உடன் இணைப்புள்ள API" எனக் காட்டப்படுகிறது) அல்லது agents (ஏஜெண்டுகள் செயலி சேவை)
அனுமதிக்கப்பட்ட மொழிகள்AutoTranslationSettings.TargetLanguagesen: செய்திகள் மொழிபெயர்க்கப்படும் மொழிகள்
மொழிபெயர்ப்பு நேரம் முடிவு (ms)AutoTranslationSettings.TimeoutMs5000
நேரடி செய்திகள் மற்றும் குழு செய்திகளில் தானியங்கு மொழிபெயர்ப்பை கட்டுப்படுத்துAutoTranslationSettings.RestrictDMAndGMஅணை

ஒவ்வொரு வழங்குநருக்கும் தனித்துவமான புலங்கள் உள்ளன:

  • LibreTranslate: LibreTranslate API முனைப்பு மற்றும் LibreTranslate API விசை (AutoTranslationSettings.LibreTranslate.URL, .APIKey). LibreTranslate சேவையாளரை உங்கள் சொந்த வலையமைப்பில் இயக்க முடியும்.
  • OpenAI-உடன் இணைப்புள்ள API: API அடிப்படை URL (/v1 வரை உள்ளடக்கியது; சேவையாளர் அதன் உரையாடல் நிறைவு முனையை பயன்படுத்துகிறது), மாதிரி மற்றும் API விசை (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). உள்ளூரில் இயக்கப்படும் சிறிய மொழிபெயர்ப்பு மாதிரி நன்றாக செயல்படுகிறது.
  • ஏஜெண்டுகள்: AI சேவை, ஏஜெண்டுகள் செயலியில் அமைக்கப்பட்ட சேவைகளில் ஒன்று.

இது இயக்கப்பட்ட பின், சேனல் நிர்வாகிகள் அதன் அமைப்புகளில் (தானியங்கி மொழிபெயர்ப்பு) மூலம் ஒரு சேனலுக்கு மொழிபெயர்ப்பை இயக்குவர், மேலும் ஒவ்வொரு உறுப்பினரும் சேனல் மெனுவில் (செய்திகளை மொழிபெயர்ப்பு) மூலம் அதை நிறுத்திக்கொள்ளலாம். நேரடி மற்றும் குழு செய்திகளில் எந்த உறுப்பினரும் அதை இயக்கலாம்; ஆனால், கட்டுப்பாடு இருந்தால், அங்கு மொழிபெயர்ப்பு கிடைக்காது. மொழிபெயர்க்கப்பட்ட செய்திகள் “மொழிபெயர்க்கப்பட்டது…” என்று, அசல் செய்தியை இணைக்கும் ஒரு இணைப்புடன் காட்டப்படும்.

கோட், இணைப்புகள், குறிப்புகள் மற்றும் எமோஜிகள், உரை அனுப்பப்படும் முன் தற்காலிக இடப்பெயர்ச்சிகளாக மாற்றப்பட்டு, பின்னர் மீண்டும் இடப்படுகின்றன.

எந்த தரவு எங்கு செல்கிறது

அம்சம்என்ன அனுப்பப்படுகிறதுஎங்கு
ஏஜெண்டுகள்கோரிக்கை, அது பற்றிய த்ரெட் அல்லது சேனலின் செய்திகள், ஏஜென்டின் உத்திகள், கருவி முடிவுகள், காட்சி இயக்கப்பட்டிருந்தால் படங்கள், கேட்கும் பயனரின் பெயர், பயனர் பெயர், பதவி மற்றும் மொழிசேவையின் API
எம்பெடிங் தேடல்ஒவ்வொரு செய்தியும் (பாட்களின் மற்றும் அமைப்பு செய்திகள் தவிர)எம்பெடிங் API
உள்நாட்டு கருவிகள் மற்றும் இணைய தேடல்தேடல் விசாரணைகள், பெற வேண்டிய பக்கங்கள், கோட்வழங்குநர், அல்லது நீங்கள் தேர்ந்தெடுத்த தேடல் இயந்திரம்
அழைப்பு எழுத்துப்பதிவுஅது இயங்கும்போது பேசும் ஒவ்வொருவரின் குரல்குரல்-இருந்து-எழுத்து API
படித்துக் கேட்கபடிக்கப்படும் செய்தியின் உரைஎழுத்து-இருந்து-குரல் API
மொழிபெயர்ப்புமொழிபெயர்க்கப்பட்ட சேனல்களில் உள்ள செய்திகளின் உரைLibreTranslate, LLM API, அல்லது Agents சேவை

இவை அனைத்தையும் உங்கள் நெட்வொர்க்கில் வைத்திருக்க, ஒவ்வொரு சேவையையும் நீங்களே இயக்கும் சர்வர்களுக்கு இணைக்கவும். மேக வழங்குநரைப் பயன்படுத்தினால், அதன் தரவு வைப்பு விதிகளைச் சரிபார்க்கவும், மேலும் உங்கள் பயனர்களுக்கு எந்த சேவைகள் அவர்களின் செய்திகளை வெளியே அனுப்புகின்றன என்பதைத் தெரிவிக்கவும்.

AI-ஐ நிறுத்துதல்

ஒரே ஒரு சுவிட்ச் இல்லை: ஒவ்வொரு சேவையும் தனியாக இயக்கப்படுகிறது.

  • ஏஜென்கள்: அமைப்பு கன்சோல் › பிளகின்கள் › பிளகின் மேலாண்மை இல் Agents செயலியை முடக்கவும். இது அழைப்பு சுருக்கங்களையும் Agents மொழிபெயர்ப்பு வழங்குநரையும் அகற்றும்.
  • எழுத்துப்பதிவு மற்றும் வசனங்கள்: AM_CALLS_ENABLE_TRANSCRIPTIONS=false மற்றும் AM_CALLS_ENABLE_LIVE_CAPTIONS=false (இயல்புநிலை).
  • படிக்க: செய்திகளை உரையாடல் மூலம் படிக்க ஐ அணைக்கவும் (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, இயல்புநிலை).
  • மொழிபெயர்ப்பு: தானியங்கு மொழிபெயர்ப்பை அணைக்கவும் (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, இயல்புநிலை).

Agents செயலியை முடக்குவது மற்ற மூன்று சேவைகளை நிறுத்தாது: அவை தங்கள் சொந்த API-களை நேரடியாக அழைக்கின்றன.
