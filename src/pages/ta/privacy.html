தனியுரிமைக் கொள்கை

கடைசியாகப் புதுப்பிக்கப்பட்டது: 11 அக்டோபர் 2026. இந்தத் தமிழ்ப் பதிப்பு உங்கள் வசதிக்காக வழங்கப்படும் மொழிபெயர்ப்பு மட்டுமே; இரண்டுக்கும் இடையே வேறுபாடு இருந்தால் ஆங்கிலப் பதிப்பே செல்லுபடியாகும்.

இந்தப் பக்கம் இரண்டு விஷயங்களை உள்ளடக்குகிறது: நிறுவனங்கள் தங்கள் சொந்த சர்வர்களில் இயக்கும் Antimatter மென்பொருள், மற்றும் இந்த இணையதளமான antimatter.chat.

Antimatter மென்பொருள்

Antimatter என்பது சுயமாக ஹோஸ்ட் செய்யப்படும் மென்பொருள். நீங்கள் ஒரு Antimatter சர்வரைப் பயன்படுத்தும்போது, எந்தத் தரவு வைக்கப்படும், எவ்வளவு காலம், யார் அதை அணுகலாம் என்பதை அந்த சர்வரை இயக்கும் நிறுவனமே தீர்மானிக்கிறது. உங்கள் சர்வர், கணக்கு, செய்திகள் எதையும் Antimatter திட்டம் அணுக முடியாது. ஒரு குறிப்பிட்ட சர்வரில் உள்ள உங்கள் தரவு பற்றிய கேள்விகளுக்கு அதன் நிர்வாகிகளைத் தொடர்புகொள்ளுங்கள்; அவர்களின் சொந்தத் தனியுரிமைக் கொள்கையே அங்கு பொருந்தும்.

மென்பொருள் தானாகச் செய்பவை:

  • டெலிமெட்ரி இல்லை. சர்வர், பயன்பாட்டுப் புள்ளிவிவரங்கள், கண்டறிதல் தரவு அல்லது வேறு எந்தத் தரவையும் Antimatter திட்டத்துக்கோ மூன்றாம் தரப்பினருக்கோ அனுப்புவதில்லை.
  • நிர்வாகி இயக்கும் அம்சங்களுக்காக மட்டுமே வெளி இணைப்புகள், அவர் உள்ளமைக்கும் சேவைகளுக்கு மட்டும்: எடுத்துக்காட்டாக புஷ் அறிவிப்புச் சேவை, செய்திகளில் இடப்படும் இணையதளங்களின் இணைப்பு முன்னோட்டங்கள், GIF வழங்குநர், மின்னஞ்சல் சர்வர், ஒற்றை உள்நுழைவுக்கான அடையாள வழங்குநர், அல்லது AI, பேச்சு, மொழிபெயர்ப்பு மாடல்கள்.
  • AI அம்சங்கள் நிர்வாகி தேர்ந்தெடுக்கும் மாடல்களைப் பயன்படுத்துகின்றன. அவை மூன்றாம் தரப்பினரால் ஹோஸ்ட் செய்யப்பட்டிருந்தால், அவற்றுக்கு அனுப்பப்படுபவை (மாற்றி எழுத வேண்டிய ஒரு செய்தி, சுருக்க வேண்டிய ஓர் உரையாடல், எழுத்தாக்கப்படும் அழைப்பின் ஒலி) அந்த வழங்குநரிடம் செல்கின்றன. எதுவும் தங்கள் நெட்வொர்க்கை விட்டு வெளியே போகாமல் இருக்க, நிர்வாகிகள் தாங்களே ஹோஸ்ட் செய்யும் மாடல்களைப் பயன்படுத்தலாம்.

இந்த இணையதளம்

  • antimatter.chat என்பது GitHub Pages-இல் ஹோஸ்ட் செய்யப்படும் ஒரு நிலையான (static) இணையதளம்.
  • இது எந்தக் குக்கீயையும் அமைப்பதில்லை; பகுப்பாய்வுக் கருவிகள், டிராக்கர்கள், விளம்பரங்கள் எதையும் பயன்படுத்துவதில்லை. இதன் எழுத்துருக்களும் படங்களும் இந்தத் தளத்திலிருந்தே வழங்கப்படுகின்றன; எனவே நீங்கள் இதைப் படிக்கும்போது உங்கள் உலாவி வேறு எந்த இணையதளத்துக்கும் கோரிக்கை அனுப்புவதில்லை.
  • எந்த வலை ஹோஸ்டையும் போலவே, பக்கங்களை வழங்குவதற்காக உங்கள் IP முகவரியையும் நீங்கள் கோரும் பக்கங்களையும் GitHub பெறுகிறது. GitHub தனியுரிமை அறிக்கையைப் பாருங்கள்.
  • GitHub-இல் நீங்கள் ஓர் issue திறந்தாலோ பங்களித்தாலோ, அங்கு நீங்கள் இடுபவை பொதுவில் தெரியும்; அவற்றை GitHub தனது சொந்த விதிமுறைகளின்படி கையாளும்.

தொடர்புக்கு

இந்தக் கொள்கை பற்றிய கேள்விகளுக்கு, இணையதளத்தின் களஞ்சியத்தில் ஓர் issue திறங்கள்.

இந்தக் கொள்கையை நாங்கள் புதுப்பிக்கக்கூடும்; இது கடைசியாக எப்போது மாற்றப்பட்டது என்பதை மேலே உள்ள தேதி காட்டும்.
