Sovelluksen toimintaperiaate

  • Palvelinosa on Go-ohjelma. Palvelin käynnistää sen erillisenä prosessina ja kommunikoi sen kanssa RPC:n kautta: se kutsuu sovelluksen koukuja (viesti on postitumassa, komento suoritettiin…) ja sovellus kutsuu palvelimen liitännäis-API:ta (luo viesti, lue käyttäjä, tallenna dataa…). Se voi myös palvella HTTP-reittejä polulla /plugins/<app id>/.
  • Web-sovellusosa on JavaScript-paketti, joka ladataan selaimeen web-sovelluksen mukana. Se rekisteröi React-komponentit ja takaisinkutsut rekisteriin: valikon painike, paneeli, tapa piirtää viestityyppi.
  • Molemmat osat ovat valinnaisia. Sovellus asennetaan .tar.gz-pakkina, ja järjestelmän ylläpitäjät voivat ottaa sen käyttöön, poistaa sen käytöstä ja määrittää sen asetukset.
Palvelinosa ajetaan täydellä pääsyoikeudella palvelimen dataan. Kohtele sovellusta kuten koodia, jonka deployaat palvelimelle.

Antimatter ajaa Mattermostille kirjoitettuja sovelluksia ja toisinpäin, niin kauan kuin sovellus käyttää vain koukuja, joita molemmilla on. Katso Vain Antimatterin omaat koukut.

Paketin rakenne

Ei ole erillistä aloituspohjaa: aloita pienestä mukana toimitetusta sovelluksesta, kuten antimatter-plugin-polls tai antimatter-plugin-todo, ja muuta sen ID:tä ja koodia. Kyselyt-sovellus on rakennettu tällä tavalla:

antimatter-plugin-polls/
├── plugin.json            the manifest
├── Makefile               build, test, bundle, deploy
├── build/                 the manifest and pluginctl helper tools (Go), setup.mk
├── assets/icon.svg        files shipped with the bundle
├── go.mod
├── server/
│   ├── main.go            plugin.ClientMain(&Plugin{})
│   ├── plugin.go          the Plugin type, OnActivate, ServeHTTP
│   ├── manifest.go        generated from plugin.json
│   ├── api.go, command.go, hooks.go, store.go …
│   └── dist/              compiled binaries, one per platform
└── webapp/
    ├── package.json, webpack.config.js, tsconfig.json
    ├── i18n/              en.json and one file per language
    ├── src/index.tsx      registers the app with the web app

    └── dist/main.js       the bundle

  • id: ainutlaatuinen ja pysyvä; käänteinen verkkotunnus on yleistä. Se nimetää reitit, tallennetut asetukset ja WebSocket-tapahtumat.
  • version: semanttinen versio. Mukana toimitetut sovellukset jättävät sen pois plugin.json-tiedostosta; niiden rakennustyökalu hakee sen uusimmasta v*-git-tagista.

  • settings_schema: sovelluksen asetussivu Järjestelmäkonsolissa (ks. Asetukset).

make apply kopioi manifestin tiedostoihin server/manifest.go ja webapp/src/manifest.ts; make manifest-check validoi sen.

Palvelinosa

Palvelinosa tuottaa saman Go-moduulin kuin Mattermost-sovellukset, github.com/mattermost/mattermost/server/public, Go-moduuliproksista. Sen main käynnistää vain sovelluksen:

package main

import "github.com/mattermost/mattermost/server/public/plugin"

func main() {
	plugin.ClientMain(&Plugin{})
}

Plugin-tyyppi upottaa plugin.MattermostPlugin-tyypin, joka antaa sille p.API:n, ja toteuttaa tarvitsemansa hookit:

type Plugin struct {
	plugin.MattermostPlugin
	router *mux.Router
}

func (p *Plugin) OnActivate() error {
	p.router = p.newRouter()
	return p.API.RegisterCommand(&model.Command{
		Trigger:          "weather",
		AutoComplete:     true,
		AutoCompleteDesc: "Show the forecast",
		AutoCompleteHint: "[city]",
	})
}

func (p *Plugin) ExecuteCommand(c *plugin.Context, args *model.CommandArgs) (*model.CommandResponse, *model.AppError) {
	city := strings.TrimSpace(strings.TrimPrefix(args.Command, "/weather"))
	return &model.CommandResponse{
		ResponseType: model.CommandResponseTypeEphemeral,
		Text:         "Forecast for " + city + ": sunny",
	}, nil
}

func (p *Plugin) ServeHTTP(c *plugin.Context, w http.ResponseWriter, r *http.Request) {
	p.router.ServeHTTP(w, r)
}

Yleiset hookit

HookKun se ajetaan
OnActivate, OnDeactivateKun sovellus otetaan käyttöön tai poistetaan käytöstä, sekä kun palvelin käynnistyy ja pysähtyy. Rekisteröi komennot ja botit OnActivate-hookissa.
OnConfigurationChangeKun sen asetukset muuttuvat; lue ne komennolla p.API.LoadPluginConfiguration(&cfg).
ServeHTTPPyyntö osoitteeseen /plugins/<app id>/…. Palvelin asettaa Mattermost-User-Id-otsikon, kun pyyntö tulee kirjautuneelta käyttäjältä; hylkää pyynnöt, joissa ei tätä ole, ellei ne ole tarkoitettu julkisiksi.
ExecuteCommandSovelluksen rekisteröimä komento suoritettiin.
MessageWillBePosted, MessageWillBeUpdatedEnnen viestin tallentamista: palauta muuttunut viesti tai syy hylkäyselle.
MessageHasBeenPosted, MessageHasBeenUpdated, MessageHasBeenDeletedTapahtuman jälkeen, sivuvaikutuksia varten.
ReactionHasBeenAdded, ReactionHasBeenRemovedReaktiot.
UserHasJoinedChannel, UserHasLeftChannel, UserHasJoinedTeam, UserHasLeftTeam, ChannelHasBeenCreatedJäsenyyden ja kanavien muutokset. Tiimi on yhteisö.
FileWillBeUploadedEnnen tiedoston tallentamista: muuta tai hylkää se.
OnPluginClusterEventViesti samasta sovelluksesta toisesta klusterin palvelimesta.

Täydellinen luettelo, täydellisillä allekirjoituksilla, on tiedostossa server/public/plugin/hooks.go; API on tiedostossa server/public/plugin/api.go. pluginapi-paketti (server/public/pluginapi) kääsee API:n ystävällisemmiksi apurutiineiksi.

Hyödylliset API-kutsut

  • CreatePost, UpdatePost, SendEphemeralPost: julkaise sovelluksen bottina tai käyttäjänä.
  • EnsureBotUser(&model.Bot{Username, DisplayName}): luo sovelluksen botti kerran ja hae sen ID.
  • PublishWebSocketEvent("poll_updated", payload, &model.WebsocketBroadcast{ChannelId: id}): lähetä tapahtuma web-sovellukselle. Se saapuu nimellä custom_<app id>_poll_updated.
  • OpenInteractiveDialog: avaa dialogi.
  • LogInfo, LogError ja vastaavat: kirjoita palvelinlokiin, merkitty sovelluksen ID:llä.
  • GetUser, GetChannel, HasPermissionToChannel: tarkista, kuka saa tehdä mitä, ennen kuin toimit käyttäjän puolesta.

Sovellus ajetaan jokaisella klusterin palvelimella. Säilytä tila avain-arvo-tallennuksessa tai tietokannassa, ei vain muistissa.

Tietojen tallentaminen

Jokaisella sovelluksella on oma avain-arvo-tallennus palvelimen tietokannassa:

  • KVSet(key, value), KVGet(key), KVDelete(key): arvot ovat tavuja, tyypillisesti JSON-muodossa. Avaimet ovat enintään 150 merkkiä.
  • KVSetWithExpiry(key, value, seconds): arvo poistuu tämän ajan jälkeen.
  • KVCompareAndSet(key, old, new) ja KVSetWithOptions -parametrilla Atomic: turvalliset päivitykset, kun useat pyynnöt tai palvelimet kirjoittavat samaa avainta. Polls-tiedote tallentaa jokaisen äänen tällä tavalla ja yrittää uudelleen konfliktin tapauksessa.
  • KVList(page, perPage): avaimet sivulta toiselle.

Web-sovelluksen osa

Paketti rekisteröi luokan metodilla window.registerPlugin. Sen initialize-metodi saa rekisterin ja Redux-tallennuksen:

import manifest from './manifest';

class Plugin {
    initialize(registry, store) {
        registry.registerTranslations((locale) => translationsFor(locale));
        registry.registerPostTypeComponent('custom_poll', PollPost);
        registry.registerWebSocketEventHandler(`custom_${manifest.id}_poll_updated`, (msg) => {
            store.dispatch(pollUpdated(JSON.parse(msg.data.poll)));
        });
        registry.registerReconnectHandler(() => store.dispatch(reloadPolls()));
    }
}

window.registerPlugin(manifest.id, new Plugin());
  • Yhteiset kirjastot. Web-sovellus tarjoaa Reactin, ReactDOM, Redux, React Reduxin ja React Intl:in: listaa ne webpackin externals-osassa (React, ReactDOM, Redux, ReactRedux, ReactIntl) sen sijaan, että pakettaisit omat kopiosi. Katso Polls-tiedotteen webpack.config.js.
  • Palvelinosan kutsuminen. Hae osoitteesta ${window.basename}/plugins/<app id>/… vaihtoehdot, jotka saat metodista Client4.getOptions() (moduulista mattermost-redux/client): ne sisältävät otsakkeet, joita palvelin tarvitsee hyväksyäkseen pyynnön selaimesta.
  • Oma tilasi. registerReducer lisää reducerin, joka tallennetaan osoitteeseen state['plugins-<app id>'].
  • Tyyppitiedot. Antimatterin lisärekisterimetodit eivät sisälly Mattermostin julkaisemiin tyyppitietoihin: Polls-tiedote määrittelee käyttämänsä rekisterin tiedostossa webapp/src/types/host.ts.

Rekisterin metodit ja niiden parametrit on dokumentoitu koodissa, tiedostoissa webapp/fusion/src/plugins/registry.ts (Fusion) ja webapp/channels/src/plugins/registry.ts (klassinen).

Fusion-käyttöliittymän tuki

Antimatterilla on kaksi web-käyttöliittymää: Fusion, joka on oletus, ja klassinen. Molemmat lataavat samat sovelluspaketit ja käyttävät samaa rekisteriä, mutta Fusion piirtää monia asioita itse ja sijoittaa lisäosien komponentit omalla tavallaan. Testaa sovelluksesi molemmissa.

Käyttöliittymän tunnistaminen

Ennen kuin mikään sovellus latautuu, molemmat käyttöliittymät asettavat window.antimatterWebUI-muuttujan arvoksi 'fusion' tai 'classic', ja saman arvon sivun juurelementtiin ominaisuutena data-am-web-ui. Mattermostissa kumpikaan ei ole asetettu.

export function isFusionUI(): boolean {
    return window.antimatterWebUI === 'fusion' || document.documentElement.dataset.amWebUi === 'fusion';
}

Sisällytetyt sovellukset käyttävät tätä piirtääkseen eri tavalla. Kyselyt piirtää kyselykorttinsa ja luontailmakkuunsa Fusionin tyyliin ja avaa oman /poll-komenton dialogin Fusionissa. Puhelut ja äänikanavat jättävät sivupalkin ja toast-komponentit pois, koska Fusion korvaa ne omalla puhelintajallaan. Agentit-sovellutus sijoittaa tekoälytoimintonsa viestimenun alamenuun, ei viestien hover-työkalupalkkiin. Fusionin omat CSS-luokat (etuliitteellä am-) ja dialogikerros (am-layer-elementti) ovat se, mitä nämä sovellukset käyttävät rajapinnan mukauttamiseen; ne eivät ole dokumentoitu, vakaa API.

Mitä Fusion ei näytä tai aja

  • registerPostDropdownMenuComponent (viestin valikon komponentti), registerPostCardTypeComponent (viestin kortti oikeanpuoleisessa paneelissa) ja registerProductSwitcherMenuItem eivät näy Fusionin päänäkymissä. Käytä registerPostDropdownMenuAction:ia ensimmäisen sijaan.
  • registerMessageWillBeUpdatedHook ei aja, kun viestiä muokataan Fusionissa. Tarkista muokkaukset palvelimella MessageWillBeUpdated-koukulla.
  • registerActionAfterChannelCreation suoritetaan vain klassisesta kanavan luontivalintaikkunasta, jonka Fusion avaa Lisää vaihtoehtoja… -kohdasta Luo kanava -valintaikkunassaan.
  • Sovelluspalkin komponentit näkyvät riippumatta supportedProductIds-arvosta.
  • Reitit, jotka on rekisteröity metodien registerNeedsTeamRoute ja registerCustomRoute kautta, säilyttävät klassisen sivukehyksen, kuten tuotteet.

Koukut, joita vain Antimatterissa on

Näitä rekisteröintimetodeja ei ole Mattermostissa. Tarkista, että metodi on olemassa ennen kutsua, jotta sovellus toimii sielläkin:

if (typeof registry.registerComposerMenuItem === 'function') {
    registry.registerComposerMenuItem({
        text: 'Create a poll',
        icon: <i className='icon icon-chart-bar'/>,
        fusionIcon: 'poll',
        action: ({channelId, rootId}) => openPollCreation(channelId, rootId),
    });
} else {
    registry.registerChannelHeaderButtonAction(icon, (channel) => openPollCreation(channel.id), 'Create a poll', 'Create a poll');
}
MetodiMitä se lisää
registerComposerMenuItem({text, icon, fusionIcon, action, shouldRender})Kohta viestikentän +-valikossa, molemmissa käyttöliittymissä. action saa parametrina {channelId, rootId}.
registerEmojiPickerTab({id, label, icon, fusionIcon, order, component, shouldRender, replacesGifPicker})Viestiruudun emojivalitsimen välilehti, kuten GIFit tai tarrat. Fusionissa välilehdet, joiden order-arvo on alle 10, tulevat Emoji-välilehden eteen. Komponentti saa parametreina channelId, rootId, filter, onFilterChange, onSelectDone, insertText ja isFusion.
registerChannelViewPanel({matcher, component})Paneeli kanavan otsikon ja viestien välillä, kanaville, jotka matcher(state, channel) valitsee. Se voi piilottaa viestit ja kirjoitusruudun (setMessagesVisible), kuten äänikanavat tekevät.
registerSidebarChannelFooterComponent(component)Rivi kanavan alla sivupalkissa, kuten puhelun osallistujat. Se saa parametrikseen channel.
registerIntegrationsOption({title, description, fusionIcon, action, shouldRender})Vain Fusionissa: kohde Integraatiot -sivuilla, mukautettujen emojien vieressä. GIF-sovellus lisää sinne mukautetut GIF-kuvaansa ja tarransa.

fusionIcon nimittää Fusionin ikoni-setin ikonia (esimerkiksi poll, sticker, calendar tai image; ks. webapp/fusion/src/fusion/components/icon). Fusion näyttää sen icon-ikonin sijaan, jotta kohde vastaa muita.

Asetukset

settings_schema -määritelmä plugin.json -tiedostossa kuvaa sovelluksen sivua Järjestelmäkonsoli › Liiteohjelmat -osiossa:

"settings_schema": {
  "header": "Forecasts come from the weather service below.",
  "settings": [
    {"key": "ServiceURL", "display_name": "Service URL", "type": "text", "default": "https://api.example.com"},
    {"key": "Units", "display_name": "Units", "type": "dropdown", "default": "metric",
     "options": [{"display_name": "Celsius", "value": "metric"}, {"display_name": "Fahrenheit", "value": "imperial"}]},
    {"key": "EnableAlerts", "display_name": "Severe weather alerts", "type": "bool", "default": false,
     "help_text": "Post alerts in the channels that follow a city."}
  ]
}

Asetustyypit: bool, text, longtext, number, dropdown, radio, generated (satunnainen salaisuus), username ja custom (piirretään komponentilla, jonka web-sovelluksen osa rekisteröi registerAdminConsoleCustomSetting -funktiolla). Asetukset voidaan ryhmitellä sections -ryhmiin.

Palvelinosa lukee ne rakenteeseen, jonka kentät vastaavat avaimia:

type configuration struct {
	ServiceURL   string
	Units        string
	EnableAlerts bool
}

func (p *Plugin) OnConfigurationChange() error {
	var cfg configuration
	if err := p.API.LoadPluginConfiguration(&cfg); err != nil {
		return err
	}
	p.setConfiguration(&cfg)
	return nil
}

Ylläpitäjät voivat myös asettaa ne asetustiedostoon kohdassa PluginSettings.Plugins.<app id>, avaimet pienin kirjaimin (ks. ylläpitäjän opas).

Käännökset

Antimatter on käännetty 37 kielelle, ja mukana toimitetut sovellukset ovat käännettyjä. Web-sovelluksen osa tekee sen näin:

  1. Kirjoita jokainen merkkijono React Intl -kirjastolla, ID:llä ja englanninkielisellä tekstillä: <FormattedMessage id='polls.create' defaultMessage='Create a poll'/> tai defineMessages. Lisää ID:hin etuliiteksi sovelluksesi nimi.
  2. Poista englanninkieliset merkkijonot tiedostoon webapp/i18n/en.json (mukana toimitetut sovellukset käyttävät formatjs extract -työkalua).
  3. Lisää yksi tiedosto per kieli sen viereen, samoin ID:llä: fr.json, de.json, pt-BR.json, zh-CN.json…
  4. Anna ne webbisovellukselle, joka kysyy käyttäjän kieltä: 
    import fr from '../i18n/fr.json';
import ptBR from '../i18n/pt-BR.json';

const catalogs = {fr, 'pt-BR': ptBR};

export function translationsFor(locale) {
    return catalogs[locale] || catalogs[locale.split('-')[0]] || {};
}

registry.registerTranslations(translationsFor);

Puuttuva merkkijono palautuu englanninkieliseen defaultMessage-arvoon. Palvelinpuolen lähettämille merkkijonoille (komentovastaukset, bottiviestit) pluginapi/i18n-paketti lukee pakettiin sisältyvät käännöstiedostot (esimerkiksi assets/i18n) ja antaa kääntäjän kullekin käyttäjälle hänen kielellään.

Asenna paketti käsin

  • Järjestelmäylläpitäjä sallii lataukset asetuksella AM_PLUGINSETTINGS_ENABLEUPLOADS=true (oletuksena pois käytöstä; Järjestelmäkonsolissa ei ole kytkintä).
  • Sitten Järjestelmäkonsoli › Liiteohjelmat › Liiteohjelmien hallinta › Lähetä liiteohjelma, tai amctl plugin add weather.tar.gz ja sen jälkeen amctl plugin enable com.example.weather.
  • Jos palvelimella on Vaadi lisäosan allekirjoitusta -asetus käytössä, se hyväksyy vain luotetulla avaimella allekirjoitetut paketit; ks. Muiden sovellusten asennus.
Nopeita kehitysiteraatiosia kehityspalvelimelle varten aseta palvelimelle AM_SERVICESETTINGS_ENABLEDEVELOPER=true: virheet sisältävät silloin tarkemmat tiedot. Pakettien Makefilet kääntävät palvelinpuolen vain sille alustalle, jolla MM_SERVICESETTINGS_ENABLEDEVELOPER on määritetty shellissäsi.
