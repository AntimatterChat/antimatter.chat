Help

Help and support

Antimatter is a community project. Here is where to find answers, and how to tell us about a problem.

Using Antimatter

  • In the app, the help menu (? in the app bar) has the user guide, keyboard shortcuts and help on message formatting and slash commands.
  • Until Antimatter has its own manual, the Mattermost documentation covers most server settings and administration tasks.
  • Your server's administrators can help with accounts, communities and settings.

Report a problem

Found a bug, or something that doesn't work as you'd expect? Open an issue on GitHub, with the version (shown in About in the app), what you did, what you expected and what happened instead:

  • The server and web app: AntimatterChat/antimatter issues
  • An app such as notes, whiteboards or calls: the issues of its repository on github.com/AntimatterChat
  • Translations: an issue on the server repository, naming the language and the string

Please search the existing issues first, and leave out any personal or confidential information.

Report a security vulnerability

Please don't report security vulnerabilities in public issues. Follow the security policy of the repository, which explains how to report one privately. We'll acknowledge the report, work on a fix, and credit you if you wish.

Commercial support

Antimatter has no paid support plans. If your organisation needs support with service levels, look for a company that supports self-hosted chat servers.
