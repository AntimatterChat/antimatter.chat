O que compõe uma instalação

O Antimatter é uma aplicação de chat de equipa auto-hospedada, um fork do Mattermost. Uma instalação completa tem as seguintes partes. Apenas as três primeiras são obrigatórias.

ParteO que fazObrigatório
O servidor AntimatterUm programa em Go (antimatter) que serve a aplicação web, a API e os websockets na porta 8065, executa as aplicações integradas (plugins) e transporta a media das chamadas na porta 8443. A ferramenta de linha de comandos amctl gerencia-o.sim
PostgreSQLA base de dados: mensagens, utilizadores, comunidades e, na configuração recomendada, a configuração do servidor. Versão 15 ou mais recente.sim
Armazenamento de ficheirosFicheiros, imagens e aplicações instaladas: um serviço compatível com S3 (o ficheiro compose executa o RustFS) ou um diretório local.sim
Um proxy reversoHTTPS à frente do servidor: o perfil Caddy do ficheiro compose, ou o seu próprio nginx.para produção
O serviço de GIF (gifs-server)GIFs e figurinhas para o seletor de GIFs, a partir do seu próprio catálogo. Comunica através da API do Tenor.não
Um proxy de notificações pushEncaminha notificações para a aplicação móvel através da Apple e do Google.para notificações móveis
rtcd, um servidor TURNUm servidor de media separado para muitas chamadas, e um retransmissor para pessoas atrás de firewalls restritivos.não
Pontos de terminação de IAOs modelos por trás da reescrita, resumos, tradução, leitura em voz alta, agentes de IA e transcrição de chamadas do compositor, adicionados como ligações de modelos: um provedor de nuvem ou servidores que você executa.não

O Antimatter não tem licença nem edição paga: o início de sessão único, LDAP, alta disponibilidade, exportações de conformidade, retenção de dados e as outras funcionalidades que o Mattermost reserva para os seus planos pagos estão todas incluídas.

Requisitos

  • Um servidor Linux, amd64 ou arm64, com 2 núcleos de CPU e 4 GB de memória ou mais para algumas centenas de pessoas, e espaço em disco para os ficheiros que as pessoas carregam.
  • Docker Engine com o plugin Compose (docker compose), para a instalação recomendada. Ou, para os pacotes, um servidor compatível com Debian, Ubuntu, Fedora ou RHEL com systemd.
  • Para produção: um nome de domínio que aponte para o servidor, e as portas 80 e 443 abertas para HTTPS.
  • Para chamadas: a porta 8443, UDP e TCP, acessível pelas pessoas que fazem as chamadas.
  • Para email: um servidor SMTP através do qual o Antimatter possa enviar.

Início rápido

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)
EOF
docker compose up -d

Depois, abra o URL do site e crie a sua conta: a primeira conta torna-se o administrador do sistema. Instalação explica cada passo e as outras formas de instalação.

Neste guia

  • Instalação: Docker Compose, as imagens, o primeiro administrador, os pacotes .deb e .rpm, o arquivo de lançamento.
  • Configuração: definições na base de dados ou num ficheiro, variáveis de ambiente AM_, a Consola do sistema, amctl, registos.
  • Domínio e HTTPS: o URL do site, Caddy, nginx, endereços dos clientes.
  • Chamadas e voz: portas, NAT, TURN, rtcd, transcrição e legendas.
  • E-mail e notificações push: SMTP, o proxy de notificações push e a aplicação móvel.
  • Aplicações incluídas: quais as aplicações ativas, as respetivas definições, a instalação de outras.
  • IA: ligações de modelos, os recursos de IA integrados, agentes, fala e tradução, a chave de criptografia e para onde vão os dados.
  • Início de sessão e contas: registo, palavras-passe, MFA, autenticação única, LDAP, convidados, sessões.
  • Cópias de segurança e atualizações: cópia de segurança, restauro, atualização, migração a partir do Mattermost.
  • Operações: monitorização, escalabilidade, retenção de dados, conformidade, resolução de problemas.
  • Segurança: lista de verificação de reforço e ligações externas.
  • Implantação da aplicação de desktop: o MSI, Group Policy e Intune, perfis do macOS e o ficheiro de política do Linux.

Gere uma comunidade em vez de um servidor (canais, papéis, moderação)? Consulte Gestão de uma comunidade. A criar integrações? Consulte Desenvolvimento no Antimatter.

A sua primeira hora

  1. Instale e crie de imediato a conta de administrador.
  2. Coloque o servidor atrás de HTTPS no seu próprio domínio.
  3. Configure o SMTP e envie um e-mail de teste.
  4. Abra a porta das chamadas. Para uma empresa, defina o tipo de novas comunidades como Local de trabalho, para que as chamadas estejam ativas nos canais.
  5. Decida quem pode criar conta e ative o MFA.
  6. Revise as ligações externas em Segurança.
  7. Configure backups diários. Antes de adicionar ligações de modelos de IA, defina a chave de criptografia da IA.
