Política de privacidade

Última atualização: 11 de outubro de 2026. Esta tradução é disponibilizada apenas por conveniência; em caso de divergência, prevalece a versão em inglês.

Esta página abrange duas coisas: o software Antimatter, que as organizações instalam nos seus próprios servidores, e este site, antimatter.chat.

O software Antimatter

O Antimatter é auto-alojado. Quando utiliza um servidor Antimatter, é a organização que o gere que decide que dados são guardados, durante quanto tempo e quem lhes pode aceder. O projeto Antimatter não tem acesso ao seu servidor, à sua conta nem às suas mensagens. Para questões sobre os seus dados num determinado servidor, contacte os respetivos administradores; aplica-se a política de privacidade desse servidor.

O que o software faz por iniciativa própria:

  • Sem telemetria. O servidor não envia estatísticas de utilização, diagnósticos nem quaisquer outros dados ao projeto Antimatter ou a terceiros.
  • Ligações ao exterior apenas para as funcionalidades que um administrador ativar, e para os serviços que este configurar: por exemplo, um serviço de notificações push, pré-visualizações de sites partilhados em mensagens, um fornecedor de GIFs, um servidor de e-mail, um fornecedor de identidade para o início de sessão único, ou modelos de IA, de voz ou de tradução.
  • As funcionalidades de IA usam os modelos escolhidos pelo administrador. Quando estes são alojados por terceiros, o que lhes é enviado (uma mensagem a reescrever, uma conversa a resumir, o áudio de uma chamada a transcrever) vai para esse fornecedor. Os administradores podem usar modelos alojados por si, para que nada saia da sua rede.

Este site

  • O antimatter.chat é um site estático alojado no GitHub Pages.
  • Não define quaisquer cookies nem utiliza ferramentas de análise, rastreadores ou publicidade. Os tipos de letra e as imagens são servidos pelo próprio site, pelo que o seu browser não faz pedidos a outros sites enquanto o lê.
  • Como qualquer serviço de alojamento web, o GitHub recebe o seu endereço IP e as páginas que pede, para as poder servir. Consulte a Declaração de Privacidade do GitHub.
  • Se abrir uma issue ou contribuir no GitHub, o que lá publicar é público e tratado pelo GitHub segundo os seus próprios termos.

Contacto

Para questões sobre esta política, abra uma issue no repositório do site.
