功能

團隊所需的一切，都在您擁有的地方

帶您認識 Antimatter，所有截圖皆取自示範伺服器。本頁介紹的每項功能都包含在自由軟體中，沒有任何功能保留給付費版本。

訊息

井然有序的對話

依分類整理的頻道、私人訊息與群組訊息，還有討論串，介面專為長時間工作而設計。

  • 頻道與分類：公開與私人頻道、由管理員為所有人設定的分類、我的最愛與追蹤。
  • 討論串與具名子聊天：在討論串中回覆，為討論串命名就能列在所屬頻道下方，並追蹤您關心的討論串。
  • 豐富的訊息格式：Markdown、語法醒目提示的程式碼、表格、LaTeX、連結預覽，以及可預覽的檔案。
  • 訊息優先順序：緊急與重要訊息、持續通知與確認回覆。
  • 排程訊息與草稿、提醒、轉寄、保留歷程的編輯，以及已儲存的訊息。
  • 搜尋訊息與檔案，支援篩選條件、完整詞句與日期。
社群

擁有角色、徽章與自訂規則的社群

無論經營公司還是社群，Antimatter 都提供歡迎新成員、維持良好氛圍所需的工具。

  • 顯示角色與團隊徽章：彩色角色、成員可自行選擇的角色，以及顯示在名字旁的徽章。
  • 新成員引導：歡迎畫面與問題，為新成員指派合適的角色與頻道。
  • 權限覆寫：可依分類和頻道設定，疊加在伺服器的權限配置之上。
  • 內容管理：暫時禁言、版主檢視、訊息檢舉與隔離。
應用程式

內建協作應用程式

應用程式會在聊天旁開啟，可以放在面板中，也可以開成獨立視窗；分享到頻道的任何內容，頻道裡的每個人都能即時看到更新。

筆記

多人即時共同編輯的文件，支援標題、清單、檢查清單與程式碼。可以留給自己，也可以分享到頻道。

白板

共用畫布，提供圖形、箭頭、文字，以及您的管理員新增的圖庫，還能看到每個人的游標，而且絕不會連線任何外部服務。

看板

用於專案管理的看板、表格與行事曆，包含卡片、屬性與多種檢視，並連結到負責該專案的頻道。

操作手冊

用於事件處理、版本發佈與新人到職的檢查清單，包含負責人、狀態更新與事後檢討。

{{icon:check}}

待辦清單

個人與共用的任務，可從任何訊息直接指派。

{{icon:calendar:anti}}

行事曆

您的 CalDAV 行事曆就在聊天旁邊，附提醒與通話連結。

{{icon:mail:spark}}

郵件

透過 IMAP 與 SMTP，在應用程式中使用您的信箱。

{{icon:poll}}

投票

單選或複選，可設定截止時間並即時顯示結果。

AI

在您決定的地方執行的 AI

您需要時才出手，其餘時間保持安靜。Antimatter 的代理程式支援 OpenAI、Anthropic、Azure、Mistral、Gemini、Bedrock，或任何您自行架設、與 OpenAI 相容的伺服器，例如 vLLM、llama.cpp 或 Ollama。

邊寫邊改寫、修正與翻譯

在訊息送出前，請輸入框幫您修正拼字與文法、精簡內容、讓語意更清楚、調整語氣或翻譯。

代理程式面板

在任何頻道旁與您的代理程式對話：摘要頻道內容、找出某項決定、草擬回覆，或透過 MCP 伺服器使用各種工具。

通話逐字稿與摘要

通話由您的語音轉文字模型轉錄，先以即時字幕顯示，結束後再以逐字稿加上 AI 摘要的形式，貼到通話的討論串中。

重點回顧與頻道摘要

休假回來後，透過您所選頻道的重點回顧與長篇討論串的摘要，快速跟上進度。

{{icon:translate}}

自動翻譯

使用 LibreTranslate 或任何與 OpenAI 相容的模型，將頻道內容翻譯成每位讀者的語言。

{{icon:speaker}}

朗讀

由您的文字轉語音模型朗讀任何訊息。

{{icon:bell}}

智慧回覆

代理程式可以在您選定的頻道中回答問題，並遵循團隊的權限。

通話與語音頻道

隨時開放的語音聊天室

語音頻道和其他頻道一樣位於側邊欄：點一下就能加入，看看誰在裡面，然後開始交談。您也可以從任何對話發起通話。

  • 視訊、螢幕分享與背景模糊，並提供適合分享程式碼或簡報的畫質預設。
  • 可排隊的舉手、表情反應與個別音量調整。
  • 按鍵通話、主持人控制，以及獨立的通話視窗。
  • 即時字幕與逐字稿，來自您自己的語音轉文字伺服器，無須額外架設基礎設施。
整合與 ChatOps

讓您的工具在頻道裡發聲

完整的 REST API 與擴充程式系統，還有自家開發的整合。

  • GitHub、GitLab 與 Jira 的訂閱、預覽與斜線指令。
  • 傳入與傳出 Webhook、斜線指令、機器人與 OAuth 應用程式。
  • 互動式訊息與對話框：按鈕、選單與表單，可將結果回傳給您的服務。
  • 擴充程式，可在 Antimatter 的介面中新增應用程式、面板、指令與訊息類型。
系統管理與安全

管理員期待的一切，應有盡有

完整的系統控制台，每台伺服器都能使用所有設定。

  • 身分驗證：SAML 2.0、OpenID Connect、Google、Microsoft Entra、LDAP/Active Directory、MFA。
  • 存取控管：權限配置、屬性型存取控制、訪客帳號、IP 篩選。
  • 合規：資料保留、合規匯出與訊息匯出、稽核紀錄。
  • 維運：Elasticsearch 或 OpenSearch 搜尋、Prometheus 監控指標、S3 相容檔案儲存。
  • 品牌形象：自訂網站名稱、標誌與登入頁文字、自訂表情符號與主題。
貼心小細節

大家都會注意到的小地方

以您的時區顯示時間

訊息中的「15:00 CET」，會以每位讀者自己的當地時間顯示。

「對方可能在睡覺」

當收訊人那邊正值深夜時會出現提示，並附上按鈕，讓您改在對方早上再傳送。

自動連結

每個社群都能定義特定格式（例如工單代碼），在訊息發佈時自動變成連結。

訊息確認

為重要訊息要求確認，並查看有誰已經確認。

閱後即焚

敏感訊息在被讀取後就會消失。

防雷遮罩

內容會先隱藏，由每位讀者自行選擇是否顯示。

對話收件匣

每段對話的提及、已儲存與已釘選的訊息、檔案與討論串，從對話標頭一鍵即可查看；再點一下就能看到整個社群的。

團隊徽章

點一下名字旁的團隊徽章，即可查看該團隊、負責人與成員，並直接前往團隊頻道。

置頂

將重要訊息置頂在對話上方，所有人都看得到，可維持一小時、一天、一週，或直到移除為止。

{{icon:bell}}

提醒

從訊息選單設定，讓訊息稍後再次提醒您。

{{icon:clock:anti}}

在對方早上傳送

將訊息排程在收訊人的上班時間送達。

{{icon:pin:spark}}

給自己的筆記

專屬於您的個人空間，可以轉寄訊息過來，也能隨手記事。

{{icon:eye-off}}

直播模式

分享螢幕時隱藏個人資訊。

自己的 GIF 與貼圖

{{icon:heart}}

主題

深色、淺色與 OLED 主題，可跟隨系統設定，也能分享自訂主題。

{{icon:image:anti}}

關於成員的私人筆記

記住誰是誰，只有您看得到。

頻道匯出

從頻道選單或使用 /export，將頻道訊息下載為試算表檔案。

{{icon:thread:anti}}

具名討論串

為討論串命名後，它就會成為所屬頻道的子聊天，出現在追蹤者的側邊欄中。
