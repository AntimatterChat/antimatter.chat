隱私權政策

最後更新：2026 年 10 月 11 日。本中文譯本僅為方便閱讀而提供，如與英文版本有任何不一致之處，以英文版本為準。

本頁面涵蓋兩個部分：由各組織在自己的伺服器上執行的 Antimatter 軟體，以及本網站 antimatter.chat。

Antimatter 軟體

Antimatter 是自行架設的軟體。當您使用某台 Antimatter 伺服器時，由營運該伺服器的組織決定保留哪些資料、保留多久，以及誰可以存取。Antimatter 專案無法存取您的伺服器、您的帳號或您的訊息。如對您在某台伺服器上的資料有任何疑問，請聯絡該伺服器的管理員；適用的是他們自己的隱私權政策。

軟體本身的運作方式：

  • 沒有遙測。伺服器不會將使用統計、診斷資訊或任何其他資料傳送給 Antimatter 專案或任何第三方。
  • 只有在管理員啟用相關功能時，才會對外連線，且僅連線到管理員所設定的服務：例如推播通知服務、訊息中所張貼網站的連結預覽、GIF 供應商、電子郵件伺服器、用於單一登入的身分識別提供者，或 AI、語音與翻譯模型。
  • AI 功能使用管理員所選擇的模型。若這些模型由第三方代管，傳送給它們的內容（要改寫的訊息、要摘要的對話、要轉錄的通話音訊）就會送到該供應商。管理員可以改用自行架設的模型，讓任何資料都不會離開自己的網路。

本網站

  • antimatter.chat 是代管於 GitHub Pages 的靜態網站。
  • 本網站不設定任何 Cookie，也不使用任何分析工具、追蹤器或廣告。字型與圖片皆由本網站自行提供，因此您在瀏覽時，瀏覽器不會向其他網站發出任何請求。
  • 如同所有網站代管服務，GitHub 會收到您的 IP 位址與您所請求的頁面，以便提供這些頁面。請參閱 GitHub 隱私權聲明。
  • 如果您在 GitHub 上建立 Issue 或貢獻內容，您在該處張貼的內容將會公開，並由 GitHub 依其自身條款處理。
