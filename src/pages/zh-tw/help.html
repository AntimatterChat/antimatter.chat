說明

說明與支援

Antimatter 是一個社群專案。以下說明可以在哪裡找到解答，以及如何向我們回報問題。

使用 Antimatter

  • 在應用程式中，說明選單（應用程式列上的 ?）提供使用者指南、鍵盤快捷鍵，以及訊息格式與斜線指令的說明。
  • 在 Antimatter 推出自己的使用手冊之前，Mattermost 說明文件涵蓋了大部分的伺服器設定與管理工作。
  • 帳號、社群與設定方面的問題，可以請您伺服器的管理員協助。

回報問題

發現錯誤，或是有功能不如預期？請在 GitHub 上建立 Issue，並附上版本（可在應用程式的關於 Antimatter 中查看）、您做了什麼、預期的結果，以及實際發生的狀況：

  • 伺服器與網頁應用程式：AntimatterChat/antimatter 的 Issues
  • 筆記、白板或通話等應用程式：請至 github.com/AntimatterChat 上對應儲存庫的 Issues
  • 翻譯：在伺服器儲存庫建立 Issue，並註明語言與字串

請先搜尋現有的 Issues，也請勿附上任何個人或機密資訊。

回報安全性漏洞

請不要在公開的 Issue 中回報安全性漏洞。請依照儲存庫的安全性政策，以非公開的方式回報。我們會確認收到您的回報、著手修正，並在您同意的情況下註明您的貢獻。

商業支援

Antimatter 沒有付費支援方案。如果您的組織需要具有服務等級保證的支援，請尋找提供自架聊天伺服器支援服務的公司。
