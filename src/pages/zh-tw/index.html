團隊的聊天、通話與應用程式，都在您自己的伺服器上

Antimatter 把頻道、討論串、語音聊天室、協作應用程式與 AI 整合在同一個地方，由您自行營運，沒有任何付費牆。

為什麼選擇 Antimatter

您的對話，始終屬於您

聊天伺服器裡存放著團隊的決策、檔案與歷史紀錄。Antimatter 讓這些資料留在您掌控的基礎架構上，也沒有廠商來決定您能使用哪些功能。

{{icon:server}}

自行架設

搭配 Docker 或發行版壓縮檔與 PostgreSQL，在您自己的硬體或雲端上執行。可完全離線運作，留在您的防火牆內。

{{icon:shield:anti}}

以 Mattermost 為基礎

建構於大型組織多年來實際使用的 Mattermost 伺服器之上：訊息傳遞、權限控管與擴充能力都經過驗證。

{{icon:lock:spark}}

企業級功能，無須授權

SSO 不另收費：SAML 與 OpenID Connect 單一登入、LDAP 同步、資料保留、合規匯出等功能，每台伺服器、每個團隊都能使用。

{{icon:code}}

開放原始碼

整個伺服器都是以 AGPL v3.0 授權的自由軟體：您可以閱讀、稽核、修改它，並提供給任意人數使用。

安全與可靠

建構於十年來承載關鍵業務的伺服器之上

Antimatter 執行於一套成熟的開放原始碼伺服器之上，這套伺服器深受重視安全的組織信賴：訊息傳遞可靠、資料模型穩定、API 文件完整，讓您的部署與整合在版本更新後依然正常運作。

  • 使用您的身分識別提供者：SAML、OpenID Connect、Google、Microsoft Entra、LDAP 與 Active Directory 同步，以及多重要素驗證。
  • 精細的存取控管：角色、權限配置、屬性型存取控制、訪客帳號與 IP 篩選。
  • 合規：資料保留政策、合規匯出、稽核紀錄、機密等級標示橫幅，以及閱後即焚訊息。
  • 沒有遙測：伺服器不會回傳任何資料。只有在您啟用特定功能時，才會連線到外部。
應用程式與 ChatOps

不必離開對話，就能一起完成工作

Antimatter 的應用程式在聊天旁邊開啟，一鍵就能分享到頻道，所有人看到的內容都會即時更新。

  • 筆記：多人即時共同編輯的協作文件。
  • 白板：在共用畫布上繪圖、畫架構圖、腦力激盪。
  • 看板與操作手冊：用看板管理專案，用檢查清單處理事件與重複性流程。
  • 待辦清單、投票、行事曆與郵件：任務、快速決策、您的行程與收件匣，都在團隊身邊。
AI，由您作主

搭配您所選模型的 AI 助理

AI 只待在自己的角落：輸入框裡的一個按鈕、一個由您開啟的面板、一份您要求時才產生的摘要。需要幫忙時它就在那裡，其餘時間不會打擾您。您可以連接任何與 OpenAI 相容的模型，包括在您自己 GPU 上執行的模型，您的資料只會送到您決定的地方。

  • 傳送前改寫與修正訊息：更清楚、更簡短、更親切，或單純修正錯誤。
  • 通話逐字稿與摘要：通話中顯示即時字幕，結束後在通話的討論串中貼出逐字稿與摘要。
  • 代理程式面板：針對頻道、討論串或您的工作提問，並依照您的權限回答。
  • 頻道摘要與重點回顧：用幾行文字掌握您錯過的內容。
  • 頻道自動翻譯，任何訊息也都能依需求朗讀出來。
通話與語音聊天室

開口說話，就像打字一樣容易

從任何對話發起通話，或直接加入隨時開放的語音頻道，就像團隊走進會議室一樣自然。

  • 語音頻道就在側邊欄，誰在裡面、誰正在說話一目了然。
  • 視訊與螢幕分享，提供畫質預設、背景模糊與子母畫面。
  • 舉手、表情反應與個別音量調整，還有按鍵通話與主持人控制。
  • 即時字幕與逐字稿，使用您自己的語音轉文字模型。
整合

與您已在使用的工具串連

完整的 REST API、Webhook、機器人與擴充程式，把其他工具帶進對話中；為 Mattermost 撰寫的整合也能直接使用。

  • GitHub、GitLab 與 Jira：在頻道中接收通知、預覽內容並直接操作。
  • Webhook、斜線指令與機器人，從 CI 流程到系統監控，什麼都能串接。
  • 互動式訊息與對話框，直接在聊天中完成審核與填寫表單。
  • 擴充程式，可新增應用程式、訊息類型、指令與面板。

開始使用

幾分鐘內即可上線

只要一個 Compose 檔案，就能啟動 Antimatter 以及它的資料庫、檔案儲存空間與 GIF 服務。您建立的第一個帳號會成為管理員。

$ curl -fsSLO https://antimatter.chat/compose.yaml
$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
$ docker compose up -d
