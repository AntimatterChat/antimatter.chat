尋找並開啟應用程式

您的管理員會決定您的伺服器有哪些應用程式，因此您可能不會在此頁看到所有應用程式。大多數應用程式在應用程式欄中都有圖示，該欄位於視窗右側邊緣、您的頭像下方。將指標指向圖示即可查看應用程式名稱，點擊即可在對話旁的面板中開啟應用程式。再次點擊即可關閉面板。拖曳面板邊緣可調整寬度；恢復預設寬度可還原。在新視窗中開啟（位於面板標題列）可將應用程式開啟在獨立視窗中，並定位到您先前開啟的筆記、看板或清單。

應用程式也會出現在其他位置：

  • 訊息輸入框的+選單（新增檔案及其他內容），例如建立投票。
  • 表情符號選擇器的分頁：GIFs、貼紙與迷因。
  • 訊息選單（訊息動作，即⋯）中的更多動作，例如加入待辦事項或執行操作手冊。每個動作都會顯示其對應應用程式的圖示。
  • 斜線指令，例如/poll或/todo：輸入/即可查看清單。
  • 部分應用程式的設定位於您的設定中的擴充程式下。

在手機上，應用程式欄位於右側抽屜中：向左滑動，或在對話標題列中選擇更多 › 成員與應用程式。

Notes

筆記是多人可同時在聊天旁編輯的文件。當其他人輸入時，您會看到他們的游標與名稱，且所有內容都會即時儲存。

撰寫筆記

  1. 點擊應用程式欄中的筆記。
  2. 選擇分頁：此頻道為頻道中所有成員皆可讀取與編輯的筆記，或我的為僅您可見的個人筆記。
  3. 點擊面板標題列中的+（在此頻道新增筆記或新增個人筆記）。將開啟一個「未命名筆記」。
  4. 在標題欄輸入標題，然後開始撰寫。標題下方的格式工具列（僅顯示給可編輯此筆記的人）提供粗體、斜體、刪除線、標題、清單與核取清單；連結、引用與程式碼也可以使用。旁邊的圓點會顯示其他正在編輯的人員，以及您的變更是否已儲存。輸入 @ 即可提及頻道成員（筆記中的提及不會通知任何人）。
  5. 按一下所有筆記（標題左側的箭頭）即可返回清單。

當頻道中的筆記有了標題後，Antimatter 會在頻道中發布「已分享筆記」，並附上開啟筆記按鈕。

筆記的其他功能

將筆記設為最愛，即可在我的最愛分頁中找到它。筆記的筆記操作選單（⋯）提供在頻道中分享（發布一張連結到該筆記的卡片）、在 ~channel 中分享（將個人筆記永久轉為頻道筆記）、版本歷史（查看並復原至此版本）、匯出為 Markdown 以及刪除。只有筆記的創建者與頻道管理員可以刪除頻道筆記。

Whiteboard

白板是一個可以共同繪製的畫布：包含形狀、箭頭、文字與手繪，並即時顯示所有人的指標。

  1. 按一下應用程式欄中的白板。
  2. 與筆記相同，選擇此頻道或我的，然後按一下+（在此頻道建立新看板或建立新個人看板）。
  3. 使用工具繪製：選取與移動 (V)、移動視圖 (H)、矩形 (R)、橢圓 (O)、箭頭 (A)、繪製 (P)、文字 (T) 與橡皮擦 (E)。在工具列中選擇顏色、線條樣式與字體，並在圖庫中選擇形狀。復原 (Ctrl+Z)可復原您上一次的變更。

看板操作選單包含全螢幕、顯示整個看板、下載為 .excalidraw、PNG 或 SVG、版本歷史、匯入 .excalidraw 檔案…（這將取代所有人的看板）、在頻道中分享，以及刪除。白板會儲存在您的 Antimatter 伺服器上。

Kanban

看板以欄位中的卡片來組織工作，例如「待辦事項」、「進行中」與「已完成」。看板也可以以表格、圖庫或行事曆的形式顯示。

開啟頻道的看板

點擊應用程式欄中的 看板。看板會開啟在面板中，位於對話旁邊，並列出與該頻道連結的看板；點擊其中一個即可開啟。如果尚未連結任何看板，請點擊 連結看板至 …，然後在目標看板旁點擊 連結，或選擇 建立看板。頻道的成員將成為已連結看板的編輯者。看板顯示時會加寬面板；點擊面板頂端的返回箭頭即可回到上一個檢視。

使用看板

  • 若要依分類檢視社群中的所有看板，請點擊面板中的 所有看板。您可以在那裡找到看板、建立看板或分類，並透過選單移動、複製、匯出、隱藏或刪除看板。
  • 若要建立看板，請點擊面板中的 新看板，然後從範本開始（會議議程、專案任務、路線圖、衝刺計畫等），或選擇 建立空白看板。
  • 點擊欄位中的 + 新增 以新增卡片。卡片會在面板上方開啟：您可以設定其屬性、新增文字、核取方塊和圖片、附加檔案，以及留言。在卡片中提及某人會通知該使用者。
  • 將卡片拖曳到不同欄位。使用 分組依據、過濾器、排序 和 搜尋卡片 來導航，並使用 新增檢視 來切換為表格、圖庫或行事曆檢視。
  • 使用看板上的 分享 功能來選擇誰可以檢視或編輯它。

Calendar

行事曆應用程式會將您的個人行事曆顯示在聊天旁邊，發送提醒，並讓您在 Antimatter 中進行會議。它支援使用 CalDAV 的行事曆伺服器，例如 Nextcloud、Fastmail 或 Radicale。

連結您的行事曆

  1. 點擊應用程式欄中的 行事曆。
  2. 在 連結您的行事曆 中，填入 CalDAV 伺服器 地址（通常只需輸入服務商的網域）、您的 使用者名稱 和 密碼。如果您的服務商提供應用程式密碼，請使用該密碼。
  3. 選擇何時 提醒我沒有設定鬧鐘的活動，然後點擊 連結。

您的密碼會以加密方式儲存在 Antimatter 伺服器上。若要稍後變更這些詳細資訊或斷開連結，請使用面板中的 帳戶設定。

使用方式

  • 在 議程 和 週 之間切換，使用 上一步、今天 和 確定 進行移動，並點擊行事曆的標籤來顯示或隱藏它。
  • 點擊 新活動，填入 標題、開始 和 結束，並選填 重複、提醒、地點 和 敘述，然後點擊 儲存。點擊活動即可變更或刪除它。
  • 要在 Antimatter 中舉行會議，請將 Meet in Antimatter 設定為頻道或語音頻道，或設定為通話，並選擇 Channel。到了時間，活動會顯示 Start call、Join call 或 Join。
  • 提醒會以行事曆機器人的私人訊息形式發送，若包含通話，訊息中會附上加入通話的連結。

此應用程式會顯示您自己的行事曆；它不會向其他人發送邀請。

Mail

Mail 應用程式會將您的信箱顯示在聊天旁邊，讓您可以讀取、回覆和分享電子郵件，而無需離開 Antimatter。

連接您的信箱

  1. 點擊應用程式欄中的 Mail。
  2. 如果您的管理員已設定，請點擊 Sign in with Google 或 Sign in with Microsoft。否則，或若要使用其他供應商，請填寫您的 Email address 和 Your name，然後填寫 Incoming mail (IMAP) 和 Outgoing mail (SMTP) 伺服器，包括其安全性、埠號、使用者名稱和密碼。您的供應商說明頁面會提供這些詳細資訊。
  3. 點擊 Connect。

使用方式

  • 選擇 Folder，使用 Search this folder 進行搜尋，並點擊訊息以讀取。來自網際網路的圖片在您點擊 Show images 之前會保持隱藏。
  • 使用 Reply、Reply all 或 Forward 進行回覆，或使用 New message 撰寫新訊息。訊息為純文字，您無法附加新檔案。
  • 點擊 Share to a channel 可將電子郵件的寄件者、主旨和摘要發布到頻道中，並附上註解。

Polls

投票會在對話中提出問題，所有人都可以透過一次點擊進行投票。結果會即時更新。

  1. 點擊訊息框中的 + 並選擇 Create a poll，或輸入 /poll。
  2. 輸入 Question 和至少兩個選項；Add answer 可新增更多選項，最多十個。
  3. 如果允許選擇多個選項，請開啟 Allow multiple answers；如果希望不顯示誰投了什麼票，請開啟 Anonymous voting。
  4. 選擇 Duration，範圍從 1 小時到 1 週，或選擇 No end。
  5. 點擊 Post poll。

要投票，請點擊選項；再次點擊可撤回您的投票。投票會在時長結束時結束，或由建立者或頻道管理員點擊 Close poll 結束；之後會顯示 Final results。

您也可以在一行內寫下完整的投票：/poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h。輸入 /poll help 即可列出所有選項。

Todo

Todo 管理待辦事項清單：包括在頻道或對話中分享的清單、您自己的清單，以及您發送給其他人的待辦事項。點擊應用程式欄中的 Todo。與筆記一樣，面板有三個分頁：

  • 此頻道（或此對話）：與其中所有人共用的清單。點擊面板標題中的+（在此頻道新增清單）即可建立。
  • 我的最愛：您已加星號的清單，無論它們位於何處。
  • 我的：僅您可見的個人清單（我的待辦事項始終存在；+可建立其他清單），接著是頻道中指派給您的、發送給您的以及您發送的。

開啟清單以新增待辦事項，可包含詳細資訊和到期日（若需要），並使用標記為完成勾選完成。在頻道的清單中，指派給…可將待辦事項指派給成員；在個人清單中，發送給…可將其發送給某人，對方可以接受、拒接或標記為完成。清單的清單動作選單可重新命名、變更圖示、封存（將變成唯讀，位於已封存下）或刪除。任何能在頻道中貼文的人都可以修改其清單；清單的建立者和頻道管理員可以刪除它。

若要將訊息轉為待辦事項，請在其選單中選擇更多動作 › 新增至待辦事項，並選擇清單。待辦事項機器人會在有人向您指派或發送待辦事項時通知您，並每天提醒您一次您的待辦事項。

指令也有效：/todo lists、/todo new name（加上 --personal 以建立您自己的清單）、/todo add list: text 依名稱新增至清單、/todo add text 新增至您自己的待辦事項，以及 /todo send @someone text。

GIF、貼紙與迷因

點擊訊息框中的表情符號（笑臉）：當這些應用程式設定完成後，選擇器會在表情符號旁邊顯示GIFs、貼紙和迷因分頁。

  • GIFs：搜尋，或瀏覽我的最愛、最近曾使用、熱門和分類。點擊 GIF 即可立即發送。點擊其星號可將其加入您的最愛。您也可以輸入 /gif 和幾個單字。
  • 貼紙：搜尋或瀏覽貼紙包，並點擊貼紙即可發送。/sticker 也有效。
  • 迷因：選擇範本，在製作迷因中填入其文字，查看預覽，並點擊發布迷因。您也可以輸入 /meme，或 /meme help 查看如何在一行中撰寫。

視您伺服器的設定而定，您可以透過搜尋框旁的 + 新增自己的 GIF、貼紙或迷因模板。這會開啟選擇器內的一個表單：選擇、拖曳或貼上檔案，檢查預覽，輸入標題（迷因模板的名稱），並可選地加上標籤或關鍵字，然後點擊 新增（迷因模板則為 儲存模板）。您新增的內容會顯示在選擇器的最前面，且伺服器上的所有人都能找到。 + 旁的按鈕（管理 GIF、管理貼紙 或 自訂迷因模板）會列出其他人新增的內容，包括新增者和時間，並允許您刪除您有權限刪除的項目。訪客無法新增或刪除任何項目。

Playbooks

操作手冊（Playbook）是針對每次遵循相同步驟的工作（例如事故處理、版本發布或歡迎新同事）所設計的可重用檢查清單。每次使用時，您都會啟動一個 執行，其中包含獨立的任務、負責人、狀態更新，以及最後的回顧。

  • 點擊應用程式欄中的 操作手冊 可查看目前頻道的執行記錄，透過 執行操作手冊 啟動新的執行，或快速建立 新檢查清單。操作手冊中的所有內容都會在此面板中開啟，並提供返回上一個視圖的箭頭。
  • 若要尋找其他內容，請點擊面板頂部的 瀏覽執行、操作手冊和任務：所有執行、所有操作手冊、您的任務，以及您的最愛和進行中的執行。
  • 若要建立操作手冊，請在該視圖中點擊 建立操作手冊 或 匯入；若要編輯，請從 所有操作手冊 中開啟。您可以從模板開始（例如產品發布、事故解決或員工入職），或從空白操作手冊開始。操作手冊編輯器顯示時會加寬面板。
  • 若要啟動執行，請點擊操作手冊上的 執行，為執行命名並提供摘要，選擇是否為其建立頻道或連結到現有頻道，然後點擊 開始執行。您也可以透過訊息選單中的 更多動作 › 執行操作手冊 來啟動。
  • 在執行期間，您可以勾選完成任務、指派負責人並設定截止日，並點擊 發布更新 告知所有人目前進度。負責人在結束時點擊 完成。

輸入 /playbook 可查看指令，例如 /playbook run 或 /playbook update。

GitHub、GitLab 和 Jira

這些應用程式將 Antimatter 與開發人員使用的工具相連。您的管理員必須先完成設定。然後：

  1. 輸入 /github connect、/gitlab connect 或 /jira connect 來連結您的帳號，然後依連結前往該網站登入。如果是 GitLab，請在網頁瀏覽器中操作，而非桌面應用程式。
  2. 當有人提及您、請求您審查或指派您任務時，您會收到私人訊息。
  3. 若要讓頻道追蹤儲存庫或專案，請使用 /github subscriptions add owner/repo、/gitlab subscriptions add group/project 或 /jira subscribe。
  4. 若要從訊息建立或附加問題，請在訊息選單的 更多動作 下，選擇 建立 GitHub Issue、建立 GitLab Issue、建立 Jira Issue，或對應的 附加至 … 項目。

輸入 /github help、/gitlab help 或 /jira help 即可查看所有指令。

行動應用程式中的應用程式

行動應用程式可建立與投票、傳送 GIF 與貼紙，以及回覆指派給您的待辦事項。筆記與白板會在應用程式內的瀏覽器視窗中開啟。看板、行事曆、郵件與迷因尚未支援行動應用程式：請使用網頁或桌面應用程式。
