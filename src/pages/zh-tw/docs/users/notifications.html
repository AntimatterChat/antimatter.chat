哪些內容會通知您

預設情況下，Antimatter 會通知您以下內容：

  • 透過您的使用者名稱提及您的訊息，例如 @maya；
  • 私人訊息和群組訊息；
  • 您所在頻道中的 @channel、@all 和 @here；
  • 您追蹤的討論串中的新回覆。

其他新訊息不會通知您：它們會使側邊欄中的頻道名稱加粗。在社群欄中，社群上的圓點表示有未讀訊息，數字則計算您的提及次數。瀏覽器分頁的標題和圖示也會顯示您是否有未讀訊息和提及。

您的狀態會改變這一點：當您處於請勿打擾狀態時，不會有任何通知。靜音頻道也不會通知您。

桌面與瀏覽器通知

若要讓 Antimatter 在您的電腦上顯示通知，您的瀏覽器必須允許通知。當您的瀏覽器詢問是否允許此網站顯示通知時，請選擇允許。如果您之前拒絕了，請在瀏覽器的網站設定中允許您的 Antimatter 位址接收通知。桌面應用程式無需此步驟即可顯示通知。

若要選擇哪些內容會通知您：

  1. 開啟設定 › 通知：點擊右上角的您的圖片，選擇個人檔案與設定，然後選擇通知。社群選單中的通知設定也會導向該頁面。
  2. 在桌面與瀏覽器下，將通知我以下訊息設為全部新訊息、提及（預設值；私人訊息和群組訊息算作提及），或無。
  3. 追蹤中討論串的回覆預設為開啟：您會收到這些討論串中每個回覆的通知。關閉它後，僅當您在那裡被提及时才會收到通知。
  4. 開啟或關閉通知音效，並選擇訊息音效。點擊播放即可聆聽。
  5. 開啟或關閉來電鈴聲，並選擇私人訊息中通話的鈴聲音效。

變更會在您操作時自動儲存。若要確認一切正常，請點擊頁面底部的傳送測試通知：它應該能到達您的桌面和您的裝置。

哪些情況算作提及

在設定 › 通知中，哪些情況算作提及下方：

  • 我的名字：當有人使用您的名字時，也會通知您。您的使用者名稱一律算數。
  • 全頻道提及：選擇是否要接收 @channel、@all 和 @here 的通知。
  • 會通知我的關鍵字：像提及一樣通知您的詞語，例如專案名稱。輸入詞語後按 Enter。這些詞語不分大小寫。
  • 僅醒目提示的關鍵字：在訊息中醒目提示但不通知您的詞語。
  • 自動追蹤以 @channel 提及我的討論串：當討論串中有全頻道提及时，您將自動追蹤該討論串。

行動裝置通知

如果您使用行動應用程式且您的伺服器會發送推播通知，請前往 設定 › 通知，其中有一個 行動裝置 區塊：

  • 推播通知內容：全部、提及 或 無。
  • 當我處於以下狀態時傳送：線上、離開或離線（預設值）、離開或離線，或僅 離線。這是您在桌面或網頁應用程式中的狀態：若選擇 離開或離線，當您在電腦上活躍時，您的手機將保持靜音。
  • 追蹤中討論串的回覆：在行動裝置上，也會為每一則回覆發送通知。

如果您的手機完全收不到通知，請詢問您的管理員：推播通知需要在伺服器上進行設定。行動應用程式也有自己的通知設定，位於應用程式內的 設定 › 通知 下。

電子郵件通知

當您的伺服器發送電子郵件時，請在 設定 › 通知 中開啟 電子郵件通知，以便在您離開或離線時，接收提及和私人訊息的電子郵件。如果您的管理員允許，您可以透過 寄送頻率 選擇 立即寄送、每 15 分鐘 或 每小時，以便將多則訊息合併在一封電子郵件中。

單一頻道的通知

每個頻道或對話都可以擁有與您一般設定不同的獨立設定。

  1. 開啟頻道的選單（側邊欄中名稱旁邊的 ⋯，或右鍵點擊它），並選擇 通知偏好設定…。
  2. 在 通知喜好設定 中，選擇在桌面端通知您的內容：所有的新訊息、僅提及、私人訊息和關鍵字，或 無。標記為「(預設)」的選項將遵循您的一般設定。
  3. 為此頻道選擇討論串回覆通知和聲音。
  4. 對於行動裝置，您可以保留 使用與桌面端相同的通知設定，或選擇不同的設定。
  5. 在靜音或忽略中，您可以靜音頻道，或在此頻道中忽略 @channel、@here 及 @all 的提及。
  6. 追蹤此頻道所有討論串會讓您追蹤該頻道中的所有新討論串，使這些討論串的回覆顯示在您的追蹤討論串中。
  7. 點擊 儲存。

頻道簡介位於訊息的最開頭，也有一個通知按鈕，可開啟相同的對話方塊。

靜音頻道、分類或團隊

已靜音的頻道不會向您發送通知，也不會顯示未讀徽章。當有人在此頻道提及您時，您仍會看到徽章。

  • 頻道或對話：在其選單中，指向靜音頻道（或將對話靜音），並選擇靜音時長：1 小時、8 小時、24 小時、1 週或直到我取消靜音。選單隨後會顯示靜音結束的時間，以及取消靜音頻道選項。
  • 分類：在其分類選項中選擇靜音分類。
  • 整個團隊：在團隊選單中選擇將團隊靜音。

在團隊選單中選擇隱藏已靜音的頻道，可將已靜音的頻道從側邊欄中移除。

您的狀態

您的狀態會告知其他人您是否在線。它會以圓點顯示在您的頭像上。Antimatter 在您使用時會將您設為線上，在您未使用時設為離開；您也可以自行設定：

  1. 點擊視窗右上角的個人照片。
  2. 選擇線上、離開、請勿打擾或隱身（您看起來是離線，但仍可使用 Antimatter）。

指令 /online、/away、/dnd 和 /offline 具有相同的功能。

請勿打擾

請勿打擾會靜音所有通知。指向它可選擇靜音時長：15 分鐘、1 小時、1 天、1 週、永久，或直到自訂時間…（選擇日期和時間，然後點擊開啟）。當它結束時，您的狀態會恢復正常。直接向您發送訊息的人會看到您已開啟此功能以及持續時間，且您不會收到通話鈴聲。

不在辦公室與自動回覆

如果您的管理員已開啟自動回覆，設定 › 通知中將有一個自動回覆部分。開啟自動回覆私人訊息並撰寫訊息：您收到的每則私人訊息都會以此訊息回覆，且您的狀態會變為不在辦公室。在您的狀態選單中選擇其他狀態會關閉自動回覆。

當您選擇自訂狀態（例如「不在辦公室」或「休假中」）時，Antimatter 會建議您同時開啟自動回覆。

直播模式

當您分享螢幕或進行簡報時，請在設定 › 進階中開啟直播模式。此模式會隱藏您的電子郵件地址和對話預覽，並靜音桌面通知。請記得在結束後將其關閉。

在桌面應用程式中

桌面應用程式會在其設定視窗的通知下提供專屬選項：當有訊息到達時，可在應用程式圖示上顯示帶有未讀數量的紅色徽章（適用於 Windows 和 macOS）、使 Dock 圖示彈跳（macOS），或使工作列圖示閃爍（Windows 和 Linux）。
