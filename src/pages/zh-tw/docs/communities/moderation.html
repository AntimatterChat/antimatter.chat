誰可以進行管理

社群管理員可以使用本頁的所有工具，但對象不包括其他管理員。其他人需要擁有具備適當權限的角色（請參閱 角色與權限）：

  • 使用管理訊息可編輯和刪除他人的訊息，以及將訊息置頂或取消置頂；
  • 移除人員：暫時禁言並將其從社群中移除；
  • 管理角色：授予和收回角色。

以上任一權限皆可存取管理員檢視。擁有 移除人員 權限的管理員，只能暫時禁言最高角色低於自己的成員。

管理員檢視

管理檢視彙整了您需要了解的個人資訊，以及您可以執行的動作。要開啟它，請開啟某人的個人檔案卡片，並選擇右上角的盾牌按鈕，或右鍵點擊其名稱並選擇管理檢視。它會在右側面板中開啟。

  • 摘要：他們加入社群的時間（加入時間）、帳號建立時間，以及他們在過去一天和過去一週內於社群中發佈的訊息數量。查看訊息可搜尋他們的訊息。
  • 角色：其在社群中的角色。如果您可以管理角色，可使用 新增角色 添加，或使用 × 移除。
  • 重要權限：他們除了成員身份外擁有的權限，例如管理訊息或移除成員及將成員禁言。
  • 動作：訊息、禁言和從團隊移除。系統管理員還會看到停用帳號。

新帳號在第一天發佈大量訊息是典型的垃圾訊息特徵：摘要可讓您一眼看出。

暫時禁言

暫時禁言會暫停某人參與社群活動一段時間，但不會將其移除。在被暫時禁言期間，他們可以閱讀社群的頻道，但不能發送訊息、做出反應、附加檔案或提及他人。其私人訊息仍保持開啟。

  1. 在管理員檢視中選擇 暫時禁言，或右鍵點擊其名稱並選擇 暫時禁言…。
  2. 選擇時長：60 秒、5 分鐘、10 分鐘、1 小時、1 天或1 週。
  3. 選填，為其他管理員寫下 原因。
  4. 選擇 暫時禁言。

該使用者會在訊息輸入框處看到「您已被禁言，直到…」，直到禁言期結束。他們也無法加入或重新加入社群的語音頻道和通話。所有成員都會在成員名單中看到其名稱旁的已禁言標籤，以及在其個人檔案卡片上看到禁言結束的時間。

禁言會自動結束。若要提前結束，請在管理檢視或其選單中選擇解除禁言。新的禁言會取代先前的禁言。將某人從團隊移除不會清除其禁言狀態：如果他們在禁言期結束前回來，他們仍處於禁言狀態。社群管理員不能被禁言。

被靜默的使用者不會看到原因，但其他成員可以透過伺服器 API 讀取原因。請撰寫您不介意讓該使用者看到的原因。

將某人移出社群

在管理檢視中選擇從團隊移除，或右鍵點擊其名稱並選擇從團隊移除…，然後確認。他們將離開社群中的所有頻道並失去該社群中的角色；他們的訊息會保留。他們不會被告知原因：該社群會直接從他們的側邊欄中消失。

被移出的人可以透過新的邀請重新加入，或者如果社群是公開的，可以立即重新加入。如果他們不應該回來，請將社群設為私人並重新生成其邀請連結（請參閱 誰可以加入），或參閱 阻止某人加入。

若要將某人從單一頻道移除，請右鍵點擊其名稱並選擇從頻道移除，或在該頻道中輸入 /kick @username。如果社群中的每個成員都在所有頻道中，則無法執行此操作。

阻止某人加入

Antimatter 沒有封鎖清單。您的選項，從最輕微的開始：

  • 最長一週的 靜默。
  • 移出該使用者，並結合私人社群或新的邀請連結。
  • 停用其帳號，這由系統管理員在管理員視圖或系統控制台中執行。他們將從所有地方登出，且在系統管理員重新啟用之前無法再次登入。這適用於整個伺服器，而不僅限於您的社群，因此適用於垃圾訊息發送者和嚴重濫用行為。

刪除和編輯訊息

使用 管理訊息（或作為社群管理員），開啟訊息的 ⋯ 選單並選擇 刪除。刪除訊息會將其對所有人移除，包括其回覆，且無法復原。社群管理員可以刪除，但預設情況下無法編輯其他人的訊息；具有 管理訊息 權限的角色可以執行兩者。

置頂訊息由管理員掌控：只有頻道的管理員、團隊的管理員以及擁有管理訊息權限的人員，才能使用取消置頂來置頂或移除訊息，因此成員無法移除您的公告。釘選則不然：任何能閱讀該頻道的人都可以釘選或取消釘選。請參閱置頂訊息。

系統沒有慢速模式。若要平息激烈的頻道討論，可以暫時透過權限限制誰能在該頻道發佈訊息（請參閱頻道權限），或對相關人員進行禁言。

檢舉

當伺服器啟用檢舉功能時，成員可以透過訊息 ⋯ 選單中的檢舉訊息來檢舉訊息。他們需選擇原因並添加註解。在審核期間，該訊息會從頻道中隱藏，審核人員會收到來自機器人的私人訊息，其中包含移除訊息和保留訊息按鈕。

檢舉功能預設為關閉，且只有系統管理員可以在系統控制台 › 網站設定 › 資料洩漏處理中開啟它。在此，系統管理員可以選擇：

  • 審核人員：是為每個社群指派相同的審核人員，還是為每個社群指派不同的審核人員，以及社群管理員和系統管理員是否也參與審核（社群管理員預設會參與）；
  • 使用者可選擇的原因清單；
  • 檢舉者和審核人員是否必須添加註解，以及訊息在審核期間是否隱藏。

此功能源自合規用途，其預設原因（如「分類不符」、「違反需知原則」等）是為處理敏感資訊的組織而設計的。對於公開社群，請要求您的系統管理員將其替換為「垃圾訊息」、「騷擾」或「離題」等原因，並指定您的版主為審核人員：擁有管理訊息權限並不會使人成為審核人員。

忽略與封鎖

成員可以透過某人姓名旁的選單來保護自己，無需版主介入：

  • 忽略：不會收到該人的通知，其訊息會被摺疊，其私人訊息會作為訊息請求等待。
  • 封鎖…：效果相同，且該人無法向您發送訊息或邀请您加入群組訊息。對方不會被告知。

在他們的設定中，於隱私與安全下，每位使用者也可以選擇來自尚未交談過的人的私人訊息是正常接收（接受所有人的訊息）還是作為訊息請求（先詢問我），適用於所有社群或各社群。這是個人選擇：社群管理員無法為其成員設定此選項。

版主應知曉的事項：

  • 封鎖不會阻止任何人發布到社群的頻道。它只會為封鎖者摺疊該使用者的訊息。頻道的濫用行為仍需由版主處理。
  • 成員也可以忽略或封鎖版主和社群管理員。版主發送的私人訊息可能變成靜音請求，或被拒絕。只有系統管理員和機器人總是能成功送出。若要發送重要警告，請發布到該使用者能讀取的頻道，或請系統管理員協助。
  • 系統管理員可以在系統控制台 › 網站設定 › 使用者與團隊中，透過啟用忽略、封鎖與訊息請求選項，為整個伺服器關閉這些功能，適用於同事必須隨時可聯繫的工作場所。

通話與語音頻道

誰可以管理通話：通話主持人、社群管理員、頻道管理員和系統管理員。在語音頻道中，擁有管理訊息、移除人員或管理角色權限的版主也可以。您不需要自己正在通話中。

右鍵點擊參與者的磁貼或列，開啟其選單：

  • 靜音：將其靜音一次；他們可以自行取消靜音。
  • 在此通話中靜音：對方將保持靜音狀態，直到您允許其取消靜音，即使他們離開並重新加入也是如此。他們的麥克風會顯示已被版主靜音。靜音狀態會在他們離開或通話結束後持續 10 分鐘，因此離開並重新加入無法規避此限制。允許取消靜音可解除靜音。
  • 請求取消靜音：請求已靜音的人發言。他們會看到請求並選擇是否取消靜音。您可以在 20 秒後再次請求同一人。
  • 放下手與停止螢幕分享。
  • 從語音頻道移除或移出通話：將中斷其連線。他們可以立即重新加入；若要防止他們再次進入，請對其進行禁言。

您只能對排名低於您的人執行通話靜音：通話主持人低於語音頻道版主，語音頻道版主低於頻道管理員，頻道管理員低於社群管理員，社群管理員低於系統管理員。

主持人與系統管理員也可以在某人的選單中選擇設為主持人，以授予其主持人控制權。

結束所有人的通話

掛斷電話只會讓您離開通話。若要結束所有人的通話，請使用對話中的通話卡片：一旦您離開通話，卡片會在加入旁邊顯示結束所有人的通話。此選項對通話的發起者（語音頻道除外）以及通話的管理員可用。請使用結束通話確認：所有仍在通話中的人員將被斷開連線，通話即告結束。

保持記錄

社群中沒有版主記錄。禁言、移除和其他操作會記錄在伺服器的稽核日誌中，只有系統管理員可以讀取。請在私人的版主頻道中自行記錄：誰被禁言或移除、何時以及原因。

公開社群的良好實務

  • 將規則寫下來。將其放在鎖定「資訊」分類下的頻道中，加上橫幅，並在入門歡迎文字中總結。
  • 將類型保持為團隊（團隊設定 › 頻道），這樣只有管理員和擁有管理頻道權限的管理員才能封存頻道。
  • 限制新成員能執行的操作。請您的系統管理員為您的團隊設定一個權限方案，讓成員無法重新命名頻道或管理其成員，而預設方案是允許這些操作的。
  • 建立管理員角色，包含管理訊息和移除人員，並單獨顯示，以便人們知道該向誰請求；版面配置預設中的「管理員」角色同時包含這兩項。請為管理員保留一個私人頻道。
  • 逐步升級處理：先在頻道中提醒，接著發送私人訊息，然後給予短暫的禁言，再延長禁言時間，接著移除成員，最後由系統管理員對垃圾訊息或濫用行為進行停用。
  • 留意新帳號。管理員視圖會顯示帳號的建立時間與發文數量。若出現大量新帳號，透過私人社群並重新產生邀請連結，便能更容易地加以阻擋。
  • 開啟檢舉功能，指派您的管理員作為審核人員，並設定符合您社群需求的檢舉原因。
  • 了解您伺服器的成員上限。社群預設沒有成員上限，但系統管理員可以設定；如果您的社群設定了上限，請在達到上限前要求管理員調高。
