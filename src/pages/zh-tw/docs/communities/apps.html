您的成員擁有的應用程式

Antimatter 附帶一組應用程式。除非系統管理員關閉了其中一些，否則伺服器上的每個社群都擁有這些應用程式：

應用程式功能說明
通話與語音頻道在任何頻道中進行通話，以及語音頻道：始終開放的通話，人們可以隨時加入或離開。
Polls對話中的投票，具有即時結果、匿名投票和結束時間。/poll 可建立投票。
Todo每個頻道中的共享待辦事項清單，以及個人清單。
Notes可即時共同編輯的文件，可與頻道共享或保持私人。
Whiteboard可與頻道共享或保持私人的白板。
Kanban由卡片組成的看板，連結到頻道。
Playbooks用於可重複流程的檢查清單，在頻道中執行。
GIF 和迷因GIF 和貼紙選擇器，以及使用模板製作的迷因，位於表情符號選擇器中。
行事曆與郵件每個人的個人行事曆和信箱，連結到他們自己的帳戶。
代理程式AI 助理，當伺服器已設定 AI 模型時。
GitHub、GitLab 和 Jira這些服務的通知和指令，一旦連接即可使用。

大多數應用程式從應用程式欄開啟，也就是視窗右側的圖示欄。應用程式是針對整個伺服器開啟或關閉的，設定位置在系統控制台 › 擴充程式：社群管理員無法為單一社群開啟或關閉應用程式。其設定也是伺服器層級的，除非本頁另有說明。若要新增應用程式或變更其設定，請向系統管理員提出。

在社群內，應用程式遵循頻道的權限：例如，只能讀取頻道的人可以看到其待辦事項清單和筆記，但不能修改它們，而頻道的管理員可以刪除其筆記和待辦事項。管理員和擁有 管理訊息 權限的人可以關閉頻道中的任何投票。

自訂表情符號

自訂表情符號是人們在訊息和反應中使用的圖像，就像其他表情符號一樣，透過在冒號之間輸入其名稱來使用，例如 :party_parrot:。

  1. 開啟表情符號選擇器（在訊息框中，或訊息上的 新增反應）。
  2. 在搜尋框旁邊選擇 +（新增自訂表情符號）。
  3. 在 新增 標籤頁中，選擇一張圖片：PNG、GIF（包括動態）、JPEG 或 WebP，最大 1 MB。
  4. 提供一個 名稱：小寫字母、數字，以及 -、+ 或 _。
  5. 選擇 新增表情符號。

所有自訂表情符號 分頁會列出這些表情符號，並提供搜尋框，您可以刪除有權限刪除的項目。

  • 自訂表情符號屬於整個伺服器，而非單一社群：伺服器上的所有人都可以使用。請選擇不會與其他社群的表情符號衝突的名稱。
  • 預設情況下，所有成員都可以新增自訂表情符號。使用者可以刪除自己的表情符號；只有系統管理員可以刪除其他人的表情符號，因此請要求管理員移除不需要的表情符號。系統管理員可以在伺服器的權限中變更此設定，或在系統控制台中透過 啟用自訂表情符號 關閉自訂表情符號功能。

GIF、貼紙與迷因

當這些應用程式啟用時，表情符號選擇器會包含 GIF、貼紙和迷因分頁。

  • GIF 和貼紙 來自系統管理員選擇的 GIF 服務，並附有由系統管理員設定的內容評級。當系統管理員允許時，使用者可以新增自己的 GIF 和貼紙。預設情況下只有系統管理員可以執行此操作；他們可以從選擇器，或從整合頁面中的 自訂 GIF 和 自訂貼紙 進行操作。新增的 GIF 和貼紙可供伺服器上的所有人使用。
  • 迷因：任何人都可以在迷因分頁中選擇範本，撰寫字幕並發布迷因。/meme 指令也可以使用。預設情況下，任何人都可以在迷因分頁搜尋框旁邊的 + 處新增迷因範本；系統管理員可以將此權限限制為僅系統管理員可用。範本由整個伺服器共用，只有建立者和系統管理員可以刪除它們。

在公開社群中，建議要求您的系統管理員將 GIF 和迷因範本的上傳權限僅限於管理員。

白板庫

社群管理員可以為社群中的所有人新增形狀庫：在白板中，開啟看板的選單或庫面板，並選擇 管理庫。庫是一個最大為 5 MB 的 .excalidrawlib 檔案。

Webhook、斜線指令和機器人

整合將您的社群與其他工具連接起來：例如發布警報的監控系統、發布答案的表單，或查詢資訊的指令。要設定這些整合，請點擊您的頭像並選擇 整合。您會看到您有權限管理的整合類型：

整合功能說明預設情況下誰可以建立
送入的 Webhook另一個服務透過呼叫秘密 URL 將訊息發布到頻道中。社群管理員
寄出的 Webhook頻道中包含觸發詞的訊息會發送到另一個服務，該服務可以回覆。社群管理員
斜線指令指令（例如 /weather）會呼叫其他服務，並在頻道中回覆。社群管理員
機器人帳號供程式使用的帳號，會以自己的名稱發文，並加上 機器人 標籤。系統管理員
OAuth 2.0 應用程式讓使用者使用 Antimatter 帳號登入的應用程式。系統管理員

具有 管理整合 自訂角色的使用者，也可以管理 Webhook 和斜線指令（請參閱 角色與權限）。Webhook 和斜線指令屬於建立它們的社群。

系統管理員必須在 系統控制台 › 整合 › 整合管理 中啟用各種整合功能。傳入和傳出 Webhook 以及斜線指令預設為啟用；建立機器人帳號預設為停用。請將 Webhook 的 URL 和指令的令牌視為密碼：任何擁有這些資訊的人都可以向您的社群發文。

若要建立整合、機器人或應用程式，請參閱 在 Antimatter 上開發。

自動連結

自動連結會將社群中所有訊息中的文字（例如問題編號）轉換為連結，無需安裝任何應用程式。社群管理員可在團隊設定 › 自動連結中進行設定；請參閱自動連結。

Playbooks

操作手冊是重複執行流程的檢查清單，例如處理事故、新同事入職或準備發布版本。每次流程啟動時，您都會執行操作手冊：Antimatter 會為該次執行建立或重用一個頻道，其中包含檢查清單、負責人及其狀態更新。

從應用程式欄開啟操作手冊。操作手冊屬於特定社群。預設情況下，任何可以建立頻道的人都可以建立操作手冊，因此實際上每位成員都可以。操作手冊可以對社群公開，也可以僅供其成員使用。

適合社群的良好操作手冊範例：歡迎新版主、處理檢舉、準備活動。適合組織的範例：事故回應、員工入職與離職。
