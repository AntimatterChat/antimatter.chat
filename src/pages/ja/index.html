チームのチャットも通話もアプリも、自分たちのサーバーで

Antimatterは、チャンネル、スレッド、音声ルーム、共同作業アプリ、AIをひとつにまとめ、自分たちの手で運用できるようにします。有料プランでしか使えない機能はありません。

はじめる 機能を見る
オープンソース（AGPL v3）ユーザー単位の課金なし、SSOの追加料金なしファイアウォールの内側で完全オフライン動作
Antimatterを選ぶ理由

会話は、自分たちの手元に

チャットサーバーには、チームの意思決定やファイル、これまでの経緯が蓄積されていきます。Antimatterなら、それらを自分たちが管理するインフラに置いたまま運用でき、どの機能を使ってよいかをベンダーに決められることもありません。

{{icon:server}}

セルフホスト

自社のハードウェアやクラウドで、DockerまたはリリースアーカイブとPostgreSQLを使って運用できます。ファイアウォールの内側で、完全にオフラインでも動作します。

{{icon:shield:anti}}

Mattermostという土台

大規模な組織で長年使われてきたMattermostサーバーがベースです。実績のあるメッセージ配信、権限管理、スケーラビリティを受け継いでいます。

{{icon:lock:spark}}

エンタープライズ機能もライセンス不要

SSOに追加料金はかかりません。SAMLとOpenID Connectによるシングルサインオン、LDAP同期、データ保持、コンプライアンスエクスポートなどを、すべてのサーバー、すべてのチームで利用できます。

{{icon:code}}

オープンソース

サーバー全体がAGPL v3.0の自由ソフトウェアです。コードを読むのも、監査するのも、改変するのも自由。何人で使っても構いません。

セキュリティと信頼性

10年にわたり重要な業務を支えてきたサーバーが土台

Antimatterは、セキュリティが重視される現場で信頼されてきた、成熟したオープンソースのサーバー上で動作します。確実なメッセージ配信、安定したデータモデル、ドキュメント化されたAPIにより、バージョンアップ後もデプロイや連携はそのまま動き続けます。

  • お使いのIDプロバイダーと連携：SAML、OpenID Connect、Google、Microsoft Entra、LDAPやActive Directoryとの同期、多要素認証。
  • きめ細かなアクセス制御：ロール、権限スキーム、属性ベースのアクセス制御、ゲストアカウント、IPフィルタリング。
  • コンプライアンス：データ保持ポリシー、コンプライアンスエクスポート、監査ログ、機密区分バナー、読んだら消えるメッセージ。
  • テレメトリーなし：サーバーが開発元に情報を送ることはありません。外部との通信が発生するのは、有効にした機能を使うときだけです。
アプリとChatOps

会話から離れずに、共同作業を

Antimatterのアプリはチャットの横に開き、ワンクリックでチャンネルに共有でき、変更は全員の画面にリアルタイムで反映されます。

  • メモ：リアルタイムで一緒に編集できる共同ドキュメント。
  • ホワイトボード：共有キャンバスで、絵を描いたり、図をスケッチしたり、ブレインストーミングしたり。
  • ボードとプレイブック：プロジェクト用のカンバンボードと、インシデント対応や定型業務のためのチェックリスト。
  • ToDoリスト、投票、カレンダー、メール：タスクも、ちょっとした意思決定も、予定も受信トレイも、チームのすぐそばに。
AIも、自分たちのルールで

選んだモデルで動くアシスタント

AIは出しゃばりません。入力欄のボタン、必要なときに開くパネル、頼んだときだけ作られる要約。手を借りたいときにはそこにあり、それ以外のときは邪魔をしません。OpenAI互換のモデルなら、自社のGPUで動かすものも含めて自由に接続でき、データが意図しない場所に送られることはありません。

  • 書き換えと修正：送信前のメッセージを、よりわかりやすく、短く、柔らかく、あるいは単に正しく整えます。
  • 通話の文字起こしと要約：通話中はライブ字幕を表示し、終了後は通話のスレッドに文字起こしと要約を投稿します。
  • エージェントパネル：チャンネルやスレッド、自分の仕事について、自分の権限の範囲で質問できます。
  • チャンネルの要約とまとめ：見逃した内容を数行で把握できます。
  • 自動翻訳によるチャンネルの翻訳と、リクエストに応じたメッセージの読み上げ。
通話と音声ルーム

文字を打つように、気軽に話そう

どの会話からでも通話を始められます。いつでも開いている音声チャンネルに、会議室へふらりと入るような感覚で参加することもできます。

  • 音声チャンネルはサイドバーに並び、誰がいて誰が話しているかがひと目でわかります。
  • ビデオと画面共有：画質プリセット、背景ぼかし、ピクチャーインピクチャーに対応。
  • 挙手、リアクション、参加者ごとの音量調整に加え、プッシュトゥトークやホスト向けの操作も。
  • ライブ字幕と文字起こし：自前の音声認識モデルで実現します。
連携

いつものツールとつながる

充実したREST API、Webhook、ボット、プラグインで、ほかのツールを会話の中に取り込めます。Mattermost向けに作られた連携機能もそのまま動作します。

  • GitHub、GitLab、Jira：通知、プレビュー、操作をチャンネルの中で。
  • Webhook、スラッシュコマンド、ボットで、CIパイプラインから監視まで、あらゆるものと接続できます。
  • インタラクティブメッセージとダイアログで、承認やフォーム入力をチャットの中で完結。
  • プラグインで、アプリ、メッセージタイプ、コマンド、パネルを追加できます。

はじめる

数分で使い始められます

composeファイルひとつで、Antimatterとデータベース、ファイルストレージ、GIFサービスが立ち上がります。最初に作成したアカウントが管理者になります。

$ curl -fsSLO https://antimatter.chat/compose.yaml
$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
$ docker compose up -d
