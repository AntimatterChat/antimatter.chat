チャンネルの作成

  1. コミュニティメニューを開き、チャンネルを作成を選択します。カテゴリの⋯メニューを開き、チャンネルを作成を選択すると、そのカテゴリ内に作成することもできます。
  2. チャンネルの種類を選択します。メッセージ、ファイル、スレッドにはテキスト、メンバーがいつでも参加・退出できる常時開通の通話には音声チャンネルを選択します。音声チャンネルは、サーバーでVoice ChannelsとCallsアプリが有効な場合に利用できます。
  3. 名前を入力します。チャンネルのアドレスはこれに基づいて作成されます。
  4. カテゴリを選択します。既存の全員向けカテゴリか、自分で作成したカテゴリのいずれかです。
  5. 招待された人のみが表示・参加できるようにするには、非公開チャンネルをオンにします。
  6. チャンネルを作成を選択します。

その他のオプション…を開くと、チャンネルのアドレスを編集したり、その目的を記述したりできる長いフォームが表示されます。

デフォルトでは、すべてのメンバーが公開チャンネルと非公開チャンネルの両方を作成できます。メンバーによるチャンネル作成を禁止するには、システム管理者がシステムコンソール（ユーザー管理 › 権限）でコミュニティの権限を変更します。カスタムロールで公開チャンネルの作成と非公開チャンネルの作成を付与することはできますが、メンバーからこれらの権限を取り除くことはできません。

全ユーザー向けのカテゴリ

カテゴリは、チャンネルリスト内でチャンネルをグループ化する見出しです。すべてのユーザーは、自分だけが確認できる独自のカテゴリを作成できます。コミュニティ管理者は、全ユーザー向けのカテゴリを作成することもできます。これらはすべてのメンバーに表示され、各自のカテゴリよりも上に表示されます。

全ユーザー向けのカテゴリの作成

  1. コミュニティメニューで、カテゴリを作成を選択します。
  2. 名前を入力し、全員向けをオンにします。
  3. 管理者のみがチャンネルをこのカテゴリに配置できるようにする場合、ロック済みをオンにします。ロック済みのカテゴリでは、すべてのユーザーに対して、チャンネルが配置された位置に固定されます。

全員向けのカテゴリは、チャンネルが1つでも含まれるまで非表示のままです。チャンネルをこのカテゴリに配置するには、チャンネルをそこにドラッグするか、チャンネルのメニューを開いて移動…を選択します。コミュニティ管理者は任意のカテゴリにチャンネルを配置できますが、チャンネル管理者は、自分のチャンネルをオープン（ロック解除済み）のカテゴリ間で移動するだけです。

オープンなカテゴリでは、メンバーは自分自身用のカテゴリにチャンネルを移動させることができます。ロックされたカテゴリでは移動できません。チャンネルのメニューには、カテゴリがロックされていることが表示されます。

すべてのユーザーのカテゴリを管理

カテゴリの ⋯ メニューを開きます。コミュニティ管理者には以下が表示されます。

  • 権限…: カテゴリ内のすべてのチャンネルが継承する権限（チャンネル権限
  • 全員に対して名前を変更…
  • ロック済み：カテゴリをロックまたはロック解除します。
  • 上へ移動 と 下へ移動: カテゴリの順序を変更します。すべてのユーザー用カテゴリ内のチャンネルは、アルファベット順でリスト表示されます。
  • 全員に対して削除：その中のチャンネルは、各ユーザーの個人用カテゴリに戻ります。

コミュニティレイアウトのプリセットを使用すると、すべてのユーザー用カテゴリが自動的に作成されます。コミュニティレイアウトを参照してください。

チャンネル設定

チャンネルのメニューを開き（ヘッダーのチャンネル名をクリックするか、チャンネルリストで右クリックして）、チャンネル設定を選択します。表示されるタブは、あなたの権限とサーバーの構成によって異なります。

  • 概要: 名前とアドレス、公開または非公開、目的（チャンネルの用途）、ヘッダー（チャンネル上部に表示されるリンク付きのテキスト行）、およびチャンネルの属性。デフォルトカテゴリは、ユーザーがチャンネルに参加した際に、そのチャンネルをどのカテゴリに配置するかを指定します。
  • 設定：
    • チャンネルバナー: チャンネル上部に表示される、テキスト付きのカラーバナーです。ルールやイベントなどの告知に使用できます。
    • 参加/退出システムメッセージ: このチャンネルでの「チャンネルに参加しました」および「チャンネルから退出しました」のメッセージを、すべてのユーザーに対して表示または非表示にします。
    • 自動翻訳: サーバーに翻訳サービスがある場合に表示されます。
  • メンバーシップポリシー と 権限ポリシー: ユーザーの属性に基づくルールです。システム管理者が属性ベースのアクセス制御を有効にした場合のみ表示されます。
  • アプリ: アプリによって追加される設定です。例えば 音声 を使用すると、チャンネルを音声チャンネルに切り替えたり、元に戻したりできます。
  • チャンネルをアーカイブ。
デフォルトでは、チャンネルのすべてのメンバーは、チャンネルの名前を変更し、ヘッダーや目的を変更し、メンバーの追加や削除を行い、アーカイブすることができます。これはアップストリームのデフォルト設定です。公開コミュニティでは、システムコンソールの ユーザー管理 › 権限 でシステム管理者にこれらの権限を制限するよう依頼するか、以下のチャンネル権限を使用して制限してください。

チャンネル権限

チャンネル権限により、ロールやユーザーが他の場所よりもそのチャンネル内でより多く、あるいはより少ない操作を行えるようになります。チャンネルのメニューを開き、権限…を選択してください。コミュニティ管理者とチャンネル管理者はこの項目を確認できます。

ダイアログは2つの部分から構成されています。

誰が見られるか

公開チャンネルはコミュニティの全員に公開されます。非公開チャンネルでは、ロールにチェックを入れることで、そのロールを持つ人のみがチャンネルに参加できます。ロールが付与されると自動的に追加され、ロールを失うと削除されます。ロールにチェックが入っていない場合、非公開チャンネルは招待された人のみ利用できます。

ここで実行できる操作

ロールを追加またはユーザーを追加…を選択し、各行をここでは拒否、他の場所と同じ、またはここでは許可に設定します：

行対象となる内容
メッセージの送信メッセージの投稿。
リアクションの追加リアクションの追加と削除。
ファイルの添付ファイルのアップロード。
@channel、@all、@hereのメンションチャンネル全体の通知。
グループとロールのメンションチームまたはロールへの通知。
メッセージの管理他の人のメッセージの編集と削除。
メンバーを管理するチャンネルメンバーの追加と削除。
チャンネルの管理名称の変更、ヘッダーと目的の変更。

各行の組み合わせ方:

  • ロールのここでは拒否は権限を剥奪し、別のロールのここでは許可はそれを付与します。ロール同士では、許可が優先されます。
  • 個人の設定は、その人のロールの設定よりも優先されます。
  • コミュニティ管理者には影響せず、権限はタイムアウトを解除しません。
  • 全ユーザー向けカテゴリ内のチャンネルは、カテゴリの権限を継承します。チャンネル自体の設定が、行ごとに優先されます。継承された行は「カテゴリから」と表示され、カテゴリと同じに設定すると行をリセットします。
  • コミュニティ管理者ではないチャンネル管理者は、自身が持つ権限の行のみ変更できます。

変更は即座に保存されます。

アナウンスチャンネルと読み取り専用チャンネル

チャンネル権限はロールと個人に適用され、「全員」には適用されません。したがって、一部の人のみ投稿可能なチャンネルを作成するには、2つの手順が必要です:

  1. システム管理者は、システムコンソール › ユーザー管理 › チャンネル内の、該当チャンネルの高度なアクセス制御セクションで、メンバーの投稿作成をオフにします。これにより、メンバーはそこに投稿できなくなります。
  2. チャンネルの権限…で、投稿すべきロール（例: "Staff" や "Moderators"）に対してメッセージの送信をここでは許可に設定します。

コミュニティ管理者は常に投稿できます。投稿できないメンバーには、メッセージ入力欄の代わりに「このチャンネルではメッセージを送信できません。」と表示されます。

すべてのメンバーにロールが付与されている場合（例: オンボーディングで付与されたロールなど）、システム管理者を介さずに設定できます。該当するロールに対してメッセージの送信をここでは拒否にし、投稿すべきロールに対してここでは許可に設定します。ロールを持たない人は影響を受けません。

チャンネルを非公開にする

チャンネルのメニューを開いて非公開チャンネルに変換…を選択するか、チャンネル設定の概要タブを使用します。デフォルトでは、この操作はコミュニティ管理者のみが実行でき、デフォルトチャンネルを非公開にすることはできません。コミュニティのインターフェースからは、非公開チャンネルを公開に戻すオプションは提供されていませんが、システム管理者はシステムコンソール › ユーザー管理 › チャンネル内の、該当チャンネルの公開チャンネルか非公開チャンネルスイッチで実行できます。

非公開チャンネルへの参加リクエスト

システム管理者が公開可能チャンネルを有効にしている場合（デフォルトでは無効）、非公開チャンネルは概要タブで公開可能（ユーザーが参加を申請できる）に設定できます。これにより、非メンバーはチャンネルを閲覧でそのチャンネルを確認し、メッセージを閲覧せずに参加を申請できます。申請は、チャンネルのメンバーリストの上部にある保留中の参加リクエストセクションに表示され、チャンネル管理者とコミュニティ管理者は承認または拒否ボタンで処理できます。

チャンネルをアーカイブする

アーカイブすると、チャンネルはリストから非表示になり、新しいメッセージの受信が停止しますが、履歴は保持されます。ユーザーは検索で見つけて、引き続き閲覧できます。チャンネルのメニューを開いてチャンネルをアーカイブ…を選択し、確認します。コミュニティ管理者は、アーカイブ済みチャンネルのメニューからチャンネルのアーカイブを解除を選択して復元できます。

  • Town Square、Off-Topic、およびコミュニティのデフォルトチャンネルもアーカイブできますが、コミュニティ管理者のみが実行できます。デフォルトチャンネル を参照してください。
  • インターフェースからチャンネルを完全に削除することはできません。完全削除はサーバーでデフォルトでは無効になっています。必要であればシステム管理者に依頼してください。

メッセージを上部に固定する

チャンネルに投稿できるユーザーは、メッセージのメニューから上部に固定を選択して、メッセージを1時間、4時間、1日、1週間、または削除するまで上部に固定できます。チャンネルには最大10件のメッセージを上部に固定できます。投稿できるユーザーは、固定を解除で固定を解除できます。この機能を制限するには、チャンネルへの投稿権限を制限してください。ピン留めされたメッセージも同様に動作します。チャンネルの閲覧権限があるユーザーは、ピン留めとピン留めの解除を行うことができます。

チャンネルをエクスポートする

チャンネルのメッセージのコピーを保持するには、メニューを開き、チャンネルをエクスポート…を選択します。メッセージの範囲（全期間、過去30日間、またはカスタム日付）とエクスポートを選択してください。スプレッドシートで開けるCSVファイルが生成されます。最大50,000件のメッセージが、作成者、時間、返信情報とともに含まれます。添付ファイルはファイル名のみがリストに表示され、ファイル本体は含まれません。削除されたメッセージや編集履歴は含まれません。

デフォルトでは、チャンネルの閲覧権限があるユーザーは、そのチャンネルをエクスポートできます。システム管理者は、システムコンソールのチャンネルのエクスポートを管理者に限定するオプションを有効にすることで、この操作をチャンネル管理者、コミュニティ管理者、およびシステム管理者に限定できます。

チャンネルメンバー

コミュニティの全員がすべてのチャンネルに参加している場合（全員がすべてのチャンネルに参加を参照）、管理するものがありません。ユーザーはフォローしていないチャンネルをミュートし、誰もチャンネルから削除されることはありません。

それ以外の場合、あるユーザーをチャンネルから削除するには、そのユーザー名を右クリックしてチャンネルから削除を選択するか、チャンネル内で/kick @usernameを入力してください。実行できるのは、そのチャンネルの管理者、コミュニティの管理者およびモデレーターのみです（モデレーターは、自分自身の最高権限より下のロールを持つユーザーのみを削除できます）。また、ユーザー自身はいつでもチャンネルから退出できます。コミュニティのデフォルトチャンネルからユーザーを削除することはできません。
