クイック検索

クイック検索は、1つのボックスからチャンネル、会話、人物、メッセージを検索できます。

  1. Ctrl+K（Macでは⌘+K）を押すか、すべてを検索（コミュニティレールの下端にある虫眼鏡アイコン）をクリックします。
  2. 数文字を入力します。入力に応じて結果が表示され、チャンネルと会話、人物、メッセージにグループ化されます。すべて、チャンネル、人物、メッセージのタブで絞り込みできます。
  3. 矢印キーで移動し、Enterキーを押して結果を開くか、クリックします。人物を選択すると、その人物とのダイレクトメッセージが開きます。

メッセージは現在のコミュニティ内で検索されます。すべてを検索するにはすべてのチームに切り替えます。一致するすべてのメッセージを表示するには、「…」のすべてのメッセージを検索を選択します。結果は右側のパネルに開きます。入力する前に、ボックスには最近の会話と最近の検索がリスト表示されます。

クイック検索には、参加しているチャンネルがリスト表示されます。参加していないチャンネルを探すには、コミュニティメニューのチャンネルを閲覧を使用します：チャンネルの検索と参加を参照してください。

メッセージの検索

  1. 会話上部の検索ボックス（コミュニティ名の後ろに「検索…」）をクリックします。
  2. 検索したい単語を入力します。ボックス下の候補には、現在地でのみ検索するための#channel内で検索（またはこの会話内で検索）、下のフィルター、最近の検索が表示されます。
  3. Enterキーを押します。検索結果が右側のパネルに開き、一致数が表示されます。

検索は単語全体と、*で終わる単語の先頭部分を探します。

フィルター

タイプ検索対象
from:@marieMarieが書いたメッセージ
in:designチャンネルまたは会話内のメッセージ
on:2026-10-051日分のメッセージ
before:2026-10-05, after:2026-09-01特定の日の前後のメッセージ
"exact phrase"これらの単語が、この順で一緒にあるメッセージ
-draft「draft」という単語を含まないメッセージ
deploy*「deploy」で始まる単語
ext:pdf特定のタイプのファイル
#hashtagそのハッシュタグを含むメッセージ

入力中に from: または in: を入力すると、該当するユーザーやチャンネルの候補が表示されます。on:、before:、after: の場合は、日付を選択 をクリックするとカレンダーが開きます。フィルターを組み合わせることもできます。例: release from:@marie in:platform after:2026-09-01。メッセージ内のハッシュタグをクリックすると、それに基づいて検索することもできます。

検索結果の利用

  • 結果をクリックすると、そのメッセージのある会話に移動します。該当するメッセージはハイライト表示されます。
  • 各結果には、スレッドを開く、保存する、チャンネルにピン留め、リンクをコピー のボタンがあります。
  • パネルの上部で メッセージ と ファイル を切り替えます。ファイルの場合は、ドキュメント、スプレッドシート、プレゼンテーション、コード、画像、音声、動画 でタイプ別にフィルターできます。
  • パネルを展開 をクリックして結果に広いスペースを確保するか、新しいウィンドウで開く を選択します。

該当する結果がない場合は、別のキーワードやフィルターを試してください。また、どのメッセージ入力欄でも /search の後にキーワードを入力して検索できます。

メンション、保存済み、ピン留めされたメッセージ

会話の右上にある受信トレイボタン（メンション、保存済み、ピン留め、スレッド）は、以下の項目を1つのパネルに集約します。

  • メンション: あなたをメンションしたメッセージ。
  • 保存しました: あなたが保存したメッセージ。
  • ピン留め: この会話にピン留めされたメッセージ。
  • ファイル: この会話で共有されたファイル。
  • スレッド: あなたがフォローしているスレッド。

ボタンにドットが表示されている場合、そこにあなたへのメンションがあることを示します。メンション、保存しました、スレッド では、上部の2つのボタンで この会話 の項目か コミュニティ全体 の項目かを選択できます。項目をクリックすると、その場所へ移動するか、スレッドを開くことができます。

ダイレクトメッセージのリスト（サイドバーの下部にある すべてのダイレクトメッセージ をクリック）にも同じリストがあります。メンション（未読メンションの数を含む）、フォロー中のスレッド、保存されたメッセージ はコミュニティ全体を対象とします。Ctrl+Shift+M（Macでは ⌘+Shift+M）を押すと、右側のパネルに 最近のメンション を開くことができます。

チャンネルの情報（チャンネル名をクリック）には、ピン留めされたメッセージ と ファイル へのリンクがあり、それぞれの件数も表示されます。

未読メッセージの確認

  • 未読メッセージのあるチャンネルを開くと、未読メッセージの開始位置を示す線が表示され、上部のバナーに前回アクセス以降に届いた新しいメッセージの件数が表示されます。移動 をクリックすると、最初の未読メッセージへ移動します。
  • 会話内で上にスクロールすると、下側に新しいメッセージの件数を数えるボタンが表示されます。これをクリックすると、新しいメッセージのある位置まで移動します。
  • デフォルトでは、未読の会話は最後に閲覧した位置から開かれます。代わりに最新のメッセージから開く場合は、設定 › メッセージ の 未読の会話を開く位置 を 最新のメッセージ に設定してください。
  • 後で戻って確認したい場合は、メッセージのメニューから 未読としてマークする を選択します。これにより、そのメッセージ以降の会話は未読のまま保持されます。
  • Alt+Shift+Up と Down で前または次の未読チャンネルに移動し、Ctrl+Shift+U でサイドバーに未読のチャンネルのみを表示します。
  • コミュニティメニューの すべて既読にする または Shift+Esc を使用すると、コミュニティ内のすべてのチャンネルを既読にします。

AIエージェントが設定されている場合、見逃した内容をサマリー化することもできます：チャンネルの最新情報を確認する および 要約 を参照してください。

メッセージとチャンネルへのリンク

すべてのメッセージとチャンネルにはリンクがあります。メニューから リンクをコピー を選択してください。リンクを開くと、閲覧可能なユーザーは該当箇所へ直接移動し、ハイライト表示されます。リンクが参加していない非公開チャンネルを指している場合、参加が許可されている場合、Antimatter は参加前に確認を求めます。
