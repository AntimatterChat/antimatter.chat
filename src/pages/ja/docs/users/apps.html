アプリの検索と開き方

管理者がサーバーに導入するアプリを選択するため、このページにすべてのアプリが表示されない場合があります。ほとんどのアプリには、ウィンドウの右端にあるあなたのアバターの下にあるアプリレールにアイコンが表示されます。アイコンにカーソルを合わせるとアプリ名が表示され、クリックすると会話の横のパネルでアプリが開きます。もう一度クリックするとパネルを閉じます。パネルの端をドラッグすると幅を広げられます。デフォルトの幅に戻すで元の幅に戻ります。パネルのヘッダーにある新しいウィンドウで開くは、メモ、ボード、またはリストを開いていた場所から、アプリを独立したウィンドウで開きます。

アプリは他の場所にも表示されます：

  • メッセージボックスの+メニュー（ファイルなどを追加）、例えば投票を作成など。
  • 絵文字ピッカーのタブ：GIFs、ステッカー、ミーム。
  • メッセージのメニュー（メッセージアクション、⋯）のその他のアクションの下に、例えばToDoに追加やプレイブックを実行などがあります。各アクションには、対応するアプリのアイコンが表示されます。
  • スラッシュコマンド、例えば/pollや/todo：/を入力するとリストが表示されます。
  • 一部のアプリの設定は、あなたの設定内のプラグインセクションにあります。

スマートフォンでは、アプリレールは右側のドロワーにあります。左にスワイプするか、会話のヘッダーでさらに › メンバーとアプリを選択してください。

メモ

Notesは、チャットの横で複数の人が同時に編集できるドキュメントです。他のユーザーが入力している間、そのカーソルと名前が表示され、入力した内容はすべて自動的に保存されます。

メモの作成

  1. アプリレールでNotesをクリックします。
  2. タブを選択します：このチャンネルはチャンネルの全メンバーが読み書きできるメモ、マイはあなただけが閲覧できる個人用メモです。
  3. パネルのヘッダーにある+（このチャンネルに新しいメモまたは新しい個人メモ）をクリックします。「Untitled note」が開きます。
  4. ヘッダーにタイトルを入力し、本文を書き込みます。ヘッダーの下にあるフォーマットバーは、メモを編集できるユーザーに表示され、太字、斜体、取り消し線、見出し、リスト、チェックリストを使用できます。リンク、引用、コードも機能します。その横にあるドットは、他の誰が編集中か、および変更が保存されたかを示します。@と入力すると、チャンネルのメンバーをメンションできます（メモ内のメンションは誰にも通知しません）。
  5. すべてのメモ（ヘッダー左側の矢印）をクリックすると、リストに戻ります。

チャンネル内のメモにタイトルが付けられると、Antimatter はそのチャンネルに「メモを共有しました」と投稿し、メモを開くボタンを表示します。

メモのその他の機能

メモにスターを付けると、お気に入りタブで見つけやすくなります。メモのメモアクションメニュー（⋯）には、チャンネルで共有（リンク付きカードを投稿）、~channelで共有（個人メモを恒久的にチャンネルメモにする）、バージョン履歴（表示およびこのバージョンを復元する）、Markdownとしてエクスポート、削除があります。チャンネルメモの削除は、メモの作成者とチャンネルの管理者のみ可能です。

ホワイトボード

ホワイトボードは、みんなで一緒に描くキャンバスです。図形、矢印、テキスト、フリーハンド描画が可能で、全員のポインターがリアルタイムで表示されます。

  1. アプリレールのホワイトボードをクリックします。
  2. メモと同様に、このチャンネルまたは自分のものを選択し、+（このチャンネルに新しいボードまたは新しい個人ボード）をクリックします。
  3. ツールで描画します：選択と移動 (V)、移動 (H)、長方形 (R)、楕円 (O)、矢印 (A)、描画 (P)、テキスト (T)、消しゴム (E)。ツールバーで色、線種、フォントを選択し、ライブラリから図形を選択します。元に戻す (Ctrl+Z)で直前の変更を取り消せます。

ボード操作メニューには、全画面表示、ボード全体を表示、.excalidraw、PNG、SVG形式でのダウンロード、バージョン履歴、.excalidrawファイルを読み込む…（全員のボードが置き換えられます）、チャンネルへの共有、削除があります。ホワイトボードはAntimatterサーバー上に保存されます。

Kanban

カンバンボードは、ワークを「ToDo」、「進行中」、「完了」などのカラム内のカードとして整理します。ボードは、テーブル、ギャラリー、カレンダー形式でも表示できます。

チャンネルのボードを開く

アプリレールでKanbanをクリックします。Kanbanは会話の横のパネルで開き、チャンネルにリンクされたボードがリスト表示されます。クリックするとボードが開きます。まだリンクされていない場合は、ボードを…にリンクをクリックし、ボードの横にあるリンクをクリックするか、ボードを作成します。チャンネルのメンバーは、リンクされたボードの編集者になります。ボードを表示している間、パネルは広くなります。パネル上部の戻る矢印で、前のビューに戻ります。

ボードで作業する

  • コミュニティのすべてのボードをカテゴリ別に確認するには、パネル内のすべてのボードをクリックします。ここでは、ボードの検索、ボードまたはカテゴリの作成、メニューからボードの移動・複製・エクスポート・非表示・削除を行うことができます。
  • ボードを作成するには、パネル内の新しいボードをクリックし、テンプレート（会議アジェンダ、プロジェクトタスク、ロードマップ、スプリントプランナーなど）から開始するか、空のボードを作成します。
  • カラム内の+ 新規をクリックしてカードを追加します。カードはパネル上に開き、プロパティの設定、テキスト・チェックボックス・画像の追加、ファイルの添付、コメントの投稿を行うことができます。カード内で誰かをメンションすると、その人に通知が送信されます。
  • カードをカラム間へドラッグして移動します。グループ化、フィルター、ソート、カードの検索を使用して目的の場所を見つけ、ビューの追加でテーブル、ギャラリー、またはカレンダービューを作成できます。
  • ボードの 共有 を使用して、ボードの閲覧または編集を許可するユーザーを選択します。

カレンダー

カレンダーアプリは、チャット横にあなたのカレンダーを表示し、リマインダーを送信し、Antimatter 内でミーティングを行うことを可能にします。Nextcloud、Fastmail、Radicale など、CalDAV を使用するカレンダーサーバーと連携できます。

カレンダーの接続

  1. アプリレールで カレンダー をクリックします。
  2. カレンダーの接続 で、CalDAV サーバー のアドレス（多くの場合、プロバイダーのドメイン名のみで構いません）、ユーザー名、パスワード を入力します。プロバイダーがアプリパスワードを提供している場合は、それを使用してください。
  3. アラームのないイベントのリマインダー のタイミングを選択し、接続 をクリックします。

パスワードは Antimatter サーバー上で暗号化されて保存されます。後でこれらの詳細を変更したり、接続を解除したりするには、パネル内の アカウント設定 を使用します。

使用方法

  • アジェンダ と 週 を切り替え、前へ、今日、次へ で移動し、カレンダーのチップをクリックして表示または非表示に切り替えます。
  • 新しいイベントをクリックし、タイトル、開始、終了を入力し、必要に応じて繰り返し、リマインダー、場所、説明を設定してから保存します。イベントをクリックすると、変更または削除を行うことができます。
  • Antimatterでミーティングを行うには、Antimatterでミーティングをチャンネルまたは音声チャンネル、または通話に設定し、チャンネルを選択します。時間になると、イベントに通話を開始、通話に参加、または参加するが表示されます。
  • リマインダーはカレンダーボットからのダイレクトメッセージとして届き、通話がある場合は通話に参加するためのリンクが付随します。

このアプリはあなた自身のカレンダーのみを表示し、他の人に招待を送信しません。

メール

メールアプリは、チャット横にメールボックスを表示するため、Antimatter を離れずにメールの読み取り、返信、共有を行うことができます。

メールボックスの接続

  1. アプリレールで メール をクリックします。
  2. 管理者が設定している場合、GoogleでサインインまたはMicrosoftでサインインをクリックします。それ以外の場合、または他のプロバイダーを使用する場合、電子メールアドレスとお名前を入力し、受信メール (IMAP)および送信メール (SMTP)サーバー、そのセキュリティ設定、ポート、ユーザー名、パスワードを入力します。これらの詳細は、プロバイダーのヘルプページで確認できます。
  3. 接続 をクリックします。

使用方法

  • フォルダーを選択し、このフォルダーを検索で検索して、メッセージをクリックして読みます。インターネットからの画像は、画像を表示をクリックするまで非表示になります。
  • 返信、全員に返信、または進むで応答するか、新しいメッセージで書き込みます。メッセージはプレーンテキストであり、新しいファイルを添付することはできません。
  • チャンネルに共有をクリックすると、メールの送信者、件名、抜粋をコメント付きでチャンネルに投稿できます。

投票

投票は会話内で質問を行い、全員がワンクリックで投票できます。結果はリアルタイムで更新されます。

  1. メッセージボックスの+をクリックして投票を作成を選択するか、/pollと入力します。
  2. 質問と少なくとも2つの選択肢を入力します。選択肢を追加で最大10個まで追加できます。
  3. 複数選択を許可する場合は複数回答を許可をオンにし、誰が何に投票したかを見せない場合は匿名投票をオンにします。
  4. 期間を1時間から1週間の間で選択するか、終了なしにします。
  5. 投票を公開をクリックします。

投票するには選択肢をクリックし、もう一度クリックすると投票を取り消せます。投票は期間終了時、または作成者またはチャンネル管理者が投票を終了をクリックした時点で終了し、その後最終結果が表示されます。

1行で投票全体を書くこともできます: /poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h。すべてのオプションについては /poll help を入力してください。

ToDo

TodoはToDoリストを管理します：チャンネルや会話で共有されたリスト、ご自身のリスト、および他の人に送信したToDoです。アプリレール内のTodoをクリックします。Notesと同様に、パネルには3つのタブがあります：

  • このチャンネル（またはこの会話）：そこにいるすべての人と共有されているリストです。パネルのヘッダー内の+（このチャンネルに新しいリスト）をクリックして作成します。
  • お気に入り：スターマークをつけたリスト（どこにあっても）。
  • マイ: 自分だけが確認できる個人用リストです（マイ ToDo は常に存在し、+ で新しいリストを作成できます）。その後、チャンネルで自分に割り当てられたもの、自分に送られたもの、自分が送ったもの が表示されます。

リストを開いて、詳細と必要に応じて期限を付けて ToDo を追加し、完了にするでチェックオフします。チャンネル内のリストでは、割り当て…でメンバーに ToDo を割り当て、個人用リストでは送信…で誰かに送信できます。受信者は承認、拒否、または完了にするを選択できます。リストのリスト操作メニューから、名前の変更、アイコンの変更、アーカイブ（アーカイブの下に移動し、読み取り専用になります）、削除を行うことができます。チャンネルに投稿できるすべての人がそのリストを変更できますが、リストの作成者とチャンネルの管理者のみが削除できます。

メッセージを ToDo に変換するには、そのメニューからその他のアクション › ToDo に追加を選択し、リストを指定します。ToDo ボットは、誰かがあなたに ToDo を割り当てたり送信したりしたときに通知し、1日1回あなたの ToDo をリマインドします。

コマンドも使用できます: /todo lists、/todo new name（自分のリストにする場合は --personal を追加）、リスト名を指定して追加する /todo add list: text、自分の ToDo に追加する /todo add text、そして /todo send @someone text。

GIF、ステッカー、ミーム

メッセージボックスの絵文字（スマイリーフェイス）をクリックします。これらのアプリが設定されている場合、ピッカーには絵文字の隣にGIF、ステッカー、ミームタブが表示されます。

  • GIF: 検索するか、お気に入り、最近使用したもの、トレンド、カテゴリをブラウズできます。GIF をクリックするとすぐに送信されます。星マークをクリックするとお気に入りに追加できます。また、/gif といくつかの単語を入力することもできます。
  • ステッカー: 検索するかステッカーパックを閲覧し、ステッカーをクリックして送信します。/sticker も使用できます。
  • ミーム: テンプレートを選択し、ミームを作成 でテキストを入力し、プレビューを確認して ミームを投稿 をクリックします。また、/meme を入力するか、/meme help を入力して1行で記述する方法を確認することもできます。

サーバーの設定によっては、検索ボックス横の+を使って、独自の GIF、ステッカー、またはミームテンプレートを追加できます。ピッカー内にフォームが開き、ファイルを選択、ドロップ、またはペーストし、プレビューを確認し、タイトル（ミームテンプレートの場合は名前）を入力し、必要に応じてタグやキーワードを付けてから追加（ミームテンプレートの場合はテンプレートを保存）をクリックします。追加したものはピッカーの先頭に表示され、サーバーの全員が検索できます。+の横のボタン（GIF の管理、ステッカーの管理、またはカスタムミームテンプレート）には、誰がいつ追加したかが一覧表示され、権限があるものを削除できます。ゲストは追加も削除もできません。

プレイブック

プレイブックは、毎回同じ手順で進める作業用の再利用可能なチェックリストです。インシデント、リリース、新入社員の歓迎などです。使用するたびに 実行 が開始され、独自のタスク、担当者、ステータス更新、そして最後に振り返りが行われます。

  • アプリレールでプレイブックをクリックすると、現在のチャンネルの実行状況を確認し、プレイブックを実行で開始したり、新しいチェックリストを素早く作成したりできます。プレイブックの内容はすべてこのパネルで開かれ、前のビューに戻る矢印が表示されます。
  • その他のすべてを表示するには、パネル上部の 実行、プレイブック、タスクを参照 をクリックします。すべての実行、すべてのプレイブック、あなたのタスク、お気に入り、進行中の実行が表示されます。
  • プレイブックを作成するには、そのビューで プレイブックを作成 または インポート をクリックします。編集するには、すべてのプレイブック から開きます。プロダクトリリース、インシデント解決、従業員オンボーディングなどのテンプレートから始めるか、空のプレイブックから始めることもできます。プレイブックエディターを表示すると、パネルが広くなります。
  • 実行を開始するには、プレイブックの 実行 をクリックし、実行に名前と概要を付け、チャンネルを作成するか既存のチャンネルにリンクするかを選択し、実行を開始 をクリックします。メッセージのメニューで その他のアクション › プレイブックを実行 を選択することもできます。
  • 実行中、タスクを完了としてマークし、担当者と期限を設定し、更新を投稿 をクリックして現在の状況を全員に伝えます。終了時にオーナーが 完了 をクリックします。

/playbook を入力すると、/playbook run や /playbook update などのコマンドを確認できます。

GitHub、GitLab、Jira

これらのアプリは、Antimatter を開発者が使用するツールに接続します。まず管理者が設定する必要があります。その後:

  1. /github connect、/gitlab connect、または /jira connect を入力してアカウントを接続し、リンクに従ってそのサイトでサインインします。GitLab の場合は、デスクトップアプリではなくWebブラウザでこれを行ってください。
  2. その後、誰かにメンションされたとき、レビューを依頼されたとき、またはタスクが割り当てられたときにダイレクトメッセージが届くようになります。
  3. チャンネルがリポジトリやプロジェクトをフォローするには、/github subscriptions add owner/repo、/gitlab subscriptions add group/project、または /jira subscribe を使用します。
  4. メッセージから問題を作成または関連付けするには、メッセージのメニューの その他のアクション 下で GitHub Issue を作成、GitLab Issue を作成、Jira Issue を作成、または該当する …に関連付け を選択します。

すべてのコマンドについては、/github help、/gitlab help、または /jira help を入力してください。

モバイルアプリでのアプリ

モバイルアプリでは、投票の作成と投票、GIF やステッカーの送信、あなたに送信されたタスクへの回答が可能です。メモとホワイトボードはアプリ内のブラウザウィンドウで開かれます。Kanban、カレンダー、メール、ミームは現時点ではモバイルアプリには対応していません。これらには Web またはデスクトップアプリを使用してください。
