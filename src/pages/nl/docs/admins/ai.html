“OpenAI-compatibel” betekent een server die dezelfde HTTP-API aanbiedt als OpenAI. De meeste modelserver die u zelf kunt draaien, doen dit (zoals Ollama, vLLM, de server van llama.cpp, of Whisper- en text-to-speech-servers), net als veel cloudproviders. Voor geen van deze functies is een licentie vereist.

AI-agents

De Agents-app (id mattermost-ai) is standaard ingeschakeld. Het instellen vereist twee stappen: voeg een service toe (een verbinding met een modelprovider) en maak vervolgens agents (bots die een service gebruiken).

1. Een service toevoegen

Ga naar Systeemconsole › Plugins › Agents en klik onder AI Services op Een AI-service toevoegen. Kies het Service type:

  • OpenAI Compatible: voor een modelserver die u zelf draait, of voor elke provider met een OpenAI-stijl API. Vul de API URL in (bijvoorbeeld http://ollama:11434/v1 of http://vllm.internal:8000/v1) en de API-sleutel alleen als de server er een vereist. Als de server alleen de Chat Completions API ondersteunt, schakel dan Use Responses API uit.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: gehoste providers. Elke provider vereist een API-sleutel (Bedrock: een AWS-regio en referenties of een IAM-role; Vertex AI: een project, regio en service account; Azure: ook de API URL).

Stel daarna het Standaard model in (een lijst als de provider zijn modellen kan rapporteren, anders typ je de naam in) en, als de provider ze niet rapporteert, de Tokenlimiet invoer en Tokenlimiet uitvoer. Een Reserve-service kan overnemen als deze faalt. Sla op.

De server voert deze aanvragen zelf uit, dus hij moet de API kunnen bereiken: een modelserver in hetzelfde compose-project, op je netwerk of op het internet. Uitgaande aanvragen respecteren de variabelen HTTP_PROXY en HTTPS_PROXY.

2. Agents aanmaken

Agents worden aangemaakt op de pagina Agents van de webapp: open deze via het productmenu of met Beheren in de agentkeuze van het Agents-paneel. Het adres is https://chat.example.com/plug/mattermost-ai/agents. Elke agent heeft een Weergavenaam, een Agent-gebruikersnaam (zoals mensen hem vermelden), een Service en optioneel een model, Aangepaste instructies en schakelaars voor Visie inschakelen (afbeeldingen) en Tools inschakelen. Het tabblad Toegang beperkt in welke kanalen de agent kan worden gebruikt en welke gebruikers hem kunnen gebruiken. Onder AI-functies in de Systeemconsole kiest Standaard bot de agent die wordt gebruikt als er geen is geselecteerd, bijvoorbeeld voor samenvattingen van gesprekken.

Standaard mag elke gebruiker eigen agents aanmaken, met de door jou geconfigureerde services. Om dit alleen voor beheerders te behouden, verwijder je de machtiging Eigen AI-agenten beheren van de rol voor leden in Systeemconsole › Gebruikersbeheer › Machtigingen.

Optionele functies van de Agents-app

  • Embedding-zoeken (experimenteel, uit): semantisch zoeken door berichten. Dit vereist PostgreSQL met de pgvector-extensie en een embedding-model (OpenAI of OpenAI-compatibel). Het stuurt elk bericht naar het embedding-model, inclusief privé-kanalen en privéberichten.
  • Webzoeken (uit): laat agents het web doorzoeken via Google, Brave of een SearXNG-server die je zelf draait.
  • Inheemse tools: bij providers die ze aanbieden, kunnen agents de eigen webzoekfunctie van de provider gebruiken (standaard ingeschakeld voor nieuwe agents, indien ondersteund), web fetch en code-uitvoering. Deze worden uitgevoerd bij de provider. Schakel ze per agent uit.
  • Model Context Protocol (MCP): verbind agents met MCP-servers die je vertrouwt, voor extra tools.
  • Debug: Trace Output (uit, serverlog of een OpenTelemetry-endpoint) en Token Usage Logging inschakelen, dat tokenaantallen schrijft naar logs/agents/token_usage.log.

Spraak-naar-tekst: transcripties en ondertiteling van gesprekken

Gesprekken kunnen worden getranscribeerd, met live ondertiteling, door een spraak-naar-tekstserver die een OpenAI-compatibele /v1/audio/transcriptions-endpoint aanbiedt. De configuratie staat in Gesprekken en spraak. Als Transcripties samenvatten is ingeschakeld, plaatst de standaardagent ook een samenvatting van elk transcript.

Tekst naar spraak: voorlezen

Als tekst naar spraak is ingeschakeld, heeft het menu van elk bericht Voorlezen: de server stuurt de tekst van het bericht naar een tekst-naar-spraak-API en speelt de audio af. De instellingen staan in Systeemconsole › Integraties › Tekst naar spraak:

InstellingSleutel en variabeleWat er in moet
Berichten hardop voorlezenTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (standaard uitgeschakeld)
API-basis-URLTextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLDe basis-URL tot en met /v1, bijvoorbeeld http://tts.internal:8000/v1. De server roept de /audio/speech-endpoint aan.
ModelTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELHet model zoals de API het noemt, bijvoorbeeld tts-1. Verplicht.
StemTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEEen van de stemmen van het model, of leeg voor de standaardstem.
API-sleutelTextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYWordt verzonden als bearer token. Leeg als de API er geen nodig heeft.

Voor verzending verwijdert de server codeblokken, links, emoji-codes en opmaak, en behoudt maximaal 4000 tekens. Het vraagt om MP3-audio en bewaart de laatste 64 resultaten in het geheugen, zodat een bericht dat twee keer wordt voorgelezen maar één keer wordt verzonden.

Automatische vertaling

Automatische vertaling toont de berichten van een kanaal in de eigen taal van elke lezer. Configureer dit in Systeemconsole › Site Configuratie › Lokalisatie, onder Automatische vertaling:

InstellingSleutelStandaardwaarde
InschakelenAutoTranslationSettings.EnableUit
VertaalproviderAutoTranslationSettings.Providerlibretranslate, openai (weergegeven als "OpenAI-compatible API") of agents (een service van de Agents-app)
Toegestane talenAutoTranslationSettings.TargetLanguagesen: de talen waarnaar berichten kunnen worden vertaald
Time-out vertaling (ms)AutoTranslationSettings.TimeoutMs5000
Automatische vertaling beperken voor privéberichten en groepsberichtenAutoTranslationSettings.RestrictDMAndGMUit

Elke provider heeft zijn eigen velden:

  • LibreTranslate: LibreTranslate API Endpoint en LibreTranslate API-sleutel (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Een LibreTranslate-server kan op uw eigen netwerk draaien.
  • OpenAI-compatible API: API-basis-URL (tot en met /v1; de server gebruikt de chat completions endpoint), Model en API-sleutel (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Een klein vertaalmodel dat lokaal draait werkt goed.
  • Agents: AI-Service, een van de services die zijn geconfigureerd in de Agents-app.

Wanneer de functie is ingeschakeld, schakelen kanaalbeheerders de vertaling in voor een kanaal in de instellingen (Automatische vertaling), en elk lid kan zich uitschakelen via het kanaalmenu (Berichten vertalen). In privé- en groepsberichten kan elk lid de functie inschakelen; als de beperking is ingeschakeld, is vertaling daar niet beschikbaar. Vertaalde berichten tonen “Vertaald van …” met een link naar het origineel.

Code, links, vermeldingen en emoji’s worden door placeholders vervangen voordat de tekst wordt verzonden, en daarna weer hersteld.

Om alles binnen uw netwerk te houden, wijst u elke functie naar servers die u zelf draait. Bij een cloudprovider controleert u de voorwaarden voor het bewaren van gegevens en informeert u uw gebruikers welke functies hun berichten naar buiten sturen.

AI uitschakelen

Er is geen enkele schakelaar: elke functie heeft er een eigen.

  • Agents: schakel de Agents-app uit in Systeemconsole › Plugins › Plugin Beheer. Hiermee worden ook de samenvattingen van gesprekken en de vertaalprovider van Agents verwijderd.
  • Transcriptie en ondertiteling: AM_CALLS_ENABLE_TRANSCRIPTIONS=false en AM_CALLS_ENABLE_LIVE_CAPTIONS=false (de standaardwaarden).
  • Voorlezen: Berichten hardop voorlezen uitschakelen (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, de standaardwaarde).
  • Vertaling: automatische vertaling uitschakelen (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, de standaardwaarde).

Het uitschakelen van de Agents-app schakelt de andere drie functies niet uit: die roepen hun eigen API’s rechtstreeks aan.
