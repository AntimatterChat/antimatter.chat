„Compatibil OpenAI” înseamnă un server care oferă aceeași API HTTP ca OpenAI. Majoritatea serverelor de modele pe care le puteți rula singuri o fac (de exemplu Ollama, vLLM, serverul llama.cpp, sau servere Whisper și de sinteză vocală), la fel ca mulți furnizori de cloud. Nu este necesară nicio licență pentru niciuna dintre aceste funcții.

Agenți AI

Aplicația Agents (id mattermost-ai) este activă implicit. Configurarea ei necesită două pași: adăugați un serviciu (o conexiune la un furnizor de modele), apoi creați agenți (boți care folosesc un serviciu).

1. Adăugați un serviciu

Accesați Consola de sistem › Plugin-uri › Agenți și, în secțiunea AI Services, faceți clic pe Add an AI Service. Selectați Service type:

  • OpenAI Compatible: pentru un server de modele pe care îl rulați dumneavoastră sau pentru orice furnizor cu o API în stil OpenAI. Completați API URL (de exemplu http://ollama:11434/v1 sau http://vllm.internal:8000/v1) și Cheie API doar dacă serverul necesită una. Dacă serverul suportă doar API-ul Chat Completions, dezactivați Use Responses API.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: furnizori găzduiți. Fiecare necesită o Cheie API (Bedrock: o regiune AWS și credentiale sau un rol IAM; Vertex AI: un proiect, o regiune și un cont de serviciu; Azure: și URL-ul API).

Apoi setați Modelul implicit (o listă dacă furnizorul poate raporta modelele sale, altfel tastați numele), precum și, dacă furnizorul nu le raportează, Limita de tokeni de intrare și Limita de tokeni de ieșire. Un Serviciu de rezervă poate prelua controlul în cazul în care acesta eșuează. Salvați.

Serverul efectuează aceste cereri în mod autonom, deci trebuie să poată accesa API-ul: un server de modele din același proiect compose, din rețeaua dumneavoastră sau de pe Internet. Cererile în afine respectă variabilele HTTP_PROXY și HTTPS_PROXY.

2. Crearea agenților

Agenții sunt creați în pagina Agenți a aplicației web: deschideți-o din meniul produsului sau cu Gestionează în selectorul de agenți din panoul Agenți. Adresa sa este https://chat.example.com/plug/mattermost-ai/agents. Fiecare agent are un Nume afișat, un Agent Username (cum îl menționează utilizatorii), un Service și, opțional, un model, Custom Instructions, și comutatoare pentru Enable Vision (imagini) și Enable Tools. Tab-ul Acces limitează în ce canale poate fi utilizat și de ce utilizatori. În AI Functions din Consola de sistem, Default bot alege agentul utilizat când niciunul nu este selectat, de exemplu pentru rezumatele apelurilor.

În mod implicit, fiecare utilizator poate crea agenți proprii, cu serviciile configurate de dumneavoastră. Pentru a restricționa această capacitate doar administratorilor, eliminați permisiunea Gestionează agenții AI proprii din rolul membrilor în Consola de sistem › Gestionarea utilizatorilor › Permisiuni.

Funcționalități opționale ale aplicației Agenți

  • Căutare prin embedding (experimental, dezactivat): căutare semantică peste mesaje. Necesită PostgreSQL cu extensia pgvector și un model de embedding (OpenAI sau compatibil cu OpenAI). Trimite fiecare mesaj către modelul de embedding, inclusiv în canalele private și mesajele directe.
  • Căutare web (dezactivat): permite agenților să caute pe web prin Google, Brave sau un server SearXNG pe care îl rulați.
  • Instrumente native: cu furnizorii care le oferă, agenții pot utiliza căutarea web proprie a furnizorului (activată implicit pentru agenții noi, unde este suportată), preluarea de pe web și execuția de cod. Acestea se execută la furnizor. Dezactivați-le per agent.
  • Protocolul de context al modelului (MCP): conectați agenții la servere MCP de încredere, pentru instrumente suplimentare.
  • Dezvoltare: Ieșire de urmărire (dezactivat, jurnalele serverului sau un endpoint OpenTelemetry) și Activează jurnalizarea utilizării tokenilor, care scrie numerele de tokeni în logs/agents/token_usage.log.

Vorbire în text: transcrieri și subtitrări pentru apeluri

Apelurile pot fi transcrise, cu subtitrări în direct, de către un server de conversie de vorbire în text care oferă un endpoint /v1/audio/transcriptions compatibil cu OpenAI. Configurarea se face în Apeluri și voce. Cu Rezumă transcrierile activat, agentul implicit publică și un rezumat pentru fiecare transcriere.

Conversie de text în voce: citire cu voce tare

Cu funcția text în vorbire activată, meniul fiecărui mesaj include Citește cu voce tare: serverul trimite textul mesajului către o API text în vorbire și redă audio. Setările se găsesc în Consola de sistem › Integrări › Text în vorbire:

SetareCheie și variabilăCe trebuie introdus
Citește mesajele cu voce tareTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (dezactivat implicit)
URL de bază APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLURL-ul de bază, inclusiv /v1, de exemplu http://tts.internal:8000/v1. Serverul apelează endpoint-ul /audio/speech.
ModelTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELModelul, așa cum este denumit de API, de exemplu tts-1. Obligatoriu.
VoceTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEUna dintre vocile modelului, sau lăsați gol pentru vocea implicită.
Cheie APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYSe trimite ca token bearer. Lăsați gol dacă API-ul nu necesită o cheie.

Înainte de trimitere, serverul elimină blocurile de cod, linkurile, codurile emoji și formatarea, și păstrează cel mult 4000 de caractere. Solicită audio în format MP3 și păstrează ultimele 64 de rezultate în memorie, astfel încât un mesaj citit de două ori este trimis o singură dată.

Traducere automată

Traducerea automată afișează mesajele unui canal în limba proprie a fiecărui cititor. Se configurează în Consola de sistem › Configurația site-ului › Localizare, în secțiunea Traducere automată:

SetareCheieImplicit
ActivareAutoTranslationSettings.Enabledezactivat
Furnizor de traducereAutoTranslationSettings.Providerlibretranslate, openai (afisat ca „API compatibil cu OpenAI”) sau agents (un serviciu al aplicației Agents)
Limbi permiseAutoTranslationSettings.TargetLanguagesen: limbile în care pot fi traduse mesajele
Limita de timp pentru traducere (ms)AutoTranslationSettings.TimeoutMs5000
Restrictie pentru traducerea automată în mesajele directe și mesajele de grupAutoTranslationSettings.RestrictDMAndGMdezactivat

Fiecare provider are propriile câmpuri:

  • LibreTranslate: Endpoint API LibreTranslate și Cheie API LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Un server LibreTranslate poate rula pe rețeaua dvs.
  • API compatibil cu OpenAI: URL de bază API (inclusiv /v1; serverul folosește endpoint-ul de completări de chat), Model și Cheie API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Un model de traducere mic, rulat local, funcționează bine.
  • Agenți: Serviciu AI, unul dintre serviciile configurate în aplicația Agenți.

Odată activată, administratorii de canal activează traducerea pentru un canal din setările acestuia (Traducere automată), iar fiecare membru poate dezactiva această opțiune din meniul canalului (Tradu mesajele). În mesajele directe și de grup, orice membru poate activa traducerea; dacă restricția este activată, traducerea nu este disponibilă acolo. Mesajele traduse afișează „Tradus din …” cu un link către mesajul original.

Codul, linkurile, mențiunile și emoji-urile sunt înlocuite cu locuri rezervate înainte ca textul să fie trimis, și readuse ulterior.

Dezactivarea AI

Nu există un singur comutator: fiecare funcție are propriul.

  • Agenți: dezactivați aplicația Agenți în Consola de sistem › Plugin-uri › Gestionare. Acest lucru elimină și rezumatele apelurilor și furnizorul de traducere pentru agenți.
  • Transcriere și subtitrări: AM_CALLS_ENABLE_TRANSCRIPTIONS=false și AM_CALLS_ENABLE_LIVE_CAPTIONS=false (valorile implicite).
  • Citește cu voce tare: dezactivați Citește mesajele cu voce tare (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, valoarea implicită).
  • Traducere: dezactivați traducerea automată (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, valoarea implicită).

Dezactivarea aplicației Agenți nu dezactivează celelalte trei: ele apelează propriile API-uri direct.
