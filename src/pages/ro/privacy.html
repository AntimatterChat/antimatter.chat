Juridic

Politica de confidențialitate

Ultima actualizare: 16 octombrie 2026.

Această pagină acoperă două aspecte: software-ul Antimatter, pe care organizațiile îl rulează pe propriile servere, și acest site, antimatter.chat.

Software-ul Antimatter

Antimatter este auto-găzduit (self-hosted). Când folosiți un server Antimatter, organizația care îl administrează decide ce date sunt păstrate, pentru cât timp și cine are acces la ele. Proiectul Antimatter nu are acces la serverul, contul sau mesajele dumneavoastră. Pentru întrebări privind datele de pe un anumit server, contactați administratorii acestuia; se aplică propria lor politică de confidențialitate.

Ce face software-ul de sine stătător:

  • Nicio telemetrie. Serverul nu trimite statistici de utilizare, diagnostice sau alte date către proiectul Antimatter, către Mattermost, Inc. (pe a cărui software se bazează Antimatter) sau către alte terțe părți.
  • Conexiuni externe doar pentru funcțiile activate de un administrator, către serviciile pe care aceștia le configurează: de exemplu, un serviciu de notificări push, un furnizor de GIF-uri, un server de e-mail, un furnizor de identitate pentru autentificare unică (single sign-on) sau modele de inteligență artificială, vorbire sau traducere.
  • Doi excepții, activate implicit, pe care administratorii le pot dezactiva. Previzualizările de linkuri: când cineva postează un link, serverul descarcă acea pagină pentru a afișa titlul și imaginea acesteia. Și apelurile: acestea folosesc serverul STUN public al Cloudflare (stun.cloudflare.com) pentru a găsi adresele de rețea publice. Serverul îl interoghează când aplicația Calls pornește, iar dispozitivul fiecărei persoane îl interoghează când se alătură unui apel. Cloudflare vede doar adresa IP și portul serverului și al fiecărei persoane care se alătură, nu însă și apelul în sine. Administratorii pot folosi în schimb propriul server STUN sau niciunul; consultați Apeluri și voce.
  • Funcțiile de inteligență artificială folosesc modelele alese de administrator. Când acestea sunt găzduite de o terță parte, ceea ce este trimis către ele (un mesaj de reformulat, o conversație de rezumatat, audio-ul unui apel transcris) ajunge la acel furnizor. Administratorii pot folosi modele auto-găzduite astfel încât nimic să nu părăsească rețeaua lor.

Acest site

  • antimatter.chat este un site static găzduit pe GitHub Pages.
  • Nu setează biscuiți și nu folosește analitică, instrumente de urmărire sau publicitate. Fonturile și imaginile sunt servite de pe site, astfel încât browserul nu face nicio cerere către alte site-uri web în timp ce îl citești.
  • Ca orice gazdă web, GitHub primește adresa ta IP și paginile pe care le soliciți, pentru a le servi. Vezi Declarația de confidențialitate GitHub.
  • Dacă deschizi o problemă sau contribui pe GitHub, ceea ce postezi acolo este public și este gestionat de GitHub în conformitate cu propriile sale condiții.
