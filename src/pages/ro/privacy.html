Politica de confidențialitate

Ultima actualizare: 11 octombrie 2026. Această traducere este oferită pentru confortul cititorilor; în caz de neconcordanță, prevalează versiunea în limba engleză.

Această pagină se referă la două lucruri: software-ul Antimatter, pe care organizațiile îl rulează pe propriile servere, și acest site, antimatter.chat.

Software-ul Antimatter

Antimatter este găzduit de fiecare organizație pe propria infrastructură. Când folosești un server Antimatter, organizația care îl administrează decide ce date sunt păstrate, pentru cât timp și cine are acces la ele. Proiectul Antimatter nu are acces la serverul, contul sau mesajele tale. Pentru întrebări despre datele tale de pe un anumit server, contactează administratorii acestuia; se aplică propria lor politică de confidențialitate.

Ce face software-ul de la sine:

  • Fără telemetrie. Serverul nu trimite statistici de utilizare, date de diagnosticare sau alte date către proiectul Antimatter ori către terți.
  • Conexiuni externe doar pentru funcțiile activate de un administrator, către serviciile configurate de acesta: de exemplu, un serviciu de notificări push, previzualizări ale site-urilor ale căror linkuri sunt publicate în mesaje, un furnizor de GIF-uri, un server de e-mail, un furnizor de identitate pentru autentificarea unică sau modele AI, de vorbire ori de traducere.
  • Funcțiile AI folosesc modelele alese de administrator. Când acestea sunt găzduite de un terț, ceea ce li se trimite (un mesaj de reformulat, o conversație de rezumat, sunetul unui apel transcris) ajunge la furnizorul respectiv. Administratorii pot folosi modele găzduite pe propria infrastructură, astfel încât nimic să nu iasă din rețeaua lor.

Acest site

  • antimatter.chat este un site static găzduit pe GitHub Pages.
  • Nu setează niciun cookie și nu folosește instrumente de analiză, de urmărire sau publicitate. Fonturile și imaginile sunt servite chiar de site, așa că browserul tău nu trimite cereri către alte site-uri cât timp îl citești.
  • Ca orice furnizor de găzduire web, GitHub primește adresa ta IP și paginile pe care le soliciți, pentru a ți le putea servi. Consultă declarația de confidențialitate GitHub.
  • Dacă deschizi un issue sau contribui pe GitHub, ce publici acolo este public și este gestionat de GitHub conform propriilor sale condiții.
