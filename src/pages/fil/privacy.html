Patakaran sa privacy

Huling na-update: 16 Oktubre 2026.

Dalawang bagay ang tinalakay sa pahinang ito: ang Antimatter software, na pinapatakbo ng mga organisasyon sa kanilang sariling server, at ang antimatter.chat website.

Ang Antimatter software

Self-hosted ang Antimatter. Kapag ginagamit ang Antimatter server, ang organisasyon na nagpapatakbo nito ang nagpapatupad kung anong datos ang itatago, para saan, at sino ang makakapag-access. Hindi may access ang Antimatter project sa iyong server, account, o mga mensahe. Para sa mga tanong tungkol sa iyong datos sa isang partikular na server, makipag-ugnayan sa mga administrator nito; ang kanilang sariling patakaran sa privacy ang gagamitin.

Ang ginagawa ng software sa sarili:

  • Wala na telemetry. Hindi nagpapadala ng mga estadistika ng paggamit, diagnostics, o anumang ibang datos ang server sa Antimatter project, sa Mattermost, Inc. (na base ang Antimatter sa software nito), o sa ibang third parties.
  • Ang mga koneksyon sa labas ay para lamang sa mga feature na pinapaganda ng administrator, sa mga serbisyo na kanilang inuugnay: halimbawa, push notification service, GIF provider, email server, identity provider para sa single sign-on, o mga model ng AI, speech, o translation.
  • Dalawang exception, na on sa default, na maaaring patayin ng administrator. Link previews: kapag may nag-post ng link, hihikain ng server ang pahinang iyon upang ipakita ang title at larawan nito. At ang mga tawag: gumagamit ng public STUN server ng Cloudflare (stun.cloudflare.com) upang makahanap ng public network addresses. Hihikain ng server ito kapag nagsimula ang Calls app, at hihikain ng device ng bawat tao ito kapag sumali sila sa tawag. Nakikita ng Cloudflare ang IP address at port ng server at ng bawat sumali, hindi ang tawag mismo. Maaaring gamitin ng administrator ang kanilang sariling STUN server, o wala; tingnan ang Calls and voice.
  • Gumagamit ng mga model na pinili ng administrator ang mga AI feature. Kapag hosted ng third party, ang ipinadala sa kanila (mensahe na isusulat muli, usapan na i-summarize, audio ng transcribed na tawag) ay pumupunta sa provider na iyon. Maaaring gamitin ng administrator ang self-hosted models upang hindi lumabas ng network ang anumang bagay.

Ang website

  • Ang antimatter.chat ay isang static website na hosted sa GitHub Pages.
  • Ito ay walang gumagamit ng cookies, at walang analytics, trackers, o advertising. Ang mga font at imahe nito ay mula sa site mismo, kaya hindi gumagawa ng request ang iyong browser sa ibang website habang binabasa mo ito.
  • Gaya ng anumang web host, tinatanggap ng GitHub ang iyong IP address at ang mga hinihiling mong pahina upang maipasa ito. Tingnan ang GitHub Privacy Statement.
  • Kung magbubukas ka ng issue o magbibigay ng kontribusyon sa GitHub, ang iyong ipinost ay pampubliko at pinangangalangan ng GitHub alinsunod sa sariling terms nito.

Makipag-ugnayan

Para sa mga tanong tungkol sa patakaran na ito, magbukas ng issue sa Antimatter community repository.

Maaaring baguhin namin ang patakaran na ito; ang petsa sa itaas ay nagpapakita kailan itong huling binago.
