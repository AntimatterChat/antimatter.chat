Patakaran sa privacy

Huling na-update: Oktubre 11, 2026. Ibinibigay ang salin na ito para sa iyong kaginhawahan; kung may hindi pagkakatugma, ang bersyong Ingles ang masusunod.

Dalawang bagay ang saklaw ng pahinang ito: ang Antimatter software, na pinapatakbo ng mga organisasyon sa sarili nilang mga server, at ang website na ito, ang antimatter.chat.

Ang Antimatter software

Self-hosted ang Antimatter. Kapag gumagamit ka ng isang Antimatter server, ang organisasyong nagpapatakbo nito ang nagpapasya kung anong data ang itinatago, gaano katagal, at kung sino ang may access dito. Walang access ang Antimatter project sa iyong server, sa iyong account o sa iyong mga mensahe. Para sa mga tanong tungkol sa data mo sa isang partikular na server, makipag-ugnayan sa mga administrator nito; ang sarili nilang patakaran sa privacy ang umiiral.

Ang ginagawa ng software nang mag-isa:

  • Walang telemetry. Hindi nagpapadala ang server ng mga usage statistic, diagnostic o anumang iba pang data sa Antimatter project o sa mga third party.
  • May koneksyon lang palabas para sa mga feature na in-on ng isang administrator, papunta sa mga serbisyong na-configure nila: halimbawa, isang push notification service, mga link preview ng mga website na naka-post sa mga mensahe, isang GIF provider, isang email server, isang identity provider para sa single sign-on, o mga AI, speech o translation model.
  • Ginagamit ng mga AI feature ang mga model na pinili ng administrator. Kapag naka-host ang mga ito sa isang third party, napupunta sa provider na iyon ang anumang ipinapadala sa kanila (isang mensaheng ire-rewrite, isang usapang bubuurin, ang audio ng isang tawag na tina-transcribe). Puwedeng gumamit ang mga administrator ng mga self-hosted na model para walang anumang lumabas sa kanilang network.

Ang website na ito

  • Ang antimatter.chat ay isang static na website na naka-host sa GitHub Pages.
  • Wala itong itinatakdang cookie, at hindi ito gumagamit ng analytics, tracker o advertising. Mula mismo sa site ang mga font at larawan nito, kaya walang request sa ibang website na ginagawa ang iyong browser habang binabasa mo ito.
  • Gaya ng anumang web host, natatanggap ng GitHub ang iyong IP address at ang mga pahinang hinihiling mo, para maihatid ang mga ito. Tingnan ang GitHub Privacy Statement.
  • Kung magbubukas ka ng issue o mag-aambag sa GitHub, pampubliko ang anumang ipo-post mo roon at pinangangasiwaan ito ng GitHub ayon sa sarili nitong mga tuntunin.

Pakikipag-ugnayan

Para sa mga tanong tungkol sa patakarang ito, magbukas ng issue sa repository ng website.

Maaari naming i-update ang patakarang ito; makikita sa petsa sa itaas kung kailan ito huling binago.
