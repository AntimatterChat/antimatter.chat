Mag-imbita ng mga tao

Buksan ang menu ng komunidad at piliin ang Mag-imbita ng mga tao. Sa default, maaaring mag-imbita ng mga tao ang bawat miyembro; nawawala ang item para sa mga hindi kayang mag-imbita.

  1. Sa ilalim ng Mag-imbita bilang, piliin ang Miyembro o Bisita. Lumalabas lamang ang opsyon na ito kapag aktibo ang mga bisita sa server.
  2. Sa Sa:, i-type ang mga pangalan ng mga taong mayroon nang account sa server, o ang mga email address ng mga taong wala.
  3. Sa ilalim ng Magdagdag sa mga channel, piliin ang mga channel na sasaliin ng mga imbitadong tao. Ito ay opsyonal para sa mga miyembro, ngunit kinakailangan para sa mga bisita.
  4. Opsyonal, piliin ang Itakda ang custom message upang magdagdag ng ilang salita sa email ng imbitasyon.
  5. Piliin ang Mag-imbita. Makikita sa isang buod kung sino ang imbitado at alin sa mga imbitasyon ang hindi maipadala.

Ang pag-imbita gamit ang email ay nangangailangan na maipadala ng server ang email, at na aktibo ang mga email imbitasyon. Kung hindi maipadala ng server ang email, maaari pa ring dagdagan ang mga taong mayroon nang account. Tanungin ang iyong system admin kung tinatanggihan ang mga email address.

Ibahagi ang invite link

Sa parehong dialog, kapag pinili ang Miyembro, ang Kopyahin ang invite link ay kopyahin ang invitation link ng komunidad. Ang sinumang bubuksan ito ay maaaring gumawa ng account (kung pinapayagan ng server ang sign-up) at sumali sa komunidad. Ibahagi ito sa isang newsletter, sa isang website, o sa isang forum post.

Mananatiling valid ang link hangga't hindi ninyo ito palitan. Kung mabubulok ito sa hindi dapat na lugar, gumawa ng bago gamit ang I-regenerate sa Mga setting ng team › Access: ang lumang link ay titigil na. May isang link ng imbitasyon lamang ang isang community sa isang pagkakataon.

Mag-imbita ng kilala mo

Upang dalhin ang isang tao mula sa ibang community sa inyong community, i-right-click ang pangalan nila at piliin ang Mag-imbita sa komunidad, tapos ang community. Agad nila sila idinadagdag.

Mga bukas na komunidad

Kung pampubliko ang community (tingnan ang Sino ang maaaring sumali), maaaring hanapin ito ng sinumang may account sa server gamit ang Sumali sa ibang team at sumali nang walang imbitasyon. Sa isang server kung saan maaaring mag-sign up ang sinuman, ito ang pinakamabilis na paraan upang mag-operate ng pampublikong community. Kung ang community ay tumatanggap lamang ng ilang domain ng email, hindi maaaring sumali ang mga may ibang address, kahit may link.

Mga bisita

Ang mga Bisita ay mga taong galing sa labas, tulad ng kliyente, kontratista, o organisasyong kasosyo. Nakikita ng Bisita ang mga Channel na idinagdag siya lang: hindi niya maaaring mag-browse o sumali sa ibang mga Channel ng komunidad. May Bisita tag sa pangalan nila, at sinasabi ng header ng isang Channel na may mga Bisita na mayroon ito.

  • Ang mga guest account ay naka-off sa default. Ipinapalitan ng isang system admin ito sa System Console › Pagpapatunay › Access ng Bisita, at maaaring hikayatin ang mga bisita na galing sa partikular na domain ng email o gamitin ang two-factor authentication.
  • Ang mga admin ng komunidad ay nag-i-imbita ng mga Bisita mula sa Mag-imbita ng mga tao, at pumipili ng mga Channel na maaari nilang gamitin. Upang bigyan ang isang Bisita ng ibang Channel sa hinaharap, idagdag sila dito mula sa Channel.
  • Kapag pinayagan ng system admin, ang Allow invited guests to log in with a magic link (without password) ay nagpapahintulot sa mga Bisita na mag-sign in gamit ang link na ipinadala sa email.
  • Upang gawing buong miyembro ang isang bisita, o gawing bisita ang isang miyembro, humingi sa isang system admin: ginagawa ito sa System Console › Pamamahala ng Mga User › Mga User, gamit ang Ipataas sa Miyembro o Bawasan sa Bisita.

Hindi laging awtomatikong idinadagdag ang mga Bisita sa mga Channel, kahit nasa lahat ng Channel ang lahat ng tao sa komunidad.

Pangasiwaan ang mga Miyembro

Buksan ang menu ng community at piliin ang Pamahalaan ang mga miyembro (ang mga miyembro ay nakikita ang Tingnan ang mga miyembro). Ang listahan ay nagpapakita ng lahat kasama ang kanilang role. Sa menu sa tabi ng role ng isang tao, maaari ninyong:

  • gawing community admin sila, gamit ang Gawing Team Admin, o kunin ito gamit ang Gawing Miyembro ng Team;
  • alisin sila mula sa community, gamit ang Alisin sa Team.

Ang dialog na ito ay galing sa klasikong interface at naninirang pa rin na "team". Maaari mo ring gawin ang aksyon sa isang tao sa anumang lugar na nakikita mo ang pangalan nila: i-right-click ito, o buksan ang kanilang profile card. Tingnan ang Moderation para sa mod view, timeouts, at pag-alis.

Walang limitasyon sa bilang ng miyembro ang isang community sa default. Kung itinakda ng inyong system admin ang isang limitasyon (Pinakamataas na Miyembro Bawat Community) at nagsimulang mabigo ang mga imbitasyon, humingi sa kanila na itaas ito.

Onboarding

Ang onboarding ay nagbubuklod ng mga bagong sumali noong unang pagbukas nila ng inyong community. Ipinapakita nito ang isang mensahe ng pagbubuklod at ilang tanong. Ang bawat sagot ay maaaring magbigay ng mga role at channel sa bagong sumali, upang makahanap ng tamang lugar ng mga tao mula sa kanilang unang minuto.

Pagsulat ng onboarding

  1. Kung ang mga sagot ay dapat magbigay ng mga role, unang gumawa ng mga role na iyon at i-on ang Maaaring kunin ng sinuman para sa kanila (tingnan ang Mga role na maaaring kunin ng sinuman). Ang onboarding ay maaari lamang magbigay ng mga role na bukas sa lahat.
  2. Buksan ang menu ng community, piliin ang Setup ng team, tapos ang Onboarding….
  3. Isulat ang Maligayang pagdating na teksto: tungkol saan ang community at ang mga pangunahing patakaran nito, sa ilang linya.
  4. Piliin ang Magdagdag ng tanong, halimbawa "Ano ang nagdudulot sa iyo dito?". Iwan ang Maraming sagot kung maaari magpili ng higit sa isang sagot ang mga tao.
  5. Para sa bawat sagot, isulat ang teksto nito, tapos i-click ang mga role at pampublikong channel na ibinibigay nito. Piliin ang Magdagdag ng sagot para sa susunod.
  6. Piliin ang I-save.

Ang mga channel na maaari mong ibigay ay ang mga pampublikong channel na miyembro ka. Para alisin ang onboarding, burahin ang mga tanong at welcome text nito, tapos i-save.

Ang nakikita ng mga bagong miyembro

Sa unang pagbukas ng community, ipapakita ng Maligayang pagdating sa dialog ang iyong teksto at mga tanong. Pipiliin nila ang kanilang mga sagot at piliin ang Tapos na, o piliin ang Laktawan. Sa anumang paraan, hindi na nila ito makikita muli sa community na iyon. Ang mga taong sumali bago mo isulat ang onboarding ay makikita ito sa susunod nilang pagbukas ng community.

Maaari ng mga miyembro palitan ang kanilang mga bukas na role sa susunod mula sa menu ng community, sa ilalim ng Ang iyong mga role….

Para sa pampublikong komunidad, pagsamahin ang onboarding sa isang naka-lock na "Information" category na may rules channel at announcements channel, at isang banner sa itaas ng rules channel (tingnan ang Channel settings).

Mga attribute ng miyembro

Ang mga attribute ng miyembro ay mga detalye tungkol sa iyong mga miyembro na ipinapakita sa kanilang profile card sa iyong komunidad, tulad ng kanilang kumpanya, site, subcontractor, o pronouns. Sila ay kinalakihan ng komunidad: hindi nila makikita ng ibang komunidad sa server.

Pagtukdo ng mga attribute

Buksan ang menu ng community, piliin ang Setup ng team, tapos ang Mga attribute ng miyembro…, at piliin ang Magdagdag ng attribute. Para sa bawat attribute, itakda ang:

  • Pangalan, halimbawa "Kumpanya".
  • Uri: Teksto, Pagpipilian, Maraming pagpipilian, Petsa, Link, Email, Numero ng telepono, Tao o mga tao. Para sa mga pagpipilian, i-list ang mga Mga pagpipilian.
  • Sino ang nagse-set: Bawat miyembro ang nagpupunta nito para sa kanilang sarili, o Mga Admin lamang ang nagpupunta.
  • Sino ang makakakita: Lahat, Mga Admin, o Nakatago. Laging nakikita ng mga Admin at ng miyembro mismo; ang mga nakatagong attribute ay hindi ipinapakita sa mga profile.
  • Ipakita sa listahan ng mga miyembro: ipinapakita ang attribute sa ilalim ng mga pangalan ng mga tao sa listahan ng mga miyembro, sa lugar ng kanilang posisyon, at nagpapahintulot sa lahat na i-filter ang listahan nito. Isang attribute lamang ang maaaring ipakita sa ganitong paraan.

Gamitin ang Ilipat pataas at Ilipat pababa upang itakda ang pagkakasunod-sunod sa mga profile card. Maaari ng isang community magkaroon ng hanggang 50 attributes. Ang pagtanggal ng attribute ay tinatanggal din ang mga halaga ng lahat.

Punan ang mga ito

Upang itakda ang mga attribute ng isang tao, i-right-click ang pangalan nila at piliin ang I-edit ang mga attribute…. Maaaring itakda ng mga community admin ang bawat attribute ng lahat; maaaring itakda ng mga miyembro ang kanilang sarili, maliban sa mga itinakda ng mga admin. Ang mga attribute na nakikita ng mga Admin lamang ay may lock sa profile card.

Sa isang kumpanya, ang isang attribute na itinakda ng mga admin at nakikita ng mga admin lamang ay magandang lugar para sa mga detalye sa loob, tulad ng petsa ng pagtatapos ng kontrata, na hindi kailangang makita ng mga kasamahan.

May mga attribute din ang server na para sa sarili, pare-pareho para sa bawat community, na tinutukoy ng isang system admin sa System Console › Mga Attributo ng Sistema › Pagmamaneho ng Attribute. Ipinapakita ito sa mga profile card bago ang mga attribute ng iyong community, at ang mga system admin lamang ang nagpupunta nito para sa iba. May mga nanggaling sa sign-in provider, tulad ng company directory.

Kapag umalis o tinanggal ang mga tao

  • Umalis ang mga miyembro gamit ang Umalis sa team sa menu ng community.
  • Ang mga umalis o tinanggal ay mawawala ang kanilang mga role at team sa community. Mananatili ang kanilang mga mensahe.
  • Ang isang tao na tinanggal mula sa community ay maaaring bumalik gamit ang bagong imbitasyon, o sa pamamagitan ng pag-uusap muli kung pampubliko ang community. Upang panatilihing malayo ang isang tao, kailangang i-deactivate ng isang system admin ang kanilang account (tingnan ang Pagpapanatili ng pagkalabas).
