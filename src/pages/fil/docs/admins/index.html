Mga bahagi ng deployment

Ang Antimatter ay isang self-hosted na team chat, isang fork ng Mattermost. Ang isang kumpletong deployment ay may mga bahaging ito. Ang unang tatlo lamang ang kailangan.

BahagiGinagawa nitoKailangan
Ang Antimatter serverIsang Go program (antimatter) na naglilingkod ng web app, API, at websockets sa port 8065, nagpapatakbo ng mga kasamang apps (plugins), at nagdadala ng call media sa port 8443. Ang command-line tool na amctl ang nagmamaniwa rito.oo
PostgreSQLAng database: mga mensahe, mga user, mga community, at, sa inirerekomendang setup, ang configuration ng server. Versyon 15 o mas bagong.oo
File storageMga na-upload na file, imahe, at installed na apps: isang S3-compatible na serbisyo (ang compose file ay nagpapatakbo ng RustFS), o isang local na directory.oo
Isang reverse proxyHTTPS sa harap ng server: ang Caddy profile ng compose file, o ang sarili mong nginx.para sa production
Ang GIF service (gifs-server)Mga GIF at sticker para sa GIF picker, mula sa sarili mong catalogue. Sinasalita nito ang Tenor API.hindi
Isang push proxyNagpapadala ng mga notisikasyon sa mobile app sa pamamagitan ng Apple at Google.para sa mobile notifications
rtcd, isang TURN serverIsang magkahiwalang media server para sa maraming tawag, at isang relay para sa mga nasa likod ng mahigpit na firewall.hindi
AI endpointsAng mga modelong nasa likod ng pag-rewrite, recaps, pagsasalin, pagbasa nang malakas, mga AI agent, at transkripsyon ng tawag ng composer, na idinagdag bilang mga koneksyon ng model: isang cloud provider o mga server na iyong pinapatakbo.hindi

Wala sa Antimatter ang lisensya o bayad na edisyon: ang single sign-on, LDAP, high availability, compliance exports, data retention, at ang ibang mga feature na inaalis ng Mattermost para sa mga bayad na plano ay lahat ay kasama.

Mga Kinakailangan

  • Isang Linux server, amd64 o arm64, na may 2 CPU cores at 4 GB ng memory o higit pa para sa ilang daang tao, at disk space para sa mga file na naa-upload ng mga tao.
  • Docker Engine na may Compose plugin (docker compose), para sa inirerekomendang pag-install. O, para sa mga package, isang Debian, Ubuntu, Fedora o RHEL-compatible na server na may systemd.
  • Para sa production: isang domain name na tumutukoy sa server, at bukas ang ports 80 at 443 para sa HTTPS.
  • Para sa mga tawag: port 8443, UDP at TCP, na maabot ng mga nagta-tawag.
  • Para sa email: isang SMTP server na maaaring gamitin ng Antimatter para magpadala.

Mabilis na pagsisimula

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)
EOF
docker compose up -d

Pagkatapos, buksan ang URL ng site at gumawa ng account: ang unang account ay maging system administrator. Ang Pag-install ay nagpaliwanag ng bawat hakbang at ng ibang paraan ng pag-install.

Sa gabay na ito

  • Pag-install: Docker Compose, ang mga image, ang unang administrator, ang mga .deb at .rpm package, at ang release archive.
  • Configuration: mga setting sa database o file, AM_ environment variables, ang System Console, amctl, at mga log.
  • Domain at HTTPS: ang URL ng site, Caddy, nginx, at mga address ng client.
  • Tawag at boses: mga port, NAT, TURN, rtcd, transkripsyon at live captions.
  • Email at push: SMTP, ang push proxy, at ang mobile app.
  • Mga kasamang app: alin sa mga app ang naka-on, ang kanilang mga setting, at ang pag-install ng iba.
  • AI: mga koneksyon ng model, ang mga built-in na AI feature, mga agent, boses at pagsasalin, ang encryption key, at kung saan pumupunta ang data.
  • Pag-sign-in at mga account: pag-sign-up, mga password, MFA, single sign-on, LDAP, mga bisita, at mga session.
  • Backup at upgrade: backup, restore, upgrade, at paglipat mula sa Mattermost.
  • Operasyon: monitoring, scaling, retention ng data, compliance, at troubleshooting.
  • Seguridad: checklist para sa pagpapatibay at mga koneksyon mula sa labas.
  • Pag-deploy ng desktop app: ang MSI, Group Policy at Intune, macOS profiles at ang Linux policy file.

Nagpapatakbo ng community sa halip na server (mga channel, mga role, moderation)? Tingnan ang Pagpapatakbo ng community. Nagbu-build ng integrations? Tingnan ang Pagbu-build sa Antimatter.

Ang unang oras mo

  1. I-install, at agad na gumawa ng account ng administrator.
  2. Ilagay ang server sa likod ng HTTPS sa sariling domain.
  3. I-configure ang SMTP at magpadala ng test email.
  4. Buksan ang port ng mga tawag. Para sa isang kumpanya, itakda ang uri ng mga bagong komunidad sa Workplace, upang naka-on ang mga tawag sa mga channel.
  5. Tukuyin kung sino ang maaaring mag-sign-up, at i-on ang MFA.
  6. Suriin ang mga koneksyon mula sa labas sa Seguridad.
  7. Itakda ang pang-araw-araw na backup. Bago magdagdag ng mga koneksyon ng AI model, itakda ang AI encryption key.

Pagkuha ng tulong

Magtanong sa community discussions, at ipa-report ang mga bug sa community repository. Ipa-report nang pribado ang mga problema sa seguridad, ayon sa paliwanag ng security policy.
