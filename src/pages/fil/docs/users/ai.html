Tungkol sa mga agent

Ang agent ay isang AI assistant na lumalabas sa Antimatter bilang isang bot, na may sariling pangalan. Kinokonekta ng iyong administrator ang mga agent sa isang AI service, na maaaring tumakbo sa sariling server ng iyong organisasyon o sa isang external provider, at nagdedesisyon kung sino ang maaaring gamitan ang bawat agent at sa aling mga channel. Kung walang agent sa iyong server, o walang agent na maaari mong gamitin, hindi lalabas ang mga feature sa pahinang ito.

Maaaring magkamali ang mga agent. Suriin ang kanilang sinulat bago mo ito maniwala o ibahagi.

Makipag-usap sa isang agent

  1. Pindutin ang Mga Agent (sparkle icon) sa app rail sa kanang gilid ng window. Bubuksan ang Agents panel.
  2. Kung may ilang agent sa iyong server, pumili ng isa gamit ang agent menu sa header ng panel ("Choose an Agent"). Iiwan ang iyong pagpipilian, at gagamitin din ito ng ibang mga AI feature.
  3. I-type ang iyong tanong sa "Ask Agents anything..." at pindutin ang Enter. Maaari mo ring mag-drop ng file sa panel upang ibigay ito sa agent.

Sasagutin ng agent sa panel. Habang isinusulat, maaari mong pindutin ang I-stop ang pag-generate; kapag tapos na, ang I-regenerate ay hihiling ng ibang sagot. Kapag gumamit ng tools o naghanap sa web ang agent, sasabihin ng sagot nito, halimbawa "Used 3 tools" o "Searched the web for …".

Bawat tanong na tinatanong mo mula sa panel ay nagpapaunlad ng isang usapan; sumagot rito upang magpatuloy. Pindutin ang New chat upang magsimula ng isa pa, at View chat history upang hanapin ang iyong mga nakaraang usapan. Isang maliit na ring ay nagpapakita kung gaano karami ang memory ng agent (context window) ang ginagamit ng usapan.

Ang panel ay isang Direct Message sa agent: makikita mo rin ito sa iyong mga Direct Message, at maaari kang sumulat sa agent doon. Bawat bagong mensahe ay nagpapaunlad ng bagong usapan, na sasagutin sa isang thread.

Magtanong tungkol sa channel na binabasa mo

Kapag binuksan mo ang Agents panel habang binabasa ang isang channel, iaoffer nito ang pag-usap "About #channel": pindutin ang Summarize unreads, Summarize the last 7 days o Summarize the last 14 days, o i-type ang tanong sa "Ask about …".

Mga custom prompt

Kung madalas mong tanong ang pare-parehong bagay, i-save ito bilang custom prompt gamit ang Manage prompts sa AI menu ng message box. Ang mga naka-pin na prompt ay lumalabas bilang mga button sa Agents panel.

Magtanong sa agent sa loob ng channel

Para magtanong sa agent sa harap ng lahat, i-mention ito gaya ng tao: mag-type ng @ at pangalan ng agent, tapos ang iyong tanong. Sasagutin ng agent ang thread sa ilalim ng iyong mensahe, na mababasa ng lahat sa channel. Babasahin nito ang thread, hindi ang buong channel.

Para magpatuloy sa agent sa loob ng thread, i-mention ito ulit sa iyong sagot. Kung nakalimutan mo, paalala ka ng Antimatter, sa iyo lamang, na may link para i-loop in ang agent.

Hindi sasagutin ng agent kung hindi ka may pahintulot na gamitin ito, o kung hindi ito pinapayagan sa channel na iyon. May mga channel na may agent na awtomatikong sumasagot: itinataguyod ito ng mga admin sa mga setting ng channel.

Mga AI action sa mensahe

  1. I-point ang mensahe at i-click ang Mga Karagdagang Aksyon (⋯).
  2. I-point ang Mga AI Action.
  3. Pumili ng isa:
    • Summarize Thread: buod ng thread kung saan nasa loob ang mensahe.
    • Find action items: ang mga gawain at sino ang dapat magawa.
    • Find open questions: ang mga tanong na naghihintay pa ng sagot.
    • React for me: pipili ng angkop na emoji ang agent at idadagdag nito bilang iyong reaksyon.

Lumalabas ang sagot sa Agents panel, sa iyong pribadong usapan sa agent: hindi ito nakikita ng iba. Ang mga pare-parehong aksyon ay nasa menu ng Mga aksyon sa thread sa thread panel.

Makapag-catch up sa channel

Kapag binuksan mo ang channel na may mga hindi nabasang mensahe, may Ask AI button sa linya ng "Unread" na nagpapakita kung saan nagsisimula ang mga ito. I-click ito, pumili ng agent sa ilalim ng "Generate With:", tapos pumili ng Summarize new messages, Find action items o Find open questions. Lumalabas ang sagot sa Agents panel, nakikita sa iyo lamang.

Ang mga buod ng channel ay sakop ng 14 araw na pinakamataas.

I-rewrite ang iyong mensahe bago ipadala

  1. Isulat ang iyong mensahe.
  2. I-click ang Ipakita ang formatting (Aa) kung nakatago ang formatting bar, tapos i-click ang AI sa kaliwang dulo nito.
  3. Sa ilalim ng I-rewrite gamit ang AI, pumili ng Pahusayin ang pagsulat, Fix spelling & grammar, Make it shorter, Make it more formal o Isalin…. Para sa pagsasalin, mag-type ng wika, tulad ng "French", at pindutin ang Enter.

Ang message box ay nagpapakita ng "The AI is rewriting your message…", tapos pinapalit ang iyong text sa bago, na may tala na Na-rewrite ng AI. Basahin ito, baguhin kung gusto mo, at ipadala. Pindutin ang I-undo para makuha muli ang sarili mong text. Sa isang reply sa thread, binabasa rin ng agent ang simula ng thread at ang huling mga reply, kaya ang rewrite ay angkop sa usapan.

Ang parehong menu ay naglilista ng iyong mga custom prompt, sa ilalim ng "GENERATE WITH:", kung saan maaari mo ring piliin ang agent.

Mga Recap

Ang recap ay isang buod ng ilang channel, na ihahanda para sa iyo ng isang agent: isang beses, o ayon sa iskedyul, tulad ng tuwing umaga ng araw ng trabaho. Ang mga recap ay available kapag pinag-activate ito ng iyong administrator. Makikita mo ang Mga Recap sa listahan ng iyong mga direct message.

Gumawa ng recap

  1. Buksan ang Mga Recap at pindutin ang Magdagdag ng recap.
  2. Bigyan ng pangalan ang iyong recap.
  3. Piliin ang I-recap ang mga napiling channel o I-recap lahat ng aking hindi nabasa.
  4. I-on ang I-run ng isang beses para makakuha agad ng recap, nang walang iskedyul.
  5. Para sa mga napiling channel, piliin ang mga channel na isasama.
  6. Para sa isang recap, i-check ang listahan ng mga channel at pindutin ang Simulan ang recap. Para sa nakaschedule, piliin ang mga araw at oras ng pag-run, ang Panahon na sasakupan (Nakaraang 24 oras, Nakaraang 7 araw o Mula noong huling nabasa), magdagdag ng mga utos para sa agent kung gusto mo, at pindutin ang Gumawa ng iskedyul.

Kailangan ng ilang sandali para mahanda ang recap. Pagkatapos ay makikita ito sa ilalim ng Hindi Nabasa, na may card para sa bawat channel: ang mga highlight at action items nito. Mula sa menu ng recap, maaari mong buksan ang channel, markahan bilang nabasa, i-regenerate ang recap, o burahin ito. Ang iyong mga nakaschedule na recap ay nasa ilalim ng Nakaschedule, kung saan maaari mong i-pause. Limitado ng iyong administrator ang bilang ng mga recap na maaari mong i-run bawat araw.

Mga buod ng meeting

Kapag may transkripsyon ang tawag (tingnan ang Transkripsyon at live captions), ang mensahe ng transkripsyon sa thread ng tawag ay maaaring mag-alok ng Gumawa ng buod ng meeting. Isusulat ng agent ang buod sa iyong pribadong usapan sa kanya, at maaaring mag-alok na ilagay ito sa thread ng tawag para sa lahat.

Maghanap gamit ang agent

Kung pinag-activate ng iyong administrator ang AI search, ang search box sa header ng usapan ay nag-aalok ng opsyon na Mga Agent sa mga mungkahi nito. Piliin ito, tapos magtanong sa sarili mong salita: hahanapin ng agent ang sagot sa mga mensahe ng mga channel na miyembro ka, at sasagot sa panel ng Mga Agent.

Mga tool at web search

Maaaring gamitin ng mga Agent ang mga tool na ikonekta ng iyong administrator, halimbawa upang hanapin ang isang bagay sa ibang sistema, o upang maghanap sa web. Ang menu ng Tools sa panel ay naglilista ng mga tool provider: maaari mong patayin o i-on ang bawat isa para sa sarili mo, at Connect sa mga kailangan ng sign-in.

May mga tool na humihingi ng iyong pahintulot bago sila tumakbo: ipapakita ng agent ang isang card na naglalarawan ng kanyang gagawin, at pindutin mo ang Tanggapin o Reject. Sa loob ng channel, may pangalawang hakbang pagkatapos tumakbo ang tool: pumili ng Ibahagi upang payagan ang agent na gamitin ang resulta sa kanyang sagot, na makikita ng lahat sa channel, o Keep private.

Tumutakbo ang mga Agent ng mga tool gamit ang iyong mga pahintulot: hindi nila maabot ang anumang bagay na hindi mo maabot.

Ang nakikita ng mga Agent

  • Binabasa lamang ng agent ang mga maaari mong basahin. Sinusuri ng mga summary, recap, at search na maaari mong basahin ang bawat channel, at ang AI search ay sakop lamang ng mga channel na miyembro ka.
  • Kapag in-mention mo ang isang agent sa isang thread, binabasa nito ang thread na iyon. Ang summary ay binabasa ang thread, o ang channel sa loob ng piling panahon. Ang rewrite ay binabasa ang iyong draft, at sa loob ng thread, pati na rin ang simula ng thread at ang huling mga sagot nito.
  • Sa bawat hiling, tinatanggap din ng agent ang ilang konteksto: ang pangalan ng server, kung sino ang humihingi, at ang channel at community.
  • Ang binabasa ng agent ay ipinapadala sa AI service na piliin ng iyong administrator para dito. Maaaring nasa labas ng iyong organisasyon ang serbisyo na iyon: tanungin ang iyong administrator kung kailangan mong malaman kung saan pumupunta ang iyong data.
  • Ang mga usapan mo sa isang agent ay itinatalaga sa iyong Antimatter server, katulad ng ibang mga mensahe.
  • Ang mga sagot sa mga AI Action, channel summary, at search ay ipinapost sa iyong pribadong usapan sa agent: ikaw lamang ang nakikita nito. Ang mga sagot sa mga mention sa channel ay makikita ng lahat sa loob nito.

Kung hindi mo nakikita ang mga Agent

Kung nagsasabi ang Agents panel na "No agents yet", hindi pa nakikonekta ng iyong administrator ang isang agent na maaari mong gamitin. Kung pinapayagan ng iyong server na lumikha ng sariling agent ang mga tao, nag-aalok ang panel ng Create an agent, gamit ang AI service na nakonekta ng iyong administrator. Kung wala ang gamit na agent, hindi ipapakita ang AI button ng message box, ang menu ng Mga AI Action, at ang Ask AI.
