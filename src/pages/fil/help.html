Tulong

Tulong at suporta

Isang community project ang Antimatter. Narito kung saan makakahanap ng mga sagot, at kung paano kami sabihan tungkol sa isang problema.

Paggamit ng Antimatter

  • Sa app, nasa help menu (? sa app bar) ang user guide, mga keyboard shortcut, at tulong sa pag-format ng mensahe at sa mga slash command.
  • Habang wala pang sariling manual ang Antimatter, saklaw ng dokumentasyon ng Mattermost ang karamihan sa mga setting ng server at mga gawain sa administrasyon.
  • Matutulungan ka ng mga administrator ng iyong server sa mga account, komunidad at setting.

Mag-report ng problema

May nakita kang bug, o may hindi gumagana gaya ng inaasahan mo? Magbukas ng issue sa GitHub, kasama ang bersyon (makikita sa Tungkol sa Antimatter sa app), ang ginawa mo, ang inaasahan mo at ang nangyari sa halip:

  • Ang server at web app: mga issue ng AntimatterChat/antimatter
  • Isang app gaya ng mga tala, whiteboard o tawag: ang mga issue ng repository nito sa github.com/AntimatterChat
  • Mga salin: isang issue sa repository ng server, na binabanggit ang wika at ang string

Pakihanap muna sa mga kasalukuyang issue, at huwag isama ang anumang personal o kumpidensyal na impormasyon.

Mag-report ng security vulnerability

Pakiusap, huwag mag-report ng mga security vulnerability sa mga pampublikong issue. Sundin ang security policy ng repository, na nagpapaliwanag kung paano ito i-report nang pribado. Kukumpirmahin namin na natanggap namin ang report, gagawa kami ng fix, at bibigyan ka namin ng kredito kung gusto mo.

Commercial support

Walang bayad na support plan ang Antimatter. Kung kailangan ng iyong organisasyon ng suportang may garantisadong service level, maghanap ng kumpanyang sumusuporta sa mga self-hosted na chat server.
