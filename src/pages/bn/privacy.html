গোপনীয়তা নীতি

সর্বশেষ হালনাগাদ: ১১ অক্টোবর ২০২৬। এই বাংলা অনুবাদটি কেবল সুবিধার জন্য দেওয়া হয়েছে; কোনো অমিল থাকলে ইংরেজি সংস্করণটিই প্রাধান্য পাবে।

এই পেজে দুটি বিষয় নিয়ে বলা হয়েছে: Antimatter সফটওয়্যার, যা প্রতিষ্ঠানগুলো নিজেদের সার্ভারে চালায়, আর এই ওয়েবসাইট, antimatter.chat।

Antimatter সফটওয়্যার

Antimatter সেলফ-হোস্টেড। আপনি যখন কোনো Antimatter সার্ভার ব্যবহার করেন, তখন কোন ডেটা রাখা হবে, কত দিন রাখা হবে আর কারা তা দেখতে পাবেন, সে সিদ্ধান্ত নেয় সার্ভারটি যে প্রতিষ্ঠান চালায়, সেই প্রতিষ্ঠান। আপনার সার্ভার, আপনার অ্যাকাউন্ট বা আপনার মেসেজে Antimatter প্রকল্পের কোনো অ্যাক্সেস নেই। কোনো নির্দিষ্ট সার্ভারে আপনার ডেটা নিয়ে প্রশ্ন থাকলে সেই সার্ভারের অ্যাডমিনিস্ট্রেটরদের সঙ্গে যোগাযোগ করুন; সেখানে তাঁদের নিজস্ব গোপনীয়তা নীতি প্রযোজ্য।

সফটওয়্যারটি নিজে থেকে যা করে:

  • কোনো টেলিমেট্রি নেই। সার্ভার ব্যবহারের পরিসংখ্যান, ডায়াগনস্টিক বা অন্য কোনো ডেটা Antimatter প্রকল্পকে বা কোনো তৃতীয় পক্ষকে পাঠায় না।
  • বাইরের সংযোগ হয় কেবল অ্যাডমিনিস্ট্রেটরের চালু করা ফিচারের জন্য, তাঁদের কনফিগার করা সার্ভিসে: যেমন একটি পুশ নোটিফিকেশন সার্ভিস, মেসেজে পোস্ট করা ওয়েবসাইটের লিংক প্রিভিউ, একটি GIF প্রোভাইডার, একটি ইমেইল সার্ভার, সিঙ্গল সাইন-অনের জন্য একটি আইডেন্টিটি প্রোভাইডার, কিংবা AI, স্পিচ বা অনুবাদ মডেল।
  • AI ফিচারগুলো সেই মডেলই ব্যবহার করে, যা অ্যাডমিনিস্ট্রেটর বেছে নেন। মডেলগুলো কোনো তৃতীয় পক্ষ হোস্ট করলে, তাদের কাছে যা পাঠানো হয় (পুনর্লিখনের জন্য একটি মেসেজ, সারসংক্ষেপের জন্য একটি কথোপকথন, ট্রান্সক্রাইব করা কলের অডিও), তা সেই প্রোভাইডারের কাছে যায়। অ্যাডমিনিস্ট্রেটররা সেলফ-হোস্টেড মডেল ব্যবহার করতে পারেন, যাতে কিছুই তাঁদের নেটওয়ার্কের বাইরে না যায়।

এই ওয়েবসাইট

  • antimatter.chat একটি স্ট্যাটিক ওয়েবসাইট, যা GitHub Pages-এ হোস্ট করা।
  • এটি কোনো কুকি সেট করে না, আর কোনো অ্যানালিটিক্স, ট্র্যাকার বা বিজ্ঞাপন ব্যবহার করে না। এর ফন্ট আর ছবি সাইট থেকেই আসে, তাই পড়ার সময় আপনার ব্রাউজার অন্য কোনো ওয়েবসাইটে রিকোয়েস্ট পাঠায় না।
  • যেকোনো ওয়েব হোস্টের মতোই, পেজগুলো দেখানোর জন্য GitHub আপনার IP অ্যাড্রেস আর আপনি কোন পেজ চাইছেন তা পায়। দেখুন GitHub Privacy Statement।
  • আপনি GitHub-এ কোনো ইস্যু খুললে বা অবদান রাখলে, সেখানে যা পোস্ট করেন তা পাবলিক, এবং GitHub তার নিজস্ব শর্ত অনুযায়ী তা পরিচালনা করে।
