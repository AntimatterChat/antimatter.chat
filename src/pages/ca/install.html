Instal·la Antimatter al teu propi servidor

Un fitxer, tres ordres i uns deu minuts: Antimatter amb la seva base de dades, l’emmagatzematge de fitxers i el servei de GIF, en qualsevol servidor Linux amb Docker.

En marxa en deu minuts

Necessites un servidor Linux amb Docker i el seu connector Compose, 2 nuclis de CPU i 4 GB de memòria o més.

1. Baixa el fitxer compose

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Crea’n la configuració, amb contrasenyes aleatòries

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Defineix SITE_URL amb l’adreça que farà servir la gent, com ara http://192.168.1.20:8065 en una xarxa local.

3. Engega’l

$ docker compose up -d

La primera arrencada triga un o dos minuts mentre es crea la base de dades. Després, obre SITE_URL al navegador i crea el teu compte: el primer compte passa a ser el d’administrador del sistema, i l’assistent de configuració et guia per crear la teva primera comunitat.

Amb el teu propi domini i HTTPS

Apunta un registre DNS del teu domini al servidor, obre els ports 80 i 443 i afegeix el domini al fitxer .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy obté un certificat de Let's Encrypt i el renova automàticament.

Què s’executa

  • antimatter: el servidor, amb les seves aplicacions (notes, pissarres, canals de veu, trucades, enquestes i la resta). No desa res al disc: la configuració és a la base de dades i els fitxers, al servei d’emmagatzematge, de manera que pots substituir el contenidor en qualsevol moment.
  • postgres: la base de dades.
  • files: RustFS, emmagatzematge compatible amb S3 per als fitxers que es pugen.
  • gifs: el servei de GIF i adhesius d’Antimatter, amb un paquet d’adhesius inicial.
  • https: Caddy, només amb el perfil https.

La base de dades, l’emmagatzematge i el servei de GIF són en una xarxa privada a la qual només té accés Antimatter.

Si el selector de GIF es queda buit, obre Consola del sistema › Plugins › GIFs i defineix l’URL del servei com a http://gifs:8080/v2 i la clau de l’API amb el valor de GIFS_API_KEY del teu .env.

Actualitzacions i còpies de seguretat

# actualitza a les imatges més recents
$ docker compose pull && docker compose up -d
# fes una còpia de seguretat de la base de dades
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Fes també una còpia de seguretat del volum files, o replica l’emmagatzematge amb qualsevol eina S3. Si vols una configuració amb nginx i els teus propis certificats, consulta els fitxers de producció a antimatter-docker.

Amb un arxiu de versió

  1. Prepara una base de dades i un usuari de PostgreSQL.
  2. Descomprimeix l’arxiu (antimatter-<os>-<arch>.tar.gz), per exemple a /opt/antimatter, i fes que SqlSettings.DataSource de config/config.json (o la variable d’entorn MM_SQLSETTINGS_DATASOURCE) apunti a la base de dades.
  3. Engega el servidor amb bin/antimatter, com a usuari sense privilegis, i obre http://localhost:8065. El primer compte que es creï passa a ser el d’administrador del sistema.

bin/amctl gestiona un servidor en funcionament des de la línia d’ordres (bin/amctl --local al mateix servidor, amb ServiceSettings.EnableLocalMode).

Passos següents

  • Trucades: obre el port de les trucades (UDP i TCP 8443 per defecte) perquè la veu i el vídeo arribin al servidor.
  • Correu electrònic: configura l’SMTP per a les invitacions i les notificacions.
  • IA: afegeix un model a la configuració d’Agents; hi funciona qualsevol API compatible amb OpenAI, inclòs un servidor que allotgis tu mateix.
  • Veu i traducció: fes que la transcripció de les trucades, la lectura en veu alta i la traducció automàtica apuntin a models de veu a text, de text a veu i de traducció que allotgis tu mateix.
