"Compatible amb OpenAI" significa un servidor que ofereix la mateixa API HTTP que OpenAI. La majoria dels servidors de models que pots executar tu mateix ho fan (per exemple Ollama, vLLM, el servidor de llama.cpp, o servidors de transcripció de veu i síntesi de veu), així com molts proveïdors en la núvol. No cal cap llicència per a cap d'aquestes funcions.

Agents d'IA

L'aplicació Agents (id mattermost-ai) està activada per defecte. Configurar-la requereix dos passos: afegir un servei (una connexió a un proveïdor de models) i després crear agents (bots que utilitzen un servei).

1. Afegeix un servei

Ves a Consola del sistema › Connectors › Agents i, sota Serveis d'IA, fes clic a Afegeix un servei d'IA. Tria el Tipus de servei:

  • Compatible amb OpenAI: per a un servidor de models que executes tu mateix o qualsevol proveïdor amb una API de tipus OpenAI. Omple URL de l'API (per exemple http://ollama:11434/v1 o http://vllm.internal:8000/v1) i Clau d'API només si el servidor n'ha de tenir una. Si el servidor només admet l'API de Completions de xat, desactiva Utilitza l'API de Respostes.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: proveïdors allotjats. Cadascun necessita la seva Clau d'API (Bedrock: una regió d'AWS i credencials o un rol IAM; Vertex AI: un projecte, una regió i un compte de servei; Azure: també l'URL de l'API).

Després, defineix el Model predeterminat (una llista si el proveïdor pot informar dels seus models, o bé escriu el nom) i, si el proveïdor no els informa, el Límit de tokens d'entrada i el Límit de tokens de sortida. Un Servei de reserva pot prendre el relleu quan aquest falli. Desa.

El servidor fa aquestes sol·licituds per si mateix, per la qual cosa ha d'arribar a l'API: un servidor de models al mateix projecte compose, a la teva xarxa o a Internet. Les sol·licituds sortents respecten les variables HTTP_PROXY i HTTPS_PROXY.

2. Crea agents

Els agents es creen a la pàgina Agents de l'aplicació web: obre-la des del menú del producte o amb Gestiona al selector d'agents del panell d'Agents. La seva adreça és https://chat.example.com/plug/mattermost-ai/agents. Cada agent té un Nom per mostrar, un Nom d'usuari de l'agent (com la gent el menciona), un Servei i, opcionalment, un model, Instruccions personalitzades i interruptors per a Activa la visió (imatges) i Activa les eines. La seva pestanya Accés limita en quins canals es pot utilitzar i quins usuaris el poden utilitzar. Sota Funcions d'IA a la Consola del sistema, Bot predeterminat tria l'agent que s'utilitza quan no se n'ha triat cap, per exemple per a resums de trucades.

De manera predeterminada, cada usuari pot crear els seus propis agents, amb els serveis que has configurat. Per restringir-ho als administradors, elimina el permís Gestiona els teus agents d’IA del rol dels membres a Consola del sistema › Gestió d'usuaris › Permisos.

Funcions opcionals de l'aplicació Agents

  • Cerca d'incrustacions (experimental, desactivada): cerca semàntica sobre missatges. Requereix PostgreSQL amb l'extensió pgvector i un model d'incrustacions (OpenAI o compatible amb OpenAI). Envia cadascun dels missatges al model d'incrustacions, inclosos els canals privats i els missatges directes.
  • Cerca web (desactivada): permet als agents buscar a la web mitjançant Google, Brave o un servidor SearXNG que executis.
  • Eines natives: amb proveïdors que les ofereixen, els agents poden utilitzar la pròpia cerca web del proveïdor (activada de manera predeterminada per als nous agents, on estigui admeso), la recuperació web i l'execució de codi. Aquestes s'executen al proveïdor. Desactiva-les per agent.
  • Protocol de context de model (MCP): connecta els agents a servidors MCP de confiança, per a eines addicionals.
  • Depuració: Sortida de traçat (desactivada, registres del servidor o un punt final OpenTelemetry) i Activa el registre d'ús de tokens, que escriu els comptadors de tokens a logs/agents/token_usage.log.

Veu a text: transcripcions i subtítols de trucades

Les trucades es poden transcriure, amb subtítols en directe, mitjançant un servidor de veu a text que ofereix un punt d'accés /v1/audio/transcriptions compatible amb OpenAI. La configuració es troba a Trucades i veu. Amb Resum de transcripcions activat, l'agent per defecte també publica un resum de cada transcripció.

Text a veu: llegeix en veu alta

Amb el text a veu activat, el menú de cada missatge inclou Llegeix en veu alta: el servidor envia el text del missatge a una API de text a veu i reprodueix l'àudio. La configuració es troba a Consola del sistema › Integracions › Text a veu:

ParàmetreClau i variableQuè introduir
Llegeix els missatges en veu altaTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (desactivat per defecte)
URL base de l'APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLLa URL base fins a /v1 inclòs, per exemple http://tts.internal:8000/v1. El servidor crida el seu punt d'accés /audio/speech.
ModelTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELEl model amb el nom que li dona l'API, per exemple tts-1. Obligatori.
VeuTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEUna de les veus del model, o buit per utilitzar-ne la per defecte.
Clau d'APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYS'envia com a testimoni de portador (bearer token). Deixeu-lo buit si l'API no n'ha de tenir cap.

Abans d'enviar-lo, el servidor elimina els blocs de codi, els enllaços, els codis d'emoji i el format, i conserva com a màxim 4000 caràcters. Sol·licita àudio MP3 i conserva els darrers 64 resultats a la memòria, de manera que un missatge que es llegeix dues vegades només s'envia una.

Traducció automàtica

La traducció automàtica mostra els missatges d'un canal en la llengua pròpia de cada lector. Configureu-la a Consola del sistema › Configuració del lloc › Localització, sota Traducció automàtica:

ParàmetreClauValor per defecte
ActivaAutoTranslationSettings.Enabledesactivat
Proveïdor de traduccióAutoTranslationSettings.Providerlibretranslate, openai (s'hi mostra com «API compatible amb OpenAI») o agents (un servei de l'aplicació Agents)
Llengües permesesAutoTranslationSettings.TargetLanguagesen: les llengües en què es poden traduir els missatges
Temps d’espera de la traducció (ms)AutoTranslationSettings.TimeoutMs5000
Limita la traducció automàtica als missatges directes i als missatges de grupAutoTranslationSettings.RestrictDMAndGMdesactivat

Cada proveïdor té els seus camps propis:

  • LibreTranslate: Punt d’accés de l’API de LibreTranslate i Clau d’API de LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Un servidor de LibreTranslate es pot executar a la vostra pròpia xarxa.
  • API compatible amb OpenAI: URL base de l'API (fins a /v1 inclòs; el servidor n'utilitza el punt d'accés de completaments de xat), Model i Clau d'API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Funciona bé un petit model de traducció executat localment.
  • Agents: Servei d’IA, un dels serveis configurats a l'aplicació Agents.

Quan està activat, els administradors de canal activen la traducció per a un canal a la seva configuració (Traducció automàtica), i cada membre pot desactivar-la des del menú del canal (Tradueix els missatges). En missatges directes i de grup, qualsevol membre pot activar-la; amb la restricció activada, la traducció no hi està disponible. Els missatges traduïts mostren «Traduït de…» amb un enllaç a l'original.

El codi, els enllaços, les mencions i els emoji es substitueixen per marcadors abans d'enviar el text i es restitueixen després.

Desactivar la IA

No hi ha un únic interruptor: cada funció en té el seu propi.

  • Agents: desactiveu l'aplicació Agents a Consola del sistema › Connectors › Gestió de plugins. Això també elimina els resums de trucades i el proveïdor de traducció d'Agents.
  • Transcripció i subtítols: AM_CALLS_ENABLE_TRANSCRIPTIONS=false i AM_CALLS_ENABLE_LIVE_CAPTIONS=false (els valors per defecte).
  • Llegeix en veu alta: desactiveu Llegeix els missatges en veu alta (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, el valor per defecte).
  • Traducció: desactiveu la traducció automàtica (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, el valor per defecte).

Desactivar l'aplicació Agents no desactiva les altres tres: aquestes criden les seves pròpies API directament.
