Les aplicacions integrades

Les aplicacions es llisten com a Connectors a la Consola del sistema. Es troben a la imatge (a /antimatter/prepackaged_plugins), signades amb la clau de signatura d'aplicacions d'Antimatter, de manera que s'instal·len sense connexió a Internet.

L'arxiu de la versió i els paquets .deb i .rpm inclouen menys aplicacions: consulta Aplicacions als paquets i a l'arxiu.

Les aplicacions que estan activades per defecte s'instal·len en cada inici si encara no ho estan, o s'actualitzen si la imatge té una versió més recent. Si n'actives una, es manté desactivada: el valor per defecte només s'aplica a les aplicacions que la configuració no menciona encara. Les aplicacions que mantenen el seu id de Mattermost (Agents, Trucades, Kanban, Guies d'actuació i les integracions) són versions pròpies d'Antimatter.

Activar, desactivar i configurar aplicacions

Vés a Consola del sistema › Connectors › Gestió de plugins. Sota Connectors instal·lats, cada aplicació té Activa o Desactiva, Configuració i Treu, i mostra el seu estat (En execució, No en execució, Error d'inici…). Cada aplicació amb configuració també té la seva pròpia pàgina sota Consola del sistema › Connectors.

Les aplicacions integrades que estan desactivades per defecte s'instal·len des de la còpia pròpia de la imatge: fes clic a la teva imatge a la part superior de la barra d'aplicacions i tria Botiga d'aplicacions (a la interfície clàssica, es troba al menú del producte), troba l'aplicació i fes clic a Instal·la, i després activa-la a la Gestió de plugins. Des de la línia d'ordres:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Altres ordres: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Activar aplicacions mitjançant la configuració

Quines aplicacions estan activades és la configuració PluginSettings.PluginStates, un mapa d'identificadors d'aplicacions. Pots fusionar-hi entrades amb amctl; amb Activa els complements preempaquetats automàticament activat (el valor per defecte), una aplicació integrada activada s'instal·la al següent inici:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Això és també com instal·lar Tasques pendents, que no s'ofereix al diàleg de la botiga. La variable AM_PLUGINSETTINGS_PLUGINSTATES també funciona, però substitueix tot el mapa: llista totes les aplicacions que vols activades.

Configuració de les aplicacions

La configuració de les aplicacions es desa a PluginSettings.Plugins.<app id>, amb claus en minúscules. Pots canviar-les a la pàgina de la Consola del sistema de l'aplicació o amb amctl config patch, com es mostra a Configuració. AM_PLUGINSETTINGS_PLUGINS substitueix la configuració de totes les aplicacions de cop i les bloqueja totes, així que evita utilitzar-lo.

El servei de GIF

El servei ho manté tot al seu directori de dades (/data, el volum gifs): un índex de cerca i els mitjans. Les seves variables principals:

AM_GIFS_RATE_LIMIT20Peticions per segon per client (clau d'API i adreça); 0 ho desactiva. El fitxer compose estableix 0, perquè totes les peticions d'Antimatter comparteixen una clau i una adreça.

Per afegir els vostres propis GIF en massa, importeu-los amb un manifest, des d'un directori muntat en un contenidor d'un sol ús:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

Per tornar a importar les enganxines inicials després d'una actualització: docker compose run --rm gifs stickers. El format del manifest i les altres comandes són al README de gifs-server.

Correu i Calendari

Correu i Calendari connecten cada persona amb la seva pròpia bústia (IMAP i SMTP) i el seu propi calendari (CalDAV). Les persones introduïxen el seu servidor i la seva contrasenya a l'aplicació; les contrasenyes s'emmagatzemen xifrades. No configureu els servidors de correu o calendari per a ells, però decidiu amb què poden connectar-se:

AplicacióParàmetreValor per defecteQuè fa
Correu, CalendariPermet servidors de correu en xarxes privades, Permet servidors de calendari en xarxes privades (AllowPrivateNetworks)desactivatDesactivat, el servidor es nega a connectar-se a adreces de bucle, privades i d'enllaç local, de manera que les aplicacions no es poden utilitzar per arribar a la vostra xarxa interna. Activeu-ho si el vostre servidor de correu o calendari està en una adreça privada.
Correu, CalendariPermet connexions sense xifrar (AllowInsecureConnections)desactivatDesactivat, les connexions han d'utilitzar TLS (Correu: TLS o STARTTLS; Calendari: HTTPS).
CorreuInterval de comprovació de no llegits (minuts) (UnreadCheckMinutes)2 minutsAmb quina freqüència es comproven els comptadors de no llegits quan el servidor de correu no els pot enviar.
CorreuMida màxima dels missatges (MB) (MaxMessageSizeMB)25 MBLímit de mida dels missatges enviats i llegits.
CalendariEnvia recordatoris (EnableReminders)activatEl bot de Calendari envia un missatge directe abans dels esdeveniments (10 minuts abans, per als esdeveniments sense la seva pròpia alarma).

Per permetre que les persones iniciïn sessió a bústies de Gmail o Microsoft 365 amb el seu compte en lloc d'una contrasenya, creeu un client OAuth i ompliu els camps de Google o Microsoft de l'aplicació de Correu:

  • Google: un client OAuth Web amb l'API de Gmail i l'abast https://mail.google.com/.
  • Microsoft: una aplicació d'Entra ID amb els permisos delegats IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email i profile. El tenant és common per defecte.
  • En ambdós, l'URI de redirecció és https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (l'URL del vostre lloc web).

Kanban, Notes, Pissarra, Enquestes i Guies d'actuació

  • Kanban (focalboard) s'obre al seu panell lateral al costat de la conversa, com fan les Guies d'actuació. Els enllaços antics a les pàgines /kanban/… i /boards/… obren el mateix tauler o targeta en una comunitat. La seva única configuració, Activa els taulers compartits públicament (EnablePublicSharedBoards, desactivat), permet als editors de taulers compartir un tauler amb qualsevol persona que tingui l'enllaç, sense haver d'iniciar sessió.
  • Notes i Enquestes no tenen configuracions.
  • Pissarra: els administradors del sistema poden penjar biblioteques de formes (fitxers Excalidraw .excalidrawlib, fins a 5 MB cadascun) per a tot el servidor a la pàgina de configuració. Els administradors de la comunitat gestionen les biblioteques de la seva pròpia comunitat.
  • Guies d'actuació s'obre al seu panell lateral. Els enllaços antics a les pàgines /playbooks/… obren la mateixa execució o guia d'actuació en una comunitat. Té diverses configuracions, majoritàriament funcions experimentals; els valors per defecte són adequats per a la majoria de servidors.
  • Memes: Qui pot afegir plantilles de memes: Tothom (el valor per defecte), Administradors del sistema o Ningú (plantilles personalitzades desactivades), que impedeix l'addició de noves plantilles, tot i que les ja afegides continuen sent utilitzables. Els convidats mai no afegeixen plantilles. La persona que va afegir una plantilla i els administradors del sistema poden suprimir-la.
  • Tasques pendents no té configuracions de servidor.

GitHub, GitLab i Jira

Aquestes aplicacions connecten Antimatter amb el vostre allotjament de codi i el gestor de problemes. Cadascuna necessita una aplicació OAuth a l'altre costat i un webhook que apunti de nou a Antimatter. Activeu l'aplicació i, a continuació, executeu la seva comanda de configuració en qualsevol canal, que us guiarà pas a pas: /github setup, /gitlab setup o /jira setup.

AplicacióURL de redirecció OAuthURL del webhook
GitHubhttps://chat.example.com/plugins/github/oauth/completehttps://chat.example.com/plugins/github/webhook
GitLabhttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/oauth/completehttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/webhook
Jira/jira instance install server <url> o /jira instance install cloud-oauth <url>; /jira webhook imprimeix les URL dels webhooks.
Deixeu Use Preregistered OAuth Application desactivat a les aplicacions de GitHub i GitLab: es basa en un servei de Mattermost que Antimatter no té, i l'aplicació es nega a iniciar-se si està activat. Registreu la vostra pròpia aplicació OAuth.

Les aplicacions de GitHub i GitLab generen el secret del webhook i la clau de xifratge en la primera desactivació. L'aplicació de GitHub es pot limitar a organitzacions (GithubOrg) i l'aplicació de GitLab a un grup (GitlabGroup); per a GitHub Enterprise o un GitLab autoallotjat, configureu la seva URL base.

Mètriques

L'aplicació Mètriques recull les mètriques de rendiment del servidor en una petita base de dades de sèries temporals dins d'Antimatter, de manera que podeu descarregar-les o incloure-les en un paquet de suport sense haver d'executar Prometheus. Quan s'inicia, activa el punt final de mètriques del servidor (MetricsSettings.Enable). Vegeu Operacions.

Instal·lació d'altres aplicacions

Antimatter executa aplicacions de Mattermost (plugins). Tres maneres d'afegir-ne una:

  • Des d'un Marketplace remot. Activa el Marketplace remot (PluginSettings.EnableRemoteMarketplace) està desactivat per defecte, i URL del Marketplace (PluginSettings.MarketplaceURL) és buit: Antimatter no utilitza el Marketplace de Mattermost i n'ignora l'adreça si una configuració de Mattermost encara la conté. Per llistar les aplicacions d'un servidor de Marketplace de confiança, activa la configuració i defineix la seva URL. Les versions de les aplicacions que Antimatter inclou (Trucades, Guies d'actuació, Kanban i les altres) d'aquest Marketplace s'amaguen, de manera que no poden substituir les d'Antimatter: Permet que el Marketplace substitueixi els plugins d’Antimatter (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) està desactivat per defecte.
  • Penjant un paquet (.tar.gz). Les pujades estan desactivades per defecte i no tenen un interruptor a la Consola del sistema: defineix AM_PLUGINSETTINGS_ENABLEUPLOADS=true i, a continuació, utilitza Carrega un plugin a la Gestió de plugins, o bé amctl --local plugin add app.tar.gz.
  • Des d'una URL: amctl plugin install-url <url>, també amb les pujades activades.

Antimatter verifica les signatures de les aplicacions contra les claus de confiança: la clau d'Antimatter, la clau amb la qual Mattermost, Inc. signa les seves aplicacions publicades (de manera que una aplicació de Mattermost que descarreguis tu mateix es pot instal·lar) i qualsevol clau que afegeixis a PluginSettings.SignaturePublicKeyFiles. Amb Requerix la signatura del complement (PluginSettings.RequirePluginSignature, desactivat per defecte) activat, les aplicacions sense signatura es rebutgen i les pujades es desactiven.

Una aplicació s'executa dins del servidor amb accés complet als seus dades. Instal·la només aplicacions en què confies.

Algunes aplicacions fetes per a les edicions de pagament de Mattermost verifiquen per si mateixes una llicència de Mattermost i es neguen a executar-se; Antimatter no pretén en tenir una per a elles.
