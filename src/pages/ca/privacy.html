Política de privadesa

Darrera actualització: 16 d'octubre de 2026.

Aquesta pàgina cobreix dos aspectes: el programari Antimatter, que les organitzacions executen als seus propis servidors, i aquest lloc web, antimatter.chat.

El programari Antimatter

Antimatter és autoallotjat. Quan utilitzeu un servidor Antimatter, l'organització que l'executa decideix quines dades es conserven, durant quant de temps i qui hi pot accedir. El projecte Antimatter no té accés al vostre servidor, al vostre compte ni als vostres missatges. Per a preguntes sobre les vostres dades en un servidor concret, contacteu amb els seus administradors; s'aplica la seva pròpia política de privadesa.

Què fa el programari per si sol:

  • Cap telemetria. El servidor no envia estadístiques d'ús, diagnòstics ni cap altre tipus de dades al projecte Antimatter, a Mattermost, Inc. (el programari sobre el qual es basa Antimatter) ni a altres tercers.
  • Connexions externes només per a les funcions que un administrador activa, cap als serveis que configuren: per exemple, un servei de notificacions push, un proveïdor de GIF, un servidor de correu electrònic, un proveïdor d'identitat per a inici de sessió únic, o models d'IA, veu o traducció.
  • Dues excepcions, activades per defecte, que els administradors poden desactivar. Previsualitzacions d'enllaços: quan algú publica un enllaç, el servidor obté aquesta pàgina per mostrar-ne el títol i la imatge. I les trucades: utilitzen el servidor STUN públic de Cloudflare (stun.cloudflare.com) per trobar les adreces de la xarxa pública. El servidor li fa la consulta quan s'inicia l'aplicació de trucades, i el dispositiu de cada persona li fa la consulta quan s'uneix a una trucada. Cloudflare només veu la direcció IP i el port del servidor i de cada persona que s'uneix, no la trucada en si. Els administradors poden utilitzar el seu propi servidor STUN en lloc d'aquest, o cap; vegeu Trucades i veu.
  • Les funcions d'IA utilitzen els models que triï l'administrador. Quan són allotjats per un tercer, el que s'envia a ells (un missatge per reescriure, una conversa per resumir, l'àudio d'una trucada transcrita) va a aquest proveïdor. Els administradors poden utilitzar models autoallotjats perquè res no surti de la seva xarxa.

Aquest lloc web

  • antimatter.chat és un lloc web estàtic allotjat a GitHub Pages.
  • No estableix galetes i no utilitza cap anàlisi, rastrejador o publicitat. Les seves tipografies i imatges es serveixen des del mateix lloc, de manera que el navegador no fa cap sol·licitud a altres llocs web mentre el llegeix.
  • Com qualsevol allotjador web, GitHub rep la teva adreça IP i les pàgines que sol·licites per servir-les. Consulta la Declaració de privadesa de GitHub.
  • Si obres un problema o hi col·labores a GitHub, el que hi publiques és públic i ho gestiona GitHub segons els seus propis termes.

Contacte

Per a qualsevol pregunta sobre aquesta política, obre un problema al dipòsit comunitari d'Antimatter.

Podem actualitzar aquesta política; la data del capçalera indica quan va canviar per darrera vegada.
