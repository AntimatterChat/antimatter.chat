Kompilace ze zdrojového kódu

Tato stránka popisuje, jak Antimatter sestavit a spustit ze zdrojového kódu, ať už pro práci na něm nebo pro vlastní sestavení. Pokrývá server a webové rozhraní, které jsou v jednom repozitáři, a dále Docker obraz a aplikace.

Co budete potřebovat

  • Jít, ve verzi v server/go.mod (1.26.7 v době psaní).
  • Node.js a npm ve verzích uvedených v .nvmrc a webapp/package.json (Node 24.11.1 s npm 11.6.2). S nástrojem mise nainstaluje soubor mise.toml v repozitáři správnou verzi Node.
  • Docker s Compose: vývojové prostředí běží s PostgreSQL a dalšími službami v kontejnerech.
  • make, git a stroj s Linuxem nebo macOS.
  • Paměť: nejnáročnější částí je sestavování webových rozhraní. Počítejte s 16 GB RAM; viz Sestavování a paměť.
git clone https://github.com/AntimatterChat/antimatter.git
cd antimatter

Repozitář obsahuje server v server/, webové rozhraní v webapp/ (Fusion v webapp/fusion, klasické v webapp/channels, sdílené balíčky v webapp/platform) a end-to-end testy v e2e-tests/.

Spusťte vývojový server

cd server
make run

make run spustí vývojové kontejnery (PostgreSQL, Redis, nástroj pro chytání e-mailů a monitoring), propojí sestavení webové aplikace na správném místě, spustí server na pozadí pomocí go run a spustí hlídač (watcher) webové aplikace, který při editaci znovu sestaví klasické rozhraní. Otevřete http://localhost:8065 a vytvořte účet: první se stane administrátorem systému.

Příkaz (v server/)Co dělá
make run-server, make run-clientSpusťte pouze server nebo pouze hlídač webové aplikace.
make restart-serverRestartujte server po změně Go kódu.
make stopZastavte server, hlídač a kontejnery.
make debug-serverSpusťte server pod ladicím nástrojem Delve.
make run-cli ARGS="-version"Spusťte příkaz serveru.
make config-resetObnovte config/config.json na výchozí hodnoty.
make clean, make nukeOdstraňte soubory ze sestavení; nuke také smaže vývojová data.

Vývojová databáze je postgres://mmuser:mostest_password@localhost/mattermost_test, výchozí zdroj dat serveru. Které kontejnery se spustí, určíte pomocí ENABLED_DOCKER_SERVICES v souboru server/config.override.mk nebo ve vašem prostředí (viz server/config.mk).

Webová rozhraní

V webapp/:

npm install      # also builds the shared packages
npm run build    # the classic interface, then Fusion

Výstupy se ukládají do webapp/channels/dist (klasické) a webapp/fusion/dist (Fusion). Příkaz make client v server/ je propojí jako server/client a server/client-fusion, odkud je server distribuuje: klasické pod /static/, Fusion pod /static/fusion/.

  • npm run run (nebo make run v webapp/) sleduje změny a přebuduje klasické rozhraní. Přidejte WATCH_FUSION=true, aby se přebudovala i Fusion.
  • npm run dev-server (make dev) spustí vývojový server webpacku: klasické rozhraní na portu 9005, Fusion na portu 9006.
  • Pokud chcete v prohlížeči zobrazit jedno z rozhraní, přidejte k adrese libovolné stránky parametr ?webui=fusion nebo ?webui=classic.

Místo go mod tidy v server/ spouštějte make modules-tidy.

Vydávací archivy

cd webapp && npm run build && cd ..
cd server
make build-linux       # the antimatter and amctl binaries
make package-linux     # dist/antimatter-linux-amd64.tar.gz and -arm64

make build najednou sestaví webové rozhraní i Linux binárky. Archiv obsahuje bin/antimatter, bin/amctl, výchozí config/config.json, obě webová rozhraní, šablony, písma a překlady. Pro ostatní platformy: make package-osx, make package-windows, make package-freebsd. Archivy neobsahují zabudované aplikace; Docker obraz je obsahuje.

Docker obraz

Repozitář antimatter-docker sestavuje publikované obrazy, server včetně aplikací, celé uvnitř Dockeru:

git clone https://github.com/AntimatterChat/antimatter-docker.git
cd antimatter-docker
scripts/build-all.sh                     # from the main branches on GitHub
SOURCES=local scripts/build-all.sh       # from your checkouts next to this folder
VARIANT=next scripts/build-all.sh        # the "next" image, with every Antimatter app

Vyžaduje Docker s buildx, Python 3, git a gpg, přibližně 16 GB RAM a 30 GB disku. Výsledek se načte jako ghcr.io/antimatterchat/antimatter:dev; vyzkoušejte to pomocí ANTIMATTER_IMAGE=ghcr.io/antimatterchat/antimatter:dev docker compose -f compose.local.yml up -d. Soubor plugins.json obsahuje seznam aplikací a sestavených verzí, varianty popisuje README v repozitáři.

Skript build-all.sh podepisuje přibalené aplikace klíčem pro podepisování Antimatter a sestavení obrazu odmítá nepodepsané aplikace. Bez tohoto privátního klíče, který mají pouze správci projektu, spusťte jednotlivé kroky samostatně: scripts/fetch-sources.sh, scripts/build-plugins.sh (balíčky aplikací v out/plugins/) a scripts/build-server.sh (archivy serveru v out/server/).

Sestavení a paměť

Webové rozhraní jsou velké webpack sestavení a nedostatek paměti je nejčastější příčinou selhání.

  • Příkaz npm run build sestaví klasické rozhraní a Fusion po sobě, ne paralelně, aby se snížil špičkový nárok na paměť. Nesnažte se je spouštět paralelně sami.
  • Minifikátor spouští jeden worker na každý procesor. Na stroji s mnoha jádry a málo paměti omezte počet procesorů, které sestavení vidí: taskset -c 0-5 npm run build.
  • Pokud Node.js dojde na heap, zvýšte jeho limit: NODE_OPTIONS=--max-old-space-size=6144. Sestavení v Dockeru používá právě tuto hodnotu (BUILD_NODE_OPTIONS v build.env).
  • Na menším stroji se vyvarujte současného spuštění celé testovací sady serveru, sestavení webu a sestavení Dockeru.

Aplikace

Každá aplikace (plugin) má vlastní repozitář a Makefile; příkaz make dist sestaví její balíček. Více viz Sestavení, instalace a ladění.

Desktopová aplikace

Desktopová aplikace je Electron aplikace. S Node.js 24 nebo novějším:

npm install --allow-git=all
npm run build          # development build, into dist/
npm start              # run it
npm run package:linux  # packages into release/ (also package:windows, package:mac)

Nastavení pro čas sestavení, jako jsou předkonfigurované servery, se nacházejí v src/common/config/buildConfig.ts.

Mobilní aplikace

Mobilní aplikace je React Native aplikace; její README obsahuje seznam příkazů (npm run ios, npm run android). Pro sestavení vlastní kopie budete potřebovat také vlastní klíče pro podepisování, projekt Firebase pro notifikace na Androidu, klíč APNs pro iOS a push proxy obsahující tyto přihlašovací údaje.
