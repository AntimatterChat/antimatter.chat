AI

Funkce Antimatter s umělou inteligencí používají modely, které si sami vyberete: cloudového poskytovatele, nebo server ve vlastní síti. Nikam se nic neodesílá, dokud nekonfigurujete model. Tato stránka popisuje jednotlivé funkce, data, která odesílají, a jak je vypnout.

Funkce s umělou inteligencí

FunkceKonfiguruje se vTyp modeluPůvodně zapnuté
Agenti s umělou inteligencí: chat s botem, shrnutí vláken a kanálů, pomoc v editoru zprávAplikaci AgentiJakoukoli službu velkého jazykového modelu (LLM)Aplikace je zapnutá, ale nic nedělá, dokud nepřidáte službu
Přepisy a titulky v reálném čase pro hovoryAplikaci HovoryPřepis řeči, kompatibilní s OpenAIne

Automatický překlad kanálůServerLibreTranslate, LLM kompatibilní s OpenAI, nebo služba Agentine

"Kompatibilní s OpenAI" znamená server, který nabízí stejné HTTP API jako OpenAI. Většina serverů s modely, které si můžete provozovat sami, to dělá (například Ollama, vLLM, server llama.cpp, nebo servery pro přepis řeči a převod textu na řeč), stejně jako mnoho cloudových poskytovatelů. Pro žádnou z těchto funkcí není potřeba licence.

AI agenti

Aplikace Agenti (id mattermost-ai) je původně zapnutá. Její nastavení vyžaduje dva kroky: přidejte službu (připojení k poskytovateli modelu) a poté vytvořte agenty (boty, které službu používají).

1. Přidání služby

Přejděte do Systémová konzole › Pluginy › Agenti a pod Služby s umělou inteligencí klikněte na Přidat službu s umělou inteligencí. Zvolte Typ služby:

  • Kompatibilní s OpenAI: pro server s modelem, který provozujete sami, nebo pro jakýkoli poskytovatel s API ve stylu OpenAI. Vyplňte URL API (například http://ollama:11434/v1 nebo http://vllm.internal:8000/v1) a API klíč pouze tehdy, pokud ho server vyžaduje. Pokud server podporuje pouze API Chat Completions, vypněte Používat API Responses.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: hostované poskytovatele. Každý z nich vyžaduje API klíč (Bedrock: region AWS a přihlašovací údaje nebo roli IAM; Vertex AI: projekt, region a služební účet; Azure: také URL API).

Nastavte Model ve výchozím nastavení (seznam, pokud poskytovatel umí reportovat své modely, jinak zadejte název) a, pokud poskytovatel neuvádí limity, Limity vstupních tokenů a Limity výstupních tokenů. Záložní služba může převzít práci, pokud tato selže. Uložte.

Server tyto požadavky provádí sám, takže musí mít přístup k API: k serveru modelu ve stejném compose projektu, v síti nebo na internetu. Odchozí požadavky respektují proměnné HTTP_PROXY a HTTPS_PROXY.

2. Vytvoření agentů

Agenti se vytvářejí na stránce Agenti webové aplikace: otevřete ji z nabídky produktu nebo přes Spravovat v selektoru agentů v panelu Agenti. Její adresa je https://chat.example.com/plug/mattermost-ai/agents. Každý agent má Zobrazovaný název, Uživatelské jméno agenta (jak ho lidé zmiňují), Službu a volitelně model, Vlastní instrukce a přepínače pro Povolení vize (obrázky) a Povolení nástrojů. Vкладка Přístup omezuje, v kterých kanálech se agent může používat a kteří uživatelé ho mohou používat. V sekci AI funkce v Systémové konzole Bot ve výchozím nastavení určuje agenta, který se použije, pokud žádný není vybrán, například pro shrnutí hovorů.

Ve výchozím nastavení může každý uživatel vytvářet vlastní agenty, se službami, které jste nakonfigurovali. Pokud to chcete omezit na administrátory, odeberte oprávnění Spravovat vlastní AI agenty z role členů v Systémová konzole › Správa uživatelů › Oprávnění.

Volitelné funkce aplikace Agenti

  • Vyhledávání pomocí embeddingů (experimentální, vypnuto): sémantické vyhledávání v zprávách. Vyžaduje PostgreSQL s rozšířením pgvector a embedding model (OpenAI nebo kompatibilní). Odesílá každou zprávu do embedding modelu, včetně soukromých kanálů a přímých zpráv.
  • Webové vyhledávání (vypnuto): umožňuje agentům vyhledávat na webu přes Google, Brave nebo SearXNG server, který provozujete.
  • Nativní nástroje: u poskytovatelů, kteří je nabízejí, mohou agenti používat vlastní webové vyhledávání poskytovatele (u nových agentů zapnuto ve výchozím nastavení, kde je podporováno), načítání webů a provádění kódu. Tyto se provádějí u poskytovatele. Vypněte je pro jednotlivé agenty.
  • Model Context Protocol (MCP): připojte agenty k MCP serverům, kterým důvěřujete, pro další nástroje.
  • Ladění: Trace Output (vypnuto, serverové logy nebo OpenTelemetry endpoint) a Povolení logování spotřeby tokenů, které zapisuje počty tokenů do logs/agents/token_usage.log.

Přepis řeči: přepisy hovorů a titulky

Hovory lze přepisovat s titulky v reálném čase pomocí serveru pro převod řeči na text, který nabízí endpoint /v1/audio/transcriptions kompatibilní s OpenAI. Nastavení najdete v sekci Hovory a hlas. Pokud je zapnuto Shrnutí přepisů, výchozí agent také zveřejní shrnutí každého přepisu.

Převod textu na řeč: Přečíst nahlas

Pokud je převod textu na řeč zapnutý, má menu každé zprávy položku Přečíst nahlas: server pošle text zprávy do API pro převod textu na řeč a přehraje zvuk. Nastavení najdete v Systémová konzole › Integrace › Převod textu na řeč:

NastaveníKlíč a proměnnáCo zadat
Přečítat zprávy nahlasTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (výchozí je vypnuto)
Základní URL APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLZákladní URL včetně /v1, například http://tts.internal:8000/v1. Server volá jeho endpoint /audio/speech.
ModelTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELModel tak, jak ho API nazývá, například tts-1. Povinné.
HlasTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEJeden z hlasů modelu, nebo prázdné pro výchozí.
API klíčTextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYOdesílá se jako bearer token. Prázdné, pokud API žádný token nevyžaduje.

Před odesláním server odstraní bloky kódu, odkazy, kódy emoji a formátování a ponechá nejvýše 4000 znaků. Požaduje MP3 zvuk a drží v paměti posledních 64 výsledků, takže zpráva přečtená dvakrát se odešle pouze jednou.

Automatický překlad

Automatický překlad zobrazuje zprávy kanálu v mateřském jazyce každého čtenáře. Nastavíte ho v Systémová konzole › Konfigurace webu › Lokalizace, v sekci Automatický překlad:

NastaveníKlíčVýchozí
ZapnoutAutoTranslationSettings.EnableVypnuto
Poskytovatel překladuAutoTranslationSettings.Providerlibretranslate, openai (zobrazováno jako „OpenAI-compatible API“) nebo agents (služba aplikace Agenti)
Povolené jazykyAutoTranslationSettings.TargetLanguagesen: jazyky, do kterých lze zprávy překládat
Časový limit překladu (ms)AutoTranslationSettings.TimeoutMs5000
Omezit automatický překlad u přímých zpráv a skupinových zprávAutoTranslationSettings.RestrictDMAndGMVypnuto

Každý poskytovatel má vlastní pole:

  • LibreTranslate: API endpoint LibreTranslate a API klíč LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Server LibreTranslate může běžet ve vaší vlastní síti.
  • OpenAI-compatible API: Základní URL API (včetně /v1; server používá jeho endpoint pro chat completions), Model a API klíč (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Dobře funguje malý překladový model běžící lokálně.
  • Agenti: AI služba, jedna ze služeb nakonfigurovaných v aplikaci Agenti.

Po zapnutí překladači správci kanálů aktivují překlad pro konkrétní kanál v jeho nastaveních (Automatický překlad), a každý člen se může od překládání odhlásit z nabídky kanálu (Přeložit zprávy). V přímých a skupinových zprávách ho může zapnout kdokoli; pokud je aktivní omezení, v těchto typech zpráv překlad není k dispozici. Přeložené zprávy zobrazují „Přeloženo z …“ s odkazem na originál.

Kód, odkazy, zmínky a emoji se před odesláním textu nahradí zástupnými znaky a po jeho zpracování se vrátí na své místo.

Pokud chcete, aby všechno zůstalo ve vaší síti, nastavte všechny funkce tak, aby používaly servery, které provozujete sami. Pokud používáte cloudového poskytovatele, zkontrolujte jeho podmínky pro uchovávání dat a informujte své uživatele, které funkce odesílají jejich zprávy ven.

Vypnutí AI

Neexistuje jeden přepínač: každá funkce má svůj vlastní.

  • Agenti: vypněte aplikaci Agenti v Systémová konzole › Pluginy › Správa pluginů. Tím se také odstraní shrnutí hovorů a překladový poskytovatel Agenti.
  • Přepis a titulky: AM_CALLS_ENABLE_TRANSCRIPTIONS=false a AM_CALLS_ENABLE_LIVE_CAPTIONS=false (výchozí hodnoty).
  • Přečíst nahlas: vypněte Přečítat zprávy nahlas (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, výchozí hodnota).
  • Překlad: vypněte automatický překlad (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, výchozí hodnota).

Vypnutí aplikace Agenti neovlivní ostatní tři funkce: ty volají přímo svá vlastní API.
