Integrované aplikace

Dockerové obrazy Antimatter obsahují sadu aplikací (v Systémové konzoli označovaných jako pluginy). Tato stránka je vyjmenovává, uvádí, které jsou povoleny po instalaci, a popisuje nastavení, která pro ně administrátor potřebuje.

Integrované aplikace

Aplikace jsou v Systémové konzoli uvedeny jako Pluginy. Jsou součástí obrazu (v /antimatter/prepackaged_plugins), podepsané klíčem pro podepisování aplikací Antimatter, takže se instalují bez připojení k internetu.

Aplikace povolené výchozí se při každém spuštění nainstalují, pokud ještě nejsou, nebo aktualizují, pokud má obraz novější verzi. Pokud některou vypnete, zůstane vypnutá: výchozí nastavení se vztahuje pouze na aplikace, které konfigurace ještě nezmíní. Aplikace, které si zachovávají ID z Mattermost (Agenti, Hovory, Kanban, Playbooky a integrace), jsou vlastní sestavy Antimatter.

Povolení, zakázání a konfigurace aplikací

Přejděte do Systémová konzole › Pluginy › Správa pluginů. V sekci Nainstalované pluginy má každá aplikace možnosti Zapnout nebo Zakázat, Nastavení a Odebrat a zobrazuje svůj stav (Běží, Neběží, Selhání při spuštění…). Každá aplikace s nastavením má také vlastní stránku pod Systémová konzole › Pluginy.

Vestavěné aplikace, které jsou ve výchozím stavu vypnuté, se instalují z vlastní kopie v obrazu: otevřete Trh s aplikacemi z produktového menu, najděte aplikaci a klikněte na Nainstalovat, poté ji zapněte ve správě pluginů. Z příkazového řádku:

docker compose exec antimatter amctl --local plugin marketplace install github
docker compose exec antimatter amctl --local plugin enable github

Další příkazy: amctl plugin list, amctl plugin disable <id>, amctl plugin delete <id>.

Povolení aplikací přes konfiguraci

Které aplikace jsou zapnuté, určuje nastavení PluginSettings.PluginStates, což je mapa identifikátorů aplikací. Záznamy do ní můžete sloučit pomocí amctl; pokud je zapnuto Povolit automatické předbalované pluginy (což je výchozí stav), zapnutá vestavěná aplikace se nainstaluje při dalším spuštění:

docker compose exec -T antimatter amctl --local config patch /dev/stdin <<'EOF'
{"PluginSettings": {"PluginStates": {"com.mattermost.plugin-todo": {"Enable": true}}}}
EOF
docker compose restart antimatter

Tímto způsobem nainstalujete i Úkoly, které nejsou nabízeny v dialogu trhu s aplikacemi. Proměnná AM_PLUGINSETTINGS_PLUGINSTATES také funguje, ale nahradí celou mapu: vyjmenujte všechny aplikace, které chcete povolené.

Nastavení aplikací

Nastavení aplikací se ukládá pod PluginSettings.Plugins.<app id>, s klíči ve小写字母. Změňte je na stránce Systémová konzole aplikace, nebo pomocí amctl config patch, jak je ukázáno v Konfiguraci. AM_PLUGINSETTINGS_PLUGINS nahrazuje nastavení všech aplikací najednou a uzamkne je všechny, takže se mu vyhněte.

Pokud je aplikace GIFs nakonfigurována, její záložka nahradí vestavěný výběr Giphy (Systémová konzole › Integrace › GIF › Povolit výběr GIFů, ServiceSettings.EnableGifPicker).

Služba pro GIFy

Služba ukládá vše do svého datového adresáře (/data, svazek gifs): index pro vyhledávání a média. Její hlavní proměnné:

ProměnnáVýchozíCo dělá
AM_GIFS_API_KEYSžádnáAPI klíče oddělené čárkami. Bez klíče je API otevřené pro kohokoli, kdo se k němu dostane. Více klíčů umožňuje jejich rotaci.
AM_GIFS_UPLOAD_KEYSžádnáKlíče povolené pro nahrávání. Bez klíče není nahrávání možné.
AM_GIFS_RATE_LIMIT20Počet požadavků za sekundu na klienta (API klíč a adresa); 0 to vypne. Compose soubor nastavuje 0, protože všechny požadavky Antimatteru sdílejí jeden klíč a adresu.
AM_GIFS_LISTEN:8080Posluchová adresa.
AM_GIFS_PUBLIC_URLz požadavkůExterní URL, pokud službu zveřejňujete.
AM_GIFS_TRUST_PROXYfalseDůvěřovat hlavičkám X-Forwarded-*, pouze za proxy.
AM_GIFS_UPLOAD_MAX_MB16Největší nahrávaný soubor.

Pokud chcete hromadně přidat vlastní GIFy, importujte je pomocí manifestu z adresáře připojeného do jednorázového kontejneru:

docker compose run --rm -v "$PWD/my-gifs:/import:ro" gifs import -manifest /import/manifest.json

Pokud chcete po aktualizaci znovu importovat výchozí samolepky: docker compose run --rm gifs stickers. Formát manifestu a ostatní příkazy najdete v README projektu gifs-server.

Pošta a kalendář

Pošta a kalendář propojí každého uživatele s jeho vlastní poštovní schránkou (IMAP a SMTP) a jeho vlastním kalendářem (CalDAV). Uživatelé zadají v aplikaci svůj server a heslo; hesla se ukládají zašifrovaná. Vy nekonfigurujete poštovní ani kalendářové servery za ně, ale určíte, na co se mohou připojit:

AplikaceNastaveníVýchozíCo dělá
Pošta, kalendářPovolit poštovní servery v soukromých sítích, Povolit kalendářové servery v soukromých sítích (AllowPrivateNetworks)VypnutoVypnuto, server odmítá připojení k smyčkovým, soukromým a link-local adresám, takže aplikacemi nelze dosáhnout na vaši vnitřní síť. Zapněte, pokud je váš poštovní nebo kalendářový server na soukromé adrese.
Pošta, kalendářPovolit nešifrované připojení (AllowInsecureConnections)VypnutoVypnuto, připojení musí používat TLS (Pošta: TLS nebo STARTTLS; Kalendář: HTTPS).
E-mailInterval kontroly nepřečtených (minuty) (UnreadCheckMinutes)2 minutyJak často se kontrolují počty nepřečtených, když poštovní server nedokáže posílat aktualizace.
E-mailNejvětší velikost zprávy (MB) (MaxMessageSizeMB)25 MBLimit velikosti odesílaných a čtených zpráv.
KalendářOdesílat připomínky (EnableReminders)zapnutoBot Kalendáře odesílá přímou zprávu před událostmi (10 minut předem, pro události bez vlastního alarmu).

Pokud chcete, aby se lidé mohli přihlásit do poštovních schránek Gmail nebo Microsoft 365 pomocí svého účtu místo hesla, vytvořte OAuth klienta a vyplňte pole Google nebo Microsoft v aplikaci Pošta:

  • Google: webový OAuth klient s Gmail API a rozsahem https://mail.google.com/.
  • Microsoft: aplikace Entra ID s delegovanými oprávněními IMAP.AccessAsUser.All, SMTP.Send, offline_access, openid, email a profile. Nájemce je výchozí common.
  • V obou případech je přesměrovací URI https://chat.example.com/plugins/com.antimatterchat.mail/oauth/callback (URL vašeho webu).

Kanban, poznámky, tabule, hlasování a playbooks

  • Kanban (focalboard) je dostupné na adrese /kanban (staré odkazy /boards se přesměrovávají sem). Jediné nastavení, Povolit veřejně sdílené nástěnky (EnablePublicSharedBoards, vypnuto), umožňuje editorům nástěnky sdílet nástěnku s kýmkoli, kdo má odkaz, bez nutnosti přihlášení.
  • Aplikace Poznámky a Hlasování nemají žádná nastavení.
  • Tabule: systémoví administrátoři mohou v nastavení serveru nahrát knihovny tvarů (soubory Excalidraw .excalidrawlib, každý do 5 MB) pro celý server. Administrátoři komunit spravují knihovny své komunity.
  • Aplikace Playbook má několik nastavení, většinou experimentálních funkcí; výchozí hodnoty vyhovují většině serverů.
  • Memes: Kdo může přidávat šablony memů (výchozí je všichni, nebo pouze administrátoři).
  • Aplikace Úkoly nemá žádná serverová nastavení.

GitHub, GitLab a Jira

Tyto aplikace propojují Antimatter s vaším hostitelem kódu a systémem pro správu chyb. Každá vyžaduje OAuth aplikaci na druhé straně a webhook směřující zpět do Antimatter. Zapněte aplikaci a poté spusťte její instalační příkaz v libovolném kanálu, který vás provede postupně krok za krokem: /github setup, /gitlab setup nebo /jira setup.

AplikaceOAuth redirect URLWebhook URL
GitHubhttps://chat.example.com/plugins/github/oauth/completehttps://chat.example.com/plugins/github/webhook
GitLabhttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/oauth/completehttps://chat.example.com/plugins/com.github.manland.mattermost-plugin-gitlab/webhook
Jira/jira instance install server <url> nebo /jira instance install cloud-oauth <url>; příkaz /jira webhook vypíše adresy webhooků.
V aplikacích GitHub a GitLab nechte Použít předregistrovanou OAuth aplikaci vypnuté: tato možnost spoléhá na službu Mattermost, kterou Antimatter nemá, a aplikace s touto volbou zapnutou odmítne spustit. Zaregistrujte si vlastní OAuth aplikaci.

Aplikace GitHub a GitLab vygenerují svůj webhook secret a šifrovací klíč při prvním uložení. Aplikaci GitHub lze omezit na organizace (GithubOrg) a aplikaci GitLab na skupinu (GitlabGroup); pro GitHub Enterprise nebo samostatně hostovaný GitLab nastavte jeho základní URL.

Metriky

Aplikace Metrics sbírá výkonové metriky serveru do malé časové řady databáze uvnitř Antimatter, takže je můžete stáhnout nebo je zahrnout do podpůrného balíčku bez nutnosti spouštět Prometheus. Při spuštění zapne metrikový endpoint serveru (MetricsSettings.Enable). Viz Provoz.

Instalace dalších aplikací

Antimatter běží s aplikacemi Mattermost (pluginy). Tři způsoby, jak aplikaci přidat:

  • Z vzdáleného tržiště. Povolit vzdálené tržiště (PluginSettings.EnableRemoteMarketplace) je ve výchozím stavu vypnuté a URL tržiště (PluginSettings.MarketplaceURL) je prázdné: Antimatter nepoužívá tržiště Mattermost a ignoruje jeho adresu, pokud se v konfiguraci z Mattermostu stále nachází. Chcete-li zobrazit aplikace ze serveru tržiště, kterému důvěřujete, zapněte toto nastavení a zadejte jeho URL. Builds aplikací, které Antimatter dodává (Calls, Playbooks, Kanban a další), jsou z tohoto tržiště skryté, aby nemohly nahradit verze od Antimatter: Povolit builds z Marketplace pro pluginy Antimatter (PluginSettings.AllowMarketplaceToReplaceAntimatterPlugins) je ve výchozím stavu vypnuté.
  • Nahráním balíčku (.tar.gz). Nahrávání je výchozí vypnuté a v Systémové konzoli nemá přepínač: nastavte AM_PLUGINSETTINGS_ENABLEUPLOADS=true, poté použijte Nahrát plugin v Správě pluginů, nebo amctl --local plugin add app.tar.gz.
  • Z adresy URL: amctl plugin install-url <url>, také s povoleným nahráváním.

Antimatter ověřuje podpisy aplikací podle klíčů, kterým důvěřuje: klíč Antimatter, klíč, jímž společnost Mattermost, Inc. podepisuje své publikované aplikace (tím se dají nainstalovat i aplikace Mattermost, které si stáhnete sami), a jakýkoli klíč, který přidáte v PluginSettings.SignaturePublicKeyFiles. Pokud je zapnuto Vyžadovat podpis pluginu (PluginSettings.RequirePluginSignature, ve výchozím stavu vypnuto), nepodepsané aplikace se zamítnou a nahrávání je zakázáno.

Aplikace běží na serveru a má plný přístup k jeho datům. Nainstalujte pouze aplikace, kterým důvěřujete.

Některé aplikace vytvořené pro placené edice Mattermost si samy kontrolují licenci Mattermost a odmítají spustit; Antimatter se u nich nedělá, že by licenci měl.
