Provozování serveru

Tento průvodce je určen systémovým administrátorům, kteří instalují a provozují server Antimatter. Předpokládá, že znáte Linux, Docker a reverzní proxy, ale neznáte Antimatter.

Z čeho se nasazení skládá

Antimatter je self-hosted týmový chat, fork projektu Mattermost. Kompletní nasazení se skládá z těchto částí. Povinné jsou pouze první tři.

KomponentaCo děláPovinná
Server AntimatterJeden Go program (antimatter), který obsluhuje webovou aplikaci, API a websockets na portu 8065, spouští zabudované aplikace (pluginy) a přenáší média hovorů na portu 8443. Spravuje se příkazovým nástrojem amctl.ano
PostgreSQLDatabáze: zprávy, uživatelé, komunity a v doporučeném nastavení i konfigurace serveru. Verze 15 nebo novější.ano
Úložiště souborůNahrané soubory, obrázky a nainstalované aplikace: S3-kompatibilní služba (soubor compose spouští RustFS) nebo lokální adresář.ano
Reverzní proxyHTTPS před serverem: profil Caddy ze souboru compose, nebo váš vlastní nginx.pro produkci
Služba pro GIF (gifs-server)GIFy a samolepky pro výběr GIFů, z vašeho vlastního katalogu. Komunikuje přes API Tenor.ne
Push proxyPřeposílá oznámení do mobilní aplikace přes Apple a Google.pro mobilní oznámení
rtcd, TURN serverSamostatný mediální server pro mnoho hovorů a relé pro lidi za přísnými firewall.ne
AI koncové bodyModely za AI agenty, přepisem hovorů, předčítáním a překladem: cloudový poskytovatel nebo servery, které provozujete sami.ne

Antimatter nemá licenci ani placenou edici: single sign-on, LDAP, vysoká dostupnost, exporty pro soulad s předpisy, uchovávání dat a další funkce, které Mattermost vyhrazuje svým placeným plánům, jsou všechny zahrnuty.

Požadavky

  • Linux server, amd64 nebo arm64, s 2 CPU jádry a 4 GB paměti nebo více pro několik set lidí, a diskový prostor pro soubory, které lidé nahrávají.
  • Docker Engine s pluginem Compose (docker compose), pro doporučenou instalaci.
  • Pro produkci: doménové jméno ukazující na server a otevřené porty 80 a 443 pro HTTPS.
  • Pro hovory: port 8443, UDP a TCP, dosažitelný pro lidi, kteří volají.
  • Pro e-mail: SMTP server, přes který Antimatter může posílat.

Rychlý start

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

Poté otevřete URL webu a vytvořte si účet: první účet se stane administrátorem systému. Instalace popisuje každý krok a další způsoby instalace.

V tomto průvodci

  • Instalace: Docker Compose, obrazy, archiv s vydáním, první administrátor.
  • Konfigurace: nastavení v databázi nebo v souboru, proměnné prostředí AM_, Systémová konzole, amctl, protokoly.
  • Doména a HTTPS: URL webu, Caddy, nginx, adresy klientů.
  • Hovory a hlas: porty, NAT, TURN, rtcd, přepis a titulky.
  • E-mail a push: SMTP, push proxy a mobilní aplikace.
  • Vestavěné aplikace: které aplikace jsou zapnuté, jejich nastavení, instalace jiných.
  • AI: modely pro agenty, řeč a překlad, a kam se data posílají.
  • Přihlášení a účty: registrace, hesla, MFA, jednotné přihlášení, LDAP, hosté, relace.
  • Zálohy a aktualizace: zálohování, obnova, aktualizace, přechod z Mattermost.
  • Provoz: monitorování, škálování, uchovávání dat, soulad s předpisy, řešení problémů.
  • Zabezpečení: kontrolní seznam posílení a externí spojení.

Provozujete spíše komunitu než server (kanály, role, moderace)? Podívejte se na Provoz komunity. Vytváříte integrace? Podívejte se na Vytváření na Antimatter.

Vaše první hodina

  1. Nainstalujte a hned vytvořte účet administrátora.
  2. Umístěte server za HTTPS na vlastní doménu.
  3. Nakonfigurujte SMTP a odešlete testovací e-mail.
  4. Otevřete port pro hovory a vypněte testovací režim aplikace Hovory.
  5. Rozhodněte, kdo se může registrovat, a zapněte MFA.
  6. Zkontrolujte externí spojení v Zabezpečení.
  7. Nakonfigurujte denní zálohy.
