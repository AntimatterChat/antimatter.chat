Antimatter vs. Mattermost

Antimatter és una bifurcació de Mattermost: en conserva el servidor, les API i les integracions. El que canvia són les llicències, la interfície i les aplicacions.

Per què els equips trien Antimatter

  • Totes les funcionalitats són programari lliure sota l’AGPL: l’SSO, la sincronització LDAP, l’exportació per a compliment normatiu, la retenció de dades i tota la resta venen amb tots els servidors.
  • Una interfície nova, amb canals de veu, rols i distintius, incorporació i eines de moderació.
  • Notes, pissarres, llistes de tasques, calendari i correu integrats, i transcripció amb IA sense serveis addicionals.
  • Conserva les API de Mattermost, de manera que les integracions escrites per a Mattermost continuen funcionant.

Quan et pot convenir més Mattermost

  • Vols assistència comercial, amb SLA, de l’empresa que desenvolupa el programari.
  • Necessites compilacions certificades, com ara imatges FIPS 140-3 o reforçades segons els STIG.
  • Necessites funcionalitats que Antimatter encara no té, com ara clústers d’alta disponibilitat provats a gran escala o la retenció per motius legals (legal hold).
