Política de privadesa

Darrera actualització: 11 d’octubre de 2026. Aquesta traducció s’ofereix només per comoditat; en cas de discrepància, preval la versió en anglès.

Aquesta pàgina tracta dues coses: el programari Antimatter, que les organitzacions executen als seus propis servidors, i aquest lloc web, antimatter.chat.

El programari Antimatter

Antimatter és autoallotjat. Quan fas servir un servidor d’Antimatter, l’organització que el gestiona decideix quines dades es conserven, durant quant de temps i qui hi pot accedir. El projecte Antimatter no té accés al teu servidor, al teu compte ni als teus missatges. Si tens preguntes sobre les teves dades en un servidor concret, adreça’t als seus administradors; s’hi aplica la seva pròpia política de privadesa.

Què fa el programari pel seu compte:

  • Cap telemetria. El servidor no envia estadístiques d’ús, diagnòstics ni cap altra dada al projecte Antimatter ni a tercers.
  • Connexions a l’exterior només per a les funcionalitats que activa un administrador, cap als serveis que configura: per exemple, un servei de notificacions push, previsualitzacions dels llocs web enllaçats als missatges, un proveïdor de GIF, un servidor de correu electrònic, un proveïdor d’identitat per a l’inici de sessió únic, o models d’IA, de veu o de traducció.
  • Les funcionalitats d’IA fan servir els models que tria l’administrador. Quan els allotja un tercer, el que se’ls envia (un missatge per reescriure, una conversa per resumir, l’àudio d’una trucada que es transcriu) va a aquest proveïdor. Els administradors poden fer servir models autoallotjats perquè res no surti de la seva xarxa.

Aquest lloc web

  • antimatter.chat és un lloc web estàtic allotjat a GitHub Pages.
  • No instal·la cap galeta ni fa servir cap eina d’analítica, rastrejador ni publicitat. Les fonts i les imatges se serveixen des del mateix lloc, de manera que el teu navegador no fa cap petició a altres llocs web mentre el llegeixes.
  • Com qualsevol servei d’allotjament web, GitHub rep la teva adreça IP i les pàgines que sol·licites, per poder-te-les servir. Consulta la declaració de privadesa de GitHub.
  • Si obres una incidència o hi contribueixes a GitHub, el que hi publiquis és públic i GitHub ho tracta d’acord amb les seves pròpies condicions.
