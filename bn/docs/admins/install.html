Antimatter ইনস্টল করা

প্রস্তুত compose ফাইল ব্যবহার করে Antimatter ইনস্টল করুন, সঠিক ইমেজ বেছে নিন, অথবা রিলিজ আর্কাইভ থেকে সার্ভার চালান। এরপর প্রথম অ্যাডমিনিস্ট্রেটর অ্যাকাউন্ট তৈরি করুন।

Docker Compose দিয়ে ইনস্টল করা

এটিই সুপারিশকৃত পদ্ধতি। একটি compose ফাইল Antimatter, PostgreSQL, ফাইল স্টোরেজ এবং GIF সার্ভিস চালায়। আপনার একটি Linux সার্ভার, Docker Engine এবং এর Compose প্লাগইন (docker compose), ২টি CPU কোর এবং ৪ GB মেমরি বা তার বেশি প্রয়োজন।

১. compose ফাইল ডাউনলোড করুন

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml

২. .env ফাইল তৈরি করুন

compose ফাইল একই ডিরেক্টরিতে থাকা .env ফাইল থেকে সেটিংস পড়ে। এটি র‍্যান্ডম সিক্রেটস সহ তৈরি করুন:

cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
chmod 600 .env

SITE_URL সেট করুন সেই ঠিকানায় যেখানে ব্যবহারকারীরা তাদের ব্রাউজারে টাইপ করবেন, যেমন লোকাল নেটওয়ার্কে http://192.168.1.20:8065 বা ডোমেইন সহ https://chat.example.com। .env ফাইলটি সংরক্ষণ করুন: ডাটাবেস এবং স্টোরেজ প্রথমবার চালুর সময় এই পাসওয়ার্ডগুলো ব্যবহার করে, এবং ব্যাকআপ রিস্টোর করতেও এই একই ফাইল প্রয়োজন।

৩. চালু করুন

docker compose up -d
docker compose ps

প্রথমবার চালু হতে এক বা দুই মিনিট লাগতে পারে: PostgreSQL ডাটাবেস তৈরি করে, একটি one-shot bucket সার্ভিস স্টোরেজ বাক্স তৈরি করে, একটি one-shot gifs-stickers সার্ভিস স্টার্টার স্টিকার প্যাক ইমপোর্ট করে, এবং Antimatter তার টেবিলগুলো তৈরি করে। এটি ট্র্যাক করতে docker compose logs -f antimatter ব্যবহার করুন।

শুরু থেকেই ডোমেইন নাম এবং HTTPS ব্যবহার করতে, দেখুন ডোমেইন এবং HTTPS: compose ফাইলের ক্ষেত্রে এটি .env-এ আরও দুই লাইন এবং https প্রোফাইল।

PostgreSQL, স্টোরেজ এবং GIF সার্ভিস একটি অভ্যন্তরীণ নেটওয়ার্ক (private)-এ আছে, যার কোনো ইন্টারনেট অ্যাক্সেস নেই, এবং শুধুমাত্র Antimatter এই নেটওয়ার্কে যোগদান করে। তাদের কেউই কোনো পোর্ট পাবলিশ করে না।

Antimatter কন্টেইনারটি ডিস্কে কিছুই রাখে না: এর সেটিংস ডাটাবেসে (AM_CONFIG এর দিকে ইঙ্গিত করে) এবং এর ফাইল ও অ্যাপস স্টোরেজ সার্ভিসে। আপনি যেকোনো সময় কন্টেইনারটি মুছে ফেলে আবার তৈরি করতে পারেন। ব্যাকআপ করার সবকিছু postgres, files এবং gifs ভলিউমে, সাথে আপনার .env।

একটি ইমেজ নির্বাচন করুন

দুটি Antimatter ইমেজ প্রকাশিত হয়েছে, উভয়ই linux/amd64 এবং linux/arm64-এর জন্য, এবং উভয়ই প্রতিটি রিপোজিটরির main ব্রাঞ্চ থেকে তৈরি:

ইমেজসংযুক্ত অ্যাপসট্যাগসমূহ
ghcr.io/antimatterchat/antimatterএজেন্ট, কল, GitHub, GitLab, Jira, Kanban, Metrics এবং প্লেবুক।latest, রিলিজের জন্য X.Y.Z, sha-<commit>
ghcr.io/antimatterchat/antimatter-nextউপরের সবকিছুর সাথে ভয়েস চ্যানেল, পোল, মেইল, ক্যালেন্ডার, নোট, হোয়াইটবোর্ড, GIF, করণীয় এবং মেম। প্রতি রাতে পুনরায় তৈরি হয়।latest, nightly, nightly-<YYYYMMDD>, sha-<commit>

সাইটের compose ফাইল antimatter-next ব্যবহার করে, কারণ GIF সার্ভিস এবং এই সাইটে বর্ণিত বেশিরভাগ অ্যাপ শুধুমাত্র সেই ইমেজে আছে। ইমেজ পরিবর্তন করতে, .env-এ ANTIMATTER_IMAGE সেট করুন এবং docker compose up -d চালান।

latest আপনার নিচে পরিবর্তিত হয়। প্রোডাকশনে, আপগ্রেডের সময় উদ্দেশ্যমূলকভাবে পরিবর্তন করার জন্য nightly-20261015 বা sha-<commit> এর মতো একটি ট্যাগ পিন করুন। সার্ভার শুরু হওয়ার সময় তার ডাটাবেস আপগ্রেড করে, তাই পূর্বে নেওয়া ব্যাকআপ রিস্টোর না করে আপনি পুরনো ইমেজে ফিরে যেতে পারবেন না, বা antimatter-next থেকে antimatter-এ ফিরে যেতে পারবেন না। দেখুন ব্যাকআপ এবং আপগ্রেড।

ইমেজের ভিতরে

  • সার্ভারটি /antimatter-এ থাকে, আর antimatter এবং amctl বাইনারিগুলো /antimatter/bin-এ (যা PATH-এ আছে)।
  • এটি একটি ন্যূনতম distroless বেসে, কোনো শেল ছাড়াই, অপ্রাইভিলেজড ইউজার antimatter (uid 2000) হিসেবে চলে।
  • পোর্ট: 8065 (ওয়েব এবং API), 8067 (মেট্রিক্স), 8074 (ক্লাস্টার), 8443 UDP এবং TCP (কল)।
  • লোকাল মোড (ServiceSettings.EnableLocalMode) চালু আছে, তাই কন্টেইনারের ভেতরে amctl --local কাজ করে। হেলথ চেক চালায় amctl system status --local।
  • বান্ডল করা অ্যাপগুলো /antimatter/prepackaged_plugins-এ আছে, যা Antimatter অ্যাপ সাইনিং কী দিয়ে সাইন করা।
  • টেক্সট এক্সট্রাকশন টুল (pdftotext, wvText, unrtf, tidy) অন্তর্ভুক্ত আছে, তাই আপলোড করা ডকুমেন্টের কনটেন্ট সার্চ করা যায়।

অন্যান্য কম্পোজ ফাইল

antimatter-docker রিপোজিটরিতে deploy/compose/-এ একটি প্রোডাকশন সেটআপ আছে: আপনার নিজের সার্টিফিকেট বা Let's Encrypt (certbot) সহ nginx, PostgreSQL, অপশনাল GIF সার্ভিস (প্রোফাইল gifs) এবং সার্ভারের কনফিগারেশন, ডেটা ও লগের জন্য নামকৃত ভলিউম, যা তার README-তে ডকুমেন্ট করা আছে। এটি ডিফল্টভাবে স্টেবল ইমেজ ব্যবহার করে এবং S3 স্টোরেজের বদলে লোকাল ভলিউমে ফাইল সংরক্ষণ করে। আপনি যদি Caddy-র চেয়ে nginx পছন্দ করেন, অথবা আগে থেকেই সার্টিফিকেট থাকে, তবে এটি ব্যবহার করুন।

প্রথম অ্যাডমিন তৈরি করুন

ব্রাউজারে SITE_URL খুলে একটি অ্যাকাউন্ট তৈরি করুন। একটি নতুন সার্ভারে তৈরি করা প্রথম অ্যাকাউন্টটি সিস্টেম অ্যাডমিন হয়ে যায়, এবং সেটআপটি আপনাকে আপনার প্রথম কমিউনিটি (Antimatter-এর টিম বা ওয়ার্কস্পেসের নাম) তৈরির வழি দেখায়।

প্রথমবার স্টার্ট করার পরেই এটি করুন: এর আগে যে কেউ সার্ভারে আগে পৌঁছালে সে তার অ্যাডমিন হয়ে যাবে। সার্ভারটি বাইরে থেকে অ্যাক্সেসযোগ্য না হওয়া পর্যন্ত কমান্ড লাইন থেকে অ্যাকাউন্ট তৈরি করতে:

docker compose exec antimatter amctl --local user create --system-admin --email-verified \
    --email admin@example.com --username admin --password 'a-long-password'
docker compose exec antimatter amctl --local team create --name main --display-name "Main"
docker compose exec antimatter amctl --local team users add main admin

তারপর SITE_URL-এ সাইন ইন করুন। পাসওয়ার্ডটি আপনার শেল হিস্ট্রি থেকে বাদ রাখতে কমান্ডের শুরুতে একটি স্পেস দিন (HISTCONTROL=ignorespace সহ), অথবা সাইন ইন করার পরে পাসওয়ার্ডটি পরিবর্তন করুন।

আপনি ভিতরে ঢোকার পরের পরবর্তী ধাপসমূহ:

  1. নির্ধারণ করুন কে কে অ্যাকাউন্ট তৈরি করতে পারবে: সাইন-ইন এবং অ্যাকাউন্ট।
  2. ইমেইল কনফিগার করুন, যাতে আমন্ত্রণ এবং পাসওয়ার্ড রিসেট কাজ করে: ইমেইল এবং পুশ নোটিফিকেশন।
  3. আপনার ফায়ারওয়ালে কলের পোর্ট খুলুন: কল এবং ভয়েস।
  4. যে অ্যাপগুলো চালু আছে তা দেখুন: বান্ডল করা অ্যাপ।

রিলিজ আর্কাইভ থেকে ইনস্টল করুন

Docker ছাড়া সার্ভারটি antimatter-<os>-<arch>.tar.gz নামের একটি আর্কাইভ থেকে চলে (যেমন antimatter-linux-amd64.tar.gz)। এতে একটি antimatter/ ডিরেক্টরি থাকে, যার মধ্যে রয়েছে bin/antimatter, bin/amctl, config/config.json, ওয়েব অ্যাপস (client/ এবং client-fusion/), ইমেইল টেমপ্লেট এবং ট্রান্সলেসন।

1. PostgreSQL প্রস্তুত করুন

Antimatter শুধুমাত্র PostgreSQL সাপোর্ট করে, ভার্সন 15 বা তার পরের (পুরনো ভার্সনগুলো স্টার্ট হয়, তবে লগে এরর দেখা যায়)। একটি ইউজার এবং ডাটাবেস তৈরি করুন:

sudo -u postgres psql <<'EOF'
CREATE USER antimatter WITH PASSWORD 'a-long-password';
CREATE DATABASE antimatter OWNER antimatter;
EOF

2. আনপ্যাক এবং কনফিগার করুন

sudo tar -xzf antimatter-linux-amd64.tar.gz -C /opt
sudo useradd --system --user-group antimatter
sudo mkdir -p /opt/antimatter/data
sudo chown -R antimatter:antimatter /opt/antimatter

সার্ভারকে ডাটাবেসের সাথে সংযুক্ত করুন, /opt/antimatter/config/config.json (SqlSettings.DataSource)-এ অথবা এনভায়রনমেন্ট ভেরিয়েবল ব্যবহার করে, এবং সাইটের URL সেট করুন:

AM_SQLSETTINGS_DRIVERNAME=postgres
AM_SQLSETTINGS_DATASOURCE=postgres://antimatter:a-long-password@localhost:5432/antimatter?sslmode=disable&connect_timeout=10
AM_SERVICESETTINGS_SITEURL=https://chat.example.com

আর্কাইভের config.json একটি সম্পূর্ণ ডিফল্ট কনফিগারেশন: System Console-এ আপনি যে সেটিংস পরিবর্তন করেন, সেগুলো সেখানেই সেভ হয়। যদি আপনি কনফিগারেশনটি ডাটাবেসে রাখতে চান, তবে Configuration দেখুন।

3. এটি একটি সার্ভিস হিসেবে চালান

একটি systemd ইউনিট, /etc/systemd/system/antimatter.service-এ:

[Unit]
Description=Antimatter
After=network.target postgresql.service

[Service]
Type=notify
User=antimatter
Group=antimatter
WorkingDirectory=/opt/antimatter
ExecStart=/opt/antimatter/bin/antimatter
EnvironmentFile=-/etc/antimatter.env
TimeoutStartSec=3600
Restart=always
RestartSec=10
LimitNOFILE=49152

[Install]
WantedBy=multi-user.target

আপনার AM_ ভেরিয়েবলগুলো /etc/antimatter.env-এ রাখুন (শুধুমাত্র root-এর দ্বারা পঠনযোগ্য), তারপর:

sudo systemctl daemon-reload
sudo systemctl enable --now antimatter
journalctl -u antimatter -f

সার্ভারটি পোর্ট 8065-এ লিসেন করে। http://<server>:8065 খুলুন, অথবা রিভার্স প্রক্সি সেটআপ করার পর আপনার ডোমেইন (দেখুন Domain and HTTPS), এবং প্রথম অ্যাকাউন্ট তৈরি করুন: এটি সিস্টেম অ্যাডমিনিস্ট্রেটর হয়ে যাবে।

bin/amctl কমান্ড লাইন থেকে চলমান সার্ভারটি ম্যানেজ করে। সার্ভারের নিজের ওপর, এটি লোকাল মোডের মাধ্যমে সাইন ইন ছাড়াই কাজ করে: AM_SERVICESETTINGS_ENABLELOCALMODE=true সেট করুন, তারপর sudo -u antimatter /opt/antimatter/bin/amctl --local system status চালান।

অন্যান্য সার্ভার কমান্ড

সার্ভার চালানোর (antimatter, অথবা antimatter server) পাশাপাশি, বাইনারিটিতে কিছু রক্ষণাবেক্ষণ কমান্ড রয়েছে। এগুলো সার্ভারের মতোই একই কনফিগারেশন পড়ে।

কমান্ডএটি কী করে
antimatter versionভার্সন, বিল্ড নম্বর, বিল্ড তারিখ এবং বিল্ড হ্যাশ প্রিন্ট করে।
antimatter db pingযাচাই করে যে ডাটাবেসে পৌঁছানো সম্ভব।
antimatter db initডাটাবেসে কনফিগারেশন তৈরি করে (AM_CONFIG একটি postgres:// URL-এ সেট করে)।
antimatter db migrateসার্ভার স্টার্ট না করে ডাটাবেস মাইগ্রেশন প্রয়োগ করে।
antimatter db versionডাটাবেসে প্রয়োগ করা শেষ মাইগ্রেশনটি প্রিন্ট করে।
antimatter import bulk, antimatter export bulkবাল্ক ফরম্যাটে ডেটা ইমপোর্ট বা এক্সপোর্ট করে (দেখুন Backups and upgrades)।
