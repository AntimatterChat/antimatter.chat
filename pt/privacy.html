Política de privacidade

Última atualização: 16 de outubro de 2026.

Esta página abrange dois aspetos: o software Antimatter, que as organizações executam nos seus próprios servidores, e este website, antimatter.chat.

O software Antimatter

O Antimatter é auto-hospedado. Quando utiliza um servidor Antimatter, a organização que o gere decide que dados são mantidos, por quanto tempo e quem pode aceder a eles. O projeto Antimatter não tem acesso ao seu servidor, à sua conta nem às suas mensagens. Para questões sobre os seus dados num servidor específico, contacte os respetivos administradores; aplica-se a respetiva política de privacidade.

O que o software faz por si só:

  • Sem telemetria. O servidor não envia estatísticas de utilização, diagnósticos nem quaisquer outros dados para o projeto Antimatter, para a Mattermost, Inc. (cujos software o Antimatter se baseia) nem para outras partes terceiras.
  • Conexões externas apenas para funcionalidades que um administrador ativa, para os serviços que configuram: por exemplo, um serviço de notificações push, um provedor de GIF, um servidor de correio eletrónico, um provedor de identidade para início de sessão único, ou modelos de IA, voz ou tradução.
  • Duas exceções, ativadas por omissão, que os administradores podem desativar. Pré-visualizações de ligações: quando alguém publica uma ligação, o servidor obtém essa página para mostrar o seu título e imagem. E chamadas: utilizam o servidor STUN público da Cloudflare (stun.cloudflare.com) para encontrar endereços de rede pública. O servidor consulta-o quando a app de Chamadas inicia, e o dispositivo de cada pessoa consulta-o quando entra numa chamada. A Cloudflare vê apenas o endereço IP e a porta do servidor e de cada pessoa que entra, não a própria chamada. Os administradores podem utilizar o seu próprio servidor STUN, ou nenhum; consulte Chamadas e voz.
  • As funcionalidades de IA utilizam os modelos escolhidos pelo administrador. Quando são hospedados por uma parte terceira, o que lhes é enviado (uma mensagem para reescrever, uma conversa para resumir, o áudio de uma chamada transcrita) vai para esse provedor. Os administradores podem utilizar modelos auto-hospedados para que nada saia da sua rede.

Este website

  • antimatter.chat é um website estático hospedado no GitHub Pages.
  • Não define cookies e não utiliza análises, rastreadores ou publicidade. As fontes e imagens são fornecidas pelo próprio site, pelo que o seu navegador não faz pedidos a outros websites durante a leitura.
  • Como qualquer alojador web, o GitHub recebe o seu endereço IP e as páginas que solicita, para as fornecer. Consulte a Declaração de Privacidade do GitHub.
  • Se abrir uma issue ou contribuir no GitHub, o que publicar lá é público e é tratado pelo GitHub nos termos próprios.

Contacto

Para questões sobre esta política, abra uma issue no repositório da comunidade Antimatter.

É possível que esta política seja atualizada; a data no topo indica quando foi alterada pela última vez.
