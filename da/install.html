Kom i gang

Kør Antimatter på din egen server

Én fil, tre kommandoer, cirka ti minutter: Antimatter med database, fillager og GIF-tjeneste på en hvilken som helst Linux-server med Docker.

Oppe at køre på ti minutter

Du skal bruge en Linux-server med Docker og Compose-pluginet, mindst 2 CPU-kerner og 4 GB hukommelse.

1. Hent compose-filen

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Opret indstillingerne med tilfældige adgangskoder

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Sæt SITE_URL til den adresse, brugerne skal bruge, f.eks. http://192.168.1.20:8065 på et lokalt netværk.

3. Start den

$ docker compose up -d

Første opstart tager et minut eller to, mens databasen oprettes. Åbn derefter SITE_URL i din browser, og opret din konto: Den første konto bliver systemadministrator, og opsætningen guider dig gennem oprettelsen af dit første fællesskab.

Med dit eget domæne og HTTPS

Lad en DNS-post for dit domæne pege på serveren, åbn port 80 og 443, og tilføj domænet i .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy henter et certifikat fra Let's Encrypt og fornyer det automatisk.

Hvad der kører

  • antimatter: serveren med dens apps (notater, whiteboards, lydkanaler, opkald, afstemninger og de øvrige). Den gemmer intet på disken: Indstillingerne ligger i databasen og filerne i lagertjenesten, så containeren kan udskiftes når som helst.
  • postgres: databasen.
  • files: RustFS, S3-kompatibelt lager til uploadede filer.
  • gifs: Antimatters tjeneste til GIF'er og stickers med en startpakke af stickers.
  • https: Caddy, kun med profilen https.

Databasen, lageret og GIF-tjenesten ligger på et privat netværk, som kun Antimatter har adgang til.

Hvis GIF-vælgeren forbliver tom, så åbn Systemkonsol › Plugins › GIFs, og sæt tjenestens URL til http://gifs:8080/v2 og API-nøglen til værdien af GIFS_API_KEY i din .env.

Opgraderinger og backup

# opgrader til de nyeste images
$ docker compose pull && docker compose up -d
# tag backup af databasen
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

Tag også backup af volumen files, eller repliker lageret med et vilkårligt S3-værktøj. Til en opsætning med nginx og dine egne certifikater kan du se produktionsfilerne i antimatter-docker.

Med et udgivelsesarkiv

  1. Opret en PostgreSQL-database og en databasebruger.
  2. Pak arkivet (antimatter-<os>-<arch>.tar.gz) ud, f.eks. i /opt/antimatter, og lad SqlSettings.DataSource i config/config.json (eller miljøvariablen AM_SQLSETTINGS_DATASOURCE) pege på databasen.
  3. Start serveren med bin/antimatter som en bruger uden særlige rettigheder, og åbn http://localhost:8065. Den første konto, der oprettes, bliver systemadministrator.

bin/amctl styrer en kørende server fra kommandolinjen (bin/amctl --local på selve serveren, med ServiceSettings.EnableLocalMode).

Næste skridt

  • Opkald: Åbn porten til opkald (som standard UDP og TCP 8443), så lyd og video kan nå serveren.
  • E-mail: Konfigurer SMTP til invitationer og notifikationer.
  • AI: Tilføj en model i indstillingerne for Agenter; ethvert OpenAI-kompatibelt API fungerer, også en server, du selv driver.
  • Tale og oversættelse: Lad transkription af opkald, oplæsning og automatisk oversættelse bruge tale-til-tekst-, tekst-til-tale- og oversættelsesmodeller, som du selv driver.
