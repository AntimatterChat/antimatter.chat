AI

Funkcje AI w Antimatter korzystają z wybranych przez Ciebie modeli: dostawcy chmurowego lub serwera w Twojej własnej sieci. Żadne dane nie są nigdzie przesyłane, dopóki nie skonfigurujesz modelu. Ta strona opisuje każdą funkcję, przesyłane przez nią dane oraz sposoby jej wyłączenia.

Funkcje AI

FunkcjaKonfigurowana wRodzaj modeluWłączona domyślnie
Agenci AI: czat z botem, podsumowania wątków i kanałów, pomoc w polu kompozycjiAplikacja AgentsDowolna usługa dużego modelu językowego (LLM)Aplikacja jest włączona, ale nie robi nic, dopóki nie dodasz usługi

Automatyczne tłumaczenie kanałówSerwerLibreTranslate, LLM zgodny z OpenAI lub usługa Agentsnie

„Zgodny z OpenAI” oznacza serwer, który oferuje to samo API HTTP co OpenAI. Większość serwerów modeli, które możesz uruchomić samodzielnie, jest z nim zgodna (na przykład Ollama, vLLM, serwer llama.cpp, a także serwery transkrypcji mowy i syntezy mowy), podobnie jak wielu dostawców chmurowych. Żadna z tych funkcji nie wymaga licencji.

Agenci AI

Aplikacja Agenci (id mattermost-ai) jest domyślnie włączona. Jej konfiguracja wymaga dwóch kroków: dodania usługi (połączenia z dostawcą modelu), a następnie utworzenia agentów (botów korzystających z usługi).

1. Dodaj usługę

Przejdź do Konsola systemu › Wtyczki › Agenci i w sekcji Usługi AI kliknij Dodaj usługę AI. Wybierz Typ usługi:

  • Zgodna z OpenAI: dla serwera modelu, który uruchamiasz samodzielnie, lub dowolnego dostawcy z API w stylu OpenAI. Wpisz Adres URL API (na przykład http://ollama:11434/v1 lub http://vllm.internal:8000/v1) oraz Klucz API tylko wtedy, gdy serwer go wymaga. Jeśli serwer obsługuje wyłącznie API Chat Completions, wyłącz Użyj API Responses.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: dostawcy hostowani. Każdy wymaga Klucza API (Bedrock: regionu AWS i danych uwierzytelniających lub roli IAM; Vertex AI: projektu, regionu i konta usługi; Azure: również adresu URL API).

Następnie ustaw Domyślny model (listę, jeśli dostawca może raportować swoje modele, w przeciwnym razie wpisz nazwę) oraz, jeśli dostawca nie raportuje limitów, Limit tokenów wejściowych i Limit tokenów wyjściowych. Usługa zapasowa może przejąć zadania, gdy ta usługa zawiedzie. Zapisz zmiany.

Serwer wykonuje te żądania samodzielnie, więc musi mieć dostęp do API: do serwera modelu w tym samym projekcie compose, w Twojej sieci lub w internecie. Wyjściowe żądania respektują zmienne HTTP_PROXY i HTTPS_PROXY.

2. Tworzenie agentów

Agenci są tworzeni na stronie Agenci aplikacji internetowej: otwórz ją z menu produktu lub za pomocą opcji Zarządzaj w selektorze agentów w panelu Agentów. Jej adres to https://chat.example.com/plug/mattermost-ai/agents. Każdy agent ma Nazwę wyświetlaną, Nazwę użytkownika agenta (w jaki sposób ludzie go wzmiankują), Usługę oraz opcjonalnie model, Własne instrukcje oraz przełączniki Włącz wizję (obrazy) i Włącz narzędzia. Zakładka Dostęp ogranicza, w których kanałach można go używać i którzy użytkownicy mogą z niego korzystać. W sekcji Funkcje AI w Konsoli systemu opcja Bot domyślny wybiera agenta używanego, gdy żaden nie zostanie wybrany, np. do podsumowań rozmów.

Domyślnie każdy użytkownik może tworzyć własnych agentów, korzystając z skonfigurowanych przez Ciebie usług. Aby ograniczyć tę możliwość do administratorów, usuń uprawnienie Zarządzaj własnymi agentami AI z roli członków w Konsola systemu › Zarządzanie użytkownikiem › Uprawnienia.

Opcjonalne funkcje aplikacji Agentów

  • Wyszukiwanie osadzania (eksperymentalne, wyłączone): wyszukiwanie semantyczne po wiadomościach. Wymaga PostgreSQL z rozszerzeniem pgvector oraz modelu osadzania (OpenAI lub zgodnego z OpenAI). Wysyła każdą wiadomość do modelu osadzania, w tym z kanałów prywatnych i wiadomości bezpośrednich.
  • Wyszukiwanie w sieci (wyłączone): pozwala agentom przeszukiwać internet za pomocą Google, Brave lub serwera SearXNG, który uruchamiasz.
  • Natywne narzędzia: przy dostawcach, którzy je oferują, agenci mogą korzystać z własnego wyszukiwania w sieci (domyślnie włączone dla nowych agentów, jeśli jest to wspierane), pobierania z sieci i wykonywania kodu. Są one wykonywane po stronie dostawcy. Wyłącz je dla poszczególnych agentów.
  • Model Context Protocol (MCP): połącz agentów z serwerami MCP, którym ufasz, aby uzyskać dodatkowe narzędzia.
  • Debuguj: Śledzenie wyjścia (wyłączone, dzienniki serwera lub punkt końcowy OpenTelemetry) oraz Włącz logowanie zużycia tokenów, które zapisuje liczbę tokenów w logs/agents/token_usage.log.

Rozpoznawanie mowy: transkrypcje i napisy rozmów

Rozmowy mogą być transkrybowane, z napisami na żywo, przez serwer konwersji mowy na tekst, który oferuje endpoint zgodny z OpenAI /v1/audio/transcriptions. Konfiguracja znajduje się w sekcji Rozmowy i głos. Jeśli opcja Summarize transcriptions jest włączona, domyślny agent publikuje również podsumowanie każdej transkrypcji.

Konwersja tekstu na mowę: odczyt na głos

Po włączeniu funkcji mówienia tekstu, w menu każdej wiadomości znajduje się opcja Odczytaj na głos: serwer wysyła tekst wiadomości do API mówienia tekstu i odtwarza audio. Ustawienia, w Konsola systemu › Integracje › Mówienie tekstu:

UstawienieKlucz i zmiennaCo wpisać
Odczytywanie wiadomości na głosTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (domyślnie wyłączona)
Podstawowy adres URL APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLAdres URL bazowy, włącznie z /v1, na przykład http://tts.internal:8000/v1. Serwer wywołuje jego endpoint /audio/speech.
ModelTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELModel pod nazwą, jaką nadaje mu API, na przykład tts-1. Pole wymagane.
GłosTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEJeden z głosów modelu lub wartość pusta, aby użyć głosu domyślnego.
Klucz APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYWysyłane jako token bearer. Puste, jeśli API nie wymaga tokenu.

Przed wysłaniem serwer usuwa bloki kodu, linki, kody emoji i formatowanie, a także ogranicza tekst do 4000 znaków. Żąda audio w formacie MP3 i przechowuje ostatnie 64 wyniki w pamięci, dzięki czemu wiadomość odczytana dwukrotnie jest wysyłana tylko raz.

Automatyczne tłumaczenie

Automatyczne tłumaczenie wyświetla wiadomości kanału w języku własnym każdego czytelnika. Skonfiguruj je w Konsola systemu › Konfiguracja strony › Języki, w sekcji Automatyczne tłumaczenie:

UstawienieKluczDomyślnie
WłączAutoTranslationSettings.EnableWyłączone
Dostawca usług tłumaczeniowychAutoTranslationSettings.Providerlibretranslate, openai (wyświetlane jako "OpenAI-compatible API") lub agents (usługa aplikacji Agents)
Dozwolone językiAutoTranslationSettings.TargetLanguagesen: języki, na które można tłumaczyć wiadomości
Limit czasu tłumaczenia (ms)AutoTranslationSettings.TimeoutMs5000
Restrict auto-translation on direct messages and group messagesAutoTranslationSettings.RestrictDMAndGMWyłączone

Każdy dostawca ma własne pola:

  • LibreTranslate: Punkt końcowy API LibreTranslate oraz Klucz API LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Serwer LibreTranslate może działać w Twojej własnej sieci.
  • API zgodne z OpenAI: Podstawowy adres URL API (do /v1 włącznie; serwer używa jego punktu końcowego do uzupełniania czatu), Model oraz Klucz API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Mały model tłumaczeniowy uruchomiony lokalnie działa dobrze.
  • Agenci: Usługa AI, jedna z usług skonfigurowanych w aplikacji Agenci.

Po włączeniu tej funkcji administratorzy kanałów włączają tłumaczenie dla danego kanału w jego ustawieniach (Automatyczne tłumaczenie), a każdy członek może zrezygnować z tłumaczenia z menu kanału (Tłumacz wiadomości). W wiadomościach bezpośrednich i grupowych każdy członek może włączyć tę funkcję; przy włączonej ograniczeniu tłumaczenie nie jest tam dostępne. Przetłumaczone wiadomości zawierają informację „Przetłumaczono z …” z linkiem do oryginału.

Kod, linki, wzmianki i emoji są zastępowane znacznikami przed wysłaniem tekstu, a następnie przywracane.

Aby utrzymać wszystko w swojej sieci, skieruj każdą funkcję do serwerów, które sam uruchamiasz. W przypadku dostawcy chmurowego sprawdź jego warunki dotyczące przechowywania danych i poinformuj użytkowników, które funkcje wysyłają ich wiadomości na zewnątrz.

Wyłączanie AI

Nie ma jednego przełącznika: każda funkcja ma swój własny.

  • Agenci: wyłącz aplikację Agentów w Konsola systemu › Wtyczki › Zarządzanie wtyczkami. Spowoduje to również usunięcie podsumowań rozmów i dostawcy tłumaczeń Agentów.
  • Transkrypcja i napisy: AM_CALLS_ENABLE_TRANSCRIPTIONS=false oraz AM_CALLS_ENABLE_LIVE_CAPTIONS=false (wartości domyślne).
  • Odczytaj na głos: Odczytywanie wiadomości na głos wyłączony (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, wartość domyślna).
  • Tłumaczenie: wyłącz tłumaczenie automatyczne (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, wartość domyślna).

Wyłączenie aplikacji Agentów nie wyłącza pozostałych trzech funkcji: one wywołują swoje API bezpośrednio.
