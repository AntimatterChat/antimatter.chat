Magsimula

Patakbuhin ang Antimatter sa sarili mong server

Isang file, tatlong command, mga sampung minuto: ang Antimatter kasama ang database, file storage at GIF service nito, sa kahit anong Linux server na may Docker.

Gumagana na sa loob ng sampung minuto

Kailangan mo ng Linux server na may Docker at ang Compose plugin nito, 2 CPU core at 4 GB na memory o higit pa.

1. I-download ang compose file

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. Gawin ang mga setting nito, na may mga random na password

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

Itakda ang SITE_URL sa address na gagamitin ng mga tao, gaya ng http://192.168.1.20:8065 sa isang local network.

3. Paandarin ito

$ docker compose up -d

Inaabot ng isa o dalawang minuto ang unang pagpapaandar habang ginagawa ang database. Pagkatapos, buksan ang SITE_URL sa iyong browser at gawin ang account mo: ang unang account ang magiging system administrator, at gagabayan ka ng setup sa paggawa ng una mong komunidad.

Gamit ang sarili mong domain at HTTPS

Ituro sa server ang isang DNS record ng iyong domain, buksan ang mga port 80 at 443, at idagdag ang domain sa .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Kumukuha ang Caddy ng certificate mula sa Let's Encrypt at kusa itong nire-renew.

Ano ang tumatakbo

  • antimatter: ang server, kasama ang mga app nito (mga tala, whiteboard, voice channel, tawag, poll at iba pa). Wala itong iniimbak sa disk: nasa database ang mga setting nito at nasa storage service ang mga file nito, kaya puwedeng palitan ang container anumang oras.
  • postgres: ang database.
  • files: RustFS, storage na compatible sa S3 para sa mga na-upload na file.
  • gifs: ang GIF at sticker service ng Antimatter, na may panimulang sticker pack.
  • https: Caddy, kapag ginamit lang ang profile na https.

Nasa isang pribadong network ang database, ang storage at ang GIF service, na Antimatter lang ang nakakaabot.

Kung walang lumalabas sa GIF picker, buksan ang System Console › Mga Plugin › GIFs at itakda ang service URL sa http://gifs:8080/v2 at ang API key sa GIFS_API_KEY ng iyong .env.

Mga upgrade at backup

# i-upgrade sa pinakabagong mga image
$ docker compose pull && docker compose up -d
# i-back up ang database
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

I-back up din ang volume na files, o i-replicate ang storage gamit ang kahit anong S3 tool. Para sa setup na may nginx at sarili mong mga certificate, tingnan ang mga production file sa antimatter-docker.

Gamit ang release archive

  1. Mag-set up ng PostgreSQL database at user.
  2. I-unpack ang archive (antimatter-<os>-<arch>.tar.gz), halimbawa sa /opt/antimatter, at ituro sa database ang SqlSettings.DataSource sa config/config.json (o ang environment variable na AM_SQLSETTINGS_DATASOURCE).
  3. Paandarin ang server gamit ang bin/antimatter, bilang user na walang espesyal na pribilehiyo, at buksan ang http://localhost:8065. Ang unang account na gagawin ang magiging system administrator.

Pinamamahalaan ng bin/amctl ang tumatakbong server mula sa command line (bin/amctl --local sa mismong server, kapag naka-on ang ServiceSettings.EnableLocalMode).

Mga susunod na hakbang

  • Mga tawag: buksan ang port para sa mga tawag (UDP at TCP 8443 bilang default) para makarating sa server ang voice at video.
  • Email: i-configure ang SMTP para sa mga imbitasyon at notisikasyon.
  • AI: magdagdag ng model sa mga setting ng Agents; gumagana ang kahit anong API na compatible sa OpenAI, kasama ang server na ikaw mismo ang nagpapatakbo.
  • Boses at pagsasalin: ituro ang call transcription, read-aloud at awtomatikong pagsasalin sa mga speech-to-text, text-to-speech at translation model na ikaw mismo ang nagpapatakbo.
