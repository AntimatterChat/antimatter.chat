Mga App

May mga app ang Antimatter na gumagana sa tabi ng chat: mga notes at whiteboard na maaaring i-edit nang sabay-sabay, mga kanban board, ang iyong kalendaryo at mail, mga poll, mga to-do list, at iba pa. Narito kung paano buksan ang bawat isa at para saan ito.

Hanapin at buksan ang mga app

Ang iyong administrator ang pumipili ng mga app na mayroon sa iyong server, kaya maaaring hindi mo makita ang lahat sa pahinang ito. Karamihan sa mga app ay may icon sa app rail, ang makitid na kolum sa kanang gilid ng window, sa ilalim ng iyong larawan. I-point ang icon upang makita ang pangalan ng app, at i-click ito upang buksan ang app sa panel sa tabi ng usapan. I-click ulit upang isara ang panel. I-drag ang gilid ng panel upang gawing mas lapad; ang Ibalik ang default na lapad ay ibabalik ito.

Makikita rin ang mga app sa ibang mga lugar:

  • Ang + menu ng message box (hal. Magdagdag ng file at iba pa), tulad ng Maglikha ng poll.
  • Ang mga tab ng emoji picker: Mga GIF, Mga Sticker at Mga Meme.
  • Ang Mga aksyon sa mensahe sa menu ng Mga Karagdagang Aksyon ng isang mensahe, hal. Idagdag sa to-do o I-run ang playbook.
  • Mga slash command, tulad ng /poll o /todo: mag-type ng / para makita ang listahan.
  • Mga buong pahina: Ang Kanban at Playbooks ay nakalista sa ilalim ng Mga Produkto sa menu ng Tungkol sa Antimatter, sa ibaba ng app rail. May Buksan bilang buong pahina button din sa kanilang panel.
  • Ang mga setting ng ilang app ay nasa ilalim ng Mga Plugin sa iyong mga setting.

Sa phone, nasa drawer sa kanan ang app rail: i-swipe pabalik, o pumili ng Pang-iba pa › Mga miyembro at mga app sa header ng usapan.

Tala

Ang mga Notes ay mga dokumento na maaaring i-edit ng maraming tao nang sabay-sabay, sa tabi ng chat. Makikita mo ang cursor at pangalan ng iba habang nagta-type, at awtomatikong na-save ang lahat habang nagpapaunlad.

Pagsulat ng note

  1. I-click ang Notes sa app rail.
  2. Piliin ang tab: This channel para sa note na maaabot at ma-edit ng bawat miyembro ng channel, o Mine para sa personal na note na ikaw lang ang makakakita.
  3. I-click ang + (New note in this channel o New personal note). Bumubukas ang "Untitled note".
  4. Ilagay ang pamagat nito, tapos magsulat. May bold, italic, strikethrough, headings, lists, at checklists sa Formatting bar; gumagana rin ang links, quotes, at code. Pindutin ang @ upang mag-mention ng miyembro ng channel (ang mga mention sa mga tala ay hindi nagpapadala ng notisikasyon sa sinuman).
  5. Pindutin ang Mga tala upang bumalik sa listahan.

Kapag may tala sa channel na may pamagat, ipapost ng Antimatter ang "Shared a note" sa channel, kasama ang Open note button.

Higit pa sa tala

I-star ang tala upang makahanap nito sa tab ng Mga Paborito. Ang menu ng ⋯ ng tala ay nag-aalok ng Ibahagi sa channel (nagpo-post ng card na may link dito), Ibahagi sa ~channel (gagawing tala ng channel ang personal na tala, nang tuloy-tuloy), Version history (makita at Ibalik ang bersyong ito), Export as Markdown at Burahin. Ang tagapaglikha ng tala at mga admin ng channel lamang ang maaaring burahin ang tala ng channel.

Whiteboard

Ang whiteboard ay isang canvas na pinagsasama-samang ginagamit sa pagguhit: mga hugis, arrow, text, at freehand drawing, na may live na pagpakita ng pointer ng bawat isa.

  1. Pindutin ang Whiteboard sa app rail.
  2. Gaya sa mga tala, piliin ang This channel o Mine, at pindutin ang + (New board in this channel o New personal board).
  3. Magguhit gamit ang mga tool: Select and move (V), Move around (H), Rectangle (R), Ellipse (O), Arrow (A), Draw (P), Text (T), at Eraser (E). Piliin ang mga kulay, line styles, at fonts sa toolbar, at mga hugis sa Library. Ang Undo (Ctrl+Z) ay bumabawi sa huling pagbabago mo.

Ang menu ng Mga aksyon sa board ay may Buong screen, Ipakita ang buong board, download bilang .excalidraw, PNG o SVG, Version history, Mag-import ng .excalidraw file… (papalit nito ang board para sa lahat), pagbabahagi sa channel, at Burahin. Ang mga whiteboard ay mananatili sa iyong Antimatter server.

Kanban

Ino-organize ng mga Kanban board ang trabaho bilang mga card sa mga column, tulad ng "To do", "Doing", at "Done". Maaari ring ipakita ang board bilang table, gallery, o kalendaryo.

Buksan ang mga board ng channel

Pindutin ang Kanban sa app rail. Ang panel ay naglilista ng mga board na nakabind sa channel; pindutin ang isa upang buksan ito. Kung wala pang nakabind, pindutin ang Link boards to …, tapos Link sa tabi ng board, o Create a board. Ang mga miyembro ng channel ay maging editor ng isang nakabind na board.

Trabaho sa board

  • Upang makita ang lahat ng iyong board, buksan ang Kanban bilang buong pahina: Buksan bilang buong pahina sa panel, o Tungkol sa Antimatter › Mga Produkto › Kanban.
  • Para gumawa ng board, pindutin ang + Magdagdag ng board, then simulan mula sa template (meeting agenda, project tasks, roadmap, sprint planner at iba pa) o Gumawa ng blangkong board.
  • Pindutin ang + Bagong sa isang column para magdagdag ng card. Buksan ang card para i-set ang mga properties nito, magdagdag ng text, checkboxes at imahe, mag-attach ng files, at mag-comment. Kapag may mention ka ng tao sa card, naa-notify siya.
  • I-drag ang mga card mula sa isang column papunta sa iba. Gamitin ang Group by, Filter, Ayusin at Maghanap ng card upang makahanap ng paraan, at Magdagdag ng view para sa table, gallery o calendar view.
  • Gamitin ang Ibahagi sa isang board upang pumili kung sino ang makakakita o mag-edit nito.

Kalendaryo

Ipinapakita ng Calendar app ang sarili mong kalendaryo sa tabi ng chat, nagpapadala ng mga paalala, at nagpapayag sa iyo na mag-meet sa Antimatter. Gumagana ito sa mga calendar server na gumagamit ng CalDAV, tulad ng Nextcloud, Fastmail o Radicale.

Ikonekta ang iyong kalendaryo

  1. Pindutin ang Calendar sa app rail.
  2. Sa Ikonekta ang iyong kalendaryo, punan ang CalDAV server address (karaniwan ay ang domain lang ng iyong provider), ang iyong Username at Password. Kung nag-aalok ng app passwords ang iyong provider, gamitan ito.
  3. Piliin kailan na Paalalahanan ako ng mga kaganapan na walang alarm, then pindutin ang Connect.

Naka-encrypt ang iyong password sa Antimatter server. Para palitan ang mga detalyeng ito sa hinaharap, o mag-disconnect, gamitin ang Account settings sa panel.

Gamitin ito

  • Palitan ang Agenda at Week, gumalaw gamit ang Nakaraan, Ngayon at Susunod, at i-click ang chip ng kalendaryo upang ipakita o itago ito.
  • Pindutin ang Bagong kaganapan, punan ang Pamagat, Pagsisimula at Pangwakas, at opsyonal na Ulitin, Paalala, Lokasyon at Paglalarawan, tapos I-save. Pindutin ang isang kaganapan upang baguhin o burahin ito.
  • Upang magpulong sa Antimatter, itakda ang Magpulong sa Antimatter sa isang channel o voice channel, o sa isang tawag, at piliin ang Channel. Kapag dumating ang oras, ipapakita ng kaganapan ang Simulan ang Tawag, Sumali sa tawag o Sumali.
  • Ang mga paalala ay dumadating bilang mga direct message mula sa Calendar bot, na may link para sumali sa call kung mayroon.

Ipinapakita ng app ang iyong mga kalendaryo; hindi ito nagpapadala ng imbitasyon sa ibang tao.

Mail

Ipinapakita ng Mail app ang iyong mailbox sa tabi ng chat, kaya maaari mong basahin, sagutin at i-share ang mga email nang hindi lumalabas sa Antimatter.

Ikonekta ang iyong mailbox

  1. Pindutin ang Mail sa app rail.
  2. Kung itinataguyod ng iyong administrator, pindutin ang Sign in with Google o Sign in with Microsoft. Kung hindi, o para sa ibang provider, punan ang iyong Email address at Your name, kasunod ang mga Incoming mail (IMAP) at Outgoing mail (SMTP) servers, kasama ang kanilang security, port, username, at password. Ang mga help page ng iyong provider ang nagbibigay ng mga detalyeng ito.
  3. Pindutin ang Connect.

Gamitin ito

  • Pumili ng Folder, maghanap gamit ang Search this folder, at pindutin ang isang mensahe upang basahin ito. Ang mga imahe mula sa internet ay nakatago hangga't hindi mo pindutin ang Show images.
  • Sagutin gamit ang Sumagot, Sumagot sa lahat o Paharap, o sumulat gamit ang Bagong mensahe. Plain text ang mga mensahe, at hindi ka maaaring mag-attach ng bagong mga file.
  • Pindutin ang Share to a channel upang ilagay ang sender, subject, at isang excerpt ng isang email sa isang channel, kasama ang isang komento.

Poll

Ang poll ay nagtatanong sa isang usapan, at ang bawat isa ay bumoto sa isang pindot. Ang mga resulta ay naa-update sa live.

  1. Pindutin ang + sa message box at pumili ng Create a poll, o mag-type ng /poll.
  2. Mag-type ng Question at hindi bababa sa dalawang sagot; ang Add answer ay nagdadagdag ng higit pa, hanggang sa sampulo.
  3. I-on ang Allow multiple answers kung maaaring pumili ng marami ang mga tao, at ang Anonymous voting kung walang makakakita ng sinumang bumoto para sa ano.
  4. Piliin ang Tagal, mula 1 oras hanggang 1 linggo, o Walang katapusan.
  5. Pindutin ang Post poll.

Upang bumoto, pindutin ang isang sagot; pindutin ito ulit upang kunin ang iyong boto. Ang poll ay tatapos sa katapusan ng duration nito, o kapag ang tagalikha nito o isang channel admin ang pindutin ang Close poll; ito ay ipapakita ang Final results.

Maaari mo ring isulat ang buong poll sa isang linya: /poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h. Mag-type ng /poll help para sa lahat ng mga opsyon.

To-do

Ang Todo ay naglalaman ng mga to-do list: ang iyong sarili, mga shared list para sa isang channel, at mga gawain na ipinadala mo sa ibang tao.

  • Pindutin ang Todo sa app rail. Sa tab na This channel, magdagdag ng gawain sa shared list ng channel, at gamitin ang Assign to… upang ibigay ito sa isang miyembro. I-star ang list upang sundan ito; ang mga list na sinusundan mo ay nakapangalawak sa tab na Following.
  • Nasa tab na Ako ang iyong sariling mga gawain, ang mga nakataas sa iyo sa mga channel, at ang mga ipinadala sa iyo o mula sa iyo. Piliin ang isang tao gamit ang Ipadala sa… upang magpadala ng gawain sa kanila: maaari nilang Tanggapin, Tanggihan o Markahan na tapos ito.
  • Upang gawing gawain ang isang mensahe, piliin ang Mga aksyon sa mensahe › Idagdag sa to-do sa menu nito.
  • Pindutin ang Mark as done kapag tapos na ang gawain.

Maaari mo ring gamitin ang /todo add …, /todo list at /todo send @someone … para sa iyong personal na mga gawain.

Mga GIF, sticker, at meme

Pindutin ang Emoji (ang mukhang nakangiti) sa kahon ng mensahe: kapag nakasets na ang mga app na ito, may mga tab na Mga GIF, Stickers at Memes sa tabi ng Emoji sa picker.

  • Mga GIF: maghanap, o mag-browse sa MGA PABORITO, Kamakailan Gamit, Trending at sa mga kategorya. Pindutin ang isang GIF upang ipadala agad ito. Pindutin ang bit ng GIF upang idagdag ito sa iyong mga paborito. Maaari mo ring mag-type ng /gif at ilang salita.
  • Stickers: maghanap o mag-browse sa mga sticker pack, at pindutin ang sticker para ipadala ito. Gumagana rin ang /sticker.
  • Memes: pumili ng template, punan ang mga teksto nito sa Gumawa ng meme, tingnan ang preview, at pindutin ang I-post ang meme. Maaari mo ring mag-type ng /meme, o /meme help para makita kung paano isulat ito sa isang linya.

Depende sa mga setting ng iyong server, maaari mong dagdagan ang sarili mong mga GIF, sticker, o meme template gamit ang + sa tabi ng search box.

Playbooks

Ang playbook ay isang muling gamit na checklist para sa trabaho na sumusunod sa parehong mga hakbang tuwing gagawin: isang insidente, isang release, o pagtanggap ng bagong kasamahan. Tuwing gagamitin mo ito, magsisimula ka ng run, na may sarili nitong mga gawain, may-ari, update sa status, at, sa huli, isang retrospective.

  • Pindutin ang Playbooks sa app rail para makita ang mga run ng kasalukuyang channel, magsimula ng isa gamit ang Run a playbook, o gumawa ng mabilis na Bagong checklist.
  • Upang gumawa o i-edit ang mga playbook, buksan ang buong pahina: Tungkol sa Antimatter › Mga Produkto › Playbooks. Magsimula mula sa isang template, tulad ng product release, incident resolution o employee onboarding, o mula sa isang blangkong playbook.
  • Upang simulan ang isang run, pindutin ang Run sa isang playbook, bigyan ng pangalan at buod ang run, piliin kung gagawa ka ng channel para dito o i-link ito sa isang umiiral na channel, at pindutin ang Simulan ang run. Maaari mo ring piliin ang Mga aksyon sa mensahe › Run playbook sa isang mensahe.
  • Noong isang run, tick off ang mga gawain, itakda ang mga ito at bigyan ng due date, at pindutin ang I-post ang update upang ipaalam sa lahat kung nasaan na ang mga bagay. Pindutin ng may-ari ang Tapusin sa dulo.

Mag-type ng /playbook para makita ang mga command, tulad ng /playbook run o /playbook update.

GitHub, GitLab, at Jira

Ang mga app na ito ay nagkonekta ng Antimatter sa mga tool na ginagamit ng mga developer. Dapat muna itong i-set up ng iyong administrator. Pagkatapos nito:

  1. I-connect ang iyong account sa pamamagitan ng pagta-type ng /github connect, /gitlab connect o /jira connect, tapos sundan ang link at mag-sign in sa site na iyon. Para sa GitLab, gawin ito sa web browser, hindi sa desktop app.
  2. Makakatangka ka ng mga Direct Message kapag may nag-mention sa iyo, humingi ng review, o nag-assign sa iyo ng bagay.
  3. Para may channel na susundin ang repository o project, gamitin ang /github subscriptions add owner/repo, /gitlab subscriptions add group/project, o /jira subscribe.
  4. Upang gumawa o mag-attach ng isyu mula sa isang mensahe, piliin ang Create GitHub Issue, Create GitLab Issue, Create Jira Issue o ang katumbas na Attach to … item sa Mga aksyon sa mensahe ng mensahe.

Mag-type ng /github help, /gitlab help o /jira help para sa lahat ng kanilang mga command.

Mga App sa mobile app

Ang mobile app ay makagawa at bumoto sa mga Poll, magpadala ng GIF at sticker, at sagutin ang mga Gawain na ipinadala sa iyo. Ang mga Tala at Whiteboard ay buksan sa browser window sa loob ng app. Ang Kanban, Kalendaryo, Mail, at meme ay wala pa sa mobile app: gamitin ang web o desktop app para sa kanila.
