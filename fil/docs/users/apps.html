Mga App

May mga app ang Antimatter na gumagana sa tabi ng chat: mga notes at whiteboard na maaaring i-edit nang sabay-sabay, mga kanban board, ang iyong kalendaryo at mail, mga poll, mga to-do list, at iba pa. Narito kung paano buksan ang bawat isa at para saan ito.

Hanapin at buksan ang mga app

Ang iyong administrator ang pumipili ng mga app na mayroon ang iyong server, kaya maaaring hindi mo makita ang lahat ng mga ito sa pahinang ito. Mayroong icon ang karamihan sa mga app sa app rail, ang makitid na kolum sa kanang gilid ng window, sa ilalim ng iyong larawan. I-point ang isang icon upang makita ang pangalan ng app, at i-click ito upang buksan ang app sa panel sa tabi ng usapan. I-click ulit upang isara ang panel. I-drag ang gilid ng panel upang gawing mas lapad; ang Ibalik ang default na lapad ay ibubalik ito. Ang Buksan sa bagong window, sa header ng panel, ay bubuksan ang app sa sariling window, sa tala, board o listahan na bukas.

Makikita rin ang mga app sa ibang mga lugar:

  • Ang + menu ng message box (Magdagdag ng file at iba pa), halimbawa ang Create a poll.
  • Ang mga tab ng emoji picker: Mga GIF, Stickers at Memes.
  • Ang menu ng mensahe (Mga aksyon sa mensahe, ang ⋯), sa ilalim ng Mga Karagdagang Aksyon, halimbawa ang Add to todo o Run playbook. Ipinapakita ng bawat aksyon ang icon ng app nito.
  • Mga slash command, tulad ng /poll o /todo: mag-type ng / para makita ang listahan.
  • Ang mga setting ng ilang app ay nasa ilalim ng Mga Plugin sa iyong mga setting.

Sa phone, nasa drawer sa kanan ang app rail: i-swipe pakaliwa, o piliin ang Pang-iba pa › Mga miyembro at mga app sa header ng usapan.

Tala

Ang mga Notes ay mga dokumento na maaaring i-edit ng maraming tao nang sabay-sabay, sa tabi ng chat. Makikita mo ang cursor at pangalan ng iba habang nagta-type, at awtomatikong na-save ang lahat habang nagpapaunlad.

Pagsulat ng note

  1. I-click ang Notes sa app rail.
  2. Piliin ang tab: This channel para sa note na maaabot at ma-edit ng bawat miyembro ng channel, o Mine para sa personal na note na ikaw lang ang makakakita.
  3. I-click ang + (New note in this channel o New personal note) sa header ng panel. Mabubuksan ang "Untitled note".
  4. Isulat ang pamagat nito sa header, tapos magsulat. Ang Formatting bar sa ilalim ng header, ipinapakita sa mga makakagawa ng edit sa tala, ay may bold, italic, strikethrough, headings, lists at checklists; gumagana rin ang mga link, quotes at code. Sa tabi nito, ipinapakita ng mga tuldok kung sino pa ang nag-e-edit, at kung na-save na ang iyong mga pagbabago. Pindutin ang @ upang i-mention ang miyembro ng channel (hindi nagpapadala ng notisikasyon ang mga mention sa mga tala).
  5. I-click ang All notes (ang arrow sa kaliwa ng header) upang bumalik sa listahan.

Kapag may tala sa channel na may pamagat, ipapost ng Antimatter ang "Shared a note" sa channel, kasama ang Open note button.

Higit pa sa tala

I-star ang tala upang makahanap nito sa tab ng Mga Paborito. Ang menu ng Note actions ng tala (⋯) ay nag-aalok ng Share in the channel (nagpo-post ng card na may link dito), Share in ~channel (gagawing channel note ang personal note, nang tuloy-tuloy), Version history (makita at Ibalik ang bersyong ito), Export as Markdown at Burahin. Ang tagapaglikha ng tala at mga admin ng channel lamang ang makabura ng channel note.

Whiteboard

Ang whiteboard ay isang canvas na pinagsasama-samang ginagamit sa pagguhit: mga hugis, arrow, text, at freehand drawing, na may live na pagpakita ng pointer ng bawat isa.

  1. Pindutin ang Whiteboard sa app rail.
  2. Gaya sa mga tala, piliin ang This channel o Mine, at pindutin ang + (New board in this channel o New personal board).
  3. Magguhit gamit ang mga tool: Select and move (V), Move around (H), Rectangle (R), Ellipse (O), Arrow (A), Draw (P), Text (T), at Eraser (E). Piliin ang mga kulay, line styles, at fonts sa toolbar, at mga hugis sa Library. Ang Undo (Ctrl+Z) ay bumabawi sa huling pagbabago mo.

Ang menu ng Board actions ay may Buong screen, Show the whole board, download bilang .excalidraw, PNG o SVG, Version history, Import an .excalidraw file… (papalitan nito ang board para sa lahat), pagbabahagi sa channel, at Burahin. Mananatili ang mga whiteboard sa iyong Antimatter server.

Kanban

Ino-organize ng mga Kanban board ang trabaho bilang mga card sa mga column, tulad ng "To do", "Doing", at "Done". Maaari ring ipakita ang board bilang table, gallery, o kalendaryo.

Buksan ang mga board ng channel

Pindutin ang Kanban sa app rail. Bumubukas ang Kanban sa kanyang panel, tabi ng usapan, at nakalista ang mga board na naka-link sa channel; pindutin ang isa para buksan ito. Kung wala pang naka-link, pindutin ang Link boards to …, tapos ang Link sa tabi ng isang board, o Create a board. Ang mga miyembro ng channel ay maging editor ng isang naka-link na board. Lumalawak ang panel ng board habang ipinapakita ito; ang back arrow sa itaas ng panel ay babalik sa nakaraang view.

Trabaho sa board

  • Para makita ang lahat ng board ng community, ayon sa kategorya, pindutin ang All boards sa panel. Doon, mahanap mo ang isang board, gumawa ng board o kategorya, at ilipat, i-duplicate, i-export, itago o burahin ang board mula sa kanyang menu.
  • Para gumawa ng board, pindutin ang New board sa panel, tapos magsimula mula sa template (meeting agenda, project tasks, roadmap, sprint planner at iba pa) o Create an empty board.
  • Pindutin ang + New sa isang column para magdagdag ng card. Bumubukas ang card sa itaas ng panel: i-set ang mga property nito, magdagdag ng text, checkboxes at imahe, i-attach ang mga file, at mag-comment. Ang pag-mention ng isang tao sa card ay nagpapahiwatig sa kanya.
  • I-drag ang mga card sa pagitan ng mga column. Gamitin ang Group by, Filter, Ayusin at Search cards para makahanap ng paraan, at Add view para sa table, gallery o calendar view.
  • Gamitin ang Ibahagi sa isang board para pumili kung sino ang makakita o mag-edit nito.

Kalendaryo

Ipinapakita ng Calendar app ang sarili mong kalendaryo sa tabi ng chat, nagpapadala ng mga paalala, at nagpapayag sa iyo na mag-meet sa Antimatter. Gumagana ito sa mga calendar server na gumagamit ng CalDAV, tulad ng Nextcloud, Fastmail o Radicale.

Ikonekta ang iyong kalendaryo

  1. Pindutin ang Calendar sa app rail.
  2. Sa Ikonekta ang iyong kalendaryo, punan ang CalDAV server address (karaniwan ay ang domain lang ng iyong provider), ang iyong Username at Password. Kung nag-aalok ng app passwords ang iyong provider, gamitan ito.
  3. Piliin kailan na Paalalahanan ako ng mga kaganapan na walang alarm, then pindutin ang Connect.

Naka-encrypt ang iyong password sa Antimatter server. Para palitan ang mga detalyeng ito sa hinaharap, o mag-disconnect, gamitin ang Account settings sa panel.

Gamitin ito

  • Palitan ang Agenda at Week, gumalaw gamit ang Nakaraan, Ngayon at Susunod, at pindutin ang chip ng kalendaryo para ipakita o itago ito.
  • Pindutin ang New event, punan ang Pamagat, Starts at Ends, at opsyonal na Repeat, Reminder, Location at Paglalarawan, tapos I-save. Pindutin ang kaganapan para baguhin o burahin ito.
  • Para magpulong sa Antimatter, i-set ang Meet in Antimatter sa isang channel o voice channel, o sa isang tawag, at pumili ng Channel. Kapag dumating ang oras, ipinapakita ng kaganapan ang Simulan ang Tawag, Sumali sa tawag o Sumali.
  • Ang mga paalala ay dumadating bilang mga direct message mula sa Calendar bot, na may link para sumali sa call kung mayroon.

Ipinapakita ng app ang iyong mga kalendaryo; hindi ito nagpapadala ng imbitasyon sa ibang tao.

Mail

Ipinapakita ng Mail app ang iyong mailbox sa tabi ng chat, kaya maaari mong basahin, sagutin at i-share ang mga email nang hindi lumalabas sa Antimatter.

Ikonekta ang iyong mailbox

  1. Pindutin ang Mail sa app rail.
  2. Kung itinataguyod ng iyong administrator, pindutin ang Sign in with Google o Sign in with Microsoft. Kung hindi, o para sa ibang provider, punan ang iyong Email address at Your name, kasunod ang mga Incoming mail (IMAP) at Outgoing mail (SMTP) servers, kasama ang kanilang security, port, username, at password. Ang mga help page ng iyong provider ang nagbibigay ng mga detalyeng ito.
  3. Pindutin ang Connect.

Gamitin ito

  • Pumili ng Folder, maghanap gamit ang Search this folder, at pindutin ang isang mensahe upang basahin ito. Ang mga imahe mula sa internet ay nakatago hangga't hindi mo pindutin ang Show images.
  • Sagutin gamit ang Sumagot, Reply all o Paharap, o sumulat gamit ang Bagong mensahe. Ang mga mensahe ay plain text, at hindi mo maaaring mag-attach ng bagong files.
  • Pindutin ang Share to a channel upang ilagay ang sender, subject, at isang excerpt ng isang email sa isang channel, kasama ang isang komento.

Poll

Ang poll ay nagtatanong sa isang usapan, at ang bawat isa ay bumoto sa isang pindot. Ang mga resulta ay naa-update sa live.

  1. Pindutin ang + sa message box at pumili ng Create a poll, o mag-type ng /poll.
  2. Mag-type ng Question at hindi bababa sa dalawang sagot; ang Add answer ay nagdadagdag ng higit pa, hanggang sa sampulo.
  3. I-on ang Allow multiple answers kung maaaring pumili ng marami ang mga tao, at ang Anonymous voting kung walang makakakita ng sinumang bumoto para sa ano.
  4. Pumili ng Tagal, mula 1 oras hanggang 1 linggo, o No end.
  5. Pindutin ang Post poll.

Upang bumoto, pindutin ang isang sagot; pindutin ito ulit upang kunin ang iyong boto. Ang poll ay tatapos sa katapusan ng duration nito, o kapag ang tagalikha nito o isang channel admin ang pindutin ang Close poll; ito ay ipapakita ang Final results.

Maaari mo ring isulat ang buong poll sa isang linya: /poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h. Mag-type ng /poll help para sa lahat ng mga opsyon.

To-do

Ang Todo ay naglalaman ng mga to-do list: mga listahan na ibinahagi sa isang channel o usapan, ang iyong sariling listahan, at mga to-do na ipinadala mo sa iba. Pindutin ang Todo sa app rail. Katulad ng sa Notes, may tatlong tab ang panel:

  • Usapang ito (o Usapang ito): ang mga listahan na ibinahagi sa lahat nito. Pindutin ang + sa header ng panel (New list in this channel) para gumawa ng isa.
  • Mga Paborito: ang mga listahan na pinag-star, saan pa man ito.
  • Ako: ang iyong personal na listahan, na nakikita mo lang (Mga to-do ko ay laging nandoon; ang + ay nagdadagdag ng isa pa), tapos ang Itinagdag sa iyo sa mga channel, Ipinadala sa iyo at Ipinadala mo.

Buksan ang isang listahan upang magdagdag ng to-do, na may mga detalye at Panghuli na petsa kung gusto mo, at markahan ito bilang tapos gamit ang Mark as done. Sa listahan ng isang channel, ang Itagdag sa… ay nagbibigay ng to-do sa isang miyembro; sa personal na listahan, ang Ipadala sa… ay nagpapadala nito sa isang tao, na maaaring Tanggapin, Tanggihan o Mark as done ito. Ang menu ng List actions ng listahan ay pumapaliwag nito, nagbabago ng icon nito, nag-a-archive nito (nagiging read-only ito, ilalim ng Naka-archive), o pinuputol nito. Ang lahat na maaaring mag-post sa isang channel ay maaaring baguhin ang mga listahan nito; ang tagapaglikha ng listahan at mga admin ng channel ay maaaring pumutol nito.

Upang gawing to-do ang isang mensahe, piliin ang Mga Karagdagang Aksyon › Add to todo sa menu nito, at piliin ang listahan. Ang Todo bot ay nagpapaalam sa iyo kapag may nag-assign o nagpadala sa iyo ng to-do, at nagpapaalala sa iyo ng mga to-do mo araw-araw.

Gumagana rin ang mga command: /todo lists, /todo new name (dagdagan ng --personal para sa sarili mong listahan), /todo add list: text upang magdagdag sa listahan ayon sa pangalan nito, /todo add text upang magdagdag sa sarili mong to-do, at /todo send @someone text.

Mga GIF, sticker, at meme

Pindutin ang Emoji (ang mukhang ngiti) sa kahon ng mensahe: kapag nakasets na ang mga app na ito, may mga tab na Mga GIF, Stickers at Memes sa tabi ng Emoji sa picker.

  • Mga GIF: maghanap, o mag-browse sa Mga Paborito, Kamakailan Gamit, Trending at mga kategorya. Pindutin ang GIF upang ipadala ito agad. Pindutin ang star nito upang idagdag ito sa iyong mga paborito. Maaari mo ring mag-type ng /gif at ilang salita.
  • Stickers: maghanap o mag-browse sa mga sticker pack, at pindutin ang sticker para ipadala ito. Gumagana rin ang /sticker.
  • Memes: pumili ng template, punan ang mga teksto nito sa Gumawa ng meme, tingnan ang preview, at pindutin ang I-post ang meme. Maaari mo ring mag-type ng /meme, o /meme help para makita kung paano isulat ito sa isang linya.

Depende sa mga setting ng iyong server, maaari mong magdagdag ng sarili mong GIF, stickers o meme template gamit ang + sa tabi ng kahon ng paghahanap. Binubuksan nito ang isang form sa loob ng picker: piliin, i-drop o i-paste ang file, suriin ang preview, bigyan ito ng pamagat (pangalan para sa meme template) at, kung gusto mo, mga tag o keyword, tapos pindutin ang Magdagdag (Save template para sa meme template). Ang iyong idinagdag ay nasa unahan sa picker, at maaari nitong makita ng lahat sa server. Ang pindutan sa tabi ng + (Manage GIFs, Manage stickers o Custom meme templates) ay naglilista ng mga idinagdag ng mga tao, kasama ang sinuman at kailan, at nagbibigay-daan sa iyo na pumutol ng mga karapatan mo. Hindi maaari ng mga bisita magdagdag o pumutol ng anumang bagay.

Playbooks

Ang playbook ay isang muling gamit na checklist para sa trabaho na sumusunod sa parehong mga hakbang tuwing gagawin: isang insidente, isang release, o pagtanggap ng bagong kasamahan. Tuwing gagamitin mo ito, magsisimula ka ng run, na may sarili nitong mga gawain, may-ari, update sa status, at, sa huli, isang retrospective.

  • Pindutin ang Playbooks sa app rail upang makita ang mga run ng kasalukuyang channel, magsimula ng isa gamit ang Run a playbook, o gumawa ng mabilis na New checklist. Lahat ng nasa Playbooks ay buksan sa panel na ito, na may back arrow papunta sa nakaraang view.
  • Upang makahanap ng iba pa, pindutin ang Browse runs, playbooks and tasks sa itaas ng panel: All runs, All playbooks, Your tasks, at ang iyong mga paborito at mga run na nasa gitna ng proseso.
  • Upang gumawa ng playbook, pindutin ang Create playbook o I-import sa view na iyon; upang i-edit, buksan mula sa All playbooks. Magsimula mula sa template, tulad ng product release, incident resolution, o employee onboarding, o mula sa blank playbook. Lumalawak ang playbook editor sa panel habang ipinapakita ito.
  • Upang magsimula ng run, pindutin ang Run sa isang playbook, bigyan ng pangalan at buod ang run, piliin kung gagawa ka ng channel para dito o ikakonekta ito sa isang umiiral na channel, at pindutin ang Start run. Maaari mo ring piliin ang Mga Karagdagang Aksyon › Run playbook sa menu ng mensahe.
  • Noong run, markahan ang mga gawain, i-assign ang mga ito, bigyan ng due date, at pindutin ang Post update upang ipaalam sa lahat kung saan na ang mga bagay. Ang owner ang pindutin ang Tapusin sa huli.

Mag-type ng /playbook para makita ang mga command, tulad ng /playbook run o /playbook update.

GitHub, GitLab, at Jira

Ang mga app na ito ay nagkonekta ng Antimatter sa mga tool na ginagamit ng mga developer. Dapat muna itong i-set up ng iyong administrator. Pagkatapos nito:

  1. I-connect ang iyong account sa pamamagitan ng pagta-type ng /github connect, /gitlab connect o /jira connect, tapos sundan ang link at mag-sign in sa site na iyon. Para sa GitLab, gawin ito sa web browser, hindi sa desktop app.
  2. Makakatangka ka ng mga Direct Message kapag may nag-mention sa iyo, humingi ng review, o nag-assign sa iyo ng bagay.
  3. Para may channel na susundin ang repository o project, gamitin ang /github subscriptions add owner/repo, /gitlab subscriptions add group/project, o /jira subscribe.
  4. Upang gumawa o i-attach ng issue mula sa mensahe, piliin ang Create GitHub Issue, Create GitLab Issue, Create Jira Issue, o ang katumbas na Attach to … item sa ilalim ng Mga Karagdagang Aksyon sa menu ng mensahe.

Mag-type ng /github help, /gitlab help o /jira help para sa lahat ng kanilang mga command.

Mga App sa mobile app

Ang mobile app ay makagawa at bumoto sa mga Poll, magpadala ng GIF at sticker, at sagutin ang mga Gawain na ipinadala sa iyo. Ang mga Tala at Whiteboard ay buksan sa browser window sa loob ng app. Ang Kanban, Kalendaryo, Mail, at meme ay wala pa sa mobile app: gamitin ang web o desktop app para sa kanila.
