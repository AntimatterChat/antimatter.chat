Mga setting at keyboard shortcuts

Gawing Antimatter ang anyo at pag-uugali ayon sa gusto mo: tema, display, wika at oras, at mga keyboard shortcut.

Buksan ang iyong mga setting

Pindutin ang iyong larawan sa itaas na kanang sulok ng window, tapos Profile & settings. Maaari mo ring pindutin ang Ctrl+Shift+A (⌘+Shift+A sa Mac), o mag-type ng /settings. I-save ang iyong mga setting habang binabago, at sumusunod sa iyo sa bawat device na ginagamitan mo ng sign-in.

Naka-group ang mga setting sa mga pane:

Sa ilalim ng Mga Plugin, may mga app na nagdadagdag ng sariling setting, tulad ng Mga Tawag para sa iyong microphone at camera. Kung ikaw ay system administrator, ang mga setting ay may link din sa System Console.

Mga tema at display

Pumili ng tema

Sa Mga Setting › Hitsura, sa ilalim ng Theme, pumili ng Dark, OLED (pure black, para sa madilim na silid at OLED na screen), Magaan, o System, na sumusunod sa light o dark mode ng iyong computer, kahit nagbago ito sa loob ng araw.

Para gumawa ng sarili, pindutin ang Custom. Sa ilalim ng Mga custom na kulay, itakda ang bawat kulay: Community rail, Sidebars, Chat area, Inputs & cards, Borders, Teksto, Secondary text, Accent at Mga Link. Ang Magsimula mula sa Antimatter ay nagre-reset nito.

Magbahagi ng tema

Ang theme ay maaaring ipasa bilang maikling code na nagsisimula sa am1:. Sa ilalim ng Magbahagi ng theme, pindutin ang Kopyahin ang code ng aking theme at ipadala ito sa iba. Para gamitin ang code na natanggap, i-paste ito sa field at pindutin ang I-apply.

Display

  • Display ng Mensahe: Compact, na nakakapaglagay ng mas marami sa screen, nang walang mga larawan at mas malapit na mga linya; Standard; o Spacious, na nagbibigay ng mas maraming espasyo paligid ng mga mensahe at sa mga listahan ng sidebar at miyembro.
  • Status sa mga larawan ng profile: ipakita kung online ang mga tao sa kanilang larawan sa mga mensahe.
  • Ipakita kung kailan ka huling online: payagan ang iba na makita ang "Huling online …".
  • Lapad ng mensahe: Buong lapad, o Naka-center para mas madaling basahin sa malaking screen.
  • Ipakita ang mga tao bilang: Username, Nickname o Buong Pangalan, maliban kung ang iyong administrator ang pumili para sa lahat.
  • 24-oras na orasan: ipakita ang oras bilang 16:00 sa halip na 4:00 PM.
  • Ipangkat ang mga hindi nabasang channel: ipagkumpuni ang mga hindi nabasang channel sa isang Hindi nabasa na seksyon sa itaas ng sidebar.
  • Mga bukas na usapan: gaano karaming direct message ang listahan ng sidebar sa pinakamataas: 5, 10 (ang default), 15, 20 o 40. Ang mga hindi nabasa na hindi nakakapagpasok ay naghihintay sa ibabaw ng community rail.

Ang klasikong interface

Ang interface ng Antimatter ang tinutukoy ng gabay na ito. Kung pinapayagan ng iyong administrator, ang Web interface sa Mga Setting › Hitsura ay nagpapahintulot sa iyo na lumipat sa Classic (legacy), ang mas lumang interface na pinanatili para sa compatibility, at bumalik sa Fusion. Ang pagpipilian ay nakaka-apply sa bawat browser na ginagamit mo para mag-sign in. Iba-iba ang mga menu at button sa classic interface.

Accessibility

Ang Mga Setting › Accessibility ay nagpapadali sa pagbasa at paggamit ng Antimatter. Sinusunod din ng Antimatter ang reduced motion setting ng iyong system.

  • Simplified interface: mas kaunti ang makikita sa screen sa isang pagkakataon. Mas malaki ang mga button at linya, walang mga animation, sarado ang listahan ng miyembro hangga’t hindi mo ito bubuksan, ang mga bilang ay ipinapakita lamang para sa mga mention, at mas kaunti ang mga button na makikita sa itaas ng mga mensahe. Nasa abot lahat.
  • Kulayan ang mga pangalan: bigyan ng sariling kulay ang pangalan ng bawat tao sa mga mensahe, upang maibigay-iba ang mga tao sa isang tingin. Off ito sa default, dahil ang mga role ay kulayan na ang mga pangalan ng mga taong mayroon rito.

Mga setting ng mensahe

Ang Mga Setting › Mga Mensahe ay nagtatakda kung paano nakikita ang mga usapan at paano ka sumusulat. Depende sa iyong server, ito ay nag-aalok ng:

  • Panatilihin ang mga sagot sa mga thread: ang mga sagot sa thread ay mananatili sa kanilang thread sa halip na ipakita rin sa channel.
  • Gawing emoji ang mga emoticon: ipakita ang :) at <3 bilang emoji.
  • Mga oras sa iyong time zone: ipahayag ang mga oras na nakasulat sa mga mensahe, na may pagpapakita ng oras sa iyong time zone kapag inilalagay ang cursor dito.
  • Ipadala gamit ang Ctrl+Enter: ang Enter ay nagpapasimula ng bagong linya, at ang Ctrl+Enter ay nagpapadala.
  • Rich text editor (beta): makikita ang pagkakabuo ng teksto habang isinulat.
  • Sa ilalim ng Pagbabasa: Buksan ang mga hindi nabasang usapan sa (Kung saan ako huminto o Ang pinakabagong mensahe), Ipakitang naka-expand ang mga larawan, Mga preview ng link (isang preview card para sa mga website na nakalink sa mga mensahe), Mga one-click na reaksyon, Mga mensahe ng pagsali at pag-alis, at Pag-format ng mensahe (patayin ito upang makita ang mga mensahe bilang plain text).

Wika at time zone

Sa Mga Setting › Wika at oras, piliin ang Wika ng interface mula sa listahan. Agad na magbabago ang Antimatter.

Ang iyong Time zone ay ipinapakita sa ilalim nito, na karaniwang awtomatikong inuugnay mula sa iyong computer. Para baguhin ito, pindutin ang Baguhin…: buksan nito ang time zone setting sa classic settings window, kung saan maaari mong isara ang awtomatikong time zone at pumili ng isa.

Mahalaga rin ang iyong time zone sa iba: ito ang paraan ng Antimatter na ipakita ang iyong lokal na oras, at babala sila kapag gabi na sa iyo.

Mga advanced na setting

  • Streamer mode: itago ang iyong email address at mga preview ng usapan, at isilensya ang mga desktop notification, halimbawa habang nagbabahagi ng iyong screen.
  • Developer mode: dagdagan ang Kopyahin ang ID sa mga menu ng mga mensahe, channel, community, at tao, para sa API at bots.
  • I-sync ang mga draft: panatilihin sa server ang mga mensahe na hindi mo pa ipinadala, upang tapusin ito sa ibang device. On ito sa default.
  • Sa ilalim ng Performance Debugging, kapag inaalok ng iyong server: I-off ang mga plugin sa browser na ito at Huwag ipakitang nagta-type ako, na kapaki-pakinabang kapag may problema.

Palitan ang shortcut

  1. Buksan ang Mga Setting › Keyboard.
  2. Pindutin ang Baguhin sa tabi ng isang aksyon, tapos pindutin ang mga bagong keys. Pindutin ang Esc para kanselahin, o Backspace para isara ang shortcut.
  3. Kung may ibang aksyon na gumagamit ng parehong key, bababala ka ng pahina: "May ibang aksyon na gumagamit rin ng mga key na ito."
  4. Pindutin ang I-reset para bumalik sa orihinal na mga key.

Maaari mong baguhin ang mga shortcut para sa paghahanap, listahan ng mga shortcut, mga setting, hindi nabasang filter, at mga tawag. Ang iba ay mananatili. Ang Lahat ng keyboard shortcut… sa ibaba ng pahina ay buksan ang buong listahan.

Sa desktop app

Ang desktop app ay may sariling mga shortcut, ipinapakita sa mga menu nito: halimbawa, Ctrl+F para hanapin ang text sa pahina, Ctrl+= at Ctrl+- para mag-zoom, Ctrl+0 para sa aktwal na laki, Ctrl+R para i-reload, Alt+Left at Right (⌘+[ at ] sa Mac) para pumunta pabalik at pabalik, at Ctrl+Shift+1 hanggang 9 (⌘+Ctrl+1 hanggang 9 sa Mac) para lumipat sa mga server.
