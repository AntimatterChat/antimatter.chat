Mga setting ng komunidad

Ang mga setting na kabilang sa isang komunidad: ang pangalan at icon nito, sino ang makakapag-join, kung paano gumagana ang membership ng channel, saan lalabas ang mga bagong miyembro, at ang mga link na awtomatikong ginagawa nito.

Buksan ang mga setting ng komunidad

Buksan ang menu ng community: i-click ang pangalan ng community sa itaas ng listahan ng mga channel, o i-right-click ang icon nito sa community rail. Pagkatapos, piliin ang Mga setting ng team. Nakikita lamang ang item na ito ng mga admin ng community (at ng mga system admin).

May mga tab na ito ang dialog ng mga setting:

TabLaman nito
Pangkalahatang-ideyaPangalan, deskripsyon at icon.
AccessPampubliko o pribado, mga pinahihanggang email domain, at ang invitation code.
Kasapihan sa Team at Kasapihan sa ChannelMga patakaran sa membership batay sa mga attribute ng mga tao. Lumalabas lamang ang mga tab na ito kapag na-on na ng isang system admin ang attribute-based access control.
Mga ChannelLahat sa bawat channel, at ang default channel.
Mga autolinkMga pattern ng teksto na nagiging link sa mga mensahe.
May mga tab na galing sa classic interface at nananatiling nagsasabi ng "team": "Team Name", "Public Team", "Team Icon". Sa Antimatter, pareho ang team at komunidad.

Nasa menu ng community ang iba pang mga opsyon para sa buong community, ilalim ng Setup ng team: mga role (tingnan ang Roles and permissions), onboarding at mga attribute ng miyembro (tingnan ang Members and onboarding), at ang layout ng community (sa ibaba).

Pangalan, deskripsyon at icon

Sa tab na Pangkalahatang-ideya:

  • Ang Pangalan ng Team ay ang pangalan na ipapakita sa community rail at sa itaas ng listahan ng mga channel. Maaari itong magkaroon ng 2 hanggang 64 na karakter.
  • Ang Paglalarawan ay tumutulong sa mga tao na piliin ang tamang community kapag tinataya nila ang mga maaaring sumali. Maaari itong magkaroon ng hanggang 50 na karakter.
  • Ang Team Icon ay ang larawan sa community rail: isang file na BMP, JPG, o PNG. Kung wala, ipapakita ng rail ang mga initial ng community. Ang Alisin ang larawan ay agad naglilinis nito.

I-save ang iyong mga pagbabago gamit ang bar sa ibaba ng dialog. Ang address ng komunidad (ang bahagi ng URL pagkatapos ng pangalan ng server) ay napipili kapag nilikha ang komunidad at hindi na maaaring baguhin pagkatapos.

Sino ang makakapag-join

Sa tab na Access:

  • Pagkakakilanlan: ang Pampublikong Team ay lumalabas sa listahan ng mga community na maaaring taya at sumali ng sinumang may account sa server. Ang Pribadong Team ay maaari lamang sumali gamit ang imbitasyon. Kapag nagbago mula pampubliko tungo sa pribado, lumilikha ng bagong link ng imbitasyon at humihinto ang lumang isa.
  • Allow only users with a specific email domain to join this team: kapag nakacheck ito, maaari lamang pumasali ang mga taong ang kanilang email address ay nagtatapos sa isa sa mga domain na iyong nakalista, halimbawa example.org. Hiwalayin ang maraming domain gamit ang puwang o koma. Angkop ito sa workspace ng kumpanya; iwan itong off para sa pampublikong komunidad.
  • Invite Code: ang code sa link ng imbitasyon ng community. Ang I-regenerate ay lumilikha ng bagong link at humihinto ang nakaraang isa. Gawin ito kung ibinahagi ang link ng imbitasyon sa lugar na hindi dapat.

Kung ang mga miyembro ng komunidad ay galing sa mga linked group (isang directory tulad ng LDAP, na inu-setup ng isang system admin), sinasabi nito ng Access tab, at ang mga pagpipilian na ito ay pinapalit ng group sync.

Ang pagpapasali ay nakadepende rin sa paraan ng pag-configure ng server: kung maaari man ng mga tao na gumawa ng account, at mula sa aling mga domain ng email. Ang mga ito ay mga setting ng server; tanungin ang iyong system admin (tingnan ang What to ask your system admin).

Wala sa mga community ang limitasyon sa bilang ng miyembro sa pamamagitan ng default. Maaari ng isang system admin na itakda ang limitasyon para sa bawat community sa server (Pinakamataas na Miyembro Bawat Community, sa System Console › Konfigurasyon ng Site › Mga User at Team); kapag naabot ng isang community ang limitasyon na ito, hindi na maaari ang iba na sumali hangga't may umalis.

Lahat sa bawat channel

Sa tab na Mga Channel, ang Nasa lahat ng channel ang mga miyembro ang nagdedesisyon kung paano gumagana ang kasapihan sa channel sa iyong community.

  • Naka-on: nasa lahat ng pampublikong channel ang bawat miyembro, at sa mga pribadong channel na binubuksan ng kanilang mga role. Walang sumasali o umaalis sa mga channel: ang mga tao ay nag-i-mute ng mga channel na hindi nilang gustong sundan. Sa menu ng channel, ipinapakita ang I-mute ang Channel kung saan dati ay Umalis sa Channel, at hindi maaari ng mga moderator na alisin ang sinuman sa isang partikular na channel. Para ipigil ang pagpasok ng isang tao, alisin siya mula sa community, i-time out siya, o baguhin ang mga permission ng channel.
  • Patay: ang mga tao ay pumapasok sa mga channel na gusto nila, maaari silang umalis, at ang mga admin ng channel ay maaaring magdagdag at tanggalin ng mga miyembro.

Hindi laging awtomatikong idinadagdag ang mga bisita at bot: nasa mga channel lamang sila na idinagdag sila. Ang mga pribadong channel na hindi binubuksan ng role (invite-only channels) ay hindi rin naaapektuhan.

Naka-save agad ang switch kapag binago mo ito. Kapag naka-on, idadagdag ang lahat sa mga channel na makikita nila; sa malaking community, may kaunting oras na kailangan para magawa ito. Kapag naka-off, mananatili sa kanilang kasalukuyang posisyon ang lahat, at malaya silang umalis.

Naka-on ito sa mga bagong community, maliban kung binago ng system admin ang default na iyon (Ang mga bagong community ay ilalagay ang lahat sa bawat channel sa System Console). Ang mga community na nabuo bago pa dumating ang setting na ito ay naka-off hangga't naka-on nito.

Sa isang workspace ng kumpanya na maraming team at proyekto, mas maganda kadalasan ang naka-off: nakikita lang ng mga tao ang mga channel ng kanilang trabaho. Sa isang maliit na pampublikong community, naka-on ito upang manatili ang lahat sa usapan.

Ang default na channel

Ang default na channel ang lugar kung saan lumalabas ang mga bagong miyembro, at kung saan pumapasok ang mga mensahe ng pag-join at pag-alis ng community. Nasa loob nito ang lahat at hindi sila maaaring umalis. Kapag nabuo ang isang community, ang default na channel nito ay Town Square.

Para pumili ng ibang channel, gamitin ang Default channel sa tab na Mga Channel, o buksan ang menu ng isang pampublikong channel at piliin ang Gawing default channel. Dapat pampublikong channel ang default channel na hindi archived. Idadagdag ang lahat sa bagong default channel.

Ang Town Square, Off-Topic, at ang default channel ay maaaring i-archive, ngunit lamang ng mga admin ng community. Kung archived ang default channel, wala nang default channel ang community: ipapakita ng setting ang Isang archived channel, at lalabas ang mga tao sa unang channel na nasa loob sila hangga't pipiliin mo ang ibang channel. Kapag nawala ang Town Square, ang listahan ay mag-aalok ng Wala: ang unang channel ng bawat tao.

Autolinks

Ginagawa ng Autolinks na maging link ang teksto sa mga mensahe habang ipinopost. Isang karaniwang gamit ay ang mga issue key: ang LUM-12 ay maging link sa issue na iyon sa tracker ninyo. Ito ay nakaka-apply sa mga mensahe na ipinopost sa community ninyo, sa bawat app, notisikasyon, at search, dahil binubuhay muli ng server ang mensahe bago ito i-save. Ang code, links, at mga larawan ay hindi binabago.

Sa tab na Mga autolink:

  1. Piliin ang Magdagdag ng autolink. Magsimula mula sa isang handa nang pattern (issue keys, pull requests, merge requests, CVE identifiers) o mula sa Blangko.
  2. Bigyan ito ng pangalan, halimbawa "Jira issues".
  3. Sa Pattern, isulat ang isang regular expression, halimbawa (PROJ-\d+).
  4. Sa Magiging, isulat kung ano ang magiging resulta ng match. Ang $0 ay ang buong text na tumugma, at ang $1, $2 at iba pa ay mga group ng pattern. Halimbawa: [$1](https://issues.example.com/browse/$1).
  5. Piliin kung saan ito gagamitin: Lahat ng channel, o ilang channel lamang.
  6. Opsyonal, markahan ang Buong salita lamang, at ang Pati mga mensahe ng bot kung ang mga mensahe na ipinost ng mga bot ay dapat din ma-link.
  7. Mag-type ng halimbawa sa Subukan sa isang mensahe para makita ang resulta, tapos piliin ang I-save.

May Naka-on box ang bawat autolink para itigil nito nang hindi ito tinatanggal. Ang I-link din ang mga na-edit na mensahe ay nag-a-apply ng mga autolink sa mga mensahe kapag na-edit na; kung hindi, ang mga bagong mensahe lamang ang ma-link. Maaaring magkaroon ng hanggang 100 autolinks ang isang community.

Layout, presets, at templates ng community

Ang layout ay ang istruktura ng isang community: ang mga kategorya nito para sa lahat at ang mga channel sa loob nito, ang mga channel nito, ang mga role at ang mga karapatan nila, at ang onboarding nito. Sa menu ng community, piliin ang Setup ng team, tapos ang Layout ng team….

Tatlong presets ang iniaalok:

PresetAng itinatag nito
Hybrid (inirerekomenda)Isang naka-lock na "Information" na kategorya na may Town Square, isang bukas na "Community" na kategorya kung saan ilalagay ng mga miyembro ang kanilang sariling channel, at isang "Moderators" na role.
KomunidadMga kategorya na inuusad lamang ng mga admin ("Information" at "Channels"), at isang role na "Moderators".
WorkplaceGaya sa Mattermost: ang bawat isa ay nag-uugnay ng kanilang sariling kategorya. Tinatanggal nito ang mga kategorya para sa lahat; ang mga role ay nananatili.

Ang mga miyembro ng role na "Moderators" mula sa mga preset ay maaaring mag-edit at magtanggal ng mga mensahe ng ibang tao, at pamahalaan ang mga channel at kanilang mga miyembro. Hindi nila maaaring tanggalin o i-time out ang mga tao hangga't hindi mo idinagdag ang Mag-alis ng mga tao sa role na ito (tingnan ang Mga role at pahintulot).

Noong unang pagbukas ng isang community admin ng bagong community na walang kategorya para sa lahat at walang mga role, iniaaliwala ng Antimatter ang mga preset nang isang beses lamang, ilalim ng Set up na sinundan ng pangalan ng community. Piliin ang Hindi ngayon para kalimutan.

Kopyahin ang layout sa ibang community

  1. Sa community na gusto mong kopyahin, buksan ang Layout ng team… at piliin ang I-export bilang template. I-download ng iyong browser ang isang JSON file.
  2. Sa ibang community, buksan ang Layout ng team…, piliin ang Mag-apply ng template… at piliin ang file.

Ang pag-apply ng isang preset o template ay magdadagdag ng mga channel at role na kulang, mag-u-update ng mga role na may parehong pangalan, ilalagay ang mga channel sa mga kategorya, at palalitan ang onboarding. Walang tinatanggal maliban sa mga kategorya para sa lahat na hindi kasama sa template. Ang export ay kasama lamang ang mga channel na miyembro ka, at walang mensahe.

Mga setting na hindi ng community

  • Mga Direct Message at mga hiling sa mensahe: ang bawat miyembro ang nagpili kung ang mga Direct Message mula sa mga hindi kilala ay darating nang normal o bilang hiling. Ito ay maaaring baguhin ng bawat miyembro para sa bawat community sa kanilang mga setting, ilalim ng Privacy & safety. Hindi maaaring itakda ito ng mga admin ng community (tingnan ang Pag-iignore at pag-block).
  • Ang panghihiwalay ng mga miyembro ayon sa role sa listahan ng miyembro, ang custom emoji, ang mga app, at ang limit ng miyembro ay itinatag para sa buong server ng isang system admin.

Pag-uwala at pagtanggal ng isang community

Ang sinumang miyembro ay maaaring umalis sa isang community gamit ang Umalis sa team sa ibaba ng menu ng community. Hindi maaari ng mga community admin na i-archive o tanggalin ang isang community mula sa interface ng Antimatter: ginagawa ito ng isang system admin sa System Console › Pamamahala ng Mga User › Mga team, sa pamamagitan ng pagbubukas ng community at pagpili ng I-archive ang Team.
