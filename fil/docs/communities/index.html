Pagpapatakbo ng komunidad

Ang gabay na ito ay para sa mga taong nagpapatakbo ng komunidad sa Antimatter: ang mga admin at moderator nito. Ipinapaalam nito kung paano itinatag ang komunidad, pinapaayos ang mga channel, ibinibigay ang mga papel sa mga tao, binabati ang mga bagong dumating, at pinapanatili ang magandang atmospera.

Ano ang isang komunidad

Ang komunidad ay isang espasyo sa isang Antimatter server na may sariling mga channel, miyembro, papel, at patakaran. Bawat komunidad ay may icon sa community rail, ang kolum sa pinakakaliwa ng window. Maaaring maglaman ng maraming komunidad ang isang server, at maaaring maging miyembro ng ilang komunidad ang isang tao. Ang mga Direct Message ay hindi bahagi ng anumang komunidad: sumusunod sila sa iyo sa buong server.

Sa System Console at sa ilang lumang dialogs, tinatawag pa rin ang komunidad bilang "team." Ibig sabihin ng dalawang salitang ito ay pare-pareho. Sa Antimatter, ang "teams" ay ibang bagay: mga grupo ng tao sa loob ng isang komunidad, na may tag at lead (tingnan ang Mga Team sa loob ng komunidad).

Dalawang uri ng komunidad

Ginagamit ang Antimatter sa dalawang malinaw na magkaibang paraan. Tinatalakay ng gabay na ito ang pareho, at binibigay kung saan magkakaiba ang mga payo. May uri ang bawat community, Komunidad o Workplace, na pinipili ng mga admin nito sa mga setting nito: ito ang nagdedesisyon, halimbawa, kung sino ang maaaring i-archive ang mga channel (tingnan ang Uri ng community).

Sino ang gumagawa ng ano

May ilang built-in na papel ang Antimatter, at maaaring magdagdag ng sariling papel ang bawat komunidad sa itaas ng mga ito.

  • System Admin: nagpapatakbo ng buong server. Maaaring gawin ng mga System Admin ang lahat sa bawat komunidad, at sila ang tanging mga taong maaaring gamitin ang System Console, ang mga pahina ng administrasyon ng server. Kung hindi ka isa sa kanila, kailangan mo ng isa para sa ilang gawain; sinasabi ng gabay na ito kailan.
  • Team Admin: namamahala ng isang team. Ang mga Team Admin ang nagbabago ng mga setting ng team, nagpapalit ng ibang tao bilang Team Admin, gumagawa ng mga role, at nagpapaalaga ng sinuman maliban sa ibang admin. Ang profile card nila ay may Team Admin chip. Ang taong gumawa ng team ay ang unang admin nito.
  • Miyembro: ang lahat ng iba sa community. Sa pamamagitan ng default, maaari ng mga miyembro na gumawa ng mga channel, mag-imbita ng mga tao, at palitan ang pangalan at pamahalaan ang mga miyembro ng mga channel na kanilang kasama. Sa isang workplace, maaari nila ring i-archive ang mga channel na nilikha nila.
  • Bisita: galing sa labas, limitado sa mga channel na kanilang inimbitahan. May mga Bisita lamang kung binuksan ng system admin ang guest accounts.
  • Channel Admin: miyembro na may karagdagang karapatan sa isang channel. Ang profile card nila ay may Channel Admin chip.

Wala ang built-in na "moderator" role. Ang mga moderator ay custom role na iyong gagawin, piliin mo kung ano ang maaari nilang gawin: burahin ang mga mensahe, i-time out ang mga tao, tanggalin sila, pamahalaan ang mga channel. Ang mga preset ng layout ng team ay gumagawa ng "Moderators" role para sa iyo. Tingnan ang Roles and permissions.

Gumawa ng team

  1. Sa rail ng team, piliin ang + button (Magdagdag ng team), tapos Gumawa ng team.
  2. Ilagay ang Pangalan. Maaari mong baguhin ito mamaya.
  3. Tingnan ang Address: ito ay puno mula sa pangalan, at naging bahagi ng mga link ng team. Hindi na ito maaaring baguhin mamaya.
  4. Iwan ang Puwedeng sumali ang sinuman sa server on para sa bukas na team, o patayin ito para sumali ang mga tao sa pamamagitan ng imbitasyon lamang.
  5. Piliin ang Gumawa ng team.

Dadalaw ka sa General, ang unang channel ng community, at ikaw ang admin nito. Iniaabot ng Antimatter na i-setup ang community mula sa isang preset; tingnan ang Layout ng team.

Kung hindi mo nakikita ang Gumawa ng team, hindi pa ibinigay ng system admin ang karapatan na gumawa ng mga team (Gumawa ng mga Team sa permissions ng System Console).

Para sumali sa team na mayroon na, piliin ang + tapos Sumali sa ibang team: ito ay naglilista ng mga team na bukas sa iyo.

Menu ng komunidad

Karamihan sa mga tinutukoy ng gabay na ito ay nagsisimula mula sa menu ng team. Buksan ito sa pamamagitan ng pag-click sa pangalan ng team sa itaas ng listahan ng mga channel, o sa pamamagitan ng pag-right-click sa icon ng team sa rail. Ang makikita mo rito ay nakadepende sa iyong mga karapatan:

  • Mag-imbita ng mga Tao, Mga setting ng team at Pamahalaan ang mga miyembro (ang mga miyembro ay nakikita ang Tingnan ang mga miyembro).
  • Setup ng team: Mga role…, Onboarding…, Layout ng team…, Mga attribute ng miyembro… at Model connections…. Bawat isa ay buksan ang tumutugtog na tab ng mga setting ng community.
  • Mga grupo ng user…, Gumawa ng channel at Gumawa ng kategorya.
  • Mga personal na pagpipilian: mark as read, i-mute ang community, ipakita lamang ang mga hindi nabasang channel, itago ang mga naka-mute na channel, mga setting ng notisikasyon at Umalis sa team.

Isang checklist para sa bagong community

  1. Bigyan ito ng paglalarawan at icon, at tukuyin kung sino ang makakapag-join: Mga setting ng community.
  2. Tukuyin kung nasa lahat ng channel ang lahat, at itagda ang mga kategorya at channel: Mga Channel.
  3. Gumawa ng mga role na kailangan, kahit mga moderator: Mga role at pahintulot.
  4. Sumulat ng onboarding at mag-imbita ng mga tao: Mga miyembro at onboarding.
  5. Magkasundo kung paano niyo gagawin ang moderation: Moderation.
  6. Magdagdag ng custom emoji, autolinks at integrations: Mga app at integrations.

Para sa pang-araw-araw na paggamit ng Antimatter (mga mensahe, mga thread, mga tawag, mga notisikasyon), tingnan ang Paggamit ng Antimatter. Para sa pag-install at pag-configure ng server, tingnan ang Pagpapatakbo ng server.
