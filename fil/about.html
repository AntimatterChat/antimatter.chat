Tungkol sa Antimatter

Isang team chat na talagang sa iyo: free software, self-hosted, at walang paywall.

Ano ang Antimatter

Ang Antimatter ay isang self-hosted na team chat server: mga channel, direct message at thread, pagbabahagi at paghahanap ng file, mga voice channel at tawag, mga collaborative na app gaya ng mga tala, whiteboard, board at playbook, mga AI assistant, at mga integration sa pamamagitan ng mga webhook, slash command, bot at plugin.

Bakit ito umiiral

Nasa team chat ang mga desisyon, kaalaman at kasaysayan ng isang organisasyon. Naniniwala kami na ang mga taong umaasa rito ay dapat may kakayahang patakbuhin ito mismo, basahin ang code nito, at gamitin ang lahat ng bahagi nito, nang walang license key na nagpapasya kung aling mga feature ang puwede nilang i-on.

Kaya tatlong bagay ang ginagawa ng Antimatter:

  • Free software ang lahat. Bahagi ng Antimatter, sa bawat server at nang walang license key, ang single sign-on gamit ang SAML, LDAP group sync, data retention, compliance export at iba pang feature na kailangan ng malalaking organisasyon.
  • Isang bagong interface. Dinadala ng Fusion, ang web interface ng Antimatter, ang mga voice channel, role at badge, onboarding at mga tool sa moderation sa isang layout na chat ang inuuna.
  • Kasama na ang mga app. Kasama na sa server ang mga tala, whiteboard, to-do list, kalendaryo, mail at poll, at gumagana ang mga AI feature sa mga model na pinili mo, pati ang mga self-hosted.

Lisensya

Free software ang Antimatter server, na may lisensyang GNU Affero General Public License v3.0. Ang web app, ang mga template at salin ng server, at ang mga pampublikong Go package nito (ang tinatawag ng lisensya na “Admin Tools and Configuration Files”) ay may lisensyang Apache License 2.0. Tingnan ang LICENSE.txt at NOTICE.txt sa source repository.

Free software rin ang mga plugin ng Antimatter; nakasaad sa bawat repository ang lisensya nito.

Saan ito nagmula

Nagsimula ang Antimatter mula sa open-source na Mattermost server (Copyright 2015-present Mattermost, Inc.) at mula noon ay nagkaroon na ng sarili nitong interface, mga app at feature. Isa itong independiyenteng proyekto, at hindi ito kaanib o ineendorso ng Mattermost, Inc.; ang Mattermost ay trademark ng Mattermost, Inc.

Pag-ambag

Malugod naming tinatanggap ang mga bug report, salin at code. Magbukas ng issue o pull request sa GitHub; ipinapaliwanag ng CONTRIBUTING.md ng server kung paano mag-set up ng development environment.
