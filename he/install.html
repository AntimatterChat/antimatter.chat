הפעילו את Antimatter על השרת שלכם

קובץ אחד, שלוש פקודות, כעשר דקות: Antimatter עם מסד הנתונים, אחסון הקבצים ושירות ה-GIF שלו, על כל שרת Linux עם Docker.

עולה ורץ תוך עשר דקות

תצטרכו שרת Linux עם Docker ותוסף ה-Compose שלו, 2 ליבות מעבד ולפחות 4 GB זיכרון.

1. הורידו את קובץ ה-compose

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. צרו את קובץ ההגדרות, עם סיסמאות אקראיות

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

הגדירו את SITE_URL לכתובת שבה המשתמשים ייכנסו, למשל http://192.168.1.20:8065 ברשת מקומית.

3. הפעילו

$ docker compose up -d

ההפעלה הראשונה נמשכת דקה או שתיים, בזמן שמסד הנתונים נוצר. אחר כך פתחו את SITE_URL בדפדפן וצרו חשבון: החשבון הראשון הופך למנהל המערכת, ותהליך ההגדרה ילווה אתכם ביצירת הקהילה הראשונה.

עם דומיין משלכם ו-HTTPS

הפנו רשומת DNS של הדומיין שלכם לשרת, פתחו את הפורטים 80 ו-443, והוסיפו את הדומיין ל-.env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy משיג תעודה מ-Let's Encrypt ומחדש אותה בעצמו.

מה רץ

  • antimatter: השרת, עם האפליקציות שלו (פתקים, לוחות לבנים, ערוצי קול, שיחות, סקרים ועוד). הוא לא שומר דבר על הדיסק: ההגדרות שלו נמצאות במסד הנתונים והקבצים בשירות האחסון, כך שאפשר להחליף את הקונטיינר בכל רגע.
  • postgres: מסד הנתונים.
  • files: RustFS, אחסון תואם S3 לקבצים שמועלים.
  • gifs: שירות ה-GIF והמדבקות של Antimatter, עם חבילת מדבקות ראשונית.
  • https: Caddy, רק עם הפרופיל https.

מסד הנתונים, האחסון ושירות ה-GIF יושבים ברשת פרטית שרק Antimatter מגיע אליה.

אם בוחר ה-GIF נשאר ריק, פתחו את קונסולת מערכת › פלאגינים › GIFs, הגדירו את כתובת השירות ל-http://gifs:8080/v2 ואת מפתח ה-API ל-GIFS_API_KEY שבקובץ .env שלכם.

שדרוגים וגיבויים

# שדרוג לאימג'ים העדכניים
$ docker compose pull && docker compose up -d
# גיבוי מסד הנתונים
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

גבו גם את ה-volume בשם files, או שכפלו את האחסון עם כל כלי S3. להתקנה עם nginx ותעודות משלכם, ראו את קובצי סביבת הייצור ב-antimatter-docker.

עם ארכיון גרסה

  1. הקימו מסד נתונים ומשתמש ב-PostgreSQL.
  2. חלצו את הארכיון (antimatter-<os>-<arch>.tar.gz), למשל לתוך /opt/antimatter, והפנו את SqlSettings.DataSource בקובץ config/config.json (או את משתנה הסביבה AM_SQLSETTINGS_DATASOURCE) אל מסד הנתונים.
  3. הפעילו את השרת עם bin/antimatter, כמשתמש ללא הרשאות מיוחדות, ופתחו את http://localhost:8065. החשבון הראשון שנוצר הופך למנהל המערכת.

bin/amctl מנהל שרת פועל משורת הפקודה (bin/amctl --local על השרת עצמו, עם ServiceSettings.EnableLocalMode).

השלבים הבאים

  • שיחות: פתחו את פורט השיחות (UDP ו-TCP 8443 כברירת מחדל) כדי שהקול והווידאו יגיעו לשרת.
  • דואר אלקטרוני: הגדירו SMTP להזמנות ולהתראות.
  • AI: הוסיפו מודל בהגדרות הסוכנים; כל API תואם OpenAI עובד, כולל שרת שאתם מריצים בעצמכם.
  • דיבור ותרגום: הפנו את תמלול השיחות, ההקראה בקול והתרגום האוטומטי למודלים של המרת דיבור לטקסט, המרת טקסט לדיבור ותרגום שאתם מריצים בעצמכם.
