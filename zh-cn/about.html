关于 Antimatter

一款真正属于您的团队聊天工具：自由软件，自行托管，没有付费墙。

Antimatter 是什么

Antimatter 是一款自托管的团队聊天服务器，提供频道、私信和话题，文件共享和搜索，语音频道和通话，笔记、白板、看板和操作手册等协作应用，AI 助手，以及通过 Webhook、斜杠命令、机器人和插件实现的集成。

为何而生

团队聊天承载着一个组织的决策、知识和历史。我们相信，依赖它的人应当能够自己运行它、阅读它的代码、使用它的全部功能，而不是由一个许可证密钥来决定哪些功能可以开启。

因此，Antimatter 做了三件事：

  • 所有功能都是自由软件。SAML 单点登录、LDAP 组同步、数据保留、合规导出，以及大型组织需要的其他功能，都是 Antimatter 的一部分，每台服务器都能使用，无需许可证密钥。
  • 全新的界面。Fusion 是 Antimatter 的 Web 界面，在以聊天为中心的布局中带来了语音频道、角色和徽章、入职引导以及内容管理工具。
  • 内置应用。笔记、白板、待办事项、日历、邮件和投票随服务器一同提供；AI 功能可搭配您选择的模型使用，包括自托管模型。

许可证

Antimatter 服务器是自由软件，采用 GNU Affero 通用公共许可证 v3.0 授权。Web 应用、服务器的模板和翻译，以及公共 Go 软件包（即许可证中所称的“Admin Tools and Configuration Files”）采用 Apache License 2.0 授权。详见源代码仓库中的 LICENSE.txt 和 NOTICE.txt。

Antimatter 的插件同样是自由软件，各仓库中注明了各自的许可证。

项目由来

Antimatter 源自开源的 Mattermost 服务器（Copyright 2015-present Mattermost, Inc.），此后发展出了自己的界面、应用和功能。它是一个独立项目，与 Mattermost, Inc. 没有隶属关系，也未获其认可；Mattermost 是 Mattermost, Inc. 的商标。
