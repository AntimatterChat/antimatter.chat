功能

团队所需的一切，汇聚在您自己掌控的平台上

Antimatter 功能一览，截图均来自演示服务器。本页介绍的每项功能都包含在自由软件中，没有任何功能留给付费版。

消息

对话井井有条

频道按分类归组，还有私信、群组消息和话题，界面专为漫长的工作日而设计。

  • 频道与分类：公共频道和私有频道、由管理员为所有人设定的分类、收藏和关注。
  • 话题与命名子话题：在话题中回复；为话题命名，即可将其列在所属频道下；关注您在意的话题。
  • 富文本消息：Markdown、语法高亮代码、表格、LaTeX、链接预览、可预览的文件。
  • 消息优先级：紧急和重要消息、持久通知以及确认。
  • 计划消息和草稿、提醒、转发、带修改历史的编辑，以及保存的消息。
  • 搜索消息和文件，支持筛选条件、精确短语和日期。
社区

社区有自己的角色、徽章和规则

无论是运营公司还是社区，Antimatter 都提供了迎接新成员、维护良好氛围的工具。

  • 展示角色和团队徽章：彩色角色、成员可自选的角色，以及显示在名字旁的徽章。
  • 入职引导：欢迎页面和一组问题，帮新成员获得合适的角色和频道。
  • 权限覆盖：在服务器权限方案之上，按分类和频道单独设置。
  • 内容管理：禁言、版主视图、消息举报和隔离。
应用

内置协作应用

应用在聊天旁打开，可以放在面板里，也可以在独立窗口中使用；分享到频道的任何内容，都会为频道里的每个人实时更新。

笔记

多人实时协同编辑的文档，支持标题、列表、检查清单和代码。可以留给自己，也可以分享到频道。

白板

共享画布，提供形状、箭头、文字和可复用的图形库，还能看到每个人的光标。

看板

面向项目的看板、表格和日历，包含卡片、属性和视图，并与负责该项目的频道关联。

操作手册

适用于事件处理、版本发布和新人入职的检查清单，支持负责人、状态更新和复盘。

待办事项

个人和共享任务，可从任意消息分配。

日历

您的 CalDAV 日历就在聊天旁边，附带提醒和通话链接。

邮件

通过 IMAP 和 SMTP，在应用内收发您的邮件。

投票

单选或多选，可设截止时间，结果实时显示。

AI

AI 在哪里运行，由您决定

需要时出手相助，其余时间安静待命。Antimatter 的智能体支持 OpenAI、Anthropic、Azure、Mistral、Gemini、Bedrock，也支持您自行运行的任何兼容 OpenAI 的服务器，例如 vLLM、llama.cpp 或 Ollama。

边写边改写、修正和翻译

在消息发出前，让输入框帮您修正拼写和语法、精简内容、表达得更清楚、调整语气，或翻译成其他语言。

智能体面板

在任意频道旁与智能体对话：总结频道内容、找出某项决定、起草回复，或通过 MCP 服务器调用工具。

通话转录与总结

通话由您的语音转文字模型转录，以实时字幕显示，结束后连同 AI 总结一起发布到通话的话题中。

回顾与频道摘要

休假归来，通过所选频道的回顾和长话题的摘要，快速跟上进度。

自动翻译

借助 LibreTranslate 或任何兼容 OpenAI 的模型，将频道内容翻译成每位读者的语言。

朗读

用您的文字转语音模型朗读任意消息。

智能回复

智能体可在您选定的频道中作答，遵循团队的权限设置。

通话与语音频道

随时开放的语音房间

语音频道和其他频道一样位于侧栏中：点击即可加入，看看谁在，开口就聊。也可以从任意对话发起通话。

  • 视频、屏幕共享和背景虚化，并提供适合共享代码或幻灯片的画质预设。
  • 举手排队、表情回应和逐人音量调节。
  • 按键通话、主持人控制和独立的通话窗口。
  • 实时字幕和转录，由您自己的语音转文字服务器提供，无需额外基础设施。
集成与 ChatOps

让您的工具在频道里发声

完整的 REST API 和插件系统，并自带多种集成。

  • GitHub、GitLab 和 Jira：订阅、预览和斜杠命令。
  • 传入和传出 Webhook、斜杠命令、机器人和 OAuth 应用。
  • 交互式消息和对话框：按钮、菜单和表单，可将结果回传给您的服务。
  • 插件：为 Antimatter 界面添加应用、面板、命令和消息类型。
管理与安全

管理员期待的一切，应有尽有

完整的系统控制台，每台服务器都能使用所有设置。

  • 身份验证：SAML 2.0、OpenID Connect、Google、Microsoft Entra、LDAP/Active Directory、MFA。
  • 访问控制：权限方案、基于属性的访问控制、访客账号、IP 过滤。
  • 合规：数据保留、合规导出与消息导出、审计日志。
  • 运维：Elasticsearch 或 OpenSearch 搜索、Prometheus 指标、兼容 S3 的文件存储。
  • 品牌定制：站点名称、徽标和登录页文字，自定义表情符号和主题。
贴心细节

用户会留意到的小地方

时间按您的时区显示

消息里的“3pm CET”，会按每位读者的当地时间显示。

“对方可能在睡觉”

当收信人那边正值深夜时会给出提示，并提供一个按钮，改在对方早上发送。

自动链接

每个社区都可以定义工单编号之类的格式，消息发出时自动变成链接。

确认

为重要消息请求确认，并查看谁已确认。

阅后即焚

敏感消息在被阅读后自动消失。

剧透

内容保持隐藏，直到每位读者自行选择显示。

会话收件箱

每个会话中的提及、保存和固定的消息、文件和话题，在会话标题栏一键直达。

团队徽章

点击名字旁的团队徽章，即可查看该团队、团队负责人和成员，并直接跳转到团队频道。

提醒

通过消息菜单，让这条消息稍后再提醒您。

在对方早上发送

将消息安排在收信人的工作时间送达。

给自己的笔记

一个私人空间，可以转发消息给自己，也可以记笔记。

主播模式

共享屏幕时隐藏个人信息。

38 种语言

包括阿拉伯语、希伯来语、波斯语和乌尔都语的从右向左布局。

自己的 GIF 和贴纸

收藏托管在您的服务器上，没有任何跟踪。

主题

深色、浅色和 OLED 主题，可跟随系统切换，还能分享自定义主题。

表情包

在表情选择器中从六十个模板里挑一个，写上配文，即可发出表情包。

成员私人备注

记住谁是谁，只有您自己能看到。
