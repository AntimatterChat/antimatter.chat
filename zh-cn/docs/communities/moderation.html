内容管理

Antimatter 提供给管理员的工具，每个工具的功能与限制，以及如何将它们结合使用来维护一个友好的社区环境。

谁可以执行管理操作

社区管理员可以使用本页面上的所有工具，但对象不包括其他管理员。其他人需要拥有相应权限的角色（参见 角色与权限）：

  • 管理消息，用于编辑和删除他人的消息；
  • 移除成员，用于禁言成员或将其从社区中移除；
  • 管理角色，用于授予和撤销角色。

拥有以上三种权限中的任意一种即可访问管理员视图。拥有 移除成员 权限的管理员只能禁言最高角色低于其自身角色的成员。

管理员视图

管理员视图汇总了你需要了解的关于某位成员的信息，以及你可以执行的操作。要打开它，请打开某人的个人资料卡片并选择右上角的盾牌按钮，或者右键点击其名称并选择 管理员视图。它将在右侧面板中打开。

  • 摘要：加入社区的时间（加入时间）、账号创建时间，以及该成员在过去一天和过去一周内在社区中发布的消息数量。查看 可搜索其消息。
  • 角色：该成员在社区中的角色。如果你可以管理角色，可以使用 添加角色 添加一个，或使用其旁边的 × 移除一个。
  • 主要权限：该成员超出普通成员权限的操作，例如 管理消息 或 移除和禁言成员。
  • 操作：消息、禁言 和 从团队中移除。系统管理员还会看到 停用账号。

一个新账号在第一天发布大量消息是垃圾信息的典型迹象：摘要部分可以一目了然地显示这一点。

禁言

禁言会在一段时间内阻止某人参与互动，但不会将其移除。在被禁言期间，他们可以阅读社区的频道，但不能在其中发送消息、发表表情回应、上传附件或提及他人。他们的私信保持开放。

  1. 在管理员视图中选择 禁言，或者右键点击其名称并选择 禁言…。
  2. 选择 时长：60 秒、5 分钟、10 分钟、一小时、1 天 或 1 周。
  3. 可选地，为其他管理员填写一个 原因。
  4. 选择 禁言。

该用户会看到“您已被禁言至……”提示，取代消息输入框，直到禁言结束。在此期间，他们也无法加入或重新加入团队的语音频道和通话。所有成员都能在成员列表中看到其姓名旁的 已禁言 标签，并在其个人资料卡片上看到禁言结束时间。

禁言会自动结束。若要提前结束，请在管理视图或该用户的菜单中选择 解除禁言。新的禁言会覆盖之前的禁言。将某人从团队中移除不会清除其禁言状态：如果他们在禁言结束前返回，仍处于禁言状态。团队管理员不能被禁言。

被禁言的用户不会看到原因，但其他成员可以通过服务器 API 读取原因。请撰写您愿意让对方看到的原因。

从团队中移除某人

在管理视图中选择 从团队中移除，或右键点击其姓名并选择 从团队移除…，然后确认。该用户将离开团队的所有频道并失去其中的角色；其消息将保留。他们不会被告知原因：团队将从其侧栏中消失。

被移除的用户可以通过新的邀请重新加入，如果团队是公共的，也可以立即重新加入。如果他们不应重新加入，请将团队设为私有并重新生成其邀请链接（参见 谁可以加入），或参见 阻止某人加入。

若要仅将某人从单个频道中移除，请右键点击其姓名并选择 从频道移除，或在该频道中输入 /kick @username。当团队中所有成员都在每个频道中时，此操作不可用。

阻止某人加入

Antimatter 没有封禁列表。您的选项，从最轻的处罚开始：

  • 禁言，最长一周。
  • 移除他们，结合私有团队或新的邀请链接。
  • 停用其账户，由系统管理员在管理视图或系统控制台中执行。他们将在所有地方被注销，并且无法再次登录，直到系统管理员重新激活他们。这适用于整个服务器，而不仅仅是您的团队，因此适用于垃圾信息发送者和严重滥用行为。

删除和编辑消息

使用 管理消息（或作为团队管理员），打开消息的 ⋯ 菜单并选择 删除。删除消息会将其从所有人处移除，包括其回复，且无法撤销。团队管理员可以删除，但默认情况下不能编辑他人的消息；拥有 管理消息 权限的角色可以执行两者。

若要暂时将消息从频道中移除，请记住：任何可以发布消息的人都可以移除置顶消息，任何可以阅读消息的人都可以取消固定。请参阅置顶消息。

系统没有慢速模式。若要平息激烈的频道，可以通过其权限暂时限制谁可以在其中发布消息（请参阅频道权限），或者对相关人员执行禁言。

举报

当服务器的举报功能开启时，成员可以通过消息 ⋯ 菜单中的举报消息来举报某条消息。他们需要选择一个原因并添加评论。在审核期间，该消息将从频道中隐藏，审核者会通过机器人私信收到该消息，并附有移除消息和保留消息按钮。

举报功能默认关闭，只有系统管理员可以在系统控制台 › 站点配置 › 数据泄露处理中将其开启。在那里，系统管理员可以选择：

  • 审核者：是所有社区使用同一组审核者，还是每个社区各有审核者，以及社区管理员和系统管理员是否也参与审核（社区管理员默认参与）；
  • 用户可以选择的原因列表；
  • 举报者和审核者是否必须添加评论，以及消息在审核期间是否隐藏。

该功能源于合规用途，其默认原因（如“分类不匹配”、“违反需知原则”等）是为处理敏感信息的组织编写的。对于公共社区，请要求系统管理员将它们替换为“垃圾信息”、“骚扰”或“跑题”等原因，并指定您的版主作为审核者：拥有管理消息权限并不自动使某人成为审核者。

忽略和屏蔽

成员无需版主即可保护自己，通过点击某人姓名旁的菜单：

  • 忽略：不接收该人的通知，其消息会被折叠，其私信将作为消息请求等待。
  • 屏蔽…：同上，且他们无法向您发送私信或发起包含您的群组消息。他们不会收到通知。

在设置中的隐私与安全下，每个人还可以选择来自尚未交流过的人的私信是正常到达（接受所有人的私信）还是作为消息请求（先询问我），适用于所有社区或在每个社区中。这是个人选择：社区管理员不能为其成员设置此项。

版主应了解的事项：

  • 屏蔽功能不会阻止任何人频道的帖子。它只会为执行屏蔽操作的人折叠被屏蔽者的消息。频道内的违规行为仍需由管理员处理。
  • 成员也可以忽略或屏蔽管理员和社区管理员。管理员的私信可能会作为静默请求送达，或者被拒绝。只有系统管理员和机器人始终可以送达。如有重要警告，请在对方可以阅读的频道中发布，或联系系统管理员。
  • 系统管理员可以在系统控制台 › 站点配置 › 成员和团队中关闭启用忽略、屏蔽和消息请求，适用于同事必须始终可联系的工作场所。

通话与语音频道

谁可以管理通话：通话主持人、社区管理员、频道管理员和系统管理员。在语音频道中，拥有管理消息、移除成员或管理角色权限的管理员也可以。您本人无需处于通话中。

右键点击参与者的方块或行以打开其菜单：

  • 静音：将其静音一次；他们可以自行取消静音。
  • 在此通话中静音：他们保持静音状态，直到您允许，即使他们离开并重新加入。他们的麦克风显示已被管理员静音。静音状态在他们离开或通话结束后保留 10 分钟，因此离开并重新加入无法绕过。允许取消静音解除此限制。
  • 请求取消静音：请求已静音的人发言。他们会看到请求并选择是否取消静音。您可以在 20 秒后再次请求同一人。
  • 放下手和停止屏幕共享。
  • 从语音频道移除或移出通话：断开他们的连接。他们可以立即重新加入；若要阻止他们，请对他们进行禁言。

您只能对排名低于您的人进行通话静音：通话主持人低于语音频道管理员，后者低于频道管理员，然后是社区管理员，最后是系统管理员。

保持记录

社区中没有管理日志。禁言、移除和其他操作记录在服务器的审计日志中，只有系统管理员可以阅读。请在私有管理员频道中保留自己的记录：谁被禁言或移除，何时，以及原因。

公共社区的良好实践

  • 写下规则。将它们放在锁定的“信息”分类的频道中，添加横幅，并在入职欢迎文本中总结。
  • 限制新成员可以执行的操作。向您的系统管理员请求为您的社区设置权限方案，使成员无法重命名、归档或管理频道成员，默认设置允许这些操作。
  • 创建一个管理员角色，并赋予管理消息和移除成员权限。单独展示这些权限，以便成员清楚知道该向谁求助。请为管理员保留一个私有频道。
  • 逐步升级处理：先在频道内提醒，然后发送私信，接着进行短暂禁言，再延长禁言时间，随后移除成员，最后由系统管理员对垃圾信息和滥用行为进行停用处理。
  • 关注新账号。管理员视图会显示账号创建时间和发帖数量。如果新账号激增，使用私有社区并重新生成邀请链接更容易加以控制。
  • 开启举报功能，将审核人员设置为你的管理员，并设置符合你社区情况的举报理由。
  • 了解你服务器的成员上限。社区默认没有成员上限，但系统管理员可以设置；如果你的社区设置了上限，请在达到上限前请管理员提高该限制。
