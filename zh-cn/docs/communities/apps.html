应用与集成

您的成员拥有哪些应用、您可以自行为您的社区设置哪些内容，以及哪些操作需要系统管理员执行。

您的成员拥有的应用

Antimatter 附带一组应用。除非系统管理员关闭了其中某些应用，否则服务器上的每个社区都拥有这些应用：

应用功能说明
通话和语音频道在任何频道中进行通话，以及语音频道：始终开放的通话，人们可以随时加入或离开。
投票对话中的投票，支持实时结果、匿名投票和结束时间。/poll 命令可创建一个投票。
待办事项在每个频道和会话中共享待办事项列表，数量不限，也支持个人列表。
笔记实时协同编辑的文档，可与频道共享或保持为个人私有。
白板可与频道共享或保持为个人私有的绘图板。
看板由列和卡片组成的看板，并与频道关联。看板会在侧栏中打开；打开看板时，侧栏会加宽。
操作手册用于可重复流程的清单，在频道内运行，并显示在操作手册的侧栏中。
GIF 和梗图GIF 和贴纸选择器，以及基于模板制作的梗图，位于表情符号选择器中。
日历和邮件每个人自己的日历和邮箱，连接到他们自己的账户。
智能体AI 助手，当服务器已设置 AI 模型时可用。
GitHub、GitLab 和 Jira连接这些服务后的通知和命令。

大多数应用从应用栏打开，即窗口右侧边缘的一列图标。应用是针对整个服务器开启或关闭的，在系统控制台 › 插件中设置：社区管理员无法为单个社区开启或关闭某个应用。它们的设置也是全局的，除非本页另有说明。要添加应用或更改其设置，请联系您的系统管理员。

在社区中，应用遵循频道的权限：例如，只能读取频道的人可以看到其中的待办事项列表和笔记，但不能修改；频道管理员可以删除其中的笔记。管理员和拥有管理消息权限的人可以关闭频道中的任何投票。

频道的待办事项列表属于其成员：任何可以在该频道发帖的人都可以添加和勾选待办事项，并重命名或归档列表。列表由创建者删除，待办事项由添加者删除，或由频道管理员、社区管理员和系统管理员删除：其他成员无法删除它们，即使他们有权重命名频道。在已归档或只读频道中，列表仅供查看。访客只能向与其共享频道的人发送待办事项。

自定义表情符号

自定义表情符号是人们在消息和表情回应中像使用其他表情符号一样使用的图像，通过输入名称并在两侧加上冒号来使用，例如 :party_parrot:。

  1. 打开表情符号选择器（在消息框中、消息的表情回应上，或用于您的状态）。
  2. 选择搜索框旁边的+（添加自定义表情符号）。选择器将显示添加视图。
  3. 拖放、粘贴或选择图片：PNG、GIF（支持动画）、JPEG 或 WebP，大小不超过 512 KB，尺寸不超过 1028 × 1028 像素。选择器会以表情符号显示的大小预览该图片。
  4. 为其命名：仅限小写字母、数字以及-、+或_，最多 64 个字符。如果名称已被占用或是标准表情符号，选择器会立即提示。
  5. 选择保存。新的表情符号将首先显示在选择器中，位于刚添加下方。

+旁边的自定义表情符号按钮会列出服务器上的自定义表情符号，包含搜索框、添加者及添加时间，以及您有权删除的表情符号上的删除按钮。相同的列表也位于集成 › 自定义表情符号中。

  • 自定义表情符号属于整个服务器，而不是某个特定的社区：服务器上的每个人都可以使用它们。请选择不会与其他社区的表情符号冲突的名称。
  • 默认情况下，所有成员都可以添加自定义表情符号；访客不能添加或删除任何表情符号。用户可以删除自己的表情符号；只有系统管理员可以删除其他用户的表情符号，因此请要求管理员移除不需要的表情符号。系统管理员可以在服务器权限中更改此设置，或在系统控制台中通过启用自定义表情关闭自定义表情符号。

GIF、贴纸和表情包

当启用这些应用时，表情符号选择器会包含 GIF、贴纸和梗图选项卡。

  • GIF 和贴纸来自系统管理员选择的 GIF 服务，并受系统管理员设定的内容分级限制。当系统管理员允许时，用户也可以添加自己的 GIF 和贴纸。默认情况下，只有系统管理员可以添加；系统管理员可以将其开放给除访客外的所有人（谁可以添加 GIF 和贴纸）。在“GIF”和“贴纸”选项卡中，搜索框旁边的 + 会打开添加视图（添加 GIF、添加贴纸），管理按钮（管理 GIF、管理贴纸）会列出用户添加的内容，包括添加者和时间。集成页面中的 自定义 GIF 和 自定义贴纸 也有效。添加的 GIF 和贴纸对服务器上的所有人都可用；添加者本人和系统管理员可以删除它们。
  • 表情包：任何人在“表情包”选项卡中选择模板，编写文字并发布表情包。/meme 命令同样有效。默认情况下，除访客外的所有人都可以通过“表情包”选项卡搜索框旁边的 + 添加表情包模板，管理按钮会列出自定义模板，包括添加者和时间。系统管理员可以将此权限限制为仅系统管理员，或选择 无人（关闭自定义模板）：已添加的模板仍然可用。模板在整个服务器范围内共享，只有创建者和系统管理员可以删除它们。

在公共社区中，建议要求系统管理员将 GIF 和梗图模板的上传权限限制为仅管理员可用。

白板库

社区管理员可以为社区中的每个人添加形状库：在白板中，打开看板菜单或库面板，然后选择管理库。库是一个最大为 5 MB 的 .excalidrawlib 文件。

Webhook、斜杠命令和机器人

集成将您的社区与其他工具连接起来：例如，发布警报的监控系统、发布其答案的表单，或查找信息的命令。要设置它们，请点击您的头像并选择集成。您将看到您有权管理的集成类型：

集成功能说明默认情况下谁可以创建
传入 Webhook另一个服务通过调用一个秘密 URL 将消息发布到频道中。社区管理员
传出 Webhook包含触发词的消息会被发送到另一个服务，该服务可以回复。或者作为消息操作：用户从消息菜单向该服务发送一条消息。社区管理员
斜杠命令诸如 /weather 之类的命令会调用另一个服务，该服务会在频道中回复。社区管理员
机器人账号供程序使用的账号，以自身名称发布内容并带有 机器人 标签。系统管理员
OAuth 2.0 应用使用 Antimatter 账号登录的应用。系统管理员

消息操作

触发时机为从消息菜单的出站 Webhook 不会在发布消息时触发。它会作为消息菜单中的一个操作，位于更多操作下的集成组中：选择该操作会将该条消息发送到服务，服务可以在频道中回复，也可以单独回复给该用户。请为其设置一个标题（即菜单中该操作的名称），如有需要，还可以设置一个图标：可以是图片 URL 或上传的图片，将以灰色显示。请将其绑定到一个公共频道，或者将频道留空，以便在社区的所有公共频道中提供该操作。归档频道时会删除绑定到该频道的 Webhook，因此已归档的频道仅保留社区范围的操作。访客只能看到绑定到其所加入频道的操作。

拥有 管理集成 权限的自定义角色允许其他人也管理 Webhook 和斜杠命令（参见 角色与权限）。Webhook 和斜杠命令属于创建它们的团队。

系统管理员必须在 系统控制台 › 集成 › 集成管理 中启用每种类型的集成。传入和传出 Webhook 以及斜杠命令默认开启；创建机器人账号默认关闭。请将 Webhook 的 URL 和命令的令牌视为密码：任何拥有它们的人都可以向您的团队发布内容。

要构建集成、机器人或应用，请参见 在 Antimatter 上构建。

自动链接

自动链接可将问题编号等文本转换为团队中所有消息中的链接，无需安装应用。团队管理员可在 团队设置 › 自动链接 中进行设置；参见 自动链接。

操作手册

操作手册是用于重复流程的检查清单：处理事故、为新同事办理入职、准备发布。每次流程启动时，您都会运行该操作手册：Antimatter 会为此次运行创建或复用一个频道，其中包含检查清单、负责人及其状态更新。

从应用栏打开操作手册：其侧栏会显示该频道的运行和检查清单。面板顶部的按钮（浏览运行、操作手册和任务）会打开浏览视图，其中包含所有运行、所有操作手册和我的任务，你可以在这里创建操作手册（创建操作手册）或导入一个。打开操作手册编辑器时，面板会加宽。频道菜单中的频道自动化…条目可用于设置欢迎消息、为新成员指定分类，以及基于关键词推荐操作手册。

操作手册属于社区。默认情况下，任何可以创建频道的用户都可以创建操作手册，因此实际上每个成员都可以。操作手册可以对整个社区公开，也可以仅对其成员可见。

适合团队的一些优秀操作手册：欢迎新管理员、处理举报、准备活动。适合组织的：事故响应、员工入职与离职。
