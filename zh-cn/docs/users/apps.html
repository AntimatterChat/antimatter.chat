应用

Antimatter 附带了可与聊天并排使用的应用：可协同编辑的笔记和白板、看板、您的日历和邮件、投票、待办事项等。以下是如何打开每个应用及其用途。

查找并打开应用

管理员决定服务器上启用哪些应用，因此您在此页面上可能看不到所有应用。大多数应用都在应用栏中拥有图标，该栏位于窗口右侧边缘、您的头像下方。将鼠标悬停在图标上可查看应用名称，点击图标即可在对话旁边的面板中打开该应用。再次点击可关闭面板。拖动面板边缘可调整宽度；点击恢复默认宽度可还原。点击面板标题栏中的在新窗口中打开，可在独立窗口中打开该应用，并定位到您之前打开的笔记、看板或列表。

应用还会出现在其他位置：

  • 消息框的+菜单（添加文件等），例如创建投票。
  • 表情选择器中的选项卡：GIF 图像、贴纸和表情包。
  • 消息菜单（消息操作，即 ⋯）下的更多操作，例如添加到待办事项或运行操作手册。每个操作都会显示其所属应用的图标。
  • 斜杠命令，例如 /poll 或 /todo：输入 / 即可查看列表。
  • 某些应用的设置位于您设置中的插件下。

在手机上，应用栏位于右侧的抽屉中：向左滑动，或在对话标题中选择更多 › 成员和应用。

笔记

笔记是多人可同时编辑的文档，位于聊天旁边。您可以看到其他人输入时的光标和姓名，所有内容都会实时保存。

撰写笔记

  1. 点击应用栏中的笔记。
  2. 选择一个选项卡：本频道用于创建频道内所有成员均可阅读和编辑的笔记，或我的用于创建仅您可见的个人笔记。
  3. 点击面板标题栏中的 +（在此频道新建笔记或新建个人笔记）。随后将打开一个“未命名笔记”。
  4. 在标题栏中输入标题，然后开始撰写。标题栏下方的格式工具栏（仅对可编辑该笔记的用户可见）包含加粗、斜体、删除线、标题、列表和清单；链接、引用和代码也可使用。工具栏旁边的圆点显示其他正在编辑的用户，以及您的更改是否已保存。输入 @ 可提及频道成员（笔记中的提及不会发送通知）。
  5. 点击所有笔记（标题栏左侧的箭头）返回列表。

当频道中的笔记获得标题时，Antimatter 会在频道中发布“共享了笔记”，并附带一个 打开笔记 按钮。

笔记的更多功能

将笔记设为星标，即可在收藏选项卡中找到它。笔记的笔记操作菜单（⋯）提供在频道中分享（发布一张链接到该笔记的卡片）、在 ~channel 中分享（将个人笔记永久转换为频道笔记）、版本历史（查看并恢复此版本）、导出为 Markdown 和删除。只有笔记创建者和频道管理员可以删除频道笔记。

白板

白板是一个可以共同绘制的画布：支持形状、箭头、文本和自由手绘，并实时显示所有人的指针。

  1. 点击应用栏中的 白板。
  2. 与笔记一样，选择 此频道 或 我的，然后点击 +（在此频道中新建看板 或 新建个人看板）。
  3. 使用工具进行绘制：选择和移动 (V)、平移 (H)、矩形 (R)、椭圆 (O)、箭头 (A)、绘制 (P)、文本 (T) 和 橡皮擦 (E)。在工具栏中选择颜色、线条样式和字体，在 库 中选择形状。撤销 (Ctrl+Z) 可撤销上一步操作。

看板操作 菜单包含 全屏、显示整个看板、下载为 .excalidraw、PNG 或 SVG、版本历史、导入 .excalidraw 文件…（这将替换所有人的看板）、在频道中共享，以及 删除。白板保留在你的 Antimatter 服务器上。

看板

看板将工作组织为列中的卡片，例如“待办事项”、“进行中”和“已完成”。看板也可以以表格、画廊或日历的形式显示。

打开频道的看板

点击应用栏中的看板。看板将在对话旁边的面板中打开，并列出与该频道关联的看板；点击其中一个即可打开。如果尚未关联任何看板，请点击关联看板到 …，然后在看板旁点击关联，或点击创建看板。频道成员将成为关联看板的编辑者。看板显示时会加宽面板；点击面板顶部的返回箭头可返回上一视图。

使用看板

  • 要按分类查看社区中的所有看板，请点击面板中的所有看板。在那里，您可以查找看板、创建看板或分类，并通过菜单移动、复制、导出、隐藏或删除看板。
  • 要创建看板，请在面板中点击新建看板，然后从模板（会议议程、项目任务、路线图、冲刺计划等）开始，或选择创建空白看板。
  • 点击列中的+ 新建以添加卡片。卡片会在面板上方打开：设置其属性，添加文本、复选框和图片，上传附件，并发表评论。在卡片中提及某人会通知对方。
  • 将卡片在不同列之间拖拽。使用 分组依据、筛选、排序 和 搜索卡片 来查找内容，并使用 添加视图 切换为表格、画廊或日历视图。
  • 使用看板的 共享 功能来选择谁可以查看或编辑它。

日历

日历应用会在聊天旁边显示您自己的日历，发送提醒，并允许您在 Antimatter 中会面。它支持与使用 CalDAV 的日历服务器配合使用，例如 Nextcloud、Fastmail 或 Radicale。

连接您的日历

  1. 单击应用栏中的 日历。
  2. 在 连接您的日历 中，填写 CalDAV 服务器 地址（通常只需提供商的域名）、您的 用户名 和 密码。如果您的提供商提供应用密码，请使用该密码。
  3. 选择何时 提醒我没有闹钟的日程，然后单击 连接。

您的密码会以加密形式存储在 Antimatter 服务器上。如需稍后更改这些详细信息或断开连接，请使用面板中的 账户设置。

使用方法

  • 在议程和周之间切换，使用上一页、今天和知道了进行导航，并点击日历的标签以显示或隐藏该日历。
  • 单击 新建日程，填写 标题、开始时间 和 结束时间，可选填写 重复、提醒、地点 和 描述，然后 保存。单击日程以修改或删除它。
  • 要在 Antimatter 中会面，请将 在 Antimatter 中会面 设置为频道或语音频道，或设置为通话，并选择 频道。时间到达时，日程将显示 开始通话、加入通话 或 加入。
  • 提醒将以日历机器人发送的私信形式到达，如果存在通话，还会附带加入通话的链接。

该应用显示您自己的日历；它不会向其他人发送邀请。

邮件

邮件应用会在聊天旁边显示您的邮箱，因此您可以在不离开 Antimatter 的情况下阅读、回复和分享电子邮件。

连接您的邮箱

  1. 单击应用栏中的 邮件。
  2. 如果管理员已进行配置，请点击使用 Google 登录或使用 Microsoft 登录。否则，或对于其他提供商，请填写您的邮箱地址和您的姓名，然后填写接收邮件 (IMAP)和发送邮件 (SMTP)服务器，包括其安全设置、端口、用户名和密码。您的提供商的帮助页面会提供这些详细信息。
  3. 点击连接。

使用方法

  • 选择一个文件夹，使用搜索此文件夹进行搜索，并点击邮件进行阅读。来自互联网的图像在您点击显示图像之前是隐藏的。
  • 使用回复、回复全部或前进进行答复，或使用新消息撰写新邮件。消息为纯文本，您无法附加新文件。
  • 点击共享到频道，可将邮件的发件人、主题和摘录连同评论一起发布到频道中。

投票

投票用于在对话中提出问题，每个人只需点击一次即可投票。结果实时更新。

  1. 点击消息框中的+并选择创建投票，或输入/poll。
  2. 输入问题和至少两个选项；添加选项可添加更多，最多十个。
  3. 如果允许人们选择多个选项，请开启允许多个答案；如果不应让任何人看到谁投了什么票，请开启匿名投票。
  4. 选择时长，从 1 小时到 1 周，或选择无结束时间。
  5. 点击发布投票。

要投票，请点击一个选项；再次点击可撤回您的投票。投票在持续时间结束时结束，或者当创建者或频道管理员点击结束投票时结束；随后将显示最终结果。

你也可以在一行内编写完整的投票：/poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h。输入 /poll help 以列出所有选项。

待办事项

Todo 用于管理待办事项列表：包括在频道或会话中共享的列表、您自己的列表，以及您发送给其他人的待办事项。点击应用栏中的Todo。与笔记一样，面板包含三个选项卡：

  • 此频道（或此会话）：与其中所有人共享的列表。点击面板标题中的+（在此频道新建列表）即可创建一个。
  • 收藏：您已加星标的列表，无论它们位于何处。
  • 我的：仅您可见的个人列表（我的待办事项始终存在；点击+可创建其他列表），然后是频道中分配给我的、发送给我的和我发送的。

打开列表以添加待办事项，您可以添加详细信息和截止日期，并通过标记为已完成将其勾选。在频道列表中，分配给…可将待办事项分配给成员；在个人列表中，发送给…可将其发送给某人，对方可以接受、拒绝或标记为已完成。列表的列表操作菜单可重命名列表、更改其图标、归档列表（它将变为只读，并移至已归档下）或删除列表。任何可以在频道中发帖的人都可以修改其列表；列表创建者和频道管理员可以删除列表。

要将消息转换为待办事项，请在其菜单中选择更多操作 › 添加到待办事项，并选择列表。Todo 机器人会在有人向您分配或发送待办事项时通知您，并每天提醒您一次您的待办事项。

命令也适用：/todo lists、/todo new name（添加 --personal 以创建您自己的列表）、/todo add list: text 按名称添加到列表、/todo add text 添加到您自己的待办事项，以及 /todo send @someone text。

GIF、贴纸和表情包

点击消息框中的表情符号（笑脸图标）：当这些应用设置完成后，选择器会在表情符号旁边显示GIF 图像、贴纸和表情包选项卡。

  • GIF 图像：搜索，或浏览收藏、最近使用过、热门和分类。点击 GIF 即可立即发送。点击其星标可将其添加到您的收藏中。您也可以输入 /gif 和几个单词。
  • 贴纸：搜索或浏览贴纸包，点击贴纸即可发送。/sticker 命令同样有效。
  • 表情包：选择一个模板，在 制作表情包 中填入文字，查看预览，然后点击 发布表情包。你也可以输入 /meme，或输入 /meme help 查看如何在一行中编写。

根据服务器的设置，您可能可以通过搜索框旁边的 + 添加自己的 GIF、贴纸或表情包模板。这会打开选择器内的一个表单：选择、拖放或粘贴文件，检查预览，输入标题（表情包模板的名称），以及（如果愿意）标签或关键词，然后点击 添加（表情包模板则点击 保存模板）。您添加的内容会显示在选择器的最前面，服务器上的所有人都能找到它。+ 旁边的按钮（管理 GIF、管理贴纸 或 自定义表情包模板）会列出其他人添加的内容，包括添加者和时间，并允许您删除您有权删除的内容。访客无法添加或删除任何内容。

操作手册

操作手册是一份可重复使用的检查清单，适用于每次遵循相同步骤的工作：例如事故处理、版本发布或欢迎新同事。每次使用时，你都会启动一个 运行，其中包含独立的任务、负责人、状态更新，最后还有一个回顾。

  • 点击应用栏中的 操作手册 可查看当前频道的运行实例，通过 运行操作手册 启动一个，或快速创建 新清单。操作手册中的所有内容都在此面板中打开，并带有返回上一视图的箭头。
  • 要查找其他所有内容，请点击面板顶部的 浏览运行实例、操作手册和任务：所有运行实例、所有操作手册、您的任务，以及您的收藏和进行中的运行实例。
  • 要创建操作手册，请在该视图中点击 创建操作手册 或 导入；要编辑操作手册，请从 所有操作手册 中打开它。您可以从模板开始，例如产品发布、事件解决或员工入职，或者从空白操作手册开始。操作手册编辑器在显示时会加宽面板。
  • 要启动运行实例，请点击操作手册上的 运行，为运行实例命名并填写摘要，选择为其创建频道或链接到现有频道，然后点击 开始运行。您也可以从消息菜单中选择 更多操作 › 运行操作手册。
  • 在运行期间，勾选完成的任务，分配负责人并设置截止日期，点击 发布更新 告知所有人当前进展。负责人在最后点击 完成。

输入 /playbook 查看命令，例如 /playbook run 或 /playbook update。

GitHub、GitLab 和 Jira

这些应用将 Antimatter 连接到开发者使用的工具。你的管理员必须首先进行设置。然后：

  1. 输入 /github connect、/gitlab connect 或 /jira connect 来连接您的账户，然后按照链接指引在该网站上登录。对于 GitLab，请在网页浏览器中操作，而不是在桌面应用中。
  2. 当有人提及您、请求您审查或分配任务给您时，您会收到私信。
  3. 要让频道关注某个仓库或项目，请使用 /github subscriptions add owner/repo、/gitlab subscriptions add group/project 或 /jira subscribe。
  4. 要从消息创建或关联问题，请在消息菜单的 更多操作 下选择 创建 GitHub Issue、创建 GitLab Issue、创建 Jira Issue 或相应的 关联到 … 选项。

输入 /github help、/gitlab help 或 /jira help 以查看所有相关命令。

移动应用中的功能

移动应用支持创建和参与投票、发送 GIF 和贴纸，以及处理发送给您待办事项。笔记和白板会在应用内的浏览器窗口中打开。看板、日历、邮件和表情包功能尚未在移动应用中提供：请使用网页版或桌面版应用来使用这些功能。
