您的个人资料与隐私

他人如何查看您、谁可以联系您，以及如何保护您的账户安全。

编辑您的个人资料

  1. 点击窗口右上角的头像，然后选择 个人资料与设置。设置将打开 我的账户 页面。
  2. 点击 更改头像 上传 JPEG、PNG 或 BMP 图片，或点击 移除 恢复为姓名首字母。
  3. 填写或修改您的 名字、姓氏、用户名、昵称 和 职位（例如您的工作头衔）。
  4. 点击 保存。

用户名使用小写字母、数字、句点、连字符和下划线，且必须以字母开头。某些字段可能被锁定：如果您的组织的登录系统提供这些字段，会显示“由您的登录提供商设置”；如果由系统管理员管理，则显示“由您的系统管理员管理”。

要更改您的邮箱地址，点击 更改邮箱…，输入 新的邮箱地址 和您的 当前密码，然后点击 更改邮箱。您可能会收到一封发送至新地址的确认邮件。

由您的组织设置的个人资料详情

您的管理员可以向个人资料中添加字段，例如部门、站点或电话号码。这些字段会显示在 我的账户 中的 个人资料详情 下方，您可以填写被允许修改的字段。社区也可以拥有自己的成员属性：如果您可以设置其中一些属性，请右键点击您自己的名字并选择 编辑属性…。

团队徽章

如果您属于当前社区中的团队，我的账户 中的 团队徽章 用于选择显示在您名字旁边的团队标签，或选择 无。每个社区保留其自己的选择。

您的角色

某些社区拥有任何人都可以担任的角色，这些角色会为您的名字着色，并可能允许您执行更多操作。在社区菜单中选择 您的角色… 来加入或离开这些角色。

他人如何查看您

当他人点击您的名字或头像时，他们会看到您的个人资料卡片：您的名字、用户名、职位、自定义状态、本地时间、角色，以及您的组织显示的个人资料详情。点击您自己的名字以查看；它包含 编辑个人资料 和 设置状态 按钮。

默认情况下，当您离开或离线时，他人会看到“最近在线 …”。要隐藏此信息，请在 设置 › 外观 中关闭 共享最近在线时间。

设置自定义状态

自定义状态是一段带有表情符号的简短文字，例如“开会中”或“休假中”，会显示在您的名字旁边。

  1. 点击窗口右上角的头像。
  2. 在设置自定义状态中输入文字，并点击表情符号按钮（选择一个表情符号）来挑选一个表情符号。或者选择建议或最近中的状态。
  3. 使用清除时间选择状态何时消失：30 分钟、一小时、4 小时、今天、本周、不清除或选择日期和时间…。

要移除状态，请点击清除自定义状态（即 ×）。关于您的可用性（在线、离开、请勿打扰），请参阅您的状态。

其他人的个人资料

点击某人的姓名或头像即可查看其个人资料卡片，其中包含其本地时间以及与您的时差。您可以从那里消息或通话对方。右键点击其姓名或头像可查看更多选项：个人资料、消息、添加到频道、邀请加入社区、提及、复制用户名、忽略和屏蔽…。

个人资料卡片还有一个笔记字段：点击它即可为这个人写一条笔记。只有您能看到它。

谁可以向您发送私信

当您的管理员允许时，设置 › 隐私与安全将决定您如何接收来自您尚未交流的人的私信。没有人会被告知您的选择。

  • 在私信下的来自您尚未交流的人中，选择接受所有人的私信或先询问我：选择后者后，他们的私信将等待在您的消息请求中，不会通知您，直到您接受为止。机器人和系统管理员始终可以发送私信。
  • 在在每个社区中下，您可以为所在的每个社区做出不同的选择。当您与某人共同的社区接受该人时，该人即可发送私信。

消息请求

等待中的私信列在消息请求下，位于您的私信列表顶部。打开一条即可阅读。消息框的位置会显示一条提示“来自……的消息请求”，并提供三个选项：

  • 接受：对话将变为普通对话，他们的私信将通知您。
  • 忽略：请求将被隐藏，直到对方再次发送私信。
  • 屏蔽：见下文。

发送者不会得知您是否阅读、忽略或屏蔽了其请求。如果您持续忽略某人的请求，Antimatter 会建议您屏蔽该人；您可以选择暂不或不再询问此人。

忽略或屏蔽某人

右键单击某人的姓名或头像，或打开其个人资料卡片上的 ⋯：

  • 忽略：他们发送的内容不会向您发送通知，其私信将等待在您的消息请求中，他们在频道中的消息会被折叠为一行“来自您忽略的人的消息”。点击 显示 可阅读其中一条。
  • 屏蔽…：他们无法再向您发送私信或发起包含您的群组消息，他们发送的内容不会向您发送通知，他们在共享频道中的消息会被折叠。点击 屏蔽 进行确认。您与他们的私信将显示“您已屏蔽…”，在您取消屏蔽之前，双方都无法在其中发送消息。

对方不会收到通知。若要撤销操作，请在同一菜单或 设置 › 隐私与安全 中选择 停止忽略 或 取消屏蔽，该页面列出了您 已屏蔽 和 已忽略 的人员。

屏蔽操作不会将某人从您的频道中移除，也不会举报他们。如果有人骚扰您，请同时告知您社区的版主，例如在您的社区提供该功能时，使用消息菜单中的 举报消息。

密码与多重验证

前往 设置 › 安全。

更改密码

  1. 在 密码 旁边，点击 更改…。
  2. 输入您的 当前密码、新密码 和 确认新密码。
  3. 点击 更改密码。

如果您通过组织的登录系统（如 SAML、AD/LDAP 或 GitLab）登录，页面会说明这一点，且您的密码由该系统管理。登录方式 可能允许您在密码和该系统之间切换。

如果您忘记了密码，请在登录页面点击 忘记密码？ 并输入您的电子邮件地址以接收链接。

开启多重验证

多重验证要求您在每次登录时输入手机应用中的验证码，以确保仅凭密码不足以登录。

  1. 在手机上安装身份验证应用，例如 Aegis、Google Authenticator 或 1Password。
  2. 在 多重验证 旁边，点击 设置…。
  3. 使用应用扫描二维码，或输入下方显示的密钥。
  4. 输入 来自应用的验证码 并点击 开启。

若要使用另一部手机，请点击 重新设置…。若要关闭，请点击 移除多因素身份验证 旁边的 移除，除非您的服务器要求必须开启。

您的登录位置

设置 › 安全 会在 登录位置 下列出已登录您账号的所有浏览器、桌面应用和手机，并显示最近一次活跃时间。如果您发现不认识的或不再使用的设备，请点击旁边的 退出登录；如果您怀疑他人使用了您的账号，请更改密码。

访问历史（点击 显示）会列出最近的登录记录以及对您账号所做的更改，并显示来源。

若要退出当前正在使用的设备，请点击右上角的个人头像，然后选择 退出登录。

令牌与已授权应用

如果您的服务器允许，设置 › 安全 中还包含 个人访问令牌，它允许您自己的脚本以您的身份使用 Antimatter。使用 创建新令牌 创建一个令牌并立即复制：它不会再次显示。请 吊销 不再需要的令牌，切勿共享令牌。您已授权的应用 列出了您允许使用您账号的外部应用程序；点击 移除访问权限 可撤销授权。

停用账号

如果您的服务器允许，设置 › 安全 底部的 停用账号 功能可让您离开服务器。点击 停用…，然后选择 停用。您将被登出且无法再次登录；您的消息将保留。管理员可以重新激活您的账号。
