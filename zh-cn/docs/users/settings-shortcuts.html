设置与键盘快捷键

让 Antimatter 的外观和行为符合您的喜好：主题、显示、语言和时间，以及键盘快捷键。

打开设置

点击窗口右上角的头像，然后选择 个人资料与设置。您也可以按 Ctrl+Shift+A（Mac 上为 ⌘+Shift+A），或输入 /settings。您的设置会在更改时自动保存，并同步到您登录的所有设备。

设置按面板分组：

面板内容查看
我的账户您的头像、姓名、用户名、昵称、职位、电子邮件和个人资料详细信息。编辑个人资料
安全密码、多因素身份验证、登录位置。密码和多因素身份验证
隐私与安全谁可以向您发送消息，以及您忽略或屏蔽的人员。谁可以向您发送消息
通知桌面、移动设备和电子邮件通知、声音、关键词、自动回复。通知和状态
外观主题、显示和侧栏。下文
无障碍简化界面，以及为人名着色。下方

语言与时间界面语言和时间区。下文
键盘更改 Antimatter 的快捷键。下文
高级主播模式、开发者模式、同步草稿、故障排查。下文

在 插件 下，某些应用会添加自己的设置，例如用于麦克风和摄像头的 通话。如果您是系统管理员，设置还会链接到 系统控制台。

主题和显示

选择主题

在 设置 › 外观 中，选择 主题，然后选择 深色、OLED（纯黑色，适用于暗室和 OLED 屏幕）、轻度，或 系统（跟随计算机的浅色或深色模式，即使一天中模式发生变化也会自动调整）。

若要创建自定义主题，请点击 自定义。在 自定义颜色 下，设置每种颜色：社区侧栏、侧栏、聊天区域、输入框与卡片、边框、文本、次要文本、强调色 和 链接。点击 恢复为 Antimatter 默认 可重置这些设置。

分享主题

主题可以以以 am1: 开头的短代码形式传递。在 分享主题 下，单击 复制我的主题代码，然后将其发送给他人。若要使用收到的代码，请将其粘贴到输入框中，然后单击 应用。

显示

  • 消息显示：紧凑，可在屏幕上显示更多内容，不显示图片且行距更紧凑；标准；或宽松，在消息周围以及侧栏和成员列表中留出更多空间。
  • 头像上的在线状态：在消息中的头像上显示用户是否在线。
  • 共享最近在线时间：允许其他人查看“最近在线……”。
  • 消息宽度：完整宽度，或 居中（便于在大屏幕上阅读）。
  • 显示名称为：用户名、昵称 或 全名，除非管理员已为所有人统一设置。
  • 24 小时制：将时间显示为 16:00，而不是 4:00 PM。
  • 分组未读频道：将未读频道汇总到侧栏顶部的 未读 部分中。
  • 打开的会话：侧栏最多列出多少条私信：5、10（默认值）、15、20 或 40。无法容纳的未读会话将等待在社区栏底部。

经典界面

本指南描述的是 Antimatter 的界面。如果管理员允许，您可以在 设置 › 外观 中的 Web 界面 选项里切换到 经典版（旧版）（为保持兼容性而保留的旧界面），也可以切换回 Fusion。此选择适用于您登录的所有浏览器。经典版界面中的菜单和按钮有所不同。

无障碍

设置 › 无障碍 使 Antimatter 更易读、更易用。Antimatter 还会遵循系统的减少动态效果设置。

  • 简化界面：屏幕上同时显示的内容更少。按钮和行更大，没有动画，成员列表保持关闭状态直到您打开它，计数仅针对提及显示，消息上方显示的按钮更少。所有功能都在触手可及之处。
  • 名称着色：为消息中每个人的名字赋予独特的颜色，以便一眼区分不同人员。默认关闭，因为角色已经为持有该角色的人员的名字着色。

消息设置

设置 › 消息 用于设置对话的外观和您的书写方式。根据您的服务器配置，它提供以下选项：

  • 将回复保留在话题中：话题回复仅保留在话题中，而不会同时显示在频道中。
  • 将颜文字转换为表情符号：将 :) 和 <3 显示为表情符号。
  • 显示您时区的时间：高亮显示消息中书写的时间，当您将鼠标悬停在时间上时，会显示您所在时区的时间。
  • 使用 Ctrl+Enter 发送：Enter 键用于换行，Ctrl+Enter 用于发送。
  • 富文本编辑器（测试版）：在输入时即可预览格式效果。
  • 在阅读下：打开未读会话时定位到（上次离开的位置或最新消息）、展开显示图片、链接预览（消息中链接的网站预览卡片）、一键表情回应、加入和离开消息，以及消息格式（关闭它以纯文本形式查看消息）。

语言和时区

在设置 › 语言与时区中，从列表中选择界面的语言。Antimatter 会立即切换。

下方会显示您的时区，通常会根据您的电脑自动设置。如需更改，请单击更改…：这将打开经典设置窗口中的时区设置，您可以在此关闭自动时区并手动选择。

您的时区对其他人也很重要：Antimatter 会据此向他们显示您的本地时间，并在您处于夜间时发出提醒。

高级设置

  • 主播模式：隐藏您的电子邮件地址和会话预览，并静音桌面通知，例如在屏幕共享时使用。
  • 开发者模式：在消息、频道、社区和用户的菜单中添加复制 ID，以便用于 API 和机器人。
  • 同步草稿：将您尚未发送的消息保留在服务器上，以便在另一台设备上完成编辑。默认开启。
  • 在 性能调试 部分（如果服务器提供该功能）：在此浏览器中关闭插件 和 不发送正在输入通知，在出现问题时非常有用。

更改快捷键

  1. 打开 设置 › 键盘。
  2. 点击操作旁边的 更改，然后按下新的按键。按 Esc 取消，或按 Backspace 关闭该快捷键。
  3. 如果另一个操作使用了相同的按键，页面会提示您：“另一个操作也使用了这些按键”。
  4. 点击 重置 恢复原始按键。

您可以更改搜索、快捷键列表、设置、未读过滤器和通话的快捷键。其他快捷键保持不变。页面底部的 所有键盘快捷键… 可打开完整列表。

在桌面应用中

桌面应用添加了其自身的快捷键，显示在其菜单中：例如 Ctrl+F 在页面中查找文本，Ctrl+= 和 Ctrl+- 缩放，Ctrl+0 恢复实际大小，Ctrl+R 重新加载，Alt+Left 和 Right（Mac 上为 ⌘+[ 和 ]）后退和前进，以及 Ctrl+Shift+1 到 9（Mac 上为 ⌘+Ctrl+1 到 9）在服务器之间切换。
