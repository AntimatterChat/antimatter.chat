隐私政策

最后更新：2026 年 10 月 11 日。本中文译文仅为方便阅读而提供，如与英文版本有任何出入，以英文版本为准。

本页面涵盖两部分内容：由各组织在自己的服务器上运行的 Antimatter 软件，以及本网站 antimatter.chat。

Antimatter 软件

Antimatter 是自托管软件。当您使用某台 Antimatter 服务器时，由运行该服务器的组织决定保留哪些数据、保留多久以及谁可以访问。Antimatter 项目无法访问您的服务器、您的账号或您的消息。如对某台服务器上的个人数据有疑问，请联系该服务器的管理员；适用的是他们自己的隐私政策。

软件本身的行为：

  • 无遥测。服务器不会向 Antimatter 项目或任何第三方发送使用统计、诊断信息或其他任何数据。
  • 仅在管理员启用相关功能时才会发起外部连接，并且只连接到管理员配置的服务：例如推送通知服务、消息中所发布网站的链接预览、GIF 提供商、邮件服务器、用于单点登录的身份提供商，或 AI、语音、翻译模型。
  • AI 功能使用管理员选择的模型。如果这些模型由第三方托管，发送给它们的内容（需要改写的消息、需要总结的对话、被转录通话的音频）会传送给该提供商。管理员可以使用自托管模型，确保数据不离开自己的网络。

本网站

  • antimatter.chat 是托管在 GitHub Pages 上的静态网站。
  • 本网站不设置任何 Cookie，也不使用任何分析、跟踪或广告。字体和图片均由本站自身提供，因此您在浏览时，浏览器不会向其他网站发出请求。
  • 与所有网站托管服务一样，GitHub 会收到您的 IP 地址和您请求的页面，以便提供这些页面。请参阅 GitHub 隐私声明。
  • 如果您在 GitHub 上提交 issue 或参与贡献，您在那里发布的内容是公开的，并由 GitHub 按照其自身条款处理。

联系我们

如对本政策有疑问，请在网站仓库中提交 issue。

我们可能会更新本政策；页面顶部的日期表示最后一次修改的时间。
