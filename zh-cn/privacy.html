隐私政策

最后更新：2026 年 10 月 16 日。

本页涵盖两部分内容：由组织在自有服务器上运行的 Antimatter 软件，以及本网站 antimatter.chat。

Antimatter 软件

Antimatter 是自托管的。当您使用 Antimatter 服务器时，运营该服务器的组织决定保留哪些数据、保留多久以及谁可以访问这些数据。Antimatter 项目无法访问您的服务器、您的账户或您的消息。如需了解特定服务器上的数据相关问题，请联系该服务器的管理员；其自身的隐私政策将适用。

软件本身执行的操作：

  • 无遥测。服务器不会向 Antimatter 项目、Mattermost, Inc.（Antimatter 基于其软件构建）或其他第三方发送使用统计、诊断信息或任何其他数据。
  • 仅当管理员启用某项功能时，才会建立外部连接，连接至管理员配置的服务：例如推送通知服务、GIF 提供商、邮件服务器、用于单点登录的身份提供商，或 AI、语音或翻译模型。
  • 有两项默认开启的例外，管理员可以将其关闭。链接预览：当有人发布链接时，服务器会获取该页面以显示其标题和图片。以及通话：它们使用 Cloudflare 的公共 STUN 服务器（stun.cloudflare.com）来查找公共网络地址。当 Calls 应用启动时，服务器会向其发起请求；每个人加入通话时，其设备也会向其发起请求。Cloudflare 仅能看到服务器和每个加入者的 IP 地址及端口，而看不到通话本身。管理员可以选择使用自己的 STUN 服务器，或者不使用；请参阅 通话与语音。
  • AI 功能使用管理员选择的模型。如果这些模型由第三方托管，则发送给它们的内容（如待重写的消息、待总结的对话、已转录通话的音频）将传输至该提供商。管理员可以使用自托管模型，以确保没有任何数据离开其网络。

本网站

  • antimatter.chat 是一个托管在 GitHub Pages 上的静态网站。
  • 它不设置 Cookie，也不使用任何分析、跟踪或广告。其字体和图片均由网站本身提供，因此您在阅读时，浏览器不会向其他网站发起请求。
  • 与任何 Web 主机一样，GitHub 会接收您的 IP 地址和所请求的页面，以便提供这些页面。请参阅GitHub 隐私声明。
  • 如果您在 GitHub 上提交问题或做出贡献，您发布的内容将是公开的，并由 GitHub 根据其自身条款进行处理。
