团队的聊天、通话与应用，尽在自己的服务器上

Antimatter 将频道、话题、语音房间、协作应用和 AI 汇聚一处，由您自行部署运行，没有任何付费墙。

为什么选择 Antimatter

您的对话，始终属于您

聊天服务器承载着团队的决策、文件和历史记录。Antimatter 让这些数据留在您掌控的基础设施上，也不会有厂商来决定您能用哪些功能。

自托管

借助 Docker 或发布包加 PostgreSQL，即可在自己的硬件或云上运行。可在防火墙内完全离线工作。

以 Mattermost 为根基

基于大型组织多年使用的 Mattermost 服务器构建，消息投递、权限管理和扩展能力久经考验。

企业级功能，无需许可证

SSO 不额外收费：SAML 与 OpenID Connect 单点登录、LDAP 同步、数据保留、合规导出等功能，每台服务器、每个团队都能使用。

开源

整个服务器均为采用 AGPL v3.0 许可的自由软件：您可以阅读、审计、修改，并为任意多的用户部署运行。

安全与可靠

基于一款十年来支撑关键业务的服务器

Antimatter 运行在一款成熟的开源服务器上，在注重安全的场景中备受信赖：消息投递可靠，数据模型稳定，API 文档完备，部署和集成在版本升级后依然正常运行。

  • 对接您的身份提供商：SAML、OpenID Connect、Google、Microsoft Entra、LDAP 与 Active Directory 同步，以及多因素身份验证。
  • 精细的访问控制：角色、权限方案、基于属性的访问控制、访客账号和 IP 过滤。
  • 合规：数据保留政策、合规导出、审计日志、分类标记横幅和阅后即焚消息。
  • 无遥测：服务器不会向外回传任何数据。只有您启用的功能才会发起外部连接。
应用与 ChatOps

协作无需离开对话

Antimatter 的应用在聊天旁边打开，一键即可分享到频道，所有人看到的内容实时同步。

  • 笔记：多人实时协同编辑的文档。
  • 白板：在共享画布上绘图、画示意图、头脑风暴。
  • 看板与操作手册：用看板管理项目，用检查清单应对事件、规范可重复的流程。
  • 待办事项、投票、日历和邮件：任务、快速决策、您的日程和收件箱，就在团队聊天旁边。
AI，由您做主

搭配您所选模型的智能助手

AI 安守本分：输入框里的一个按钮、一个按需打开的面板、一份您要求时才生成的摘要。需要帮忙时随叫随到，其余时间绝不打扰。可接入任何兼容 OpenAI 的模型，包括运行在您自有 GPU 上的模型，数据去向完全由您决定。

  • 改写和修正待发送的消息：更清晰、更简洁、更友好，或者只是改正错误。
  • 通话转录与总结：通话中显示实时字幕，结束后在通话的话题中发布转录文本和总结。
  • 智能体面板：就某个频道、某个话题或您的工作提问，以您的权限作答。
  • 频道摘要与回顾：用几行文字补上您错过的内容。
  • 自动翻译频道内容，还可按需朗读任意消息。
通话与语音房间

开口说话，和打字一样轻松

可以从任意对话发起通话，也可以随时进入常开的语音频道，就像团队成员走进会议室一样自然。

  • 语音频道位于侧栏中，谁在里面、谁在说话一目了然。
  • 视频和屏幕共享，支持画质预设、背景虚化和画中画。
  • 举手、表情回应和逐人音量调节，还有按键通话和主持人控制。
  • 实时字幕和转录，使用您自己的语音转文字模型。
集成

连接您已在使用的工具

完整的 REST API、Webhook、机器人和插件，将其他工具带入对话之中；为 Mattermost 编写的集成同样可用。

  • GitHub、GitLab 和 Jira：在频道中接收通知、查看预览、执行操作。
  • Webhook、斜杠命令和机器人，从 CI 流水线到监控系统，什么都能连接。
  • 交互式消息和对话框，直接在聊天中完成审批和表单填写。
  • 插件，可添加应用、消息类型、命令和面板。
贴心小细节

让每一天都更顺心的细节

小小的设计，帮您避免一次误会、一次打扰，或是省下一次点击。

时区自动换算

写下“3pm CET”，每个人看到的都是自己时区的时间。

“对方可能在睡觉”

给正值深夜的人发消息前，会有一条温和的提醒，并可选择“在对方早上发送”。

自动链接

消息发出时，工单编号等特定格式的文本会自动变成链接。

确认

请大家确认一条重要消息，并查看谁已确认。

阅后即焚

消息被阅读后自动删除，适合发送敏感内容。

剧透

隐藏消息内容，由读者自行选择是否显示。

会话收件箱

每个会话中的提及、保存和固定的消息、文件和话题，一键直达，也可查看整个社区的。

团队徽章

点击名字旁的徽章，即可查看此人所在的团队、团队负责人及其频道。

表情包

选个模板，写上配文，不离开对话就能发出一张表情包。

38 种语言

界面支持您的语言，包括从右向左书写的语言。

GIF 和贴纸

您自己的 GIF 和贴纸收藏，托管在您的服务器上。

主播模式

共享屏幕时隐藏个人信息。

置顶

将重要消息置顶在对话上方，时长可选一小时、一天、一周或直到取消。

频道导出

将频道消息下载为电子表格文件。

成员私人备注

记住谁是谁，只有您自己能看到。

开始使用

几分钟即可上线

只需一个 compose 文件，即可启动 Antimatter 及其数据库、文件存储和 GIF 服务。创建的第一个账号将成为管理员。

$ curl -fsSLO https://antimatter.chat/compose.yaml
$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
$ docker compose up -d
