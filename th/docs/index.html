เอกสารประกอบ Antimatter

คู่มือ 4 เล่ม แต่ละเล่มเขียนขึ้นสำหรับผู้ที่ต้องการใช้งาน เลือกเล่มที่ตรงกับสิ่งที่คุณต้องการทำ

การใช้ Antimatter

สำหรับทุกคนที่ใช้งานแชท: ข้อความและเธรด, ช่องและชุมชน, การโทรและช่องเสียง, แอปพลิเคชัน, การแจ้งเตือนและความเป็นส่วนตัว

การดูแลเซิร์ฟเวอร์

สำหรับผู้ดูแลระบบ: การติดตั้ง Antimatter, การตั้งค่า, HTTPS, การโทร, อีเมลและการแจ้งเตือนแบบ push, โมเดล AI, การเข้าสู่ระบบ, การสำรองข้อมูลและการอัปเกรด

การดูแลชุมชน

สำหรับผู้ดูแลและผู้ดูแลชุมชน ทั้งในที่ทำงานหรือในชุมชนสาธารณะ: การตั้งค่า, ช่อง, บทบาทและสิทธิ์, สมาชิก, การดูแลชุมชนและแอปพลิเคชัน

การสร้างบน Antimatter

สำหรับนักพัฒนา: REST API, webhooks และคำสั่่งสแลช, บอท, การเขียนแอปพลิเคชัน, การสร้าง Antimatter จากซอร์สโค้ดและการมีส่วนร่วม

ไม่พบสิ่งที่คุณต้องการ? ถามใน การสนทนาของชุมชน หรือดู ความช่วยเหลือและการสนับสนุน
