ความปลอดภัย

รายการตรวจสอบเพื่อเสริมความมั่นคงปลอดภัยของเซิร์ฟเวอร์ Antimatter: สิ่งที่ควรเปิด, ข้อจำกัดและการตั้งค่าความเป็นส่วนตัวที่ต้องตรวจสอบ, บริการภายนอกที่เซิร์ฟเวอร์ติดต่อ และวิธีรายงานปัญหาความปลอดภัย

สิ่งที่ต้องเปิด

พอร์ตบริการการเปิด
443/tcp, 443/udp, 80/tcpHTTPS proxy ของคุณ (Caddy หรือ nginx)สาธารณะ: นี่คือวิธีที่ผู้คนเข้าถึง Antimatter
8443/udp และ 8443/tcpสื่อสำหรับโทรสาธารณะ หากผู้คนใช้การโทรจากภายนอกเครือข่ายของคุณ
8065/tcpเซิร์ฟเวอร์เว็บของ Antimatterเฉพาะไปยัง proxy: เผยแพร่ที่ 127.0.0.1 (HTTP_PORT=127.0.0.1:8065)
8067/tcpตัวชี้วัดเฉพาะเครือข่ายส่วนตัว เมื่อเปิดใช้งาน ไม่ต้องเข้าสู่ระบบ
8074/tcp และ udpCluster gossipเฉพาะระหว่างโหนดในคลัสเตอร์
5432, 9000, 8080, 8066PostgreSQL, ที่เก็บไฟล์, บริการ GIF, push proxyห้ามเปิดเด็ดขาด ไฟล์ compose จะเก็บไว้ในเครือข่ายภายในโดยไม่มีพอร์ตที่เผยแพร่

ไฟล์ compose ของเว็บไซต์ยังรันทุกคอนเทนเนอร์ด้วย no-new-privileges, รัน Antimatter ด้วยผู้ใช้ที่ไม่ใช่ผู้ดูแลระบบบนอิมเมจแบบ distroless และรันบริการ GIF ด้วยระบบไฟล์แบบอ่านอย่างเดียว ฐานข้อมูล ที่เก็บข้อมูล และบริการ GIF อยู่บนเครือข่ายที่ไม่มีอินเทอร์เน็ต

รายการตรวจสอบหลังติดตั้ง

  1. สร้างบัญชีผู้ดูแลระบบคนแรกก่อนที่ใครจะเข้าถึงเซิร์ฟเวอร์ได้ (การติดตั้ง)
  2. ให้บริการ Antimatter ผ่าน HTTPS เท่านั้น และตั้งค่า URL ของเว็บไซต์เป็นที่อยู่ https:// (โดเมนและ HTTPS)
  3. เก็บ .env, config.json และคีย์ TLS ให้ root (หรือผู้ใช้ของเซิร์ฟเวอร์) เท่านั้นที่อ่านได้: chmod 600 .env
  4. กำหนดว่าใครสามารถสร้างบัญชีได้ ปิด เปิดเซิรฟ์เวอร์สาธารณะ เว้นแต่ชุมชนจะเป็นสาธารณะ และเปิด กำหนดให้ต้องยืนยันอีเมล เมื่อระบบอีเมลทำงานแล้ว (การเข้าสู่ระบบและบัญชี)
  5. เปิดใช้การยืนยันตัวตนสองขั้นตอน และบังคับใช้สำหรับบัญชีผู้ดูแลระบบอย่างน้อย หรือใช้ของผู้ให้บริการตัวตนของคุณ
  6. ตรวจสอบการเชื่อมต่อภายนอกด้านล่าง โดยเฉพาะเซิร์ฟเวอร์ STUN ที่การโทรใช้โดยค่าเริ่มต้น
  7. สำรองข้อมูล และทดสอบการกู้คืน (การสำรองข้อมูลและการอัปเกรด)
  8. อัปเดตอิมเมจให้ทันสมัย: การแก้ไขความปลอดภัยจะมาถึงพร้อมอิมเมจใหม่

การจำกัดอัตรา

เซิร์ฟเวอร์สามารถจำกัดจำนวนคำขอ API ที่แต่ละไคลเอนต์ทำได้ ซึ่งปิดไว้โดยค่าเริ่มต้น ใน คอนโซลระบบ › สภาพแวดล้อม › การจำกัดอัตร:

การตั้งค่าคีย์ค่าเริ่มต้น
เปิ่ด Rate LimitingRateLimitSettings.Enableปิด
จำนวนคำขอสูงสุดต่อวินาที (Maximum Queries per Second)RateLimitSettings.PerSec10
ขนาด Burst สูงสุดRateLimitSettings.MaxBurst100
ขนาด Memory StoreRateLimitSettings.MemoryStoreSizeติดตามไคลเอนต์ 10,000 ตัว
ปรับการจำกัดอัตรตามท่ีอย่ระยะไกลRateLimitSettings.VaryByRemoteAddrเปิด
ปรับการจำกัดอัตรตามผ้ใชRateLimitSettings.VaryByUserปิด
ปรับการจำกัดอัตรตาม HTTP headerRateLimitSettings.VaryByHeaderว่าง

เมื่ออยู่หลังพร็อกซี การจำกัดตามที่อยู่จะทำงานได้เฉพาะเมื่อเซิร์ฟเวอร์ทราบที่อยู่ของไคลเอนต์แต่ละตัว (ServiceSettings.TrustedProxyIPHeader และ ServiceSettings.TrustedProxyIPs ดู ที่อยู่ไคลเอนต์ที่อยู่หลังพร็อกซี) มิฉะนั้น คำขอทั้งหมดจะดูเหมือนมาจากพร็อกซี และทุกคนจะแชร์ขีดจำกัดเดียวกัน สิ่งเดียวกันนี้ใช้กับการกรอง IP และที่อยู่ในบันทึกการตรวจสอบ (audit logs) ด้วย

การจำกัดจำนวนครั้งในการเข้าสู่ระบบแยกต่างหาก: จำนวนคร้่งสูงสุดในการเข้่าสู่ระบบ (10) จะล็อกบัญชีหลังจากป้อนรหัสผ่านไม่ถูกต้องตามจำนวนครั้งดังกล่าว

การกรอง IP

คอนโซลระบบ › การตั้่งค่าไซต์ › การกรอง IP ใช้เพื่อจำกัดการเข้าถึงเซิร์ฟเวอร์ตามที่อยู่ IP โดยมีกฎอนุญาตและกฎปฏิเสธ (แต่ละกฎเป็นที่อยู่หรือช่วง CIDR) เมื่อเปิด เปิดการกรอง IP ผู้ที่มีที่อยู่ตรงกับกฎปฏิเสธ หรือไม่มีกฎอนุญาตเมื่อมีกฎอนุญาตอยู่ จะไม่สามารถเข้าถึงเซิร์ฟเวอร์ได้ หน้านี้จะปฏิเสธกฎที่จะบล็อกที่อยู่ของคุณเอง หากอยู่หลังพร็อกซี ให้ตั้งค่าที่อยู่ไคลเอนต์ก่อน (ที่อยู่ไคลเอนต์หลังพร็อกซี): มิฉะนั้นคำขอทั้งหมดจะดูเหมือนมาจากพร็อกซี

การอัปโหลดและการแชร์ไฟล์

การตั้งค่าตำแหน่งค่าเริ่มต้น
ขนาดไฟลส์ุงสุด (FileSettings.MaxFileSize)Environment › File Storage100 MB. ให้อัตราส่วนขนาดคำขอของพร็อกซีอย่างน้อยเท่านี้
ขนาด Payload ท่ีมากท่ีสุด (ไบต) (ServiceSettings.MaximumPayloadSizeBytes)Environment › Web Server300000: คำขอ API ที่ใหญ่ที่สุดที่ไม่ใช่การอัปโหลดไฟล์
อนุญาติให้อั้ปโหลดไฟล์ (FileSettings.EnableFileAttachments)Site Configuration › File Sharing and Downloadsเปิด
อนุญาตให้อัปโหลดไฟล์บนมือถือ, อนุญาติให้อั้ปโหลดไฟล์บนโมบายSite Configuration › File Sharing and Downloadsเปิด
เปิดใช์ลิงก์ไฟล์สาธารณะ (FileSettings.EnablePublicLink)Site Configuration › Public Linksปิด: เมื่อเปิด ผู้คนสามารถแชร์ไฟล์ด้วยลิงก์ที่ใช้งานได้โดยไม่ต้องเข้าสู่ระบบ
เปิดใช้งาน SVG (ServiceSettings.EnableSVGs)Site Configuration › Postsปิดในเซิร์ฟเวอร์ใหม่: เมื่อเปิด รูปภาพ SVG จะแสดงแบบอินไลน์

Antimatter ไม่สแกนการอัปโหลดเพื่อหาโปรแกรมประสงค์ร้าย

การตั้งค่าความเป็นส่วนตัว

ใน คอนโซลระบบ › การตั้่งค่าไซต์ › ผ้ใช้งานและทิม:

การตั้งค่าคีย์ค่าเริ่มต้นสิ่งที่ทำ
แสดงข้่อมูลอีเมลPrivacySettings.ShowEmailAddressเปิดปิด: ที่อยู่อีเมลของสมาชิกรู้จักเฉพาะผู้ดูลำดับระบบเท่านั้้น
แสดงชื่-นามสกุลPrivacySettings.ShowFullNameเปิดปิด: ชื่อเต็มจะถูกซ่อน และแสดงชื่อผู้ใชแทน
เปิดใช้งานการเพิกเฉย การบล็อก และคำขอร้องข้่อความPrivacySettings.EnableUserBlockingเปิดดูด้านล่าง
เปิดใหผ้ใช้เปิดข้่อความส่วตวกับTeamSettings.RestrictDirectMessageผู้ใชทุกคนในเซิร์ฟเวอร์ Antimatterหรือ สมาชิกรายใดเท่านั้ในทิม: เฉพาะผู้ที่อยู่ในชุมชนเดียวกันเท่านั้น

การเพิกเฉย การบล็อก และการขอร้องข้อมความ

เมื่อกำหนด เปิดใช้งานการเพิกเฉย การบล็อก และคำขอร้องข้อความ (ค่าเริ่มต้น) ผู้ใช้สามารถเพิกเฉยและบล็อกกันได้ และเลือกให้รับข้อความส่วนตัวจากคนที่ไม่รู้จักเป็นคำขอร้องข้อความ ซึ่งจะไม่แจ้งเตือนจนกว่าจะยอมรับ เหมาะสำหรักชุมชนสาธารณะ ในพื้้นที่ทำงานที่ผู้ร่วมงานต้องสามารถติดต่อหากันได้เสมอ ให้ปิดการทำงาน (AM_PRIVACYSETTINGS_ENABLEUSERBLOCKING=false): ระบบจะไม่บังคับใช้งานเหล่านี้อีกต่อไป แต่รายการและตัวเลือกที่ผู้ใช้เคยทำไว้จะยังคงอยู่ และจะกลับมาใช้ได้อีกครั้งเมื่อกำหนดใหม่อีกครัง

เซสชันและโทเคน

  • ความยาวของเซสชันและไทม์เอาต์เมื่อไม่มีการใช้งาน: ดู การลงชื่อเข้าใช้และบัญชี เซสชันที่สั้นลงหมายความว่าแล็ปท็อปหรือโทรศัพท์ที่หายไปจะยังคงลงชื่อเข้าใช้ได้น้อยกว่า
  • เปิดใช้งานโทเคนการเข้าถึงส่วนตัว (ServiceSettings.EnableUserAccessTokens, ปิด) อนุญาตให้ผู้ใช้สร้างโทเคน API ได้ และอายุการใช้งานสูงสุดของโทเคนการเข้าถึงส่วนบุคคล (วัน) ใช้เพื่อจำกัดอายุการใช้งานของโทเคนเหล่านี้ ทั้งสองรายการอยู่ในคอนโซลระบบ › อินทิเกรชัน › การจัดการอินทิเกรชัน
  • เพื่อออกจากระบบพร้อมกันสำหรับทุกคน เช่น หลังเกิดเหตุการณ์ที่สงสัยว่าจะถูกเจาะระบบ: ใช้เพิกถอนเซสชันทั้งหมด ในคอนโซลระบบ › การจัดการผ้้ใช้ › ผู้ใช้งาน

การเชื่อมต่อไปยังบริการภายนอก

Antimatter ไม่ติดต่อบริการใด ๆ ที่ดำเนินการโดย Mattermost, Inc. ไม่มีการส่งข้อมูลโทรเมตริก รายงานการล่ม หรือการตรวจสอบการอัปเดตความปลอดภัย และไม่ได้ดึงข้อมูลประกาศผลิตภัณฑ์ การตั้งค่าที่นำมาจาก Mattermost ซึ่งยังระบุชื่อหนึ่งของบริการของ Mattermost (บริการพุช, ตลาดแอป, ประกาศ หรือเซิร์ฟเวอร์ STUN สำหรบการโทร) ไม่ทำให้เซิร์ฟเวอร์ติดต่อพวกเขา: ที่อยู่เหล่านั้นจะถูกเพิกเฉย

เซิร์ฟเวอร์และแอปเชื่อมต่อไปยังบริการภายนอกอื่น ๆ เฉพาะสำหรบฟีเจอร์ที่ต้องการ และไปยังบริการที่คุณตั้งค่า:

ฟีเจอร์การติดต่อโดยค่าเริ่มต้น
การโทร: การค้นหาที่อยู่สาธารณะด้วย STUN เซิร์ฟเวอร์และแต่ละคนที่เข้าร่วมการโทรจะส่งคำขอ ซึ่งแสดงที่อยู่ IP และพอร์ตของเซิร์ฟเวอร์ STUNเซิร์ฟเวอร์ STUN สาธารณะของ Cloudflare, stun.cloudflare.comเปิดใช้งานอยู่ ขณะแอปการโทรเปิดใช้งานอยู่ หากต้องการเปลี่ยน ให้ดูที่ การโทร
ตัวอย่างลิงก์: เซิร์ฟเวอร์จะดึงหน้าเว็บที่แนบในข้อความ (เปิดใช้งานตัวอย่างลิงก์เว็บไซต์, ServiceSettings.EnableLinkPreviews)เว็บไซต์ที่ผู้คนแนบไว้เปิดใช้งานอยู่ ปิดด้วย AM_SERVICESETTINGS_ENABLELINKPREVIEWS=false
การแจงเตือนผาน push สู่แอปบนโทรศัพทพร็อกซีการแจ้งเตือนแบบพุชของคุณเอง (การแจ้งเตือนแบบพุช)ปิดอยู่ จนกว่าคุณจะตั้งค่าที่อยู่
ตลาดแอประยะไกล (PluginSettings.EnableRemoteMarketplace)URL ของ Marketplace ที่คุณตั้งค่าไว้ปิดอยู่ และไม่มีที่อยู่
อีเมลเซิร์ฟเวอร์ SMTP ของคุณเซิร์ฟเวอร์เริ่มต้นคือ localhost
การเข้าสู่ระบบแบบเดียว (SSO), โมเดล AI, การแปลงเสียงเป็นข้อความและการแปลภาษา, เว็บฮุคขาออก และแอปต่าง ๆ เช่น อีเมล, ปฏิทิน, GitHub, GitLab หรือ Jiraบริการที่คุณตั้งค่าปิดอยู่ จนกว่าคุณจะตั้งค่า

โดยค่าเริ่มต้น เซิร์ฟเวอร์จะปฏิเสธการเชื่อมต่อไปยังที่อยู่ส่วนตัวและ loopback สำหรับสิ่งเหล่านี้ (ตัวอย่างเช่น การแสดงตัวอย่างลิงก์, เว็บฮุค, แอป) เพื่อป้องกันไม่ให้ข้อความหรืออินทิเกรชันถูกใช้เพื่อเข้าถึงเครือข่ายภายในของคุณ ระบุโฮสต์ภายในที่อนุญาตให้เข้าถึงได้ในอนุญาติการเช่ือมต่อนภายในท่ีไม่ไว้วางใจถิง (ServiceSettings.AllowedUntrustedInternalConnections ในคอนโซลระบบ › สภาพแวดล้อม › นักพัฒนา); ไฟล์ compose ของไซต์ระบุ gifs ไว้ที่นั่น
