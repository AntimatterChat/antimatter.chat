การรันเซิร์ฟเวอร์

คู่มือนี้สำหร้บผู้ดูลำดับระบบท่ีติดตั้งและรันเซิร์ฟเวอร์ Antimatter. สมมติว่าคุณร้บ Linux, Docker และ reverse proxies แต่ไมร้บ Antimatter.

อะไรท่ีประกอบเป็นดิลพลอย

Antimatter เป็นทีมแชทท่ีโฮสต์เอง, เป็น fork ของ Mattermost. การดิลพลอยท่ีสมบูรณ์ประกอบด้วยส่วนเหล่านี้. มีเพียสามส่วนแรกท่ีเป็นส่วนท่ีตองมี.

ส่วนสิ่งที่ทำตองมี
เซิร์ฟเวอร์ Antimatterโปรแกรม Go หน่ึง (antimatter) ท่ีให้บริการแอปเว็บ, API และ websockets บนพอร์ต 8065, รันแอปท่ีรวมมา (plugins), และแบกรับมีเดียการโทรบนพอร์ต 8443. เครื่องมือ command-line amctl ใช้เพื่อดูแลระบบ.ใช่
PostgreSQLฐานข้อมู: ข้อความ, ผู้ใช้, ชุมชน และในการต้งค่าท่ีแนะนำ, การต้งค่าของเซิร์ฟเวอร์. เวอร์ชัน 15 หรือใหม่กว่.ใช่
พื้่นท่ีจัดเก็บไฟล์ไฟล์ท่ีอปัโหลด, ภาพ และแอปท่ีติดตั้ง: บริการท่ีเข้ากันได้กับ S3 (ไฟล์ compose รัน RustFS) หรือไดเรกทอรีในเครื่อง.ใช่
Reverse proxyHTTPS ท่ีอยู่หน้าเซิร์ฟเวอร์: โปรไฟล์ Caddy ของไฟล์ compose หรือ nginx ของคุณเอง.สำหร้บ production
บริการ GIF (gifs-server)GIF และสติ๊กเกอร์สำหร้บ GIF picker, จากแคตตาล็อกของคุณเอง. ใช้ Tenor API.ไม่
Push proxyส่งการแจ้้งเตือนไปยังแอปมือถือผ่่าน Apple และ Google.สำหร้บการแจ้้งเตือนมือถือ
rtcd, เซิร์ฟเวอร์ TURNเซิร์ฟเวอร์มีเดียแยกสำหร้บการโทรหลายครั้ง, และ relay สำหร้บคนท่ีอยู่หลังไฟร์วอลล์ท่ีเข้มงวด.ไม่
AI endpointsโมเดลท่ีอยู่หลัง AI agents, การถอดเสียงการโทร, การอ่านออกเสียง และการแปล: ผู้ให้บริการคลาวด์หรือเซิร์ฟเวอร์ท่ีคุณรัน.ไม่

Antimatter ไมมีไลเซ่นส์และไมมีเวอร์ชันท่ีต้องจ่าย: single sign-on, LDAP, high availability, compliance exports, data retention และฟีเจอร์อ่นๆ ท่ี Mattermost สำรองไว้สำหร้บแผนท่ีต้องจ่าย ล้วนรวมอยู่แลว.

ข้อกำหนด

  • เซิร์ฟเวอร์ Linux, amd64 หรือ arm64, พร้อม 2 CPU cores และ 4 GB ของหน่วยความจำหรือมากกว่ สำหร้บคนหลักร้อย, และพื้่นท่ีบนดิสก์สำหร้บไฟล์ท่ีคนอปัโหลด.
  • Docker Engine พร้อม Compose plugin (docker compose), สำหร้บการติดตั้งท่ีแนะนำ.
  • สำหร้บ production: ชื่อดอมเมนท่ีชี้ไปยังเซิร์ฟเวอร์, และพอร์ต 80 และ 443 ท่ีเปิิดสำหร้บ HTTPS.
  • สำหร้บการโทร: พอร์ต 8443, UDP และ TCP, ท่ีคนท่ีโทรสามารถเข้าถึงได้.
  • สำหร้บอีเมล: เซิร์ฟเวอร์ SMTP ท่ี Antimatter สามารถส่งผ่่านได้.

เร่ิมตั้นอย่างเร็ว

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
docker compose up -d

จากนั้นเปิด URL ของไซต์และสร้างบัญชีของคุณ: บัญชีแรกจะกลายเป็นผู้ดูแลระบบ การติดตั้ง อธิบายแต่ละขั้นตอนและวิธีการติดตั้งอื่น ๆ

ในคู่มือนี้

  • การติดตั้ง: Docker Compose, ภาพ, อาร์ไคฟ์เวอร์ชัน, ผู้ดูแลระบบคนแรก
  • การตั้งค่า: การตั้งค่าในฐานข้อมูลหรือไฟล์, ตัวแปรสภาพแวดล้อม AM_, คอนโซลระบบ, amctl, โลก
  • โดเมนและ HTTPS: URL ของไซต์, Caddy, nginx, ที่อยู่ไคลเอนต์
  • การโทรและเสียง: พอร์ต, NAT, TURN, rtcd, การถอดเสียงและคำบรรยาย
  • อีเมลและ Push: SMTP, ตัวแทน Push และแอปมือถือ
  • แอปที่รวมมา: แอปใดที่เปิดอยู่, การตั้งค่าของพวกมัน, การติดตั้งแอปอื่น
  • AI: โมเดลสำหรับเอเจนต์, เสียง และการแปล, และข้อมูลไปอยู่ที่ไหน
  • การเข้าสู่ระบบและบัญชี: การสมัคร, รหัสผ่าน, MFA, การเข้าสู่ระบบแบบเดียว (SSO), LDAP, แขก, เซสชัน
  • การสำรองข้อมูลและการอัปเกรด: การสำรองข้อมูล, การกู้คืน, การอัปเกรด, การย้ายจาก Mattermost
  • การดำเนินงาน: การตรวจสอบ, การขยายขนาด, การเก็บรักษาข้อมูล, การปฏิบัติตามกฎระเบียบ, การแก้ปัญหา
  • ความปลอดภัย: รายการตรวจสอบเพื่อความปลอดภัยและการเชื่อมต่อจากภายนอก

ต้องการจัดการชุมชนแทนที่จะเป็นเซิร์ฟเวอร์ (ช่อง, บทบาท, การดูแล)? ดู การจัดการชุมชน ต้องการสร้างการบูรณาการ? ดู การสร้างบน Antimatter

ชั่วโมงแรกของคุณ

  1. ติดตั้ง และสร้างบัญชีผู้ดูแลระบบทันที
  2. วางเซิร์ฟเวอร์ไว้เบื้องหลัง HTTPS บนโดเมนของตัวเอง
  3. ตั้งค่า SMTP และส่งอีเมลทดสอบ
  4. เปิดพอร์ตสำหรับการโทร และปิดโหมดทดสอบของแอปการโทร
  5. กำหนดว่าใครสามารถสมัครได้ และเปิดใช้งาน MFA
  6. ตรวจสอบการเชื่อมต่อจากภายนอกใน ความปลอดภัย
  7. ตั้งค่าการสำรองข้อมูลรายวัน

การขอความช่วยเหลือ

ถามคำถามในการอภิปรายของชุมชน และรายงานบั๊กในรีพอสิทอรีของชุมชน รายงานปัญหาความปลอดภัยเป็นการส่วนตัว ตามที่นโยบายความปลอดภัยอธิบายไว้
