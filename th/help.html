ความช่วยเหลือ

ความช่วยเหลือและการสนับสนุน

Antimatter เป็นโปรเจกต์ของคอมมูนิตี้ หน้านี้บอกว่าจะหาคำตอบได้จากที่ไหน และจะแจ้งปัญหาให้เราทราบได้อย่างไร

การใช้งาน Antimatter

  • ในแอป เมนูช่วยเหลือ (? ในแถบแอป) มีคู่มือผู้ใช้ คีย์ลัด และคำอธิบายการจัดรูปแบบข้อความและคำสั่งสแลช
  • ระหว่างที่ Antimatter ยังไม่มีคู่มือของตัวเอง เอกสารของ Mattermost ครอบคลุมการตั้งค่าเซิร์ฟเวอร์และงานดูแลระบบส่วนใหญ่
  • ผู้ดูแลเซิร์ฟเวอร์ของคุณช่วยเรื่องบัญชี คอมมูนิตี้ และการตั้งค่าได้

รายงานปัญหา

เจอบั๊ก หรือมีอะไรที่ไม่ทำงานอย่างที่คาดไว้? เปิด issue บน GitHub โดยระบุเวอร์ชัน (ดูได้ที่ เกี่ยวกับ Antimatter ในแอป) สิ่งที่คุณทำ สิ่งที่คาดว่าจะเกิดขึ้น และสิ่งที่เกิดขึ้นจริง:

  • เซิร์ฟเวอร์และเว็บแอป: issue ของ AntimatterChat/antimatter
  • แอปอย่างโน้ต ไวท์บอร์ด หรือการโทร: issue ของรีโพซิทอรีของแอปนั้นบน github.com/AntimatterChat
  • คำแปล: เปิด issue ในรีโพซิทอรีของเซิร์ฟเวอร์ โดยระบุภาษาและข้อความที่เกี่ยวข้อง

โปรดค้นหาใน issue ที่มีอยู่ก่อน และอย่าใส่ข้อมูลส่วนบุคคลหรือข้อมูลที่เป็นความลับ

รายงานช่องโหว่ด้านความปลอดภัย

โปรดอย่ารายงานช่องโหว่ด้านความปลอดภัยใน issue สาธารณะ ให้ทำตามนโยบายความปลอดภัยของรีโพซิทอรี ซึ่งอธิบายวิธีรายงานแบบส่วนตัว เราจะตอบรับรายงาน ดำเนินการแก้ไข และให้เครดิตคุณหากคุณต้องการ

การสนับสนุนเชิงพาณิชย์

Antimatter ไม่มีแพ็กเกจการสนับสนุนแบบเสียเงิน หากองค์กรของคุณต้องการการสนับสนุนที่มีการรับประกันระดับบริการ ลองมองหาบริษัทที่ให้บริการสนับสนุนเซิร์ฟเวอร์แชตแบบโฮสต์เอง
