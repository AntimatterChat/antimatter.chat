นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 16 ตุลาคม 2026.

หน้านี้ครอบคลุมสองส่วน: ซอฟต์แวร์ Antimatter ซึ่งองค์กรต่าง ๆ รันบนเซิร์ฟเวอร์ของตนเอง และเว็บไซต์นี้ antimatter.chat

ซอฟต์แวร์ Antimatter

Antimatter เป็นระบบโฮสต์เอง (self-hosted) เมื่อคุณใช้เซิร์ฟเวอร์ Antimatter องค์กรที่ดำเนินการจะตัดสินใจว่าข้อมูลใดจะถูกเก็บไว้ นานแค่ไหน และใครสามารถเข้าถึงได้ โครงการ Antimatter ไม่มีสิทธิ์เข้าถึงเซิร์ฟเวอร์ บัญชี หรือข้อความของคุณ สำหรับคำถามเกี่ยวกับข้อมูลของคุณบนเซิร์ฟเวอร์เฉพาะ ให้ติดต่อผู้ดูแลระบบของเซิร์ฟเวอร์นั้น; นโยบายความเป็นส่วนตัวของพวกเขาจะบังคับใช้

สิ่งที่ซอฟต์แวร์ดำเนินการด้วยตนเอง:

  • ไม่มีข้อมูลทางไกล (telemetry). เซิร์ฟเวอร์ไม่ส่งสถิติการใช้งาน การวินิจฉัย หรือข้อมูลอื่นใดไปยังโครงการ Antimatter, Mattermost, Inc. (ผู้พัฒนาซอฟต์แวร์ที่ Antimatter สร้างขึ้นจาก) หรือบุคคลที่สามรายอื่น
  • การเชื่อมต่อภายนอกเฉพาะสำหรับฟีเจอร์ที่ผู้ดูแลระบบเปิดใช้งาน ไปยังบริการที่พวกเขาตั้งค่า: เช่น บริการการแจ้งเตือนแบบ push (push notification), ผู้ให้บริการ GIF, เซิร์ฟเวอร์อีเมล, ผู้ให้บริการตัวตน (identity provider) สำหรับ single sign-on, หรือโมเดล AI, เสียง หรือการแปลภาษา
  • ข้อยกเว้นสองประการ ซึ่งเปิดใช้งานโดยค่าเริ่มต้น และผู้ดูแลระบบสามารถปิดได้. การแสดงตัวอย่างลิงก์ (Link previews): เมื่อมีคนโพสต์ลิงก์ เซิร์ฟเวอร์จะดึงหน้าเว็บนั้นมาแสดงชื่อและรูปภาพ และ การโทร (Calls): ใช้เซิร์ฟเวอร์ STUN สาธารณะของ Cloudflare (stun.cloudflare.com) เพื่อค้นหาที่อยู่เครือข่ายสาธารณะ เซิร์ฟเวอร์จะสอบถามเมื่อแอป Calls เริ่มทำงาน และอุปกรณ์ของแต่ละคนจะสอบถามเมื่อเข้าร่วมการโทร Cloudflare จะเห็นเฉพาะที่อยู่ IP และพอร์ตของเซิร์ฟเวอร์และของแต่ละคนที่เข้าร่วมเท่านั้น ไม่ใช่ตัวการโทรเอง ผู้ดูแลระบบสามารถใช้เซิร์ฟเวอร์ STUN ของตนเองแทน หรือไม่ต้องใช้เลย; ดู Calls and voice
  • ฟีเจอร์ AI ใช้โมเดลที่ผู้ดูแลระบบเลือก. เมื่อโมเดลเหล่านั้นโฮสต์โดยบุคคลที่สาม สิ่งที่ถูกส่งไปยังพวกเขา (ข้อความที่จะเขียนใหม่, บทสนทนาที่จะสรุป, เสียงจากการถอดเสียงการโทร) จะถูกส่งไปยังผู้ให้บริการนั้น ผู้ดูแลระบบสามารถใช้โมเดลโฮสต์เองเพื่อให้ไม่มีข้อมูลใดออกจากเครือข่ายของพวกเขา

เว็บไซต์นี้

  • antimatter.chat เป็นเว็บไซต์แบบคงที่ (static website) ที่โฮสต์บน GitHub Pages
  • เว็บไซต์นี้ไม่ตั้งค่าคุกกี้ และไม่ใช้การวิเคราะห์ข้อมูล เทร็กเกอร์ หรือโฆษณา ฟอนต์และรูปภาพทั้งหมดจะถูกรับส่งจากเว็บไซต์นี้โดยตรง ดังนั้นเบราว์เซอร์ของคุณจึงไม่มีการส่งคำขอไปยังเว็บไซต์อื่นใดระหว่างที่คุณกำลังอ่าน
  • เช่นเดียวกับโฮสต์เว็บอื่น ๆ GitHub จะได้รับที่อยู่ IP ของคุณและหน้าเว็บที่คุณร้องขอเพื่อนำไปให้บริการ ดูคำแถลงความเป็นส่วนตัวของ GitHub
  • หากคุณเปิด issue หรือมีส่วนร่วมใน GitHub สิ่งที่คุณโพสต์ที่นั่นจะเป็นข้อมูลสาธารณะและ GitHub จะดำเนินการจัดการภายใต้ข้อกำหนดของตนเอง
