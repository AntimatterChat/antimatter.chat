ปรับปรุงล่าสุด: 11 ตุลาคม 2026 ฉบับแปลภาษาไทยนี้จัดทำขึ้นเพื่อความสะดวกเท่านั้น หากมีข้อความใดขัดแย้งกัน ให้ถือตามฉบับภาษาอังกฤษเป็นหลัก

หน้านี้ครอบคลุมสองเรื่อง ได้แก่ ซอฟต์แวร์ Antimatter ซึ่งองค์กรต่างๆ รันบนเซิร์ฟเวอร์ของตนเอง และเว็บไซต์นี้ antimatter.chat

ซอฟต์แวร์ Antimatter

Antimatter เป็นซอฟต์แวร์ที่โฮสต์เอง เมื่อคุณใช้งานเซิร์ฟเวอร์ Antimatter องค์กรที่ดูแลเซิร์ฟเวอร์นั้นเป็นผู้ตัดสินว่าจะเก็บข้อมูลใด เก็บนานเท่าใด และใครเข้าถึงได้บ้าง โปรเจกต์ Antimatter ไม่มีสิทธิ์เข้าถึงเซิร์ฟเวอร์ บัญชี หรือข้อความของคุณ หากมีคำถามเกี่ยวกับข้อมูลของคุณบนเซิร์ฟเวอร์ใด โปรดติดต่อผู้ดูแลเซิร์ฟเวอร์นั้น ซึ่งนโยบายความเป็นส่วนตัวของผู้ดูแลจะมีผลบังคับใช้

สิ่งที่ซอฟต์แวร์ทำด้วยตัวเอง:

  • ไม่มีการเก็บข้อมูลการใช้งาน เซิร์ฟเวอร์ไม่ส่งสถิติการใช้งาน ข้อมูลการวินิจฉัย หรือข้อมูลอื่นใดไปยังโปรเจกต์ Antimatter หรือบุคคลภายนอก
  • เชื่อมต่อออกภายนอกเฉพาะสำหรับฟีเจอร์ที่ผู้ดูแลระบบเปิดใช้ และเฉพาะไปยังบริการที่ผู้ดูแลระบบกำหนดค่าไว้ เช่น บริการ push notification ตัวอย่างลิงก์ของเว็บไซต์ที่โพสต์ในข้อความ ผู้ให้บริการ GIF เซิร์ฟเวอร์อีเมล ผู้ให้บริการยืนยันตัวตนสำหรับการลงชื่อเข้าใช้ครั้งเดียว หรือโมเดล AI เสียงพูด หรือการแปลภาษา
  • ฟีเจอร์ AI ใช้โมเดลที่ผู้ดูแลระบบเลือก หากโมเดลเหล่านั้นโฮสต์โดยบุคคลภายนอก ข้อมูลที่ส่งไปให้โมเดล (ข้อความที่จะเรียบเรียงใหม่ บทสนทนาที่จะสรุป หรือเสียงของการโทรที่จะถอดเสียง) จะถูกส่งไปยังผู้ให้บริการรายนั้น ผู้ดูแลระบบสามารถใช้โมเดลที่โฮสต์เองเพื่อไม่ให้ข้อมูลใดออกนอกเครือข่ายของตน

เว็บไซต์นี้

  • antimatter.chat เป็นเว็บไซต์แบบสแตติกที่โฮสต์บน GitHub Pages
  • เว็บไซต์นี้ไม่ตั้งค่าคุกกี้ และไม่ใช้เครื่องมือวิเคราะห์ ตัวติดตาม หรือโฆษณา ฟอนต์และรูปภาพทั้งหมดให้บริการจากเว็บไซต์นี้เอง เบราว์เซอร์ของคุณจึงไม่ส่งคำขอไปยังเว็บไซต์อื่นขณะที่คุณอ่าน
  • เช่นเดียวกับผู้ให้บริการโฮสต์เว็บทั่วไป GitHub จะได้รับที่อยู่ IP ของคุณและหน้าที่คุณขอ เพื่อส่งหน้าเหล่านั้นให้คุณ ดูคำชี้แจงเรื่องความเป็นส่วนตัวของ GitHub
  • หากคุณเปิด issue หรือร่วมพัฒนาบน GitHub สิ่งที่คุณโพสต์ที่นั่นจะเป็นสาธารณะ และ GitHub จะจัดการตามข้อกำหนดของ GitHub เอง
