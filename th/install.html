เริ่มต้นใช้งาน

รัน Antimatter บนเซิร์ฟเวอร์ของคุณเอง

ไฟล์เดียว สามคำสั่ง ราวสิบนาที: Antimatter พร้อมฐานข้อมูล ที่เก็บไฟล์ และบริการ GIF บนเซิร์ฟเวอร์ Linux เครื่องใดก็ได้ที่มี Docker

พร้อมใช้งานในสิบนาที

คุณต้องมีเซิร์ฟเวอร์ Linux ที่ติดตั้ง Docker และปลั๊กอิน Compose แล้ว พร้อม CPU อย่างน้อย 2 คอร์ และหน่วยความจำอย่างน้อย 4 GB

1. ดาวน์โหลดไฟล์ compose

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. สร้างไฟล์การตั้งค่าพร้อมรหัสผ่านแบบสุ่ม

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

ตั้งค่า SITE_URL เป็นที่อยู่ที่ผู้ใช้จะใช้เข้าถึง เช่น http://192.168.1.20:8065 ในเครือข่ายภายใน

3. เริ่มการทำงาน

$ docker compose up -d

การเริ่มครั้งแรกจะใช้เวลาหนึ่งถึงสองนาทีระหว่างที่สร้างฐานข้อมูล จากนั้นเปิด SITE_URL ในเบราว์เซอร์แล้วสร้างบัญชีของคุณ บัญชีแรกจะเป็นผู้ดูแลระบบ และขั้นตอนการตั้งค่าจะพาคุณสร้างคอมมูนิตี้แรก

ใช้โดเมนของคุณเองและ HTTPS

ชี้ระเบียน DNS ของโดเมนไปที่เซิร์ฟเวอร์ เปิดพอร์ต 80 และ 443 แล้วเพิ่มโดเมนลงใน .env:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy จะขอใบรับรองจาก Let's Encrypt และต่ออายุให้เองโดยอัตโนมัติ

บริการที่ทำงานอยู่

  • antimatter: ตัวเซิร์ฟเวอร์พร้อมแอปต่างๆ (โน้ต ไวท์บอร์ด ช่องเสียง การโทร โพล และอื่นๆ) โดยไม่เก็บอะไรไว้บนดิสก์ การตั้งค่าอยู่ในฐานข้อมูลและไฟล์อยู่ในบริการจัดเก็บ จึงเปลี่ยนคอนเทนเนอร์ได้ทุกเมื่อ
  • postgres: ฐานข้อมูล
  • files: RustFS ที่เก็บข้อมูลที่เข้ากันได้กับ S3 สำหรับไฟล์ที่อัปโหลด
  • gifs: บริการ GIF และสติกเกอร์ของ Antimatter พร้อมชุดสติกเกอร์เริ่มต้น
  • https: Caddy ทำงานเฉพาะเมื่อใช้โปรไฟล์ https

ฐานข้อมูล ที่เก็บข้อมูล และบริการ GIF อยู่ในเครือข่ายส่วนตัวที่มีเพียง Antimatter เท่านั้นที่เข้าถึงได้

หากตัวเลือก GIF ว่างเปล่า ให้เปิด คอนโซลระบบ › ปลั๊กอิน › GIFs แล้วตั้ง URL ของบริการเป็น http://gifs:8080/v2 และตั้งคีย์ API เป็นค่า GIFS_API_KEY ในไฟล์ .env ของคุณ

การอัปเกรดและการสำรองข้อมูล

# อัปเกรดเป็นอิมเมจล่าสุด
$ docker compose pull && docker compose up -d
# สำรองฐานข้อมูล
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

สำรองวอลุ่ม files ด้วย หรือทำสำเนาที่เก็บข้อมูลด้วยเครื่องมือ S3 ใดก็ได้ หากต้องการติดตั้งร่วมกับ nginx และใบรับรองของคุณเอง ดูไฟล์สำหรับใช้งานจริงได้ใน antimatter-docker

ติดตั้งด้วยไฟล์รีลีส

  1. เตรียมฐานข้อมูลและผู้ใช้ PostgreSQL
  2. แตกไฟล์ (antimatter-<os>-<arch>.tar.gz) เช่น ไว้ที่ /opt/antimatter แล้วตั้งค่า SqlSettings.DataSource ใน config/config.json (หรือตัวแปรสภาพแวดล้อม MM_SQLSETTINGS_DATASOURCE) ให้ชี้ไปที่ฐานข้อมูล
  3. เริ่มเซิร์ฟเวอร์ด้วย bin/antimatter โดยใช้ผู้ใช้ที่ไม่มีสิทธิ์พิเศษ แล้วเปิด http://localhost:8065 บัญชีแรกที่สร้างจะเป็นผู้ดูแลระบบ

bin/amctl ใช้จัดการเซิร์ฟเวอร์ที่ทำงานอยู่ผ่านบรรทัดคำสั่ง (ใช้ bin/amctl --local บนตัวเซิร์ฟเวอร์เอง โดยเปิด ServiceSettings.EnableLocalMode)

ขั้นตอนถัดไป

  • การโทร: เปิดพอร์ตสำหรับการโทร (ค่าเริ่มต้นคือ UDP และ TCP 8443) เพื่อให้เสียงและวิดีโอเข้าถึงเซิร์ฟเวอร์ได้
  • อีเมล: ตั้งค่า SMTP สำหรับคำเชิญและการแจ้งเตือน
  • AI: เพิ่มโมเดลในการตั้งค่าเอเจนต์ ใช้ API ใดก็ได้ที่เข้ากันได้กับ OpenAI รวมถึงเซิร์ฟเวอร์ที่คุณรันเอง
  • เสียงพูดและการแปล: ตั้งค่าการถอดเสียงการโทร การอ่านออกเสียง และการแปลอัตโนมัติ ให้ใช้โมเดลแปลงเสียงพูดเป็นข้อความ แปลงข้อความเป็นเสียงพูด และโมเดลแปลภาษาที่คุณรันเอง
