팀의 채팅과 통화, 앱을 자체 서버에서

Antimatter는 채널, 글타래, 음성 채널, 협업 앱, AI를 한곳에 모았습니다. 직접 운영할 수 있고, 유료 장벽도 없습니다.

왜 Antimatter인가

대화의 주인은 여러분입니다

채팅 서버에는 팀의 결정과 파일, 지난 기록이 모두 담겨 있습니다. Antimatter는 이 모든 것을 여러분이 관리하는 인프라에 보관하며, 어떤 기능을 쓸 수 있을지 벤더가 정하지 않습니다.

자체 호스팅

Docker 또는 릴리스 아카이브와 PostgreSQL로 자체 하드웨어나 클라우드에서 실행하세요. 방화벽 안에서 완전히 오프라인으로도 동작합니다.

Mattermost를 기반으로

대규모 조직이 수년간 사용해 온 Mattermost 서버를 기반으로 만들었습니다. 메시지 전달, 권한, 확장성이 이미 검증되었습니다.

라이선스 없이 쓰는 엔터프라이즈 기능

SSO에 추가 요금이 없습니다. SAML과 OpenID Connect 기반 싱글 사인온, LDAP 동기화, 데이터 보존, 컴플라이언스 내보내기 등이 모든 서버, 모든 팀에 기본으로 제공됩니다.

오픈 소스

서버 전체가 AGPL v3.0 자유 소프트웨어입니다. 코드를 읽고, 감사하고, 수정하고, 원하는 만큼 많은 사람을 위해 운영하세요.

보안과 안정성

10년 동안 중요한 업무를 지탱해 온 서버 위에

Antimatter는 보안이 중요한 곳에서 신뢰받아 온 성숙한 오픈 소스 서버에서 동작합니다. 안정적인 메시지 전달, 견고한 데이터 모델, 문서화된 API 덕분에 버전이 바뀌어도 배포 환경과 연동은 그대로 작동합니다.

  • 사용 중인 ID 공급자: SAML, OpenID Connect, Google, Microsoft Entra, LDAP 및 Active Directory 동기화, 다단계 인증.
  • 세밀한 액세스 제어: 역할, 권한 체계, 속성 기반 액세스 제어, 게스트 계정, IP 필터링.
  • 컴플라이언스: 데이터 보존 정책, 컴플라이언스 내보내기, 감사 로그, 분류 배너, 읽은 후 삭제 메시지.
  • 원격 측정 없음: 서버는 외부로 아무것도 보내지 않습니다. 외부 연결은 여러분이 켠 기능에서만 이루어집니다.
앱과 ChatOps

대화를 벗어나지 않고 함께 일하세요

Antimatter의 앱은 채팅 바로 옆에 열리고, 클릭 한 번으로 채널에 공유되며, 모두에게 실시간으로 반영됩니다.

  • 메모: 여럿이 실시간으로 함께 편집하는 문서.
  • 화이트보드: 공유 캔버스에서 그림을 그리고, 다이어그램을 스케치하고, 브레인스토밍하세요.
  • 칸반과 플레이북: 프로젝트용 보드, 장애 대응과 반복 업무용 체크리스트.
  • 할 일 목록, 투표, 캘린더, 메일: 작업과 빠른 의사 결정, 일정과 받은편지함을 팀 곁에 둡니다.
AI, 원하는 방식대로

직접 고른 모델로 일하는 어시스턴트

AI는 제자리를 지킵니다. 입력창의 버튼 하나, 필요할 때 여는 패널, 요청할 때만 만드는 요약. 도움이 필요할 때는 곁에 있고, 그 밖에는 방해하지 않습니다. 자체 GPU에서 실행하는 모델을 포함해 OpenAI 호환 모델이라면 무엇이든 연결할 수 있으며, 데이터는 여러분이 정한 곳 외에는 어디로도 가지 않습니다.

  • 보내기 전에 메시지를 다시 쓰고 다듬으세요. 더 명확하게, 더 짧게, 더 친근하게, 또는 그저 바르게.
  • 통화 녹취록과 요약: 통화 중에는 실시간 자막을, 통화가 끝나면 녹취록과 요약을 통화의 글타래에 남깁니다.
  • 에이전트 패널: 채널이나 글타래, 내 업무에 대해 질문하세요. 답변은 내 권한 범위 안에서 이루어집니다.
  • 채널 요약과 리캡: 놓친 내용을 몇 줄로 따라잡으세요.
  • 채널 자동 번역, 그리고 요청하면 어떤 메시지든 소리 내어 읽어 줍니다.
통화와 음성 채널

타이핑하듯 편하게 대화하세요

어떤 대화에서든 통화를 시작하거나, 언제나 열려 있는 음성 채널에 들어가세요. 회의실에 들어서듯 자연스럽게.

  • 사이드바의 음성 채널에서 누가 있고 누가 말하고 있는지 바로 보입니다.
  • 영상과 화면 공유: 화질 프리셋, 배경 흐림, 화면 속 화면 지원.
  • 손 들기, 반응, 사람별 볼륨 조절, 눌러서 말하기, 호스트 제어.
  • 자체 음성 인식 모델로 만드는 실시간 자막과 녹취록.
연동

이미 쓰고 있는 도구와 연결됩니다

완전한 REST API, 웹훅, 봇, 플러그인으로 다른 도구를 대화 속으로 끌어오세요. Mattermost용으로 만든 연동도 그대로 작동합니다.

  • GitHub, GitLab, Jira: 채널에서 알림, 미리보기, 작업 실행.
  • 웹훅, 슬래시 명령, 봇으로 CI 파이프라인부터 모니터링까지 무엇이든 연결하세요.
  • 대화형 메시지와 대화창으로 승인과 양식 입력을 채팅 안에서 바로 처리합니다.
  • 플러그인으로 앱, 메시지 유형, 명령, 패널을 추가하세요.
작은 배려

매일을 조금 더 편하게 만드는 디테일

오해 하나, 방해 한 번, 클릭 한 번을 줄여 주는 작은 손길.

시간대 자동 변환

"3pm CET"라고 쓰면 모두가 자기 시간대로 읽습니다.

"자고 있을 수 있어요"

상대방이 한밤중일 때 메시지를 보내려 하면 살짝 알려 주고, "상대방 아침에 보내기" 옵션을 제안합니다.

자동 링크

메시지를 올리면 티켓 번호 같은 패턴이 링크로 바뀝니다.

확인 요청

중요한 메시지에 확인을 요청하고, 누가 확인했는지 볼 수 있습니다.

읽은 후 삭제

민감한 내용은 읽고 나면 스스로 사라지는 메시지로 보내세요.

스포일러

상대방이 직접 열어 볼 때까지 메시지를 가려 둡니다.

대화별 받은편지함

대화마다 멘션, 저장된 메시지와 고정된 메시지, 파일, 글타래를 클릭 한 번으로, 커뮤니티 전체의 것까지.

팀 배지

이름 옆 배지를 클릭하면 그 사람의 팀과 팀 리더, 팀 채널을 볼 수 있습니다.

밈

템플릿을 고르고 문구를 쓰면, 대화를 벗어나지 않고 밈을 올릴 수 있습니다.

38개 언어

오른쪽에서 왼쪽으로 쓰는 언어까지, 인터페이스가 여러분의 언어로 표시됩니다.

GIF와 스티커

서버에 직접 호스팅하는 나만의 GIF와 스티커 컬렉션.

스트리머 모드

화면을 공유하는 동안 개인 정보를 숨깁니다.

맨 위에 올리기

중요한 메시지를 1시간, 하루, 일주일 동안 또는 내릴 때까지 대화 위에 올려 두세요.

채널 내보내기

채널의 메시지를 스프레드시트 파일로 내려받으세요.

사람에 대한 비공개 메모

누가 누구인지 기억해 두세요. 나에게만 보입니다.

몇 분이면 준비 완료

Compose 파일 하나로 Antimatter와 데이터베이스, 파일 스토리지, GIF 서비스가 함께 실행됩니다. 처음 만드는 계정이 관리자가 됩니다.

$ curl -fsSLO https://antimatter.chat/compose.yaml
$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF
$ docker compose up -d
