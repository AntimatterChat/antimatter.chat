검색 및 항목 찾기

어떤 메시지, 파일, 채널, 사람이든 찾고, 중요한 것으로 돌아가세요: 멘션, 저장 및 고정된 메시지, 팔로우 중인 글타래.

빠른 검색

빠른 검색은 하나의 입력창에서 채널, 대화, 사람, 메시지를 찾습니다.

  1. Ctrl+K (⌘+K on a Mac)를 누르거나, 커뮤니티 레일 하단의 전체 검색(돋보기)을 클릭하세요.
  2. 몇 글자를 입력해 보세요. 입력하는 동안 채널 및 대화, 사람들, 메시지로 그룹화된 결과가 표시됩니다. 모든 메시지, 채널, 사람들, 메시지 탭을 사용해 범위를 좁힐 수 있습니다.
  3. 화살표 키로 이동하고 Enter를 눌러 결과를 열거나, 결과를 클릭하세요. 사람을 선택하면 해당 사람과의 다이렉트 메시지가 열립니다.

메시지는 현재 커뮤니티에서 검색됩니다. 모든 커뮤니티에서 검색하려면 모든 팀에서로 전환하세요. 일치하는 모든 메시지를 보려면 "…"에 대한 모든 메시지 검색을 선택하세요. 결과는 오른쪽 패널에 열립니다. 입력하기 전에는 상자에 최근 대화와 최근 검색이 나열됩니다.

빠른 검색은 참여 중인 채널을 나열합니다. 참여하지 않은 채널을 찾으려면 커뮤니티 메뉴의 채널 탐색을 사용하세요: 채널 찾기 및 참여를 참고하세요.

메시지 검색

  1. 대화 상단의 검색 입력창(커뮤니티 이름 뒤에 "검색 …")을 클릭하세요.
  2. 찾고 있는 단어를 입력하세요. 입력창 아래에 있는 제안은 현재 위치에서만 찾기 위한 #채널에서 검색(또는 이 대화에서 검색), 아래에 있는 필터, 최근 검색을 제공합니다.
  3. Enter를 누르세요. 결과 검색이 오른쪽 패널에 열리며, 일치하는 항목의 수가 표시됩니다.

검색은 전체 단어와 *로 끝내는 단어의 앞부분을 찾습니다.

필터

유형찾을 내용
from:@marieMarie가 작성한 메시지
in:design채널 또는 대화의 메시지
on:2026-10-05특정 날짜의 메시지
before:2026-10-05, after:2026-09-01특정 날짜 이전 또는 이후의 메시지
"exact phrase"이 단어들을 함께, 그리고 이 순서로
-draft"draft" 단어가 없는 메시지
deploy*"deploy"로 시작하는 단어
ext:pdf특정 유형의 파일
#hashtag해시태그가 있는 메시지

from: 또는 in:을 입력하면 일치하는 사람이나 채널이 제안 목록에 표시됩니다. on:, before:, after:의 경우 날짜 선택을 통해 캘린더가 열립니다. 필터를 조합할 수 있으며, 예를 들어 release from:@marie in:platform after:2026-09-01와 같이 사용할 수 있습니다. 메시지의 해시태그를 클릭하면 해당 해시태그로 검색됩니다. 커뮤니티 채널 이름 앞에 #이 붙은 것은 해당 채널로 연결되는 링크이며, 해시태그가 아닙니다.

결과 사용

  • 결과를 클릭하면 해당 대화 내 메시지로 이동하며, 해당 메시지는 하이라이트됩니다.
  • 각 결과에는 글타래 열기, 저장, 공지하기, 링크 복사 버튼이 있습니다.
  • 패널 상단에서 메시지와 파일 간 전환이 가능합니다. 파일의 경우 문서, 스프레드시트, 프레젠테이션, 코드, 이미지, 오디오, 비디오 유형별로 필터링할 수 있습니다.
  • 결과에 더 많은 공간을 주려면 패널 펼치기를 클릭하거나, 새 창에서 열기를 선택하세요.

일치하는 항목이 없으면 다른 단어 또는 필터를 시도해 보세요. 또한 모든 메시지 입력란에 /search를 입력한 뒤 검색어를 입력할 수도 있습니다.

멘션, 저장된 메시지 및 고정된 메시지

대화 오른쪽 상단의 인박스 버튼(멘션, 저장한 메시지, 고정된 메시지, 글타래)은 다음을 하나의 패널에 모읍니다:

  • 멘션: 사용자를 멘션한 메시지.
  • 저장됨: 사용자가 저장한 메시지.
  • 공지사항: 이 대화에서 고정된 메시지입니다.
  • 파일: 이 대화에서 공유된 파일.
  • 글타래: 사용자가 팔로우하는 글타래.

버튼에 점이 표시되면 해당 대화에서 사용자를 멘션했다는 뜻입니다. 멘션, 저장됨, 글타래 탭에서는 상단의 두 버튼을 통해 이 대화의 항목을 볼지, 전체 커뮤니티의 항목을 볼지 선택할 수 있습니다. 항목을 클릭하면 해당 위치로 이동하거나, 해당 글타래를 열 수 있습니다.

다이렉트 메시지 목록(커뮤니티 레일 하단의 채팅 버블인 모든 다이렉트 메시지를 클릭)에도 동일한 목록이 있습니다. 멘션(읽지 않은 멘션 수 포함), 구독한 글타래, 중요 메시지는 전체 커뮤니티 대상입니다. Ctrl+Shift+M(Mac의 경우 ⌘+Shift+M)를 누르면 오른쪽 패널에 최근 멘션이 열립니다.

채널 정보(채널 이름을 클릭)에는 해당 채널의 포스트 고정과 파일 링크가 있으며, 각각의 수가 표시됩니다.

읽지 않은 메시지 확인

  • 읽지 않은 메시지가 있는 채널을 열면, 읽지 않은 메시지가 시작되는 위치를 표시하는 줄이 나타나고, 상단 배너에 마지막으로 방문한 이후에 도착한 새 메시지의 수가 표시됩니다. 바로가기를 클릭하여 첫 번째 읽지 않은 메시지로 이동할 수 있습니다.
  • 대화에서 위로 스크롤하면 하단에 도착한 새 메시지의 개수를 표시하는 버튼이 나타납니다. 이 버튼을 클릭하면 해당 메시지로 이동합니다.
  • 기본적으로 읽지 않은 대화는 마지막으로 멈춘 위치에서 열립니다. 대신 최신 메시지에서 열려면 설정 › 메시지에서 읽지 않은 대화를 열 때 이동할 위치를 최신 메시지로 설정하세요.
  • 나중에 다시 확인하려면 메시지 메뉴에서 읽지 않은 상태로 표시를 선택하세요. 해당 대화는 그 메시지에서 읽지 않은 상태로 유지됩니다.
  • Alt+Shift+Up 및 Down 키로 이전 또는 다음 읽지 않은 채널로 이동할 수 있으며, Ctrl+Shift+U 키를 누르면 사이드바에 읽지 않은 채널만 표시됩니다.
  • 커뮤니티 메뉴에서 모두 읽음으로 표시를 선택하거나 Shift+Esc 키를 누르면 커뮤니티의 모든 채널을 읽음으로 표시합니다.

AI 에이전트가 설정되어 있으면 놓친 내용을 요약할 수도 있습니다. 채널에서 놓친 내용 확인 및 요약을 참고하세요.

메시지 및 채널 링크

모든 메시지와 채널에는 링크가 있습니다. 해당 메뉴에서 링크 복사를 선택하세요. 링크를 열면 읽을 수 있는 사용자는 해당 위치로 바로 이동하며, 해당 항목이 강조 표시됩니다. 링크가 소속되지 않은 비공개 채널로 연결되는 경우, 참여가 허용된 상태라면 Antimatter가 참여 전에 확인을 요청합니다.
