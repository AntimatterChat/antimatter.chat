설정 및 키보드 단축키

Antimatter를 원하는 대로 보이게 하고 작동하게 하세요: 테마, 표시, 언어 및 시간, 그리고 키보드 단축키.

설정 열기

창의 오른쪽 위를 클릭한 다음 프로필 및 설정을 선택하세요. 또는 Ctrl+Shift+A (Mac의 경우 ⌘+Shift+A)를 누르거나 /settings를 입력할 수도 있습니다. 설정은 변경 즉시 저장되며, 로그인하는 모든 기기에서 함께합니다.

테마 및 표시

테마 선택

설정 › 모양의 테마에서 어둡게, OLED(순수한 검은색, 어두운 방과 OLED 화면에 적합), 약하게, 또는 컴퓨터의 라이트 또는 다크 모드를 따르는 시스템을 선택할 수 있습니다. 하루 동안 설정이 변경되는 경우에도 이를 자동으로 따릅니다.

직접 만들려면 사용자 정의를 클릭하세요. 사용자 지정 색상에서 커뮤니티 레일, 사이드바, 채팅 영역, 입력 필드 및 카드, 테두리, 텍스트, 보조 텍스트, 강조, 링크의 각 색상을 설정할 수 있습니다. Antimatter 기본 테마에서 시작을 클릭하면 초기값으로 되돌립니다.

테마 공유

테마는 am1:로 시작하는 짧은 코드로 전달할 수 있습니다. 테마 공유 아래에서 내 테마 코드 복사를 클릭한 후 해당 코드를 다른 사람에게 보내면 됩니다. 받은 코드를 사용하려면 해당 필드에 붙여넣은 후 적용을 클릭하세요.

표시

  • 메시지 표시: 화면에 더 많이 표시되도록 이미지 없이 행 간격을 조정한 압축, 표준, 또는 메시지 주변과 사이드바 및 멤버 목록에 더 많은 여백을 두는 넓은.
  • 프로필 사진에 접속 상태 표시: 메시지 내 프로필 사진에 사용자의 온라인 여부를 표시합니다.
  • 마지막 접속 시간 공유: 다른 사용자에게 "마지막 접속 …" 정보를 표시합니다.
  • 메시지 너비: 전체 너비 또는 대형 화면에서 읽기 편하도록 가운데 정렬을 선택합니다.
  • 사용자 표시 방식: 관리자가 전원에 대해 다른 설정을 지정하지 않은 경우, 사용자 이름, 별명 또는 본명으로 표시합니다.
  • 24시간제 시계: 시간을 4:00 PM 대신 16:00으로 표시합니다.
  • 읽지 않은 채널 그룹화: 읽지 않은 채널을 사이드바 상단의 읽지않음 섹션에 모아 표시합니다.
  • 열린 대화: 사이드바에 최대 몇 개의 다이렉트 메시지를 목록으로 표시할지 설정합니다: 5, 10(기본값), 15, 20 또는 40. 표시되지 않는 읽지 않은 대화는 커뮤니티 레일 하단에 대기합니다.

클래식 인터페이스

이 가이드에서 설명하는 인터페이스는 Antimatter의 기본 인터페이스입니다. 관리자가 허용하는 경우, 설정 › 모양의 웹 인터페이스에서 호환성을 위해 유지되는 구버전 인터페이스인 클래식 (레거시)로 전환하고 다시 Fusion으로 돌아갈 수 있습니다. 이 선택은 로그인하는 모든 브라우저에 적용됩니다. 클래식 인터페이스에서는 메뉴와 버튼이 다릅니다.

접근성

설정 › 접근성을 사용하면 Antimatter를 더 쉽게 읽고 사용할 수 있습니다. Antimatter는 시스템의 모션 감소 설정도 따릅니다.

  • 간소화된 인터페이스: 한 번에 화면에 표시되는 요소를 줄입니다. 버튼과 행이 더 커지고, 애니메이션이 없으며, 열기 전까지 멤버 목록이 접힌 상태로 유지되고, 멘션에만 개수가 표시되며, 메시지 위에 표시되는 버튼이 줄어듭니다. 모든 요소가 손이 닿는 곳에 유지됩니다.
  • 이름에 색상 표시: 메시지 내 각 사용자의 이름에 고유한 색상을 부여하여 한눈에 사용자를 구분할 수 있습니다. 역할이 이미 해당 역할을 가진 사용자의 이름을 색상으로 표시하기 때문에 기본적으로 꺼져 있습니다.

메시지 설정

설정 › 메시지에서 대화의 표시 방식과 작성 방식을 설정합니다. 서버에 따라 다음과 같은 옵션을 제공합니다:

  • 답글을 글타래에 유지: 글타래 답글이 채널에도 함께 표시되지 않고 해당 글타래에만 유지되도록 설정합니다.
  • 이모티콘을 이모지로 변환: :)와 <3를 이모지로 표시합니다.
  • 메시지 속 시각을 내 시간대로 표시: 메시지에 작성된 시각을 강조 표시하고, 마우스를 올리면 내 시간대로 변환된 시각을 보여줍니다.
  • Ctrl+Enter로 보내기: Enter는 새 줄을 시작하고, Ctrl+Enter는 메시지를 보냅니다.
  • 리치 텍스트 편집기 (베타): 작성하면서 서식이 최종적으로 어떻게 보일지 미리 볼 수 있습니다.
  • 읽기 아래: 읽지 않은 대화를 열 때 이동할 위치(마지막으로 읽은 위치 또는 최신 메시지), 이미지 펼쳐서 표시, 링크 미리보기(메시지에 링크된 웹사이트의 미리보기 카드), 원클릭 반응, 참여 및 나가기 메시지, 메시지 서식(끄면 메시지를 일반 텍스트로 봅니다).

언어와 시간대

설정 › 언어 및 시간에서 목록에서 인터페이스의 언어를 선택합니다. Antimatter는 즉시 전환됩니다.

아래에 시간대가 표시됩니다. 보통 컴퓨터에서 자동으로 설정됩니다. 변경하려면 변경…을 클릭하세요. 그러면 클래식 설정 창에서 시간대 설정이 열리며, 자동 시간대를 끄고 원하는 시간대를 선택할 수 있습니다.

시간대는 다른 사람에게도 중요합니다. Antimatter가 사용자의 현지 시간을 표시하고, 밤 시간임을 알리는 데 사용됩니다.

고급 설정

  • 스트리머 모드: 화면 공유 중과 같이 이메일 주소와 대화 미리보기를 숨기고, 데스크톱 알림을 비활성화합니다.
  • 개발자 모드: 메시지, 채널, 커뮤니티, 사용자 메뉴에 ID 복사를 추가하여 API와 봇을 사용할 수 있습니다.
  • 임시 저장 글 동기화: 아직 보내지 않은 메시지를 서버에 유지하여 다른 기기로 마무리할 수 있습니다. 기본적으로 켜져 있습니다.
  • 서버가 지원하는 경우, 성능 디버깅 섹션에서 이 브라우저에서 플러그인 끄기와 입력 중 알림 보내지 않기를 사용할 수 있으며, 문제가 발생했을 때 유용합니다.

단축키 변경

  1. 설정 › 키보드를 여세요.
  2. 동작 옆의 변경을 클릭한 후 새 키를 누르세요. Esc를 눌러 취소하거나, Backspace를 눌러 단축키를 끄세요.
  3. 다른 동작이 동일한 키를 사용 중이면 페이지가 경고합니다: "다른 동작도 이 키를 사용하고 있습니다."
  4. 초기화를 클릭하여 원래 키로 되돌리세요.

검색, 단축키 목록, 설정, 읽지 않은 필터 및 통화의 단축키는 변경할 수 있습니다. 나머지는 그대로 유지됩니다. 페이지 하단의 모든 키보드 단축키…를 클릭하면 전체 목록을 열 수 있습니다.

데스크톱 앱에서

데스크톱 앱은 자체 단축키를 추가하며, 이는 앱의 메뉴에 표시됩니다. 예를 들어, 페이지에서 텍스트를 찾기 위해 Ctrl+F, 확대/축소하기 위해 Ctrl+= 및 Ctrl+-, 실제 크기로 보기 위해 Ctrl+0, 새로 고침을 위해 Ctrl+R, 뒤로/앞으로 이동하기 위해 Alt+Left 및 Right (Mac에서는 ⌘+[ 및 ]), 서버 간 전환을 위해 Ctrl+Shift+1부터 9까지 (Mac에서는 ⌘+Ctrl+1부터 9까지)를 사용할 수 있습니다.
