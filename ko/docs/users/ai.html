AI 에이전트

관리자가 설정한 경우, AI 에이전트는 질문에 답하고, 대화를 요약하며, 메시지를 다시 쓰고, 요약 정보를 준비할 수 있습니다. 이 페이지에서는 에이전트 사용 방법과 에이전트가 볼 수 있는 데이터에 대해 설명합니다.

에이전트 소개

에이전트는 Antimatter에서 봇으로 등장하며 고유한 이름을 가진 AI 어시스턴트입니다. 관리자가 에이전트를 AI 서비스에 연결하며, 이 서비스는 조직 자체 서버 또는 외부 제공업체에서 실행될 수 있습니다. 또한 각 에이전트를 누가 사용할 수 있는지, 그리고 어떤 채널에서 사용할 수 있는지를 결정합니다. 서버에 에이전트가 없거나 사용 가능한 에이전트가 없는 경우, 이 페이지의 에이전트 관련 기능이 표시되지 않습니다.

에이전트가 필요 없는 기능도 있습니다. 메시지 다시 작성과 요약은 Antimatter에 내장되어 있습니다. 관리자가 각각에 대해 AI 서비스(모델 연결)를 선택하면 작동합니다.

에이전트는 실수를 할 수 있습니다. 신뢰하거나 공유하기 전에 작성된 내용을 확인하세요.

에이전트와 대화하기

  1. 창의 오른쪽 가장자리에 있는 앱 레일에서 에이전트(반짝이 아이콘)를 클릭합니다. 에이전트 패널이 열립니다.
  2. 서버에 여러 에이전트가 있는 경우, 패널 헤더의 에이전트 메뉴("에이전트 선택")에서 하나를 선택합니다. 선택한 에이전트는 유지되며, 다른 AI 기능에서도 사용됩니다.
  3. "에이전트에 무엇이든 물어보세요..." 입력란에 질문을 입력하고 Enter 키를 누릅니다. 파일을 패널에 드래그하여 에이전트에 전달할 수도 있습니다.

에이전트는 패널에서 답변합니다. 작성하는 동안 생성 중지를 클릭할 수 있으며, 완료된 후에는 재생성을 클릭하여 다른 답변을 요청할 수 있습니다. 에이전트가 도구를 사용하거나 웹을 검색한 경우, 답변에 이를 명시합니다. 예를 들어 "3개 도구 사용" 또는 "웹에서 ... 검색"과 같이 표시됩니다.

패널에서 질문을 하면 대화이 시작됩니다. 해당 대화에 답글을 작성하여 대화를 계속할 수 있습니다. 새 대화를 클릭하여 새로운 대화를 시작하고, 대화 기록 보기를 클릭하여 이전 대화를 찾을 수 있습니다. 작은 링은 해당 대화가 에이전트의 메모리(컨텍스트 윈도우)를 얼마나 사용하는지 보여줍니다.

패널은 에이전트와의 다이렉트 메시지입니다: 다이렉트 메시지 목록에서도 에이전트를 찾을 수 있으며, 그곳에서 에이전트에게 메시지를 작성할 수 있습니다. 각 새 메시지는 글타래에서 답변되는 새 대화를 시작합니다.

읽고 있는 채널에 대해 질문하기

채널을 읽는 동안 에이전트 패널을 열면 "#채널에 대해" 대화할 수 있는 옵션이 제공됩니다. 읽지 않은 메시지 요약, 최근 7일 요약 또는 최근 14일 요약를 클릭하거나, "...에 대해 질문하기" 입력란에 질문을 입력하세요.

사용자 정의 프롬프트

자주 묻는 질문이 있다면 메시지 상자의 AI 메뉴에서 프롬프트 관리를 통해 사용자 지정 프롬프트로 저장하세요. 고정된 프롬프트는 에이전트 패널에 버튼으로 표시됩니다.

채널에서 에이전트에게 질문하기

모두 앞에서 에이전트에게 질문하려면 사람처럼 멘션하세요: @를 입력한 뒤 에이전트 이름과 질문을 입력하세요. 에이전트는 모든 채널 멤버가 읽을 수 있는, 해당 메시지 아래 글타래에서 답변합니다. 에이전트는 채널 전체가 아니라 해당 글타래만 읽습니다.

글타래에서 에이전트와 대화를 계속하려면 답글에서 다시 멘션하세요. 잊어버린 경우 Antimatter가 에이전트를 대화에 참여시키는 링크를 본인에게만 알려줍니다.

에이전트 사용 권한이 없거나 해당 채널에서 사용이 허용되지 않은 경우 에이전트는 답변하지 않습니다. 일부 채널에는 자동으로 답변하는 에이전트가 있습니다. 채널 관리자가 채널 설정에서 이를 구성합니다.

메시지에 대한 AI 작업

  1. 메시지를 가리킨 후 메시지 작업(⋯)을 클릭합니다.
  2. 더 많은 작업을 가리킵니다.
  3. AI 작업에서 다음 중 하나를 선택합니다:
    • 글타래 요약: 해당 메시지가 포함된 글타래의 요약입니다.
    • 실행 항목 찾기: 해야 할 작업과 담당자를 찾습니다.
    • 미답변 질문 찾기: 아직 답변을 기다리는 질문을 찾습니다.
    • 대신 반응하기: 에이전트가 적절한 이모지를 선택하여 내 이름으로 반응을 추가합니다.

답변은 에이전트 패널의 에이전트와의 개인 대화에 표시됩니다. 다른 사람은 볼 수 없습니다. 동일한 작업은 글타래 패널의 글타래 작업 메뉴의 더 많은 작업 아래에도 있습니다.

채널 업데이트 확인하기

읽지 않은 메시지가 있는 채널을 열면, 읽지 않은 메시지의 시작을 표시하는 "읽지 않음" 줄에 AI에게 질문 버튼이 있습니다. 클릭한 뒤 "생성할 에이전트:" 아래에서 에이전트를 선택하고, 새 메시지 요약, 실행 항목 찾기 또는 미답변 질문 찾기를 선택하세요. 답변은 에이전트 패널에 표시되며 본인만 볼 수 있습니다.

채널 요약은 최대 14일치를 처리합니다.

보내기 전에 메시지 다시 쓰기

관리자가 다시 작성에 사용할 AI 서비스를 선택한 후 사용할 수 있습니다. 에이전트를 사용하지 않으므로 선택할 에이전트가 없습니다.

  1. 메시지를 작성하세요.
  2. 서식 표시줄이 숨겨져 있으면 서식 표시(Aa)를 클릭한 뒤, 왼쪽 끝의 AI를 클릭하세요.
  3. AI로 다시 작성 아래에서 글쓰기 개선, 철자 및 문법 수정, 짧게 만들기, 격식 있게 만들기 또는 번역…를 선택하세요. 번역의 경우 "프랑스어"와 같은 언어를 입력한 뒤 Enter를 누르세요.

메시지 입력란에 "AI가 메시지를 다시 작성하는 중…"이라는 메시지가 표시된 후, 텍스트가 AI가 다시 작성함으로 표시된 새 텍스트로 대체됩니다. 내용을 읽고, 원하면 수정한 후 전송합니다. 실행 취소를 클릭하면 원래 텍스트로 되돌릴 수 있습니다. 글타래의 답글인 경우, AI는 글타래의 시작 부분과 마지막 답글들도 읽으므로 다시 작성된 내용이 대화 흐름에 맞게 조정됩니다.

서버에 에이전트가 있는 경우, 동일한 메뉴의 "GENERATE WITH:" 아래에 사용자 정의 프롬프트가 나열되며, 여기서 실행할 에이전트를 선택합니다.

요약

요약은 AI가 여러 채널을 정리하여 준비하는 요약본으로, 한 번만 실행하거나 평일 아침과 같은 일정으로 실행할 수 있습니다. 관리자가 요약에 사용할 AI 서비스를 선택한 후 사용할 수 있습니다. 이후 다이렉트 메시지 목록에서 요약을 찾을 수 있습니다. 나중에 서비스가 제거되면, 기존 요약은 읽거나 삭제할 수 있도록 남아있지만, 다른 서비스가 선택될 때까지 새로 만들거나 재생성할 수 없습니다.

요약 생성

  1. 요약을 열고 요약 추가를 클릭합니다.
  2. 요약에 이름을 지정합니다.
  3. 선택한 채널 요약 또는 모든 읽지 않은 메시지 요약을 선택합니다.
  4. 일정 없이 즉시 요약을 받으려면 한 번만 실행을 켭니다.
  5. 선택한 채널의 경우, 포함할 채널을 선택합니다.
  6. 단일 요약의 경우, 채널 목록을 확인하고 요약 시작을 클릭합니다. 일정 기반 요약의 경우, 실행 요일과 시간, 대상 기간(최근 24시간, 최근 7일 또는 마지막 읽은 이후)을 선택하고, 원하면 AI에 대한 추가 지침을 추가한 후 일정 생성을 클릭합니다.

요약 준비에 잠시 시간이 걸립니다. 준비가 완료되면 읽지 않음 아래에 각 채널별 하이라이트와 실행 항목이 포함된 카드로 표시됩니다. 요약의 메뉴에서 채널을 열거나 읽음으로 표시하거나, 요약을 다시 생성하거나 삭제할 수 있습니다. 예약된 요약은 예약된 메시지 아래에 있으며, 여기서 일시 중지할 수 있습니다. 관리자가 하루에 실행할 수 있는 요약 횟수를 제한할 수 있습니다.

회의 요약

통화가 녹취된 경우(자세한 내용은 녹취록 및 실시간 자막 참조), 통화 글타래의 녹취록 메시지에서 회의 요약 생성을 제안할 수 있습니다. 에이전트는 해당 에이전트와의 개인 대화에서 요약을 작성하며, 원하면 통화 글타래에 모든 사람에게 게시할 것을 제안할 수 있습니다.

에이전트를 사용한 검색

관리자가 AI 검색을 활성화한 경우, 대화 헤더의 검색 상자 제안 목록에 에이전트 옵션이 표시됩니다. 이를 선택한 후 자신의 언어로 질문을 입력하면, 에이전트가 멤버로 참여 중인 채널의 메시지를 검색하여 에이전트 패널에서 답변합니다.

도구 및 웹 검색

에이전트는 관리자가 연결한 도구를 사용할 수 있습니다. 예를 들어 다른 시스템에서 정보를 조회하거나 웹을 검색하는 용도로 사용할 수 있습니다. 패널의 Tools 메뉴에는 도구 제공자가 나열되어 있으며, 각 도구를 개인별로 켜거나 끌 수 있고, 로그인이 필요한 도구의 경우 Connect를 클릭하여 연결할 수 있습니다.

일부 도구는 실행 전에 사용자의 승인을 요청합니다. 에이전트는 수행하려는 작업을 카드 형태로 표시하며, 수락 또는 거부를 선택할 수 있습니다. 채널에서는 도구 실행 후 두 번째 단계가 있습니다. 공유를 선택하면 에이전트가 답변에 결과를 사용할 수 있으며, 채널의 모든 사람이 이를 볼 수 있습니다. 비공개 유지를 선택하면 결과를 비공개로 유지합니다.

에이전트는 사용자의 권한으로 도구를 실행합니다. 사용자가 접근할 수 없는 곳에 에이전트도 접근할 수 없습니다.

에이전트가 볼 수 있는 정보

  • 에이전트는 사용자가 직접 읽을 수 있는 정보만 읽습니다. 요약, 리캡 및 검색 기능은 각 채널에 대한 읽기 권한을 확인하며, AI 검색은 사용자가 멤버인 채널만 대상이 됩니다.
  • 글타래에서 에이전트를 멘션하면 해당 글타래를 읽습니다. 요약 기능은 글타래를 읽거나, 사용자가 선택한 기간 동안의 채널 내용을 읽습니다. 다시 작성 기능은 사용자의 임시 저장 글을 읽으며, 글타래인 경우 글타래의 시작 부분과 마지막 답글들도 함께 읽습니다.
  • 각 요청 시 에이전트는 일부 컨텍스트도 함께 수신합니다. 서버 이름, 요청자, 그리고 해당 채널 및 커뮤니티 정보입니다.
  • 에이전트가 읽는 내용은 관리자가 해당 에이전트에 대해 선택한 AI 서비스에 전송되며, 내장 기능이 읽는 내용(예: 다시 작성할 임시 저장 글, 요약할 채널)은 해당 기능에 대해 선택된 서비스에 전송됩니다. 해당 서비스가 조직 외부에 있을 수 있으므로, 데이터가 어디로 전송되는지 확인이 필요하면 관리자에게 문의하세요.
  • 에이전트와의 대화는 다른 메시지와 마찬가지로 Antimatter 서버에 저장됩니다.
  • AI 작업, 채널 요약 및 검색에 대한 답변은 에이전트와의 개인 대화에 게시되며, 사용자만 볼 수 있습니다. 채널에서 멘션에 대한 답변은 해당 채널의 모든 사람에게 표시됩니다.

에이전트가 표시되지 않는 경우

에이전트 패널에 "아직 에이전트가 없습니다"라고 표시되면, 관리자가 사용할 수 있는 에이전트를 설정하지 않은 것입니다. 서버에서 사용자가 자체 에이전트를 만들 수 있도록 허용되어 있으면, 패널에서 관리자가 설정한 AI 서비스를 사용하여 에이전트 만들기를 사용할 수 있습니다. 사용할 수 있는 에이전트가 없으면 AI 작업과 AI에게 질문이 표시되지 않습니다. 메시지 상자의 AI 버튼은 다시 작성 기능이 설정된 경우 또는 사용자 정의 프롬프트용 에이전트가 있는 경우에 표시됩니다.
