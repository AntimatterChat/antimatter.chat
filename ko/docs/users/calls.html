통화와 음성 채널

팀과 대화하세요: 대화에서 누군가와 통화하거나, 항상 열려 있는 음성 채널에 참여할 수 있습니다. 이 페이지에서는 통화, 음성 채널 및 통화 중 수행할 수 있는 모든 기능을 다룹니다.

시작하기 전

통화는 관리자가 설치하고 활성화하는 앱입니다. 통화가 사용 가능한 곳에서는 대화 헤더에 전화 버튼이 표시됩니다. 워크플레이스로 설정된 커뮤니티에서는 기본적으로 채널에 통화가 활성화됩니다. 음성 채널로 대화하는 다른 커뮤니티에서는 채널에 통화가 활성화되어 있지 않는 한, 해당 채널에 통화가 없습니다. 다이렉트 메시지와 그룹 메시지에서는 서버에 통화가 활성화되어 있는 경우 어디서나 통화를 사용할 수 있습니다. 전화 버튼을 볼 수 없다면, 서버에서 통화가 사용 불가능하거나 해당 채널에서 비활성화되어 있습니다.

처음으로 통화에 참여할 때 브라우저 또는 데스크톱 앱이 마이크 사용 권한을 요청합니다. 허용하지 않으면 다른 사람이 당신의 음성을 들을 수 없습니다. Antimatter에서 사용할 마이크와 스피커를 선택하는 방법은 마이크, 스피커 및 카메라 선택을 참고하세요.

통화 시작

채널 또는 대화에서

  1. 채널, 다이렉트 메시지 또는 그룹 메시지를 엽니다.
  2. 통화 시작을 클릭합니다(대화 오른쪽 위를 참조).

통화가 시작되고 당신은 통화에 참여하게 됩니다. 대화에 카드가 표시되어 다른 사용자에게 통화가 시작되었음을 알리며, 참여 버튼이 포함됩니다. 당신은 대화의 메시지에 계속 머물러 있으며, 통화는 사이드바 하단의 도크에 표시됩니다(참조: 통화 도크).

1명과 통화

사용자의 이름이나 사진을 클릭하여 프로필 카드를 연 다음, 통화를 클릭합니다. Antimatter가 해당 사용자와의 다이렉트 메시지를 열고 거기서 통화를 시작합니다. 사용자를 마우스 오른쪽 버튼으로 클릭하여 통화를 선택할 수도 있습니다.

벨소리

다이렉트 메시지나 그룹 메시지에서 통화를 시작하면, 누군가 참여할 때까지 통화 도크에 통화 중…라고 표시되고, 이후 통화 연결됨으로 바뀝니다. 관리자가 벨소리를 활성화한 경우, 상대방은 벨소리를 듣습니다. Antimatter의 어디에 있든, 상대방 화면의 오른쪽 위 모서리에 "통화 중" 또는 "…이(가) 그룹에 통화 중"이라는 카드가 나타납니다. 상대방은 참여, 거절, 또는 카드를 유지하면서 소리를 멈추기 위해 벨소리 음소거를 클릭할 수 있습니다. 약 30초 이내에 아무도 참여하지 않으면 통화가 종료되고, 대화 내의 해당 카드에는 응답 없음, 거절됨 또는 취소됨이라고 표시됩니다.

다른 통화 중, 상태가 방해 금지 또는 외출 중일 때, 음소거한 대화에서, 또는 무시하거나 차단한 사용자로부터는 벨소리가 울리지 않습니다.

벨소리를 선택하거나 끄려면 설정 › 알림의 데스크톱 및 브라우저 섹션에서 통화 수신 벨소리를 켜거나 끄고, 벨소리에서 소리를 선택하세요.

통화 참여 또는 나가기

당신이 참여하지 않은 채널 또는 대화에서 통화가 진행 중일 때, 다음과 같은 여러 방법으로 참여할 수 있습니다:

  • 대화 내 통화 카드의 참여를 클릭합니다.
  • 대화 상단 바로 아래 배너(“…이 통화를 시작했습니다”)에서 통화 참여를 클릭하세요.
  • 통화에 참여 중인 인원수가 표시되는 헤더의 초록색 참여 버튼을 클릭하세요.

사이드바에서 채널 이름 뒤의 초록색 전화 아이콘 또는 대화의 통화 중 배지는 해당 대화에서 통화가 진행 중임을 나타냅니다. 통화가 진행 중인 대화는 통화 종료까지 다이렉트 메시지 목록의 맨 위로 이동합니다.

한 번에 하나의 통화에만 참여할 수 있습니다. 다른 통화에 참여하면 현재 통화에서 나갑니다.

통화에서 나가기 위해 헤더의 통화 나가기(빨간 전화 아이콘), 통화 도크 또는 통화 컨트롤의 연결 해제를 클릭하거나 Ctrl+Shift+L (⌘+Shift+L (Mac))를 누르세요.

음성 채널

음성 채널은 항상 열려 있는 통화 공간입니다. 누군가가 통화를 시작할 필요가 없습니다. 사람들이 자유롭게 오가며, 커뮤니티의 모든 사람이 사이드바의 채널 아래에 나열된 참여자를 볼 수 있습니다. 음성 채널은 # 대신 스피커 아이콘을 사용합니다.

음성 채널 참여

  1. 사이드바의 음성 채널을 클릭하세요. 즉시 연결됩니다(“…에 연결됨”) 그리고 이전에 읽던 대화에 그대로 머무릅니다.
  2. 방에 있는 사람들을 보려면 음성 채널을 다시 클릭하거나 통화 도크의 음성 채널 표시를 클릭하세요.

일부 서버에서는 음성 채널을 클릭하면 참여하지 않고 방만 열립니다: 음성 참여를 클릭하여 참여하세요. 다른 음성 채널로 이동하면 해당 채널로 이동합니다.

텍스트 채팅

각 음성 채널에는 대화 중 링크와 메모를 위한 메시지도 있습니다. 사이드바의 채널 옆에 있는 텍스트 채팅 열기 또는 헤더의 텍스트 채팅을 클릭하여 오른쪽 패널에서 열 수 있습니다. 통화 중이 아니어도 그곳에서 읽거나 쓸 수 있습니다.

음소거

음성 채널에서 헤드셋 음소거는 통화의 모든 소리를 차단하고 사용자의 마이크도 음소거합니다. 다시 클릭하거나 음소거를 해제하면 다른 사용자의 소리를 다시 들을 수 있습니다.

음성 채널 만들기

채널을 만들 수 있는 권한이 있다면, 커뮤니티 메뉴에서 채널 만들기를 선택하고 음성 채널 유형을 선택한 후 이름을 지어 생성하세요. 채널 만들기를 참조하세요.

통화 도크

통화나 음성 채널에 있는 동안, 사이드바 하단의 도크에는 음성 연결됨 또는 통화 연결됨(다이렉트 메시지나 그룹 메시지에서 시작하여 벨소리가 울리는 통화의 경우 통화 중…)과 통화 위치가 표시됩니다. 해당 이름을 클릭하면 해당 대화로 이동합니다. 도크에는 다음 버튼이 있습니다:

  • 마이크를 음소거하거나 음소거 해제합니다.
  • 헤드셋 음소거(음성 채널에서).
  • 비디오가 허용되는 경우 카메라를 켜거나 끕니다.
  • 화면 공유를 시작하거나 공유 중지합니다.
  • 통화 표시(또는 음성 채널 표시)를 클릭하면 통화 창이 메인 영역에 열립니다.
  • 연결 해제를 클릭하여 통화를 나갑니다.

누군가 화면을 공유하면 도크에 작은 미리보기가 나타납니다. 클릭하여 통화를 볼 수 있습니다.

통화 보기

통화는 세 가지 위치에 표시될 수 있습니다:

  • 주 영역에서 메시지를 대신하여: 대화 헤더 또는 도크에서 통화 표시를 클릭합니다. 동시에 대화에서 읽고 쓰기 위해 헤더에서 통화 옆에 메시지 표시를 클릭하면, 오른쪽 패널에 메시지가 열립니다. 통화 컨트롤의 통화 채팅은 통화 옆에 해당 통화의 글타래를 엽니다.
  • 작은 플로팅 창에서 드래그하여 원하는 위치로 이동할 수 있습니다: Ctrl+Shift+P(Mac에서는 ⌘+Shift+P)를 누르세요. 사이드바로 돌아가기를 클릭하면 창이 닫히지만 통화는 계속 유지됩니다.
  • 별도의 창에서: 통화 컨트롤에서 새 창에서 열기를 클릭하세요. 브라우저가 팝업 창을 차단하는 경우, 통화는 플로팅 창 대신 열립니다. 창을 닫으면 통화가 Antimatter로 다시 돌아옵니다.

각 사용자는 타일을 가집니다. 타일에서 스테이지에 고정을 클릭하거나 더블클릭하면 해당 사용자를 크게 유지할 수 있으며, 고정 해제를 클릭하면 되돌릴 수 있습니다. 카메라나 공유된 화면에서 화면 속 화면은 브라우저가 지원하는 경우 다른 창 위에 항상 표시되도록 하고, 전체 화면은 공유된 화면을 전체 화면으로 표시합니다.

통화 중

통화 아래 컨트롤을 사용하여 다음을 수행할 수 있습니다:

버튼기능
음소거 / 음소거 해제마이크를 끄거나 켭니다. 단축키: Ctrl+Shift+Space(Mac에서는 ⌘+Shift+Space).
헤드셋 음소거음성 채널에서 통화를 듣지 않도록 합니다.
카메라비디오가 허용되는 경우 카메라를 켜거나 끕니다.
화면 공유 / 공유 중지화면, 창 또는 브라우저 탭을 공유합니다. 단축키: Ctrl+Shift+E.
손 들기 / 손 내리기말할 수 있도록 요청합니다. 단축키: Ctrl+Shift+Y.
반응 남기기몇 초 동안 통화 위에 떠다니는 빠른 반응을 보냅니다.
실시간 자막 표시통화가 녹취되는 동안 사람들이 말하는 내용을 텍스트로 표시합니다.
통화 녹화 / 녹화 중지관리자가 녹화를 활성화한 경우, 통화 호스트는 통화를 녹화할 수 있습니다(자세한 내용은 통화 녹화 참고).
통화 채팅대화에서 시작된 통화의 글타래를 엽니다.
새 창에서 열기통화를 별도의 창으로 이동합니다.
연결 해제통화를 나갑니다.

Mac에서는 이러한 단축키에서 Ctrl가 ⌘입니다. 설정 › 키보드에서 변경할 수 있습니다.

비디오

관리자가 비디오를 비활성화했거나 채널에서 비디오가 꺼져 있지 않는 한, 통화가 가능한 곳에서 카메라가 작동합니다. 음성 채널에서는 음성 채널이 비디오를 허용할 때 작동합니다. 다른 곳에서는 카메라 버튼에 "이 통화에서 카메라가 꺼져 있습니다"라고 표시됩니다. 카메라 버튼의 작은 화살표를 클릭(카메라 옵션)하여 내 배경 흐리게를 켜고 강도를 선택할 수 있습니다: 약하게, 보통 또는 강하게.

화면 공유

  1. 화면 공유를 클릭합니다. 무엇을 어떻게 공유할지 선택하려면 먼저 그 작은 화살표(화면 공유 옵션)를 클릭합니다.
  2. 화면 공유에서 화면 전체, 창 또는 브라우저 탭를 선택하세요(일부 브라우저에서는 화면 또는 창 선택…만 제공됨). 해상도를 480p에서 소스까지, 프레임 속도를 15, 30 또는 60fps로 선택할 수도 있습니다. Antimatter는 선택 사항을 기억합니다.
  3. 그 후 나타나는 대화 상자에서 공유할 화면이나 창을 선택합니다.

한 번에 한 명만 화면을 공유할 수 있습니다. 데스크톱 앱에서는 Antimatter가 자체 선택기인 공유할 항목 선택을 표시하며, 여기에 화면과 창가 나열됩니다. Windows와 Linux에서는 컴퓨터 소리도 함께 공유를 선택할 수 있습니다. Mac에서는 시스템이 앱의 화면 녹화를 허용하도록 한 번만 묻습니다.

손 들기

말하고 싶다는 것을 표시하려면 손 들기를 클릭합니다. 타일에 손 모양과 대기 순서가 표시됩니다. 예를 들어 "손 들음, 1번째"와 같이요. 끝나면 손 내리기를 클릭합니다.

다른 사람의 볼륨 변경

사람의 타일을 우클릭하거나, 사이드바의 음성 채널 아래에 있는 이름을 우클릭한 후 볼륨 슬라이더를 이동합니다. Antimatter는 이 브라우저에서 해당 사람에 대해 이를 기억합니다.

누르면 말하기

음소거 상태를 유지하면서 키를 누르는 동안만 말하고 싶다면, 설정 › 키보드로 이동하여 통화 중 누르면 말하기 (누름) 옆의 변경을 클릭하고 원하는 키를 누릅니다. 통화 중에는 해당 키를 길게 눌러 말하면 됩니다. Antimatter 창이 맨 앞에 있을 때 작동합니다.

음소거 및 기타 진행자 작업

통화 호스트(처음에는 통화를 시작한 사람)와 채널 및 커뮤니티 관리자는 통화를 관리할 수 있습니다. 음성 채널에서는 커뮤니티 모더레이터도 통화를 관리할 수 있습니다. 사용자를 마우스 오른쪽 단추로 클릭하여 메뉴를 열면, "…에서" 섹션에서 모더레이터는 다음을 찾을 수 있습니다:

  • 음소거: 말하고 있는 사람을 음소거합니다. 해당 사람은 스스로 음소거를 해제할 수 있습니다.
  • 음소거 해제 요청: 음소거된 사용자에게 발언을 요청합니다. 해당 사용자는 "…님이 음소거 해제를 요청합니다"라는 메시지와 함께 음소거 해제 및 나중에 버튼을 봅니다.
  • 이 통화에서 음소거: 사용자가 나갔다 돌아와도 허용할 때까지 음소거 상태를 유지합니다. 음소거 해제 허용을 통해 이를 해제할 수 있습니다.
  • 손 내리기 및 화면 공유 중지.
  • 통화에서 제거 또는 음성 채널에서 내보내기를 선택합니다.
  • 호스트로 지정: 호스트 및 시스템 관리자가 사용할 수 있으며, 이 작업을 수행하면 해당 사용자에게 호스트 권한이 이관됩니다.

모더레이터가 통화에 대해 음소거를 설정한 경우, 마이크 버튼에 "모더레이터가 음소거했습니다"라고 표시되며, 허용을 받으면 음소거를 해제할 수 있습니다.

모든 사용자는 해당 메뉴에서 프로필, 메시지, 통화, 사용자 이름 복사 및 볼륨을 찾을 수 있습니다.

모두에게 통화를 종료

통화를 나가는 것은 다른 참여자에게는 통화를 종료하지 않습니다. 모든 참여자에게 통화를 종료하려면 먼저 통화를 나가야 합니다. 그러면 대화 내 통화 카드에서 통화를 시작한 사람과 통화를 관리할 수 있는 사용자에게 참여 옆에 모두에게 통화 종료가 표시됩니다. 통화 종료를 확인하면 통화 중인 모든 사용자가 연결이 끊어집니다.

통화 녹화

관리자가 녹화를 활성화한 경우, 통화 호스트는 컨트롤에서 통화 녹화를 클릭할 수 있습니다. 그러면 통화 참여자 모두 녹화 배지를 볼 수 있습니다. 호스트가 녹화 중지를 클릭하거나 통화가 종료되면, 녹화 파일은 통화의 글타래에 게시됩니다. 음성 채널의 통화는 녹화할 수 없습니다.

녹취록 및 실시간 자막

관리자가 녹취록을 설정한 경우, 통화를 시작한 사람은 컨트롤에서 통화 녹취를 클릭할 수 있습니다. 그러면 모든 사람이 녹취 중 배지를 보게 되며, 모든 사람의 발언이 텍스트로 변환됩니다. 호스트가 녹취 중지를 클릭하거나 통화가 종료되면, 녹취록은 통화의 글타래("통화 녹취록입니다")에 텍스트 파일로 게시되거나, 음성 채널의 경우 해당 채널에 게시됩니다.

통화가 녹취되는 동안, 관리자가 실시간 자막을 켠 경우, 실시간 자막 표시를 클릭하여 통화 하단에 화자의 이름과 함께 마지막 발언 내용을 볼 수 있습니다. 실시간 자막 숨기기를 클릭하여 숨길 수 있습니다. AI 에이전트가 설정된 경우, 녹취록을 기반으로 회의 요약을 작성할 수 있습니다: AI 에이전트를 참조하세요.

마이크, 스피커 및 카메라 선택

  1. 설정을 엽니다(우측 상단의 프로필 사진을 클릭한 후 프로필 및 설정을 선택).
  2. 플러그인에서 통화를 선택합니다.
  3. 오디오 장치에서 편집을 클릭하여 마이크 입력과 스피커 출력을 선택한 후 저장합니다.
  4. 비디오가 사용 가능한 경우, 비디오 장치에서 카메라 입력을 선택하고, 비디오를 거울 반사하며, 배경 흐림을 설정할 수 있습니다.
  5. 화면 공유 설정에서 공유하는 콘텐츠의 소리를 포함할지 여부(화면과 함께 소리 공유)를 설정합니다.

통화 중, 카메라 옵션의 카메라 및 마이크 설정…을 클릭하면 동일한 페이지가 열립니다. Antimatter가 마이크를 사용할 수 없는 경우, 예를 들어 "통화에서 말하려면 마이크 접근을 허용하세요"와 같은 메시지가 표시됩니다. 브라우저 또는 시스템 설정에서 이를 허용하세요.

모바일 앱에서 통화

모바일 앱은 통화와 음성 채널을 시작하고 참여할 수 있으며, 음소거, 완전 음소거, 손 들기 및 실시간 자막을 사용할 수 있습니다. 카메라, 푸시 투 토크, 개인별 볼륨은 지원되지 않습니다. 데스크톱 및 모바일 앱을 참조하세요.
