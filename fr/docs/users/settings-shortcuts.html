Paramètres et raccourcis clavier

Personnalisez l'apparence et le comportement d'Antimatter : thèmes, affichage, langue, heure et raccourcis clavier.

Ouvrir vos paramètres

Cliquez sur votre photo en haut à droite de la fenêtre, puis sur Profil et paramètres. Vous pouvez également appuyer sur Ctrl+Shift+A (⌘+Shift+A sur Mac), ou taper /settings. Vos paramètres sont enregistrés à mesure que vous les modifiez, et vous suivent sur tous les appareils depuis lesquels vous êtes connecté.

Les paramètres sont regroupés dans des panneaux :

Sous Plugins, certaines applications ajoutent leurs propres paramètres, comme Appels pour votre micro et votre caméra. Si vous êtes administrateur système, les paramètres lient également à la Console système.

Thèmes et affichage

Choisir un thème

Dans Paramètres › Apparence, sous Thème, choisissez Sombre, OLED (noir pur, pour les salles sombres et les écrans OLED), Léger, ou Système, qui suit le mode clair ou sombre de votre ordinateur, même s'il change au cours de la journée.

Pour créer le vôtre, cliquez sur Personnalisé. Sous Couleurs personnalisées, définissez chaque couleur : Barre latérale principale, Barres latérales, Zone de discussion, Champs de saisie et cartes, Bordures, Texte, Texte secondaire, Accent et Liens. Partir du thème Antimatter les réinitialise.

Partager un thème

Un thème peut être transmis sous forme d'un code court commençant par am1:. Sous Partager un thème, cliquez sur Copier le code de mon thème et envoyez-le à quelqu'un. Pour utiliser un code reçu, collez-le dans le champ et cliquez sur Appliquer.

Affichage

  • Affichage des messages : Standard, ou Compact, qui permet d'afficher plus de messages à l'écran, sans images et avec des lignes plus serrées.
  • Noms en couleur : attribuer à chaque personne dans les messages une couleur qui lui est propre. Les couleurs de rôle définies par votre communauté ont la priorité.
  • Disponibilité sur les photos de profil : indiquer si les personnes sont en ligne sur leurs photos de profil dans les messages.
  • Indiquer quand vous étiez en ligne pour la dernière fois : permettre aux autres de voir « Dernière connexion… ».
  • Largeur des messages : Largeur pleine, ou Centré pour une lecture plus aisée sur un grand écran.
  • Afficher les noms sous forme de : Nom d'utilisateur, Pseudo ou Nom complet, sauf si votre administrateur a choisi pour tout le monde.
  • Horloge 24 heures : affichez les heures comme 16:00 au lieu de 4:00 PM.
  • Regrouper les canaux non lus : regrouper les canaux non lus dans une section Non lus en haut de la barre latérale.
  • Conversations ouvertes : le nombre de messages personnels que la barre latérale liste.

L'interface classique

L'interface d'Antimatter est celle décrite dans ce guide. Si votre administrateur l'autorise, Interface web dans Paramètres › Apparence vous permet de passer à Classique (obsolète), l'ancienne interface conservée pour la compatibilité, et de revenir à Fusion. Le choix s'applique à tous les navigateurs depuis lesquels vous vous connectez. Les menus et les boutons diffèrent dans l'interface classique.

Paramètres des messages

Paramètres › Messages définit l'apparence des conversations et la façon dont vous écrivez. Selon votre serveur, il propose :

  • Garder les réponses dans les fils de discussion : les réponses aux fils de discussion restent dans leur fil au lieu d'être également affichées dans le canal.
  • Aperçus de liens : affichez une carte d'aperçu pour les sites web liés dans les messages.
  • Convertir les émoticônes en emojis : afficher :) et <3 sous forme d'emojis.
  • Heures dans votre fuseau horaire : mettez en évidence les heures écrites dans les messages, avec votre propre heure lorsque vous pointez dessus.
  • Messages d’arrivée et de départ : afficher quand les personnes rejoignent ou quittent les canaux.
  • Envoyer avec Ctrl+Entrée : Enter commence une nouvelle ligne, et Ctrl+Enter envoie.
  • Éditeur de texte enrichi (bêta) : visualisez la mise en forme pendant la saisie.
  • Synchroniser les brouillons : conservez vos messages non envoyés sur le serveur pour les finaliser sur un autre appareil.
  • Sous Lecture : Ouvrir les conversations non lues (Au dernier message lu ou Au message le plus récent), Afficher les images dépliées, Réactions en un clic, et Mise en forme des messages (désactivez-la pour voir les messages en texte brut).

Langue et fuseau horaire

Dans Paramètres › Langue et heure, choisissez la Langue de l'interface dans la liste. Antimatter s'adapte immédiatement.

Votre Fuseau horaire est affiché en dessous, généralement défini automatiquement à partir de votre ordinateur. Pour le modifier, cliquez sur Modifier… : cela ouvre le paramètre du fuseau horaire dans la fenêtre de paramètres classique, où vous pouvez désactiver le fuseau horaire automatique et en choisir un.

Votre fuseau horaire est également utile aux autres : c'est ainsi qu'Antimatter leur affiche votre heure locale et les avertit quand il est nuit chez vous.

Paramètres avancés

  • Mode streamer : masque votre adresse e-mail et les aperçus des conversations, et met en sourdine les notifications de bureau, par exemple pendant un partage d'écran.
  • Mode développeur : ajoute Copier l’ID aux menus des messages, des canaux, des communautés et des personnes, pour l'API et les bots.
  • Sous Débogage des performances, lorsque votre serveur le propose : Désactiver les plugins dans ce navigateur et Ne pas signaler quand j’écris, utile lorsque quelque chose ne fonctionne pas correctement.

Modifier un raccourci

  1. Ouvrir Paramètres › Clavier.
  2. Cliquez sur Modifier à côté d'une action, puis appuyez sur les nouvelles touches. Appuyez sur Esc pour annuler, ou sur Backspace pour désactier le raccourci.
  3. Si une autre action utilise les mêmes touches, la page vous avertit : « Une autre action utilise également ces touches ».
  4. Cliquez sur Annuler pour revenir aux touches d’origine.

Vous pouvez modifier les raccourcis pour la recherche, la liste des raccourcis, les paramètres, le filtre des non-lus et les appels. Les autres restent inchangés. Tous les raccourcis clavier… en bas de la page ouvre la liste complète.

Dans l'application de bureau

L'application de bureau ajoute ses propres raccourcis, affichés dans ses menus : par exemple Ctrl+F pour rechercher du texte dans la page, Ctrl+= et Ctrl+- pour zoomer, Ctrl+0 pour la taille réelle, Ctrl+R pour recharger, Alt+Left et Right (⌘+[ et ] sur Mac) pour naviguer en arrière et en avant, et Ctrl+Shift+1 à 9 (⌘+Ctrl+1 à 9 sur Mac) pour basculer entre les serveurs.
