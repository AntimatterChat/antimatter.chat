IA

Les fonctionnalités IA d'Antimatter utilisent des modèles de votre choix : un fournisseur cloud ou un serveur sur votre propre réseau. Rien n'est envoyé nulle part tant que vous n'avez pas configuré un modèle. Cette page détaille chaque fonctionnalité, les données qu'elle envoie et comment la désactiver.

Les fonctionnalités IA

FonctionnalitéConfiguration dansType de modèleActivé par défaut
Agents IA : discussion avec un bot, résumés de fils de discussion et de canaux, aide dans le composeurL'application AgentsTout service de grand modèle de langage (LLM)L'application est activée, mais ne fait rien tant que vous n'avez pas ajouté un service
Transcriptions d'appels et sous-titres en directL'application AppelsTranscription vocale, compatible OpenAInon
Lecture à voix hauteLe serveurSynthèse vocale, compatible OpenAInon
Traduction automatique des canauxLe serveurLibreTranslate, un LLM compatible OpenAI, ou un service Agentsnon

« Compatible OpenAI » désigne un serveur qui propose la même API HTTP qu'OpenAI. La plupart des serveurs de modèles que vous pouvez exécuter vous-même le font (par exemple Ollama, vLLM, le serveur de llama.cpp, ou les serveurs de transcription vocale et de synthèse vocale), tout comme de nombreux fournisseurs cloud. Aucune licence n'est requise pour aucune de ces fonctionnalités.

Agents IA

L'application Agents (id mattermost-ai) est activée par défaut. Sa configuration se fait en deux étapes : ajouter un service (une connexion à un fournisseur de modèles), puis créer des agents (des bots qui utilisent un service).

1. Ajouter un service

Accédez à Console système › Plugins › Agents et, sous Services IA, cliquez sur Ajouter un service IA. Choisissez le Type de service :

  • Compatible OpenAI : pour un serveur de modèle que vous exécutez vous-même, ou tout fournisseur disposant d’une API de type OpenAI. Renseignez URL de base de l’API (par exemple http://ollama:11434/v1 ou http://vllm.internal:8000/v1) et Clé API uniquement si le serveur en exige une. Si le serveur ne prend en charge que l’API Chat Completions, désactivez Utiliser l’API Responses.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral : fournisseurs hébergés. Chacun nécessite sa Clé API (Bedrock : une région AWS et des identifiants ou un rôle IAM ; Vertex AI : un projet, une région et un compte de service ; Azure : l’URL de l’API également).

Ensuite, définissez le Modèle par défaut (une liste si le fournisseur peut signaler ses modèles, sinon saisissez le nom), ainsi que, si le fournisseur ne les signale pas, la Limite de jetons d'entrée et la Limite de jetons de sortie. Un Service de secours peut prendre le relais en cas d'échec. Enregistrez.

Le serveur effectue ces requêtes lui-même, il doit donc pouvoir accéder à l'API : un serveur de modèle dans le même projet compose, sur votre réseau, ou sur Internet. Les requêtes sortantes respectent les variables HTTP_PROXY et HTTPS_PROXY.

2. Créer des agents

Les agents sont créés sur la page Agents de l'application web : ouvrez-la depuis le menu du produit, ou avec Gérer dans le sélecteur d'agents du panneau Agents. Son adresse est https://chat.example.com/plug/mattermost-ai/agents. Chaque agent a un Nom d'affichage, un Nom d'utilisateur d'agent (la façon dont les personnes le mentionnent), un Service et, en option, un modèle, des Instructions personnalisées, ainsi que des interrupteurs pour Activer la vision (images) et Activer les outils. Son onglet Accès limite les canaux dans lesquels il peut être utilisé et les utilisateurs qui peuvent l'utiliser. Sous Fonctions IA dans la Console système, Bot par défaut choisit l'agent utilisé lorsqu'aucun n'est sélectionné, par exemple pour les résumés d'appels.

Par défaut, chaque utilisateur peut créer ses propres agents, avec les services que vous avez configurés. Pour réserver cette fonctionnalité aux administrateurs, supprimez la permission Gérer ses propres agents IA du rôle des membres dans Console système › Gestion des utilisateurs › Permissions.

Fonctionnalités optionnelles de l'application Agents

  • Recherche par intégration (expérimental, désactivé) : recherche sémantique sur les messages. Elle nécessite PostgreSQL avec l'extension pgvector et un modèle d'intégration (OpenAI ou compatible OpenAI). Elle envoie chaque message au modèle d'intégration, y compris les canaux privés et les messages personnels.
  • Recherche web (désactivé) : permet aux agents de rechercher sur le web via Google, Brave ou un serveur SearXNG que vous exécutez.
  • Outils natifs : avec les fournisseurs qui les proposent, les agents peuvent utiliser la recherche web propre du fournisseur (activée par défaut pour les nouveaux agents, si supportée), la récupération web et l'exécution de code. Ces opérations s'exécutent chez le fournisseur. Désactivez-les par agent.
  • Protocole de contexte de modèle (MCP) : connectez les agents à des serveurs MCP auxquels vous faites confiance, pour des outils supplémentaires.
  • Débogage : Sortie de trace (désactivé, journaux du serveur ou un point de terminaison OpenTelemetry) et Activer la journalisation de l'utilisation des jetons, qui écrit les nombres de jetons dans logs/agents/token_usage.log.

Conversion de la parole en texte : transcriptions d'appels et sous-titres

Les appels peuvent être transcrits, avec des sous-titres en direct, par un serveur de reconnaissance vocale offrant un point de terminaison /v1/audio/transcriptions compatible OpenAI. La configuration se trouve dans Appels et voix. Si Résumer les transcriptions est activé, l'agent par défaut publie également un résumé de chaque transcription.

Synthèse vocale : lecture à voix haute

Lorsque la synthèse vocale est activée, le menu de chaque message propose Lire à voix haute : le serveur envoie le texte du message à une API de synthèse vocale et lit l'audio. Paramètres dans Console système › Intégrations › Synthèse vocale :

ParamètreClé et variableCe qu'il faut saisir
Lire les messages à voix hauteTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (désactivé par défaut)
URL de base de l’APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLL'URL de base jusqu'à et y compris /v1, par exemple http://tts.internal:8000/v1. Le serveur appelle son point de terminaison /audio/speech.
ModèleTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELLe modèle tel que nommé par l'API, par exemple tts-1. Obligatoire.
VoixTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEL'une des voix du modèle, ou vide pour utiliser la voix par défaut.
Clé APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYEnvoyé en tant que jeton bearer. Vide si l'API n'en nécessite pas.

Avant l'envoi, le serveur supprime les blocs de code, les liens, les codes emoji et la mise en forme, et conserve au maximum 4000 caractères. Il demande un audio MP3 et conserve les 64 derniers résultats en mémoire, de sorte qu'un message lu deux fois n'est envoyé qu'une seule fois.

Traduction automatique

La traduction automatique affiche les messages d’un canal dans la langue de chaque lecteur. Configurez-la dans Console système › Configuration du site › Paramètres linguistiques, sous Traduction automatique :

ParamètreParamètreValeur par défaut
ActiverAutoTranslationSettings.EnableDésactivé
Fournisseur de traductionAutoTranslationSettings.Providerlibretranslate, openai (affiché comme « API compatible OpenAI ») ou agents (un service de l'application Agents)
Langues autoriséesAutoTranslationSettings.TargetLanguagesen : les langues dans lesquelles les messages peuvent être traduits
Délai d’attente de la traduction (ms)AutoTranslationSettings.TimeoutMs5000
Restreindre la traduction automatique aux messages personnels et aux messages de groupeAutoTranslationSettings.RestrictDMAndGMDésactivé

Chaque fournisseur a ses propres champs :

  • LibreTranslate : Point de terminaison de l’API LibreTranslate et Clé API LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Un serveur LibreTranslate peut être exécuté sur votre propre réseau.
  • API compatible OpenAI : URL de base de l’API (jusqu’à et y compris /v1 ; le serveur utilise son point de terminaison de complétion de discussion), Modèle et Clé API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Un petit modèle de traduction exécuté localement fonctionne bien.
  • Agents : Service IA, l'un des services configurés dans l'application Agents.

Une fois activée, les administrateurs de canal activent la traduction pour un canal dans ses paramètres (Traduction automatique), et chaque membre peut s’en exclure depuis le menu du canal (Traduire les messages). Dans les messages personnels et de groupe, n’importe quel membre peut l’activer ; avec la restriction activée, la traduction n’est pas disponible dans ces contextes. Les messages traduits affichent « Traduit de … » avec un lien vers l’original.

Le code, les liens, les mentions et les emojis sont remplacés par des espaces réservés avant l'envoi du texte, puis rétablis ensuite.

Où va chaque donnée

FonctionnalitéCe qui est envoyéÀ
AgentsLa requête, les messages du fil de discussion ou du canal concerné, les instructions de l'agent, les résultats des outils, les images lorsque la vision est activée, ainsi que le nom, l'identifiant, le poste et la langue de l'utilisateur qui pose la questionL'API du service
Recherche par intégrationChaque message (sauf les messages des bots et du système)L'API d'intégration
Outils natifs et recherche webRequêtes de recherche, pages à récupérer, codeLe fournisseur, ou le moteur de recherche choisi
Transcription d'appelLa voix de chaque personne qui parle pendant que la transcription est activéeL'API de transcription vocale
Lecture à voix hauteLe texte du message lu à voix hauteL'API de synthèse vocale
TraductionLe texte des messages dans les canaux traduitsLibreTranslate, l'API du LLM, ou le service Agents

Pour garder tout cela sur votre réseau, pointez chaque fonctionnalité vers des serveurs que vous exploitez vous-même. Avec un fournisseur cloud, vérifiez ses conditions de conservation des données et informez vos utilisateurs des fonctionnalités qui envoient leurs messages à l'extérieur.

Désactiver l'IA

Il n'y a pas d'interrupteur unique : chaque fonctionnalité a le sien.

  • Agents : désactivez l’application Agents dans Console système › Plugins › Gestion des plugins. Cela supprime également les résumés d’appels et le fournisseur de traduction Agents.
  • Transcription et sous-titres : AM_CALLS_ENABLE_TRANSCRIPTIONS=false et AM_CALLS_ENABLE_LIVE_CAPTIONS=false (les valeurs par défaut).
  • Lire à voix haute : désactivez Lire les messages à voix haute (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, la valeur par défaut).
  • Traduction : désactivez la traduction automatique (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, la valeur par défaut).

La désactivation de l'application Agents ne désactive pas les trois autres : elles appellent directement leurs propres API.
