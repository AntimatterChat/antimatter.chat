Politique de confidentialité

Dernière mise à jour : 16 octobre 2026.

Cette page couvre deux aspects : le logiciel Antimatter, que les organisations hébergent sur leurs propres serveurs, et ce site web, antimatter.chat.

Le logiciel Antimatter

Antimatter est auto-hébergé. Lorsque vous utilisez un serveur Antimatter, l'organisation qui l'exploite décide des données conservées, de leur durée de conservation et de qui y a accès. Le projet Antimatter n'a aucun accès à votre serveur, à votre compte ou à vos messages. Pour toute question concernant vos données sur un serveur particulier, contactez ses administrateurs ; leur propre politique de confidentialité s'applique.

Ce que le logiciel fait de lui-même :

  • Aucune télémétrie. Le serveur n'envoie pas de statistiques d'utilisation, de diagnostics ni aucune autre donnée au projet Antimatter, à Mattermost, Inc. (dont le logiciel est issu) ou à d'autres tiers.
  • Des connexions externes uniquement pour les fonctionnalités activées par un administrateur, vers les services qu'ils configurent : par exemple un service de notifications push, un fournisseur de GIF, un serveur de messagerie, un fournisseur d'identité pour l'authentification unique, ou des modèles d'IA, de reconnaissance vocale ou de traduction.
  • Deux exceptions, activées par défaut, que les administrateurs peuvent désactiver. Les aperçus de liens : lorsque quelqu'un publie un lien, le serveur récupère cette page pour afficher son titre et son image. Et les appels : ils utilisent le serveur STUN public de Cloudflare (stun.cloudflare.com) pour trouver les adresses réseau publiques. Le serveur l'interroge au démarrage de l'application Appels, et l'appareil de chaque personne l'interroge lorsqu'elle rejoint un appel. Cloudflare ne voit que l'adresse IP et le port du serveur et de chaque personne qui rejoint, pas l'appel lui-même. Les administrateurs peuvent utiliser leur propre serveur STUN, ou aucun ; voir Appels et vocal.
  • Les fonctionnalités d'IA utilisent les modèles choisis par l'administrateur. Lorsqu'ils sont hébergés par un tiers, ce qui leur est envoyé (un message à réécrire, une conversation à résumer, l'audio d'un appel transcrit) part vers ce fournisseur. Les administrateurs peuvent utiliser des modèles auto-hébergés pour que rien ne sorte de leur réseau.

Ce site web

  • antimatter.chat est un site web statique hébergé sur GitHub Pages.
  • Il ne définit aucun cookie et n'utilise aucun outil d'analyse, de suivi ou de publicité. Ses polices et images sont servies par le site lui-même, de sorte que votre navigateur n'effectue aucune requête vers d'autres sites web pendant que vous le consultez.
  • Comme tout hébergeur web, GitHub reçoit votre adresse IP et les pages que vous demandez, afin de les servir. Consultez la Déclaration de confidentialité de GitHub.
  • Si vous ouvrez une issue ou contribuez sur GitHub, ce que vous y publiez est public et géré par GitHub selon ses propres conditions.

Contact

Pour toute question concernant cette politique, ouvrez une issue dans le dépôt communautaire Antimatter.

Nous pouvons mettre à jour cette politique ; la date en haut indique la dernière modification.
