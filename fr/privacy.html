Politique de confidentialité

Dernière mise à jour : 11 octobre 2026. Cette traduction est fournie pour votre commodité ; en cas de divergence, la version anglaise fait foi.

Cette page traite de deux choses : le logiciel Antimatter, que les organisations exploitent sur leurs propres serveurs, et ce site web, antimatter.chat.

Le logiciel Antimatter

Antimatter est auto-hébergé. Lorsque vous utilisez un serveur Antimatter, c’est l’organisation qui l’exploite qui décide quelles données sont conservées, pendant combien de temps et qui peut y accéder. Le projet Antimatter n’a accès ni à votre serveur, ni à votre compte, ni à vos messages. Pour toute question sur vos données sur un serveur donné, contactez ses administrateurs ; c’est leur propre politique de confidentialité qui s’applique.

Ce que fait le logiciel de lui-même :

  • Aucune télémétrie. Le serveur n’envoie ni statistiques d’utilisation, ni diagnostics, ni aucune autre donnée au projet Antimatter ou à des tiers.
  • Des connexions externes uniquement pour les fonctionnalités activées par un administrateur, vers les services qu’il configure : par exemple un service de notifications push, les aperçus des sites web dont les liens sont publiés dans les messages, un fournisseur de GIF, un serveur de messagerie, un fournisseur d’identité pour l’authentification unique, ou des modèles d’IA, de reconnaissance vocale ou de traduction.
  • Les fonctionnalités d’IA utilisent les modèles choisis par l’administrateur. Lorsqu’ils sont hébergés par un tiers, le contenu qui leur est envoyé (un message à reformuler, une conversation à résumer, l’audio d’un appel transcrit) est transmis à ce fournisseur. Les administrateurs peuvent utiliser des modèles auto-hébergés pour que rien ne sorte de leur réseau.

Ce site web

  • antimatter.chat est un site web statique hébergé sur GitHub Pages.
  • Il ne dépose aucun cookie et n’utilise ni outil d’analyse, ni traceur, ni publicité. Ses polices et ses images sont servies par le site lui-même : votre navigateur n’envoie donc aucune requête à d’autres sites pendant que vous le consultez.
  • Comme tout hébergeur web, GitHub reçoit votre adresse IP et les pages que vous demandez, afin de vous les servir. Consultez la déclaration de confidentialité de GitHub.
  • Si vous ouvrez une issue ou contribuez sur GitHub, ce que vous y publiez est public et traité par GitHub selon ses propres conditions.

Contact

Pour toute question sur cette politique, ouvrez une issue sur le dépôt du site web.

Nous pouvons être amenés à modifier cette politique ; la date indiquée en haut de la page précise quand elle a été modifiée pour la dernière fois.
