隱私權政策

最後更新：2026 年 10 月 16 日。

本頁涵蓋兩項內容：由組織自行部署在伺服器上的 Antimatter 軟體，以及本網站 antimatter.chat。

Antimatter 軟體

Antimatter 採用自託管模式。當您使用 Antimatter 伺服器時，營運該伺服器的組織決定保留哪些資料、保留多久，以及誰可以存取。 Antimatter 專案無法存取您的伺服器、帳號或訊息。 若對特定伺服器上的資料有疑問，請聯絡該伺服器的管理員；其自身的隱私權政策將適用。

軟體本身執行的功能：

  • 無遙測。 伺服器不會向 Antimatter 專案、Mattermost, Inc.（Antimatter 所基於的軟體）或其他第三方傳送使用統計、診斷或任何其他資料。
  • 僅在管理員啟用的功能下才會建立外部連線，連接到其所設定的服務：例如推送通知服務、GIF 供應商、郵件伺服器、用於單一登入的身分驗證提供者，或 AI、語音或翻譯模型。
  • 有兩項預設開啟但管理員可關閉的例外。 連結預覽：當有人貼上連結時，伺服器會抓取該頁面以顯示其標題與圖片。以及通話：通話使用 Cloudflare 的公開 STUN 伺服器（stun.cloudflare.com）來尋找公共網路位址。伺服器會在通話應用程式啟動時向其查詢，而每位使用者的裝置會在加入通話時向其查詢。Cloudflare 只能看到伺服器及每位加入者的 IP 位址與埠號，無法看到通話內容。管理員可以改用自有的 STUN 伺服器，或完全不使用；請參閱 通話與語音。
  • AI 功能使用管理員選擇的模型。 若模型由第三方託管，則傳送至該提供者的內容（例如要改寫的訊息、要摘要的對話、已轉錄通話的音訊）將送往該提供者。管理員可以使用自託管模型，以確保沒有任何資料離開其網路。

本網站

  • antimatter.chat 是一個託管在 GitHub Pages 上的靜態網站。
  • 本站不設定 Cookie，也不使用任何分析、追蹤或廣告工具。字型與圖片皆由本站自行提供，因此您在閱讀時，瀏覽器不會向其他網站發出請求。
  • 如同任何網頁主機，GitHub 會接收您的 IP 地址與您請求的頁面，以便提供服務。請參閱GitHub 隱私權聲明。
  • 如果您在 GitHub 上開啟問題或進行貢獻，您發布的內容將為公開，並由 GitHub 依其自身條款處理。

聯絡方式

若對本政策有任何疑問，請在Antimatter 社群儲存庫中開啟問題。
