執行伺服器

本指南適用於安裝並執行 Antimatter 伺服器的系統管理員。假設您熟悉 Linux、Docker 和反向代理，但不熟悉 Antimatter。

部署的組成

Antimatter 是一款自託管的團隊聊天工具，是 Mattermost 的分支。完整的部署包含以下部分，其中僅前三項為必要。

部分功能說明必要
Antimatter 伺服器一個 Go 程式（antimatter），在 8065 埠上提供網頁應用程式、API 和 WebSocket 服務，執行內建應用程式（外掛程式），並在 8443 埠上承載通話媒體。使用命令列工具 amctl 進行管理。是
PostgreSQL資料庫：儲存訊息、使用者、社群，以及在建議設定中儲存伺服器的設定。版本需為 15 或更新。是
檔案儲存上傳的檔案、圖片和已安裝的應用程式：使用 S3 相容服務（Compose 檔案執行 RustFS）或本地目錄。是
反向代理在伺服器前提供 HTTPS：使用 Compose 檔案的 Caddy 設定檔，或您自己的 nginx。用於生產環境
GIF 服務（gifs-server）為 GIF 選擇器提供 GIF 和貼紙，來自您自己的目錄。它使用 Tenor API。否
推送代理透過 Apple 和 Google 將通知轉發至行動應用程式。用於行動通知
rtcd、TURN 伺服器用於大量通話的獨立媒體伺服器，以及供位於嚴格防火牆後的使用者使用的中繼。否
AI 端點驅動輸入欄重寫、摘要、翻譯、朗讀、AI 代理程式與通話文字轉錄的模型，以模型連線的方式加入：雲端供應商或您自行運行的伺服器。否

Antimatter 沒有授權限制或付費版本：單一登入、LDAP、高可用性、合規性匯出、資料保留以及 Mattermost 保留給付費方案的其它功能，全部包含在內。

需求

  • 一台 Linux 伺服器，amd64 或 arm64，供數百人使用時需具備 2 個 CPU 核心和 4 GB 以上的記憶體，以及供使用者上傳檔案的磁碟空間。
  • 搭配 Compose 外掛的 Docker Engine（docker compose），用於建議的安裝方式。或者，若要使用套件，則需具備 systemd 的 Debian、Ubuntu、Fedora 或 RHEL 相容伺服器。
  • 用於生產環境：指向伺服器的網域名稱，並開啟 80 和 443 埠以進行 HTTPS。
  • 用於通話：8443 埠，UDP 和 TCP，需可被通話的使用者存取。
  • 用於電子郵件：Antimatter 可透過其發送郵件的 SMTP 伺服器。

快速入門

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)
EOF
docker compose up -d

接著開啟網站網址並建立您的帳號：第一個建立的帳號將成為系統管理員。安裝 說明每個步驟以及其他安裝方式。

本指南內容

  • 安裝：Docker Compose、映像檔、首位管理員、.deb 與 .rpm 套件，以及發行版檔案。
  • 設定：資料庫或檔案中的設定、AM_ 環境變數、系統控制台、amctl、日誌。
  • 網域與 HTTPS：網站網址、Caddy、nginx、用戶端位址。
  • 通話與語音：埠號、NAT、TURN、rtcd、文字轉錄與即時字幕。
  • 電子郵件與推送：SMTP、推送代理程式與行動應用程式。
  • 內建應用程式：哪些應用程式已啟用、其設定、安裝其他應用程式。
  • AI：模型連線、內建 AI 功能、代理程式、語音與翻譯、加密金鑰，以及資料流向。
  • 登入與帳號：註冊、密碼、多因素驗證、單一登入、LDAP、訪客、工作階段。
  • 備份與升級：備份、還原、升級、從 Mattermost 遷移。
  • 營運：監控、擴展、資料保留、合規性、疑難排解。
  • 安全性：強化檢查清單與外部連線。
  • 桌面應用程式部署：MSI、群組原則與 Intune、macOS 設定檔，以及 Linux 原則檔案。

要營運社群而非伺服器（頻道、角色、內容管理）？請參閱 營運社群。要建置整合？請參閱 在 Antimatter 上建置。

您的第一個小時

  1. 安裝並立即建立管理員帳號。
  2. 將伺服器放在 HTTPS 後端，並使用專屬網域。
  3. 設定 SMTP 並傳送一封測試電子郵件。
  4. 開啟通話埠。若為公司使用，請將新社群的類型設為工作場所，以便在頻道中啟用通話。
  5. 決定誰可以註冊，並啟用多因素驗證。
  6. 檢視 安全性 中的外部連線。
  7. 設定每日備份。在加入 AI 模型連線之前，請先設定 AI 加密金鑰。

在社群討論區提出問題，並在社群儲存庫回報錯誤。請依安全政策的說明，私下回報安全問題。
