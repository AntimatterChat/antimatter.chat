AI

Antimatter 的 AI 功能使用您選擇的模型：雲端供應商，或您自己網路上的伺服器。在您設定模型之前，不會有任何資料被傳送。本頁涵蓋各項功能、其傳送的資料，以及如何關閉。

AI 功能

功能設定位置模型類型預設開啟
AI 代理程式：與機器人對話、討論串與頻道的摘要、輸入框中的協助代理程式應用程式任何大型語言模型 (LLM) 服務應用程式已開啟，但在您新增服務之前不會執行任何動作
通話文字轉錄與即時字幕通話應用程式文字轉錄，相容於 OpenAI否
朗讀伺服器文字轉語音，相容於 OpenAI否
頻道的自動翻譯伺服器LibreTranslate、相容於 OpenAI 的 LLM，或代理程式服務否

「相容於 OpenAI」是指提供與 OpenAI 相同 HTTP API 的伺服器。大多數您可以自行執行的模型伺服器都支援（例如 Ollama、vLLM、llama.cpp 的伺服器，或 Whisper 和文字轉語音伺服器），許多雲端供應商也支援。這些功能均不需要授權。

AI 代理程式

代理程式應用程式 (id mattermost-ai) 預設為開啟。設定需要兩個步驟：新增一個服務（與模型供應商的連線），然後建立代理程式（使用該服務的機器人）。

1. 新增服務

前往 系統控制台 › 擴充程式 › 代理程式，在 AI Services 下方，按一下 Add an AI Service。選擇 Service type：

  • OpenAI 相容：適用於您自行執行的模型伺服器，或任何具有 OpenAI 風格 API 的供應商。填寫API URL（例如 http://ollama:11434/v1 或 http://vllm.internal:8000/v1），僅在伺服器需要時填寫API 金鑰。如果伺服器僅支援 Chat Completions API，請關閉使用 Responses API。
  • OpenAI、Anthropic、Google Gemini、Google Vertex AI、AWS Bedrock、Azure、Cohere、Mistral：託管供應商。每個都需要其API 金鑰（Bedrock：AWS 區域和憑證或 IAM 角色；Vertex AI：專案、區域和服務帳戶；Azure：也需要 API URL）。

接著設定預設模型（若供應商能回報其模型清單，則從清單中選擇；否則請輸入模型名稱），以及（若供應商未回報）輸入 Token 上限和輸出 Token 上限。您可以設定備援服務，當此服務失敗時由其接管。完成後儲存。

伺服器會自行發出這些請求，因此必須能連接到 API：可以是同一個 compose 專案中的模型伺服器、您網路中的伺服器，或是網際網路上的伺服器。外發請求會遵循 HTTP_PROXY 和 HTTPS_PROXY 變數。

2. 建立代理程式

代理程式是在網頁應用程式的代理程式頁面建立的：您可以從產品選單開啟，或在代理程式面板的代理程式選擇器中使用管理。其網址為 https://chat.example.com/plug/mattermost-ai/agents。每個代理程式都有顯示名稱、代理程式使用者名稱（供他人提及使用）、服務，以及選填的模型、自訂指令，以及啟用視覺（影像）和啟用工具的開關。其存取分頁可限制該代理程式可在哪些頻道使用，以及哪些使用者可以使用它。在系統控制台的AI 功能中，預設機器人用於選擇在未指定代理程式時所使用的代理程式，例如用於通話摘要。

預設情況下，每位使用者都可以使用您設定的服務建立自己的代理程式。若要將此權限僅保留給管理員，請在系統控制台 › 使用者管理 › 權限中，從成員角色移除管理自己的 AI 代理程式權限。

代理程式應用程式的選填功能

  • 嵌入搜尋（實驗性，已停用）：對訊息進行語意搜尋。需要支援 pgvector 擴充功能的 PostgreSQL 以及嵌入模型（OpenAI 或相容於 OpenAI 的模型）。它會將每一則訊息（包括私人頻道和私人訊息）傳送至嵌入模型。
  • 網頁搜尋（已停用）：讓代理程式透過 Google、Brave 或您自行運行的 SearXNG 伺服器搜尋網頁。
  • 原生工具：若供應商提供，代理程式可使用供應商自有的網頁搜尋（對於支援的新代理程式，預設為開啟）、網頁抓取和程式碼執行。這些操作在供應商端執行。您可以針對每個代理程式關閉這些功能。
  • 模型上下文協定 (MCP)：將代理程式連接至您信任的 MCP 伺服器，以獲得更多工具。
  • 偵錯：Trace Output（關閉、伺服器記錄或 OpenTelemetry 端點）以及 Enable Token Usage Logging，此選項會將 token 數量寫入 logs/agents/token_usage.log。

語音轉文字：通話文字轉錄與即時字幕

通話可由提供 OpenAI 相容 /v1/audio/transcriptions 端點的語音轉文字伺服器進行文字轉錄，並提供即時字幕。設定方式請參閱通話與語音。開啟摘要文字轉錄後，預設代理程式也會為每份轉錄內容發布摘要。

文字轉語音：朗讀

開啟文字轉語音後，每則訊息的選單中都會出現朗讀選項：伺服器會將訊息文字傳送至文字轉語音 API 並播放音訊。設定位於系統控制台 › 整合 › 文字轉語音：

設定金鑰與變數應填入的內容
朗讀訊息TextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue（預設為關閉）
API 基礎 URLTextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URL包含 /v1 在內的基礎 URL，例如 http://tts.internal:8000/v1。伺服器將呼叫其 /audio/speech 端點。
模型TextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELAPI 所命名的模型，例如 tts-1。必填。
語音TextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICE模型其中一種語音，或留空以使用預設值。
API 金鑰TextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEY作為 Bearer Token 傳送。若 API 不需要金鑰，則留空。

傳送前，伺服器會移除程式碼區塊、連結、表情符號代碼與格式，並保留最多 4000 個字元。它要求 MP3 音訊格式，並在記憶體中保留最近 64 個結果，因此同一則訊息若被朗讀兩次，只會傳送一次。

自動翻譯

自動翻譯功能可將頻道的訊息顯示為每位讀者自己的語言。請在系統控制台 › 網站設定 › 區域化下的自動翻譯中進行設定：

設定金鑰預設值
啟用AutoTranslationSettings.Enable關閉
翻譯供應商AutoTranslationSettings.Providerlibretranslate、openai（顯示為「OpenAI 相容 API」）或 agents（代理程式應用程式的服務）
允許的語言AutoTranslationSettings.TargetLanguagesen：訊息可被翻譯成的語言
翻譯逾時（ms）AutoTranslationSettings.TimeoutMs5000
限制私人訊息與群組訊息的自動翻譯AutoTranslationSettings.RestrictDMAndGM關閉

每個供應商都有各自的欄位：

  • LibreTranslate：LibreTranslate API 端點與LibreTranslate API 金鑰（AutoTranslationSettings.LibreTranslate.URL、.APIKey）。LibreTranslate 伺服器可運行在您自己的網路上。
  • OpenAI 相容 API：API 基礎 URL（包含 /v1 在內；伺服器使用其聊天完成端點）、模型與API 金鑰（AutoTranslationSettings.OpenAI.URL、.Model、.APIKey）。在本地運行的輕量級翻譯模型效果良好。
  • 代理程式：AI 服務，即代理程式應用程式中設定的一種服務。

開啟後，頻道管理員可在頻道的設定中（自動翻譯）為該頻道啟用翻譯功能，而每位成員可透過頻道選單（翻譯訊息）選擇退出。在私人訊息與群組訊息中，任何成員皆可開啟此功能；若已啟用限制，則這些情境中無法使用翻譯。已翻譯的訊息會顯示「已從……翻譯」，並附上連結指向原始訊息。

在傳送文字之前，程式碼、連結、提及與表情符號會被替換為佔位符，之後再還原。

資料流向

功能傳送內容目的地
代理程式請求、所關聯討論串或頻道的訊息、代理程式的指令、工具結果、開啟視覺功能時的圖片，以及提問者的姓名、使用者名稱、職位與語言該服務的 API
嵌入搜尋所有訊息（機器人與系統訊息除外）嵌入 API
原生工具與網頁搜尋搜尋查詢、要抓取的頁面、程式碼供應商或您選擇的搜尋引擎
通話文字轉錄開啟期間所有發言者的聲音語音轉文字 API
朗讀正在朗讀的訊息文字文字轉語音 API
翻譯已翻譯頻道中的訊息文字LibreTranslate、LLM API 或代理程式服務

若要將所有資料保留在您的網路內，請將各項功能指向您自行執行的伺服器。若使用雲端供應商，請核對其資料保留條款，並告知使用者哪些功能會將訊息傳送至外部。

關閉 AI

沒有單一開關：每項功能都有各自的開關。

  • 代理程式：在 系統控制台 › 擴充程式 › 擴充程式管理 中停用 Agents 應用程式。這也會移除通話摘要和 Agents 翻譯提供者。
  • 文字轉錄與即時字幕：AM_CALLS_ENABLE_TRANSCRIPTIONS=false 與 AM_CALLS_ENABLE_LIVE_CAPTIONS=false（預設值）。
  • 朗讀：關閉 朗讀訊息（AM_TEXTTOSPEECHSETTINGS_ENABLE=false，預設值）。
  • 翻譯：關閉自動翻譯（AM_AUTOTRANSLATIONSETTINGS_ENABLE=false，預設值）。

停用代理程式應用程式不會關閉其他三項功能：它們會直接呼叫各自的 API。
