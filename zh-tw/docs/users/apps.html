應用程式

Antimatter 內建了與聊天並行運作的應用程式：可共同編輯的筆記與白板、看板、行事曆與郵件、投票、待辦事項等。以下是如何開啟每個應用程式及其用途。

尋找並開啟應用程式

您的管理員會決定您的伺服器有哪些應用程式，因此您可能不會在此頁面上看到所有應用程式。大多數應用程式在應用程式欄中都有圖示，該欄位於視窗右側邊緣、您的頭像下方。將滑鼠指標移到圖示上可看到應用程式名稱，點擊即可在對話旁邊的面板中開啟應用程式。再次點擊可關閉面板。拖曳面板邊緣可調整寬度；恢復預設寬度可將其恢復原狀。

應用程式也會出現在其他位置：

  • 訊息框的+選單（新增檔案及其他內容），例如建立投票。
  • 表情符號選擇器的分頁：GIFs、貼紙和迷因。
  • 訊息更多動作選單中的訊息動作部分，例如加入待辦事項或執行操作手冊。
  • 斜線指令，例如 /poll 或 /todo：輸入 / 即可查看清單。
  • 完整頁面：看板和操作手冊列在應用程式欄底部的關於 Antimatter選單中的產品下。其面板也有以完整頁面開啟按鈕。
  • 部分應用程式的設定位於您的設定中的擴充程式下。

在手機上，應用程式欄位於右側的抽屜中：向左滑動，或在對話標題中選擇更多 › 成員與應用程式。

Notes

筆記是多人可同時在聊天旁邊編輯的文件。當其他人輸入時，您會看到他們的游標和名稱，且內容會即時儲存。

撰寫筆記

  1. 點擊應用程式欄中的筆記。
  2. 選擇分頁：此頻道用於所有頻道成員皆可讀取和編輯的筆記，或我的用於僅您可見的個人筆記。
  3. 點擊+（在此頻道新增筆記或新增個人筆記）。將開啟一個「未命名筆記」。
  4. 輸入標題，然後開始撰寫。格式工具列包含粗體、斜體、刪除線、標題、清單和核取清單；連結、引用和程式碼也可使用。輸入 @ 可提及頻道的成員（筆記中的提及不會通知任何人）。
  5. 按一下 所有筆記 即可返回清單。

當頻道中的筆記有了標題後，Antimatter 會在該頻道中發布「已分享筆記」，並附上 開啟筆記 按鈕。

筆記的更多功能

將筆記加星號，即可在 我的最愛 分頁中找到它。筆記的 ⋯ 選單提供 分享至頻道（發布一張連結至該筆記的卡片）、分享至 ~頻道（永久將個人筆記轉為頻道筆記）、版本歷史（檢視並 復原至此版本）、匯出為 Markdown 以及 刪除。只有筆記的創作者和頻道管理員可以刪除頻道筆記。

Whiteboard

白板是一塊可以共同繪製的畫布：包含形狀、箭頭、文字和自由繪圖，並即時顯示所有人的指標。

  1. 按一下應用程式欄中的 白板。
  2. 與筆記相同，選擇 此頻道 或 我的，然後按一下 +（在此頻道新增看板 或 新增個人看板）。
  3. 使用工具進行繪製：選取並移動 (V)、移動視圖 (H)、矩形 (R)、橢圓 (O)、箭頭 (A)、繪製 (P)、文字 (T) 和 橡皮擦 (E)。在工具列中選擇顏色、線條樣式和字體，並在 圖庫 中選擇形狀。復原 (Ctrl+Z) 可復原您最後的變更。

看板操作 選單包含 全螢幕、顯示整個看板、下載為 .excalidraw、PNG 或 SVG、版本歷史、匯入 .excalidraw 檔案…（這將取代所有人的看板）、分享至頻道，以及 刪除。白板會保留在您的 Antimatter 伺服器上。

Kanban

看板將工作組織為欄位中的卡片，例如「待辦事項」、「進行中」和「已完成」。看板也可以以表格、畫廊或行事曆的形式顯示。

開啟頻道的看板

按一下應用程式欄中的 看板。面板會列出連結至該頻道的看板；按一下其中一個即可開啟。如果尚未連結任何看板，請按一下 連結看板至 …，然後在目標看板旁按一下 連結，或 建立看板。頻道的成員將成為已連結看板的編輯者。

使用看板

  • 若要查看所有看板，請以完整頁面開啟看板：在面板中選擇 以完整頁面開啟，或前往 關於 Antimatter › 產品 › 看板。
  • 若要建立看板，請按一下 + 新增看板，然後從範本開始（會議議程、專案任務、路線圖、衝刺規劃者等），或 建立空白看板。
  • 在欄位中點擊 + 新增 以新增卡片。開啟卡片後可設定其屬性、新增文字、核取方塊與圖片、附加檔案並留言。在卡片中提及某人時，系統會通知該使用者。
  • 將卡片拖曳至不同欄位。使用 分組、過濾器、排序 與 搜尋卡片 來快速定位，並使用 新增檢視 切換為表格、畫廊或行事曆檢視。
  • 在看板上使用 分享 功能，選擇誰可以查看或編輯該看板。

Calendar

行事曆應用程式會將您的個人行事曆顯示在聊天介面旁，發送提醒，並讓您在 Antimatter 中進行會議。它支援使用 CalDAV 協定的行事曆伺服器，例如 Nextcloud、Fastmail 或 Radicale。

連結您的行事曆

  1. 在應用程式欄中點擊 行事曆。
  2. 在 連結您的行事曆 中，填入 CalDAV 伺服器 地址（通常只需輸入服務商的網域）、您的 使用者名稱 與 密碼。如果您的服務商提供應用程式密碼，請使用該密碼。
  3. 選擇何時 提醒我沒有設定鬧鐘的活動，然後點擊 連結。

您的密碼會以加密方式儲存在 Antimatter 伺服器上。若要稍後變更這些資訊或斷開連結，請使用面板中的 帳戶設定。

使用方式

  • 在 行程 與 週 檢視之間切換，使用 上一步、今天 與 確定 進行移動，並點擊行事曆的標籤來顯示或隱藏該行事曆。
  • 點擊 新增活動，填入 標題、開始時間 與 結束時間，並可選填 重複、提醒、地點 與 敘述，然後點擊 儲存。點擊活動即可修改或刪除它。
  • 若要透過 Antimatter 進行會議，請將 透過 Antimatter 會議 設定為某個頻道、語音頻道或通話，並選擇 頻道。當時間來臨時，活動上會顯示 開始通話、加入通話 或 加入。
  • 提醒會以行事曆機器人的私人訊息形式發送，若該活動包含通話，訊息中會附上加入通話的連結。

此應用程式僅顯示您自己的行事曆；它不會向其他人發送邀請。

Mail

郵件應用程式會將您的信箱顯示在聊天介面旁，讓您在 Antimatter 中即可讀取、回覆與分享電子郵件。

連結您的信箱

  1. 在應用程式欄中點擊 郵件。
  2. 如果您的管理員已設定，請點擊 使用 Google 登入 或 使用 Microsoft 登入。否則，或若要使用其他服務商，請填入您的 電子郵件地址 與 您的姓名，然後輸入 接收郵件 (IMAP) 與 發送郵件 (SMTP) 伺服器資訊，包括安全性、埠號、使用者名稱與密碼。您的服務商說明頁面會提供這些詳細資訊。
  3. 點擊 連結。

使用方式

  • 選擇資料夾，使用搜尋此資料夾進行搜尋，然後點擊訊息以閱讀。來自網路的圖片在您點擊顯示圖片之前會保持隱藏。
  • 使用回覆、回覆所有人或下一步進行回應，或使用新訊息撰寫新訊息。訊息為純文字，您無法附加新檔案。
  • 點擊分享至頻道，即可將電子郵件的寄件者、主旨及內容摘要，加上註解後發布到頻道中。

Polls

投票是在對話中提出問題，讓每個人只需點擊一次即可投票。結果會即時更新。

  1. 點擊訊息框中的+並選擇建立投票，或輸入 /poll。
  2. 輸入問題及至少兩個選項；使用新增選項可添加更多選項，最多可達十個。
  3. 如果允許選擇多個選項，請開啟允許多選；如果希望不顯示誰投了什麼票，請開啟匿名投票。
  4. 選擇時長，範圍從 1 小時到 1 週，或選擇無結束時間。
  5. 點擊發布投票。

要投票，請點擊某個選項；再次點擊該選項可取消投票。投票會在時長結束時結束，或由建立者或頻道管理員點擊結束投票；之後會顯示最終結果。

您也可以在一行內寫下整個投票：/poll "Lunch?" "Pizza" "Sushi" --multi --duration 1h。輸入 /poll help 即可列出所有選項。

Todo

待辦事項功能可管理待辦清單：您自己的清單、頻道的共享清單，以及您發送給其他人的任務。

  • 點擊應用程式側欄中的待辦事項。在此頻道分頁中，您可以向頻道的共享清單新增任務，並使用指派給…將其指派給成員。將清單設為星號以追蹤它；您追蹤的清單會彙整在追蹤中分頁。
  • 我的分頁包含您自己的任務、在頻道中指派給您的任務，以及發送給您或由您發送的任務。使用發送給…選擇某人以向其發送任務：他們可以接受、拒接或標記為完成。
  • 若要將訊息轉為任務，請在其選單中選擇訊息動作 › 新增至待辦事項。
  • 當任務完成時，點擊標記為完成。

您也可以使用 /todo add …、/todo list 和 /todo send @someone … 來管理您的個人任務。

GIF、貼紙與迷因

點擊訊息框中的表情符號（笑臉）：當這些應用程式設定完成後，選擇器中會在表情符號旁邊出現GIFs、貼紙和迷因分頁。

  • GIFs：搜尋，或瀏覽我的最愛、最近曾使用、Trending 和分類。按一下 GIF 即可立即傳送。按一下其星號可將其加入您的最愛。您也可以輸入 /gif 和幾個單字。
  • 貼紙：搜尋或瀏覽貼紙包，並按一下貼紙即可傳送。/sticker 也可以。
  • 迷因：選擇範本，在製作迷因中填入其文字，查看預覽，並按一下發佈迷因。您也可以輸入 /meme，或 /meme help 以查看如何在一行中撰寫。

根據您的伺服器設定，您可能可以使用搜尋框旁邊的 + 添加您自己的 GIF、貼紙或迷因範本。

Playbooks

操作手冊是為每次遵循相同步驟的工作而設的可重用檢查清單：事件、發布、歡迎新同事。每次您使用它時，您都會開始一個執行，擁有其自身的任務、負責人、狀態更新，以及在最後的回顧。

  • 按一下應用程式欄中的 操作手冊 以查看目前頻道的執行，使用 執行操作手冊 開始一個，或建立一個快速的 新檢查清單。
  • 若要建立或編輯操作手冊，請開啟完整頁面：關於 Antimatter › 產品 › 操作手冊。從範本開始，例如產品發布、事件解決或員工入職，或從空白操作手冊開始。
  • 若要開始執行，請按一下操作手冊上的 執行，為執行命名並提供摘要，選擇是否為其建立頻道或將其連結到現有頻道，然後按一下 開始執行。您也可以選擇訊息上的 訊息動作 › 執行操作手冊。
  • 在執行期間，勾選任務、指派它們並設定到期日，並按一下 發佈更新 以告知大家目前的情況。負責人在最後按一下 完成。

輸入 /playbook 以查看指令，例如 /playbook run 或 /playbook update。

GitHub、GitLab 和 Jira

這些應用程式將 Antimatter 連接到開發人員使用的工具。您的管理員必須先設定它們。然後：

  1. 透過輸入 /github connect、/gitlab connect 或 /jira connect 來連結您的帳戶，然後遵循連結並在那個網站上登入。對於 GitLab，請在網頁瀏覽器中執行此操作，而不是在桌面應用程式中。
  2. 然後，當有人提及您、要求您審查或指派您某事時，您會收到私人訊息。
  3. 若要讓頻道追蹤儲存庫或專案，請使用 /github subscriptions add owner/repo、/gitlab subscriptions add group/project 或 /jira subscribe。
  4. 若要從訊息建立或附加問題，請在訊息的訊息動作中選擇建立 GitHub 問題、建立 GitLab 問題、建立 Jira 問題，或對應的附加至 …選項。

輸入 /github help、/gitlab help 或 /jira help 即可查看所有指令。

行動應用程式中的應用程式

行動應用程式可建立並投票、傳送 GIF 和貼紙，以及回覆傳送給您的待辦事項。筆記和白板會在應用程式內的瀏覽器視窗中開啟。看板、行事曆、郵件和迷因尚未支援行動應用程式：請使用網頁或桌面應用程式。
