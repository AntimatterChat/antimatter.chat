撰寫訊息

關於訊息的一切：撰寫與格式化、回覆、反應、編輯、排程，以及追蹤重要的訊息。

傳送訊息

訊息輸入框位於每個頻道和對話的底部。它會顯示您正在撰寫訊息的對象名稱，例如「訊息 #general」。

  1. 點擊訊息輸入框，或按 Ctrl+Shift+L（Mac 上為 ⌘+Shift+L）即可跳轉至該處。
  2. 輸入您的訊息。
  3. 按 Enter，或點擊 傳送 按鈕（紙飛機圖示）。

若要換行而不傳送，請按 Shift+Enter。如果您偏好使用 Enter 換行，請在 設定 › 訊息 中開啟 使用 Ctrl+Enter 傳送：此時您需按 Ctrl+Enter（Mac 上為 ⌘+Enter）來傳送訊息。

當您輸入文字時，對話中的其他人會在訊息框下方看到「… 正在輸入…」。您可以在 設定 › 進階 中透過 不傳送「正在輸入」狀態 停止傳送此通知。

無法送出的訊息會保留在對話中，以灰色顯示並標記為 未送出。您可以點擊 重試 重新送出，或點擊 捨棄 將其移除。

訊息有最大長度限制，由您的伺服器設定。當接近此限制時，訊息輸入框中會出現計數器。如果訊息過長，Antimatter 會告知您超出多少字元，並不會傳送該訊息。

格式化您的文字

Antimatter 使用 Markdown 格式化訊息：在文字周圍或前方加上幾個字元即可改變其外觀。您不需要記住這些語法：格式列會為您處理。

使用格式列

  1. 如果訊息輸入框下方的格式列被隱藏，請點擊 顯示格式（訊息輸入框中的 Aa 按鈕）。
  2. 選取部分文字，然後點擊按鈕：粗體、斜體、刪除線、標題、連結、行內程式碼、程式碼區塊、援引、符號清單 或 編號清單。
  3. 當視窗較窄時，部分按鈕會移至 更多格式（⋯ 按鈕）中。

若要查看訊息送出前的顯示效果，請點擊格式列中的 預覽訊息的顯示效果，或按 Ctrl+Alt+P（Mac 上為 ⌘+⌥+P）。? 按鈕會開啟關於格式、提及、檔案和指令的說明頁面。

若您希望在輸入時就能看到粗體、清單與連結的實際樣貌，請在 設定 › 訊息 中開啟 豐富文字編輯器（測試版）（若您的伺服器提供此功能）。

若要將訊息顯示為純文字（不含任何格式），請在 設定 › 訊息 中關閉 訊息格式。

以各自時區顯示的時間

當訊息中提到時間（例如「15:30 CET」或「明天下午 3 點」）時，Antimatter 會將其高亮顯示並附上小時鐘圖示。將滑鼠指標指向該時間，即可查看您所在時區的時間。您可以在 設定 › 訊息 中透過 您所在時區的時間 關閉此功能。

您也可以寫入一個精確的時間點，讓每位讀者都能以自己的時區和格式看到：輸入 <t:1700000000>，其中數字是 Unix 時間戳記（自 1970 年 1 月 1 日 UTC 以來的秒數）。在冒號後加上字母可選擇樣式：t 簡短時間、T 完整時間、d 簡短日期、D 完整日期、f 日期與時間（預設值）、F 含星期的日期與時間、R 相對時間，例如「3 小時後」。例如：<t:1700000000:R>。

提及人員與頻道

提及會通知某人，即使他們沒有密切關注該對話。

  • 輸入 @ 和姓名的開頭，然後使用方向鍵和 Tab 或 Enter 從清單中選擇該人員。他們會收到通知。
  • @channel 和 @all 會通知頻道中的所有人；@here 會通知其中線上的人。當頻道有超過幾位成員時，Antimatter 會先要求您確認，並告知您即將通知多少人以及他們所在的時區。
  • 輸入 ~ 和頻道名稱的開頭，即可連結到該頻道。
  • 您的社群也可能有您可以一次提及的群組，當您輸入 @ 時，它們會與人員一起列出。

您在編輯訊息時新增的提及不會通知任何人。

若要從個人檔案提及某人，請右鍵點擊其姓名或圖片，然後選擇提及。

表情符號與反應

為訊息新增表情符號

  • 點擊表情符號（訊息框中的笑臉），或按 Ctrl+Alt+E（Mac 上為 ⌘+⌥+E）。搜尋或瀏覽分類，然後點擊一個表情符號。選擇器會保持開啟，以便您可以新增多個。
  • 或者輸入 : 和表情符號名稱的開頭，例如 :thumb，然後從清單中選擇它。
  • 使用選擇器中的膚色按鈕選擇膚色。您的選擇會被保留。
  • 預設情況下，文字表情（如 :) 和 <3）會轉為表情符號。您可以在 設定 › 訊息 中透過 將文字表情轉為表情符號 關閉此功能。

當這些應用程式已安裝時，選擇器也有 GIF 和貼紙的分頁：請參閱GIF、貼紙和迷因。

對訊息做出反應

  1. 將指標指向訊息：其右上角會出現工具列。
  2. 點擊 新增反應（笑臉圖示）並選擇一個表情符號。更多動作（⋯）選單中也提供六種快速反應。

反應會顯示在訊息下方並附上計數。按一下反應即可新增，再按一次即可移除。將滑鼠指標移到反應上，即可查看誰做出了反應。若要使用鍵盤對對話中的最後一則訊息做出反應，請在訊息框中按下 Ctrl+Shift+\（Mac 上為 ⌘+Shift+\）。

在 設定 › 訊息 中開啟 一鍵反應 後，您上次使用過的表情符號會顯示在訊息工具列中，讓您只需按一下即可做出反應。

新增自訂表情符號

如果您的伺服器允許，請在表情符號選取器中按一下 新增自訂表情符號。為表情符號設定 名稱（小寫字母、數字以及 -、+ 或 _），選擇 圖片（PNG、GIF、JPEG 或 WebP，最大 1 MB；支援動態 GIF），然後按一下 新增表情符號。伺服器上的所有人都可以使用 :name: 來使用它。

回覆訊息

回應訊息有兩種方式：在對話中回覆（會引用該訊息），或在討論串中回覆。

在對話中回覆

  1. 將滑鼠指標指向訊息並點擊 回覆（彎曲箭頭），或在 更多動作 選單中選擇 回覆。
  2. 訊息框會顯示「回覆」並附上您回覆的訊息。預設情況下，該訊息的作者會收到通知。如果您不想通知對方，請點擊 @ 已開啟 切換為 @ 已關閉；Antimatter 會記住您下次的選擇。
  3. 輸入您的回覆並送出。它會顯示在對話中，上方為被引用的訊息。按一下引用內容即可跳轉至原始訊息。

若要取消，請按一下 取消回覆（即 ×）或按下 Esc。在空白的訊息框中，按 Shift+Up 可引用上一則訊息，再按一次則可繼續往前；按 Shift+Down 則可繼續往後。

您的管理員可以關閉這些回覆功能。屆時只提供討論串選項。

在討論串中回覆

討論串可將旁支討論集中在啟動它的訊息下方，避免佔滿頻道。

  1. 將滑鼠指標指向訊息並點擊 在討論串中回覆，或在 更多動作 選單中選擇 在討論串中回覆。
  2. 討論串會在右側面板中開啟，並擁有獨立的訊息框「回覆討論串」。輸入您的回覆並送出。

在頻道中，附有回覆的訊息會顯示回覆者、回覆數量以及最後一則回覆的時間。按一下即可開啟討論串。在討論串面板中，您可以按一下在新視窗中開啟，在獨立視窗中閱讀，或按一下展開面板以加寬面板。按 Esc 或按一下關閉討論串即可關閉。

追蹤討論串

當您開啟討論串、回覆討論串或在討論串中被提及时，系統會自動讓您追蹤該討論串。當您追蹤討論串時，新的回覆會使其顯示為未讀。若要追蹤或停止追蹤討論串，請在訊息的 更多動作 選單或討論串面板的 討論串操作 選單（⋯）中選擇 追蹤討論串 或 取消追蹤討論串。您可以在 已追蹤的討論串 中找到您追蹤的所有討論串：請參閱 提及、已儲存和已釘選的訊息。

預設情況下，討論串的回覆會保留在討論串中。如果您希望同時在頻道中看到回覆，請在您的伺服器提供此選項時，於設定 › 訊息中關閉將回覆保留在討論串中。

為討論串命名

您可以為您開啟的討論串命名，使其成為該頻道的子聊天室：所有追蹤該討論串的人都能在側邊欄的該頻道下方看到它。

  1. 開啟討論串第一則訊息的更多動作選單，並選擇命名討論串…。
  2. 在為此討論串命名中輸入名稱（例如「2.1 版發行」），然後按一下儲存。

若要稍後變更名稱，請在同一選單中選擇重新命名討論串…。

訊息選單

將滑鼠指標移至訊息上，並點擊更多動作（⋯）以開啟選單。在觸控螢幕上，請長按該訊息。選單中提供的選項會因訊息類型及您的權限而異：

項目功能說明
快速反應，然後是更多反應使用六種常見表情符號之一進行反應，或選擇其他表情符號。
回覆在您的回覆中引用該訊息。
在討論串中回覆開啟該訊息的討論串。
下一步在另一個頻道或對話中分享該訊息（詳見下文）。
命名討論串…將該討論串設為頻道的命名子聊天室。
移動討論串…在您被允許時，將整個討論串移動到另一個頻道。
儲存至筆記將該訊息複製到您的給自己的筆記中。
追蹤討論串 / 取消追蹤討論串接收或停止接收該討論串的新回覆。
朗讀當您的管理員啟用此功能時，可讓系統朗讀該訊息。選擇停止朗讀即可停止。
標記為未讀從該訊息開始，將對話重新標記為未讀。

置頂暫時將此訊息顯示在頻道訊息的上方。
複製連結複製此訊息的連結。
複製文字複製訊息的文字內容，包含其 Markdown 格式。
AI 操作摘要及其他 AI 操作，當已設定 AI 代理程式時（請參閱 訊息上的 AI 操作）。
訊息動作由其他應用程式新增的操作，例如 加入待辦事項 或 執行操作手冊。
編輯修改您的訊息。
刪除將此訊息對所有人刪除。
檢舉訊息當您的社群已啟用檢舉功能時，可向管理員檢舉他人的訊息。

編輯或刪除訊息

編輯

  1. 在訊息的更多動作選單中選擇編輯。若要編輯上一則訊息，也可以將游標移至空白訊息框中，然後按 Up 鍵。
  2. 就地修改文字。按 Enter 或點擊 儲存 以儲存，按 Shift+Enter 換行，或按 Esc 取消。

已編輯的訊息會顯示（已編輯）。將滑鼠指標移至其上即可查看編輯時間。對於您自己的訊息，點擊（已編輯）可查看較早的版本。管理員可能會限制訊息在發佈後多久內仍可編輯。

刪除

  1. 在訊息的更多動作選單中選擇刪除。
  2. 使用 刪除 確認。該訊息將對所有人移除，若該訊息開啟了討論串，其回覆和檔案也會一併移除。此操作無法復原。

分享檔案和圖片

若要將檔案附加到訊息，請執行以下其中一項操作：

  • 點擊新增檔案及其他內容（訊息框中的 +），並選擇上傳檔案。
  • 將檔案拖曳到對話中並放開。
  • 將圖片或檔案貼上到訊息框中。

每個檔案都會在訊息框中顯示上傳進度；點擊其 × 可移除或取消上傳。您可以加上一些文字，然後發送。一則訊息可包含多個檔案，但有數量限制；您的管理員會設定允許的最大檔案大小。

在訊息中，點擊圖片即可放大檢視。您可以使用放大（+）和縮小（−）進行縮放，切換到上一張圖片或下一張圖片，下載圖片或複製連結。其他檔案若 Antimatter 能顯示預覽（例如 PDF 檔案、程式碼、音訊和影片），開啟時也會顯示預覽。每個檔案都有一個選單，包含下載、複製連結、取得公開連結（如果您的伺服器允許公開連結）以及在頻道中開啟。

圖片預設會完整顯示。若要讓圖片在開啟前保持摺疊狀態，請在設定 › 訊息中關閉展開顯示圖片，或輸入 /collapse；輸入 /expand 可再次展開顯示。

連結與連結預覽

當訊息包含指向網站的連結時，Antimatter 可以顯示一張預覽卡片，包含頁面標題、描述和圖片。如果是您撰寫的訊息，您可以點擊卡片上的遠端連結預覽將其移除。若要停止顯示預覽，請在設定 › 訊息中關閉網頁連結預覽。

若要分享訊息，請在其選單中選擇複製連結，並將連結貼上 Antimatter 的任何位置。該連結會顯示為一個帶有頻道名稱的小標籤；點擊它即可跳轉至該訊息。只有能讀取該頻道的人才能看到此訊息。

轉發訊息

  1. 在訊息的更多動作選單中選擇下一步。將開啟轉傳訊息對話框。
  2. 選擇要轉發的頻道或人員。
  3. 選擇性地，在新增留言（選擇性）中輸入一些內容。
  4. 點擊下一步。

來自私人頻道或私人對話的訊息，只能轉發給已經能讀取該訊息的人；當符合此條件時，對話框會向您說明。

草稿

Antimatter 會保留您已撰寫但尚未發送的內容，針對每個頻道和討論串：您可以離開並稍後回來完成。所有未發送的訊息都列在草稿下（帶有數量統計），位於您的私人訊息清單中（請參閱版面配置）。您可以從那裡發送、編輯、排程或刪除每個草稿。

若在設定 › 訊息中開啟同步草稿，您的草稿將儲存在伺服器上，讓您可以透過其他裝置完成編輯。

排程訊息

您可以現在撰寫訊息，並讓 Antimatter 稍後發送。

  1. 撰寫訊息。
  2. 點擊排程訊息（格式工具列中的時鐘圖示，或+選單中）。
  3. 選擇 明天 9:00、週一 9:00、您 最近使用的自訂時間，或在 自訂時間 下選擇日期與時間，然後點擊 排程。

訊息框上方會出現一則備註，說明訊息將於何時發送。點擊 查看全部 可開啟已排程訊息的清單，該清單也位於您的私人訊息清單中的 已排程 項目下。您可以在那裡立即發送訊息、重新排程、編輯或刪除訊息。如果已排程的訊息無法發送（例如因為頻道已被封存），清單中會說明原因。

當您向某人發送私人訊息或群組訊息，而對方處於夜間（其時區時間為 22:00 至 06:00 之間）時，系統會顯示提示：「對方時間為 23:10 — 他們可能正在睡覺。」點擊於對方時間 07:00 傳送可將訊息排程於對方早晨發送，或點擊關閉以隱藏提示。

類似的備註會告知您，當您發送訊息的對象已開啟 請勿打擾 或不在辦公室時的情況。

重要與緊急訊息

如果您的伺服器允許，您可以將訊息標記為重要或緊急，並要求接收者確認已讀。此功能適用於頻道或對話中的新訊息，不適用於討論串中的回覆。

  1. 點擊訊息優先權（格式工具列中的旗標）。
  2. 選擇 標準、重要 或 緊急。
  3. 如果希望讀者確認已讀，請開啟勾選已讀請求。
  4. 對於緊急訊息，您也可以開啟 持續通知：被通知的人會每隔幾分鐘再次收到通知，直到他們確認已讀為止。
  5. 點擊 完成，然後發送訊息。

訊息顯示重要或緊急標籤。當需要確認時，下方會出現已讀按鈕，並顯示已確認者的頭像。點擊即可確認，之後會顯示為已確認。

劇透

劇透功能會隱藏訊息的文字與檔案，直到每位讀者選擇查看為止。通知中也不會顯示其文字內容。

  1. 撰寫您的訊息，如有需要可附上檔案。
  2. 點擊以防雷訊息傳送（格式欄中的劃線眼睛圖示）。訊息框中會顯示防雷內容標籤；點擊其上的×即可取消。
  3. 發送訊息。

讀者會看到帶條紋的遮罩。點擊即可顯示訊息。若要再次隱藏，請點擊訊息工具列中的防雷：顯示或隱藏。

讀後焚毀訊息

當管理員允許時，您可以傳送在每個人開啟後一段時間自動刪除的訊息。

  1. 撰寫訊息。
  2. 點擊閱後即焚（格式欄中的火焰圖示），開啟開關，然後點擊完成。開關會顯示訊息開啟後的保留時間；此時間由您的管理員設定。
  3. 發送訊息。

讀者會看到「點擊以閱讀——此訊息在您開啟後 … 將被焚毀」。開啟後，計時器會顯示剩餘時間。作為發送者，您可以看到有多少人已閱讀，並可一次為所有人刪除。開啟後焚毀的訊息無法在討論串中回覆或轉發。

釘選訊息或將其置頂

在訊息選單中選擇 釘選至頻道，會將該訊息加入頻道的已釘選訊息，頻道內所有人都可以列出：請參閱 提及、已儲存與已釘選的訊息。已釘選的訊息會顯示 已釘選 標籤。

置頂 功能更進一步：該訊息會顯示在頻道訊息上方的橫幅中，對所有人可見，持續一段時間。

  1. 在訊息選單中，指向 置頂。
  2. 選擇持續時間：1 小時、4 小時、1 天、1 週 或 直到移除。

可以同時有多則訊息置頂：使用置頂列中的上一步和確定來瀏覽這些訊息，並使用跳至在對話中查看特定訊息。若要取消置頂，請點擊置頂列中的×，或在該訊息的選單中，於置頂 · 變更下方選擇取消置頂。

儲存訊息並設定提醒

在訊息選單中選擇 儲存 以保留該訊息供日後使用。已儲存的訊息會顯示 已儲存 標籤，僅您可見。您可以在 已儲存的訊息 中找到它們。

選擇 提醒我 以稍後提醒某則訊息，時間可選建議的時間或 自訂時間…（選擇日期和時間，然後按一下 設定提醒）。

您的給自己的筆記是一個只有您能看到的對話，可用於筆記、提醒和草稿。您可以從私人訊息清單中開啟它，或在訊息選單中使用儲存至筆記將訊息傳送至此。

已翻譯的頻道

當頻道的管理員開啟翻譯功能，且您的伺服器支援您的語言時，該頻道的訊息會以您的語言顯示，且頻道的標題會顯示已翻譯。在每則已翻譯的訊息下方，您可以點擊顯示原文，然後點擊顯示翻譯來切換回去。若要查看整個頻道的原始語言內容，請在頻道的選單中關閉翻譯訊息。

斜線指令

以/開頭的訊息是指令。輸入/即可查看清單，其中包含每個指令的簡短說明；應用程式會加入其自訂的指令。您也可以選擇使用斜線指令在+選單中。您可能使用的一些指令如下：

指令功能說明
/away, /online, /offline, /dnd設定您的狀態。
/msg @name message傳送私人訊息。
/groupmsg @name1, @name2 message傳送群組訊息。
/join ~channel, /leave加入或離開頻道。
/mute靜音或取消靜音目前頻道。
/header text, /purpose text設定頻道的標題或用途。
/me text發佈動作，以斜體顯示。
/shrug text在您的訊息中加入 ¯\_(ツ)_/¯。
/code text將文字發佈為程式碼區塊。
/search words搜尋訊息。
/expand, /collapse顯示圖片為展開或摺疊狀態。
/settings, /shortcuts開啟設定，或鍵盤快捷鍵清單。
/logout登出。
