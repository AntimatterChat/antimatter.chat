設定與鍵盤捷徑

讓 Antimatter 的外觀與操作方式符合您的喜好：主題、顯示、語言與時間，以及鍵盤捷徑。

開啟您的設定

點擊視窗右上角的個人照片，然後選擇個人檔案與設定。您也可以按下 Ctrl+Shift+A（Mac 上為 ⌘+Shift+A），或輸入 /settings。您的設定會在變更時自動儲存，並同步至您登入的所有裝置。

設定依面板分組如下：

面板內容查看
我的帳號您的照片、姓名、使用者名稱、暱稱、職稱、電子郵件及個人檔案詳細資訊。編輯個人檔案
安全性密碼、多重驗證，以及您目前登入的裝置。密碼與多重驗證
隱私與安全誰可以向您傳送訊息，以及您忽略或封鎖的人員。誰可以向您傳送訊息
通知桌面、行動裝置與電子郵件通知、音效、關鍵字、自動回覆。通知與狀態
外觀主題、顯示與側邊欄。下方
訊息訊息的顯示與撰寫方式。下方

鍵盤變更 Antimatter 的捷徑。下方

在擴充程式中，部分應用程式會加入自己的設定，例如通話的麥克風與攝影機。如果您是系統管理員，這些設定也會連結到系統控制台。

主題與顯示

選擇主題

在設定 › 外觀的主題中，選擇Dark、OLED（純黑色，適合暗室與 OLED 螢幕）、輕度，或系統（會跟隨電腦的亮色或暗色模式，即使在一天中切換也是如此）。

若要自訂，請點擊自訂。在自訂顏色中，設定每種顏色：Community rail、Sidebars、Chat area、Inputs & cards、Borders、文字、Secondary text、Accent 和 連結。以 Antimatter 預設主題為基礎可將這些設定重設。

分享主題

主題可以透過以 am1: 開頭的短代碼進行傳遞。在 分享主題 下方，按一下 複製我的主題代碼，然後將其傳送給他人。若要使用收到的代碼，請將其貼上至輸入欄位中，然後按一下 套用。

顯示

  • 訊息顯示：標準，或密集（在螢幕上顯示更多訊息，不顯示圖片且行距較緊）。
  • 為名稱上色：讓訊息中每個人的名稱擁有獨立的顏色。社群設定的角色顏色優先。
  • 大頭貼上的上線狀態：在訊息中的大頭貼上顯示人員是否線上。
  • 分享上次上線時間：讓其他人看到「上次上線 …」。
  • 訊息寬度：全寬，或 置中（方便在大螢幕上閱讀）。
  • 人員名稱顯示方式：使用者名稱、暱稱或全名，除非管理員已為所有人指定。
  • 24 小時制：以 16:00 而非 4:00 PM 顯示時間。
  • 分組未讀頻道：將未讀頻道彙整至側邊欄頂部的 未讀 區塊中。
  • 開啟中的對話：側邊欄列出多少私人訊息。

經典介面

Antimatter 的介面即為本指南所描述的介面。若管理員允許，您可以透過 設定 › 外觀 中的 網頁介面 切換至 經典（舊版）（為相容性保留的舊介面），或切換回 Fusion。此選擇適用於您登入的所有瀏覽器。經典介面中的選單與按鈕有所不同。

訊息設定

設定 › 訊息 可設定對話的外觀與您的輸入方式。視您的伺服器而定，它提供以下選項：

  • 將回覆保留在討論串中：討論串的回覆將保留在討論串內，而不會同時顯示在頻道中。
  • 連結預覽：為訊息中連結的網站顯示預覽卡片。
  • 將文字表情轉為表情符號：將 :) 和 <3 顯示為表情符號。
  • 以您的時區顯示時間：突出顯示訊息中寫入的時間，當您將指標指向這些時間時，會顯示您所在時區的時間。
  • 加入與離開頻道的訊息：顯示人員加入或離開頻道的訊息。
  • 使用 Ctrl+Enter 傳送：Enter 換行，Ctrl+Enter 傳送。
  • 豐富文字編輯器（測試版）：在輸入時即可看到格式呈現的效果。
  • 同步草稿：將未傳送的訊息保留在伺服器上，以便在其他裝置上繼續編輯。
  • 在閱讀中：開啟未讀對話時跳至（上次閱讀位置或最新訊息）、展開顯示圖片、一鍵反應，以及訊息格式（關閉後訊息將以純文字顯示）。

語言與時區

在設定 › 語言與時區中，從清單選擇介面的語言。Antimatter 會立即切換。

下方的時區通常會依您的電腦自動設定。若要變更，請點擊變更…：這會開啟傳統設定視窗中的時區設定，您可以在那裡關閉自動時區並手動選擇。

您的時區對其他人也很重要：Antimatter 會依此向他們顯示您的當地時間，並在您當地是夜晚時發出提醒。

進階設定

  • 直播模式：隱藏您的電子郵件地址與對話預覽，並靜音桌面通知，例如在螢幕分享時使用。
  • 開發人員模式：在訊息、頻道、社群與人員的選單中加入複製 ID，供 API 與機器人使用。
  • 在效能偵錯中（若您的伺服器提供）：在此瀏覽器中停用外掛程式與不傳送「正在輸入」狀態，在系統出現異常時特別有用。

變更捷徑

  1. 開啟 設定 › 鍵盤。
  2. 點擊動作旁的 變更，然後按下新的按鍵組合。按 Esc 取消，或按 Backspace 關閉該捷徑。
  3. 如果另一個動作使用相同的按鍵，頁面會警告您：「另一個動作也使用這些按鍵」。
  4. 點擊 重設 回到原始按鍵。

您可以變更搜尋、快捷鍵清單、設定、未讀篩選器與通話的快捷鍵。其他快捷鍵則維持不變。頁面底部的 所有鍵盤快捷鍵… 可開啟完整的快捷鍵清單。

在桌面應用程式中

桌面應用程式會新增其專屬的捷徑，顯示在其選單中：例如 Ctrl+F 在頁面中搜尋文字，Ctrl+= 和 Ctrl+- 縮放，Ctrl+0 恢復實際大小，Ctrl+R 重新載入，Alt+Left 和 Right（Mac 上為 ⌘+[ 和 ]）向前和向後瀏覽，以及 Ctrl+Shift+1 至 9（Mac 上為 ⌘+Ctrl+1 至 9）在伺服器之間切換。
