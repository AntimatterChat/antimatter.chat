使用 Antimatter

本指南適用於所有在 Antimatter 伺服器上進行聊天的使用者，無論是在工作場合或社群中。您不需要具備技術背景知識。請從這裡開始，完成登入並熟悉介面。

本指南內容

Antimatter 是一個與團隊或社群交流的平台：您可以在頻道、私人對話、通話中互動，並使用共享筆記和白板等應用程式。本指南的各個頁面將逐步說明如何執行每項操作：

  • 撰寫訊息：格式設定、提及、表情符號、回覆與討論串、編輯、草稿、排程等。
  • 社群與頻道：加入、整理側邊欄、私人訊息與群組訊息。
  • 通話與語音頻道：語音對話、螢幕分享、即時字幕。
  • 應用程式：筆記、白板、看板、行事曆、郵件、投票、待辦事項等。
  • AI 代理程式：摘要、改寫與問答功能（若您的伺服器已啟用）。
  • 通知與狀態：哪些通知會傳送到您，以及何時傳送。
  • 個人檔案與隱私：您的個人檔案、誰可以向您傳送訊息、封鎖功能，以及帳戶安全性。
  • 搜尋與查找：搜尋、提及、已儲存的訊息與未讀訊息。
  • 設定與捷徑：主題、語言與鍵盤捷徑。

每個 Antimatter 伺服器都由各自的管理員營運，由他們決定啟用哪些功能和應用程式。如果本指南中的某些功能未出現在您的界面上，可能是您的伺服器尚未啟用該功能：請向您的管理員詢問。

登入

Antimatter 沒有中央登入網站：每個組織或社群都營運自己的伺服器，並擁有獨立的網址，例如 chat.example.com。您的管理員或邀請您的人會提供該網址。

  1. 在您的網頁瀏覽器中開啟該網址，或將其加入桌面版或行動版應用程式（請參閱 桌面版與行動版應用程式）。
  2. 在登入您的帳號中，輸入您的電子郵件地址或使用者名稱以及密碼，然後按一下登入。如果您的組織使用自己的登入系統，請改為按一下「或透過以下方式登入」下方的該系統按鈕。
  3. 如果您已啟用多重驗證，請輸入驗證應用程式提供的代碼。

如果您收到邀請連結，請開啟它以建立您的帳號：在建立您的帳號中填寫您的電子郵件地址、使用者名稱和密碼，然後按一下建立帳號。如果您忘記了密碼，請按一下忘記密碼？並輸入您的電子郵件地址：您將收到一個連結以選擇新密碼。

有些團隊會透過幾個問題來歡迎新成員，回答這些問題後，您就能獲得相應的角色與頻道。您可以回答這些問題，或點擊跳過。

視窗

從左到右分別是：社群欄、側邊欄、對話區、成員清單和應用程式欄。

  1. 社群欄位於最左側：每個您加入的社群都有一個圓形圖示。圓點表示有未讀訊息，數字則顯示提及您的次數。圖示下方的新增團隊（+）可讓您加入或建立社群。最下方的所有私人訊息（對話氣泡圖示）會顯示您所有的私人訊息，包括提及、追蹤中的討論串、已儲存的訊息、草稿以及給自己的筆記。當未讀對話無法在開啟中的對話中完整顯示時，它們的頭像會出現在對話氣泡下方，並附上未讀數量。最後是搜尋所有內容（放大鏡圖示）。
  2. 側邊欄：顯示目前社群的名稱，點擊可開啟其選單，接著是依分類分組的頻道。最下方的開啟中的對話會列出您最近的私人訊息，預設最多顯示 10 則。未讀對話的頭像周圍會有紅色圓環，並附有小字灰色數字顯示未讀數量。
  3. 對話區：顯示您開啟的頻道或對話中的訊息，底部為訊息輸入框。其標題列顯示名稱（點擊可查看頻道資訊）、簡短的標題文字、搜尋框，以及用於通話、查看提及、已儲存和已釘選訊息與檔案、以及顯示成員清單的按鈕。
  4. 右側面板：顯示頻道的成員，或當您開啟時，顯示討論串、搜尋結果或應用程式。按 Esc 可關閉面板。
  5. 應用程式欄位於右邊緣：頂部是您的頭像，點擊可開啟您的狀態和設定；中間是應用程式的圖示；底部是關於 Antimatter選單。

通話期間，通話面板會顯示在側邊欄底部，並提供靜音、螢幕分享或離開的按鈕：請參閱通話面板。

在小螢幕上

在窄視窗或手機瀏覽器上，側邊欄會變成抽屜式選單。點按左上角的開啟導覽，或向右滑動，即可查看社群與頻道。向左滑動可查看成員清單與應用程式。長按訊息即可開啟其選單。

入門步驟

  1. 設定個人檔案：上傳照片並確認您的姓名，以便他人識別您。請參閱編輯個人檔案。
  2. 當瀏覽器詢問時，請允許通知，以便您知道何時有人需要您。請參閱通知。
  3. 加入您關注的頻道：開啟社群選單（點按社群名稱），並選擇瀏覽頻道。請參閱尋找並加入頻道。
  4. 問候大家：點按某個頻道，在底部的訊息框中輸入文字，然後按 Enter。
  5. 直接與某人通訊：點按對方的姓名，然後選擇訊息。

若要快速跳轉至任何位置，請按 Ctrl+K（Mac 上為 ⌘+K），然後輸入頻道、人員或訊息的幾個字母。

尋求協助

點擊應用程式欄底部的 Antimatter 標誌，即可開啟關於 Antimatter。在說明下方：

  • 使用者指南會開啟 Antimatter 內建的協助功能，涵蓋訊息傳送、格式設定、提及、檔案與指令等內容。
  • 鍵盤快捷鍵列出所有快捷鍵。
  • 格式說明解釋如何格式化訊息。
  • 若管理員已設定，回報問題功能可讓管理員了解您遇到的問題。

在網頁瀏覽器中，相同的選單也提供下載應用程式選項，點擊後會開啟可下載您伺服器桌面版與行動版應用程式的頁面。如果某個應用程式有獨立的頁面，選單會在產品下列出它。訊息輸入框格式列中的?按鈕也會開啟說明。關於您的帳號或伺服器的任何問題，請詢問您的管理員。

桌面與行動應用程式

您可以在任何最新的網頁瀏覽器中使用 Antimatter。此外，也有適用於電腦與手機的應用程式。

這些應用程式已發布在 GitHub 上：桌面版在其發布頁面，行動版在其發布頁面。關於 Antimatter選單中的下載應用程式會導向管理員選擇的下載頁面，預設為上述的發布頁面。

桌面版與行動版應用程式的首個版本（0.9.0）正在準備中。在正式發布之前，請使用網頁瀏覽器存取 Antimatter，包括在手機上。

桌面應用程式

桌面應用程式支援 Windows、macOS 和 Linux。它顯示與瀏覽器相同的視窗，並額外提供以下功能：無需透過瀏覽器即可接收通知、應用程式圖示上的未讀徽章、團隊欄頂部的返回和下一步按鈕、通話中獨立的螢幕分享選擇器，以及在同一個應用程式中連接多個伺服器。

要安裝應用程式，請從發布頁面下載適用於您系統的文件：Windows 使用 .exe 安裝程式；Mac 使用 .dmg 磁碟映像檔；Linux 使用 .deb 或 .rpm 套件，或 .AppImage。由於應用程式尚未簽章，您的系統在首次執行時會發出警告：

  • 在 Windows 上，SmartScreen 會警告未知發布者：請選擇更多資訊，然後選擇仍要執行。
  • 在 macOS 15 及更新版本上，先嘗試開啟應用程式一次，然後前往系統設定 › 隱私與安全性，並點擊 Antimatter 訊息旁的仍要開啟。在較舊的版本上，請對應用程式按下滑鼠右鍵並選擇開啟。

然後將其連接到您的伺服器：

  1. 啟動應用程式。在歡迎畫面之後，點擊開始使用。
  2. 在連線到您的伺服器中，輸入管理員提供的伺服器 URL，並選擇您想要的伺服器顯示名稱，然後點擊連線。
  3. 如同在瀏覽器中一樣登入。

若要新增另一個伺服器，請在視窗頂部的伺服器選單中選擇新增伺服器，或在應用程式的設定中的伺服器下進行操作。應用程式的設定視窗（在 Windows 和 Linux 上為 Ctrl+,，在 Mac 上為偏好設定…）也可設定是否在登入時啟動、檔案下載位置、拼字檢查器的語言以及通知。

行動應用程式

行動應用程式支援 Android 11 或更新版本，以及 iOS 18 或更新版本。在 Android 上，請從發布頁面下載 .apk 檔案並開啟它；您的手機會先要求您允許從瀏覽器安裝應用程式。發布頁面上的 iPhone 版本未簽章，因此無法直接安裝：您的組織必須先對其進行簽章。請向您的管理員詢問如何取得該應用程式。

  1. 開啟應用程式並滑動通過歡迎畫面。
  2. 在連線到您的伺服器中，於輸入伺服器 URL欄位輸入伺服器位址，選擇顯示名稱，然後輕觸連線。
  3. 使用您的電子郵件或使用者名稱與密碼登入，或使用您組織的登入系統。

行動應用程式擁有獨立的設計：底部的標籤頁可導航至首頁、搜尋、提及、已儲存訊息以及您的帳戶，您可以在帳戶中設定狀態並找到應用程式設定。它涵蓋訊息、討論串、頻道、通話和語音頻道、投票、GIF 和貼紙。網路應用程式的某些功能尚未包含在內，包括通話中的相機、編輯筆記和白板、Kanban、行事曆和郵件。手機上的推送通知需要管理員在伺服器上進行設定。
