搜尋與查找內容

查找任何訊息、檔案、頻道或人員，並返回您關注的內容：您的提及、已儲存與已釘選的訊息，以及您追蹤的討論串。

快速搜尋

快速搜尋可從一個輸入框中查找頻道、對話、人員與訊息。

  1. 按 Ctrl+K（Mac 上為 ⌘+K），或點擊搜尋所有內容（社群側欄底部的放大鏡圖示）。
  2. 輸入幾個字母。結果會隨您輸入而顯示，並分組為頻道與對話、人員和訊息。使用全部、頻道、人員和訊息分頁來縮小範圍。
  3. 使用方向鍵移動並按 Enter 開啟結果，或直接點擊。選擇人員會開啟與該人員的私人訊息。

訊息搜尋範圍為目前社群；切換至在所有團隊中可搜尋所有社群。若要查看所有符合的訊息，選擇搜尋所有「…」訊息：結果將在右側面板中開啟。在輸入之前，輸入框會列出您的最近的對話和最近搜尋。

快速搜尋會列出您所在的頻道。若要查找您尚未加入的頻道，請使用社群選單中的瀏覽頻道：請參閱查找並加入頻道。

搜尋訊息

  1. 點擊對話頂部的搜尋框（「搜尋 …」後接社群名稱）。
  2. 輸入您要查找的單字。輸入框下方的建議提供在 #頻道中搜尋（或在此對話中搜尋）以僅在當前位置查找，下方的篩選器，以及您的最近的搜尋。
  3. 按 Enter。搜尋結果將在右側面板中開啟，並顯示匹配數量。

搜尋會查找完整單字，以及以 * 結尾的單字開頭。

篩選器

類型要查找的內容
from:@marieMarie 撰寫的訊息
in:design頻道或對話中的訊息
on:2026-10-05某一天的訊息
before:2026-10-05, after:2026-09-01某一天之前或之後的訊息
"exact phrase"這些單字，一起且按此順序
-draft不包含「draft」單字的訊息
deploy*以「deploy」開頭的單字
ext:pdf特定類型的檔案
#hashtag帶有該標籤的訊息

當您輸入 from: 或 in: 時，建議清單會列出符合條件的人員或頻道；輸入 on:、before: 或 after: 時，選擇日期 會開啟行事曆。您可以組合使用過濾器，例如 release from:@marie in:platform after:2026-09-01。點擊訊息中的標籤（hashtag）也會進行搜尋。

使用搜尋結果

  • 點擊結果即可跳轉至該訊息所在的對話，該訊息會被高亮顯示。
  • 每個結果都有按鈕，可開啟討論串、儲存、釘選至頻道 或 複製連結。
  • 在面板頂部切換 訊息 與 檔案。對於檔案，可按類型過濾：檔案、試算表、簡報、程式碼、圖像、音訊 或 影音檔案。
  • 點擊 展開面板 以提供更多空間顯示結果，或選擇 在新視窗中開啟。

如果沒有找到符合的結果，請嘗試其他關鍵字或過濾器。您也可以在任何訊息框中輸入 /search 加上您的關鍵字。

提及、已儲存與已釘選的訊息

對話右上角的收件匣按鈕（提及、已儲存、已釘選與討論串）會在一個面板中彙整：

  • 提及：提及您的訊息。
  • 已儲存：您儲存的訊息。
  • 已釘選：在此對話中釘選的訊息。
  • 檔案：在此對話中分享的檔案。
  • 討論串：您追蹤的討論串。

按鈕上的圓點表示有人在此提及您。在 提及、已儲存 和 討論串 中，使用頂部的兩個按鈕選擇要查看 此對話 或 整個社群 的項目。點擊項目即可跳轉至該處，或開啟其討論串。

您的私人訊息清單中也有相同的列表（點擊側邊欄底部的 所有私人訊息）：提及（包含未讀提及的數量）、已追蹤的討論串 和 已儲存的訊息，涵蓋整個社群。按 Ctrl+Shift+M（Mac 上為 ⌘+Shift+M）可在右側面板開啟您的 最近提及。

頻道的資訊（點擊其名稱）也會連結到其 置頂的訊息 和 檔案，並顯示數量。

補看未讀訊息

  • 當您開啟有未讀訊息的頻道時，一條線會標記未讀訊息的起始位置，頂部的橫幅會顯示自您上次離開以來新增了多少訊息。點擊 跳至 即可前往第一則未讀訊息。
  • 當您在對話中向上捲動時，底部會出現一個按鈕，顯示新收到的訊息數量；按一下即可跳至這些訊息。
  • 預設情況下，未讀對話會開啟在您上次離開的位置。若要改為開啟在最新訊息處，請在設定 › 訊息中，將開啟未讀對話時跳至設為最新訊息。
  • 若要稍後再回來查看，請在訊息選單中選擇標記為未讀：該對話將從該訊息起保持未讀狀態。
  • 按 Alt+Shift+Up 或 Down 可跳至上一個或下一個未讀頻道，按 Ctrl+Shift+U 則可在側邊欄中僅顯示未讀頻道。
  • 在社群選單中選擇全部標為已讀，或按 Shift+Esc，可將社群中的所有頻道標記為已讀。

若已設定 AI 代理程式，它們也可以為您總結遺漏的內容：請參閱補看頻道與摘要。

訊息與頻道的連結

每則訊息和每個頻道都有連結：在其選單中選擇複製連結。開啟連結後，任何有權查看的人都會直接跳轉到該處並高亮顯示。如果連結指向您未加入的私人頻道，Antimatter 會在您有權加入時，先請您確認再讓您加入。
