應用程式與整合

您的成員擁有哪些應用程式、您可以自行為社群設定哪些項目，以及哪些項目需要系統管理員處理。

您的成員擁有的應用程式

Antimatter 附帶一組應用程式。除非系統管理員關閉了其中一些，否則伺服器上的每個社群都擁有這些應用程式：

應用程式功能說明
通話與語音頻道在任何頻道中進行通話，以及語音頻道：始終開放的通話，人們可以隨時加入或離開。
Polls對話中的投票，具有即時結果、匿名投票和結束時間。/poll 可建立投票。
Todo在每個頻道和對話中共享待辦事項清單，數量不限，也支援個人清單。
Notes可即時共同編輯的文件，可與頻道共享或保持私人。
Whiteboard可與頻道共享或保持私人的白板。
Kanban由卡片組成的看板，可連結至頻道。看板會在側邊欄中開啟；若開啟看板，側邊欄會變寬。
Playbooks用於重複流程的檢查清單，可在頻道的操作手冊側邊欄中執行。
GIF 和迷因GIF 和貼紙選擇器，以及使用模板製作的迷因，位於表情符號選擇器中。
行事曆與郵件每個人的個人行事曆和信箱，連結到他們自己的帳戶。
代理程式AI 助理，當伺服器已設定 AI 模型時。
GitHub、GitLab 和 Jira這些服務的通知和指令，一旦連接即可使用。

大多數應用程式可從應用程式列開啟，該列位於視窗右側邊緣。應用程式的啟用與停用是針對整個伺服器設定的，路徑為 系統控制台 › 擴充程式：社群管理員無法為單一社群啟用或停用應用程式。其設定也是伺服器層級的，除非本頁另有說明。若要新增應用程式或變更其設定，請洽詢系統管理員。

在社群中，應用程式會遵循頻道的權限設定：例如，只能讀取頻道的人可以查看該頻道的待辦事項清單和筆記，但無法修改；頻道的管理員可以刪除該頻道的筆記。管理員和擁有管理訊息權限的人員可以關閉該頻道中的任何投票。

頻道的待辦事項清單屬於該頻道的成員：所有能在頻道中貼文的人都可以新增和勾選待辦事項，並重新命名或封存清單。清單由建立者刪除，待辦事項由新增者刪除，或由頻道管理員、社群管理員和系統管理員刪除：其他成員無法刪除，即使他們可以重新命名頻道。在已封存或唯讀的頻道中，清單只能讀取。訪客只能向與他們共享頻道的人發送待辦事項。

自訂表情符號

自訂表情符號是人們在訊息和反應中使用的圖像，就像其他表情符號一樣，透過在冒號之間輸入其名稱來使用，例如 :party_parrot:。

  1. 開啟表情符號選擇器（在訊息框中、訊息的反應上，或用於您的狀態）。
  2. 點選搜尋框旁邊的+（新增自訂表情符號）。選擇器會顯示新增檢視。
  3. 拖曳、貼上或選擇圖片：PNG、GIF（包括動態）、JPEG 或 WebP，大小上限為 512 KB，解析度上限為 1028 × 1028 像素。選擇器會以表情符號顯示的大小預覽圖片。
  4. 輸入名稱：小寫字母、數字，以及-、+或_，最多 64 個字元。若名稱已被使用或是標準表情符號，選擇器會立即提示。
  5. 選擇儲存。新的表情符號會出現在選擇器的最上方，位於剛新增之下。

自訂表情符號按鈕位於+旁邊，列出伺服器上的自訂表情符號，並包含搜尋框、新增者與時間，以及您有權限刪除的項目上的刪除按鈕。相同的清單也位於整合 › 自訂表情符號中。

  • 自訂表情符號屬於整個伺服器，而非單一社群：伺服器上的所有人都可以使用。請選擇不會與其他社群的表情符號衝突的名稱。
  • 預設情況下，所有成員都可以新增自訂表情符號；訪客無法新增或刪除任何表情符號。使用者可以刪除自己的表情符號；只有系統管理員可以刪除其他人的表情符號，因此請向系統管理員請求移除不需要的表情符號。系統管理員可以在伺服器的權限中變更此設定，或在系統控制台中透過啟用自訂表情符號關閉自訂表情符號。

GIF、貼紙與迷因

當這些應用程式啟用時，表情符號選擇器會包含 GIF、貼紙和迷因分頁。

  • GIF 和貼圖來自系統管理員選擇的 GIF 服務，並套用系統管理員設定的內容分級。當系統管理員允許時，使用者可以新增自己的 GIF 和貼圖。預設只有系統管理員可以新增；系統管理員可以開放給除訪客外的所有人（誰可以新增 GIF 和貼圖）。在「GIF」和「貼圖」分頁中，搜尋框旁的 + 會開啟新增畫面（新增 GIF、新增貼圖），而管理按鈕（管理 GIF、管理貼圖）會列出使用者新增的內容，包含新增者與時間。整合頁面中的 自訂 GIF 和 自訂貼圖 也有效。新增的 GIF 和貼圖對伺服器上的所有人都可用；新增者與系統管理員可以刪除它們。
  • 迷因：任何人都可以在「迷因」分頁中選擇範本，撰寫文字並發布迷因。/meme 指令也有效。預設除訪客外的所有人都可以在「迷因」分頁搜尋框旁的 + 新增迷因範本，而管理按鈕會列出自訂範本，包含新增者與時間。系統管理員可以將此權限限制為僅系統管理員，或選擇 無（停用自訂範本）：已新增的範本仍可繼續使用。範本由整個伺服器共用，只有建立者與系統管理員可以刪除它們。

在公開社群中，建議要求您的系統管理員將 GIF 和迷因範本的上傳權限僅限於管理員。

白板庫

社群管理員可以為社群中的所有人新增形狀庫：在白板中，開啟看板的選單或庫面板，並選擇 管理庫。庫是一個最大為 5 MB 的 .excalidrawlib 檔案。

Webhook、斜線指令和機器人

整合將您的社群與其他工具連接起來：例如發布警報的監控系統、發布答案的表單，或查詢資訊的指令。要設定這些整合，請點擊您的頭像並選擇 整合。您會看到您有權限管理的整合類型：

整合功能說明預設情況下誰可以建立
送入的 Webhook另一個服務透過呼叫秘密 URL 將訊息發布到頻道中。社群管理員
寄出的 Webhook包含觸發詞的頻道訊息會傳送至另一服務，該服務可以回覆。或是訊息動作：使用者從訊息選單中將單則訊息傳送至該服務。社群管理員
斜線指令指令（例如 /weather）會呼叫其他服務，並在頻道中回覆。社群管理員
機器人帳號供程式使用的帳號，會以自己的名稱發文，並加上 機器人 標籤。系統管理員
OAuth 2.0 應用程式讓使用者使用 Antimatter 帳號登入的應用程式。系統管理員

訊息動作

當 觸發於 設為 從訊息選單 的傳出 Webhook 不會在訊息發布時觸發。它會成為訊息選單中的一個動作，位於 更多動作 下的 整合 群組中：選擇它會將該則訊息傳送至服務，該服務可以在頻道中或單獨回覆該使用者。請為它設定標題（選單中動作的名稱），以及（如果喜歡）圖示：圖片 URL 或已上傳的圖片，會以灰色顯示。將其綁定到一個公開頻道，或留空頻道欄位以在社群的每個公開頻道中提供此動作。封存頻道會刪除綁定到該頻道的 Webhook，因此封存的頻道只保留社群範圍的動作。訪客只能看到綁定到其所加入頻道的動作。

具有 管理整合 自訂角色的使用者，也可以管理 Webhook 和斜線指令（請參閱 角色與權限）。Webhook 和斜線指令屬於建立它們的社群。

系統管理員必須在 系統控制台 › 整合 › 整合管理 中啟用各種整合功能。傳入和傳出 Webhook 以及斜線指令預設為啟用；建立機器人帳號預設為停用。請將 Webhook 的 URL 和指令的令牌視為密碼：任何擁有這些資訊的人都可以向您的社群發文。

若要建立整合、機器人或應用程式，請參閱 在 Antimatter 上開發。

自動連結

自動連結可將問題編號等文字轉為連結，適用於社群中的所有訊息，且無需安裝任何應用程式。社群管理員可在 團隊設定 › 自動連結 中進行設定；請參閱 自動連結。

Playbooks

操作手冊是重複執行流程的檢查清單，例如處理事故、新同事入職或準備發布版本。每次流程啟動時，您都會執行操作手冊：Antimatter 會為該次執行建立或重用一個頻道，其中包含檢查清單、負責人及其狀態更新。

從應用程式列開啟操作手冊：其側邊欄會顯示該頻道的執行記錄與檢查清單。面板頂端的按鈕（瀏覽執行、操作手冊與任務）會開啟瀏覽檢視，其中包含所有執行、所有操作手冊與您的任務，您可以在這裡建立操作手冊（建立操作手冊）或匯入。操作手冊編輯器開啟時會加寬面板。頻道選單中的頻道自動化…項目，可設定歡迎訊息、新成員的分類，以及根據關鍵字建議操作手冊。

操作手冊屬於社群。預設情況下，任何能建立頻道的人都能建立操作手冊，因此實際上每位成員都可以。操作手冊可以對社群公開，也可以僅供其成員使用。

適合社群的良好操作手冊範例：歡迎新版主、處理檢舉、準備活動。適合組織的範例：事故回應、員工入職與離職。
