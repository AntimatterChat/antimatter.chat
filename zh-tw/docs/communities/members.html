成員與入門指南

人員如何加入您的社群、如何使用入門指南歡迎他們、如何記錄成員的詳細資訊，以及成員如何離開或被移除。

邀請人員

開啟社群選單並選擇邀請他人。預設情況下，每位成員都可以邀請他人；若無此權限，該選項將不會顯示。

  1. 在邀請為下方，選擇成員或訪客。此選項僅在伺服器啟用訪客功能時才會出現。
  2. 在收件人：中，輸入已在伺服器上擁有帳號的人員姓名，或尚未擁有帳號的人員電子郵件地址。
  3. 在新增至頻道下方，選擇受邀者將加入的頻道。對成員而言此為選填，對訪客而言則為必填。
  4. 選填地，選擇設定自訂訊息，以在邀請電子郵件中加入幾句話。
  5. 選擇邀請。摘要畫面將顯示已邀請的人員，以及無法送出的邀請。

透過電子郵件邀請需要伺服器能發送電子郵件，且已開啟電子郵件邀請功能。若伺服器無法發送電子郵件，您仍可添加已擁有帳號的人員。若電子郵件地址被拒絕，請洽詢您的系統管理員。

分享邀請連結

在同一對話框中，選取成員後，複製邀請連結可複製社群的邀請連結。任何開啟該連結的人都可以建立帳號（若伺服器允許註冊）並加入社群。您可以將其分享至電子報、網站或論壇貼文。

連結在您變更前均保持有效。若連結外洩至不該出現的地方，可透過團隊設定 › 存取中的重新產生建立新連結，舊連結隨即失效。同一時間，一個社群只有一個邀請連結。

邀請您已認識的人

若要將其他社群的人員帶入您的社群，請右鍵點擊其姓名並選擇邀請至社群，然後選擇目標社群。該人員將立即被加入。

公開社群

若社群為公開（請參閱誰可以加入），伺服器上任何擁有帳號的使用者皆可透過加入其他團隊找到並加入該社群，無需邀請。在允許任何人註冊的伺服器上，這是營運公開社群最簡單的方式。若社群僅允許特定電子郵件網域，其他地址的使用者即使持有連結也無法加入。

訪客

訪客是來自外部的人，例如客戶、承包商或合作夥伴組織。訪客只能看到被加入的頻道：他們無法瀏覽或加入社群的其他頻道。訪客的姓名旁會顯示訪客標籤，且包含訪客的頻道標題也會如此顯示。

  • 訪客帳號預設為停用。系統管理員可在系統控制台 › 驗證 › 訪客存取中啟用，並可要求訪客必須來自特定電子郵件網域，或必須使用雙重驗證。
  • 社群管理員可透過邀請他人邀請訪客，並選擇其可使用的頻道。若要稍後為訪客開放其他頻道，請從該頻道將其加入。
  • 當系統管理員允許時，允許受邀訪客使用魔法連結登入（無需密碼）可讓訪客透過電子郵件收到的連結登入。
  • 若要將訪客轉為正式成員，或將成員轉為訪客，請聯繫系統管理員：此操作需在系統控制台 › 使用者管理 › 使用者中，透過升級為使用者或降級為訪客完成。

訪客絕不會被自動加入頻道，即使社群中所有人都加入了所有頻道也是如此。

管理成員

開啟社群選單並選擇管理成員（成員看到的是檢視成員）。清單會顯示所有人員及其角色。在人員角色旁的選單中，您可以：

  • 使用設為團隊管理員將其設為社群管理員，或使用設為團隊成員取消該角色；
  • 透過移出團隊將其移出社群。

此對話方塊來自經典介面，因此仍顯示「團隊」。您也可以在任何看到某人姓名的地方對其採取行動：右鍵點擊姓名，或開啟其個人檔案卡片。如需管理員檢視、暫時禁言與移除功能，請參閱內容管理。

社群預設沒有成員人數上限。若系統管理員設定了上限（每個社群的最高成員數）且邀請開始失敗，請聯繫管理員調高上限。

新手引導

新成員引導功能會在成員首次開啟社群時向他們致意。它會顯示歡迎文字和幾個問題。每個答案都可以為新成員指派角色和頻道，讓成員從第一分鐘起就能找到合適的地方。

撰寫新手引導

  1. 如果答案應賦予角色，請先建立這些角色，並為它們開啟任何人都可取得（請參閱任何人都可取得的角色）。新手引導只能賦予對所有人開放的角色。
  2. 開啟社群選單，選擇團隊初始設定，然後選擇新成員引導…。這會開啟社群設定中的新成員引導分頁。
  3. 撰寫歡迎文字：簡述社群的主題與主要規則，幾行即可。
  4. 選擇新增問題，例如「什麼原因促使您加入？」。若允許使用者選擇多個答案，請保持可複選開啟。
  5. 為每個答案撰寫文字，然後點選該答案所賦予的角色與公開頻道。若要新增下一個答案，請選擇新增答案。
  6. 選擇儲存。

您可以提供的頻道是身為成員的公開頻道。若要移除迎新，請刪除其問題與歡迎文字，然後儲存。

新成員看到的內容

當某人首次開啟社群時，會顯示歡迎至對話框，其中包含您設定的文字與問題。他們選擇答案後點選完成，或選擇跳過。無論哪種方式，他們在該社群中都不會再次看到此對話框。在您設定新成員引導之前已加入的使用者，下次開啟社群時會看到它。

成員之後可以從社群選單下的您的角色…變更其公開角色。

對於公開社群，請將迎新與一個鎖定且包含規則頻道與公告頻道的「資訊」分類結合，並在規則頻道頂部加上橫幅（請參閱頻道設定）。

成員屬性

成員屬性是關於您社群成員的詳細資訊，會顯示在社群中的個人檔案卡片上，例如公司、地點、分包商或代稱。這些屬性屬於該社群：伺服器上的其他社群不會看到它們。

定義屬性

開啟社群選單，選擇團隊初始設定，然後選擇成員屬性…：這會開啟社群設定中的成員屬性分頁。選擇新增屬性。針對每個屬性，請設定：

  • 名稱，例如「公司」。
  • 類型：文字、單選、多選、日期、連結、電子郵件、電話號碼、人員或人們。若為選項，請列出選項。
  • 設定者：各成員自行填寫，或僅由管理員設定。
  • 可見者：所有人、管理員或已隱藏。管理員與成員本人永遠可見；已隱藏的屬性不會顯示在個人檔案中。
  • 在成員清單中顯示：在成員清單中，於人名下方顯示該屬性（取代職位），並讓所有人依此篩選清單。只能以此方式顯示一個屬性。

使用 上移 和 下移 來設定個人檔案卡片的順序。社群最多可擁有 50 個屬性。刪除屬性時，所有人的對應值也會一併刪除。

填寫屬性

若要設定某人的屬性，請右鍵點擊其姓名並選擇 編輯屬性…。社群管理員可以設定所有人的所有屬性；成員可以設定自己的屬性，但無法設定由管理員設定的屬性。僅對 管理員 可見的屬性，會在個人檔案卡片上顯示鎖定圖示。

在公司中，由管理員設定且僅對管理員可見的屬性，是存放內部細節（例如合約結束日期）的好位置，這些資訊不需要讓同事看到。

伺服器本身也有屬性，對每個社群都相同，由系統管理員在 系統控制台 › 系統屬性 › 屬性管理 中定義。這些屬性會顯示在社群屬性之前，且只有系統管理員可以為他人設定。部分屬性可能來自登入提供者，例如公司目錄。

當成員離開或被移除時

  • 成員可透過社群選單中的離開團隊離開。
  • 離開或被移除的人將失去其在社群中的角色和團隊。他們的訊息會保留。
  • 被移出社群的人可以透過新的邀請重新加入，或者如果社群是公開的，也可以再次加入。若要永久禁止某人進入，系統管理員必須停用其帳號（請參閱 禁止某人進入）。
