經營社群

本指南適用於在 Antimatter 上營運社群的人員，包括管理員與版主。內容涵蓋社群的設定、頻道的組織、角色的指派、新成員的歡迎，以及如何維持良好的社群氛圍。

什麼是社群

社群是 Antimatter 伺服器上的一個空間，擁有獨立的頻道、成員、角色與規則。每個社群在社群欄（視窗最左側的欄位）中都有專屬圖示。單一伺服器可容納多個社群，而一個人也可以加入多個社群。私人訊息不屬於任何社群：它們會跟隨您到伺服器的任何地方。

在系統控制台及部分較舊的對話框中，社群仍被稱為「團隊」。這兩個詞彙意思相同。在 Antimatter 中，「團隊」指的是社群內部的群組，擁有標籤與負責人（請參閱 社群內的團隊）。

兩種社群類型

Antimatter 有兩種截然不同的使用方式。本指南涵蓋這兩種情況，並說明建議差異之處。

公司或組織工作區公開或興趣社群
成員組成同事，有時也包括來自合作夥伴組織的訪客。任何找到它的人，彼此通常是陌生人。
加入方式透過邀請，或電子郵件網域（例如您公司的網域）。任何人都可加入的公開社群，或共用的邀請連結。
頻道每個團隊或專案都有許多頻道；人們加入與自己工作相關的頻道。頻道數量較少，且所有人都加入所有頻道。
管理員關注的重點控制、訪客管理、訊息保留、合規性。內容審核、角色管理、新成員引導。
進一步閱讀為組織營運 Antimatter內容審核

角色與職責

Antimatter 提供幾個內建角色，且每個社群都可以在這些角色之上添加自訂角色。

  • 系統管理員：管理整個伺服器。系統管理員可以在所有社群中執行任何操作，且是唯一能使用系統控制台（伺服器管理頁面）的人員。如果您不是系統管理員，某些任務將需要系統管理員協助；本指南會說明何時需要。
  • 團隊管理員：管理單一團隊。團隊管理員可變更團隊設定、將其他人設為團隊管理員、建立角色，並管理除其他管理員以外的任何人。其個人檔案卡片上會顯示 團隊管理員 標籤。建立團隊的人將成為該團隊的第一位管理員。
  • 成員：社群中的其他人。預設情況下，成員可以建立頻道、邀請人員，並管理其所加入的頻道。
  • 訪客：來自外部的人員，僅限於被邀請加入的頻道。只有當系統管理員開啟訪客帳戶功能時，訪客才存在。
  • 頻道管理員：在特定頻道中擁有額外權限的成員。其個人檔案卡片上會顯示頻道管理員標籤。

系統沒有內建的「調解員」角色。調解員是您可以建立的自訂角色，您可以精確選擇他們能執行的操作：刪除訊息、暫時禁言、移除成員、管理頻道。社群版面配置預設值會為您建立一個「調解員」角色。請參閱角色與權限。

建立社群

  1. 在團隊側邊欄中，選擇 + 按鈕（新增團隊），然後選擇 建立團隊。
  2. 輸入名稱。您可以稍後再修改。
  3. 檢查網址：它會根據名稱自動填入，並成為社群連結的一部分。之後無法修改。
  4. 若要建立開放式團隊，請保持 伺服器上的任何人都可以加入 開啟；若要僅限受邀者加入，請將其關閉。
  5. 選擇 建立團隊。

您將進入「Town Square」，這是社群的第一個頻道，而您是其管理員。Antimatter 接著會建議您使用預設值來設定社群；請參閱社群版面配置。

如果您看不到建立社群，表示系統管理員尚未授予您建立社群的權限（系統控制台中權限設定裡的建立團隊）。

若要加入已存在的團隊，請選擇 +，然後選擇 加入其他團隊：系統會列出您可以加入的團隊。

社群選單

本指南描述的大部分内容都始於社群選單。您可以點擊頻道列表頂部的社群名稱，或在欄位中右鍵點擊社群圖示來開啟它。您看到的内容取決於您的權限：

  • 邀請他人、團隊設定 以及 管理成員（成員看到的是 檢視成員）。
  • 團隊初始設定：角色…、新成員引導…、團隊版面配置… 以及 成員屬性…。
  • 使用者群組…、建立頻道 以及 建立分類。
  • 個人選項：標記為已讀、靜音團隊、僅顯示未讀頻道、隱藏靜音頻道、通知設定以及 離開團隊。

新社群的檢查清單

  1. 提供描述和圖示，並決定誰可以加入：社群設定。
  2. 決定是否所有人都加入每個頻道，並設定分類和頻道：頻道。
  3. 建立所需的角色，至少包括版主：角色與權限。
  4. 撰寫迎新指南並邀請成員：成員與迎新。
  5. 商定管理方式：管理。
  6. 新增自訂表情符號、自動連結和整合：應用程式與整合。
