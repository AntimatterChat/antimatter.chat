社群設定

屬於團隊的設定：其名稱與圖示、誰可以加入、其類型、頻道成員資格如何運作、新成員的初始位置、自動建立的連結、專屬的 AI 供應商，以及版面配置。

開啟社群設定

開啟團隊選單：點擊頻道列表上方的團隊名稱，或在團隊欄中右鍵點擊其圖示。然後選擇 團隊設定。只有團隊管理員、擁有 管理員 角色的使用者，以及系統管理員才能看到此選項。

團隊選單中 團隊初始設定 下的項目（角色…、新成員引導…、團隊版面配置…、成員屬性… 和 模型連線…）會在對應的分頁上開啟相同的對話框。僅管理角色或僅管理團隊模型連線的使用者，只能看到這些分頁。

設定對話框包含以下分頁：

分頁內容
概觀名稱、描述與圖示。
存取公開或私人、允許的電子郵件網域、邀請碼。
團隊成員 與 頻道成員基於人員屬性的成員資格規則。這些分頁只有在系統管理員開啟基於屬性的存取控制時才會出現。
頻道團隊類型、所有頻道的成員，以及預設頻道。
角色團隊的角色、角色顏色、團隊徽章，以及成員列表如何分組人員（請參閱 角色與權限）。
新成員引導給新成員的歡迎文字與問題（請參閱 新成員引導）。
成員屬性顯示在成員個人檔案卡片上的詳細資訊（請參閱 成員屬性）。
團隊版面配置預設值與範本（請參閱 下方）。
自動連結在訊息中變成連結的文字樣式。
模型連線團隊專屬的 AI 供應商（請參閱 下方）。

新成員引導 分頁有獨立的 儲存 和 取消 按鈕。在 角色、成員屬性 和 團隊版面配置 分頁上，變更會在您操作時自動儲存，其編輯器中也有 儲存 和 取消 按鈕，而 關閉 則用於關閉對話框。如果分頁有未儲存的變更，Antimatter 會在您切換分頁或關閉對話框前提醒您。

有些分頁來自經典介面，仍然顯示「團隊」：「團隊名稱」、「公開團隊」、「團隊圖示」。在 Antimatter 中，團隊與社群是同一件事。

名稱、描述與圖示

在概觀分頁中：

  • 團隊名稱 是顯示在社群欄與頻道列表頂部的名稱。它可以包含 2 到 64 個字元。
  • 敘述可幫助使用者在瀏覽可加入的社群時做出選擇。敘述最多可包含 50 個字元。
  • 團隊圖示是社群欄中的圖片，可以是 BMP、JPG 或 PNG 檔案。若未設定，社群欄將顯示社群名稱的縮寫。刪除圖片可立即移除該圖片。

使用對話框底部的列儲存您的變更。社群的地址（URL 中伺服器名稱之後的部分）是在社群建立時選定的，之後無法變更。

誰可以加入

在 存取 分頁中：

  • 可見性：公開團隊會出現在伺服器上任何擁有帳號的使用者都能瀏覽並加入的社群列表中。私人團隊只能透過邀請加入。從公開切換為私人時，系統會產生新的邀請連結，並使舊連結失效。
  • 只允許具有特定電子郵件網域的用戶加入此團隊：勾選此選項後，只有電子郵件地址結尾為您所列網域的人才能加入，例如 example.org。請用空格或逗號分隔多個網域。這適合公司工作區；如果是公開社群，請保持未勾選。
  • 邀請碼：社群邀請連結中的代碼。重新產生會建立新的連結並使舊連結失效。如果邀請連結被分享到不該出現的地方，請執行此操作。

如果社群成員來自連結的群組（例如由系統管理員設定的 LDAP 目錄），存取分頁會顯示此資訊，且這些選項將被群組同步取代。

加入社群也取決於伺服器的設定：是否允許任何人建立帳號，以及允許哪些電子郵件網域。這些是伺服器設定；請向您的系統管理員詢問（見 要向系統管理員詢問什麼）。

社群預設沒有成員人數上限。系統管理員可以為伺服器上的所有社群設定上限（位於系統控制台 › 網站設定 › 使用者與團隊中的每個社群的最高成員數）；一旦社群達到該上限，在有人離開之前，其他人無法加入。

團隊類型

在 頻道 分頁上，團隊類型 會告知 Antimatter 您的團隊是如何運作的。變更後會立即儲存。

類型適用對象變更內容
社群公開或興趣團隊。只有團隊管理員，以及擁有 管理頻道 角色的使用者，可以封存頻道。其頻道中的通話預設為關閉：語音頻道僅供語音對話使用。
工作場所公司或組織的工作區。頻道的管理員（包括建立者及其指定的管理員）也可以封存該頻道。頻道內的通話遵循伺服器的通話預設值，除非系統管理員已將其變更，否則預設為開啟。

在兩種類型中，只有頻道管理員、社群管理員以及具有管理訊息權限的版主才能將訊息置頂。擁有獨立通話設定的頻道會保留該設定，而私人訊息與群組訊息不受類型影響。

新社群的類型由系統管理員為伺服器所選定（新社群的類型，除非變更，否則預設為社群）。套用版面配置預設值也會設定類型：混合與社群會建立社群，工作場所會建立工作場所（請參閱社群版面配置）。範本會保留其匯出來源社群的類型。

所有頻道中的所有成員

在頻道分頁中，成員加入所有頻道決定您社群中的頻道成員資格運作方式。

  • 開啟：所有成員都會加入所有公開頻道，以及其角色允許的私人頻道。成員不會加入或離開頻道：他們會靜音不想追蹤的頻道。頻道選單中原本顯示離開頻道的位置，現在改為靜音頻道，且管理員無法將任何人從單一頻道中移除。若要將某人排除在外，請將其移出社群、暫時禁言，或修改該頻道的權限。
  • 關閉：成員可以加入想要的頻道，也可以離開，頻道管理員則可以新增或移除成員。

訪客和機器人永遠不會被自動加入：他們只出現在被加入的頻道中。未由角色開啟的私人頻道（僅限邀請的頻道）也不受影響。

切換後會立即儲存。開啟此選項會將所有成員加入他們可見的頻道；在大型社群中，這可能需要一點時間。關閉此選項則會保留成員目前的所在位置，他們可以自由離開。

新的社群預設會開啟此選項，除非系統管理員變更了預設值（位於系統控制台的新社群將所有成員加入所有頻道）。在此設定推出前建立的社群，預設為關閉，直到您開啟為止。

對於擁有許多團隊和專案的公司工作區，通常關閉較佳：成員只能看到與工作相關的頻道。對於小型公開社群，開啟此選項可讓所有成員都參與對話。

預設頻道

預設頻道是新成員加入時的落點，也是社群加入與離開訊息的發布位置。所有成員都在其中，且無法離開。建立社群時，其預設頻道為 General（其位址為 general）。

較舊的社群擁有 Town Square。升級至 Antimatter 0.9.0 時，它被重新命名為 General，位址為 general，除非社群中已存在具有該位址的頻道；您自行設定的名稱會保留。指向 town-square 的舊連結仍會導向社群的預設頻道。

若要選擇其他頻道，請使用頻道分頁上的預設頻道，或開啟公開頻道的選單並選擇設為預設頻道。預設頻道必須是未封存的公開頻道。所有成員都會被加入新的預設頻道。

General、Off-Topic 和預設頻道都可以被封存，但只能由社群管理員執行。如果預設頻道被封存，社群將不再有預設頻道：設定會顯示已封存的頻道，直到您選擇另一個頻道為止，成員會進入他們所在的第一个頻道。當 General 消失時，清單會提供無：每位成員的第一個頻道。

自動連結

自動連結會在訊息發布時，將文字轉換為連結。典型用途是問題編號：LUM-12 會變成指向追蹤器中該問題的連結。這些連結適用於社群中發布的所有訊息、所有應用程式、通知和搜尋結果，因為伺服器會在儲存前重寫訊息。程式碼、連結和圖片不會被修改。

在自動連結分頁上：

  1. 選擇新增自動連結。您可以從現成的範本（問題編號、拉取請求、合併請求、CVE 識別碼）或空白開始。
  2. 為其命名，例如「Jira 問題」。
  3. 在模式中輸入正規表示式，例如 (PROJ-\d+)。
  4. 在轉換為欄位中，輸入匹配後要轉換成的內容。$0 代表整個匹配的文字，$1、$2 等代表樣式中的群組。例如：[$1](https://issues.example.com/browse/$1)。
  5. 選擇套用範圍：所有頻道，或僅限部分頻道。
  6. 選填：勾選僅比對完整單字，以及包含機器人的訊息（如果希望由機器人發布的訊息也能被連結）。
  7. 在輸入訊息試試看中輸入範例以查看結果，然後選擇儲存。

每個自動連結都有一個開啟選項，可將其暫停而不刪除。也連結已編輯的訊息會在訊息被編輯時套用自動連結；否則只有新訊息會被連結。一個團隊最多可設定 100 個自動連結。

模型連線

模型連線是指 AI 供應商，例如相容於 OpenAI 的服務或 Anthropic，包含其位址和金鑰。系統管理員會設定伺服器範圍的連線。社群也可以擁有自己的連線，供其成員的應用程式在社群頻道中使用。Antimatter 內建的 AI 功能（重寫、摘要、自動翻譯、文字轉語音）使用系統管理員選擇的伺服器範圍連線，而非社群的連線。

社群管理員和具有管理模型連線權限的角色可以在模型連線分頁中管理它們，或從社群選單下的團隊初始設定、模型連線…中管理。選擇新增ㄧ個連線，然後填寫：

  • 名稱，以及供應商：OpenAI-compatible（大多數供應商和閘道）或 Anthropic。預設值會填入常用的值。
  • Base URL 和 API 金鑰。金鑰會加密儲存，之後不會再顯示，僅顯示最後四個字元。額外標頭是供需要它們的閘道使用。
  • 模型：當應用程式未指定時，用於各項功能的模型。載入模型會列出該端點提供的模型。
  • 限制：每分鐘的請求數和每月的 token 數，適用於連線和個人。留空或 0 表示沒有限制。
  • 誰可以使用：社群中的所有人，或僅限您選擇的團隊、角色和管理員。訪客只有在開啟也允許訪客時才能使用，此選項預設為關閉。

測試連線可在儲存前或儲存後進行檢查。每個連線都會顯示本月的使用量，而使用量則提供詳細資訊。刪除連線會遺忘其金鑰，且使用它的功能將停止使用 AI。

社群版面配置、預設值與範本

版面配置是社群的結構：包括所有人的分類及其中的頻道、其頻道、其角色及其權限、其入門指南，以及其類型。開啟社群設定的團隊版面配置分頁，或在社群選單中選擇團隊初始設定，然後選擇團隊版面配置…。

提供三種預設值：

預設值設定內容
混合式（建議）一個鎖定狀態的「資訊」分類，包含 General；一個開放狀態的「社群」分類，包含 Off-Topic，成員可在此建立自己的頻道；以及一個「Moderators」角色。類型設定為社群。
社群僅由管理員排列的分類（包含 General 的「資訊」，以及包含 Off-Topic 的「頻道」），以及一個「Moderators」角色。類型設定為社群。
工作場所所有人自行排列自己的分類，並封存他們建立的頻道。這會移除所有人的分類；角色會保留。類型設定為工作場所。

預設值中的「Moderators」角色可以編輯和刪除他人的訊息、將訊息置頂、重新命名頻道並管理其成員，以及移除和暫時停用人員。它不會封存頻道（請參閱 Moderators 角色）。

當團隊管理員第一次開啟一個沒有「所有人」分類且沒有角色的新團隊時，Antimatter 會在設定加上團隊名稱下方，提供一次預設選項。選擇稍後再說即可略過。

將版面配置複製到其他社群

  1. 在要複製的團隊中，開啟團隊版面配置…並選擇匯出為範本。您的瀏覽器將下載一個 JSON 檔案。
  2. 在另一個團隊中，開啟團隊版面配置…，選擇套用範本…並選取該檔案。

套用預設值或範本會新增缺少的頻道與角色、更新同名角色、將頻道歸入對應的分類、取代新手引導內容，並設定社群類型。除了範本未包含的「所有成員」分類外，不會移除任何其他內容。匯出的內容僅包含您為成員的頻道，且不含任何訊息。在升級至 0.9.0 之前匯出、且命名為 Town Square 的範本，會以 General 取代它。

非社群的設定

  • 私人訊息與訊息請求：來自陌生人的私人訊息是正常送達還是作為請求，由每位成員自行決定，他們可以在設定中的隱私與安全下，依社群個別設定。社群管理員無法代為設定（請參閱忽略與封鎖）。
  • 自訂表情符號、應用程式、成員上限以及新社群的類型，均由系統管理員為整個伺服器設定。系統管理員也可以為整個伺服器關閉依角色分組成員的功能，此設定會優先於您社群的成員清單選項。

離開與刪除社群

任何人都可以透過團隊選單底部的離開團隊離開團隊。團隊管理員無法從 Antimatter 介面封存或刪除團隊：這需要由系統管理員在系統控制台 › 使用者管理 › 團隊中執行，方法是開啟該團隊並選擇封存團隊。
