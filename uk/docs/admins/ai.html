ШІ

Функції ШІ Antimatter використовують моделі на ваш вибір: хмарного провайдера або сервер у вашій мережі. Жодні дані не передаються дотоді, поки ви не налаштуєте модель. На цій сторінці описано кожну функцію, які дані вона передає та як її вимкнути.

Функції ШІ

ФункціяНалаштовується вТип моделіУвімкнено за замовчуванням
Агенти ШІ: чат із ботом, резюме обговорень і каналів, допомога у полі введенняДодаток AgentsБудь-яка служба великої мовної моделі (LLM)Додаток увімкнено, але не виконує жодних дій, доки ви не додасте службу
Транскрипція дзвінків та живі субтитриДодаток CallsПеретворення мовлення в текст, сумісне з OpenAIні
ОзвученняСерверПеретворення тексту в мовлення, сумісне з OpenAIні
Автоматичний переклад каналівСерверLibreTranslate, LLM, сумісна з OpenAI, або служба Agentsні

«Сумісне з OpenAI» означає сервер, який пропонує той самий HTTP API, що й OpenAI. Більшість серверів моделей, які можна запустити самостійно, це роблять (наприклад Ollama, vLLM, сервер llama.cpp або сервери перетворення мовлення в текст і тексту в мовлення), а також багато хмарних провайдерів. Для жодної з цих функцій не потрібна ліцензія.

Агенти ШІ

Додаток «Агенти» (id mattermost-ai) увімкнено за замовчуванням. Його налаштування складається з двох кроків: додавання сервісу (з’єднання з провайдером моделі) та створення агентів (ботів, які використовують сервіс).

1. Додайте службу

Перейдіть у Системна консоль › Плагіни › Агенти і, у розділі AI Services, натисніть Add an AI Service. Оберіть Service type:

  • OpenAI Compatible: для сервера моделей, який ви запускаєте самостійно, або будь-якого провайдера з API у стилі OpenAI. Заповніть API URL (наприклад http://ollama:11434/v1 або http://vllm.internal:8000/v1) та Ключ API лише тоді, коли сервер його потребує. Якщо сервер підтримує лише API Chat Completions, вимкніть Use Responses API.
  • OpenAI, Anthropic, Google Gemini, Google Vertex AI, AWS Bedrock, Azure, Cohere, Mistral: хостингові провайдери. Кожен потребує свого Ключа API (Bedrock: регіон AWS та облікові дані або роль IAM; Vertex AI: проєкт, регіон та обліковий запис служби; Azure: також API URL).

Потім встановіть Модель за замовчуванням (список, якщо провайдер може повідомляти про свої моделі, інакше введіть назву вручну), а також, якщо провайдер не повідомляє про них, Обмеження входних токенів та Обмеження вихідних токенів. Резервний сервіс може взяти на себе обробку, якщо цей не спрацює. Збережіть зміни.

Сервер виконує ці запити сам, тому він повинен мати доступ до API: модельний сервер у тому самому compose-проєкті, у вашій мережі або в Інтернеті. Вихідні запити дотримуються змінних HTTP_PROXY та HTTPS_PROXY.

2. Створення агентів

Агентів створюють на сторінці Агенти веб-додатку: відкрийте її з меню продукту або через Керувати у виборі агента на панелі «Агенти». Її адреса — https://chat.example.com/plug/mattermost-ai/agents. Кожен агент має Відображуване ім'я, Agent Username (як його згадують), Service та, за бажанням, модель, Custom Instructions, а також перемикачі Enable Vision (зображення) та Enable Tools. Вкладка Доступ обмежує канали, де агента можна використовувати, та користувачів, яким це дозволено. У AI Functions системної консолі пункт Default bot визначає агента, який використовується, коли жоден не обрано, наприклад для резюме дзвінків.

За замовчуванням кожен користувач може створювати власних агентів із використанням налаштованих вами сервісів. Щоб обмежити це лише адміністраторами, приберіть дозвіл Керування власними ШІ-агентами з ролі учасників у Системна консоль › Керування користувачами › Дозволи.

Додаткові можливості застосунку «Агенти»

  • Пошук за векторними описами (експериментальна, вимкнено): семантичний пошук серед повідомлень. Потребує PostgreSQL із розширенням pgvector та модель для векторизації (OpenAI або сумісну з OpenAI). Вона надсилає кожне повідомлення до моделі векторизації, включно з приватними каналами та приватними повідомленнями.
  • Веб-пошук (вимкнено): дозволяє агентам шукати в мережі через Google, Brave або ваш власний сервер SearXNG.
  • Вбудовані інструменти: за наявності провайдерів, які їх пропонують, агенти можуть використовувати власний веб-пошук провайдера (увімкнено за замовчуванням для нових агентів, де підтримується), отримання веб-сторінок та виконання коду. Ці інструменти працюють на боці провайдера. Вимкніть їх для кожного агента окремо.
  • Протокол контексту моделей (MCP): підключення агентів до серверів MCP, яким ви довіряєте, для додаткових інструментів.
  • Дебаг: Trace Output (вимкнено, журнали сервера або кінцева точка OpenTelemetry) та Enable Token Usage Logging, який записує кількість токенів у logs/agents/token_usage.log.

Розпізнавання мовлення: транскрипція та субтитри дзвінків

Дзвінки можна транскрибувати з живими субтитрами за допомогою сервера розпізнавання мови, який пропонує кінцеву точку /v1/audio/transcriptions, сумісну з OpenAI. Налаштування виконується в розділі Дзвінки та голос. Якщо увімкнено Summarize transcriptions, агент за замовчуванням також публікує резюме кожного транскрипту.

Синтез мови: озвучення

Якщо текст у мовлення увімкнено, у меню кожного повідомлення є пункт Прочитати вголос: сервер надсилає текст повідомлення до API тексту в мовлення та відтворює аудіо. Налаштування у Системна консоль › Інтеграції › Текст у мовлення:

НалаштуванняКлюч і зміннаЩо вказати
Озвучення повідомленьTextToSpeechSettings.Enable, AM_TEXTTOSPEECHSETTINGS_ENABLEtrue (вимкнено за замовчуванням)
Базова URL APITextToSpeechSettings.URL, AM_TEXTTOSPEECHSETTINGS_URLБазова URL-адреса до /v1 включно, наприклад http://tts.internal:8000/v1. Сервер звертається до його кінцевої точки /audio/speech.
МодельTextToSpeechSettings.Model, AM_TEXTTOSPEECHSETTINGS_MODELМодель під назвою, якою її вказує API, наприклад tts-1. Обов’язкове поле.
ГолосTextToSpeechSettings.Voice, AM_TEXTTOSPEECHSETTINGS_VOICEОдин із голосів моделі або порожнє значення для голосу за замовчуванням.
Ключ APITextToSpeechSettings.APIKey, AM_TEXTTOSPEECHSETTINGS_APIKEYНадсилається як токен доступу. Порожнє, якщо API не потребує ключа.

Перед надсиланням сервер видаляє блоки коду, посилання, коди емодзі та форматування, а також обмежує текст 4000 символами. Він запитує аудіо у форматі MP3 і зберігає останні 64 результати в пам’яті, тому повідомлення, яке читають двічі, надсилається лише один раз.

Автоматичний переклад

Автоматичний переклад показує повідомлення каналу в рідній мові кожного читача. Налаштуйте його в Системна консоль › Конфігурація сайту › Локалізація, у розділі Автоматичний переклад:

НалаштуванняКлючТипове значення
УвімкнутиAutoTranslationSettings.EnableВимкнено
Провайдер перекладуAutoTranslationSettings.Providerlibretranslate, openai (відображається як "OpenAI-compatible API") або agents (служба додатка Agents)
Дозволені мовиAutoTranslationSettings.TargetLanguagesen: мови, на які можна перекладати повідомлення
Час очікування перекладу (мс)AutoTranslationSettings.TimeoutMs5000
Restrict auto-translation on direct messages and group messagesAutoTranslationSettings.RestrictDMAndGMВимкнено

Кожен провайдер має власні поля:

  • LibreTranslate: API-адреса LibreTranslate та API-ключ LibreTranslate (AutoTranslationSettings.LibreTranslate.URL, .APIKey). Сервер LibreTranslate може працювати у вашій власній мережі.
  • Сумісний з OpenAI API: Базова URL API (включно з /v1; сервер використовує його endpoint для завершення чату), Модель та Ключ API (AutoTranslationSettings.OpenAI.URL, .Model, .APIKey). Непогано працює невелика модель перекладу, запущена локально.
  • Агенти: ШІ-сервіс, один із сервісів, налаштованих у додатку Agents.

Після увімкнення адміністратори каналу вмикають переклад для конкретного каналу в його налаштуваннях (Автоматичний переклад), а кожен учасник може відмовитися від нього через меню каналу (Перекласти повідомлення). У приватних та групових повідомленнях будь-який учасник може увімкнути переклад; якщо обмеження ввімкнено, переклад там недоступний. Перекладені повідомлення мітяться написом «Перекладено з …» з посиланням на оригінал.

Код, посилання, згадки та емодзі замінюються на заміни перед відправкою тексту, а потім відновлюються.

Щоб утримати всі дані в межах вашої мережі, спрямовуйте кожну функцію на сервери, які ви адмініструєте самостійно. Якщо використовуєте хмарного провайдера, перевірте його умови зберігання даних та повідомте користувачів, які функції надсилають їхні повідомлення назовні.

Вимкнення ШІ

Єдиного перемикача немає: у кожної функції є власний.

  • Агенти: вимкніть додаток Agents у Системна консоль › Плагіни › Керування плагінами. Це також прибере резюме дзвінків та провайдера перекладу Agents.
  • Транскрипція та живі субтитри: AM_CALLS_ENABLE_TRANSCRIPTIONS=false та AM_CALLS_ENABLE_LIVE_CAPTIONS=false (типові значення).
  • Прочитати вголос: вимкніть Озвучення повідомлень (AM_TEXTTOSPEECHSETTINGS_ENABLE=false, значення за замовчуванням).
  • Переклад: вимкніть автоматичний переклад (AM_AUTOTRANSLATIONSETTINGS_ENABLE=false, типове значення).

Вимкнення додатка Agents не вимикає три інші функції: вони викликають власні API напряму.
