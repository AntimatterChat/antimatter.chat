Запуск сервера

Цей посібник призначений для системних адміністраторів, які встановлюють та експлуатують сервер Antimatter. Припускається, що ви знайомі з Linux, Docker і зворотними проксі, але не з Antimatter.

З чого складається розгортання

Antimatter — це самостійно хостовий командний чат, форк Mattermost. Повне розгортання складається з таких компонентів. Обов’язковими є лише перші три.

КомпонентПризначенняОбов’язковий
Сервер AntimatterОдна програма на Go (antimatter), яка надає веб-додаток, API та вебсокети на порту 8065, запускає вбудовані додатки (плагіни) та передає медіа для дзвінків на порту 8443. Керується командним інструментом amctl.так
PostgreSQLБаза даних: повідомлення, користувачі, спільноти та, у рекомендованій конфігурації, налаштування сервера. Версія 15 або новіша.так
Файлове СховищеЗавантажені файли, зображення та встановлені додатки: S3-сумісна служба (у файлі compose запускається RustFS) або локальний каталог.так
Зворотний проксіHTTPS перед сервером: профіль Caddy у файлі compose або ваш власний nginx.для продуктивної експлуатації
Служба GIF (gifs-server)GIF та наклейки для вибору GIF із вашого власного каталогу. Використовує API Tenor.ні
Проксі для push-сповіщеньПередає сповіщення в мобільний додаток через Apple та Google.для мобільних сповіщень
rtcd, TURN-серверОкремий медіа-сервер для багатьох дзвінків та релей для користувачів за строгими файрволами.ні
AI-кінцеві точкиМоделі, що забезпечують переписування, стислі підсумки, переклад, озвучування, AI-агентів та транскрипцію дзвінків, додаються як підключення моделей: хмарний провайдер або сервери, які ви адмініструєте.ні

Antimatter не має ліцензійних обмежень і не має платної версії: єдиний вхід, LDAP, висока доступність, експорт для відповідності вимогам, збереження даних та інші функції, які Mattermost відводить для платних планів, усі включені.

Вимоги

  • Сервер на Linux, amd64 або arm64, з 2 ядрами CPU та 4 ГБ пам’яті або більше для кількох сотень користувачів, а також місцем на диску для файлів, які завантажують користувачі.
  • Docker Engine із плагіном Compose (docker compose) для рекомендованого способу встановлення. Або, для пакетів, сервер на базі Debian, Ubuntu, Fedora або сумісний із RHEL із systemd.
  • Для продуктивної експлуатації: доменне ім’я, що вказує на сервер, та відкриті порти 80 і 443 для HTTPS.
  • Для дзвінків: порт 8443, UDP та TCP, доступний для тих, хто дзвонить.
  • Для електронної пошти: SMTP-сервер, через який Antimatter може надсилати листи.

Швидкий старт

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)
EOF
docker compose up -d

Потім відкрийте URL-адресу сайту та створіть акаунт: перший акаунт стає системним адміністратором. Встановлення пояснює кожен крок та інші способи встановлення.

У цьому посібнику

  • Встановлення: Docker Compose, образи, перший адміністратор, пакети .deb та .rpm, архів релізу.
  • Налаштування: параметри в базі даних або файлі, змінні середовища AM_, Системна консоль, amctl, журнали.
  • Домен і HTTPS: URL-адреса сайту, Caddy, nginx, адреси клієнтів.
  • Дзвінки та голос: порти, NAT, TURN, rtcd, транскрипція та живі субтитри.
  • Електронна пошта та push-сповіщення: SMTP, push-проксі та мобільний додаток.
  • Вбудовані додатки: які додатки увімкнено, їхні налаштування, встановлення інших.
  • ШІ: підключення моделей, вбудовані функції ШІ, агенти, мовлення та переклад, ключ шифрування та дані, які передаються.
  • Вхід та акаунти: реєстрація, паролі, MFA, єдиний вхід, LDAP, гості, сесії.
  • Резервне копіювання та оновлення: резервне копіювання, відновлення, оновлення, перехід з Mattermost.
  • Експлуатація: моніторинг, масштабування, зберігання даних, відповідність вимогам, усунення несправностей.
  • Безпека: чек-лист захисту та зовнішні з’єднання.
  • Розгортання настільного додатка: MSI, Group Policy та Intune, профілі macOS та файл політики для Linux.

Ви керуєте спільнотою, а не сервером (канали, ролі, модерація)? Дивіться Керування спільнотою. Створюєте інтеграції? Дивіться Розробка на Antimatter.

Ваша перша година

  1. Встановіть сервер і одразу створіть акаунт адміністратора.
  2. Розмістіть сервер за HTTPS на власному домені.
  3. Налаштуйте SMTP та надішліть тестовий лист.
  4. Відкрийте порт для дзвінків. Для компанії встановіть тип нових спільнот на Робоче середовище, щоб дзвінки були доступними в каналах.
  5. Визначте, хто може реєструватися, та увімкніть MFA.
  6. Перегляньте зовнішні з’єднання в розділі Безпека.
  7. Налаштуйте щоденні резервні копії. Перед додаванням підключень моделей ШІ встановіть ключ шифрування ШІ.

Отримання допомоги

Завдавайте запитання в обговореннях спільноти, а про помилки повідомляйте в репозиторії спільноти. Проблеми безпеки повідомляйте конфіденційно, як описано в політиці безпеки.
