Antimatter پر تعمیر

یہ رہنما ڈویلپرز کے لیے ہے۔ اس میں API استعمال کرنے والے اسکرپٹس اور بوٹس، ویب ہکس اور سلاش کمانڈز پر مبنی انضمام، ایپس (پلگ انز) جو سرور اور ویب ایپ کو خصوصیات فراہم کرتی ہیں، اور Antimatter کو سورس سے بلڈ کر کے اس میں حصہ ڈالنے کا طریقہ شامل ہے۔

Antimatter کو وسیع کرنے کے طریقے

جو کام کرے اس کے لیے سب سے ہلکا ٹول منتخب کریں۔ پہلے چار کے لیے سرور تک رسائی کی ضرورت نہیں ہے؛ ایپس اس کے اندر چلتی ہیں۔

ٹولیہ کیا کرتا ہےکس کے لیے موزوں ہے
REST APIایپس جو کچھ بھی کرتی ہیں: پیغامات، چینلز، افراد، فائلیں، ترتیبات۔ WebSocket واقعات کے وقت واقعات بھیجتا ہے۔اسکرپٹس، دیگر نظاموں کے ساتھ ہم آہنگی، کسٹم کلائنٹس۔
داخلی ویب ہکسایک خفیہ URL جو چینل میں پیغام پوسٹ کرتا ہے جب کوئی چیز اسے JSON بھیجتی ہے۔الارمز، CI نتائج، مانیٹرنگ، دیگر ٹولز سے اطلاعات۔
خارجی ویب ہکسجب عوامی چینل میں کوئی پیغام ٹریگر ورڈ سے شروع ہو، یا کوئی شخص پیغام کے مینو میں آپ کی کارروائی منتخب کرے، Antimatter آپ کے URL کو کال کرتا ہے اور آپ کا جواب پوسٹ کرتا ہے۔سادہ چیٹ پر مبنی خودکار عملیات، کسی دوسرے ٹول کو پیغام بھیجنا۔
سلاش کمانڈزلوگ /something ٹائپ کرتے ہیں؛ Antimatter آپ کے URL کو کال کرتا ہے اور آپ کا جواب انہیں یا چینل کو دکھاتا ہے۔تلاش، چیٹ سے شروع کی گئی کارروائیاں۔
بوٹسپروگراموں کے لیے بنائے گئے اکاؤنٹس، جن کے اپنے ٹوکنز، بوٹ ٹیگ، اور انٹرایکٹو پیغامات اور ڈائیلاگز ہیں۔اسسٹنٹس، نٹیفائرز، کچھ بھی جو لوگوں سے بات کرتا ہے۔
ایپس (پلگ انز)کوڈ جو سرور (Go) اور ویب ایپ (React) کے اندر چلتا ہے: ہر پیغام پر ہکس، نئے مینو، پینلز، پیغامات کی اقسام، صفحات۔خصوصیات: پولز، نوٹس، کیلنڈرز، ایسے انضمام جو یوزر انٹرفیس کی ضرورت ہوتی ہے۔

انٹرفیس میں، لوگ پلگ انز کو "ایپس" کہتے ہیں۔ یہ رہنما جہاں دونوں الفاظ مددگار ہوں وہاں "ایپس (پلگ انز)" لکھتا ہے، کیونکہ کوڈ، API اور کنفیگریشن ابھی بھی "پلگ ان" کہتے ہیں۔

Mattermost کے ساتھ مطابقت

Antimatter، Mattermost کا فورک ہے۔ Mattermost سرور کے ساتھ جو کچھ کام کرتا ہے، Antimatter کے ساتھ بھی کام کرتا ہے۔

کیا ایک جیسا ہے

  • REST API جو /api/v4 کے تحت دستیاب ہے، اس کی تصدیق (authentication)، اس کا WebSocket اور اس کی غلطیوں کا فارمیٹ۔ سرور ورژن 12.0.0 رپورٹ کرتا ہے، اس لیے کلائنٹس اور ایپس جو سرور کے ورژن کی جانچ کرتی ہیں، انہیں حالیہ Mattermost نظر آتا ہے۔
  • Webhooks اور slash commands، جن میں ان کے Slack-compatible payloads شامل ہیں۔
  • سرور پلگ ان API اور hooks: Antimatter انہیں بالکل اسی طرح برقرار رکھتا ہے۔ سرور کوڈ اسی Go module کے خلاف بنایا جاتا ہے، github.com/mattermost/mattermost/server/public۔ Antimatter صرف اپنے AI سروس کے لیے طریقے (methods) شامل کرتا ہے (دیکھیں AI سروس)۔
  • ویب ایپ پلگ ان رجسٹری: Mattermost کی رجسٹری کا ہر register… طریقہ Antimatter کے دونوں ویب انٹرفیسز میں موجود ہے۔
  • کلائنٹ لائبریریز: Go کلائنٹ model.Client4 اور TypeScript کلائنٹ @mattermost/client (دیکھیں کلائنٹ لائبریریز)۔
  • پلگ ان بنڈلز: .tar.gz فائل جس میں plugin.json مینی فیسٹ شامل ہو۔ Mattermost کی کنج سے سائن شدہ پلگ انسٹال ہوتے ہیں، اور Antimatter کی کنج سے سائن شدہ بھی۔

کیا مختلف ہے

  • دو ویب انٹرفیسز۔ نیا انٹرفیس، Fusion، ڈیفالٹ ہے؛ کلاسیکی Mattermost انٹرفیس ابھی بھی دستیاب ہے۔ Fusion اکثر پلگ ان اجزاء (components) کو رینڈر کرتا ہے، لیکن ان میں سے کچھ کو مختلف جگہ رکھتا ہے اور کچھ کو چھوڑ دیتا ہے۔ ایپ بتا سکتی ہے کہ کون سا انٹرفیس چل رہا ہے۔ دیکھیں Fusion انٹرفیس کی سپورٹ۔
  • اضافی API۔ Antimatter اپنے خصوصیات کے لیے endpoints شامل کرتا ہے: کمیونٹی کی خصوصیات، timeouts، اوپر کے پیغامات، پیغامات کی درخواستیں، چینل اور زمرہ کے اوور رائڈز، چینل ایکسپورٹ، سلسلے کو منتقل کرنا، ماڈل کنکشنز، پیغامات کے اقدامات، اور کمیونٹیز پر نئے فیلڈز۔ دیکھیں Antimatter API میں کیا شامل کرتا ہے۔
  • اضافی پیغام خصوصیات۔ پیغامات کے منسلک فائلز (attachments) پائپ لائن کے مراحل اور ایک چھوٹا چارٹ دکھا سکتی ہیں؛ پوسٹس ان لائن جواب (inline replies) یا اسپوئلرز ہو سکتی ہیں۔
  • ایپس کے لیے اضافی ویب ایپ hooks: کمپوزر میں "+" مینی آئٹم، ایموجی پکر کے ٹیبز، چینل ویو میں پینل، سائیڈ بار چینلز کے نیچے فوٹر، انٹیگریشنز صفحات پر ایک اندراج، ایموجی پکر کے add اور manage ویوز، اور ایک سائیڈ پینل جو نئے ونڈو میں اسی جگہ دوبارہ کھلتا ہے جہاں وہ تھا۔ دیکھیں صرف Antimatter کے hooks۔
  • کوئی لائسنس نہیں۔ لائسنس کی ضرورت کے بغیر ہر فیچر دستیاب ہے۔ لائسنس، ٹرائل اور انٹرپرائز اپ گریڈ کے ایونڈ پوائنٹس ختم کر دیے گئے ہیں؛ GET /api/v4/license/client ان کلائنٹس کے لیے برقرار ہے جو اس کی درخواست کرتے ہیں۔ Mattermost کے پیڈ ایڈیشنز کے لیے بنائے گئے کچھ ایپس خود لائسنس کی جانچ کرتے ہیں اور چلنے سے انکار کر دیتے ہیں۔
  • نام۔ انٹرفیس میں ٹیمز کو کمیونٹیز کہا جاتا ہے، لیکن API اور کوڈ اب بھی team کہتے ہیں۔ ایونارمنٹ ویری ایبلز AM_ پری فکس استعمال کرتے ہیں، کمانڈ لائن ٹول amctl ہے اور سرور بائنری antimatter ہے۔

کوڈ کہاں موجود ہے

ہر چیز اوپن سورس ہے، GitHub پر AntimatterChat آرگنائزیشن میں۔ ہر ریپوزٹری اپنے main برانچ پر کام کرتی ہے۔

ریپوزٹریاس میں کیا ہے
antimatterسرور (Go، server/ میں)، دونوں ویب انٹرفیس (webapp/fusion اور webapp/channels)، TypeScript کلائنٹ اور amctl۔
antimatter-dockerDocker امیجز، جن میں شامل ایپس اور compose فائلز شامل ہیں۔
antimatter-plugin-*ہر شامل ایپ کے لیے ایک ریپوزٹری: polls، todo، notes، whiteboard، calendar، mail، gifs، memes، voice-channels، calls، boards (Kanban)، playbooks، agents اور metrics۔
gifs-serverGIFs ایپ کے استعمال ہونے والا خود میزبان (self-hosted) GIF اور اسٹیکر سروس۔
desktop-app، mobile-app، push-proxyڈیسک ٹاپ اور موبائل ایپس، اور وہ سروس جو فونز کو پش اطلاعات (push notifications) بھیجتی ہے۔
antimatter.chatیہ ویب سائٹ اور اس کی دستاویزات۔
communityAntimatter کے ہر حصے کے لیے مسائل (issues) اور گفتگو۔

شروع کرنے سے پہلے

  • ٹیسٹ سرور حاصل کریں۔ سب سے تیز طریقہ Docker image ہے: Antimatter کی تنصیب دیکھیں۔ Antimatter پر کام کرنے کے لیے، سورس سے بلڈنگ دیکھیں۔
  • چیک کریں کہ سرور کس چیز کی اجازت دیتا ہے۔ کئی انٹیگریشن خصوصیات پہلے سے بند ہیں اور ان کے لیے سسٹم ایڈمن کی ضرورت ہوتی ہے: ذاتی رسائی ٹوکنز (personal access tokens)، بوٹ اکاؤنٹس، یوزر نیم اور آئیکن کی تبدیلی، اور ایپس کا اپ لوڈ۔ ہر صفحہ بتاتا ہے کہ اس کے لیے کون سی ترتیب درکار ہے۔
  • اپنی سائٹ کے URL کو جانیں۔ مثالوں میں https://chat.example.com استعمال ہوتا ہے۔ اسے اپنے سرور کے پتے سے تبدیل کریں۔

اس گائیڈ میں

  • REST API: تصدیق (authentication)، بنیادی وسائل (resources)، پیجینیشن (pagination)، غلطیاں (errors)، ریٹ لمٹس (rate limits)، WebSocket، کلائنٹ لائبریریز، اور Antimatter کی اضافی خصوصیات۔
  • ویب ہکس: داخلہ اور خارجہ ویب ہکس، پے لوڈز (payloads)، منسلک فائلیں اور کارڈز۔
  • سلاش کمانڈز: کسٹم کمانڈز، ان کی درخواست اور جواب، اور خودکار تکمیل (autocomplete)۔
  • بوٹس اور تعاملی پیغامات: بوٹ اکاؤنٹس، بٹن، مینو اور ڈائیلاگز۔
  • ایپس لکھنا: پلگ ان کی ترتیب، سرور ہکس، ویب ایپ رجسٹری، Fusion، ترتیبات، اسٹوریج، تراجم اور پیکنگ۔
  • سورس سے بلڈنگ: سرور، ویب انٹرفیسز، Docker image اور ایپس۔
  • معاشرے میں حصہ لینا: مسائل، پُل ریکسٹس (pull requests)، اسٹائل، تراجم، سیکیورٹی اور لائسنسز۔
سوالات کمیونٹی ڈسکشنز میں خوش آمدید ہیں۔ باگز کمیونٹی آئیوز میں رپورٹ کریں۔
