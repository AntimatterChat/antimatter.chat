سرور چلانا

یہ گائیڈ ان سسٹم ایڈمنسٹریٹرز کے لیے ہے جو Antimatter سرور انسٹال اور چلاتے ہیں۔ یہ فرض کرتا ہے کہ آپ Linux، Docker اور ریورس پراکسیز جانتے ہیں، لیکن Antimatter نہیں۔

ڈیپلائمنٹ میں کیا شامل ہے

Antimatter ایک سیلف-ہوسٹڈ ٹیم چیٹ ہے، جو Mattermost کا فورک ہے۔ مکمل ڈیپلائمنٹ میں یہ اجزاء شامل ہیں۔ صرف پہلے تین اجزاء ضروری ہیں۔

جزویہ کیا کرتا ہےضروری
Antimatter سرورایک Go پروگرام (antimatter) جو پورٹ 8065 پر ویب ایپ، API اور ویب ساکٹس فراہم کرتا ہے، شامل ایپس (پلگ انز) چلاتا ہے، اور پورٹ 8443 پر کال میڈیا منتقل کرتا ہے۔ کمانڈ لائن ٹول amctl اس کا انتظام کرتا ہے۔ہاں
PostgreSQLڈیٹا بیس: پیغامات، صارفین، کمیونٹیز اور، سفارش شدہ سیٹ اپ میں، سرور کی ترتیبات۔ ورژن 15 یا اس سے نیا۔ہاں
فائل اسٹوریجاپ لوڈ شدہ فائلیں، تصاویر اور انسٹال شدہ ایپس: ایک S3-موزوں سروس (compose فائل RustFS چلاتی ہے)، یا ایک مقامی ڈائریکٹری۔ہاں
ریورس پراکسیسرور کے سامنے HTTPS: compose فائل کا Caddy پروفائل، یا آپ کا اپنا nginx۔پروڈکشن کے لیے
GIF سروس (gifs-server)GIF پکر کے لیے GIFs اور اسٹیکرز، آپ کے اپنے کیٹلاگ سے۔ یہ Tenor API سے بات چیت کرتا ہے۔نہیں
پش پراکسیApple اور Google کے ذریعے موبائل ایپ کو اطلاعات بھیجتا ہے۔موبائل اطلاعات کے لیے
rtcd, ایک TURN سروربہت سی کالز کے لیے ایک الگ میڈیا سرور، اور سخت فائر والز کے پیچھے موجود لوگوں کے لیے ایک ریلی۔نہیں
AI اینڈ پوائنٹسکمپوزر کے دوبارہ لکھنے، خلاصوں، ترجمے، پڑھ کر سننے، AI ایجنٹس اور کال ٹرانسکرپشن کے پیچھے موجود ماڈلز، جو ماڈل کنکشنز کے طور پر شامل کیے گئے ہیں: ایک کلاؤڈ پرووائڈر یا آپ کے چلائے جانے والے سرورز۔نہیں

Antimatter میں کوئی لائسنس یا ادائیگی والا ایڈیشن نہیں ہے: سنگل سائن-ان، LDAP، ہائی ایویلیبلٹی، کمپلائنس ایکسپورٹس، ڈیٹا ریٹینشن اور دیگر خصوصیات جو Mattermost اپنے ادائیگی والے پلانز کے لیے محفوظ رکھتا ہے، سب شامل ہیں۔

ضروریات

  • ایک Linux سرور، amd64 یا arm64، کچھ سو لوگوں کے لیے 2 CPU کورز اور 4 GB میموری یا اس سے زیادہ، اور لوگوں کے اپ لوڈ کردہ فائلوں کے لیے ڈسک اسپیس۔
  • Docker Engine Compose پلگ ان کے ساتھ (docker compose)، سفارشی تنصیب کے لیے۔ یا پیکجز کے لیے، systemd والا Debian، Ubuntu، Fedora یا RHEL سے ہم آہنگ سرور۔
  • پروڈکشن کے لیے: سرور کی طرف اشارہ کرنے والا ایک ڈومین نام، اور HTTPS کے لیے پورٹ 80 اور 443 کھلے۔
  • کالز کے لیے: پورٹ 8443، UDP اور TCP، جو کال کرنے والے لوگوں کے لیے رسائی پذیر ہو۔
  • ای میل کے لیے: ایک SMTP سرور جس کے ذریعے Antimatter بھیج سکتا ہے۔

تیز شروع

mkdir antimatter && cd antimatter
curl -fsSLO https://antimatter.chat/compose.yaml
cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
AM_AI_ENCRYPTION_KEY=$(openssl rand -base64 32)
EOF
docker compose up -d

پھر سائٹ کا URL کھولیں اور اپنا اکاؤنٹ بنائیں: پہلا اکاؤنٹ سسٹم ایڈمن بن جاتا ہے۔ انسٹالیشن میں ہر قدم اور انسٹال کرنے کے دیگر طریقے بیان کیے گئے ہیں۔

اس گائیڈ میں

  • تنصیب: Docker Compose، امیجز، پہلا ایڈمن، .deb اور .rpm پیکجز، ریلیس آرکائیو۔
  • کنفیگریشن: ڈیٹا بیس یا فائل میں ترتیبات، AM_ ماحولیاتی متغیرات، سسٹم کنسول، amctl، اور لاگز۔
  • ڈومین اور HTTPS: سائٹ کا URL، Caddy، nginx، اور کلائنٹ کے پتے۔
  • کالز اور وائس: پورٹس، NAT، TURN، rtcd، ٹرانسکرپشن اور کیپشنز۔
  • ای میل اور پش: SMTP، پش پراکسی اور موبائل ایپ۔
  • بندل شدہ ایپس: کون سی ایپس فعال ہیں، ان کی ترتیبات، اور دیگر ایپس کی انسٹالیشن۔
  • AI: ماڈل کنکشنز، درجہ بندی شدہ AI خصوصیات، ایجنٹس، بول چال اور ترجمہ، انکرپشن کلید، اور ڈیٹا کہاں جاتا ہے۔
  • سائن ان اور اکاؤنٹس: سائن اپ، پاسورڈز، MFA، سنگل سائن آن، LDAP، مہمان، اور سیشنز۔
  • بیک اپس اور اپ گریڈز: بیک اپ، ریستور، اپ گریڈ، اور Mattermost سے منتقلی۔
  • آپریشنز: نگرانی، اسکیلنگ، ڈیٹا رٹینشن، کمپلائنس، اور ٹربل شوٹنگ۔
  • سیکیورٹی: ہارڈننگ چیک لسٹ اور باہری کنکشنز۔
  • ڈیسک ٹاپ ایپ کی تنصیب: MSI، Group Policy اور Intune، macOS پروفائلز اور Linux پالیسی فائل۔

کیا آپ سرور کے بجائے کمیونٹی چلانا چاہتے ہیں (چینلز، کردار، مڈریشن)؟ کمیونٹی کی انتظامیہ دیکھیں۔ انٹیگریشنز بنانے ہیں؟ Antimatter پر تعمیر دیکھیں۔

آپ کا پہلا گھنٹہ

  1. انسٹال کریں اور فوراً ایڈمن اکاؤنٹ بنائیں۔
  2. سرور کو اپنے ڈومین پر HTTPS کے پیچھے رکھیں۔
  3. SMTP کنفیگر کریں اور ایک ٹیسٹ ای میل بھیجیں۔
  4. کالز پورٹ کھولیں۔ کمپنی کے لیے، نئے کمیونٹیز کی قسم کو ورک پلیس پر سیٹ کریں، تاکہ چینلز میں کالز فعال ہوں۔
  5. فیصلہ کریں کہ کون سائن اپ کر سکتا ہے، اور MFA کو فعال کریں۔
  6. سیکیورٹی میں باہری کنکشنز کا جائزہ لیں۔
  7. روزانہ بیک اپس سیٹ اپ کریں۔ AI ماڈل کنکشنز شامل کرنے سے پہلے، AI انکرپشن کلید سیٹ کریں۔
