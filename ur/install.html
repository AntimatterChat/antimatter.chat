Antimatter کو اپنے سرور پر چلائیں

ایک فائل، تین کمانڈز، تقریباً دس منٹ: Antimatter اپنے ڈیٹا بیس، فائل اسٹوریج اور GIF سروس کے ساتھ، Docker والے کسی بھی Linux سرور پر۔

دس منٹ میں تیار

آپ کو Docker اور اس کے Compose پلگ ان والا ایک Linux سرور چاہیے، جس میں کم از کم 2 CPU کورز اور 4 GB میموری ہو۔

1. compose فائل ڈاؤن لوڈ کریں

$ mkdir antimatter && cd antimatter
$ curl -fsSLO https://antimatter.chat/compose.yaml

2. رینڈم پاس ورڈز کے ساتھ اس کی ترتیبات بنائیں

$ cat > .env <<EOF
SITE_URL=http://localhost:8065
POSTGRES_PASSWORD=$(openssl rand -hex 24)
S3_SECRET_KEY=$(openssl rand -hex 24)
GIFS_API_KEY=$(openssl rand -hex 24)
EOF

SITE_URL کو اس ایڈریس پر سیٹ کریں جو لوگ استعمال کریں گے، جیسے لوکل نیٹ ورک پر http://192.168.1.20:8065۔

3. اسے چلائیں

$ docker compose up -d

پہلی بار چلنے میں ایک دو منٹ لگتے ہیں جب تک ڈیٹا بیس بنتا ہے۔ پھر اپنے براؤزر میں SITE_URL کھولیں اور اپنا اکاؤنٹ بنائیں: پہلا اکاؤنٹ سسٹم ایڈمن بن جاتا ہے، اور سیٹ اپ آپ کی پہلی ٹیم بنانے میں رہنمائی کرتا ہے۔

اپنے ڈومین اور HTTPS کے ساتھ

اپنے ڈومین کا ایک DNS ریکارڈ سرور کی طرف پوائنٹ کریں، پورٹس 80 اور 443 کھولیں، اور ڈومین کو .env میں شامل کریں:

$ cat >> .env <<EOF
DOMAIN=chat.example.com
EOF
$ sed -i 's|^SITE_URL=.*|SITE_URL=https://chat.example.com|' .env
$ docker compose --profile https up -d

Caddy، Let's Encrypt سے سرٹیفکیٹ حاصل کرتا ہے اور خود ہی اس کی تجدید کرتا رہتا ہے۔

کیا کیا چلتا ہے

  • antimatter: سرور، اپنی ایپس کے ساتھ (نوٹس، وائٹ بورڈز، وائس چینلز، کالز، پولز اور دیگر)۔ یہ ڈسک پر کچھ نہیں رکھتا: اس کی ترتیبات ڈیٹا بیس میں اور فائلیں اسٹوریج سروس میں ہوتی ہیں، اس لیے کنٹینر کو کسی بھی وقت بدلا جا سکتا ہے۔
  • postgres: ڈیٹا بیس۔
  • files: RustFS، اپ لوڈ کی گئی فائلوں کے لیے S3 سے مطابقت رکھنے والا اسٹوریج۔
  • gifs: Antimatter کی GIF اور اسٹیکر سروس، ایک ابتدائی اسٹیکر پیک کے ساتھ۔
  • https: Caddy، صرف https پروفائل کے ساتھ۔

ڈیٹا بیس، اسٹوریج اور GIF سروس ایک نجی نیٹ ورک پر ہوتے ہیں جس تک صرف Antimatter کی رسائی ہے۔

اگر GIF پکر خالی رہے تو سسٹم کنسول › پلگ انز › GIFs کھولیں، سروس URL کو http://gifs:8080/v2 پر اور API کی کو اپنی .env فائل کی GIFS_API_KEY پر سیٹ کریں۔

اپ گریڈ اور بیک اپ

# تازہ ترین امیجز پر اپ گریڈ کریں
$ docker compose pull && docker compose up -d
# ڈیٹا بیس کا بیک اپ لیں
$ docker compose exec postgres pg_dump -U antimatter antimatter > antimatter.sql

files والیوم کا بھی بیک اپ لیں، یا کسی بھی S3 ٹول سے اسٹوریج کو ریپلیکیٹ کریں۔ nginx اور اپنے سرٹیفکیٹس والے سیٹ اپ کے لیے antimatter-docker میں پروڈکشن فائلیں دیکھیں۔

ریلیز آرکائیو کے ساتھ

  1. PostgreSQL ڈیٹا بیس اور اس کا یوزر تیار کریں۔
  2. آرکائیو (antimatter-<os>-<arch>.tar.gz) کو، مثال کے طور پر /opt/antimatter میں، ان پیک کریں اور config/config.json میں SqlSettings.DataSource (یا MM_SQLSETTINGS_DATASOURCE انوائرنمنٹ ویری ایبل) کو ڈیٹا بیس کی طرف پوائنٹ کریں۔
  3. سرور کو bin/antimatter سے، بغیر خصوصی اختیارات والے یوزر کے طور پر، شروع کریں اور http://localhost:8065 کھولیں۔ بنایا جانے والا پہلا اکاؤنٹ سسٹم ایڈمن بن جاتا ہے۔

bin/amctl چلتے ہوئے سرور کو کمانڈ لائن سے منظم کرتا ہے (خود سرور پر bin/amctl --local، ServiceSettings.EnableLocalMode کے ساتھ)۔

اگلے مراحل

  • کالز: کالز کا پورٹ کھولیں (ڈیفالٹ طور پر UDP اور TCP 8443) تاکہ آواز اور ویڈیو سرور تک پہنچ سکیں۔
  • ای میل: دعوت ناموں اور اطلاعات کے لیے SMTP کنفیگر کریں۔
  • AI: Agents کی ترتیبات میں ایک ماڈل شامل کریں؛ کوئی بھی OpenAI سے مطابقت رکھنے والی API کام کرتی ہے، بشمول وہ سرور جو آپ خود چلاتے ہیں۔
  • آواز اور ترجمہ: کال ٹرانسکرپشن، بلند آواز میں پڑھنے اور خودکار ترجمے کو ان اسپیچ ٹو ٹیکسٹ، ٹیکسٹ ٹو اسپیچ اور ترجمے کے ماڈلز سے جوڑیں جو آپ خود چلاتے ہیں۔
